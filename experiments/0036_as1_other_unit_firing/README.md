## 0. 問いと主張の範囲

### 0.1 問い

0035 では、二経路近似（源と受だけを残し、他の Unit と t の後の可塑性を無視する近似）の予測が外れた 186 の出来事のうち、185 で他の Unit が区間の中で発火していた（0035 §15.4。記述）。設計メモは、他の Unit の関わり方を少なくとも二つに分けた（設計メモ §0.1 の 2）。

- **(i) 発火の変化を通す**：e が受の発火を変え、それが他の Unit の発火の時刻を変え、その違いが源に届く
- **(ii) 同じ発火の伝達を通す**：他の Unit の発火の時刻は F と N で同じだが、その発火の伝達が、源と受の状態を変え、受 → 源 の効果の条件を変える

この実験の主の問いは、(i) に介入で触れるものである。

> **問い Q1-P**：同じ分岐の前の状態 Σ_t から、F の中で**他の Unit の発火の時刻だけを N のものに固定した系 F^{o:=N}** を作る。固定すると帰還の効果の符号が変わる出来事（s_e^{fix} ≠ s_e）が、評価できる出来事の 1 割以上を占める個体は、多数を占めるか。

- これは推定対象 A（e がその時点の重み・状態を通って次の意図に与える効果）について、他の Unit の発火の時刻の変化への依り方を問う
- **2 × 2（他の Unit の伝達の遮断の有無 × e の有無）は、必ず報告する因果の対照として、報告の形を事前に固定する**（§6.1。設計メモ §3.5）。主の判定にしない理由は §1.2 の 2

### 0.2 主張の形（成立したとき）

「AS1（C0 の力学と可塑性のまま、L ＝ 2、外の刺激なし）で、W に 10 以上の出来事がある個体のうち、他の Unit の発火の時刻を N のものに固定すると帰還の効果の符号が変わる出来事が、評価できる出来事の 1 割以上を占める個体が、事前に決めた基準（§5）を超えて多かった。」

- 主張の水準は、**この介入（発火の時刻の固定）のもとでの、条件付きの対比**の頻度について、まで（設計メモ §4.3・§7）
- s_e^{fix} ≠ s_e は、「他の Unit の発火の時刻を N のものにそろえると、符号が自然な系と違う」ことを意味する。**「他の Unit を通る経路が効果を運んだ」「他の Unit を通らない効果はこれだけ」とは言わない**。固定した系でも、他の Unit は、e に依りうる重みで源と受を駆動する（設計メモ §4.3）
- 個体をまたぐ部分は、出生時の状態を独立・同一分布の標本と見なした統計の判断である

### 0.3 主張しないこと

- 他の Unit が帰還の効果の向きを決める機構であること。0035 の外れの原因を説明したこと（設計メモ §6.4・§7）
- (i) と (ii) のどちらが主かを、一意に識別したこと
- 不成立のときに「他の Unit の発火の時刻は効かない」「(ii) が主である」と言うこと（総括 §5.3）
- 推定対象 B・C、行動の選択（S3）、学習、意味、目的、価値、感じ方
- 0034 の J_A・0035 の J_S の結果を変えること

### 2.1 本体と出来事

- 0035 §2.1・§2.2 と同じ。各 seed について、AS1 の道具の `build(seed, delay=2, multiplicity="per_reservation", respond=True, exogenous=())` で組み立て、Pulse 1 から 2099 まで走らせる。本体には介入をしない

### 2.2 系の一覧

どの系も、Pulse t の処理の後の本体の複製から作る（M1）。介入は Pulse t の境界で一度だけ宣言し、解除しない。

|---|---|---|---|---|---|
| **F** | 届く | そのまま | 規則どおり | τ_F（本体の意図の記録）か t ＋ H | 本体 |
| **N** | 取り消す | そのまま | 規則どおり | 最初の意図か t ＋ H | 0034・0035 と同じ |

| **N^{o:=F}** | 取り消す | 発火の時刻を F のものに固定 | 規則どおり | 最初の意図か c ＝ F の止まる Pulse | 逆の順（感度の分析） |

- 「最初の意図」は、源の Unit の発火の数で検知する（`advance_until_first_intent`。0034・0035 と同じ）
- F の止まる Pulse は、本体の意図の記録から τ_F が t ＋ H までに決まれば τ_F、なければ t ＋ H
- 系の数は、出来事ごとに 16 と、O7 の走り直し（§7）

### 2.3 他の Unit の発火の時刻の固定（設計メモ §4.1・§4.2）

- 対象は他の Unit 一つだけ。区間は、Pulse t の処理の後から、その系が止まるまで。Pulse t の他の Unit の発火とその駆動は Σ_t に入っていて、どの系でも同じ
- **決まり方**：他の Unit の内部の状態は、Core の `SimpleActivityDynamics.advance` で自然な力学のまま計算し（道具の中で式を書き直さない）、発火するかどうかだけを、指定した列で決める
  - 列が「発火」の Pulse：自然な発火と同じ更新（活動を 0 に戻す、不応、順応の増分、発火の数）。`advance` の発火の枝の更新と同じ
  - 列が「発火しない」の Pulse：閾値を越えていても、発火の更新をしない。`advance` の発火しない枝の更新と同じ
  - C0 の不応の Pulse の数は 0 なので、不応の途中で列が「発火」を求めることはない。起きたら道具は止まり、その実行は無効（O8）
- **出力の駆動と可塑性**：発火した Pulse に、その系のその時点の重み（Pulse の冒頭に固定した重み）で駆動が作られ、次の Pulse に届く（runtime の順序のまま）。可塑性の更新は、指定した発火を `fired` に入れて、規則どおりに行う（今の規則は、送り手・受け手が発火したかどうかだけを使う）
- **指定する列**は、参照の系の、区間 (t, 参照の止まった Pulse] の他の Unit の発火の列。∅ なら空の列（区間 (t, t ＋ H]）
- **恒等の条件**：指定した列が、その系自身の自然な発火の列と同じなら、固定した系は自然な系と、列が定義された区間の全体で一致する（O10）
- **固定しないもの**：他 → 源・他 → 受 の重み。その系の可塑性で動き、e に依りうる（設計メモ §4.3）
- **部品の入れ方**：Core は変えない。Core には、組み立てた後に Unit を差し替える公開の口がない。そのため、部品の入れ方（AS1 の道具の `build` に、既定では何もしない包みの口を足す、など）は道具の PR で決める。AS1 の道具を変える場合は、既定の動作が変わらないことを、AS1 の契約テストの全件の通過で示す

### 2.4 伝達の遮断と、発火の抑制（設計メモ §3.5）

- **遮断（blk）**：AS1 の道具の FB-1（`InterventionConnections`。伝達に渡す重みを 0 にし、中の重みは規則どおり動く）を、対象を 他 → 源・他 → 受 の 2 本にして使う。Pulse t の境界で宣言するので、Pulse t ＋ 1 の冒頭の重みの固定から効く
  - Σ_t に入っている、Pulse t に作られた駆動（Pulse t の他の Unit の発火によるものを含む）は、そのまま t ＋ 1 に届く。遮断されるのは、Pulse t ＋ 1 以後の発火による伝達である
  - 他の Unit は発火し続け、その発火による可塑性の更新も規則どおり
- **抑制（o:=∅）**：他の Unit の発火の時刻を「発火しない」に固定する（§2.3 の決まり方で、列を空にする）。他の Unit にかかわる接続の更新も、発火がないものとして行われる
- 遮断と抑制は違う操作として扱い、同一視しない

## 3. 符号と、打ち切りの規則

### 3.1 τ と打ち切り

- 系 X は、t の後の最初の意図の時刻 τ_X か、打ち切りの Pulse c_X で止まる
- τ_X が見つかれば「既知」。見つからなければ「c_X で打ち切り（τ_X ＞ c_X）」
- F・N・blk・o:=∅・cf の系は c ＝ t ＋ H。固定した系（o:=N・o:=F）は c ＝ 参照の系の止まった Pulse（≤ t ＋ H）

### 3.2 符号の規則（設計メモ §3.4）

系 X と Y の差 τ_Y − τ_X の符号：
- 両方が既知：sign(τ_Y − τ_X)
- X が既知、Y が c_Y で打ち切り：c_Y ≥ τ_X なら ＋。そうでなければ ？
- Y が既知、X が c_X で打ち切り：c_X ≥ τ_Y なら −。そうでなければ ？
- 両方が打ち切り：？
- 値（差そのもの）は、両方が既知のときだけ求まる
- c がどちらも t ＋ H なら、0034 §2.3 の表と同じになる

### 3.3 出来事ごとの量

| 量 | 定義（X → Y の順で τ_Y − τ_X） |
|---|---|
| d_e・s_e | F → N（0034・0035 と同じ） |
| d_e^{fix}・s_e^{fix} | F^{o:=N} → N（**主の対比**） |
| d_e^{chg}・s_e^{chg} | F → F^{o:=N} |
| d_e^{fix′}・s_e^{fix′} | F → N^{o:=F}（逆の順） |
| d_e^{chg′}・s_e^{chg′} | N^{o:=F} → N（逆の順） |
| d_e^{blk}・s_e^{blk} | F^{blk} → N^{blk} |
| d_e^{∅}・s_e^{∅} | F^{o:=∅} → N^{o:=∅} |
| d_e^{cf}・s_e^{cf} | F^{cf} → N^{cf} |

- 恒等式 d_e ＝ d_e^{fix} ＋ d_e^{chg}（と逆の順の d_e ＝ d_e^{fix′} ＋ d_e^{chg′}）は、三つの τ がすべて既知のときだけ使う
- **d_e^{chg} ＝ 0 の近道**（設計メモ §3.3）：(1) τ_F が既知で、N の止まった Pulse ≥ τ_F、かつ (2) (t, τ_F] で他の Unit の発火が F と N で同じ、のときだけ、F^{o:=N} ＝ F が恒等の条件から従う。この実験では F^{o:=N} を常に走らせ、近道が成り立つ出来事では F^{o:=N} ＝ F を確かめる（O10）。近道で値を置き換えることはしない

## 4. 主の判定 J_P

### 4.1 個体ごとの量

- **適用できる個体** ＝ 本体の W に出来事が 1 つ以上ある個体（0034・0035 と同じ）
- **判定の母集団** ＝ 適用できる個体のうち、本体の W に出来事が **10 以上**ある個体。本体の記録だけで、反実仮想の前に決まる（A3 を満たす）
- **評価できる出来事**（主の判定の）＝ s_e ≠ ？ かつ s_e^{fix} ≠ ？ の出来事
- 母集団の個体 i について
  - n_i ＝ 評価できる出来事の数
  - k_i ＝ そのうち s_e^{fix} ≠ s_e の出来事の数
  - r_i ＝ k_i ÷ n_i（n_i ＝ 0 なら null）
  - **個体の事象 P_i** ＝ n_i ≥ 1 かつ **10 k_i ≥ n_i**（r_i ≥ 0.1 を整数で比べる）
  - n_i ＝ 0 の個体は、母集団から除かず、P_i 不成立として数える（成立に不利な側）

### 4.2 判定 J_P

- m ＝ 判定の母集団の個体の数。m ＜ 10 なら**判定不能**
- m ≥ 10 なら、**P_i が成り立つ個体の数 ≥ k(m)** のとき J_P が成立する。k(m) は、二項分布 Bin(m, 1/2) の上側の確率が 0.05 以下になる最小の数（§5.1）

### 4.3 向き・c・母集団の閾値を、この形にした理由（結果を見る前の理由）

**向き：設計メモの見込みの訂正**
- 設計メモ §0.1 の 5 は、「受 → 他 の 1 回の駆動（≤ w_max ＝ 0.01）は、閾値（約 0.5）までの距離に比べて小さいので、他の Unit の発火の時刻を動かすことは少ない」と見込んだ。この理由づけは不十分だった
  - 比べるべきは、閾値までの距離ではなく、**閾値を越える直前の、1 Pulse あたりの差の縮まり方**である（0035 の設計メモ `docs/as1-state-dependent-feedback-design.md` §3.3 の「感度」）
  - C0 の Unit は、順応がゆっくり戻ることで閾値を越える区間をもちうる。その区間では差の縮まり方が遅く、小さい駆動でも越える Pulse がずれうる
  - 同じ大きさの駆動（受 → 源、≤ 0.01）で、源の次の発火の時刻が変わる出来事（d_e ≠ 0）は、0034 で 552 のうち 217、0035 で 1,217 のうち 335 あった（記述）。受 → 他 の駆動でも、他の Unit の発火の時刻が動くことは、まれではないと見込む
  - この訂正は、この案を書く中で、既に公表した集計（上の数）と力学の性質から気づいたもので、新しいデータは見ていない
- そのため、主の判定の向きを「**他の Unit の発火の時刻の固定で符号が変わる出来事が、まれではない**」にする
- 向きの由来の開示：この向きは、0034・0035 の結果を見た後に立てた。新しい seed で確かめる

**c ＝ 0.1**
- 「まれではない」の下限として、評価できる出来事の 1 割を事前に固定する。区切りのよい慣例の値で、データから選んでいない（0036 の seed の値はまだ一つも見ていない。0034・0035 の raw には s_e^{fix} がない）

**母集団の閾値 10 ＝ 1/c**
- r_i が c の刻みを表せる最小の分母にする。出来事が 10 未満の個体では、1 つの出来事で r_i が c を越え、「1 割以上」が「1 つでもある」と同じになる（設計メモ §6.3 は、「1 つでもある」を個体の事象に使わないとした）
- 本体の出来事の数で決めるので、評価できる出来事の数 n_i は 10 を下回りうる（打ち切りの ？ があるとき）。その個体では、P_i は「1 つでもある」に近づく。n_i の分布と、評価できない出来事の数を R2 で報告する
- 0035 で、この閾値で除かれる個体の数を見ている（§11 で開示）

**構造的に決まる個体（常設チェック A7）**
- 他の Unit が区間でずっと発火しない個体などでは、s_e^{fix} ＝ s_e が構造的に続き、P_i は不成立になる。これは成立に不利な側の凍結なので、(a) 問いの一部として母集団に含める（除かない）

### 4.4 帰無仮説と、その条件

- **推論の対象**：本体の W に出来事が 10 以上ある個体の母集団
- **H₀^P**：出生時の状態（seed）を独立・同一分布の標本と見なす。この母集団で、P(P_i) ≤ 1/2
- 個体の事象 P_i は、個体ごとのデータだけで決まる。母集団の条件（出来事が 10 以上）は本体の記録だけで決まる。したがって、P_i が成り立つ個体の数は、H₀^P のもとで Bin(m, 1/2) に確率的に支配され、P(J_P 成立 | H₀^P) ≤ 0.05
- r_i の精度は分母 n_i で違う。個体ごとの n_i と、評価できない出来事の数を報告する（R2）
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない
- 個体の中の出来事を、独立の標本として数えない

### 4.5 結果の扱い（総括 §5.3）

| 結果 | 言えること | 言えないこと |
|---|---|---|
| 成立 | この介入のもとで、他の Unit の発火の時刻の固定で符号が変わる出来事が 1 割以上の個体が、母集団の多数を占めた | 他の Unit が効果を運ぶ機構であること。0035 の外れの原因の説明 |
| 不成立（m ≥ 10） | その基準では、1 割以上の個体の多数を確立できなかった | 「他の Unit の発火の時刻は効かない」「(ii) が主」。不存在の証明ではない。識別に役立つ陰性の結果か、情報の足りない不成立かは、§12 の材料で評価して示す |
| 判定不能（m ＜ 10） | 問いに答えが出ていない | 何も足さない。理由を示し、再設計か新しい事前登録かを判断する。同じ seed で走らせ直さない |
