## 1. 問い

```text
0013  内部の活動だけで、接続の状態が自己形成する
0014  Life History の時間配置で、接続の状態が変わる。その weight 差は活動へ因果的に効く
0015  その Life History 由来の A→B／A→C の weight contrast の差は、外からの入力がなくなった後の終端でも同じ向きか
```

> **同じ個体（同じ Birth State）に、刺激の数・時刻は同じで順序だけ違う経験を与える。経験の終わりにあった 2 つの履歴のあいだの A→B／A→C の weight contrast の差は、同じ長さの無入力の自発活動の終端でも、同じ向きで存在するか**

名前は「記憶」ではなく **history-induced A→B／A→C weight-contrast difference の終端での保持** とする。直接測るのは、接続の状態の全体（痕跡・規則の状態を含む）ではなく、

```text
W ＝ w(A→B) − w(A→C)
D ＝ W_ordered − W_shuffled
```

だけである。成り立っても「記憶した」「接続の状態が保持された」とは書かず、「事前登録した区間の終端でも、経験の終わりの D0 と同じ向きの weight contrast の差が存在した」と書く。

**D の読み方**：同じ seed で Birth State を固定しても、2 条件は札が分かれた後、時間配置 × 自発活動 × Unit の状態 × 痕跡 × 可塑性 が相互作用して別々の軌道になる。したがって D は「履歴が作った部分だけ」を取り出したものではなく、**時間配置だけを変えたことによる総因果効果** である（0014 の解釈と同じ）。

### 決めないこと・主にしないこと

- **形成**（順序ありのほうが大きく形成されるか）は問わない。0014 の w（19/20）で見た。0015 は、経験の終わりに存在した差が **持続したか** だけを問う
- **出生の向きとの関係**（経験の向きが、出生由来の自己形成の向きと同じか逆か）は分類しない。0013 の b_ij は Birth State そのものではなく、可塑性なしの双子を走らせた発火の順番の代理で、しかも組ごとの向きを 1 つのスカラーへ畳む新しい式が要る（常設チェック A6）。0015 では生の Birth State と a_AB・a_AC の軌跡を保存するだけにし、差が消えた・反転した場合の理由は次の問いで直接問う
- **活動の読み出し** は入れない。持続した差が活動に出るかは、必要なら後で（活動への出方は 0014 で見た）
- 力学・可塑性・設計図の値は変えない（0014 と同じ）

## 4. 指標と判定

```text
W(t)  ＝ w(A→B) − w(A→C)                 （本体の Pulse t の処理の終わり）
D(t)  ＝ W_ordered(t) − W_shuffled(t)    （同じ seed の 2 条件）
D0    ＝ D(12000)
DT    ＝ D(24000)

P     ＝ sign(D0) × DT                   主の判定 p：P ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 p** | D0 ≠ 0 の個体（D0 ＝ 0 は N/A） | P ＞ 0 | 成り立った個体数 ÷ 適用対象の個体数 ≥ 0.8 |

- P ＞ 0 は「事前登録した区間（12000 Pulse の無入力の自発活動）の終端でも、D0 と同じ向きの weight contrast の差が存在した」と読む
- **終端の判定である**。区間のあいだずっと差が残り続けたことは保証しない（途中で 0 を跨いで反転し、また戻って終端で同じ向き、でも成り立つ）。区間のあいだの連続した保持を主にすると別の判定になるので、0015 では主にしない。途中の振る舞いは記録（§5）で見る
- **D0 ＝ 0 の個体は N/A**（持続を問う差が始めに存在しない。常設チェック A3）。0 点として混ぜず、分母に入れない。N/A の個体数は報告する。適用対象が 0 個体なら、判定そのものが N/A
- 0.8 は 0012〜0014 と同じ比

### 式の形の理由（常設チェック A6）

- **差 D(t) を使う理由**：2 条件は同じ Birth State・同じ刺激の数・同じ刺激の時刻から始まり、違うのは時間配置だけなので、差は時間配置を変えたことの総因果効果になる（自己形成などとの相互作用を含む。上の「D の読み方」）。W の単位（重み）のまま、新しい正規化を入れない
- **sign(D0) × DT にする理由**：問いは「始めにあった差の向きが保たれたか」。向きは窓（無入力の区間）より前に決まる D0 から取るので、自己参照にならない（常設チェック A2）。D0 の向きを決めずに DT ＞ 0 とすると、「順序ありのほうが大きく形成されたか」（形成）と「形成された差が残ったか」（持続）が混ざる
- **比 DT／D0 にしない理由**：分母が 0 になりうる、D0 が小さいとき値が暴れる、なぜこの正規化なのかが新しい恣意性になる。主は連続量 P そのものとし、「＞ 0」は「同じ側に残った／0 を跨いだ」という自然な境界としてだけ使う
- 「どれだけ変わったか」は、比ではなく、記録の P − |D0|（**始めの向きに揃えた終端の変化**。負なら始めの向きの側で小さくなった）として出す（探索的）

### 符号が構造上決まっていないことの確認（常設チェック A1）

0014 の p は、単調な力学と介入の定義から符号が決まっていた。0015 の P について、事前登録の段で次を確かめる。

- **解析（符号を保つ規則が導けないこと）**：可塑性 v1.1 では、各相互の組で w(i→j) ＋ w(j→i) ＝ w_max が保たれ、W ＝ (a_AB − a_AC)／2 と書ける（`docs/plasticity-v1.1-scale.md` §8）。a_AB・a_AC は、それぞれの組の 2 つの Unit の発火の前後関係で、どちらの向きにも動く（釣り合った窓：d ≥ 1 で強め、d ≤ −1 で同じ大きさで弱め、柔らかい上限・下限）。経験の終わりの後、2 条件は別々の発火の列を持つ別々の個体で、その発火の前後関係は Unit の状態・痕跡・重みから決まる。方程式・runtime の順序から、D の符号を保つ規則（0014 の単調性のようなもの）は導けなかった。**ただし「導けなかった」ことは、符号を保つ規則がないことの証明ではない**。証明は次の構成的な契約テストで行う
- **合成の runtime の全状態からの契約テスト**（道具の段で書く。自然な seed の結果は見ない）：可塑性の規則に発火の列を直接流すのではなく、妥当な合成の runtime の全状態（Unit の状態・痕跡・重み。どれも実装が取りうる範囲で、組の和 ＝ w_max を満たす）を 2 つ（ordered 側・shuffled 側に当たるもの）作り、実物の runtime で入力なしで 12000 Pulse 進める。**同じ D0 ＞ 0** から、(i) DT ＞ 0 になる組と (ii) DT ＜ 0 になる組の **両方が実装上ありうる** ことを、具体的な状態で示す
- **smoke で正負の両方が出ることは要求しない**（それは現象への条件になる。常設チェック D1）

### 10.3 事後の観察：A が区間中に一度も発火しなかった 4 個体では、D がほぼ凍結していた（判定ではない）

結果を見たあとに、次のことに気づいた。

- **観測されたこと**：6002・6008・6011・6013 の 4 個体では、12001〜24000 に A の Unit が両条件とも一度も発火しなかった。この 4 個体では D がほぼ凍結していた（P − |D0| ＝ 6002：−3.34 × 10⁻⁹、6008：−1.50 × 10⁻¹⁶、6011：＋9.91 × 10⁻¹¹、6013：0）
- **仕組み（A が発火しなくても W は厳密には更新されうる）**：可塑性 v1.1 では、A→B が強まるのは B の発火のときの A の痕跡の大きさに比例し、B→A が弱まるのも同じ A の痕跡による（A–C も同じ）。Pulse 12000 の時点で A の痕跡が残っていれば、その後 B・C が発火したときに a_AB・a_AC は少し更新される。A が新たに発火しないので痕跡は補充されず速く減衰し、結果として W はほぼ凍る。「構造上動けない」のではない
- **出生時の ρ_A との対応（事後の対応関係）**：この 4 個体は、出生時の ρ_A（＝ 内在的駆動 ／ ((1 − decay) × 閾値)。内在的駆動だけのときの活動の平衡点が閾値に届くか）がどれも 1 未満（0.94〜0.98）だった。ただし 0015 の無入力は「外からの感覚の入力がない」だけで、B・C → A の網の中の駆動はある。したがって「ρ_A ＜ 1 なら無入力で A は発火できない」とは言えない。言えるのは、今回 ρ_A ＜ 1 だった 4 個体で、実際に A が 0 回だったという対応だけである
- **post-hoc の部分集合**：内在的駆動だけでも自発発火できる出生時の指標 ρ_A ≥ 1 による post-hoc の部分集合（16 個体）では、P ＞ 0 は 15／16（満たさないのは 6014）。事前登録していないので、判定には使わない
- **読み方**：0015 の問いは「実際に起きた無入力の自発力学の後でも、終端で同じ向きか」なので、何も書き換えられずに残った場合も、判定としては正当な成立である。ただし 19／20 には、(i) 自発力学の中で weight contrast が動きながら同じ符号を保った個体と、(ii) weight contrast が実効的に凍結していたため同じ符号だった個体（上の 4 個体）の両方が含まれる。結論はこの限定つきで読む

### 10.4 次へ
