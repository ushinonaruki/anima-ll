## 1. 問い

```text
0013  内部の活動だけで、接続の状態が自己形成する
0014  Life History の時間配置で、接続の状態が変わる。その weight 差は活動へ因果的に効く
0015  その Life History 由来の接続の状態の差は、外からの入力がなくなっても残るか
```

> **同じ個体（同じ Birth State）に、刺激の数・時刻は同じで順序だけ違う経験を与える。経験の終わりにあった 2 つの履歴のあいだの接続の状態の差は、同じ長さの無入力の自発活動の後にも、同じ向きで残っているか**

名前は「記憶」ではなく **history-induced ConnectionState difference の persistence**（経験が作った接続の状態の差の持続）とする。成り立っても「記憶した」とは書かず、「経験によって生じた接続の状態の差が、その後の無入力の自発力学の中でも保持された」と書く。

### 決めないこと・主にしないこと

- **形成**（順序ありのほうが大きく形成されるか）は問わない。0014 の w（19/20）で見た。0015 は、経験の終わりに存在した差が **持続したか** だけを問う
- **出生の向きとの関係**（経験の向きが、出生由来の自己形成の向きと同じか逆か）は分類しない。0013 の b_ij は Birth State そのものではなく、可塑性なしの双子を走らせた発火の順番の代理で、しかも組ごとの向きを 1 つのスカラーへ畳む新しい式が要る（常設チェック A6）。0015 では生の Birth State と a_AB・a_AC の軌跡を保存するだけにし、差が消えた・反転した場合の理由は次の問いで直接問う
- **活動の読み出し** は入れない。持続した差が活動に出るかは、必要なら後で（活動への出方は 0014 で見た）
- 力学・可塑性・設計図の値は変えない（0014 と同じ）

## 4. 指標と判定

```text
W(t)  ＝ w(A→B) − w(A→C)                 （本体の Pulse t の処理の終わり）
D(t)  ＝ W_ordered(t) − W_shuffled(t)    （同じ seed の 2 条件）
D0    ＝ D(12000)
DT    ＝ D(24000)

P     ＝ sign(D0) × DT                   主の判定 p：P ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 p** | D0 ≠ 0 の個体（D0 ＝ 0 は N/A） | P ＞ 0 | 成り立った個体数 ÷ 適用対象の個体数 ≥ 0.8 |

- P ＞ 0 は「経験の終わりに存在していた 2 つの履歴のあいだの差が、12000 Pulse の無入力の自発活動の後にも同じ向きで残った」と読む
- **D0 ＝ 0 の個体は N/A**（持続を問う差が始めに存在しない。常設チェック A3）。0 点として混ぜず、分母に入れない。N/A の個体数は報告する。適用対象が 0 個体なら、判定そのものが N/A
- 0.8 は 0012〜0014 と同じ比

### 式の形の理由（常設チェック A6）

- **差 D(t) を使う理由**：2 条件は同じ Birth State から始まる。0013 の自己形成（出生由来の向き）は 2 条件の両方に働くので、2 条件の差をとることで、履歴が作った部分だけを問う。W の単位（重み）のまま、新しい正規化を入れない
- **sign(D0) × DT にする理由**：問いは「始めにあった差の向きが保たれたか」。向きは窓（無入力の区間）より前に決まる D0 から取るので、自己参照にならない（常設チェック A2）。D0 の向きを決めずに DT ＞ 0 とすると、「順序ありのほうが大きく形成されたか」（形成）と「形成された差が残ったか」（持続）が混ざる
- **比 DT／D0 にしない理由**：分母が 0 になりうる、D0 が小さいとき値が暴れる、なぜこの正規化なのかが新しい恣意性になる。主は連続量 P そのものとし、「＞ 0」は「同じ側に残った／0 を跨いだ」という自然な境界としてだけ使う
- 「どれだけ弱まったか」は、比ではなく、記録の P − |D0|（絶対の変化）として出す（探索的）

### 符号が構造上決まっていないことの確認（常設チェック A1）

0014 の p は、単調な力学と介入の定義から符号が決まっていた。0015 の P について、事前登録の段で次を確かめる。

- **解析**：可塑性 v1.1 では、各相互の組で w(i→j) ＋ w(j→i) ＝ w_max が保たれ、W ＝ (a_AB − a_AC)／2 と書ける（`docs/plasticity-v1.1-scale.md` §8）。a_AB・a_AC は、それぞれの組の 2 つの Unit の発火の前後関係で、どちらの向きにも動く（釣り合った窓：d ≥ 1 で強め、d ≤ −1 で同じ大きさで弱め、柔らかい上限・下限）。経験の終わりの後、2 条件は別々の発火の列を持つ別々の個体で、2 条件の W を結びつける保存量はない。したがって D(t) の符号を保つ・変える規則は、方程式からは導けない
- **合成の入力での契約テスト**（道具の段で書く。自然な seed の結果は見ない）：実装の可塑性の規則に、手で作った発火の列を与える。同じ D0 ＞ 0 から始めて、(i) DT ＞ 0 になる列と、(ii) DT ＜ 0 になる列の **両方が実装上ありうる** ことを示す
- **smoke で正負の両方が出ることは要求しない**（それは現象への条件になる。常設チェック D1）

## 6. 操作の確認（invalid なら判定の量は計算も表示もしない）

| 確認 | 内容 |
|---|---|
| 刺激の数 | 刺激の列と、本体が受けた感覚の出来事の両方で、A・B・C が 200 ずつ（2 条件とも）、時刻の集合が 2 条件で同じ。順序ありでは各 A の 2 Pulse 後に B、30 Pulse 後に C（0014 と同じ） |
