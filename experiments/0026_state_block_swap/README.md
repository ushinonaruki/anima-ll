## 0. 問いと主張の範囲

### 0.1 問い

> **0025 と同じ C0・経験・試し・読み出しで、経験の終わりの共通の時刻 T に、受け手の個体 W1 の状態のうち一方の塊――6 本の重み、または 3 Unit の状態（activity・順応・痕跡）――だけを、ドナーの個体のものに替える。ドナーが順序のある経験の個体 O のとき、その後の試しへの応答 L は、ドナーが試行の中の並べ替えの個体 W2〜W20 のときの分布（介入の参照）の中で典型的でないか。重みの塊と Unit の塊のそれぞれについて問う**

- 設計の整理の **Q1**（ある背景の状態で成分を別の個体の値に替えると、読み出しが変わるか）に、**介入の参照（設計の整理 §3.4：参照のドナーどうしで同じ塊を入れ替えた値）との比較**の形で答える
- 答えの水準は、設計の整理 §3.1 の **C-I（固定した背景のもとでの介入の効果）と、その介入の参照との比較まで**。ここでの背景は、受け手 W1 の残りの塊（重みの家族では W1 の Unit の状態、Unit の家族では W1 の重み）と時刻 T である
- **C-II（自然な差の再現と消去）は判定しない**。C-II には、自然な O が参照の外にあること、O の塊を移すと受け手が外れること、O の塊を戻すと O の外れが消えることが要る（設計の整理 §3.1）が、この実験の主の判定の成立条件には、自然な O が外にあることも、外れが消えることも入っていない（§3）
- **C-III（自然な O と並べ替えの差が、その塊の違いの「せいで」生じた。その塊が自然な状態の担い手だった）も判定しない**（設計の整理 命題 5。§0.3・§12）
- 0025 で、C0 の O は W の参照に対して典型的でない応答を示した（h ＝ 7／20）〔0025〕。0026 はその個体を追うのではなく、**新しい seed の全個体**で問う（設計の整理 命題 6）

### 0.2 主張の形（成立したとき）

塊 c（重み、または Unit の状態）について成立したとき：

「C0 で、この世界・この手順のもとで、経験の終わりの時刻 T に、受け手 W1 の状態の塊 c を順序のある経験の個体 O のものに替えると、その後の試しへの応答 L は、塊 c を試行の中の並べ替えの個体 W2〜W20 のものに替えた場合の分布では典型的でない形になった（向きを問わない）。その頻度は、ドナーとしての O が W2〜W20 と交換可能であるという帰無仮説のもとで期待される頻度より多かった（個体間の独立性の前提のもとで、水準 0.025。2 つの判定の家族全体で 0.05）。つまり、**W1 の残りの塊を背景に固定したとき、O 由来の塊 c は、参照のドナー由来の塊 c と比べて典型的でない応答を生んだ**（C-I とその介入の参照との比較）」

- 命題 A（§3）により、同じ判定は「全員の残りの塊を W1 のものにそろえた本体どうしの比較」とも書ける。これは**同じ混成状態の別の書き方**で、自然な O の外れが、塊を戻すと消えることを確かめたもの（C-II）ではない

### 0.3 主張しないこと

- **自然な差の原因の特定（C-III）**：成立しても、「0023・0025 で O が典型的でなかったのは、塊 c の違いのせいだった」「塊 c が自然な状態の担い手だった」とは言わない。C0 は加法的でなく（設計の整理 §3.3）、ある背景での効果は別の背景での効果と違いうる（命題 5）
- **自然な差の再現と消去（C-II）**：成立しても、「O の塊 c を移すと自然な O の差が再現された」「O の塊を戻すと自然な O の外れが消えた」とは言わない。自然な O が参照の外にあったかは補助の記録にとどめ（§6）、主の判定と結びつけない。命題 A の同値は、それを独立に確かめたことにならない（§3）
- **寄与の割合**：重みと Unit の状態の寄与を割合に分けない（識別のメモ U5、設計の整理 命題 3）。2 つの判定の結果を足し合わせたり、h の大きさを比べたりしない
- **入れ替えた状態が自然に起こる**：入れ替えた状態は I1〜I4 を満たすが、何らかの経験の履歴から到達できるかは分からない（設計の整理 命題 2）。その状態での応答は、自然な個体からの外挿である
- 不成立のとき：塊 c は応答に効かない、塊 c に O に特有の違いはない。外れは組み合わせの性質でもありうる（命題 3 (c)）、判定の検出力・受け手の背景（W1）・時刻 T に依る
- どちらでも：経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した・記憶した、順序を学習した。0023〜0025 の h と 0026 の h の違いから何かを結論すること

### 2.2 入れ替える時刻 T（個体ごとに 1 つ）

```text
T ＝ max{ t ∈ [11972, 12000] ： Pulse t に、自然な 21 本体のどれでも、どの Unit も発火していない }
     （11972 ＝ 最後の刺激の Pulse 11971 ＋ 1。窓の中には Receptor の出来事がない）
```

- 窓の中に T がない個体は、入れ替えをせず、**両方の判定で「外にない」に数える**（除外しない。記録して報告する）
- T は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる

## 3. 命題 A（同じ混成状態の二つの書き方）と、入れ替えた状態の位置づけ

**【命題 A】（2 つの塊・共通の時刻での補い合い）** T の処理の終わりの力学に効く状態を (w, u)（w：重みの塊、u：Unit の塊）と書く（§2.2 により、置かれた駆動はない）。12001 以後の外からの入力は試しだけで、系は決定論的なので、T より後の本体の軌道と L は (w, u) だけで決まる（設計の整理 命題 1 と同じ形）。このとき

```text
Y(重み ← d)    の状態 ＝ (w_d,  u_W1)  ＝ 「d の Unit の塊を W1 のものに戻した本体」
Y(Unit ← d)   の状態 ＝ (w_W1, u_d)   ＝ 「d の重みの塊を W1 のものに戻した本体」
```

（証明：定義どおりに書き下すだけ。発火の回数は力学に使わないので、軌道と L は変わらない。）

- **帰結（書き方の同値）**：重みの家族 {Y(重み ← d)} は、「W1 に d の重みを移した本体」の家族とも、「d の Unit の状態を W1 のものに戻した本体」の家族とも書ける。どちらで書いても**同じ混成状態の同じ比較**で、主の判定が直接比べるのは次の家族の中の値である。Unit の家族も同じ

```text
重みの家族： (w_O, u_W1)   対   (w_Wk, u_W1)      k ＝ 2..20
Unit の家族：(w_W1, u_O)   対   (w_W1, u_Wk)      k ＝ 2..20
```

- **同値が言わないこと**：この同値は状態の代数的な等しさで、**自然な差の再現・消去（C-II）を独立に確かめたことではない**。C-II に要る「自然な O が参照の外にあった」ことと「O の塊を戻すと、その外れが消えた」ことは、どちらも主の判定の成立条件に入っていない。自然な O が外にあるかは補助の記録だけで（§6）、外れが消えるかは、この設計では「W1 の塊をそろえた本体どうしの比較で O が外にない」という形でしか現れず、それは自然な O の外れが消えたことと同じではない（自然な O が外になかった個体でも、同じ形の結果になりうる）
- **成り立つ・成り立たないの読み**：重みの家族で O が外にあることは、「W1 の Unit の状態を背景に固定したとき、O の重みは参照のドナーの重みと比べて典型的でない応答を生んだ」という、**固定した背景のもとでのドナーのあいだの条件付きの効果（C-I とその介入の参照との比較）**である。自然な差の再現・消去（C-II）でも、自然な O で重みが違いを運んだこと（C-III。命題 5）でもない。Unit の家族も同じ
- **到達できるか**：入れ替えた状態は、組の和（I1）・痕跡が Unit ごと（I2）・activity が正（I3）・置かれた駆動がない（I4）を満たす（§7 で確かめる）。I5・I6 は、T に発火がないので当てはまる場面がない。ただし、これらを満たすことは到達できることの十分条件ではない。(w_O, u_W1) のような組み合わせが、何らかの経験の履歴から到達できるかは分からない（設計の整理 命題 2）
- **組み合わせ**：外れが 2 つの塊の組み合わせの性質であれば、どちらの家族でも外れないことがある（命題 3 (c)）。2 つの家族の結果から、組み合わせの有無は判定しない

## 5. 主の評価

### 5.1 個体ごと（塊 c ∈ {重み, Unit の状態} のそれぞれ）

```text
c で O が外にある  ⇔  L(Y(c ← O)) ＞ max_{k＝2..20} L(Y(c ← W_k))   または   L(Y(c ← O)) ＜ min_{k＝2..20} L(Y(c ← W_k))
```

向きを問わない。等号は「外にない」。20 個の L（ドナー O と W2〜W20）がすべて等しい家族（凍結）も「外にない」。T がない個体は両方とも「外にない」（§2.2）。どれも除外しない。

### 5.2 個体をまたぐ判定（2 つ）

- h_重み ＝ 重みで O が外にある個体の数、h_Unit ＝ Unit の状態で O が外にある個体の数（20 個体のうち）
- **判定：それぞれ、h ≥ 6 なら成立（holds）、h ≤ 5 なら不成立（fails）**
- 根拠：塊 c ごとの帰無仮説「どの個体でも、W1 への塊 c のドナーとして、O は W2〜W20 と交換可能」のもとで、各個体で O が外にある確率は 2／20 ＝ 0.1 以下（同じ値があれば小さくなりうる）。個体間の独立性を統計モデル上の前提として置くと、h は Bin(20, 0.1) に確率的に支配され、**P(h ≥ 6) ≤ P(Bin(20, 0.1) ≥ 6) ≈ 0.01125**。2 つの判定の家族全体の水準 0.05 を Bonferroni で 0.025 ずつに分け、Bin(20, 0.1) の上側確率が 0.025 以下になる最小の閾値が 6（P(Bin(20, 0.1) ≥ 5) ≈ 0.0432 は 0.025 を超える）。どちらか一方でも誤って成立とする確率は、両方の帰無仮説のもとで 0.05 以下（和の上界）
- 成立は、上の前提のもとで帰無仮説を水準 0.025 で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- **判定の範囲**：C0 で、受け手 W1 の残りの塊と時刻 T を背景に固定したときの、ドナーのあいだの塊の入れ替えの条件付きの効果（C-I とその介入の参照との比較）まで（protocol の judgment.scope）。C-II（自然な差の再現・消去）・C-III（自然な差の原因）は判定しない

7. **0023〜0025 との関係**：0023（C0、参照 S）は h ＝ 6、0024（V1、参照 S）は h ＝ 3、0025（C0、参照 W）は h ＝ 7 だった。0026 は問いも量も（入れ替えた本体の L のドナーのあいだの比較）違い、**これらの h と 0026 の h を比べる検定は置いていない**。違いから何かを結論しない（§13）

### 15.6 言えること・言えないこと（§12・§13 に従う）

**言えること**：§12 の「両方で成立」の行。**C0 で、この世界・この手順（共通の時刻 T、受け手 W1、ドナー O・W2〜W20、試しの区間 12001〜12300、T_w ＝ 300、20 個体）のもとで、経験の終わりの時刻 T に**
- **W1 の重みを O のものに替えると（W1 の Unit の状態を背景に固定して）、その後の試しへの応答 L は、重みを W2〜W20 のものに替えた場合の分布では典型的でない形になった。その頻度（20 個体のうち 13）は、ドナーとしての O が W2〜W20 と交換可能であるという帰無仮説のもとで期待される頻度より多かった**（個体間の独立性の前提のもとで、水準 0.025）
- **W1 の Unit の状態を O のものに替えると（W1 の重みを背景に固定して）、同じ意味で典型的でない形になった。その頻度は 20 個体のうち 6**（同じ前提・水準。閾値ちょうど）
- つまり、**どちらの塊も、もう一方を W1 の値に固定した背景のもとで、O 由来の塊は、参照のドナー由来の同じ塊と比べて典型的でない応答を生んだ**（C-I とその介入の参照との比較）。家族全体の誤りの水準は 0.05

**言えないこと**：
- **C-II（自然な差の再現・消去）**：「O の重みを移すと自然な O の差が再現された」「O の Unit の状態を戻すと自然な O の外れが消えた」。命題 A の同値（移す ＝ もう一方を戻す）は、この実証ではない（§3）
- **C-III（自然な差の原因）**：「0023・0025 で O が典型的でなかったのは重み（Unit の状態）のせいだった」「重み（Unit の状態）が自然な状態の担い手だった」「重み（Unit の状態）が順序の記憶を担っていた」「学習が原因」
- **2 つの効果が足し合わさる（加法性）**。両方の塊が自然な差を運んだ。組み合わせの有無（命題 3 (c)。2 つの家族の結果からは判定しない）
- **寄与の割合**。2 つの h（13 と 6）を比べて、どちらの塊が「より重要」「より効く」と言うこと
- 入れ替えた本体の応答を、自然な個体で起きうる応答と呼ぶこと（(w_O, u_W1) などの状態に、何らかの経験の履歴から到達できるかは分からない：命題 2）
- 別の受け手（ほかの W・O 自身）・別の時刻での効果（§5.3。この実験は W1 という一つの背景・共通の T だけを見た）
- すべての個体・大多数の個体で O 由来の塊が外れを生む。h／20 を母集団の割合と呼ぶ
- 交換可能性の破れの数学的証明、個体間の独立性が異なる seed から従うこと
- 試しへの応答の大きさだけの違い（§15.5 の 3：窓の中で発火するかどうかの違いを含む）
- 0023〜0025 の h と 0026 の h の違いから何かを結論すること
- 自然な比較（補助）で外にあった個体だけを取り出して、入れ替えの効果を語ること
- 補助（向き・自然な比較・silence_counts・Clopper–Pearson）のどれかから、主に何かを足すこと
- §0.3 のすべて：経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した・記憶した、順序を学習した
