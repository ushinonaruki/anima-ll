## 0. 問いと主張の範囲

### 0.1 問い

> **0025 と同じ C0・経験・試し・読み出しで、経験の終わりの共通の時刻 T に、受け手の個体 W1 の状態のうち一方の塊――6 本の重み、または 3 Unit の状態（activity・順応・痕跡）――だけを、ドナーの個体のものに替える。ドナーが順序のある経験の個体 O のとき、その後の試しへの応答 L は、ドナーが試行の中の並べ替えの個体 W2〜W20 のときの分布（介入の参照）の中で典型的でないか。重みの塊と Unit の塊のそれぞれについて問う**

- 設計の整理の **Q1・Q2**（状態の成分を替えると読み出しが変わるか。移す向きと戻す向き、介入の参照に照らして）に答える
- 答えの水準は設計の整理 §3.1 の **C-I・C-II（選んだ背景のもとでの条件付きの因果効果）まで**。**C-III（自然な O と並べ替えの差が、その塊の違いの「せいで」生じた。その塊が自然な状態の担い手だった）は判定しない**（設計の整理 命題 5。§0.3・§12）
- 0025 で、C0 の O は W の参照に対して典型的でない応答を示した（h ＝ 7／20）〔0025〕。0026 はその個体を追うのではなく、**新しい seed の全個体**で問う（設計の整理 命題 6）

### 0.2 主張の形（成立したとき）

塊 c（重み、または Unit の状態）について成立したとき：

「C0 で、この世界・この手順のもとで、経験の終わりの時刻 T に、受け手 W1 の状態の塊 c を順序のある経験の個体 O のものに替えると、その後の試しへの応答 L は、塊 c を試行の中の並べ替えの個体 W2〜W20 のものに替えた場合の分布では典型的でない形になった（向きを問わない）。その頻度は、ドナーとしての O が W2〜W20 と交換可能であるという帰無仮説のもとで期待される頻度より多かった（個体間の独立性の前提のもとで、水準 0.025。2 つの判定の家族全体で 0.05）。同じことは、**全員の残りの塊を W1 のものにそろえたとき、塊 c の違いだけで O が参照のドナーと区別される応答になった**、とも言える（§3 の命題 A）」

### 0.3 主張しないこと

- **自然な差の原因の特定（C-III）**：成立しても、「0023・0025 で O が典型的でなかったのは、塊 c の違いのせいだった」「塊 c が自然な状態の担い手だった」とは言わない。C0 は加法的でなく（設計の整理 §3.3）、ある背景での効果は別の背景での効果と違いうる（命題 5）
- **寄与の割合**：重みと Unit の状態の寄与を割合に分けない（識別のメモ U5、設計の整理 命題 3）。2 つの判定の結果を足し合わせたり、h の大きさを比べたりしない
- **入れ替えた状態が自然に起こる**：入れ替えた状態は I1〜I4 を満たすが、何らかの経験の履歴から到達できるかは分からない（設計の整理 命題 2）。その状態での応答は、自然な個体からの外挿である
- 不成立のとき：塊 c は応答に効かない、塊 c に O に特有の違いはない。外れは組み合わせの性質でもありうる（命題 3 (c)）、判定の検出力・受け手の背景（W1）・時刻 T に依る
- どちらでも：経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した・記憶した、順序を学習した。0023〜0025 の h と 0026 の h の違いから何かを結論すること

## 2. 自然な本体と入れ替え

### 2.1 自然な本体（同じ seed、同じ出生時の状態から 21）

| 本体 | 内容 |
|---|---|
| **O** | 試行 k（0〜199）の 3 つの枠（`t_k ＝ 1 ＋ 60k`、`t_k ＋ 2`、`t_k ＋ 30`）に A・B・C（0023・0025 と同じ） |
| **W1〜W20** | 0025 と同じ作り方の試行の中の並べ替え。i 番目は乱数の流れ `"0026-within-trial-<i>:<seed>"` を 1 本だけ使い、k ＝ 0, 1, …, 199 の順に [A, B, C] を 1 回ずつ並べ替えて 3 つの枠に置く |

経験は Pulse 1〜12000。12001 以後はどの本体にも外からの入力はない（可塑性あり）。自然な本体は 0025 と同じく 12601 まで進め、12001〜12300 の各 t0 で試しをする（L を補助として記録し、確認の基準にする）。

### 2.2 入れ替える時刻 T（個体ごとに 1 つ）

```text
T ＝ max{ t ∈ [11972, 12000] ： Pulse t に、自然な 21 本体のどれでも、どの Unit も発火していない }
     （11972 ＝ 最後の刺激の Pulse 11971 ＋ 1。窓の中には Receptor の出来事がない）
```

- **理由**：T の処理の終わりには、どの本体にも次の Pulse に届く駆動が置かれておらず（発火がないため）、Receptor の出来事もない。したがって全状態は「3 Unit の状態」と「接続の状態（重みと痕跡）」だけで、どちらの塊を入れ替えても、駆動の重みと接続の重みの不整合（設計の整理 I6）や、発火の印と駆動の不整合（I3・I4）が起きない（設計の整理 §3.2 の【候補】）
- 窓の中に T がない個体は、入れ替えをせず、**両方の判定で「外にない」に数える**（除外しない。記録して報告する）
- T は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる

### 2.3 塊と入れ替えた本体

| 塊 | 入れ替える値（T の処理の終わり） | 受け手のまま |

## 3. 移す向きと戻す向き（命題 A）と、入れ替えた状態の位置づけ

**【命題 A】（2 つの塊・共通の時刻での補い合い）** T の処理の終わりの力学に効く状態を (w, u)（w：重みの塊、u：Unit の塊）と書く（§2.2 により、置かれた駆動はない）。12001 以後の外からの入力は試しだけで、系は決定論的なので、T より後の本体の軌道と L は (w, u) だけで決まる（設計の整理 命題 1 と同じ形）。このとき

```text
Y(重み ← d)    の状態 ＝ (w_d,  u_W1)  ＝ 「d の Unit の塊を W1 のものに戻した本体」
Y(Unit ← d)   の状態 ＝ (w_W1, u_d)   ＝ 「d の重みの塊を W1 のものに戻した本体」
```

（証明：定義どおりに書き下すだけ。発火の回数は力学に使わないので、軌道と L は変わらない。）

- **帰結**：重みの家族 {Y(重み ← d)} の判定は、「O の重みを W1 へ**移す**と W1 が参照のドナーの場合と区別されるか」と、「全員の Unit の状態を W1 のものに**そろえて（戻して）**も、O は残りの重みの違いで参照のドナーと区別されるか」の、同じ一つの問いである。Unit の家族も同じ。したがって、**2 つの家族で、2 つの塊それぞれの移す向きと戻す向きを、同じ介入の参照に照らして見る**（設計の整理 §3.4 の介入の参照）
- **成り立つ・成り立たないの読み**：重みの家族で O が外にあることは、「Unit の状態を W1 にそろえた背景のもとで、O の重みは参照のドナーの重みと交換可能でない応答を生んだ」という**条件付きの効果（C-II）**である。自然な O で重みが違いを運んだこと（C-III）ではない（命題 5）。Unit の家族も同じ
- **到達できるか**：入れ替えた状態は、組の和（I1）・痕跡が Unit ごと（I2）・activity が正（I3）・置かれた駆動がない（I4）を満たす（§7 で確かめる）。I5・I6 は、T に発火がないので当てはまる場面がない。ただし、これらを満たすことは到達できることの十分条件ではない。(w_O, u_W1) のような組み合わせが、何らかの経験の履歴から到達できるかは分からない（設計の整理 命題 2）
- **組み合わせ**：外れが 2 つの塊の組み合わせの性質であれば、どちらの家族でも外れないことがある（命題 3 (c)）。2 つの家族の結果から、組み合わせの有無は判定しない

## 5. 主の評価

### 5.1 個体ごと（塊 c ∈ {重み, Unit の状態} のそれぞれ）

```text
c で O が外にある  ⇔  L(Y(c ← O)) ＞ max_{k＝2..20} L(Y(c ← W_k))   または   L(Y(c ← O)) ＜ min_{k＝2..20} L(Y(c ← W_k))
```

向きを問わない。等号は「外にない」。20 個の L（ドナー O と W2〜W20）がすべて等しい家族（凍結）も「外にない」。T がない個体は両方とも「外にない」（§2.2）。どれも除外しない。

### 5.2 個体をまたぐ判定（2 つ）

- h_重み ＝ 重みで O が外にある個体の数、h_Unit ＝ Unit の状態で O が外にある個体の数（20 個体のうち）
- **判定：それぞれ、h ≥ 6 なら成立（holds）、h ≤ 5 なら不成立（fails）**
- 根拠：塊 c ごとの帰無仮説「どの個体でも、W1 への塊 c のドナーとして、O は W2〜W20 と交換可能」のもとで、各個体で O が外にある確率は 2／20 ＝ 0.1 以下（同じ値があれば小さくなりうる）。個体間の独立性を統計モデル上の前提として置くと、h は Bin(20, 0.1) に確率的に支配され、**P(h ≥ 6) ≤ P(Bin(20, 0.1) ≥ 6) ≈ 0.01125**。2 つの判定の家族全体の水準 0.05 を Bonferroni で 0.025 ずつに分け、Bin(20, 0.1) の上側確率が 0.025 以下になる最小の閾値が 6（P(Bin(20, 0.1) ≥ 5) ≈ 0.0432 は 0.025 を超える）。どちらか一方でも誤って成立とする確率は、両方の帰無仮説のもとで 0.05 以下（和の上界）
- 成立は、上の前提のもとで帰無仮説を水準 0.025 で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- **判定の範囲**：C0 で、受け手 W1・時刻 T・この読み出しのもとでの、塊の入れ替えの条件付きの効果（C-II）まで（protocol の judgment.scope）

### 5.3 新しく選んだ値

| 値 | 理由 |
|---|---|
| W の数 20 | 受け手 1 と参照のドナー 19 で、0023・0025 と同じ K ＝ 19（各個体の帰無の確率 0.1 以下）を保つため |
| 閾値 6 | 2 つの判定の家族全体で 0.05 を保つ Bonferroni の分け方（0.025 ずつ）から決まる最小の値 |
| T の窓 [11972, 12000] | 最後の刺激の後で、経験の終わりまで（protocol の式から決まる）。新しく選んだ数ではない |

ほかの判定・手順の値（T_w・試しの区間・個体数・水準の家族全体の値）は 0023 から継承する。

## 13. 言わないこと

- §0.3 のすべて
- 成立を「重み（Unit の状態）が順序の記憶を担っていた」「学習が原因」と呼ばない。不成立を「重み（Unit の状態）は無関係」と呼ばない
- 2 つの判定の h を比べて、どちらの塊が「より重要」かを言わない。寄与の割合に分けない
- 入れ替えた本体の応答を、自然な個体で起きうる応答と呼ばない（到達できるかは分からない）

- 自然な比較で外にあった個体だけを取り出して、入れ替えの効果を語らない
- h を母集団の割合と呼ばない。交換可能性を O について確かめた性質と呼ばない。個体間の独立性を異なる seed から従う性質と呼ばない
- invalid の個体を、O が外れなかった個体と呼ばない。補助の成立で主の不成立を救わない
- 入れ替えの確認・命題 3・空の側の同一性・組の和を、結果や成功の証拠として書かない（設計から決まる）
- smoke・合成の結果を見て、T の規則・塊の分け方・受け手・ドナー・判定の基準を変えない
