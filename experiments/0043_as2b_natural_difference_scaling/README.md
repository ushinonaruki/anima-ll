## 0. 実行の形式と、問いと主張の範囲

### 0.1 実行の形式：0039 型の事前登録の実験にする

0042 と同じく、**0039 型の事前登録の実験**（事前登録 → 道具 → 盲検の smoke → 本番の一度限りの実行 → 結果）にする。0038 型の前方の関門にはしない。

- 推定対象は、新しい個体群での、人工に延ばした重みの対比による試しの区間の選択の差の、個体ごとの分布（現象の量）である。0038 型の関門はこの量を出さない
- 本体・境界・移植・FREEZE は 0042 と同じ組み立てで、動くことは関門（0038）、AS2b の契約テスト、0039〜0042 の道具で確かめてある。別の関門を置くと、その結果を見て値を選び直す道が開く
- seed は、契約テストの合成の seed（36301〜36399）・盲検の smoke（36201〜36206）・判定の一度限りの seed（36001〜36200）に分ける（§9.2）

### 0.2 問い

> **問い Q-C**：同じ個体（seed）の二つの本体 B^{A1}・B^{A2}（規則 c ＝ A1 と c ＝ A2。ほかはすべて同じ）を、0042 と同じく境界 P_E ＝ 1,065 まで走らせる。自然な差 e ＝ W^{A1} − W^{A2}（P_E の 6 本の重みの差）の向きを保ったまま、各背景の本体の重み W^c を中心に、前もって決めた倍率 k だけ両側に動かした二つの人工の重み W^c ＋ k e と W^c − k e を、P_E で複製に移植する。試しの区間 U（窓 26〜50）で 6 本を FREEZE し、世界は背景の本体の規則のまま（閉ループ）走らせる。試しの区間の A1 の割合 s から、
>
> C_k ＝ [s(G^{A1}[W^{A1} ＋ k e]) − s(G^{A1}[W^{A1} − k e])] ＋ [s(G^{A2}[W^{A2} ＋ k e]) − s(G^{A2}[W^{A2} − k e])] ＝ C_k^{(A1)} ＋ C_k^{(A2)}
>
> を求める。主の段は **k₀ ＝ 2**（§4.6）。
> - **判定 J_C**：C_2 が定まり 0 でない個体の中で、C_2 の向きがそろう個体は、事前に決めた基準を超えて多いか
> - **推定 E_C**：C_2 が定まる個体のうち、合算の C_2 が 0 でない個体と、少なくとも一方の背景で C_2^{(c)} ≠ 0 の個体はどれだけあり、C_2 はどれだけか

- **新しく立てる問い**：0042 の J_T を判定し直す問いではなく、0042 の不成立の原因を特定する実験でもない（提案の文書 §2.1・§3.1）。0042 で確立しなかったのは、T ≠ 0 の個体（77/189）の中での向きの偏りで、その原因は識別されていない
- **主の問い**：0042 の J_T と同じ型の、**合算の C_2 が 0 でない個体に限った、条件付きの向き**である。過半数の問い（C_2 が定まる個体の過半数で一方向に動くか）は判定では問わず、広がりは推定 E_C（p_nz・p_any）で示す（§4.7）
- **向き**は事前に決めない。両側で問う（§4.7）
- **人工の重み**：k ≥ 2 では、両端がどちらも、自然な差の向きを延ばした人工の重みである。そのため、J_C の結果は「自然に形づくられた重みの差が選択を動かした」こと（段 (iv) の成立）にはならない（§0.4）
- **C_k ＝ 0 の意味**：0042 の T と同じく、二つの背景で逆向きに同じだけ変われば C_k ＝ 0 になる（打ち消し。§3.2）

### 0.3 主張の形（J_C が成立したとき）

「AS2b（関門の組：C0 の力学と可塑性、関門の予定・窓・出口・役、結果を返す世界）で、同じ個体の二つの本体を規則 c ＝ A1・A2 で経験の区間（窓 1〜25）まで育て、P_E で、各本体の重みを中心に、二つの本体の重みの差の向きに、その差の 2 倍だけ両側に動かした二つの人工の重みを複製に移植し、試しの区間（窓 26〜50）で重みを固定して閉ループの世界で走らせた。すると、二つの背景を足した試しの区間の A1 の割合の差 C_2 が［＋／−］の向きの個体が、C_2 が定まり 0 でない個体の中で、事前に決めた基準を超えて多かった」

- **＋の向き**（C_2 ＞ 0）：重みを、自然な差の向きに沿って W^{A1} の側（A1 に結果を返す規則のもとで形づくられた重みの側）に動かしたほうが、A1 の割合が高い（二つの背景について足し合わせた量で）。−の向きはその逆。0042 の T と同じ「規則の意味」の符号で、δ では向きをつけない
- 符号は、行動 ID の札の付け方に依らない（§3.3）
- **主張の水準**
  - P_E の時点の 6 本の重みへの、**人工の介入の制御した効果**である。背景（P_E の活動の状態・I2 の決定の部品・世界の状態と規則）は複製の元の本体のまま固定し、試しの区間の可塑性による後の変化を含まない（FREEZE）
  - 閉ループの条件の結果で、重みの違いで変わった選択に結果が返る経路（即時の帰還）も C_2 に含まれる
  - 主張は、C_2 が定まり 0 でない個体の中での**向きのそろい**である。広がりは推定 E_C で示し、J_C の結果と同じ目立ち方で必ず添える
  - この個体群（C_2 が定まる個体。範囲と s の定義で選んだ後の母集団：§4.3・§4.8）・この時点・この試しの区間の条件・この段（k ＝ 2）についての、条件付きの結果である

### 0.4 主張しないこと

- 自然に形づくられた重みの差そのものが選択を動かしたこと（段 (iv) の成立）。k ＝ 2 の重みは人工の重みである
- 0042 の不成立の理由（自然な差が小さかったため・形のためなど）。0042 の J_T・E_T の言い換え・救済
- 「大きさのせいか、形のせいか」の分離。δ をそろえた対称な介入の対照との並びは、δ の大きさだけをそろえた二種類の介入の記述で、形だけの違いではない（§6.2）
- 規則 c の入れ替えの総効果とその内訳、媒介の割合。S3 の層 1・層 2 の主張の成立（基準 §2）
- 学習・報酬・価値・罰・意味・目的を学んだこと。＋・−の向きを、接近・回避・好みと呼ぶこと（基準 §2・§8、命題 G-11）
- どの接続の効果か（6 本を一度に動かし、分けていない）。どの可塑性の経路が e を作ったか
- **広がり**：「多くの個体で選択が変わる」こと。J_C は p_nz・p_any の判定ではない
- k ＝ 2 以外の段（1・4・8）での向き。それらは記述で、判定しない
- **不成立・判定不能から**、「延ばしても選択に届かない」「規則に依る重みの変化は選択に届かない」と言うこと。不成立を、構成の見直し（提案の文書の候補 E）を始める条件にすること
- E_C の値から、効果が大きい・小さいと判定すること
- ほかの時点・ほかの長さの経験・可塑性 ON の試しの区間・結果を返さない世界で、同じ向きになること

### 2.2 重みの算術

記号：c・d ∈ {A1, A2}、c ≠ d。W^c は本体 B^c の P_E の可塑的な 6 本の重み（浮動小数）。6 本は、C → 源 1・源 1 → C・C → 源 2・源 2 → C・源 1 → 源 2・源 2 → 源 1 の順に書く。組は (C → 源 1, 源 1 → C)・(C → 源 2, 源 2 → C)・(源 1 → 源 2, 源 2 → 源 1)。

- **正確な算術**：W^{A1}・W^{A2} の浮動小数の値を、有理数として正確に扱う（`Fraction(float)`）。端の重みは、有理数で正確に計算し、重みごとに一度だけ最近接の浮動小数に丸める（`float(Fraction)`）
- **自然な差**：e ＝ W^{A1} − W^{A2}（有理数で正確に）
- **δ**：δ(Δ) ＝ Δ(C → 源 1) − Δ(C → 源 2)（0041 §3.2 の δ を、6 本の変化 Δ に当てたもの）。δ(e) は、この個体の 0041 型の δ
- **自然な差の段**：V^c_{±k} ＝ W^c ± k e、k ∈ {1, 2, 4, 8}

## 3. 比べる量

### 3.1 試しの区間の選択

0042 §3.1 と同じ。系 X について、U の窓 26〜50 の結末を層 A から数え、n_U(X)、#A1_U(X)・#A2_U(X)、**s(X) ＝ #A1_U(X)／n_U(X)**（n_U(X) ＝ 0 なら定まらない。0 にしない）、s_c(X)（c ＝ A1 なら s、c ＝ A2 なら 1 − s）を求める。層 A と層 B の突合（CT-E10）は O3。

### 3.2 量の一覧

どれも、保存した記録から分数で正確に計算し、符号はその正確な値の符号とする。差は「a − b」の順。量は、その差に使う系がすべて作られ、その s がすべて定まるときだけ定める。

| 名前 | 定義 | 役目 |

| up_k^{(c)}・dn_k^{(c)} | s(G^c[V^c_{+k}]) − s(G^c[W^c])、s(G^c[W^c]) − s(G^c[V^c_{−k}]) | 片側の差（記述）。C_k^{(c)} ＝ up_k^{(c)} ＋ dn_k^{(c)} |

- **C_k ＝ 0 の意味と、打ち消し**：C_k ＝ 0 は、両方 0（C_k^{(A1)} ＝ C_k^{(A2)} ＝ 0）と打ち消し（C_k^{(A1)} ＝ −C_k^{(A2)} ≠ 0）を含む。少なくとも一方の背景で C_k^{(c)} ≠ 0 の個体の事象を C_k^{any} とする（0042 の T_any と同じ形）

### 3.3 札の入れ替えに対する性質（SE-C14）

- 6 本の成分を同じ順序で書き、源 1 と源 2 の置換を P とする。札を入れ替えると、本体 A1 と A2 が入れ替わり、W′^{A1} ＝ P W^{A2}、W′^{A2} ＝ P W^{A1} になる。そのため e′ ＝ −P e、P u ＝ −u、δ(e′) ＝ δ(e)、m_k は変わらない。s は 1 − s に移る
- 新しい札の G^{A1}[V′_{+k}] は元の G^{A2}[V_{−k}] に、G^{A1}[Y′_{+k}] は元の G^{A2}[Y_{−k}] に、G^{A1}[X1] は元の G^{A2}[X2] に当たる（逆も同じ）

- **この性質は、C_k の符号が＋・−で対称であることの根拠ではない**（札の入れ替えは C_k を −C_k に移さない。§4.8）
- **確かめた範囲**：`analysis.py` の `weight_arithmetic_check` が、手で置いた 6 本の重みの組で、札を入れ替えて計算した端が、元の背景の逆の端の札の付け替えに、ビット単位で一致することを確かめる。`label_swap_and_identity_check` が、手で置いた割合で、量の不変と入れ替わりを確かめる。道具が実際の記録から計算する量での確かめは、道具の契約テスト（§14 の CT-43-9）で行う

## 4. 主の判定 J_C と主の推定 E_C

ここで前もって定め、結果を見てから変えない。提案の文書 §3.1 の (a)〜(d) を、倍数案に当てて具体にしたもの。

### 4.1 値の区分（背景ごと・段ごと）

(個体, c, k) ごとに、C_k^{(c)} と D^u_k^{(c)} のそれぞれを、次の順に確かめて、一つの区分に入れる。

| 2 | **s が定まらない** | 二つの端の系が作られ、少なくとも一方の n_U ＝ 0 |
| 3 | **構造上の 0** | 二つの端の 6 本が、丸めた後にビット単位で同じで、s が定まる（同じ系なので差は厳密に 0） |
| 4 | **測った差が 0** | 二つの端の重みが違い、s が定まり、差が 0 |

- 構造上の 0 も、s が定まることを先に確かめる（区分 2 が先）

### 4.2 個体の量と、二つの背景の合算の条件

- **合算の条件**：個体の C_k は、**二つの背景の両方**で C_k^{(c)} が区分 3〜5 にあるときだけ定め、C_k ＝ C_k^{(A1)} ＋ C_k^{(A2)} とする。一方の背景だけが定まる個体では C_k を定めない（片方の背景の値で代えない。0 にしない）
- 理由
  - 札の入れ替えの不変（§3.3）は、二つの背景の和について成り立つ。片方だけの値は別の推定対象で、個体によって量の意味が変わる
  - 0042 の T と同じ条件で、主の量の型を J_T とそろえる
- 一方の背景だけが定まる個体の C_k^{(c)} は、背景ごとの記述の表に並べる（§6.1）
- D^u_k の個体の量も、同じ合算の条件で定める
- 二つの背景の両方で範囲の中であることは、外側の二点 W^{A1} ＋ k e と W^{A2} − k e が範囲の中であることと同じ（SE-C10）

### 4.3 個体の分け方と分母（J_C・E_C。k ＝ 2）

| 分け方 | 定義 | J_C での扱い | E_C での扱い | 報告 |

### 4.4 判定 J_C

- k₂(m)：P(Bin(m, 1/2) ≥ k) ≤ 0.025 となる最小の k（§5.1）
- **J_C**：m≠ ≥ 10 のとき、「＋」の個体の数 ≥ k₂(m≠) なら **＋の向きで成立**、「−」の個体の数 ≥ k₂(m≠) なら **−の向きで成立**。どちらでもなければ**不成立**

### 4.6 段の組と、主の段 k₀ の理由（結果を見る前の理由）

**倍数案にした理由**（絶対量案を採らない理由）
- 問いは「自然な差の向きを保ったまま延ばすと」で、倍数 k は自然な差 e そのものを伸ばす、問いに直接の形である
- 主の量が δ(e) ≠ 0 を要さず、δ(e) で個体を選ばない
- 絶対量案は、\|δ(e)\| の小さい個体で倍率 a／\|δ(e)\| が大きくなり、δ に現れない成分（共通の変化・源どうし）まで大きく延ばす。範囲の外も増える
- k ＝ 1 の段が、自然な重みの入れ替え T の記述を、別の系を足さずに与える（§3.2）
- 費用：段の大きさが個体ごとの自然な差に比例し、個体に共通の大きさではない。これは問いの形の選択で、δ の単位の共通の大きさの比べは、この実験では問わない

**段の組を {1, 2, 4, 8} にした理由**
- 倍の段（1、2、4、…）は、比の目盛りで等しい間隔で、特定の値を選ばずに一桁ほどの幅を少ない段で覆う。段を 4 つにして、系の数を提案の文書 §3.1 の見積もり（40 系）に収める
- 下限の 1：自然な側の端を含み、T の記述を与える
- 上限の 8：0042 の R4 の公表値の、周辺の値からの粗い目安（中央の重みから範囲の端までの距離を、|差| の第 3 四分位で割った値）は、どの接続でも約 10.9 以上だった（C → 源 1 で約 10.9、C → 源 2 で約 11.1、源どうしで約 78）。8 は、この目安を超えない最大の倍の段で、16 は超える。目安を超える段では、|差| の中央の近くの個体まで範囲の外に出うる（|差| の中央で割ると、C → 源 1 で約 19、C → 源 2 で約 25）ので、残った個体の記述が、選別の後の母集団のものになる程度が大きくなると見込む【見込み】（`analysis.py` の `range_guide`）
- この目安は周辺の値の組み合わせで、個体の結合の分布ではなく、0043 の個体群の値でもない。範囲の外の個体の数の予測ではない

**主の段を k₀ ＝ 2 にした理由**
- 条件 (i)：k ＞ 1。k ＝ 1 では、各背景の一方の端が自然な重みで、問い（延ばした重みの対比）に当たらない。k ≥ 2 では、両端がどちらも、自然な差の向きに延ばした人工の重みになる
- 条件 (ii)：0042 の R4 の公表値の端の値からの、保守的な目安以下。各接続について、W^{A1}・W^{A2} の最小と最大から範囲の端までの距離 min(最小, w_max − 最大) を、|差| の最大で割った値は、C → 源 1 で約 3.22、C → 源 2 で約 3.13、源どうしで約 7.10 である。k がその最小（約 3.13）以下なら、0042 のどの値の組み合わせでも、W^c ± k e は範囲の中にある（十分条件）
- 段の組の中で (i)・(ii) を満たす段は 2 だけで、k₀ ＝ 2 に一つに決まる（`range_guide`）
  - k ＝ 4 は (ii) を満たさない。0042 で C → 源 2 の |差| が最大（0.001321）の個体では、k ＝ 4 の両端の幅が 8 × 0.001321 ≈ 0.010568 で、範囲の全幅 0.01 を超えるので、中心に依らず範囲に収まらない
  - k ＝ 2 の保守的な目安に対する余裕は約 1.57 倍（3.13 ÷ 2）である。0042 の端の値は新しい個体群の端の値を縛らないので、余裕のある段を主にする
- **この選び方の理由の中心は、主の判定の母集団を、範囲による選別から守ることである**。倍数案で範囲の外になるのは、|e| の大きい個体（自然な差が大きく形づくられた個体）や、重みが範囲の端に近い個体で、主の段でそれを外すと、判定の母集団が介入の大きさに関わる性質で選ばれる
- **費用**：k₀ ＝ 2 の対比の幅は、0042 の T の比べ（W^{A1} と W^{A2}、幅 |e|）の 4 倍（2k |e|）で、δ の単位では、\|δ(e)\| が 0042 の中央（0.0004419）の個体で 0.0018 ほどである。0040 の対比（0.01・0.02）よりずっと小さい。k₀ ＝ 2 で不成立になっても、より大きい段で向きがそろうかどうかには答えない。大きい段（4・8）は記述で、判定しない
- **選ばなかった理由**：検出力（向きがそろう見込み）からは選んでいない。検出力の見込みには 0042 の選択の結果（T・S の向きや 0 の数）が要り、それを使うと、結果を知った後の選び直しになる（§4.7 の (c)・§11）

### 4.8 帰無仮説と、その条件

- **推論の対象**：C_2 が定まる個体の母集団（出生時の状態を独立・同一分布の標本と見なすモデルで、k ＝ 2 の両端が二つの背景で範囲の中にあり、四つの系の s が定まるという条件で選んだ後の母集団）
- **H₀^C**（明示の統計上の帰無）：その母集団で、P(C_2 ＞ 0) ＝ P(C_2 ＜ 0)
- 帰無と独立・同一分布のモデルのもとでは、C_2 ≠ 0 の個体の集合と m≠ に条件付けると、「＋」の個体の数は正確に Bin(m≠, 1/2) に従う。そのため P(J_C がどちらかの向きで成立 | H₀^C, m≠) ≤ 0.05
- **この向きの対称性は、仮定する帰無であって、導いた性質ではない**
  - 札の入れ替えからは導けない（C_2 は札の入れ替えで値が変わらない。§3.3）
  - 定まる条件（範囲と n_U ≥ 1）の対称性からも導けない
  - 系の構造からも導けない（AS2b は、結果が規則の指す側にだけ返る非対称な構成：G-11）
- 成立は、「C_2 が定まる個体の母集団で、C_2 ≠ 0 の個体の向きが偏っていた」ことで、選別の前の全個体についての主張ではない
- 同じ個体の系どうしは独立ではない。C_2 を一つの個体の事象にして、この依存を判定に入れない

## 付録 専門知識がなくても読める説明（t-k さんへ）

### 何を決めたか

前の提案で選んだ次の課題（候補 A）について、本番の実験の「調べ方」を、結果を見る前に決めて固定する文書です。

1. 0042 と同じく、同じ AI を二つ用意し、片方は「A1 を選ぶと結果が返る世界」、もう片方は「A2 を選ぶと結果が返る世界」で、前半だけ育てます。二つの AI のつながりの強さには、自然に違いができます
2. 前半の終わりで AI をそっくり写し取り、つながりの強さだけを人の手で替えます。今回は、自然にできた違いの「向き」はそのままにして、その違いを 2 倍に延ばした強さを、元の強さを真ん中にして両側に作り、二つを比べます
3. 後半は、つながりの強さを固定したまま走らせ、A1 と A2 をどれくらいの割合で選ぶかを比べます

### 何を確かめるか

- 両側に動かした二つの強さで、選ぶ割合の差が出た AI の中で、その向きが偶然とは言いにくいほどそろっているかを確かめます。確かめ方は 0042 と同じで、向きは前もって決めていません
- 確かめるのは「2 倍」の一つの段だけです。1 倍・4 倍・8 倍も測りますが、記録として並べるだけで、合否は付けません
- 2 倍を選んだのは、前の 0042 の AI のつながりの強さの記録から計算すると、2 倍ならどの AI でも強さが決まった範囲からはみ出さないからです。4 倍では、はみ出す AI が出ます。はみ出す AI を外すと、比べる AI の集まりが偏るので、外さずに済む段を本番の判定にしました
- はみ出した AI や、比べられなかった AI は、理由ごとに数えて報告します
- 同じ物差しで大きさをそろえた「左右対称な違い」も並べて記録します。ただし、そろうのはその物差しだけなので、「大きさのせいか、形のせいか」を分けるものではありません

### 言わないこと

- 向きがそろっても、人の手で 2 倍に延ばした強さの話なので、「自然にできた違いが選び方を変えた」とは言いません
- 0042 で向きがそろわなかった理由も、この実験では言いません
- そろわなくても、「つながりの強さは選び方に効かない」とは言いません

0042 の AI は使いません。0042 の記録には、同じ AI のつながりの強さがすでに入っているので、同じ AI で本番をすると、結果を見る前に決めたことになりません。本番は新しい 200 体で行います。
