## 3. 可塑性の経路の列挙（②a の解析。符号・頻度は決めない）

#176 のマージ後の申し送り ③（Gemini 監査の照合）を受けて、方式 1（意図は決定の翌 Pulse）のもとで、AS2b の一つの窓のまわりに生じうる可塑性の寄与を、規則（`src/anima_ll/neuroarchitecture/plasticity.py` の `balanced_pair_window`）から列挙する。

**規則**【既存の事実】：接続 S → T について、Pulse の境界で、その Pulse の発火だけを使う。T が発火すれば、前の Pulse までの S の痕跡 x に比例して強める（A · x · (w_max − w)／w_max）。S が発火すれば、前の Pulse までの T の痕跡 y に比例して弱める（A · y · w／w_max）。同じ Pulse の発火（時刻の差 0）は数えない。痕跡は τ ≒ 6.15 秒で減る。

記号：C ＝ 手がかりの Unit、S_w ＝ 勝った源、S_l ＝ もう一方の源。手がかりの刺激が Pulse c、C の発火が c ＋ 1、S_w の発火（決定）が t、意図が t ＋ 1、規則 c が S_w の行動を指すとき結果の刺激が t ＋ L、C の結果による発火が t ＋ L ＋ 1。

| # | 出来事の順 | 一つの寄与（規則から決まる向き） | 起きる条件 |
|---|---|---|---|
| P1 | C（c ＋ 1）→ S_w（t） | C → S_w を強める。S_w → C を弱める | t ＞ c ＋ 1 で、C の痕跡が残っているとき |
| P2 | S_w（t）→ C（t ＋ L ＋ 1、結果による） | S_w → C を強める。**C → S_w を弱める**（逆順の弱める項：命題 G-11） | 規則 c が S_w の行動を指すとき（結果があるとき）だけ |
| P3 | S_w（t）→ S_l（t ＋ 1 以後。S_w からの駆動で遅れて発火） | S_w → S_l を強める。S_l → S_w を弱める | S_l がその後に発火するとき。窓は閉じているので意図は生まれない |
| P4 | S_l（遅れて）→ C（結果による） | S_l → C を強める。C → S_l を弱める。S_l の痕跡が S_w より新しければ、C → S_l の弱める項の方が大きくなりうる | P2 と P3 が両方起きるとき |
| P5 | 同じ Pulse の発火（C と源、S_w と S_l） | その組の寄与は 0（時刻の差 0 は数えない）。ただし前の Pulse までの痕跡を通して、ほかの組の寄与の大きさが変わる | 同時のとき（引き分けを含む） |
| P6 | 前の窓・前の結果の痕跡 | 上のどの寄与の大きさも変える | 窓の間隔 41 でも、痕跡は 0 にはならない（exp(−41/6.15) ≒ 0.001） |

**言えないこと**
- どの経路が、どれだけの頻度で起きるかは、立証していない
- 一つの窓の正味の重みの変化の符号も、立証していない（P1 と P2 は C → S_w に逆の向きで効き、P3〜P6 がその大きさを変える）
- したがって、「勝った源の C → S の重みは必ず強まる」「結果を受けた行動は必ず増える／減る」とは言わない（命題 G-10・G-11、基準 §6.3）

**③で事前登録するもの**（候補）
- 主の量と、その帰無。正味の向きを事前に決めない形にする
- 識別の限界：R-1（LC1・PC-3・PC-4）と R-7（規則 c の入れ替え。P2・P4 が規則 c で切り替わる）で言える範囲
- 経路を分けたい場合の対照の候補（必須にはしない）：C → S の接続の FB-1、C → S の接続だけの FREEZE。これらは機構の探索で、S3 の主張の必須の比べではない
