## 1. 問い

```text
0017  Life History → 後の target weight substate の差 → 同じ ordered の土台の上での後の Activity の差（20/20）
      ただし移植は W（＝ x − y）の差と平均の成分 m（＝ (x ＋ y)／2）の差を一緒に動かした
0018  A→B・A→C の forward mean m を 2 腕で同じ値にそろえ、W の差だけを残しても、読み出しは変わるか
```

> **0017 と同じ経験・無入力の自発活動・試しの手順で、各 t0 の ordered の試しの元を土台に、A–B／A–C の 4 本を対称標準化背景（m ＝ w_max／2）に置いた 2 つの腕を作る。腕 ordered_std には ordered の W(t0)、腕 shuffled_std には同じ時点・同じ境界の shuffled の W(t0) を載せる。2 腕で、標準の A の試しに対する直後の B・C の発火が、少なくとも 1 回は違うか**

x ＝ w(A→B)、y ＝ w(A→C)、W ＝ x − y、m ＝ (x ＋ y)／2 とする。**m は A→B・A→C の 2 本の forward mean で、4 本全体の平均ではない**（4 本全体の平均は、組の和の不変量 w(A→B) ＋ w(B→A) ＝ w(A→C) ＋ w(C→A) ＝ w_max から、自然な状態でも常に w_max／2）。以下「平均の成分」はこの m を指す。

### 言えること・言わないこと

成り立ったときに言うのは次まで：

> 対称標準化背景の上では、Life History 由来の W contrast の差だけで、直後の離散的な活動を変えるのに十分だった

- **standardized-background sufficiency test であって、自然な媒介の証明ではない**。2 腕とも自然な重みの状態ではない（平均の成分を w_max／2 へ動かしている）。どちらの腕も as_is とは呼ばない
- **「0017 の読み出しの差は W が担った」とは言わない**。0017 の自然な状態で何が効いたかは、0018 が成り立っても決まらない
- **成り立たなかったとき（S ＝ 0 が多い）も、「W は自然な状態では効かない」とは言わない**。標準化した m と W の相互作用で読み出しが消えた可能性が残る
- 平均の成分だけの効果（W をそろえて m だけを変える）は問わない
- 成り立っても「記憶した」とは書かない

## 3. 試しと介入

### 3.1 手順

試しの元の作り方と runtime の境界は 0017 §3.1・§3.3 とまったく同じ。各 t0（24001〜24300）で、両条件の本体の t0 − 1 の終わりから独立に、受け手（ordered）と提供側（shuffled）の試しの元を作り、どちらも t0 に Receptor A を入れて **Pulse t0 の可塑性の更新まで** 終える（t0 ＋ 1 の重みの固定の前）。

```text
受け手の試しの元（ordered）の t0 の終わり ── W_o ＝ x_o − y_o を読む
提供側の試しの元（shuffled）の t0 の終わり ── W_s ＝ x_s − y_s を読む
受け手の試しの元を 2 腕に複製し、どちらも 4 本だけを置き直す
   ├─ ordered_std ：x ＝ w_max／2 ＋ W_o／2、y ＝ w_max／2 − W_o／2
   └─ shuffled_std：x ＝ w_max／2 ＋ W_s／2、y ＝ w_max／2 − W_s／2
   （どちらも w(B→A) ＝ w_max − x、w(C→A) ＝ w_max − y）
          ↓ 可塑性ありのまま
      t0 ＋ 2 の s_B・s_C の発火を読む
```

- 痕跡（pre_trace・post_trace）・Unit の状態・B–C の 2 本・それ以外は、2 腕とも受け手の試しの元のまま
- 2 腕の違いは、4 本の weight のうち **W の差 D ＝ W_o − W_s だけ**（x の差 ＝ D／2、y の差 ＝ −D／2、逆向きの 2 本はその符号を反転したもの）。m は 2 腕とも w_max／2 で、a_AB ＋ a_AC ＝ 0
- **標準化で動かす量**：2 腕はどちらも受け手（ordered）の試しの元の複製なので、介入の直前の m はどちらも m_o である。標準化で 2 腕に共通に加わる変位は **m_o − w_max／2 だけ**。shuffled から持ってくるのは W_s だけで、shuffled_std の腕を m_s から動かしているわけではない（m_s − w_max／2 は提供側が自然な状態で持っていた offset で、介入の量ではない）
- runtime の順序から、2 腕は t0 の終わりまで同一で、t0 ＋ 1 の発火も同一。t0 ＋ 2 の B・C で違いうるのは、s_A の t0 ＋ 1 の発火が A→B・A→C を通る伝達だけ（0014 §3.3、0017 §3.3）

### 3.2 背景の平均 m ＝ w_max／2 の由来（常設チェック A6・C1）

m は新しく自由に選んだ値ではなく、0018 の要件から一意に決まる。

- 要件：自然にありうる全ての W（組の和の不変量から −w_max ≤ W ≤ w_max）を、切り詰め・拡大縮小・適用条件なしに、**1 つの固定の平均** の上へ状態空間の中のまま載せる
- x ＝ m ＋ W／2、y ＝ m − W／2 について、W ＝ ＋w_max のとき x ≤ w_max には m ≤ w_max／2、y ≥ 0 には m ≥ w_max／2 が要る。したがって **m ＝ w_max／2 だけ** が要件を満たす（W ＝ −w_max でも同じ）。そのとき任意の |W| ≤ w_max で x・y ∈ [0, w_max]
- 結果として可塑性 v1.1 の w0 ＝ w_max／2 と一致する（ChatGPT の導出、BLACKBOARD `c940699`）
- **名前は「対称標準化背景（symmetric standardized mean background）」とし、「中立な平均」とは呼ばない**。w_max／2 は可塑性・状態空間の上の対称点だが、活動の力学に対して中立だとは示していない
- 0017 で D だけの移植を主にしなかった理由（ordered の自然な平均のまま W を差し替えると、状態空間の外に出る個体がある）は、両腕の平均を同じ対称点に置くことで解消する。その代わりに、両腕が自然な状態から離れる（§1）

## 4. 指標と判定

```text
各試し：E(t0) ＝ |B_ordered_std(t0) − B_shuffled_std(t0)| ＋ |C_ordered_std(t0) − C_shuffled_std(t0)|   ∈ {0, 1, 2}
個体ごと：S ＝ Σ_t0 E(t0)                                                                     主の判定 s：S ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 s** | すべての個体 | S ＞ 0 | 成り立った個体数 ÷ 20 ≥ 0.8 |

- **standardized-background sufficiency test**。nonzero の検定で、向きの検定ではない
- **式の形（A6）**：E・S は 0016・0017 と同じ形。介入だけが替わる
- **適用対象（A3・A7）**：すべての個体。W_o ＝ W_s の試しは 2 腕が同一になり、専用の分岐を置かずふつうの算術で E ＝ 0 として S に入る。全試しでそうなった個体も N/A にせず S ＝ 0 の不成立（whole-pipeline。0016・0017 と同じ扱い）

### 4.1 符号・非空虚性の確認（A1・A7）

- **A1**：E ≥ 0 は定義から。単調な Unit の力学では、t0 ＋ 2 の B が 2 腕で違うならその符号は x の差 D／2 の符号と、C が違うならその符号は y の差 −D／2 の符号と整合することが構造上決まる。離散の発火なので、B だけ・C だけが違うこともあり、両方が違った場合に限り互いに逆向きになる。向きは問わず、効果が 0 でないかだけを問う。向き（E ＞ 0 の試しで、B・C の変化の符号が D の符号と整合したか）は記録
- **A7**：A が無入力の区間に自発発火しない個体でも、外から A を入れるので読み出しの機会はある。受け手（B・C）が閾値に近づかない状態では、D ≠ 0 でも S ＝ 0 になりうる。どちらも対象から除かない
- **合成の runtime の全状態からの契約テスト**（道具の段で書く。合成専用の seed 9500〜9599 だけを使う。自然な seed・smoke の結果では確かめない）：妥当な全状態の受け手と提供側の組を作り、実物の runtime で 0018 と同じ手順を通して、
  - (i) **300 回すべての試しで W_o ≠ W_s（2 腕の 4 本が実際に違う）のに、300 回すべてで E ＝ 0（S ＝ 0）** になる組
  - (ii) **S ＞ 0** になる組

  の両方がありうることを、具体的な状態で示す
- **ゼロの差の契約**：W_o ＝ W_s（提供側を受け手と同じ状態にする）なら、2 腕は t0 ＋ 2 まで同一（E ＝ 0）
- **ほかの runtime の契約**：2 腕の t0 ＋ 1 の一致、s_A が t0 ＋ 1 に発火しない試しで E ＝ 0、受け手・提供側の試しの元の重みがそれぞれの本体の t0 の終わりと一致（境界を 1 Pulse ずらすと検出される）

### 4.2 測れる大きさか（C3）

独立した既存の測定（0017 の本番の記録、別の seed。最初の試し 24001）で見当をつける。

- 2 腕の違い：|D| の中央値 2.35 × 10⁻³（3.5 × 10⁻⁵〜5.3 × 10⁻³）。x・y はそれぞれ D／2 ≈ 1.2 × 10⁻³ 動く。0016 の equalize（|W|／2 ずつ。18/20 で S ＞ 0）と同じ桁
- 標準化で両腕に共通に動かす量：受け手の m_o と w_max／2 の差 |m_o − w_max／2| の中央値 2.1 × 10⁻³（9.4 × 10⁻⁵〜4.3 × 10⁻³）。これは 2 腕の差には入らないが、受け手の B・C の駆動の水準を自然な状態から動かす。§1 の「相互作用で読み出しが消えた可能性」はここから来る
- 値の調整には使わない。smoke では見ない

## 5. 記録（判定に使わない）
