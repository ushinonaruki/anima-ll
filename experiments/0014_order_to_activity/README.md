## 1. 問い

0012 では、順序ありの経験で接続の状態（A→B の重み）は変わったが、A だけを入れたときの B の応答（活動）には出なかった。事後の解析では、重みの効果はあったが、同じ時期の興奮しやすさのずれ（順応が候補）がそれを打ち消していた。つまり 0012 の読み出しでは、**接続の違い** と **Unit の状態の違い** が分けられていなかった。

0014 はこれを正面から分ける。

> **同じ個体に、刺激の量は同じで順序だけ違う Life History を与える。その結果できた接続の重みの差そのものが、その時点の Unit の状態（興奮しやすさ）とは別に、その後の活動を変えるか**

```text
同じ Birth State・同じ刺激の数・同じ刺激の時刻
        │
        ├─ 順序あり（ordered） ──→ 重みの B/C 差 W
        │                              ↓
        │                     複製で W だけを消す（介入）
        │                              ↓
        │                     A だけを入れたときの活動
        │
        └─ 順序を崩した（shuffled） ──→ W の対照
```

| | 何を見るか | 何に答えるか |
|---|---|---|
| **主（p）** | 順序ありの個体で、複製の上で重みの B/C 差だけを消すと、A だけの読み出しが変わるか | 接続の違いが、Unit の状態と独立に活動へ出るか |
| **副（w）** | 順序ありの W ＝ w(A→B) − w(A→C) が、同じ seed の順序を崩した個体より大きいか | その重みの差は、刺激の量ではなく順序から来たか |
| 記録 | 順序あり − 順序を崩した の、ふだんの活動の差。順序を崩した個体での介入の効果。それらと W の関係 | 仕組みの記録（判定に使わない） |

### 決めないこと・主にしないこと

- **0013 で見つかった、刺激なしでの接続の自己形成は打ち消さない**。経験は自己形成と同じ時期に入れる（§3.1）。順序あり − 順序を崩した には「順序 × 自己形成」の相互作用も入る。それを含めて「同じ個体なら、この Life History の違いがどこへ連れていくか」を見る
- 力学・可塑性の値は変えない（minimal-v3、可塑性 v1.1：w_max ＝ α、w0 ＝ α／2、振幅の比 0.01）。設計図は 0012 v0.3 のもの
- 成り立っても「記憶した」「学習した」とは書かない。「この配線・この力学・この規則の上で、順序から来た重みの差が、その時点の Unit の状態と独立に、A だけを入れたときの B・C の応答を変えた」と書く
- 成り立たなくても、値・読み出しの窓・試しの時刻を変えて測り直さない

## 2. 脳の設計図

`experiments/0012_passive_world/neuroarchitecture.yaml` をそのまま使う（新しい設計図は作らない）。

```text
receptor.x1 → s1   receptor.x2 → s2   receptor.x3 → s3   （各 1.0、可塑性なし）
s1 ⇄ s2 ⇄ s3 ⇄ s1                                       （6 本、w0 ＝ α／2 ＝ 0.005、可塑性 v1.1）
```

役（A・B・C）と Receptor の対応は、0012 と同じく `(seed − 1) mod 6` で 6 通りを回す。

## 3. 手順

### 3.1 条件（同じ seed で 2 つ）

| 条件 | 内容 |
|---|---|
| **順序あり（ordered）** | 試行 k（0〜199）で、A を `600 ＋ 60k` に、B をその 2 Pulse 後に、C をその 30 Pulse 後に入れる |
| **順序を崩した（shuffled）** | 順序ありの 600 個の刺激の時刻はそのままに、600 個の札（A・B・C）を時刻のあいだで並べ替える（刺激用の乱数 `seed × 1000 ＋ 14`。Birth State の乱数とは別の流れ） |

- **刺激の数は A・B・C とも 200 で、2 条件で同じ**。0012 では B 160・C 40 で、刺激の数の偏りが重みと興奮しやすさの両方に入っていた。0014 ではそれを設計で外す
- **刺激の時刻の集合も 2 条件で同じ**。違うのは、どの時刻にどの札が来るかだけ
- 2 条件は、札が最初に違う Pulse より前は完全に同じ（同じ seed・同じ Birth State）。それ以降、内部の活動も可塑性も分かれる
- **経験は Pulse 600 から始める**。0013 で、刺激がなくても接続はかなり極性化すると分かった。長く無刺激で育ててから経験を入れると、「経験が接続を作るか」ではなく「すでにできた接続を経験が上書きできるか」という別の問いになる。Q1 は前者なので、経験は自己形成と同じ時期に入れる。600 は 0012 と同じ「落ち着く」長さ

#### 新しく選んだ値

| 値 | 理由 |
|---|---|
| C の時刻 ＝ A の 30 Pulse 後 | 試行の間隔（60）の半分。A の発火の痕跡（τ ≒ 6.15 秒）が 30 Pulse 後には e^(−30/6.15) ≒ 0.008 まで減るので、A と C は可塑性の窓の中で組にならない。C は次の試行の A の 30 Pulse 前でもあり、どちらの A からも等しく離れる |
| 試しの開始 ＝ 12600 | 最後の A（12540）の 60 Pulse 後（試行の間隔と同じ） |
| 試しの間隔 ＝ 6 Pulse | 複製の長さ（5 Pulse）＋ 1。試しの窓が重ならない中で最も密に置く |
| 試しの数 ＝ 200 | 試行の数と同じ。範囲は 12600〜13794（約 1200 Pulse ≒ τ_a の 4 倍）。経験の後の重みが残っているあいだの読み出しを、時刻を選ばずに全部並べる |
| seed 4001〜4020・5001〜5006 | これまでに一度も走らせていない seed |

### 3.2 時間の流れ（1 Pulse ＝ 1 秒）

```text
0 ─── 600 ──────────────────── 12570 ── 12600 ─────────── 13800
 落ち着く   経験（200 試行、60 Pulse ごと）     試し（200 回、6 Pulse ごと）
```

本体は、経験の後は刺激なしで進める（可塑性あり）。試しは本体に入れず、本体の複製の上でだけ行う。

### 3.3 試しと介入（主の判定の材料）

各試しの時刻 t0 で、本体の Pulse t0 − 1 の終わりの状態から、複製を 2 つ作る。

- **そのまま（as_is）**：何も変えない
- **重みの差を消した（equalized）**：複製の上でだけ、A–B・A–C の 4 本の重みを次のように置き直す

```text
x ＝ w(A→B)、 y ＝ w(A→C)、 m ＝ (x ＋ y)／2

w(A→B)' ＝ w(A→C)' ＝ m
w(B→A)' ＝ w(C→A)' ＝ w_max − m
```

両方の複製の Receptor A に t0 で同じ刺激を入れ、可塑性ありのまま t0〜t0 ＋ 4 の 5 Pulse だけ進める。

#### この介入が何を消し、何を残すか

組の和の不変量（`docs/plasticity-v1.1-scale.md` §8）により、可塑性 v1.1 のこの設計図では、各相互の組で w(i→j) ＋ w(j→i) ＝ w_max が保たれる。組の非対称 a_ij ＝ w(i→j) − w(j→i) は a_ij ＝ 2w(i→j) − w_max なので、この介入は

```text
a_AB' ＝ a_AC' ＝ (a_AB ＋ a_AC)／2
```

である。すなわち、

- **消すもの**：A–B と A–C の **差** だけ（W ＝ w(A→B) − w(A→C) を 0 にする）
- **残すもの**：A–B・A–C の平均の接続の状態（a_AB ＋ a_AC）、各相互の組の和（＝ w_max）、4 本全体の和、B–C の組の 2 本、**すべての痕跡**、すべての Unit の状態（活動・順応）、Birth State
- 新しい数値はない。a_AB ＝ a_AC という面の上で、4 本の重みの変更量の二乗和が最小の点でもある（余計に接続を動かさない最小の介入）

名前は「**接続の状態の weight 成分にある B/C 方向の非対称だけを消す**」とする。接続の状態には痕跡も含まれ、それは揃えないので、「A–B と A–C の接続の状態を同じにする」とは書かない。

2 つの複製の違いは、この 4 本の重みだけである。したがって読み出しに差が出れば、**その時点の重みの差への介入が、その後の活動の差を生んだ** と言える（その瞬間の Unit の状態は完全に同じなので、0012 の打ち消しの元だった興奮しやすさの違いは入らない）。

#### 読み出しを早い窓にする理由

- s_A は t0 ＋ 1 に発火し（操作の確認：`a_fired_at: 1`）、その駆動が s_B・s_C に届くのは t0 ＋ 2 から。窓は 0012 と同じ t0 ＋ 2〜t0 ＋ 4
- 複製を長く進めると、「最初の重みの差 → 活動の差 → その後の可塑性の差」まで含んだ総合の効果になる。それも因果としては正しいが、「その時点の重みが直接活動に効いた」を見たいので、最初の A の伝達に対する早い読み出しを主にし、複製は窓の終わり（t0 ＋ 4）で止める
- 経験の前の読み出し（出生直後の複製での試し）は行わない。主の比較は同じ時刻の複製の対で閉じているので、基準線を要しない

## 4. 指標

順序ありの個体ごとに：

```text
W_end   ＝ w(A→B) − w(A→C)          （本体の Pulse 12599 の終わり。最初の試しの直前）

R(t0)   ＝ B(t0) − C(t0)             B・C は、その複製で s_B・s_C が窓の中で 1 回以上発火したら 1、しなければ 0
ΔR(t0)  ＝ R_as_is(t0) − R_equalized(t0)

p_i     ＝ sign(W_end) × mean_t0 ΔR(t0)   （200 回の試しの平均）
```

- sign(W_end) で揃えるのは、順序ありの経験が作る重みの差の向きを結果を見て決めないため。W_end ＞ 0（A→B が強い）なら、差を消すと B の応答が相対的に減るはずで、ΔR ＞ 0 になる。W_end ＜ 0 なら逆
- W_end ＝ 0 のとき p_i ＝ 0（成り立たない）。専用の扱いは置かない。ふつうの算術でそうなる

## 5. 判定

| 判定 | 個体ごとの量 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 p** | p_i（順序あり） | p_i ＞ 0 | 成り立った個体数 ÷ 20 ≥ 0.8 |
| **副 w** | W_end（順序あり）と W_end（同じ seed の順序を崩した） | 順序あり ＞ 順序を崩した | 成り立った個体数 ÷ 20 ≥ 0.8 |

- 0.8 は 0012・0013 と同じ比（16／20）。新しい値ではない
- **p が成り立てば**、Q1 に「この設計図・この力学・この規則の上では、順序ありの経験の後の重みの B/C 差は、その時点の Unit の状態と独立に、A だけの読み出しを変えた」と答える
- **w が成り立てば**、その重みの差は刺激の量ではなく順序から来た、と言える。w が成り立たないとき、p の結果は「重みの差が活動に出る」ことは示すが、その差の出どころを順序とは言わない
- p と w の組み合わせについて、上の 2 行以上の結論の規則は置かない

### 記録（判定に使わない）

- 順序あり − 順序を崩した の、そのまま（as_is）の複製の読み出しの差：mean_t0 R(順序あり) − mean_t0 R(順序を崩した)
- 順序を崩した個体での介入の効果：sign(W_end) × mean_t0 ΔR
- 上の 2 つと W_end の関係（個体ごとの散布）
- ΔR(t0) の試しの時刻による推移、各試しの時刻の W
- 0012 の事後の解析と同じ形の、興奮しやすさの記録（B・C の順応の値）
