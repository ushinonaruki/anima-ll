## 1. 問い

0012 では、順序ありの経験で接続の状態（A→B の重み）は変わったが、A だけを入れたときの B の応答（活動）には出なかった。事後の解析では、重みの効果はあったが、同じ時期の興奮しやすさのずれ（順応が候補）がそれを打ち消していた。つまり 0012 の読み出しでは、**接続の違い** と **Unit の状態の違い** が分けられていなかった。

0014 はこれを正面から分ける。

> **同じ個体に、刺激の量は同じで順序だけ違う Life History を与える。その結果できた接続の重みの差そのものが、その時点の Unit の状態（興奮しやすさ）とは別に、その後の活動を変えるか**

```text
同じ Birth State・同じ刺激の数・同じ刺激の時刻
        │
        ├─ 順序あり（ordered） ──→ 重みの B/C 差 W
        │                              ↓
        │                     複製で W だけを消す（介入）
        │                              ↓
        │                     A だけを入れたときの活動
        │
        └─ 順序を崩した（shuffled） ──→ W の対照
```

| | 何を見るか | 何に答えるか |
|---|---|---|
| **主（p）** | 順序ありの個体で、複製の上で重みの B/C 差だけを消すと、A だけの読み出しが変わるか | weight の差 → 活動 |
| **副（w）** | 経験の終わりの W ＝ w(A→B) − w(A→C) が、同じ seed の順序を崩した個体より大きいか | 順序 → weight の差 |
| 記録 | 順序あり − 順序を崩した の、ふだんの活動の差。順序を崩した個体での介入の効果。それらと W の関係。A の発火 | 仕組みの記録（判定に使わない） |

### 決めないこと・主にしないこと

- **0013 で見つかった、刺激なしでの接続の自己形成は打ち消さない**。経験は Birth の直後から、自己形成と同じ時期に入れる（§3.1）。順序あり − 順序を崩した には「順序 × 自己形成」の相互作用も入る。それを含めて「同じ個体なら、この Life History の違いがどこへ連れていくか」を見る
- 力学・可塑性の値は変えない（minimal-v3、可塑性 v1.1：w_max ＝ α、w0 ＝ α／2、振幅の比 0.01）。設計図は 0012 v0.3 のもの
- 成り立っても「記憶した」「学習した」とは書かない。「この配線・この力学・この規則の上で、その時点の重みの B/C 差が、その時点の Unit の状態と独立に、A だけを入れたときの B・C の最初の応答を変えた」と書く
- 成り立たなくても、値・読み出しの時刻・試しの時刻を変えて測り直さない

## 3. 手順

### 3.1 条件（同じ seed で 2 つ）

| 条件 | 内容 |
|---|---|
| **順序あり（ordered）** | 試行 k（0〜199）で、A を `1 ＋ 60k` に、B をその 2 Pulse 後に、C をその 30 Pulse 後に入れる |
| **順序を崩した（shuffled）** | 順序ありの 600 個の刺激の時刻はそのままに、600 個の札（A・B・C）を時刻のあいだで並べ替える（刺激用の乱数 `random.Random("0014-shuffle:<seed>")`。名前で分けた流れで、Birth State の整数の seed の流れとは別。新しい数値を持たない） |

- **刺激の数は A・B・C とも 200 で、2 条件で同じ**。0012 では B 160・C 40 で、刺激の数の偏りが重みと興奮しやすさの両方に入っていた。0014 ではそれを設計で外す
- **刺激の時刻の集合も 2 条件で同じ**。違うのは、どの時刻にどの札が来るかだけ
- 2 条件は同じ seed なので Birth State は同じ。札が最初に違う Pulse から、内部の活動も可塑性も分かれる
- **経験は Pulse 1（runtime で刺激を入れられる最初の Pulse）から始める**。0013 で、刺激がなくても接続はかなり極性化し、最初の重みの変化は Pulse 10〜29 で始まると分かった。無刺激の助走を置くと、そのあいだに自己形成が先に進み、「経験が接続を作るか」ではなく「すでにできた接続を経験が上書きできるか」に近づく。経験の前の読み出しも要らない（§3.3）ので、助走を置く理由がない。Birth から Life History が始まる、とする

#### 値の由来

| 値 | 由来 |
|---|---|
| B の時刻 ＝ A の 2 Pulse 後、試行の間隔 60、試行の数 200 | 0012 と同じ |
| C の時刻 ＝ A の 30 Pulse 後（新しく選んだ値） | 隣り合う A（60 Pulse ごと）の中点。A–C の外からの時刻の関係が、前の A からも次の A からも ±30 で対称になる。A の痕跡（τ ≒ 6.15 秒）の寄与も e^(−30/6.15) ≒ 0.008 まで小さくなる（0 にはならない） |
| 試しの開始 ＝ 12001 | 次の A の時刻（1 ＋ 200 × 60。実際には A は来ない）。経験の周期の続きの位置 |
| 試しの間隔 ＝ 1 Pulse、数 ＝ 300 | 毎 Pulse、順応の時定数 τ_a の 1 区間。τ_a は秒なので、Pulse の数は adaptation_tau ÷ pulse_interval_seconds ＝ 300 ÷ 1.0 ＝ 300。複製どうしは独立なので、間隔に重ならないための条件はない。新しい間隔・期間を作らず、既にある力学の時定数から決める |
| 読み出しの時刻 ＝ t0 ＋ 2、介入の時点 ＝ t0 の処理の終わり | §3.3。runtime の 1 Pulse の処理の順序から決まる |
| seed 4001〜4020・5001〜5006 | これまでに一度も走らせていない seed |

### 3.2 時間の流れ（1 Pulse ＝ 1 秒）

```text
1 ─────────────────────────── 11971 ── 12001 ──────── 12300
 経験（200 試行、60 Pulse ごと）    最後の C   試し（毎 Pulse、300 回）
```

本体は、経験の後は刺激なしで進める（可塑性あり）。試しは本体に入れず、本体の複製の上でだけ行う。

### 3.3 試しと介入（主の判定の材料）

各試しの時刻 t0（12001〜12300）で、次の順に進める。

```text
本体の t0 − 1 の処理の終わり
   ↓ 複製
試しの元（probe_base）
   ↓ t0 に Receptor A へ刺激を入れ、t0 を処理する
t0 の処理の終わり
   ↓ ここで 2 つの腕に複製する
   ├─ そのまま（as_is）
   └─ 重みの差を消した（equalized）
          ↓ どちらも可塑性ありのまま
      t0 ＋ 1  s_A が発火しうる（2 腕で同じ）。その伝達は、腕ごとの重みで凍結される
      t0 ＋ 2  s_B・s_C を読む
```

- **そのまま（as_is）**：何も変えない
- **重みの差を消した（equalized）**：その複製の上でだけ、A–B・A–C の 4 本の重みを次のように置き直す

```text
x ＝ w(A→B)、 y ＝ w(A→C)、 m ＝ (x ＋ y)／2

w(A→B)' ＝ w(A→C)' ＝ m
w(B→A)' ＝ w(C→A)' ＝ w_max − m
```

#### 介入をこの時点で入れる理由（runtime の 1 Pulse の順序）

runtime の 1 Pulse の処理（`src/anima_ll/runtime/pulse_runtime.py` の `run_pulse`）は次の順である。

1. Pulse の冒頭で、その Pulse の伝達に使う重みを固定する
2. 感覚の出来事・発火を、その固定した重みで駆動にし、**次の Pulse に届ける**
3. 終わりに、その Pulse の発火を接続の状態に渡す（可塑性。更新は次の Pulse の冒頭の固定から見える）

ここから、t0 の処理の終わりで分けると：

- **t0 の終わりまで 2 腕は完全に同じ**（同じ複製）。v0.2 のように t0 − 1 の終わりで分けると、置き直した 4 本の重みが t0 の自然な発火の伝達と可塑性にも先に効き、A が発火する前から 2 腕が分かれうる
- **t0 ＋ 1 の Unit の状態と発火は 2 腕で同じ**。t0 ＋ 1 の Unit が受ける駆動は t0 に作られ、t0 の冒頭の重み（2 腕で同じ）で凍結されているから。したがって s_A が t0 ＋ 1 に発火するかも 2 腕で同じ
- t0 ＋ 1 の冒頭で固定される重みが、腕ごとの重み（介入した 4 本）になる。t0 ＋ 1 の発火の伝達はこの重みで凍結され、t0 ＋ 2 に届く
- t0 ＋ 2 で s_B・s_C が受ける駆動のうち、2 腕で違いうるのは **A→B・A→C を通る s_A の t0 ＋ 1 の発火の伝達だけ**（B→A・C→A の違いは A に届くもので、B・C には届かない。B–C の 2 本は触らない）
- t0 ＋ 1 の終わりの可塑性の更新は t0 ＋ 2 の冒頭の固定から見えるので、t0 ＋ 2 の B・C の応答には入らない
- したがって **s_A が t0 ＋ 1 に発火しなかった試しでは、t0 ＋ 2 の B・C は 2 腕で同じになり、ΔR ＝ 0 になる**（構造上の帰結。道具の契約テストで確かめる）

#### この介入が何を消し、何を残すか

組の和の不変量（`docs/plasticity-v1.1-scale.md` §8）により、可塑性 v1.1 のこの設計図（初期の 2 本の和 ＝ w_max）では、各相互の組で w(i→j) ＋ w(j→i) ＝ w_max が保たれる。組の非対称 a_ij ＝ w(i→j) − w(j→i) は a_ij ＝ 2w(i→j) − w_max なので、この介入は

```text
a_AB' ＝ a_AC' ＝ (a_AB ＋ a_AC)／2
```

である。すなわち、

- **消すもの**：A–B と A–C の **差** だけ（その時点の W ＝ w(A→B) − w(A→C) を 0 にする）
- **残すもの**：A–B・A–C の平均の接続の状態（a_AB ＋ a_AC）、各相互の組の和（＝ w_max）、4 本全体の和、B–C の組の 2 本、**すべての痕跡**、すべての Unit の状態（活動・順応）、Birth State
- 新しい数値はない。a_AB ＝ a_AC という面の上で、4 本の重みの変更量の二乗和が最小の点でもある（余計に接続を動かさない最小の介入）

名前は「**接続の状態の weight 成分にある B/C 方向の非対称だけを消す**」とする。接続の状態には痕跡も含まれ、それは揃えないので、「A–B と A–C の接続の状態を同じにする」とは書かない。

2 つの複製の違いは、この 4 本の重みだけである。したがって読み出しに差が出れば、**その時点の重みの差への介入が、その後の活動の差を生んだ** と言える（その瞬間の Unit の状態は完全に同じなので、0012 の打ち消しの元だった興奮しやすさの違いは入らない）。

#### 読み出しを t0 ＋ 2 の 1 Pulse にする理由

```text
t0      Receptor A に刺激
t0 ＋ 1  s_A が発火しうる
t0 ＋ 2  s_A の伝達が s_B・s_C に最初に届く   ← ここだけ読む
```

- t0 ＋ 2 だけを見れば、その後の網の中の折り返し（B・C の発火が A や互いに返る）や、試しの中の可塑性による重みの変化を混ぜない（上の runtime の順序により、t0 ＋ 2 の B・C の応答に入る 2 腕の違いは、s_A の t0 ＋ 1 の発火の伝達だけ）。「その時点の重みが、最初の A の伝達を通して直接活動に効いたか」に対応する
- これで、読み出しの窓 [2, 4] と複製の長さという値はなくなる（0012 から引き継いだ窓も外す）
- 経験の前の読み出し（出生直後の複製での試し）は行わない。主の比較は同じ時刻の複製の対で閉じているので、基準線を要しない

## 4. 指標

```text
W(t)        ＝ w(A→B) − w(A→C)          （本体の Pulse t の処理の終わり）
W_probe(t0) ＝ w(A→B) − w(A→C)          （probe_base の t0 の処理の終わり。介入の直前。as_is の腕の重みそのもの）

B(t0)・C(t0) ＝ その腕で、s_B・s_C が t0 ＋ 2 に発火したら 1、しなければ 0
R(t0)   ＝ B(t0) − C(t0)
ΔR(t0)  ＝ R_as_is(t0) − R_equalized(t0)

p_i     ＝ mean_t0 [ sign(W_probe(t0)) × ΔR(t0) ]   （300 回の試しの平均。順序ありの個体）

W_post  ＝ W(probes.first − 1) ＝ W(12000)
```

- 向きを W_probe(t0) で揃えるのは、各試しで消しているのが **介入の直前の** 重みの差だから。本体は試しの区間も可塑性ありで進み、0013 で刺激なしでも重みが動くと分かっているので、W は試しの区間で変わりうる。W_probe(t0) ＞ 0（A→B が強い）なら、差を消すと B の応答が相対的に減るはずで ΔR ＞ 0 になる。W_probe(t0) ＜ 0 なら逆。向きは結果を見て決めない
- W_probe(t0) ＝ 0 の試しの項は 0。s_A が t0 ＋ 1 に発火しなかった試しの項は ΔR ＝ 0 で 0（§3.3）。どちらも専用の扱いは置かず、ふつうの算術のまま平均に入れる
- W_post は「経験が作った重みの差」。最後の経験の刺激は C の 11971 だが、その Unit の応答は 11972 に出て、その可塑性の更新は 11973 の冒頭から見える。11971 ではまだ反映が終わっていない。新しい時刻を作らず、最初の試しの直前（次の、来ない A の直前）という既にある周期の境界 12000 で測る

## 5. 判定

| 判定 | 個体ごとの量 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 p** | p_i（順序あり） | p_i ＞ 0 | 成り立った個体数 ÷ 20 ≥ 0.8 |
| **副 w** | W_post（順序あり）と W_post（同じ seed の順序を崩した） | 順序あり ＞ 順序を崩した | 成り立った個体数 ÷ 20 ≥ 0.8 |

- 0.8 は 0012・0013 と同じ比（16／20）。新しい値ではない
- p は「weight の差 → 活動」、w は「順序 → weight の差」を、それぞれ直接報告する。組み合わせの規則は置かない
- **p が成り立てば**、Q1 に「この設計図・この力学・この規則の上では、順序ありの経験の後の重みの B/C 差は、その時点の Unit の状態と独立に、A だけを入れたときの B・C の最初の応答を変えた」と答える
- **w が成り立てば**、経験の終わりの重みの差は刺激の量ではなく順序から来た、と言える

### 記録（判定に使わない）

- 順序あり − 順序を崩した の、そのまま（as_is）の複製の読み出しの差：mean_t0 R(順序あり) − mean_t0 R(順序を崩した)
- 順序を崩した個体での介入の効果：mean_t0 [ sign(W_probe(t0)) × ΔR(t0) ]
- 上の 2 つと W_post・W_probe(t0) の関係（個体ごとの散布）
- ΔR(t0) と W_probe(t0) の試しの時刻による推移
- s_A が t0 ＋ 1 に発火した試しの割合（条件ごと。2 腕で同じ）。v0.1 では操作の確認に入れていたが、A が実際に発火するかは操作ではなく現象なので、記録に回した（0013 v0.5 の「smoke では実際の現象に条件を課さない」と同じ理由）。発火しなければその試しの効果は 0 になる。それも結果として受け取る
- 0012 の事後の解析と同じ形の、興奮しやすさの記録（B・C の順応の値）

### 9.3 事後の観察：p の向きは構造上決まっていた（判定ではない）

結果を見たあとに、次のことに気づいた。

- 2 腕は同じ状態から出発し、t0 ＋ 2 の B・C が受ける入力で違うのは、s_A の t0 ＋ 1 の発火が A→B・A→C を通って運ぶ駆動だけである（§3.3）
- W_probe ＞ 0 のとき、介入は w(A→B) を下げ、w(A→C) を上げる。Unit の力学（`simple_activity_dynamics.py`）は、受ける刺激について単調（activity に足して、threshold ＋ adaptation 以上なら発火）なので、B は as_is のほうが発火しやすく、C は equalized のほうが発火しやすい。したがって **sign(W_probe) × ΔR は、どの試しでも負にならない**（W_probe ＜ 0 のときも対称）
- 実際に、順序あり・順序を崩した の両条件 12000 回の試しで、sign(W_probe) × ΔR が負になった試しは 0 回だった

したがって、個体ごとの p_i ＞ 0 は「W_probe ≠ 0 で、300 回のうち 1 回以上、B か C が閾値の際にいて、その重みの差で発火が入れ替わった」と同じ意味になる。p の判定が答えているのは、**この大きさ（w_max ＝ α の尺度）の重みの差が、Unit の状態を揃えたうえで、最初の応答を 1 回以上変えるほどの大きさを持つか** であって、効果の向きではない。向きは、この配線と単調な力学では、介入の定義から決まっている。

- この性質は事前登録（v0.1〜v0.3）の議論で Claude も ChatGPT も指摘しておらず、結果を見て初めて気づいた。判定の式・基準は変えない
- 情報を持つのは効果の **大きさ**（§9.2：p_i 0.010〜0.220、ΔR ≠ 0 は 300 回中 3〜66 回）と、それが W の大きさとどう関係するか（相関 0.51）のほう
- 0012 の結論（重みの効果はあったが、興奮しやすさの違いに打ち消されて、ふだんの活動には出なかった）と合わせると：**重みの差は、Unit の状態を揃えれば、最初の応答を確かに動かす大きさを持つ。ただし、ふだんの活動の差（§9.2）としては、他の違いに埋もれやすい**
