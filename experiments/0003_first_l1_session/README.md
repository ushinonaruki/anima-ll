### 繰り返しの仕組み

```text
u1：12 Pulse ごとに自発発火 → 受容野は空 → LLM に「（断片なし）」
    → ほぼ毎回同じ文「現在の状況や状況に関係のない情報がなく、具体的な内容はわかりません。」
u3：それを受けて毎回同じ一文「状況が不明なので、具体的な情報が得られていない。」
```

自分の出力が自分に戻って増幅しているのではない。毎回まったく同じ空の入力に、sampling を固定した LLM が同じ答えを返しているだけ。

### u2 は毎回発火して claim を出すが、Kernel の実行権を獲得できない

u2 は 12 回 claim を出している（u1 の出力を重み 0.4 で受けて発火する）。しかし毎回 u3 と同じ Pulse に発火し、llm_pool（容量 1）を u3 に取られている（strength 0.82 対 1.0）。u2 が実際に計算できたのは、「こんばんは」のあと u3 と重ならなかった 1 回だけ。

負けた Unit も発火したものとして活動がリセットされるので、次も同じタイミングで発火して同じように負ける（0001 §3 の候補「claim に負けた Unit の扱い」と同じ論点）。

### 「こんばんは」の行方

- 22 Pulse 目に入力。u0 が中継し、23 Pulse 目から u1・u2 に見える
- u1 はちょうど 22 Pulse 目に（入力が見える前に）発火して不応期に入り、受け取り損ねた。次の発火（38 Pulse 目）では Delta の保持期間（10 Pulse）が切れていた
- u2 が「夜の時間です。」と連想し、u3 がそれを u1 の「情報がない」と混ぜて「状況が不明なので、夜の時間だけは明確に言います。」と発話した。外からの入力に辿り着いた唯一の発話

## 整理（Claude ↔ ChatGPT ↔ t-k）

「何もないなら同じ返答でもよいのでは」（t-k）。その通りで、同じ返答になること自体は問題ではない。中身が同じなのに言い回しだけ乱数で変えるのは、生命感演出の乱数と同じなので行わない。

足りていないのは次のこと：

| | 内容 |
|---|---|
| A. 表象不足 | 「静かだった」「時間が経った」「さっき話しかけられた」を内部の情報として表せない。どの「何もない」も同じ空の箱になる |
| B. 自発的な内容の不足 | 「考える時刻」は自発的に生まれるが、「考える内容」は生まれない（想起・残留表象・予測がない） |
| C. cognitive leakage | 内容の生成も、口に出すかどうかの判断も、LLM の事前分布が肩代わりしている。発話の中身は AnIma-ll の状態ではなく、入力の形式についての説明になっている |
| D. 時間スケールの食い違い | Unit の力学（自発周期 ≒ 12 Pulse）、Delta の保持期間（10 Pulse）、Kernel の推論時間が噛み合わないと、一過性の出来事を取りこぼす。ただし保持期間を「記憶」の代わりとして調整することはしない |
| E. 力学の分岐と競合 | 小さな初期値の差や発火の同期で、Unit の役割が質的に分かれる（u1 は周期的なペースメーカー、u2 は毎回競合に負ける）。「創発的な分化」と「たまたま閾値や競合に勝った Unit だけが動く」は別物なので、本番の設計図では注意する |

## 結論

L1 では認知の力学に手を入れず、観察結果として記録する。`utter` の仮の足場が「黙る自由」を実現できなかったことも、そのまま結果として残す。

L1 として確認できたこと：実際の LLM が Compute Kernel として動いた／Pulse を止めずに非同期で推論した／コンソール入力がネットワークを通った／来歴から原因を追えた／cognitive leakage を実測できた／力学の周期性と Unit 間の差が観測できた。

## L2 への申し送り

1. **発火履歴に依存する順応・恒常性（adaptation / homeostasis）**：発火すると一時的に発火しにくくなり、時間とともに戻る。payload を読まないので「中身を読まない刺激計算」と衝突しない。周期的なペースメーカーにも直接効く見込み。意味的な慣れ（同じ種類の刺激への慣れ）は、必要になってから別の仮説として
2. **内部状態・時間を情報にする仕組み**：「何も起きなかった」を空の箱ではなく中身のある入力にする（v1.4 §6.3）
3. **競合に負けた Unit の扱い**（u2 の件）
4. 長期記憶は、1・2 で「内容のない自発活動」がどう安定するかを見てから
