## 探索的に観察したこと（2026-10-06）

### 1. 内在的駆動の大きさで、自発性が「ある／ない」に分かれる

活動の平衡値はおよそ `intrinsic_drive / (1 − decay)`。

- `drive=0.05, decay=0.85` → 平衡値 ≒ 0.33 < 閾値 0.5 → 入力がない限り一度も発火しない
- `drive=0.08` → 平衡値 ≒ 0.53 → ゆっくり自発発火する

自発性が「少しずつ増える」のではなく、閾値をまたぐかどうかで急に切り替わる。

### 2. 同値の claim を unit_id 順で決めると、特定の Unit が勝ち続ける

claim の強さが 1.0 で頭打ちになりやすく、同値が多発する。同値を unit_id の辞書順で決めていたため、`u1` と同時に発火する `u2` が 120 Pulse のあいだ一度も採択されなかった。

→ 同値は Pulse ごとに順番を回す方式に変更（決定論的・意味なし・長期的に偏らない）。変更後は `u2` も採択されるようになった。

### 3. 自発活動は周期的になる（未解決）

入力がないと、`u1` が 12 Pulse ごと、`u3` がその 5 Pulse 後に、ほぼ正確に繰り返す。初期値のばらつき（jitter 10%）と Unit 間の相互作用では、周期は序盤に崩れても後半に戻ってくる。

これは避けたい「決まった間隔で喋るタイマー」的な振る舞いそのもの。対処の候補（設計判断が必要）：

- 恒常性（長く発火していない／しすぎた Unit の感受性を変える）
- claim に負けた Unit の扱いを変える（現在は負けても活動がリセットされる）
- 神経の確率的なゆらぎ（チャネルノイズ等。生物学的根拠はあるが、「生命感演出の乱数は使わない」原則との線引きが必要）
- 中身を読む刺激計算（L2）で、入力内容の違いがタイミングの違いになる
