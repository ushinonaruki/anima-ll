## 0. 実行の形式と、問いと主張の範囲

### 0.1 実行の形式：0039 型の事前登録の実験にする

候補の文書 §4.1 の二つの形のうち、**0039 型の事前登録の実験**（事前登録 → 道具 → 盲検の smoke → 本番の一度限りの実行 → 結果）にする。0038 型の前方の関門にはしない。

| 観点 | 0038 型の前方の関門 | 0039 型の事前登録の実験（この実験） |
|---|---|---|
| 推定対象 | 操作の可能性（窓で選択が出るか）。公表する量を操作の可能性の量に限り、選択の割合や系の間の差を報告しない（0038 は A1・A2 の窓の数を別々には出さなかった） | **選択の割合の変化の、個体ごとの分布**（現象の量）。判定 J_A と推定 E_A（§4） |
| seed | 関門の専用の seed を一度だけ | 契約テストの合成の seed（33301〜33399）・盲検の smoke（33201〜33206）・判定の一度限りの seed（33001〜33200）を分ける（§9.2） |
| 判定の量の表示 | 関門の量だけ | 契約テストと smoke では表示しない（権限の文書 §3）。本番で一度だけ計算する（§9.3） |

- **この形にする理由**：候補 A の推定対象は、「前もって固定した対称な二つの端への介入で、選択が変わる個体はどれだけあり、どれだけ変わるか」（候補の文書 §3）で、選択の割合とその差そのものを測る。0038 型の関門は、まさにこの量を出さない形なので、推定対象を報告できない
- **別の関門を置かない理由**
  - この実験の系（世界が結果を返さない・出生から FREEZE）で窓の選択が出るかは、関門 0038 の本体（閉ループ・可塑性あり）とは条件が違い、確かめていない
  - ただし、選択が出ない個体は「定まらない」として分母から外れ、定まる個体が 10 未満なら判定不能という、事前に決めた結末になる（§4.1・§4.7）
  - 判定不能を避けるための関門を別に置くと、その結果を見て値を選び直す道が開く。判定不能になっても、値を変えて同じ seed で走らせ直さない

### 0.2 問い

> **問い Q-A**：同じ個体（seed）から、可塑的な 6 本の重みのうち、手がかりの Unit C と源の間の 2 組（4 本）だけが違う二つの系 X1・X2 を作る。X1 は C → 源 1 を w_max・C → 源 2 を 0 に（源 1 に寄せた端）、X2 はその鏡に置く。どちらも出生のときから 6 本を FREEZE し、世界は意図を記録するだけで結果を返さない。試しの区間 U（窓 26〜50）の A1 の割合を二つの系で比べる。
> - **判定 J_A**：A1 の割合が一方の向きにずれる個体は、事前に決めた基準を超えて多いか
> - **推定 E_A**：A1 の割合が変わる個体はどれだけあり、どれだけ変わるか

- 報告の量は物理の行動 ID（A1 の割合）にそろえる
- 向きは事前に決めない。両側で問う（理由は §4.5）
- **0039 の D^W との関係**：0039 の D^W は、経験の区間の終わりの状態で、二つの本体に自然にできた重みの差を移植し、結果を返す世界（c ＝ A1）で比べた記述だった。段 (iii) の存在の水準の観測である（候補の文書 §0）。この実験は、介入（固定した対称な端）・背景（出生の状態、経験なし）・世界（結果を返さない）・個体群（新しい seed）のすべてが違う。D^W を確かめ直したり、言い換えたりするものではない

### 0.3 主張の形（J_A が成立したとき）

「AS2b（関門の宣言の予定・窓・出口・役と、C0 の力学）で、出生のときから可塑的な 6 本を FREEZE し、世界が結果を返さない条件のもとで、C ↔ 源の 2 組を前もって固定した対称な二つの端に置くと、試しの区間の A1 の割合が［＋／−］の向きにずれる個体が、A1 の割合が定まる個体の母集団で、事前に決めた基準を超えて多かった」

- **＋の向き**：C → 源の重みを w_max にした側の源の行動の割合が高い。X1 の A1 の割合が X2 より高いこと（D^X ＞ 0）で、札の付け方に依らない（§3.2）
- **−の向き**：その逆。C → 源の重みを w_max にした側の源の行動の割合が低い
- **主張の水準**：この二つの端・この窓の条件・出生からの FREEZE・結果を返さない世界・定まる個体の母集団についての、条件付きの結果である。推定 E_A（変わる個体の割合と大きさ）は、判定の成否に依らず必ず添える

### 0.4 主張しないこと

- 学習・経験による変化・規則 c に依る変化（この実験の系は、経験で重みが変わらず、世界は規則で結果を返さない）
- 報酬・価値・意思決定・好み。＋・−の向きを接近・回避と呼ぶこと
- 自然な経験で届く重みの変化の効果。端は自然な経験では到達しない状態でありうる
- 端の結果を、範囲の中のほかの重みでの結果の上限・下限と読むこと（`docs/activity-plasticity-loop-math.md` §5.2 の非単調性）
- **不成立から**、「AS2b は重みで選択を動かしにくい」「構成の余地が小さい」「構成の限界」と結論すること。不成立を、構成の見直し（候補 D）を始める条件にすること（候補の文書 §3 の候補 D）
- どの接続の効果か。C → 源 と 源 → C は組の和の保存（F1）で一緒に変わり、分けていない
- 0039 の D^W・J_W の確かめ直し・言い換え・比べ。0039 の J_7 の不成立の理由の説明
- 候補の文書 §2 の仮説 H1 を確かめたこと（H1 は課題を選ぶ材料で、この実験の判定の対象ではない）

  - X1′ の全 Pulse の重みを、計算から作り直して実測の記録として保存しない

## 4. 主の判定 J_A と主の推定 E_A

### 4.1 個体の分け方

どれも、ここで前もって定め、結果を見てから変えない。

| 分け方 | 定義 | J_A・E_A での扱い | 報告 |
|---|---|---|---|
| **定まらない** | n_U(X1) ＝ 0 または n_U(X2) ＝ 0 | 分母に入れない（N/A。常設チェック A3 の (3)） | 件数を、片方だけ・両方に分けて報告する |
| **定まる** | 残りの個体 | 分母に入れ、D^X_i の符号を数える | — |

- **適格外は置かない**：X1 と X2 は Pulse 0 から重みが違い、0039 の「共通の部分で経験が分かれていない」に当たる条件がない。二つの系の発火が最後まで分かれなかった個体は、問いの答え（変わらなかった）の一部なので、定まるなら分母に残し、D^X_i ＝ 0 になる。札を付けて件数を報告する（R5）
- **定まらない条件は二つの系について対称**にした（片方の系の性質だけで個体を選ばないため）。ただし、条件が対称であることだけからは、残した個体の D^X_i の符号が＋・−で対称であることは導けない。符号の対称性は、§4.6 で帰無として明示的に仮定する
- **沈黙**：系 S-1′（§7.2）の条件を満たす源（構造的に沈黙する源）を持つ個体には、札を付けて件数を報告する。定まるなら分母に残す（常設チェック A7 の (a)）。その個体では、もう一方の行動しか勝てないので、s はどの系でも 1 か 0 で、D^X_i ＝ 0（成立に不利な側）
- ほかの除外はしない。札を、個体を除くために使わない
- 記述の対照（D^M・Δ^1・Δ^2・D^X_E）の分母も、それぞれの二つの系について同じ形で決める

### 4.2 個体の事象

- 定まる個体 i について、**D^X_i ＝ s(X1) − s(X2)**。事象「＋」は D^X_i ＞ 0、「−」は D^X_i ＜ 0、「0」は D^X_i ＝ 0
- 個体の中の比べは決定論で、一つの個体から一つの符号が得られる（命題 G-6 の形）。個体の中の窓を独立の標本として数えない

### 4.3 判定 J_A

- k₂(m)：P(Bin(m, 1/2) ≥ k) ≤ 0.025 となる最小の k（§5.1）
- m ＝ 定まる個体の数。m ＜ 10 なら**判定不能**
- m ≥ 10 で、「＋」の個体の数 ≥ k₂(m) なら **＋の向きで成立**、「−」の個体の数 ≥ k₂(m) なら **−の向きで成立**（k₂(m) ＞ m/2 なので、両方が同時には成り立たない）。どちらでもなければ**不成立**
- 主の判定は J_A の一つだけで、ほかの判定を置かない

### 4.4 主の推定 E_A（判定ではない）

有効で m ≥ 1 なら、J_A の成否に依らず必ず計算して報告する。

| 量 | 定義 | 区間 |
|---|---|---|
| **p_change** | (＋の数 ＋ −の数)／m：U の A1 の割合が二つの端で違う個体の割合 | Clopper–Pearson の 95%（両側） |
| p_＋・p_− | ＋の数／m、−の数／m | 同じ |
| **p_flip** | (s(X1) − 1/2)(s(X2) − 1/2) ＜ 0 の個体の数／m：勝ちの多い行動が二つの端で入れ替わる個体の割合 | 同じ |
| **|D^X| の分布** | 定まる個体全体と、変わる個体（D^X_i ≠ 0）のそれぞれで、最小・四分位・最大 | なし |

- E_A は推定で、閾値を置かない。「割合が高い・低い」「効果が大きい・小さい」を判定として主張しない
- p_flip で s ＝ 1/2 の系を持つ個体は、入れ替わりに数えない（積が 0）

### 4.5 この形にした理由（結果を見る前の理由）

**主の条件を (a)・結果を返さない世界にした理由**
- 候補 A の推定対象は、「前もって固定した対称な介入への応答」（候補の文書 §3）。二つの系の違いを 4 本の重みだけにすると、推定対象がいちばん単純になる
- (a) は、経験・規則 c・境界の操作を入れない。(b) は、背景の状態が経験と規則 c に依り、どちらの本体を条件にするか（R-2）が入る（§1.3）
- 結果を返さない世界は、即時の帰還（結果 → C → 源）と規則 c を入れない。返す世界では、重みの介入が結果の刺激の数・時刻とその後の軌道を変え、それも介入の総効果に入る（媒介の経路で、交絡ではない）。結果の刺激のない状態での重みへの応答を切り出すため、主の条件は返さない世界にする
- 出生から FREEZE にすると、介入の値が終わりまで保たれ、可塑性による重みの変化が比べに入らない
- 道具の費用が小さい：`build`・`transplant`・`declare` を Pulse 0 で組み合わせるだけで、境界の手順（0039 の S0〜S5）が要らない

**向きを決めず両側にした理由**
- 端では、C → 源と源 → C が F1 で一緒に変わる。X1 では C → 源 1 が強いが、源 1 → C は 0、源 2 → C は w_max になる。源 2 の発火が C を駆動し、C が源 1 を駆動する経路も強まる。どちらの経路が勝ちの時刻に効くかを決める命題はない
- **位相の逆転がありうる**【機構の上の可能性。未検証】
  - 時刻の順序：手がかりの刺激は c_k、C の発火は c_k ＋ 1、その駆動が源に届くのは c_k ＋ 2 で、これが窓の始まり a_k である（契約 §1 の注・命題 G-3。関門 0038 の o ＝ 2 の理由）。したがって、**今の手がかりの駆動が、窓の始まる前に源を発火させることはない**
  - ただし、力学（`SimpleActivityDynamics`）は、発火で activity を 0 に戻し、順応を増やす。それまでの窓での駆動の違い（過去の発火の履歴）や、源の自発の発火とそのリセットを通して、源の発火の位相は系ごとに変わりうる。たとえば、源が窓の始まりの直前に（過去の履歴や自発の発火で）発火していれば、その窓の早い Pulse では activity が低い
  - そのため、C → 源を強くした側の源が、窓の中で先に発火するとは限らない。その側の行動の割合が下がる向き（−）もありうる
  - これが実際に生じるかは、この実験の判定では確かめない。窓の直前の発火の数を、記述だけの記録 R9 に残す
- 時間をまたぐと、力学は入力について単調でない（`docs/activity-plasticity-loop-math.md` §5.2）
- そのため、＋の向きは事前の見込みとしても置かない

**個体の事象を符号に、判定を個体の多数にした理由**
- 0034〜0039 と同じく、個体の単位の判定にする。符号は閾値・比・正規化を持ち込まない（A6）
- 個体ごとに向きが違う効果（ある個体は＋、ある個体は−）は、J_A では検出しない。それを記述するのが E_A の p_change・p_flip と |D^X| の分布である。ただし、E_A は判定ではないので、「個体ごとに向きの違う効果がある」とは主張しない

**記述の対照を置いた理由**
- D^M（中間の対）：端と端の間の一つの点での応答。候補 A の陰性が「途中の重みでは変わる可能性」を除かないこと（§0.4）を、記述で補う。一点だけで範囲を覆わないので、どの結論の根拠にもしない
- Δ^1・Δ^2（参照の系 X0 との差）：それぞれの端が、出生時の値から A1 の割合をどちらに動かしたかの記述
- D^X_E：判定に入れない窓 1〜25 での同じ対比。区間の分け方に依る違いを、記述として並べる

**個体数・誤りの水準・最小の m**：0039 と同じ（§5）

### 4.6 帰無仮説と、その条件

- **推論の対象**：定まる個体の母集団
- **H₀^A**（選別の後の母集団についての、明示の統計上の帰無）：出生時の状態（seed）を独立・同一分布の標本と見なす。定まる個体の母集団で、P(D^X_i ＞ 0) ＝ P(D^X_i ＜ 0)
- 帰無のもとでは、各個体が「＋」である確率は (1 − P(D^X_i ＝ 0))／2 ≤ 1/2。0 の個体を分母に残すので、「＋」の個体の数は Bin(m, 1/2) に確率的に支配される。「−」も同じ。したがって P(J_A がどちらかの向きで成立 | H₀^A) ≤ 0.025 ＋ 0.025 ＝ 0.05
- **この向きの対称性は、仮定する帰無であって、導いた性質ではない**
  - 定まらない条件が対称であることからは導けない（§4.1）
  - 役の乱数の割り当てからも導けない。札の入れ替えは D^X を変えない（§3.2）ので、D^X → −D^X の根拠にならない
  - そのため、成立は「定まる個体の母集団で、ずれの向きが偏っていた」ことで、選別の前の全個体についての主張ではない
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない
- 同じ個体の二つの系は独立ではない。対の差を一つの個体の事象にして、この依存を判定に入れない

|---|---|---|---|

- この実験は、**割合が低いこと・効果がないことを主張する判定を置かない**。不成立のときの陰性の読みは、上の言えることの範囲だけ

### 何を決めたか

前回決めた次の課題（候補 A）の「調べ方」を、結果を見る前に決めて固定する文書です。まだ AI は動かしていません。

### 何を確かめるか

AI の中には、手がかりを受け取る部品と、二つの行動（A1・A2）のどちらかを起こす二つの部品があります。手がかりの部品と行動の部品の間の「つながりの強さ」を、許される範囲のいちばん端に置きます。

- 片方の AI は、A1 の部品へのつながりを最も強く、A2 の部品へのつながりを最も弱くします
- もう片方は、その逆にします

ほかはすべて同じにし、つながりの強さは最後まで固定します。世界は、どちらの行動にも結果を返しません。後半の 25 回の選ぶ機会で、A1 を選んだ割合を二つの AI で比べます。

200 体すべてを動かして記録しますが、比べられるのは、二つの AI の両方で後半に A1 か A2 を選んだ機会が 1 回以上あり、割合が決まった AI だけです。その数を m 体とします。

1. **向きがそろうか**：割合が一方の向きにずれる AI が、その m 体のうち、偶然とは言いにくいほど多いかを確かめます。m が 10 体に満たなければ、判定できない（判定不能）とします
2. **どれくらい変わるか**：その m 体のうち、割合が変わった AI がどれくらいいて、どれくらい変わったかを、成否に関係なく必ず数えます

### 言わないこと

- 成り立っても、「AI が学んだ」「経験で選び方が変わった」とは言いません。つながりの強さは、人の手で端に置いたものです
- 成り立たなくても、「つながりの強さでは選び方は変わらない」「今の仕組みでは無理」とは言いません。前もって決めた二つの端では、決めた形の差が見えなかった、というところまでです
