## 1. 問い

```text
0017  Life History → 後の target weight substate の差（W と m の両方）→ 同じ ordered の土台の上での Activity の差（20/20）
0018  W だけを各履歴の値に、m を 2 腕で w_max／2 にそろえる → 対称標準化背景の上での sufficiency（16/20）
0019  m だけを各履歴の値に、W を 2 腕で 0 にそろえる → 対称 contrast 背景の上での sufficiency
```

> **0017・0018 と同じ経験・無入力の自発活動・試しの手順で、各 t0 の ordered の試しの元を土台に、A–B／A–C の 4 本を対称 contrast 背景（W ＝ 0）に置いた 2 つの腕を作る。腕 ordered_m には ordered の m(t0)、腕 shuffled_m には同じ時点・同じ境界の shuffled の m(t0) を載せる。2 腕で、標準の A の試しに対する直後の B・C の発火が、少なくとも 1 回は違うか**

x ＝ w(A→B)、y ＝ w(A→C)、W ＝ x − y、m ＝ (x ＋ y)／2（A→B・A→C の forward mean。4 本全体の平均ではない。4 本全体の平均は組の和の不変量から常に w_max／2）。

### 言えること・言わないこと

成り立ったときに言うのは次まで：

> 対称 contrast 背景（W ＝ 0）の上では、Life History 由来の A→B／A→C forward mean の差だけで、直後の離散的な活動を変えるのに十分だった

- **standardized-background sufficiency test であって、自然な媒介の証明ではない**。2 腕とも自然な重みの状態ではない（W を 0 へ動かしている）。どちらの腕も as_is とは呼ばない
- **0018 と合わせても「0017 の読み出しの差のうち W の分・m の分」とは言わない**。0018 と 0019 は別々の標準化背景の上の sufficiency で、W と m の相互作用が残る
- **成り立たなかったとき（S ＝ 0 が多い）も、「m は自然な状態では効かない」とは言わない**。W ＝ 0 にそろえたことと m の相互作用で読み出しが消えた可能性が残る
- **0018 の救済措置ではない**。0018 の判定（16/20、基準ちょうど）はそのままで、0019 の結果で 0018 の頑健性を言い換えない。0019 は 0018 の追試でもない（問いが違う）
- 成り立っても「記憶した」とは書かない

## 3. 試しと介入

### 3.1 手順

試しの元の作り方と runtime の境界は 0017 §3.1・§3.3 とまったく同じ。各 t0（24001〜24300）で、両条件の本体の t0 − 1 の終わりから独立に、受け手（ordered）と提供側（shuffled）の試しの元を作り、どちらも t0 に Receptor A を入れて **Pulse t0 の可塑性の更新まで** 終える（t0 ＋ 1 の重みの固定の前）。

```text
受け手の試しの元（ordered）の t0 の終わり ── m_o ＝ (x_o ＋ y_o)／2 を読む
提供側の試しの元（shuffled）の t0 の終わり ── m_s ＝ (x_s ＋ y_s)／2 を読む
受け手の試しの元を 2 腕に複製し、どちらも 4 本だけを置き直す
   ├─ ordered_m ：x ＝ y ＝ m_o
   └─ shuffled_m：x ＝ y ＝ m_s
   （どちらも w(B→A) ＝ w(C→A) ＝ w_max − m）
          ↓ 可塑性ありのまま
      t0 ＋ 2 の s_B・s_C の発火を読む
```

- 痕跡（pre_trace・post_trace）・Unit の状態・B–C の 2 本・それ以外は、2 腕とも受け手の試しの元のまま
- 2 腕の違いは、4 本の weight のうち **m の差 Δm ＝ m_o − m_s だけ**（x・y の差はどちらも Δm、逆向きの 2 本の差はどちらも −Δm）。W は 2 腕とも 0
- **標準化で動かす量**：2 腕はどちらも受け手の試しの元の複製なので、介入の直前の W はどちらも W_o である。標準化で 2 腕に共通に加わる変位は **W_o → 0 だけ**（recipient_contrast_displacement ＝ W_o）。shuffled から持ってくるのは m_s だけで、shuffled_m の腕を W_s から動かしているわけではない（W_s は提供側の自然な contrast で、介入の量ではない）
- runtime の順序から、2 腕は t0 の終わりまで同一で、t0 ＋ 1 の発火も同一。t0 ＋ 2 の B・C で違いうるのは、s_A の t0 ＋ 1 の発火が A→B・A→C を通る伝達だけ（0014 §3.3、0017 §3.3）

### 3.2 背景の contrast W ＝ 0 の由来（常設チェック A6・C1）

W は新しく自由に選んだ値ではなく、0019 の要件から一意に決まる（0018 §3.2 の m ＝ w_max／2 と同じ形の導出）。

- 要件：自然にありうる全ての m（x・y ∈ [0, w_max] から 0 ≤ m ≤ w_max）を、切り詰め・拡大縮小・適用条件なしに、**1 つの固定の W** の上へ状態空間の中のまま載せる
- x ＝ m ＋ W／2、y ＝ m − W／2 について、m ＝ 0 のとき y ≥ 0 には W ≤ 0、x ≥ 0 には W ≥ 0 が要る。したがって **W ＝ 0 だけ** が要件を満たす（m ＝ w_max でも同じ）。そのとき任意の 0 ≤ m ≤ w_max で x ＝ y ＝ m ∈ [0, w_max]
- **名前は「対称 contrast 背景（symmetric contrast background）」とし、「中立」とは呼ばない**。W ＝ 0 は B／C の方向について状態空間の上の対称点だが、活動の力学に対して中立だとは示していない（B と C の受け手としての状態は違う）

|---|---|

| W ＝ 0 | §3.2（要件から一意） |
| 0.8 | 0012〜0018 と同じ比。Birth State 間の頑健性の基準 |

**新しく選んだ数値は seed の範囲だけ**（常設チェック C1）。

## 4. 指標と判定

```text
各試し：E(t0) ＝ |B_ordered_m(t0) − B_shuffled_m(t0)| ＋ |C_ordered_m(t0) − C_shuffled_m(t0)|   ∈ {0, 1, 2}
個体ごと：S ＝ Σ_t0 E(t0)                                                                 主の判定 s：S ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 s** | すべての個体 | S ＞ 0 | 成り立った個体数 ÷ 20 ≥ 0.8 |

- **standardized-background sufficiency test**。nonzero の検定で、向きの検定ではない
- **式の形（A6）**：E・S は 0016〜0018 と同じ形。介入だけが替わる
- **適用対象（A3・A7）**：すべての個体。m_o ＝ m_s の試しは 2 腕が同一になり、専用の分岐を置かずふつうの算術で E ＝ 0 として S に入る。全試しでそうなった個体も N/A にせず S ＝ 0 の不成立（whole-pipeline。0016〜0018 と同じ扱い）
- 0.8 は「事前登録の基準を満たしたか」の判定であり、母集団で成り立つ割合が 0.8 以上という統計的な主張ではない（常設チェック D6 の案）

### 4.1 向きの構造的な必然と、nonzero の非空虚性（A1・A7）

- **向き（構造的な必然。記録だけ）**：E ≥ 0 は定義から。単調な Unit の力学では、t0 ＋ 2 の B が 2 腕で違うならその符号は x の差 Δm の符号と、C が違うならその符号は y の差 Δm の符号と整合することが構造上決まる。x と y は同じだけ動くので、**B と C の両方が違った場合は同じ向き** になる（0018 では逆向きだった）。離散の発火なので、片方だけが違うこともある。向きは問わない
- **nonzero の非空虚性（判定が構造上自明でないこと）**：向きが構造上決まっても、S ＞ 0 が構造上保証されるわけではない。それを次の合成の契約で事前に示す
- **A7**：A が無入力の区間に自発発火しない個体でも、外から A を入れるので読み出しの機会はある。受け手（B・C）が閾値に近づかない状態では、Δm ≠ 0 でも S ＝ 0 になりうる。どちらも対象から除かない
- **合成の runtime の全状態からの契約テスト**（道具の段で書く。合成専用の seed 9600〜9699 だけを使う。自然な seed・smoke の結果では確かめない）：妥当な全状態の受け手と提供側の組を作り、実物の runtime で 0019 と同じ手順を通して、
  - (i) **300 回すべての試しで m_o ≠ m_s（2 腕の 4 本が実際に違う）のに、300 回すべてで E ＝ 0（S ＝ 0）** になる組
  - (ii) **S ＞ 0** になる組

  の両方がありうることを、具体的な状態で示す
- **ゼロの差の契約**：m_o ＝ m_s（提供側を受け手と同じ状態にする）なら、2 腕は t0 ＋ 2 まで同一（E ＝ 0）
- **ほかの runtime の契約**：2 腕の t0 ＋ 1 の一致、s_A が t0 ＋ 1 に発火しない試しで E ＝ 0、受け手・提供側の試しの元の重みがそれぞれの本体の t0 の終わりと一致（境界を 1 Pulse ずらすと検出される）、標準化の腕で W ＝ 0・m ＝ 各履歴の m・組の和、|m| が 0・w_max の端でも範囲内

### 4.2 測れる大きさか（C3）

独立した既存の測定（0017・0018 の本番の記録、別の seed。最初の試し 24001）で、**2 腕の差 |m_o − m_s| そのもの** の尺度を確かめる。

- 0017：|m_o − m_s| の中央値 2.05 × 10⁻³（4.0 × 10⁻⁴〜3.4 × 10⁻³）
- 0018：|m_o − m_s| の中央値 1.25 × 10⁻³（7.0 × 10⁻⁵〜3.8 × 10⁻³）
- 0019 では x・y がそれぞれ Δm 動く（同じ向き）。0018 で x・y がそれぞれ D／2（中央値 約 1.0 × 10⁻³）動いたのと同じ桁で、0016 の equalize（|W|／2 ずつ）とも同じ桁
- 0018 で記録した |m_o − w_max／2| は、標準化で 2 腕に共通に加えた変位であって、0019 の 2 腕の差の大きさではない（ここでは使わない）
- 0019 で標準化が 2 腕に共通に加える変位は W_o → 0。0017 の記録で |W_o| の中央値は 2.55 × 10⁻³（8.1 × 10⁻⁴〜8.1 × 10⁻³）。2 腕の差には入らないが、受け手の B・C の駆動の B/C 方向の偏りを自然な状態から動かす。§1 の「相互作用で読み出しが消えた可能性」はここから来る
- 値の調整には使わない。smoke では見ない
