## 0. 実行の形式と、問いと主張の範囲

### 0.1 実行の形式：0039 型の事前登録の実験にする

**0039 型の事前登録の実験**（事前登録 → 道具 → 盲検の smoke → 本番の一度限りの実行 → 結果）にする。0038 型の前方の関門にはしない。

| 観点 | 0038 型の前方の関門 | 0039 型の事前登録の実験（この実験） |
|---|---|---|
| 推定対象 | 操作の可能性。公表する量を操作の可能性の量に限る | **規則 c の入れ替えによる、経験の区間の終わりの重みの差の、個体ごとの分布**（現象の量）。判定 J_B と推定 E_B（§4） |
| seed | 関門の専用の seed を一度だけ | 契約テストの合成の seed（34301〜34399）・盲検の smoke（34201〜34206）・判定の一度限りの seed（34001〜34200）を分ける（§9.2） |
| 判定の量の表示 | 関門の量だけ | 契約テストと smoke では表示しない（権限の文書 §3）。本番で一度だけ計算する（§9.3） |

- **この形にする理由**：候補 B の推定対象は、重みの差の向きそのもので、現象の量である。0038 型の関門はこの量を出さない形なので、推定対象を報告できない
- **別の関門を置かない理由**：本体 B^{A1}・B^{A2} は関門の本体と同じ組み立てで、関門（0038）で窓の選択が出ることは確かめてある。重みは、どの個体でも P_E に定まるので（§4.1）、分母が足りずに判定できない結末はない。関門を足すと、その結果を見て値を選び直す道が開く

### 0.2 問い

> **問い Q-B**：同じ個体（seed）の二つの本体 B^{A1}・B^{A2}（規則 c ＝ A1 と c ＝ A2。ほかはすべて同じ。可塑性あり、世界は規則 c が指す行動にだけ結果を返す）を、関門と同じ組で、経験の区間 E（窓 1〜25）の終わりの境界 P_E ＝ 1,065 まで走らせる。P_E の C → 源 の重みから、
>
> δ_i ＝ [W^{A1}(C → 源 1) − W^{A2}(C → 源 1)] − [W^{A1}(C → 源 2) − W^{A2}(C → 源 2)]
>
> を求める（候補の文書 §3）。
> - **判定 J_B**：δ が一方の向きにずれる個体は、生まれた個体の母集団で、事前に決めた基準を超えて多いか
> - **推定 E_B**：δ が 0 でない個体はどれだけあり、δ はどれだけか

- 向きは事前に決めない。両側で問う（§4.5。命題 G-11）
- **0039 との関係**：本体 B^{A1}・B^{A2} と境界 P_E は 0039 と同じ組み立て・同じ定義である。0039 は、試しの区間の選択（J_7）と、P_E の重みの移植（J_W）を問い、重みそのものの差は大きさ（|W^{A1} − W^{A2}|）だけを記述した（0039 §15.5 の R4）。この実験は、重みの差の**向き**を、新しい個体群で問う。0039 の判定を確かめ直したり、救ったりするものではなく、0039 の J_7 の不成立の理由の説明にも使わない
- **0040 との関係**：0040 は、前もって固定した重みの端への介入と選択の割合を、結果を返さない世界で問うた。この実験は、介入をせず、結果を返す世界で、経験から生じる重みの差を問う。二つの結果を、規則 → 重み → 選択の媒介としてつながない（§0.4）

### 0.3 主張の形（J_B が成立したとき）

「AS2b（関門の組：C0 の力学と可塑性、関門の予定・窓・出口・役、結果を返す世界）で、同じ個体の二つの本体の規則 c（結果を返す行動 ID）を入れ替えると、経験の区間（窓 1〜25）の終わりの C → 源 の重みの差 δ が［＋／−］の向きにずれる個体が、生まれた個体の母集団で、事前に決めた基準を超えて多かった」

- **＋の向き**（δ ＞ 0）：C → 源 の重みが、その源の行動に結果を返す規則の本体の側で、もう一方の規則の本体より高い（二つの源について足し合わせた量で）。組の和の保存（F1）により、源 → C の重みは、そのぶん低い（§3.2・SE-B5）
- **−の向き**（δ ＜ 0）：その逆。C → 源 の重みが、その源の行動に結果を返す規則の本体の側で低い
- 符号は、行動 ID の札の付け方（どの源を A1 と呼ぶか）に依らない（§3.2）
- **主張の水準**
  - 規則 c の入れ替えの、重みへの**総効果**である。結果の刺激が手がかりの Unit を発火させることで生じる時刻の組の寄与（可塑性の経路 P2・P4、命題 G-11）だけでなく、結果の刺激の数・時刻の違い、それに続く経験の軌道（窓の結末・発火）の分岐が生む重みの違いを、すべて含む
  - この本体・この経験の区間の長さ・生まれた個体の母集団（構造的な 0 を含む：§4.1）についての、条件付きの結果である
  - 推定 E_B（δ が 0 でない個体の割合と δ の大きさ）は、判定の成否に依らず必ず添える

### 0.4 主張しないこと

- 選択の変化。この実験は選択の割合を判定しない（経験の区間の選択の数は記述だけ）
- 学習・報酬・価値・罰・意味・目的を学んだこと。＋・−の向きを、接近・回避・好み・結果を求めた・避けたと呼ぶこと（基準 §2・§8、命題 G-11）
- 行動に固有の結果の連合の獲得・信用の割り当て（結果の刺激の数・時刻の効果と分けていない。ヨークの対照を置いていない）
- どの接続の変化か。C → 源 と 源 → C は F1 で一緒に変わり、分けられない。どの可塑性の経路（P1〜P6）が向きを決めたか
- 規則 → 重み → 選択の媒介。0039 の J_W・D^W、0040 の J_A・E_A と、この実験の結果をつないで、規則の違いが重みを通して選択を変えたと言うこと
- 0039 の J_7 の不成立の理由の説明・救済。候補の文書 §2 の仮説 H1 を確かめたこと
- **不成立から**、「規則 c は重みを変えない」「重みの変化は規則に依らない」と言うこと。個体ごとに向きの違う効果がないと言うこと。不成立を、構成の見直し（候補 D）を始める条件にすること
- E_B の値から、効果が大きい・小さいと判定すること
- この経験の区間の長さ（25 窓）のほかの時点・ほかの長さでの向き

## 2. 本体と区間

### 2.1 区間

- E ＝ 窓 1〜25（Pulse 1〜1,065）：経験の区間
- 境界 P_E ＝ 1,065：Pulse 1,065 の処理の後（Pulse のあいだ）。重みはここで読む
- 本体は P_E で止める。窓 26〜50 は走らせない
- 窓 k の境界：c_{k+1} − 1（k ＝ 1〜25。最後が P_E）。記述の重みの記録（R4）にだけ使う
- 1 Pulse ＝ 1 秒（AS1・AS2b と同じ）

### 2.2 本体の一覧

どの本体も `build(seed, schedule=関門の予定, delay=2, rule_c=c, respond=True)` で組み立て、出生（Pulse 0）から P_E まで走らせる。どの本体にも介入（移植・FREEZE・複製・世界の切り替え）をしない。

| 本体 | 規則 c | 役目 | 観測 |
|---|---|---|---|
| **B^{A1}** | A1 | **主**（J_B・E_B） | 観測する |
| **B^{A2}** | A2 | **主**（J_B・E_B） | 観測する |
| B′^{A1} | A1 | 記録の非干渉と決定論の確かめ（O8） | 観測しない |

- 1 個体で走らせる Pulse の数：3 本体 × 1,065 ＝ 3,195
- **観測の区分**（0040 v0.3 の形）
  - 観測する本体（B^{A1}・B^{A2}）：Pulse 0 の Σ を書き出し、1 Pulse ずつ進めて、Pulse ごとの 6 本の重みを実測して保存する。共通の部分の最初の決まった窓 k*（§3.3）の意図の Pulse の処理の後の Σ も書き出す（O4。k* があるときだけ）
  - B′^{A1}：B^{A1} と同じ組み立てで、AS2b の道具の既定の来歴のログのまま、P_E まで一度に進める。走らせている間は状態を読まない。残すのは、P_E まで進んだ後に書き出す P_E の Σ・層 A・層 B・発火・感覚の出来事の記録だけ
  - B′^{A1} の全 Pulse の重みを、計算から作り直して実測の記録として保存しない
  - 3 本体とも、P_E の Σ を値の全体とその SHA-256 で保存する（本体が P_E まで進んだ後に書き出すので、B′^{A1} の非干渉と両立する）

### 2.3 世界

- すべての本体で、関門の宣言の世界：手がかりの予定（c_k）が手がかりの Receptor に来る。規則 c が指す行動 ID の意図にだけ、手がかりの Receptor に結果を 1 つ返す（意図の Pulse ＋ L − 1 に成立）
- 違うのは規則 c だけ（B^{A1} と B′^{A1} は A1、B^{A2} は A2）
- 世界の規則の切り替え（`switch_world`）・再生（PC-3）・LC3 は使わない

|---|---|---|

### 3.2 量の一覧

どれも、保存した倍精度の値を有理数（`fractions.Fraction`）として正確に計算し、符号はその正確な値の符号とする。

| 名前 | 定義 | 役目 |
|---|---|---|
| **δ** | (a_1^{A1} − a_1^{A2}) − (a_2^{A1} − a_2^{A2}) ＝ q_1 ＋ q_2 | **J_B・E_B** |
| q_1 | a_1^{A1} − a_1^{A2}：源 1 について、規則が源 1 の行動を指す本体と、指さない本体の差 | 必ず報告する記述（9 つの組の表） |
| q_2 | a_2^{A2} − a_2^{A1}：源 2 について、同じ形の差 | 同上 |
| δ^← | (b_1^{A1} − b_1^{A2}) − (b_2^{A1} − b_2^{A2}) | 必ず報告する記述。F1 で −δ に浮動小数の誤差まで一致する（SE-B5） |
| ε | (e_{12}^{A1} − e_{12}^{A2}) − (e_{21}^{A1} − e_{21}^{A2}) | 必ず報告する記述（源どうし） |

- **＋の意味**
  - δ ＞ 0：C → 源 の重みが、その源の行動を規則が指す本体の側で高い（二つの源について足し合わせた量で）
  - ε ＞ 0：源どうしの接続の重みが、送り手の源の行動を規則が指す本体の側で高い（二つの向きについて足し合わせた量で）
- **札の入れ替えに対する性質**（`analysis.py` の `label_swap_check`）：源 1 と源 2（A1 と A2）の札を入れ替えると、規則 c ＝ A1 の本体は入れ替えた札では規則 c ＝ A2 の本体になる。δ・δ^←・ε は正確に同じ値のまま、q_1 と q_2 は入れ替わる。そのため、δ・δ^←・ε の符号は札の付け方に依らない。**この性質は、δ の符号が＋・−で対称であることの根拠ではない**（§4.6）
- **分解をしない**：δ ＝ q_1 ＋ q_2 は算術である。q_1・q_2 を、源ごとの本当の効果・内訳と呼ばない
- **差の差にした理由**：出生時の源の違い（θ・c）による、規則に依らない C → 源 の重みの違いは、二つの本体に共通なので差し引かれる。残るのは、規則の入れ替えに伴う違いである（総効果。§0.3）
- **C → 源 を主にした理由**：候補の文書 §3 の量。F1 により、源 → C は C → 源 と補い合い、独立な情報を足さない。δ^← は、F1 の確かめを兼ねて必ず報告する

### 3.3 経験の区間の選択と、共通の部分

- 本体ごとに、窓 1〜25 の結末（A1・A2・引き分け・発火なし）を、I2 の決定の部品の記録（層 A）から数える。層 A は世界の受けた意図の記録（層 B）と一対一に突合する（CT-E10。§8 の O3）。これらは記述だけで、判定に使わない

### 4.5 この形にした理由（結果を見る前の理由）

**主の量を δ にした理由**
- 候補の文書 §3 の量で、「規則 c が指す源への手がかりの重みが、指さない源への重みに比べてどちらに動くか」をそのまま書いたもの
- 札の入れ替えで値が変わらないので、物理の行動 ID の札の付け方に依らない（§3.2）
- 差の差なので、出生時の源の違いによる、規則に依らない重みの違いが差し引かれる

**個体の事象を符号にした理由**
- 二つの本体は、k* の結果の刺激から分かれ、その後の軌道は決定論のもとで違いうる。「重みが違う」という存在の形は、軌道の分岐だけで成り立ちやすく、向きの問いの答えにならない
- 符号は閾値・比・正規化を持ち込まない（A6）。|δ| の分布は E_B として必ず並べる

**向きを事前に決めない理由**（命題 G-11、AS2b の道具 README §3 の P1〜P6）
- 規則が勝った源 S_w の行動を指すとき、結果の刺激で手がかりの Unit C が発火し、逆順の時刻の組（S_w の発火の後に C が発火する）で、C → S_w を弱め、S_w → C を強める項が生じうる（P2、G-11）
- 一方で、手がかりの後に S_w が発火する順の組は C → S_w を強める（P1）。結果に誘発された C の発火が源を駆動して生む追加の発火、痕跡の残り、順応・位相の違い（P3〜P6）が、それぞれの大きさを変える。軌道の分岐も重みの違いに入る
- したがって、正味の向きは前もって決まらない（G-11 の原文の範囲。正味が負の向きだとは断定しない）。両側で問う

**個体の多数を問う理由**
- 独立の標本と見なせるのは、出生時の状態のモデルのもとでの個体である
- 0034〜0040 と同じく、個体の中の比べ（同じ個体の二つの本体の差）を個体の事象にし、その向きの個体の多数を問う
- 向きごとに 0.025 にしたのは、向きを事前に決めない両側の判定で、全体の誤りの水準を 0.05 に保つためである

**母集団を生まれた全個体にした理由**：§4.1

**判定を一つにした理由**
- 候補 B の問いは δ の向き一つである。δ^←・ε・q_1・q_2・記述の母集団は、F1 の確かめ・源どうしの接続・同じ個体での対応・条件づけた見方を記述するもので、それぞれを判定にすると族が増え、水準の扱いが要る。そのため記述に回した

### 4.6 帰無仮説と、その条件

- **推論の対象**：生まれた個体の母集団（出生時の状態を独立・同一分布の標本と見なすモデル）
- **H₀^B**（明示の統計上の帰無）：P(δ_i ＞ 0) ＝ P(δ_i ＜ 0)
- 帰無のもとでは、各個体が「＋」である確率は (1 − P(δ_i ＝ 0))／2 ≤ 1/2 である。0 の個体を分母に残すので、「＋」の個体の数は Bin(200, 1/2) に確率的に支配される。「−」も同じ。したがって P(J_B がどちらかの向きで成立 | H₀^B) ≤ 0.025 ＋ 0.025 ＝ 0.05
- **この向きの対称性は、仮定する帰無であって、導いた性質ではない**
  - 役の乱数の割り当てからは導けない。札の入れ替えは δ を変えない（§3.2）ので、δ → −δ の根拠にならない
  - 系の構造からも導けない。結果は規則が指す側にだけ返り、AS2b は非対称な構成である（G-11）。その非対称が重みの向きのそろいとして現れるかが、この実験の問いである
- 選別をしないので、帰無も主張も、生まれた個体の母集団についてのものである（§4.1）
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない
- 同じ個体の二つの本体は独立ではない。対の差を一つの個体の事象にして、この依存を判定に入れない

### 4.7 結果の扱い

| 結果 | 条件 | 言えること | 言えないこと |
|---|---|---|---|
| **無効** | 操作の確認（§8）の一つでも不成立 | 何も言わない。判定と推定の量を計算・表示しない | — |
| **不成立** | どちらの向きも 115 に届かない | **事前に定めた、向きのそろった個体の多数の主張は確立しなかった**。E_B と §6 を示す | 「規則 c は重みを変えない」「重みの変化は規則に依らない」「効果はまれ・小さい」。個体ごとに向きの違う効果がないこと |

- この実験は、**割合が低いこと・効果がないことを主張する判定を置かない**。不成立のときの陰性の読みは記述だけで、「識別に役立つ陰性」とは呼ばない

### 9.1 保存の形（独立に再計算できること）

  - 値は JSON の数（Python の `repr` で往復できる形）で保存し、値どうしの完全な一致で照合する（SHA-256 は補助）

- 本番の後、実行した側は、`analyze.py`・`measure.py`・`anima_ll`・AS2b の道具を読み込まない標準のライブラリだけの独立の検算で、次を行う（0040 の道具 v0.3 と同じ形）

- 走らせた後に、この README・protocol・道具を変えない

### 何を決めたか

前に合意した順番の二つ目の候補（候補 B）について、本番の実験の「調べ方」を、結果を見る前に決めて固定する文書です。

AI の中には、手がかりを受け取る部品と、二つの行動（A1・A2）のどちらかを起こす部品があり、そのあいだの「つながりの強さ」は経験で変わります。世界の決まりで、片方の行動にだけ「結果」（刺激）が返ります。同じ AI を二つ用意し、

- 片方は「A1 を選ぶと結果が返る世界」
- もう片方は「A2 を選ぶと結果が返る世界」

で、前半（25 回の選ぶ機会）だけ育てます。違うのは、この世界の決まりだけです。

### 何を確かめるか

前半の終わりで、「手がかりの部品から、結果が返る側の行動の部品へのつながり」が、もう一方の世界で育った AI と比べて強くなっているか、弱くなっているかを調べます。200 体の AI のうち、向きのそろった AI が、偶然とは言いにくいほど多いかを確かめます（200 体のうち 115 体以上が同じ向きなら「成り立った」とします）。

- 強くなる向きか、弱くなる向きかは、前もって決めていません。理屈の上では、どちらの向きの力も働きうるからです
- 前半で一度も行動が選ばれなかった AI は、二つの世界の違いが生まれないので、差は 0 になります。こうした AI も除かずに数えます。除くと、「どの AI を数えるか」を後から選べる余地が生まれるからです。そのぶん「成り立った」と言いにくくなりますが、それを受け入れます

### 言わないこと

- 成り立っても、「ご褒美を覚えた」「結果を求めた・避けた」「好きになった」とは言いません
- 「つながりの強さが変わったので、選び方が変わった」とも言いません。この実験は、つながりの強さだけを調べます。前の二つの実験（0039・0040）の結果とつないで、そこまで言うことはしません
- 成り立たなくても、「世界の決まりはつながりの強さに効かない」とは言いません

### 15.7 言えること・言えないこと

**言えること**（§0.3・§12）
- この本体・この経験の区間（窓 1〜25、P_E ＝ 1,065）・生まれた個体の母集団で、規則 c の入れ替えによる E の終わりの C → 源 の重みの差 δ が−の向きにずれる個体が、事前に決めた基準（k₂(200) ＝ 115）を超えて多かった。−の向きは、C → 源 の重みが、その源の行動に結果を返す規則の本体の側で低いことである
- これは、規則 c の入れ替えの重みへの総効果についての、条件付きの結果である。E_B（p_change・p_＋・p_− とその区間、|δ| の分布）と §15.5 の記述の対照を、必ず並べて読む

**言えないこと**（§0.4・§13）
- AS2b が学んだ、報酬・価値・罰を学んだ、結果を求めた・避けた。−の向きを、回避・嫌悪・罰と呼ぶこと
- 行動に固有の結果の連合の獲得・信用の割り当て。結果の刺激の数・時刻の効果と、軌道の分岐の効果を分けていない（ヨークの対照を置いていない）
- どの接続（C → 源か、源 → C か）・どの可塑性の経路（P1〜P6）が向きを決めたか。q_1・q_2 を源ごとの本当の効果と呼ぶこと。§15.5 の 9 つの組の表は記述で、分解ではない
- 選択の変化。この実験は選択の割合を判定していない（R2 は記述だけ）
- 規則 → 重み → 選択の媒介。0040 の J_A（＋の向きで成立）・0039 の J_7・J_W・D^W と、この J_B（−の向きで成立）をつないで、規則の違いが重みを通して選択を変えた・変えなかったと言うこと。0039 の J_7 の不成立の理由の説明・救済に使うこと。候補の文書の仮説 H1 が確かめられた・否定されたと言うこと
- 効果が大きい・小さい（E_B から効果の大小を判定しない）
- E の終わりのほかの時点・ほかの長さで、同じ向きになること。R4 の窓の境界ごとの記述を、判定や時点の選び直しに使うこと
