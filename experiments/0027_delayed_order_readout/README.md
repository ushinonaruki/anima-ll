## 0. 問いと主張の範囲

### 0.1 問い

> **0025 と同じ設計図（C0）・同じ経験・同じ参照（試行の中の並べ替え W_1〜W_19）・同じ試し・同じ読み出し・同じ判定で、主の試しの時刻だけを、経験の終わりから D ＝ 5τ_a ＝ 1500 Pulse 遅らせる（t0 ＝ 13501〜13800）。待つあいだ、どの本体にも外からの入力はなく、自発の活動と可塑性は続く。順序のある経験（O）の個体は、この遅い時点で、同じ試し（A の入力）に対して、W の分布の中で典型的でない応答を示すか**

- 設計の整理の **Q6**（O の外れは、経験の最後の短い時間尺度の状態――直近の刺激による順応・位相――に依るのか。契約 X6）に、時間の側から近づく。ただし、遅い時点の状態にも経験の終わりの状態は重み・待つあいだの発火の履歴などを通して残るので、Q6 そのものには答えない（§3.3）
- 待つあいだも系は動き続ける。**経験の終わりの状態を保存して放置する実験ではなく、経験の後も生きて動く系を観測する実験**である。参照の W も同じだけ待つ
- 同じ個体で、早い時点（t0 ＝ 12001〜12300。0025 の主と同じ区間）の試しも**補助として**記録する。判定は置かない（§5.3・§6）

### 0.2 主張の形（成立したとき）

「C0 という設計で、この世界・この手順のもとで、順序のある経験の後、外からの入力なしに 1500 Pulse（順応の時定数の 5 倍）経った時点の自然な状態は、試しの入力 A が B・C の次の発火の時刻を動かす効果（R2）を、どの試行でも A・B・C が 1 回ずつ来る並べ方（W）の参照分布では典型的でない形で示した（向きを問わない）。その頻度は、O が W と交換可能であるという帰無仮説のもとで期待される頻度より多かった（個体間の独立性の前提のもとで、水準 0.05）。つまり、**この Γ では、O の非典型性は、経験から 5τ_a 経った時点の読み出しにも現れた**」

### 0.3 主張しないこと

- 成立したとき
  - **記憶ができた・形成された**（研究④・契約の区別。現象 ① の L2 の一つの時点での観測にとどまる）
  - **何が持続を担ったか**（重み・順応・痕跡・位相・待つあいだの発火の履歴。§3.3 のとおり、遅い時点の状態の違いはこれらを分けずに含む）。「順応ではなかった」「重みが運んだ」とは言わない
  - 経験の終わりの状態が**そのまま保存された**（待つあいだも状態は変わる）
  - 0025 の外れ、またはこの実験の早い時点の外れと**同じものが続いた**（同じものかを確かめる検定は置かない）。順序を学習した
- 不成立のとき：**経験の影響が消えた**、早い時点の効果は一時的だった、C0 に持続がない（判定の検出力、待つあいだに凍結が増えうること（§6.1）、ほかの R・遅れ・時刻は未検討。研究④の命題 2・3）
- どちらでも：**時間による減衰・持続の度合い**を結論しない（早い時点の補助の h と遅い時点の h を比べる検定、0025 の h との比較は置かない）。経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した

## 3. 遅らせる長さ D ＝ 5τ_a の根拠

### 3.1 C0 の時間の尺度（設計図の値）

| 量 | 1 Pulse の更新 | 時定数 |
|---|---|---|
| activity a_i | 発火しなければ a ← λ a ＋（届いた駆動）＋ c_i（λ ＝ 0.85）、発火すれば 0 | −1／ln λ ≈ 6.15 Pulse |
| 痕跡 X_i | X ← κ X ＋ 1［発火］（κ ＝ λ。設計図の trace_tau ＝ activity_time_constant） | ≈ 6.15 Pulse |
| 順応 h_i | h ← ρ h ＋ α·1［発火］（ρ ＝ e^{−1/τ_a}、τ_a ＝ 300） | 300 Pulse |
| 重み w(i→j) | i か j が発火した Pulse にだけ、可塑性の規則で変わる。減衰はない | なし |

### 3.2 命題 1（経験の終わりの値の、そのままの持ち越し）【命題】（C0 の式による）

Unit i と D ≥ 1 について、f_i(t) ＝ 1［i が t に発火］と書くと

```text
h_i(12000 ＋ D) ＝ ρ^D · h_i(12000) ＋ α · Σ_{s=1..D} ρ^{D−s} f_i(12000 ＋ s)
X_i(12000 ＋ D) ＝ κ^D · X_i(12000) ＋ Σ_{s=1..D} κ^{D−s} f_i(12000 ＋ s)
```

D ＝ 5τ_a ＝ 1500 では、第 1 項（経験の終わりの値のそのままの持ち越し）の係数は ρ^D ＝ e^{−5} ≈ 0.0067、κ^D ＝ e^{−1500/6.15} ≈ e^{−244} である。activity は、i が待つあいだに一度でも発火すれば 0 に戻り、経験の終わりの値は残らない。発火しなければ、経験の終わりの値は λ^D 倍で残る。重みは減衰せず、経験の終わりの値に、待つあいだの発火による更新が加わる。

（証明：順応と痕跡の更新は、値について線形で、発火の項が足し算で入る（実装：adaptation に exp(−Δt／τ_a) を掛け、発火の Pulse に α を足す。痕跡も同じ形）。D 回の更新を展開する。activity は更新の式と、発火で 0 に戻ることから。重みは可塑性の規則が端の Unit の発火の Pulse にだけ働くことから。）

### 3.3 帰結と、言えないこと

- **言えること**：遅い時点の始まり（13500）では、経験の終わりの順応・痕跡・activity の値の**そのままの持ち越し**は、順応で 1% 未満、痕跡・activity では事実上 0 になっている
- **言えないこと**：遅い時点の状態が、経験の終わりの状態と無関係になった、とは言えない。13500 の状態は、(a) 重み（経験の終わりの値が、待つあいだの更新を受けながら残る）、(b) 待つあいだの発火の履歴（経験の終わりの全状態――順応を含む――から非線形に決まり、順応・痕跡・重みの更新を通して状態に入る）、(c) 第 1 項の小さな残り、を通して経験の終わりの状態に依存する。L は発火の時刻で決まる区分的に一定で不連続な量なので（設計の整理 §3.4）、(c) のような小さな違いも L を変えうる
- したがって、遅い時点で O が外にあっても、**どの成分・どの経路が違いを運んだかは言えない**（Q6 の「直近の短い時間尺度の状態で説明できるか」への答えにもならない）。言えるのは、経験から 5τ_a 経った時点でも、O の読み出しが W の参照分布で典型的でなかった、という**時間についての記述**までである

### 3.4 倍数 5 を選んだ理由

- 力学に効く Unit の状態のうち最も遅く減る順応について、経験の終わりの値のそのままの持ち越しが 1% 未満（e^{−5} ≈ 0.0067 ＜ 0.01）になる最小の整数の倍数が 5（e^{−4} ≈ 0.018 は 1% を超える）。1% は、時定数の何倍で「減りきった」とみなすかの慣用の目安で、この実験のデータから選んだものではない
- これより長い遅れも考えられるが、一つの遅れに一つの主の判定を置く（複数の遅れを並べると検定が増え、閾値が上がる）。長い遅れ・複数の遅れは、この結果を見てから別の事前登録で決める
- 計算の量：本体を 1500 Pulse 長く進め、試しの複製は早い・遅いの 2 区間分になる（§9）

## 5. 主の評価

### 5.1 個体ごと

```text
O が外にある（遅い時点）  ⇔  L_late(O) ＞ max_i L_late(W_i)   または   L_late(O) ＜ min_i L_late(W_i)    （どちらも厳密な不等号）
```

向きを問わない。等号は「外にない」。20 個の L_late がすべて等しい個体（凍結）も「外にない」に数え、除外しない。

### 5.2 個体をまたぐ判定

- h_late ＝ 遅い時点で O が外にある個体の数（20 個体のうち）
- **判定：h_late ≥ 5 なら成立（holds）、h_late ≤ 4 なら不成立（fails）**
- 根拠（0025 §5.2 と同じ）：帰無仮説「どの個体でも、L_late(O) は L_late(W_1)〜L_late(W_19) と交換可能」のもとで、各個体で O が外にある確率は 2／20 ＝ 0.1 以下。個体間の独立性を統計モデル上の前提として置くと（異なる seed から数学的に従うものではない）、h_late は Bin(20, 0.1) に確率的に支配され、**P(h_late ≥ 5) ≤ P(Bin(20, 0.1) ≥ 5) ≈ 0.04317**。上側確率が 0.05 以下になる最小の閾値が 5（P(Bin(20, 0.1) ≥ 4) ≈ 0.133）
- 成立は、上の前提のもとで帰無仮説を水準 0.05 で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- **判定の範囲**：C0 で、遅い時点の区間（13501〜13800）の、試行の中の並べ替えの参照に相対的な判定（protocol の judgment.scope）。持続の機構・二つの区間のあいだの減衰・記憶の成立は判定しない（judgment.not_judged）

### 5.3 新しく選んだ値と、方法上の選択

**数値**

| 値 | 理由 |
|---|---|
| D の倍数 5（D ＝ 5τ_a ＝ 1500 Pulse） | §3.4：順応の経験の終わりの値のそのままの持ち越しが 1% 未満になる最小の整数の倍数 |

**方法上の選択**（この実験で新しく確定する）

| 選択 | 理由と、何を限るか |
|---|---|
| **主の判定は遅い時点の一つだけ** | E4 の問いは遅い時点にある。早い時点を二つ目の主の判定にすると、Bonferroni で各判定の閾値が 6 に上がり、遅い時点の検出力が下がる。また、二つの判定を並べても、時間による減衰の検定にはならない（§0.3） |
| **早い時点の試しを同じ個体で補助として残す** | 命題 0 により、遅い時点の読み出しを変えない。0025 との別の seed どうしの比較の代わりに、同じ個体の早い・遅い時点を並べて記録できる。ただし、比べる検定は置かず、h の大小から結論しない |
| **参照は W（K ＝ 19）、M は置かない** | 0025 と同じ参照で、遅らせたことだけを変えた比較にする |
| **待つあいだも可塑性あり、入力なし** | 生きて動く系の観測（§0.1）。待つあいだに可塑性を止める・状態を凍結する設計は、別の問い（ℐ-2・状態の保存）になる |

ほかの判定・手順の値は 0025 から継承する。

- **早い時点で外にあった個体だけを選んで、遅い時点の結果を読まない**（設計の整理 命題 6 と同じ理由）。早い・遅いの組の数え上げは、全個体の記録として示すだけにする
- 早い・遅いの組から、「持続した個体」「消えた個体」を名づけない（どちらの区間の外れも、帰無仮説のもとで各個体 0.1 以下の確率で起こる）

### 6.1 沈黙の扱い（0025 §6.1 と同じ。測定の前に固定する）

1. **個体を除かない**。出生時の状態による適格の条件は置かない
2. 窓の中で発火しない Unit は、両方の側で打ち切りになり ℓ ＝ 0（ふつうの算術）。その本体の L はもう一方の Unit だけで決まる
3. 20 個の L がすべて等しい個体（凍結）は「外にない」に数える（§5.1、A7）
4. silence_counts を区間ごと・個体ごとに記録し、打ち切りの数とともに報告する
5. 沈黙の多さを、主の判定を救う・変える・個体を除く理由に使わない。沈黙を操作の確認に入れない
6. 沈黙がなぜ起きたかは、この実験では調べない

**遅い時点に特有の限界（事前に書く）**：待つあいだに経験の終わりの順応が戻り、順応は自発の活動の水準に落ち着く。余裕 m_i が 0 以下の Unit は、ほかの Unit からの駆動が足りなければ発火しない（設計の整理 命題 11 の条件のもとで）。その場合、遅い時点では沈黙・凍結が早い時点より**増える**こともありうる（減ることもありうる）。凍結が増えれば検出力が下がる。これは不成立の解釈を弱める理由として報告するが、結果を見て規則・区間・遅れを変えない
