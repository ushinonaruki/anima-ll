## 0. 問いと主張の範囲

### 0.1 問い

S3 の主の問い（基準 §2）は、「固定した対応のもとで、試しの区間の選択の割合が、経験に依って変わったか」である。基準は主張を二つの層に分けた。

- **層 1**：経験による可塑的な変化を通して、選択の分布が変わった（R-1 の比べが要る）
- **層 2**：その変化が、結果の付与の規則（どの固定した行動 ID が結果を生むか）に依った（R-1 に加えて R-7 が要る）

この実験は、層 2 を二段の判定で問う。

> **問い Q3-T（総効果）**：同じ個体の二つの本体（規則 c ＝ A1 と c ＝ A2。ほかはすべて同じ）を、関門と同じ組で走らせる。試しの区間 U（窓 26〜50）の A1 の割合を、二つの本体で比べる。**規則 c を入れ替えると U の A1 の割合が一方の向きにずれる個体は、事前に決めた基準を超えて多いか。**

> **問い Q3-W（重みが運ぶか）**：経験の区間 E（窓 1〜25）の終わりで、c ＝ A1 の本体を複製し、可塑的な 6 本の重みだけを、c ＝ A2 の本体が E の終わりに持つ重みに替える。替えた系と替えない系を、同じ状態・同じ世界の規則（c ＝ A1）・U で 6 本を FREEZE した条件で走らせる。**E の重みを替えると U の A1 の割合が一方の向きにずれる個体は、事前に決めた基準を超えて多いか。**

- どちらも、報告の量は物理の行動 ID（A1 の割合）にそろえる（基準 §2.1）。結果を返す側を X と呼び直して比べ直さない
- 向きは事前に決めない（命題 G-10・G-11）。両側で問う
- Q3-T は R-7 の入れ替えによる**総効果**、Q3-W は R-1 の PC-4 の型の比べ（重みの移植）を、R-7 の二つの本体の重みの間で行うものである

### 0.2 主張の形（成立したとき）

二段がともに同じ向きで成立したとき（§4.6）：

「AS2b（関門の組：C0 の力学と可塑性のまま、手がかりの間隔 41、o ＝ 2、W ＝ 19、L ＝ 2、同時は引き分け）で、経験の区間に二つの本体の経験が分かれた個体のうち、
- 結果を返す行動 ID の規則 c を入れ替えると、試しの区間の A1 の割合が［＋／−］の向きにずれる個体が、事前に決めた基準を超えて多かった（J_7）
- さらに、経験の区間の終わりの可塑的な 6 本の重みだけを、もう一方の規則のもとで形づくられた重みに替えると（同じ状態・同じ世界の規則・試しの区間で重みを固定）、同じ向きにずれる個体が、事前に決めた基準を超えて多かった（J_W）」

- ＋の向き：規則 c が指す行動の割合が、同じ行動を規則 c が指さないときより高い。−の向きはその逆
- 主張の水準
  - J_7：規則 c の入れ替えの**総効果**の向きが、個体の多数で一方にそろうこと。総効果には、結果の刺激の数・時刻の違い、それに続く経験の軌道の分岐、可塑性を通さない即時の帰還が、すべて媒介として入る（基準 §2.1）
  - J_W：その違いを運ぶものの一つに、経験で形づくられた重みがあること。**その状態・その世界の規則・試しの区間で重みを固定した条件付き**の効果で、総効果のうち重みが運んだ割合ではない（U5）
- 個体をまたぐ部分は、出生時の状態を独立・同一分布の標本と見なした統計の判断である

### 0.3 主張しないこと

- 報酬・価値・罰・回避・意味・目的を学んだこと（基準 §2・§8、命題 G-11）。＋の向きを「結果を求めた」、−の向きを「結果を避けた」と呼ぶこと
- 行動に固有の結果の連合の獲得、信用の割り当て（基準 §2.1。結果の刺激の総量・時刻の効果と分けていない。ヨークの対照を置いていない）
- 意思決定・選好・自己決定（契約 §9。I2 は窓の中の先着の競合で、窓は世界の予定に由来する装置である）
- 総効果のうち、可塑性が運んだ割合・即時の帰還が運んだ割合（U5。分け方は一意でない）
- どの接続・どの経路の学習か（全 6 本の移植で、経路を特定しない。基準 §2・R5 §5.3）
- 不成立のときに、「規則 c は選択に効かない」「重みは効かない」と言うこと（§4.6）

## 2. 系と区間

### 2.1 区間

- E ＝ 窓 1〜25（Pulse 1〜1,065）：経験の区間
- U ＝ 窓 26〜50（Pulse 1,066〜2,072）：試しの区間
- 境界 P_E ＝ 1,065：Pulse 1,065 の処理の後（Pulse のあいだ）
- 1 Pulse ＝ 1 秒（AS1・AS2b と同じ）

### 2.2 系の一覧

記号：c・d ∈ {A1, A2}。W^c は、本体 B^c の P_E の可塑的な 6 本の重み。W_0 は出生時の値（6 本とも 0.005）。

### 2.3 世界の規則

- すべての系で、関門の宣言の世界（手がかりの予定、L ＝ 2、規則 c が指す行動 ID の意図にだけ、手がかりの Receptor に結果を 1 つ返す）。世界は意図に応じる（閉ループ）
- G^c[·] は背景の本体 B^c の規則 c のまま。移植で世界の規則・予約・手がかりの予定は変えない
- この実験は、世界の規則の切り替え（`switch_world`）・再生（PC-3）・LC3 を使わない

- **沈黙**：命題 S-1（§7.2）の条件を満たす源（構造的に沈黙する源）を持つ個体には、札を付けて件数を報告する。そのような個体でも、適格で定まるなら分母に残す（常設チェック A7 の (a)）。その個体では、もう一方の行動しか勝てないので、s はどの系でも 1 か 0 で、D_i ＝ 0 になる（成立に不利な側）

### 4.2 個体の事象

- 適格で定まる個体 i について、**D_i ＝ s(B^{A1}) − s(B^{A2})**。事象「＋」は D_i ＞ 0、「−」は D_i ＜ 0、「0」は D_i ＝ 0
- J_W の分母の個体について、**D^W_i ＝ s(G^{A1}[W^{A1}]) − s(G^{A1}[W^{A2}])**。符号の事象は同じ形
- 個体の中の比べは決定論で、一つの個体から一つの符号が得られる（命題 G-6 の形。§7.3）。個体の中の窓を独立の標本として数えない

### 4.3 判定と、固定の順序

- k₂(m)：P(Bin(m, 1/2) ≥ k) ≤ 0.025 となる最小の k（§5.1）
- **J_7**：m ＝ J_7 の分母の個体の数。m ＜ 10 なら判定不能。m ≥ 10 で、「＋」の個体の数 ≥ k₂(m) なら **＋の向きで成立**、「−」の個体の数 ≥ k₂(m) なら **−の向きで成立**（k₂(m) ＞ m/2 なので、両方が同時には成り立たない）。どちらでもなければ不成立
- **J_W**：**J_7 が成立したときだけ判定する**。m_W ＝ J_W の分母の個体の数。m_W ＜ 10 なら判定不能。m_W ≥ 10 で、J_7 と同じ規則（k₂(m_W)、両側）で、＋・−の向きの成立を決める
- J_7 が不成立・判定不能・無効のときは、J_W を判定しない（「未判定」）。D^W の数と区間は記述として必ず報告する（§6）
- **二つを合わせた主張**（§0.2）は、J_7 と J_W が**同じ向きで**成立したときだけ行う

### 4.4 この形にした理由（結果を見る前の理由）

**主の量を A1 の割合にした理由**
- S3 の問いの量（行動の割合。基準 §2）そのもので、物理の行動 ID で書ける
- 決まった窓の数（選択が出る頻度）と、どちらが選ばれるかを分ける。数の差（#A1 の差、#A1 − #A2 の差）は、規則 c で選択の頻度そのものが変わると、頻度の違いを選択の違いと混ぜる（常設チェック A4）。そのため、数は記述に回す（§6.2）
- 割合の分母 0 は、適用の対象がないこととして N/A にする（A3 の (3)）。その条件は二つの系について対称にした（§4.1）

**個体の事象を符号にした理由**
- 二つの本体は、最初の結果の刺激から分かれ、その後の軌道は決定論のもとで違いうる。「U の選択の列が違う」という存在の形は、規則 c の効果の向きとは無関係な軌道の分岐だけでも成り立ちやすく、層 2 の問い（選択の分布が規則に依ってずれたか）の答えにならない
- 符号は、閾値・比・正規化を持ち込まない（A6）。向きは事前に決めず（G-10・G-11：結果を返す側の接続には、強める項も弱める項も生じうる）、両側で問う
- 個体ごとに向きが違う効果（ある個体は＋、ある個体は−）は、この判定では検出しない。それは限界として §4.6 と §13 に書く。|D_i| の分布は記述として必ず並べる（§6.2）

**多数を問う理由**（R4 §7.2、R5 §2）
- 独立の標本と見なせるのは、出生時の状態のモデルのもとでの個体である
- 0034〜0037 と同じく個体の単位の判定で、基準 §9 の未決（主の判定の形）には「個体の中の比べ（同じ個体の二つの系の差）を個体の事象にし、その向きの個体の多数を問う」で答える
- 向きごとに 0.025 にしたのは、向きを事前に決めない両側の判定で、全体の誤りの水準を 0.05 に保つためである

**J_W を主の二番目にした理由**
- 層 2 の主張には、R-7（規則の入れ替え）に加えて、変化が可塑性を通したことを示す R-1 の比べが要る（基準 §2）
- PC-4 の型の移植を、R-7 の二つの本体の重みの間で行うと、状態・世界の規則・U の条件をそろえたまま、**規則の違いのもとで形づくられた重みの違い**だけを替えられる。これは「規則の違いが、可塑的な変化を通して、選択に届いたか」を、層 1 と層 2 をまとめて問う形である
- LC1（D^F）は、可塑性を止めた系での規則の入れ替えで、経験の列も変わる（PC-1 の型）。可塑性を通さない即時の帰還で同じ向きのずれが生じるかを示す記述の対照にし、判定にはしない
- 固定の順序（J_7 → J_W）にしたのは、二つの判定を合わせても、誤りの水準を 0.05 に保つためである（§4.5）。総効果が確立しないときに、重みの運び手だけを主張しない

**移植の系の U の条件（TC-1 ＋ TP-1）にした理由**
- U で重みを止めると、移植の系と替えない系の違いは、P_E の重みだけになり、その後の重みの変化の違いが入らない。E で形づくられた重みを運び手として問う（0037 の TP-1 と同じ理由）
- 世界の規則は背景の本体のまま（閉ループ）にする。U でだけ世界を変えると、比べる条件が本体から一つ多く離れる
- そのため J_W の結果は、「U で重みを固定した系」の結果で、自然な AS2b の全体の効果とは呼ばない（R-3）

**J_W の主の状態を c ＝ A1 の本体の状態にした理由**
- R-2 は、どの状態を条件にした対比を主にするかを前もって決め、逆を必ず報告することを求める
- A1・A2 の札は、個体ごとに名前で分けた乱数で源に割り当てる（`as2b-roles-{seed}`）。そのため、c ＝ A1 の本体の状態と c ＝ A2 の本体の状態は、母集団の上で同じ分布になり、どちらを主にしても判定の性質は同じである。主の状態は、札の付け方の慣例（A1 を先に書く）で決めた
- どちらの状態の対比も、一方は自然な状態（自分の重み）、もう一方は自然には到達しない組み合わせ（ほかの軌道の重み）である。この限界は 0037 の L-T2 と同じで、§13 に書く

**E と U を 25 窓ずつにした理由**
- 50 窓（関門の組）を、経験と試しに同じ数ずつ分けた。データからは選んでいない
- 試しの区間の窓が少なすぎると、s が粗くなり、多すぎると経験が短くなる。そのどちらにも寄せない中立の分け方である
- 0037 の P_E ＝ 6τ（1,800 Pulse）に合わせると、U は窓 44〜50 の 7 窓しか残らない。AS2b は AS1 と違い、窓の数が選択の数の上限になるので、窓の数を基準にした

### 4.5 帰無仮説と、その条件

- **推論の対象**：J_7 では、適格で定まる個体の母集団。J_W では、J_W の分母の個体の母集団
- **H₀^7**：出生時の状態（seed）を独立・同一分布の標本と見なす。この母集団で、P(D_i ＞ 0) ＝ P(D_i ＜ 0)（規則 c の入れ替えに対して、ずれの向きが対称）
- **H₀^W**：同じく、P(D^W_i ＞ 0) ＝ P(D^W_i ＜ 0)
- 帰無のもとでは、各個体が「＋」である確率は (1 − P(D_i ＝ 0))／2 ≤ 1/2 である。0 の個体を分母に残すので、「＋」の個体の数は Bin(m, 1/2) に確率的に支配される。「−」も同じ。したがって P(J_7 がどちらかの向きで成立 | H₀^7) ≤ 0.025 ＋ 0.025 ＝ 0.05
- 適格外 (a) は共通の部分（U に依らない）で、定まらない (b) は二つの系に対称な条件で決まる。どちらも、残した個体の符号の対称性を崩さない
- **固定の順序**：H₀^7 が正しいとき、何かの判定が成立する確率は J_7 の成立の確率以下（≤ 0.05）。H₀^7 が誤りで H₀^W が正しいとき、J_W が成立する確率は ≤ 0.05。したがって、二つの判定の族の誤りの水準は 0.05 以下
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない
- 同じ個体の二つの本体は独立ではない。対の差を一つの個体の事象にして、この依存を判定に入れない

### 7.2 命題 S-1（AS2b の入力の条件での、源の沈黙の十分条件）【命題】（R-4、N-3・N-4 §3.6、総括 E14）

**前提**：C0 の力学（`SimpleActivityDynamics`、Δt ＝ 1、不応 0、activity ≥ 0、発火で activity を 0 に戻す、発火の条件 activity ≥ θ ＋ h、h ≥ 0）。λ ＝ 0.85、α ＝ 0.01、τ_a ＝ 300。出生時に θ ∈ [0.45, 0.55]、c ∈ [0.072, 0.088]（独立に一様）、activity ∈ [0, θ/2]、h ＝ 0。可塑的な 6 本の重みは [0, w_max]、w_max ＝ 0.01（規則の切り詰めと、移植の値が本体の重みであること）。Receptor から Unit への重みは 1.0。関門の組の世界（源の Receptor には刺激が来ない：K1。手がかりの Unit C の Receptor の出来事は、手がかり c_k と、結果の刺激だけ）。

**補題 L2（源の発火の間隔）**：源の連続する二つの発火は 7 Pulse 以上離れる。
- 証明：源は Receptor の入力を持たず、1 Pulse に受ける駆動は高々 2 w_max（C ともう一方の源から、各 1 回の発火あたり高々 w_max）。発火の後 n Pulse の activity は高々 (c_max ＋ 2 w_max)(1 − λ^n)／(1 − λ) ＝ 0.72 (1 − λ^n) で、n ≤ 6 では θ_min ＝ 0.45 に届かない。∎

**補題 L1（手がかりの Unit の発火）**：C の Receptor の入力が入る Pulse（R の Pulse）では、C は必ず発火する。R でない Pulse の C の発火は、C の直前の発火から 7 Pulse 以上離れる。
- R の Pulse の間隔：手がかり c_k の後の結果の刺激は、決定 t ≥ a_k ＝ c_k ＋ 2、意図 t ＋ 1、結果 t ＋ 2 なので、手がかりから 4 以上後。結果は遅くとも b_k ＋ L ＝ c_k ＋ 22 で、次の手がかり c_k ＋ 41 まで 19 以上ある。どの連続する二つの間隔の和も 23 以上
- 証明（Pulse についての帰納法）：「それまでのすべての R の Pulse で C が発火し、h ＜ 0.441」を仮定する。(i) R の Pulse では activity ≥ 1.0 ＋ c_min ＝ 1.072 ＞ θ_max ＋ 0.441 なので発火する。(ii) R でない Pulse g の発火では、直前の発火 f との間に R の Pulse はない（あれば (i) によりそこで発火している）。そのため activity は高々 0.72 (1 − λ^(g−f)) ＜ 0.72 で、g − f ≥ 7（L2 と同じ計算）。また発火には θ ＋ h ≤ 0.72 が要るので、h(g) ＜ 0.27、発火の後は ＜ 0.28。(iii) 最後の R でない発火の後に h を上げるのは R の発火だけで、手がかりの発火は 41 ごと、結果の発火は 1 周期に高々 1 つ（連続する二つは 23 以上離れる）なので、その寄与は高々 α[1／(1 − e^(−41/300)) ＋ 1 ＋ e^(−23/300)／(1 − e^(−41/300))] ≒ 0.161。よって h ＜ 0.28 ＋ 0.161 ＝ 0.441。出生時は h ＝ 0。∎

**命題 S-1**：源の余裕 g ＝ c／(1 − λ) − θ が **g ＜ −E_S**、

E_S ＝ w_max [ (1 ＋ λ⁴)／(1 − λ²³) ＋ 2／(1 − λ⁷) ] ≒ **0.0450**

を満たすなら、その源は、AS2b のこの組のどの系（重みの値・可塑性の有無・規則 c・移植・FREEZE に依らない）でも、一度も発火しない。

- 証明：源が Pulse t − 1 まで発火していなければ、activity(t) ≤ max(初期値, c／(1 − λ)) ＋ w_max (Φ_C ＋ Φ_S′)。Φ は、送り手の過去の発火の λ^(経過) の和である。L1 から、C の R の発火の和は高々 (1 ＋ λ⁴)／(1 − λ²³)（間隔が 4 と 19 で交互のときが最大）、R でない発火の和は高々 1／(1 − λ⁷)。L2 から、もう一方の源の和は高々 1／(1 − λ⁷)。初期値 ≤ θ/2 で、E_S ＜ θ/2 なので、g ＜ −E_S なら activity(t) ＜ θ ≤ θ ＋ h。帰納法で一度も発火しない。∎
- **割合**（`analysis.py`。θ と c の出生時の一様分布から）：源ごとに **約 2.9%**（構造的な層）。g ＜ 0 の源は約 23.0% で、そのうち −E_S ≤ g ＜ 0 の約 20.0% は、ほかの Unit の駆動しだいで発火しうる条件付きの層である。二つの源の少なくとも一方が構造的な層に入る個体は **約 5.8%**
- **読み方**：S-1 は十分条件で、条件付きの層の源が実際に発火するかは個体の軌道に依る【未識別】。構造的な層に入る個体は分母から除かず（§4.1）、札と件数を報告する。S-1 は判定の量に使わない（札だけに使う）。本番で S-1 に反する発火が記録されたら、その旨と件数を開示し、S-1 の札の報告を取り下げる。判定は S-1 に依らないので変えない
- 道具の PR で、補題 L1・L2 と S-1 を、Unit の値を範囲の角に置いた合成の系で確かめる（§14）

## 付録 専門知識がなくても読める説明（t-k さんへ）

### 何を決めたか

次の段階（S3）の本番の実験の「調べ方」を、結果を見る前に決めて固定する文書です。

AI の中には、二つの行動（A1・A2）のどちらかを選ぶ仕組みがあります。世界の決まりで、片方の行動にだけ「結果」（刺激）が返ります。同じ AI を二つ用意し、

- 片方は「A1 を選ぶと結果が返る世界」
- もう片方は「A2 を選ぶと結果が返る世界」

で育てます。違うのは、この世界の決まりだけです。

### 何を確かめるか

1. **後半の選び方が、世界の決まりによって一方の向きにずれるか**：前半（25 回の選ぶ機会）で経験させ、後半（25 回）の A1 を選んだ割合を、二つの世界で比べます。200 体の AI のうち、ずれの向きがそろった AI が、偶然とは言いにくいほど多いかを確かめます
2. **そのずれを、経験でできた「つながりの強さ」が運んでいるか**：前半の終わりで AI を写し取り、つながりの強さだけを、もう一方の世界で育った AI のものに取り替えます。それで後半の選び方が同じ向きにずれるかを確かめます

1 が成り立ったときだけ、2 を判定します。偶然で「成り立った」と誤る確率を、全体で 5% 以下に抑えるためです。

### 言わないこと

- 成り立っても、「ご褒美を覚えた」「結果を求めた・避けた」「好きになった」とは言いません。言えるのは「結果の返し方の決まりを変えると、経験でできたつながりを通して、選び方が一方の向きに変わった」までです
- 成り立たなくても、「決まりは選び方に効かない」とは言いません

### 前の試しとの関係

前の試しで使った 40 体の AI は、使いません。前の試しの記録には、この比べの答えがすでに入っているので、同じ AI で本番をすると、結果を見る前に決めたことになりません。本番は新しい 200 体で行います。
