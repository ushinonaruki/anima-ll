## 2. 命題 T-5（入力のない Unit の内在の発火の間隔）【命題】

**前提**：C0 の力学（`SimpleActivityDynamics`。Δt ＝ 1）。λ ＝ 0.85、不応 0、α ＝ 0.01、τ_a ＝ 300。出生時に θ と c は、それぞれ 0.5・0.08 の ±10 % の範囲で独立に一様（`bootstrap._build_unit` の `vary`）。出生時の activity は [0, θ/2]。入力はない（源は入口に刺激を受けない：K1）。A ＝ c／(1 − λ) と書く。

**主張**（数は `analysis.py` の出力。seed・乱数・既存の raw を使わない）
- **(a) 発火しない Unit**：A ≤ θ なら、入力のない Unit は発火しない（activity は max(初期値, A) を超えず、初期値 ≤ θ/2 ＜ θ）。出生時の範囲で A ∈ [0.48, 0.587]、θ ∈ [0.45, 0.55] なので、その割合は閉じた形で **P(A ≤ θ) ≒ 0.230** である（格子の反復でも 0.229）
- **(b) 間隔の下限**：発火して activity が 0 に戻った後、次の発火までは、順応がなくても **9 Pulse 以上**（θ 最小・c 最大の角で A(1 − λ^n) ≥ θ となる最小の n）。順応があれば、さらに長い
- **(c) 順応が積もった後の間隔**：(θ, c) の格子（60 × 60）の各点で反復すると（6,000 Pulse、最後の 3 間隔）、発火する Unit の間隔は **24 Pulse 以上**で、格子の上の分位は 10 %：31、25 %：39、50 %：59、75 %：101、90 %：196 Pulse である。A が θ に近いほど長く、A → θ で限りなく長くなる
- **(d) 窓の長さ**：手がかりの Unit の 1 回の駆動 w が源の活動に残す量は、n Pulse 後に w λ^n。λ^n ≤ 0.05 となる最小の n は **19**

**証明**：(a)・(b)・(d) は力学の式からの直接の計算。(c) は力学の部品そのものの決定論の反復で、格子の点の値である（格子の外の値の分布の推定ではない）。∎

**読み方**
- 源は、手がかりの Unit とほかの源を経た駆動（1 回あたり高々 w_max ＝ 0.01）も受ける。A が θ よりわずかに小さい Unit（0 ＜ θ − A ≤ 0.01：格子で約 6 %）は、その駆動で発火しうる。(a) の割合は、入力のない場合の値である
- W ＝ 19 は、(c) の下限 24 より短い。したがって、順応が積もった後は、一つの源が一つの窓で発火するのは高々一回で、窓の中の発火の有無は、源の発火の相にも大きく依る
- (a) から、二つの源がどちらも内在に発火する個体の割合は、入力のない場合の近似で約 (1 − 0.23)² ≒ 0.59 である。これは関門の条件 (2) に関わる。**閾値（過半）は、§1 の理由（個体の多数の主張）で決め、この値に合わせて決めていない**。ここに書くのは、関門が成り立たない場合がありうることを前もって開示するためである

## 3. 手がかりの間隔 41 の導き方

- 命題 T-4：c_(k＋1) ≥ b_k ＋ L ＋ 1 ＝ c_k ＋ o ＋ W − 1 ＋ L ＋ 1 ＝ c_k ＋ 23
- 結果の駆動の残り：窓 k の結果の刺激は遅くとも b_k ＋ L に成立し、手がかりの Unit はそれで b_k ＋ L ＋ 1 に発火しうる。その駆動が源に届くのは b_k ＋ L ＋ 2。次の窓の始まり a_(k＋1) までに、その駆動が 5 % 以下に減るには、a_(k＋1) − (b_k ＋ L ＋ 2) ≥ 19。a_(k＋1) ＝ c_(k＋1) ＋ 2、b_k ＝ c_k ＋ 20 を入れると、**c_(k＋1) ≥ c_k ＋ 41**
- 二つのうち厳しい方の 41 を、等間隔の予定にした（乱数の流れを足さない）
