## 0. 問いと主張の範囲

### 0.1 問い

0034 では、結果の刺激 e の予約だけを取り消すと、552 の出来事のうち 217 で次の意図の時刻が変わり、その向きは ＋ と − にほぼ半々で分かれた（0034 §15）。**同じ結果の刺激が戻っても、次の行動が早まるか・変わらないか・遅れるかは、そのときの内部の状態で決まっているのか。**

この実験は、それを次の形で問う。

> **問い Q-SD**：出来事 e ごとの符号 s_e ∈ {＋, 0, −}（0034 §2.3 と同じ定義）を、分岐の前の状態 Σ_t だけから、前もって決めた規則（§3 の **二経路近似**）で予測すると、**個体の中で、状態を見ないどの予測（定数の予測）よりも多く当たる個体**が、多数を占めるか。

- これは推定対象 A（e がその時点の重み・状態を通って次の意図に与える効果）の、**条件づけ**の問いである。0034 は A の向きの多数を問うた。0035 は、どの状態のときにどの符号になるかを問う
- 予測を当てる道具を作ることが目的ではない。0034 §3.2 に結果より前に書いた二つの経路（直接の経路・受の位相の経路）が、分岐の前の状態から符号を説明できるかを確かめる

### 0.2 主張の形（成立したとき）

「AS1（C0 の力学と可塑性のまま、L ＝ 2、外の刺激なし）で、区間 W のすべての結果の刺激について、分岐の前の状態だけから事前に固定した二経路近似で符号を予測すると、個体の中で、どの定数の予測よりも多く当たった個体が、事前に決めた基準（§5）を超えて多かった。」

- 主張の水準は、**事前に固定した機構の近似の予測が、新しい個体のデータと整合した**、まで（設計メモ §7.4）。個体をまたぐ部分は、出生時の状態を独立・同一分布の標本と見なした統計の判断である
- **予測の成功は、機構の証明ではない**。Σ_t の量が符号を因果的に決めたと特定するには、その量だけを変えた複製で符号を見るような、追加の介入の検証が要る（別の事前登録）

### 0.3 主張しないこと

- 状態の量が符号の原因であること（§0.2）。「状態依存の帰還が機構として確かめられた」とは書かない
- 推定対象 B・C（可塑性の経路の寄与）、行動の選択（S3）、学習、意味、目的、価値、感じ方
- 0034 の J_A の結果を変えること・救うこと。0034 の J_A 不成立（m ＝ 18、10 ＜ 13）はそのまま
- 不成立のときに「符号は状態に依らない」と言うこと（§12）

## 2. 出来事・反実仮想・分岐の前の状態

### 2.1 本体

- 各 seed について、道具の `build(seed, delay=2, multiplicity="per_reservation", respond=True, exogenous=())` で個体と世界を組み立て、Pulse 1 から 2099 まで走らせる。本体には介入をしない
- 本体の来歴は 0034 と同じものを記録する。意図、感覚の出来事、発火、Pulse 300・600・…・1800・2099 の接続の状態、出生時の Unit の状態

### 2.2 出来事 e と系 N

0034 §2.2 と同じ。W のすべての出来事を使う（標本にしない）。系 N は、本体を Pulse t の処理の後まで進めたところの複製から、e の識別子の予約だけを取り消したもの。N は、最初の意図か t ＋ H まで進める。

### 2.3 符号 s_e

0034 §2.3 の表のまま。τ_F は本体の意図の記録から、τ_N は系 N の源の Unit の発火の数で検知する（`advance_until_first_intent`）。0035 では、N のすべての Unit の発火も保存し、τ_N をそこから計算し直して一致を確かめる（O5）。

### 2.4 分岐の前の状態 Σ_t

- **Σ_t** ＝ 本体を Pulse t の処理の後まで進めたところ（分岐の時点。F と N の共通の出発点）の状態。道具の `sigma(system)` の書き出しをそのまま保存する。中身は次のとおり
  - 各 Unit の状態：活動、順応、不応の残り、発火の数、力学の値（閾値・内在の駆動・decay・順応の増分と τ_a）

  - Pulse t に作られ、Pulse t ＋ 1 に届く駆動（送り手・受け手・重み）
  - 世界の予約の列（W-2 により e だけ）
  - runtime の数え（意図の通し番号など）
- **保存は読み出すだけ**。Core・AS1 の道具・本体・系 N の動きを変えない。そのことを、契約テストと O7（§7）で確かめる
- 予測（§3）は、保存した Σ_t から `analyze.py` が計算する（D2）

## 3. 予測の規則：二経路近似

### 3.1 定義

**二経路近似**は、0034 §3.2 の二つの経路だけを残し、ほかを無視して、F と N の源の最初の発火の Pulse を Σ_t から計算する。

- 残すのは、**源と受の二つの Unit**と、**受 → 源 の接続**だけ。Unit の式は Core の `SimpleActivityDynamics.advance` をそのまま使う（runtime と Application は組み立てない）
- 世界 X ∈ {F, N} ごとに、Pulse p ＝ t ＋ 1, t ＋ 2, …, t ＋ H について、次を順に計算する
  1. 受への入力 S_r(p)
     - p ＝ t ＋ 1 のとき：Σ_t の、受に届く駆動の重みの和
     - p ＝ t ＋ 2 で、X ＝ F のとき：**結果の刺激の重み**（受の Receptor から受への投射の重み。設計図では 1.0）を足す（e は Pulse t ＋ 1 に成立し、その駆動は t ＋ 2 に届く：0034 §3.2、命題 G-3）
     - それ以外：0
  2. 源への入力 S_s(p)
     - p ＝ t ＋ 1 のとき：Σ_t の、源に届く駆動の重みの和
     - 世界 X で受が Pulse p − 1 に発火していれば：**w(受 → 源)**（Σ_t の重み）を足す
  3. 受と源を、それぞれ `advance(state, S, Δt ＝ 1)` で進める（同じ Pulse の中では、受の発火が源に届くのは次の Pulse。runtime の順序：0034 §10 の B1〜B3）
  4. 源が発火したら、τ̂_X ＝ p として止める
- t ＋ H までに源が発火しなければ、τ̂_X は「なし」
- **予測の符号 ŝ**：0034 §2.3 の表を τ̂_F・τ̂_N に当てる。ただし、両方「なし」のときは **0** とする（予測は ？ を出さない）

| τ̂_F | τ̂_N | ŝ |
|---|---|---|
| ある | ある | sign(τ̂_N − τ̂_F)（＋・0・−） |
| ある | なし | ＋ |
| なし | ある | − |
| なし | なし | 0 |

### 3.2 使う量・使わない量（設計メモ §4）

| 使う（分岐の前に分かる） | 使わない（将来か反実仮想でしか分からない） |
|---|---|
| Σ_t の源と受の状態と力学の値、w(受 → 源)、Pulse t に作られて t ＋ 1 に届く駆動、結果の刺激の重み（設計図の定数） | τ_F・τ_N・d_e。本体・系 N の t の後の軌道（受・他の実際の発火を含む）。ほかの出来事の結果。t の後の重み |

- 二経路近似は、設計メモ §4.3 の **孤立の外挿**を、受と源の二つの Unit に広げたものである。レビュー（#155）で示された条件を満たす
  1. 実際の F・N の系を進めない（runtime を組み立てない）
  2. 式を、ここで評価の前に固定する
  3. 孤立では発火しない場合の扱いを決めている（§3.3）
  4. 外挿を使わない予測との比較を、補助として残す（§6 の R3）

### 3.3 孤立では発火しない場合

- 源の内在の駆動だけによる平衡が、閾値と順応の和に届かない源（0034 の 27011・27012 の源）は、二経路近似の中でも、受からの駆動がなければ発火しない。τ̂ は「なし」になりうる。§3.1 の表がそのまま扱う（両方なしなら 0）
- 受が孤立では発火しない場合も、N で受からの駆動は届かない。そのまま扱う
- 場合分けや特別な値は置かない

### 3.4 二経路近似が無視するもの（予測が外れうる理由）

- **他の Unit**：t の後の他の発火と、他から源・受への駆動。F では受が t ＋ 2 に発火するので、受 → 他 → 源 の間接の経路も、F と N で違いうる
- **可塑性**：t の後の重みの変化。二経路近似は、重みを Σ_t のまま固定する（0034 では B ≠ 0 が 2/552）
- **源 → 受**：源は τ̂ まで発火しないので、t の後の源から受への駆動はない。無視しているわけではない

外れた出来事で、他の Unit が t の後に発火していたかを、補助として記録する（§6 の R4）。予測には使わない。

### 3.5 なぜこの形か（常設チェック A6）

- 二経路近似は、新しい関数の形や閾値を持ち込まない。Unit の式と、runtime の Pulse の順序と、0034 §3.2 の二つの経路から決まる
- 「感度」（源がゆっくり閾値に近づくほど、小さい駆動で越える Pulse がずれる。設計メモ §3.3）は、規則の中の Unit の式に含まれている。別の量や閾値として足していない
- 同じくらいもっともらしい別の規則（直接の経路だけ、過去のリズムだけ）は、主の判定にせず、補助として記録する（§6 の R3）
- **二経路近似は、同じ Unit の式を、源と受の二つに縮めた計算でもある**。そのため、成立が示すのは「この縮約（他の Unit と、t の後の可塑性を無視すること）のもとでの予測が、多くの個体で定数の予測より当たる」ことである。縮約に残した経路（直接・受の位相）が実際に効いたという因果の証明ではない（§0.2）

## 4. 主の判定 J_S

### 4.1 個体ごとの量

- **適用できる個体** ＝ 本体 F で、区間 W に結果の予約 e が 1 つ以上ある個体。0034 §2.4 と同じで、本体の意図の記録だけで、反実仮想と予測を見る前に決まる（常設チェック A3）。出来事が 1 つもない個体だけ N/A
- **評価できる出来事** ＝ s_e ≠ ？ の出来事。？ の出来事の数は報告する
- 適用できる個体 i について
  - acc_rule(i) ＝ 評価できる出来事のうち、ŝ ＝ s_e の割合
  - acc_const(i) ＝ max_{c ∈ {＋, 0, −}}（評価できる出来事のうち、s_e ＝ c の割合）。個体の中の最良の定数の予測の当たりの割合
  - **個体の事象 Q_i** ＝ 評価できる出来事が 1 つ以上あり、かつ **acc_rule(i) ＞ acc_const(i)**（等しいときは成り立たない。保守の側）
- 評価できる出来事のない適用できる個体は、Q_i 不成立として m に数える
- s_e が個体の中で 1 種類しかない個体（例：すべて 0）は、acc_const(i) ＝ 1 なので、Q_i は成り立たない。これも m に数える（結果を見てから除かない）

### 4.2 判定 J_S

- m ＝ 適用できる個体の数。m ＜ 10 なら**判定不能**
- m ≥ 10 なら、**Q_i が成り立つ個体の数 ≥ k(m)** のとき J_S が成立する。k(m) は、二項分布 Bin(m, 1/2) の上側の確率が 0.05 以下になる最小の数（§5）

### 4.3 帰無仮説と、その条件

- **H₀^S**：出生時の状態（seed）を独立・同一分布の標本と見なす。本体で W に出来事がある個体の母集団で、**P(Q_i) ≤ 1/2**
- H₀^S のもとで、m を条件として、Q_i が成り立つ個体の数は Bin(m, 1/2) に確率的に支配される。したがって P(J_S 成立 | H₀^S) ≤ 0.05。個体は独立で、適用できるかどうかは本体だけで決まり、それぞれの個体で Q_i の成り立つ確率は 1/2 以下だからである
- **これは、個体の過半数で、二経路近似が定数の予測より当たるかの検定**であって、状態が因果的に寄与したことを直接に示す検定ではない（設計メモ §7.2・§7.4）
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない（0034 §4.2 と同じ）
- 個体の中の出来事を、独立の標本として数えない。個体の事象 Q_i に一つにまとめる

### 4.4 なぜ個体の中の最良の定数と比べるのか

- 出生時の性質・役の割り当て・個体の要約だけを使う予測は、個体の中のすべての出来事に同じ予測を出す。そのような予測の当たりの割合は、acc_const(i) を超えない
- したがって、acc_rule(i) ＞ acc_const(i) は、**個体差だけでは届かない当たり**を、出来事ごとの Σ_t から得たことを意味する（設計メモ §7.1 の「個体だけの予測」を、最も強い形で含む）
- 定数 0（0034 で最も多かったクラス）と定数 ＋（直接の経路だけの見込み）も、この比べ方に含まれる
- acc_const(i) は、その個体の実際の結果から選んだ最良の定数なので、二経路近似にとって不利な側の比べ方である。二経路近似は、データに合わせ込む値を持たない（§1.1）

- R3 の (a)・(b) の当たりを、主の判定と事後に入れ替えない
