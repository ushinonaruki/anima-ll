## 0. 問いと主張の範囲

### 0.1 問い

0034 では、結果の刺激 e の予約だけを取り消すと、552 の出来事のうち 217 で次の意図の時刻が変わり、その向きは ＋ と − にほぼ半々で分かれた（0034 §15）。**同じ結果の刺激が戻っても、次の行動が早まるか・変わらないか・遅れるかは、そのときの内部の状態で決まっているのか。**

この実験は、それを次の形で問う。

> **問い Q-SD**：出来事 e ごとの符号 s_e ∈ {＋, 0, −}（0034 §2.3 と同じ定義）を、分岐の前の状態 Σ_t だけから、前もって決めた規則（§3 の **二経路近似**）で予測すると、**W の符号が 2 種類以上に分かれた個体のうち、個体の中で、状態を見ないどの予測（定数の予測）よりも多く当たる個体**が、多数を占めるか。

- これは推定対象 A（e がその時点の重み・状態を通って次の意図に与える効果）の、**条件づけ**の問いである。0034 は A の向きの多数を問うた。0035 は、どの状態のときにどの符号になるかを問う
- 予測を当てる道具を作ることが目的ではない。0034 §3.2 に結果より前に書いた二つの経路（直接の経路・受の位相の経路）が、分岐の前の状態から符号を説明できるかを確かめる

### 0.2 主張の形（成立したとき）

「AS1（C0 の力学と可塑性のまま、L ＝ 2、外の刺激なし）で、区間 W のすべての結果の刺激について、分岐の前の状態だけから事前に固定した二経路近似で符号を予測すると、W の符号が 2 種類以上に分かれた個体のうち、個体の中で、どの定数の予測よりも多く当たった個体が、事前に決めた基準（§5）を超えて多かった。」

- 主張の水準は、**事前に固定した機構の近似の予測が、新しい個体のデータと整合した**、まで（設計メモ §7.4）。個体をまたぐ部分は、出生時の状態を独立・同一分布の標本と見なした統計の判断である
- **予測の成功は、機構の証明ではない**。Σ_t の量が符号を因果的に決めたと特定するには、その量だけを変えた複製で符号を見るような、追加の介入の検証が要る（別の事前登録）

### 0.3 主張しないこと

- 状態の量が符号の原因であること（§0.2）。「状態依存の帰還が機構として確かめられた」とは書かない
- 推定対象 B・C（可塑性の経路の寄与）、行動の選択（S3）、学習、意味、目的、価値、感じ方
- 0034 の J_A の結果を変えること・救うこと。0034 の J_A 不成立（m ＝ 18、10 ＜ 13）はそのまま
- 不成立のときに「符号は状態に依らない」と言うこと（§12）

## 3. 予測の規則：二経路近似

### 3.1 定義

**二経路近似**は、0034 §3.2 の二つの経路だけを残し、ほかを無視して、F と N の源の最初の発火の Pulse を Σ_t から計算する。

- 残すのは、**源と受の二つの Unit**と、**受 → 源 の接続**だけ。Unit の式は Core の `SimpleActivityDynamics.advance` をそのまま使う（runtime と Application は組み立てない）
- 世界 X ∈ {F, N} ごとに、Pulse p ＝ t ＋ 1, t ＋ 2, …, t ＋ H について、次を順に計算する
  1. 受への入力 S_r(p)
     - p ＝ t ＋ 1 のとき：Σ_t の、受に届く駆動の重みの和
     - p ＝ t ＋ 2 で、X ＝ F のとき：**結果の刺激の重み**（受の Receptor から受への投射の重み。設計図では 1.0）を足す（e は Pulse t ＋ 1 に成立し、その駆動は t ＋ 2 に届く：0034 §3.2、命題 G-3）
     - それ以外：0
  2. 源への入力 S_s(p)
     - p ＝ t ＋ 1 のとき：Σ_t の、源に届く駆動の重みの和
     - 世界 X で受が Pulse p − 1 に発火していれば：**w(受 → 源)**（Σ_t の重み）を足す
  3. 受と源を、それぞれ `advance(state, S, Δt ＝ 1)` で進める（同じ Pulse の中では、受の発火が源に届くのは次の Pulse。runtime の順序：0034 §10 の B1〜B3）
  4. 源が発火したら、τ̂_X ＝ p として止める
- **受の発火は何回でも追う**（監査 032）。受が t の後に何度発火しても、そのたびに次の Pulse に w(受 → 源) を源へ通す。F では、t ＋ 2 の発火の後の自発の発火も含む。最初の 1 回だけを比べるのではない
- t ＋ H までに源が発火しなければ、τ̂_X は「なし」
- **予測の符号 ŝ**：0034 §2.3 の表を τ̂_F・τ̂_N に当てる。ただし、両方「なし」のときは **0** とする（予測は ？ を出さない）

| τ̂_F | τ̂_N | ŝ |
|---|---|---|
| ある | ある | sign(τ̂_N − τ̂_F)（＋・0・−） |
| ある | なし | ＋ |
| なし | ある | − |
| なし | なし | 0 |

### 3.2 使う量・使わない量（設計メモ §4）

| 使う（分岐の前に分かる） | 使わない（将来か反実仮想でしか分からない） |
|---|---|
| Σ_t の源と受の状態と力学の値、w(受 → 源)、Pulse t に作られて t ＋ 1 に届く駆動、結果の刺激の重み（設計図の定数） | τ_F・τ_N・d_e。本体・系 N の t の後の軌道（受・他の実際の発火を含む）。ほかの出来事の結果。t の後の重み |

- 二経路近似は、設計メモ §4.3 の **孤立の外挿**を、受と源の二つの Unit に広げたものである。レビュー（#155）で示された条件を満たす
  1. 実際の F・N の系を進めない（runtime を組み立てない）
  2. 式を、ここで評価の前に固定する
  3. 孤立では発火しない場合の扱いを決めている（§3.3）
  4. 外挿を使わない予測との比較を、補助として残す（§6 の R3）

### 3.3 孤立では発火しない場合

- 源の内在の駆動だけによる平衡が、閾値と順応の和に届かない源（0034 の 27011・27012 の源）は、二経路近似の中でも、受からの駆動がなければ発火しない。τ̂ は「なし」になりうる。§3.1 の表がそのまま扱う（両方なしなら 0）
- 受が孤立では発火しない場合も、N で受からの駆動は届かない。そのまま扱う
- 場合分けや特別な値は置かない

### 3.4 二経路近似が無視するもの（予測が外れうる理由）

- **他の Unit**：t の後の他の発火と、他から源・受への駆動。F では受が t ＋ 2 に発火するので、受 → 他 → 源 の間接の経路も、F と N で違いうる
- **可塑性**：t の後の重みの変化。二経路近似は、重みを Σ_t のまま固定する（0034 では B ≠ 0 が 2/552）
- **源 → 受**：源は τ̂ まで発火しないので、t の後の源から受への駆動はない。無視しているわけではない

外れた出来事で、他の Unit が t の後に発火していたかを、補助として記録する（§6 の R4）。予測には使わない。

**他の Unit を無視する根拠と限界**（監査 032）
- 根拠：e が F と N で直接に変えるのは、受の入力だけである（t ＋ 2 の結果の刺激）。他の Unit の入力が F と N で違ってくるのは、受の発火が違ってから後（受 → 他 の駆動。重みは w ≤ w_max ＝ 0.01）で、他の発火の Pulse がそれでずれたときに限る。二経路近似は、この間接の経路を二次の効果として無視する
- 限界
  - 他の Unit が t から源の発火までのあいだに発火すると、その駆動は F と N の両方の源に届く。そのため、源が閾値を越える Pulse の基準がずれる。二経路近似はこれも無視するので、どちらの世界でも τ̂ がずれうる
  - 受 → 他 → 源 の経路で、F と N の差が生まれうる
  - どれだけ外れるかは、事前には分からない。R4 と R8（§6）で記述する
- 0034 の FB-1 の記録（s^FB と s_e の符号の一致が 382/552）は、二経路近似の当たりの割合とは別のものである。残りの 170 を当たりの上限や、他の Unit を経た割合として読まない（ChatGPT の監査 032 の判定、0034 の U5）

### 3.5 なぜこの形か（常設チェック A6）

- 二経路近似は、新しい関数の形や閾値を持ち込まない。Unit の式と、runtime の Pulse の順序と、0034 §3.2 の二つの経路から決まる
- 「感度」（源がゆっくり閾値に近づくほど、小さい駆動で越える Pulse がずれる。設計メモ §3.3）は、規則の中の Unit の式に含まれている。別の量や閾値として足していない
- 同じくらいもっともらしい別の規則（直接の経路だけ、過去のリズムだけ）は、主の判定にせず、補助として記録する（§6 の R3）
- **二経路近似は、同じ Unit の式を、源と受の二つに縮めた計算でもある**。そのため、成立が示すのは「この縮約（他の Unit と、t の後の可塑性を無視すること）のもとでの予測が、多くの個体で定数の予測より当たる」ことである。縮約に残した経路（直接・受の位相）が実際に効いたという因果の証明ではない（§0.2）

## 4. 主の判定 J_S

### 4.1 個体ごとの量

- **適用できる個体** ＝ 本体 F で、区間 W に結果の予約 e が 1 つ以上ある個体。0034 §2.4 と同じで、本体の意図の記録だけで、反実仮想と予測を見る前に決まる（常設チェック A3）。出来事が 1 つもない個体だけ N/A
- **評価できる出来事** ＝ s_e ≠ ？ の出来事。？ の出来事の数は報告する
- 適用できる個体 i について
  - acc_rule(i) ＝ 評価できる出来事のうち、ŝ ＝ s_e の割合
  - acc_const(i) ＝ max_{c ∈ {＋, 0, −}}（評価できる出来事のうち、s_e ＝ c の割合）。個体の中の最良の定数の予測の当たりの割合
  - 評価できる出来事が 0 の個体では、分母が 0 になる。acc_rule・acc_const・定数ごとの当たりの割合は **null** と記録する（0 とはしない）。そうした個体は V_i を満たさない（2 種類以上に分かれようがない）ので、J_S には入らない（R9 で数える）
  - **個体の事象 Q_i** ＝ 評価できる出来事が 1 つ以上あり、かつ **acc_rule(i) ＞ acc_const(i)**（等しいときは成り立たない。保守の側）
- **判定の対象の個体（V_i）** ＝ 適用できる個体のうち、評価できる出来事の s_e が **2 種類以上に分かれた**個体
  - s_e が 1 種類しかない個体（例：すべて 0）では acc_const(i) ＝ 1 なので、どんな予測も Q_i を満たせない（監査 031 の天井）。こうした個体は、予測の良し悪しについて情報を持たない
  - V_i は s_e のラベルだけで決まり、予測 ŝ を計算に使わない（§4.3）。ただし、符号の分布そのものが当たりに関係するので、V_i が予測の当たりと無関係な選び方だとは言わない（§4.5）
  - V_i でない適用できる個体（1 種類だけの個体、評価できる出来事のない個体）は、J_S から除き、その数と、そこでの二経路近似の当たりの割合を記述として報告する（R2・R9）

### 4.2 判定 J_S

- m ＝ 判定の対象の個体（V_i が成り立つ個体）の数。m ＜ 10 なら**判定不能**
- m ≥ 10 なら、**判定の対象の個体のうち、Q_i が成り立つ個体の数 ≥ k(m)** のとき J_S が成立する。k(m) は、二項分布 Bin(m, 1/2) の上側の確率が 0.05 以下になる最小の数（§5）

### 4.3 帰無仮説と、その条件

- **推論の対象**：本体の W に出来事があり、その s_e が 2 種類以上に分かれた個体の母集団（判定の対象の個体の母集団）
- **H₀^S**：出生時の状態（seed）を独立・同一分布の標本と見なす。この母集団で、**P(Q_i | V_i) ≤ 1/2**
- **条件付きの推論が成り立つ理由**（監査 031 の「条件付き推論の妥当化」）
  1. 個体は独立・同一分布で、V_i は個体ごとのデータだけで決まる。そのため、V_i が成り立つ個体は、条件付きの母集団からの独立・同一分布の標本になる
  2. m を条件とすると、そのうち Q_i が成り立つ個体の数は、H₀^S のもとで Bin(m, 1/2) に確率的に支配される。したがって P(J_S 成立 | H₀^S) ≤ 0.05
  3. 1・2 は、V_i が予測と独立であることを要しない。H₀^S は、条件付きの母集団の中での P(Q_i | V_i) についての仮説であり、V_i で選ぶこと自体は、その母集団からの標本の取り方として扱える
  4. 除くのは、どんな予測でも Q_i が構造的に成り立たない個体だけである。ただし、これは常設チェック A3・A7(b) の要件（適用の条件が結果と独立に決まる）を満たさない。そのため、**例外**として §4.5 に根拠と範囲を書く
- **推論の対象が変わることの明記**：J_S は「符号が分かれた個体で、二経路近似が定数より当たるか」を問う。符号が分かれない個体を含む母集団についての主張はしない。そうした個体の数と、そこでの当たりは記述する（R2・R9）
- **選ばなかった案**：結果のラベルで分母を決めず、すべての適用できる個体を数える形（v0.1）は、天井のため、二経路近似が完全に当たっても成り立ちにくい。そのため主の判定にはしない。数は R9 で報告する
- **これは、個体の過半数で、二経路近似が定数の予測より当たるかの検定**であって、状態が因果的に寄与したことを直接に示す検定ではない（設計メモ §7.2・§7.4）
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない（0034 §4.2 と同じ）
- 個体の中の出来事を、独立の標本として数えない。個体の事象 Q_i に一つにまとめる

### 4.4 なぜ個体の中の最良の定数と比べるのか

- 出生時の性質・役の割り当て・個体の要約だけを使う予測は、個体の中のすべての出来事に同じ予測を出す。そのような予測の当たりの割合は、acc_const(i) を超えない
- したがって、acc_rule(i) ＞ acc_const(i) は、**個体差だけでは届かない当たり**を、出来事ごとの Σ_t から得たことを意味する（設計メモ §7.1 の「個体だけの予測」を、最も強い形で含む）
- 定数 0（0034 で最も多かったクラス）と定数 ＋（直接の経路だけの見込み）も、この比べ方に含まれる
- acc_const(i) は、その個体の実際の結果から選んだ最良の定数なので、二経路近似にとって不利な側の比べ方である。二経路近似は、データに合わせ込む値を持たない（§1.1）
- 判定の対象の個体（s_e が 2 種類以上）では acc_const(i) ＜ 1 なので、すべて当たる予測は必ず Q_i を満たす。同点は、すべて当たる場合には起きない

### 4.5 常設チェック A3・A7(b) の例外（V_i）

- **区別**：この実験には、対象の個体の集まりが 2 つある
  - **適用できる個体**（§4.1）：本体の W に出来事がある個体。本体の意図の記録だけで、反実仮想と予測の前に決まる。A3 をそのまま満たす。R2・R9 の記述は、この集まりの全体について出す
  - **判定の対象の個体 V_i**：適用できる個体のうち、s_e が 2 種類以上に分かれた個体。**反実仮想の結果 s_e に依る**
- **例外であること**：A3 と A7(b) は、適用・除外の条件が結果と独立に決まることを求める。V_i は s_e に依るので、この要件を満たさない。V_i は、この実験の J_S に限った**例外**として置く
- **例外を置く根拠**
  - s_e が 1 種類しかない個体では、どんな予測も、最良の定数に厳密に勝てない（acc_const ＝ 1）。これは予測の良し悪しによらない構造的な凍結である（監査 031）
  - 凍結した個体を判定に含めると、二経路近似がすべて当たっても J_S が成り立ちにくくなり、問い Q-SD に答えられない
  - 条件付きの母集団についての二項の判定は、§4.3 の 1・2 のとおり、個体の独立・同一分布のもとで成り立つ
- **例外の範囲**
  - V_i を使うのは J_S と、それに対応する R6 の区間だけ。それ以外の記述（R2・R5・R9）は、適用できる個体の全体について出す
  - V_i の条件は「評価できる s_e が 2 種類以上」の 1 つに固定する。結果を見てから、ほかの条件（例：出来事の数、0 の割合）を足さない
  - 主張は、V_i の母集団についてだけ（§4.3、§12）
- **言えないこと**：V_i は予測 ŝ を計算に使わないが、符号の分布は予測の当たりに関係する。例えば、0 と ＋ だけに分かれた個体と、＋ と − に分かれた個体では、二経路近似の当たりやすさが違いうる。そのため、V_i が「当たりやすい個体を選ばない」選び方だとは言わない。V_i の個体と、そうでない個体での当たりの違いは、R9 で記述する

### 15.5 言えること・言えないこと

**言えること**
- AS1（この構成）で、事前に固定した二経路近似は、事前登録した基準では、**分岐の前の状態から帰還の効果の符号を予測し、個体の中の最良の定数より多く当たる個体の多数を示さなかった**
  - 判定の対象は、W の符号が 2 種類以上に分かれた 30 個体で、成立は 14。基準は 20 以上
  - J_S は不成立で、出生時の状態の独立・同一分布のモデルを仮定した統計の判断である
- 記述
  - 他の Unit が区間の中で発火しなかった出来事では、二経路近似の予測はほぼ当たった（416/417）
  - 外れた出来事のほぼすべて（185/186）で、他の Unit が発火していた
  - 二経路近似が無視した他の Unit が、予測の外れに関わっている可能性と整合する（§3.4、§12）

**言わないこと**（§12・§13）
- 「符号は状態に依らない」
- 「他の Unit が符号を決めた」「他の経路が帰還の効果を担う」（R4・R8 は記述で、経路の寄与を分けた推定ではない）
- 「状態依存の帰還が機構として確かめられた／否定された」
- R3 の別の規則の当たりを、主の判定に替えること
- 出来事を独立の標本として数えた統計の主張（R5 の全体の表に検定をしない）
- B・C（可塑性の経路の寄与）、学習・選択・意味についての主張
- 結果を見てから、判定の対象の条件・N/A の個体の扱い・パラメータ・W・H を変えて走らせ直すこと（必要なら、理由を書いた別の事前登録で行う：§9）
- J_S の結果を使って、0034 の J_A の結論を変えること
