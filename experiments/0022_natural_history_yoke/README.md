## 0. 問いと主張の範囲

**問い**：同じ Birth State から ordered・shuffled という違う経験を自然に経た 2 つの個体 O・S について、**W の可塑性の更新に使う発火の列を、自分の発火から相手の個体の発火に置き換えると**、その後の自発の発火（入力のない W の離散的な発火の列）は変わるか。

- 比べるのは、yoke した腕と、その腕が出発した自然な個体（基準）。Y_O←S と O、Y_S←O と S の 2 組で、どちらも個体ごとに記述する
- **主張の範囲**：選んだ初期状態（O の t0 の全状態、または S の t0 の全状態）のもとで、可塑性の入力の発火の列を相手のものに置き換えたことの **条件付きの因果効果** に限る（Q4 のメモ 命題 7.2）
- **同定しないこと**：自然な O と S の違いのうち、循環（自分の発火 → 可塑性 → 後の発火）が占めた割合（Q4 のメモ 命題 7.1・§7）
- yoke は **循環を取り除く操作ではない**。自分の発火による可塑性の駆動を、相手の発火による駆動に置き換える操作で、相手の発火には相手自身の循環の結果が含まれる（Q4 のメモ §3.1）。したがって効果は「自分の発火の返りを外したこと」と「相手に特有の発火による書き込みを入れたこと」を分けない
- Q4 のメモの恒等式（命題 4.3・4.5・4.8・4.9 など）は **操作の確認** に使い、結果・成功の証拠にしない（Q4 のメモ §0.1）
- 集団の holds／fails、合格の基準、方向の予想、増幅率、成功の閾値、Clopper–Pearson の区間は置かない。結果の個体数を母集団の性質とは呼ばない
- 量を 1 つの式でまとめて「循環の強さ」「差を広げた・縮めた」と判定しない（Q4 のメモ §6）

**言わないこと**（§9 にもまとめる）：再活性化、記憶、意味、感情、経験したパターンの再出現、自然な媒介、循環が自然な差を広げた・縮めた、24000 より先、該当なしを「効果が永久にない」と読むこと。

## 2. 手順

```text
ordered・shuffled を同じ Birth State から経験させる（1〜12000。刺激の列は 0014〜0021 と同じ格子、乱数の流れは "0022-shuffle:<seed>"）
Pulse 12000（＝ t0）の可塑性の更新の終わり ＝ 12001 の重みの固定の前に、両方の個体から複製を作る：
   ├─ O       ：ordered の本体そのもの（自然な個体）
   ├─ S       ：shuffled の本体そのもの（自然な個体。0021 と違い 24000 まで進める）
   ├─ Y_O←S   ：O の複製（Unit の状態・重み・痕跡・12001 に届く駆動まで同じ）
   ├─ Y_S←O   ：S の複製（同上）
   ├─ twin_O  ：O の複製（何も変えない。確認用）
   ├─ twin_S  ：S の複製（同上）
   ├─ Y_O←O   ：O の複製（自分の基準の発火で yoke する。確認用）
   └─ Y_S←S   ：S の複製（同上）
12001〜24000（＝ W）：8 つの腕を、入力なしで 1 Pulse ずつ並べて進める
```

**各腕の規則**：

| 腕 | 活動・伝達に使う重み | 可塑性の更新（発火の出来事と痕跡の更新） | 痕跡の初めの値 | 役割 |
|---|---|---|---|---|
| O | 自分 | 自分の発火 | 自分（ordered の t0） | 自然な個体・基準 |
| S | 自分 | 自分の発火 | 自分（shuffled の t0） | 自然な個体・基準 |
| **Y_O←S** | 自分 | **全 6 接続で、同じ Pulse の S の発火** | O の t0 の値（自分の基準のまま） | 置き換えの腕 |
| **Y_S←O** | 自分 | **全 6 接続で、同じ Pulse の O の発火** | S の t0 の値（同上） | 置き換えの腕 |
| twin_O・twin_S | 自分 | 自分の発火 | 基準と同じ | 複製の確認。O・S が yoke の参照に使われても変わらないことの確認 |
| **Y_O←O・Y_S←S** | 自分 | 同じ Pulse の **自分の基準** の発火 | 基準と同じ | yoke の仕組みの確認（入力が同じなら何も変えないので、基準と完全に一致するはず） |

- yoke の腕の Unit の状態（activity・順応）は自分の発火で進む（可塑性ではない）
- **痕跡は自分の基準の t0 の値を保ち、相手の発火で更新する**（Q4 のメモ §3.1 の基本の候補を採る）。理由：問いは「可塑性に返す発火を置き換える」ことで、t0 の痕跡は自然な履歴が残した状態の一部である。相手の痕跡に置き換えると、自然な履歴の痕跡を移植する 2 つ目の介入が加わる（Q4 のメモ §3.1 の【未解決】をこの案で決める。レビューで確かめてほしい）
- 痕跡を自分の発火で更新し、出来事だけを相手のものにする混ざった腕にはしない（0021 README §2 と同じ理由。恒等式が成り立たない）
- 全 6 接続を yoke する（0021 と同じ。循環のメモ §5.7）
- O・S は、yoke の腕に発火の集合を渡すだけで、何も受け取らない（ChatGPT：O と S は独立に進め、yoke の参照に使われても変わらない）

**各 Pulse t（W の中）の処理の順序**：

```text
1. O      ：run_pulse(t)。自分の w_O(t−1)。終わりに s^O(t) で可塑性
2. S      ：run_pulse(t)。自分の w_S(t−1)。終わりに s^S(t) で可塑性
3. Y_O←S  ：run_pulse(t)。自分の w(t−1) で Unit・駆動。終わりの可塑性だけ、自分の発火ではなく 2 の s^S(t) で更新
4. Y_S←O  ：run_pulse(t)。同上。終わりの可塑性を 1 の s^O(t) で更新
5. twin_O ：run_pulse(t)（自分）
6. twin_S ：run_pulse(t)（自分）
7. Y_O←O  ：run_pulse(t)。終わりの可塑性を 1 の s^O(t) で更新
8. Y_S←S  ：run_pulse(t)。終わりの可塑性を 2 の s^S(t) で更新
```

- s^X(t) は腕 X で Pulse t に発火した Unit の集合。yoke の腕に渡す集合は、Pulse 番号が t で一致することを確かめる（0021 の YokedConnections の契約：その Pulse に 1 回だけ使う。一致しない・渡されない・使われずに残るとエラー）
- yoke の腕の Unit の判定は自分の w(t−1) だけで決まり、同じ Pulse の相手の発火に依らない（相手の発火が効くのは、その Pulse の終わりの可塑性だけ）
- 置き換えは実験の道具の中だけで行う（接続の状態に渡す発火の集合を差し替える薄い包み。0021 と同じ形）。Runtime の本体・世界の構造・数値・内部の機構は変えない

### 3.2 最初の違いの、接続ごとの寄与（0021 README §3.2 の導出をこの組に当てはめる）

O と Y_O←S の組で書く（S と Y_S←O の組も同じ。t_OS は共通、t_YO を t_YS に替える）。

**前提**：
1. Y_O←S は O の複製で、t0 で全状態が同じ（t0 ＋ 1 に届く駆動まで同じ）
2. 不応期 0、W の間は感覚の入力なし、Delta・Kernel は活動を駆動しない（0021 README §3.2 と同じ）
3. t_YO の定義により、O と Y_O←S の発火の列は t0 ＋ 1〜t_YO − 1 で共通（以下 s(k)）

**重みが分かれる時刻**：t ≤ t_OS − 1 では s^S(t) ＝ s^O(t)（t_OS の定義）なので、O と Y_O←S の可塑性の入力は同じで、重み・痕跡は同じ（Δw(m) ＝ 0、m ≤ t_OS − 1。Δ は O − Y_O←S）。t_OS の終わりに、O は s^O(t_OS) で、Y_O←S は s^S(t_OS)（≠ s^O(t_OS)）で更新するので、Δw(t_OS) は 0 でなくなりうる。

**伝達の遅れ**：Pulse m の終わりの重みは m ＋ 1 に作る駆動に使われ、その駆動は m ＋ 2 に届く。したがって Δw(k − 2) が受け手に入るのは Pulse k で、k ≥ t_OS ＋ 2。よって **t_YO ≥ t_OS ＋ 2**（Q4 のメモ 命題 4.9）。Unit の状態（activity・順応）も t_OS ＋ 1 の終わりまで同じ。

**t_YO での寄与**：r_j を、t_YO より前に j が（共通の列で）最後に発火した Pulse とする（なければ t0）。0021 README §3.2 と同じ差分方程式から

```text
Δã_j(t_YO) = ã_j^O(t_YO) − ã_j^{Y_O←S}(t_YO) = Σ_i K_ij(t_YO)
K_ij(t_YO) = Σ_{k = max(r_j + 1, t_OS + 2)}^{t_YO} λ^(t_YO − k) · Δw_ij(k − 2) · s_i(k − 1)
Δw_ij(m)   = w^O_ij(m) − w^{Y_O←S}_ij(m) = F_O,ij(m)        （m ≤ t_OS − 1 では 0）
```

- 実効の閾値 θ_j ＋ h̃_j(t) は自分の発火の列だけで決まるので、t_YO まで 2 つの腕で同じ
- affine の仮定を使わない（実際の重みの差をそのまま使う）
- **K は副の記録**。ある接続の K を 0 にした腕は走らせていないので、その接続の差が「必要だった」とは言えない（0021 と同じ限界）
- S と Y_S←O の組では Δw ＝ w^S − w^{Y_S←O} ＝ −F_S

### 3.3 設計から決まること・決まらないこと（常設チェック A1・A7 の監査）

**設計から決まる**（操作の確認に回す。知見にしない）：

| 性質 | 根拠 |
|---|---|
| t_OS がない（W の間 s^O ≡ s^S）なら、Y_O←S ≡ O、Y_S←O ≡ S が W の全体で成り立ち、t_YO・t_YS もない | Q4 のメモ 命題 4.9 |
| t_OS があれば、yoke の腕と基準は t_OS ＋ 1 まで同じ発火（Unit の状態も t_OS ＋ 1 まで、接続の状態は t_OS − 1 まで同じ） | 命題 4.9・§3.2 |
| t_YO があれば t_OS もあり、t_YO ≥ t_OS ＋ 2（t_YS も同じ） | 同上 |
| Y_O←O ≡ O、Y_S←S ≡ S | 入力が同じなので（0021 の Y0 ＝ C と同じ形） |
| 痕跡の差 κ^(t−t0)·ΔX、P の恒等式、組の和、切り詰めなし | 命題 4.1・4.3・4.5 |

**設計から決まらない**（観測しなければ分からない）：

- **t_OS があるときに t_YO があるか**：置き換えで重みの差 F_O が生まれても、それがどの発火の判定も W の中で変えないことがある（循環のメモ F3：同じ発火の列を与える状態の区画）。また、ある Pulse で発火が違った Unit の、接続の相手の Unit の痕跡がその Pulse の更新の前に 0 なら、その Pulse の発火の違いはその接続の重みの差を作らない（Q4 のメモ §4 の更新式）。したがって t_YO の有無は、保存則・単調性・介入の定義からは決まらない。似た設計の実例として、0021 では T で I と Y の重みが違ったのに、W の中で発火の列が同じだった個体が 4 つあった（0021 README §12.3 の (b)。この実験の設計そのものの例ではない）
- t_YO・t_YS の時刻、違った Unit とどちらの腕で発火したか、2 つの向きの両方に違いが出るか
- 接続ごとの重みの差・痕跡の差・発火の列が W の間にどう推移するか

**ほぼ必然ではないか（ChatGPT の監査の求め）**：論理的には必然ではない（上）。

- 存在の例：同じ更新式・同じ順序の 3 Unit の玩具（seed・乱数・runtime・実験の記録を使わない。経験と W をそれぞれ 1200 Pulse に短くし、θ・c を名目の値の近くの格子（一部は出生時のばらつきの範囲の少し外）に置いた 81 通り）で、t_OS があるのに t_YO・t_YS のどちらもない場合が実際に起きた。玩具の長さ・入力は実験と違うので、これは「起こりうる」ことの例で、この実験での頻度の見込みではない。同じ玩具で、§3.2 の分解の恒等式と命題 4.9 の一致・下限に違反は 0 だった。玩具の道具は PR に含めない
- それでも、次の理由で **t_YO・t_YS が多くの個体で現れる見込みはある**【予想。判定・閾値に使わない】
  - O と S は t0 で全成分が違いうるので（命題 2.1）、t_OS は早いことが多いと見込まれる。そうなら yoke の腕の可塑性の入力は W の大半で基準と違い、重みの差 F_O・F_S が W の大半で 0 でない
  - 重みは順応で決まる範囲で発火の時刻を大きく動かしうる（理論のメモ §4.4）
  - W は 12000 Pulse あり、違いが判定を変える機会が多い

したがって **「違いが現れた個体の数」そのものは、循環についての発見として扱わない**。この実験の記述として意味があるのは、(1) 違いが W の中で現れない個体があるか（反証の側。§8）、(2) 違いが現れる時刻と Unit、(3) 2 つの向きで現れ方が同じか違うか、(4) 接続ごとの重みの差・痕跡の差・発火の列の推移、を個体ごとに並べることで、どれも判定にしない。

**凍結・吸収（A7）**：W の間、O と S のどちらの Unit も発火しない個体、または O と S の発火の列が W の間ずっと同じ個体（t_OS なし）では、置き換えは設計上何も変えない。これは問いの一部として区分 (a)（§11）に含め、除外しない。A が W の間沈黙する個体なども除外しない。

## 5. 観測（個体ごとに記述。判定なし）

### 5.1 主

| 量 | 定義 |
|---|---|
| **t_YO・U_YO** | t_YO ＝ min{t ∈ W : s^O(t) ≠ s^{Y_O←S}(t)}。なければ null（**「指定された W では該当なし」**）。U_YO は s^O(t_YO) と s^{Y_O←S}(t_YO) の対称差の Unit と、その役（A・B・C）、どちらの腕で発火したか |

## 8. 反証可能性

**この実験の主張の形**（個体ごと・組ごと）：「この個体では、O の t0 の状態のもとで、可塑性の入力を S の発火に置き換えると、W の自発の発火が変わった」（Y_S←O と S も同じ形）。

| 観測 | 意味 |
|---|---|
| t_YO がある | その個体・その組について、主張の形が W の中で成り立った |
| **t_OS があるのに t_YO がない** | **その個体・その組について、主張が W の中で成り立たなかった**（反証の側）。置き換えで重みの差が生じても、W の中の発火の判定を変えなかった。窓の外については言わない |
| t_OS がない | 置き換えは設計上何も変えない（区分 (a)）。主張の対象にならない（反証でも支持でもない） |
| 操作の確認が成り立たない | 道具・実装の誤り。その個体は invalid で、脳についての知見ではない |

- **反証にならないもの**：恒等式（§3.3 の「設計から決まる」）は実装が正しければ必ず成り立つので、成り立っても主張の支持にならない
- **主張を超える読み方は、結果がどうであっても採らない**：t_YO が全個体にあっても「循環が自然な差を広げた」とは言わない。2 つの向きで結果が違っても「O の循環のほうが強い」とは言わない（背景が違う条件付きの効果で、比べる尺度がない。Q4 のメモ 命題 4.4・§7）
- **見込み**（§3.3）：t_YO・t_YS は多くの個体で現れる見込みがある【予想】（ただし必然ではない。§3.3 の存在の例）。そのため、現れた個体の数を発見として報告しない。一方、t_OS があるのに W の中で違いが現れない個体があれば、それは設計から決まらない記述として残る
- 母集団の主張はしない（判定がない）。追試を企画するなら、独立の事前登録・新しい seed で行い、元の実験と合算しない（D6）

## 9. 言わないこと

- yoke を「循環を取り除いた腕」「可塑性を止めた腕」と呼ばない（相手の発火への置き換え。§0）
- 自然な O と S の違いのうち、循環が占めた割合を言わない。F_O・F_S・P_O・P_S をその割合と呼ばない（命題 7.1・7.2）
- 2 つの向きの効果が等しい・逆符号・足すと自然な差になる、と仮定しない
- 量をまとめた尺度（ノルム・比・平均・得点）で「全体として広がった・縮んだ」「循環の強さ」と言わない
- t_OS を「重みの表出」と呼ばない（命題 2.2）
- 恒等式・t_YO ≥ t_OS ＋ 2 を、結果や成功の証拠として書かない
- null を「効果が永久にない」と言わない。24000 より先について言わない
- K から、特定の接続の差が「必要だった」と言わない
- 最後に違う Pulse が T に近いことを「保持」と呼ばない（違いの持続）
- 結果の個体数を母集団の性質と呼ばない
