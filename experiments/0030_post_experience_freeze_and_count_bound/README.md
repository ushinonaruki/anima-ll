## 0. 問いと主張の範囲

### 0.1 問い

この実験は、**同じ新しい 20 個体の自然な本体を共有する、二つの別の家族**の問いに答える。

> **F**：C0 で、0028 と同じ世界・経験（O・M・試行の中の並べ替え W）の後、**経験の終わりの直前の静かな Pulse T_0 から、各本体の重みを T_0 の値に固定して可塑性を止めた変種（F 本体）**でも、主の区間（13501〜25500）の時間差 1 の発火の組の非対称 Δ_AB と D ＝ Δ_AB − Δ_AC は、F(O)（F(M)）のとき、F(W1)〜F(W19) の分布の中で予測した向きに典型的でないか

> **N^cnt**：C0 の**自然な**本体 O・M・W1〜W19 の主の区間で、O（M）の Δ_AB（D）は、**どの W_i とも、発火の数の違いだけ（担い手の設計 命題 3 の (a)・(b)）では作れない大きさの差で**、予測した向きに外れるか

- **F** が問うのは、経験の後の自発の発火による重みの書き換えがない別の力学でも、この L3 が主の区間に現れるかである。答えは**変種についての答え**で、自然な C0 で書き換えが役に立っていたかどうかではない（担い手の設計 §4.3）
- **N^cnt** が問うのは、自然な本体の外れのうち、命題 3 の (a)（足し引きだけ）・(b)（条件付きの組の割合が同じまま数だけが違う）の意味で「数だけの違い」では作れないものが、帰無仮説の想定より多いかである（担い手の設計 §3.3 (iii)・§4.4）
- **二つの家族は、0029 の Wt の効果を「発火の数の寄与」と「入れ替えた後の可塑性の寄与」に分解する実験ではない**。F は可塑性を止めた変種について、N^cnt は自然な本体の数の差の上界について、それぞれ独立した問いに答える
- 答えの水準：F は「この変種でこの L3 が現れたか」、N^cnt は「自然な本体の外れが (a)・(b) の数だけの違いを超えたか」まで。どちらも、記憶・意味・担い手の特定・自然な差の原因（C-III）は言わない

### 0.2 主張の形（成立したとき）

どれも「C0 で、この世界・この手順のもとで、個体間の独立性の前提のもとで、家族の水準 0.05（§5 の割り当て）で」という限定が付く。

| 家族 | 判定 | 成立したときの主張の形 |
|---|---|---|
| **F** | J_Ca^F | T_0 から重みを固定して可塑性を止めた変種で、F(O) の Δ_AB は F(W) の分布より予測した向き（大きい側）に典型的でなかった。その頻度は、F(O) が F(W) と交換可能であるという帰無仮説の想定より多かった |
| F | J_O^F・J_M^F | 同じ変種で、F(O) の D は大きい側、F(M) の D は小さい側に典型的でなかった |
| F | J_OM^F | **同じ個体で、F(O) の D が F(W) のすべてより大きく、F(M) の D が F(W) のすべてより小さい、ということが、21 の F 本体の交換可能性の想定より多くの個体で起きた**（経験の後の書き換えのない変種での、内容に応じた逆向きの L3） |
| **N^cnt** | J_Ca^cnt | 自然な O の Δ_AB が、**どの W_i とも、∣ΔN_A∣ ＋ ∣ΔN_B∣ を超える差で**大きかった個体が、帰無仮説の想定より多かった。外れた個体の一つひとつについては、算術の事実として「(a)・(b) の意味の数だけの違いでは作れない差」と言える |
| N^cnt | J_O^cnt・J_M^cnt | 同じく、D の差が 2∣ΔN_A∣ ＋ ∣ΔN_B∣ ＋ ∣ΔN_C∣ を超えて、O は大きい側、M は小さい側に外れた |
| N^cnt | J_OM^cnt | 同じ個体で、O と M の両方が、数の差を超えて逆の向きに外れた |

### 0.3 主張しないこと

- **0029 の Wt の効果の分解**：F・N^cnt のどの結果からも、「0029 の Wt の外れのうち、どれだけが発火の数の違い・入れ替えた後の可塑性によるものだったか」は言わない
- **F について**：自然な C0 で、経験の後の書き換えが不要だった・役に立っていなかった（変種は別の力学：担い手の整理 命題 10 の形）。重みが担い手だった（F は Unit の状態も自然なまま残す）。学習が必要だった（F は経験の中の学習を保つ）。**F の不成立は、書き換えが必要だった証拠ではない**（棄却できなかったこと）
- **N^cnt について**：相対の時刻の違いが重みから来たのか位相から来たのか。「数だけの違い」の (a)・(b) 以外の形（例：周期だけが違い、位相の関係が同じまま）を除いたこと。**N^cnt の不成立は、X7（数だけの違い）の証拠ではない**（事象を厳しくした分、検出力が下がる）
- 二つの家族の結果を組み合わせた主張（例：「F と N^cnt の両方が成り立ったので、重みが内容を運んだ」）。家族の h を比べること
- 記憶ができた・内容を理解した・意味を持った、3 要素の順序・時間差を表した
- 0028・0029 の h と、0030 の h の違いから何かを結論すること

## 2. 本体と F の変種

### 2.1 自然な本体（同じ seed、同じ出生時の状態から 21）

| 本体 | 経験の札の列 |
|---|---|
| **O** | 試行 k（0〜199）の 3 つの枠（t_k、t_k ＋ 2、t_k ＋ 30）に A・B・C |
| **M** | 同じ枠に A・C・B |
| **W1〜W19** | i 番目は乱数の流れ `"0030-within-trial-<i>:<seed>"` を 1 本だけ使い、k ＝ 0, 1, …, 199 の順にリスト [A, B, C] をその流れで 1 回ずつ並べ替えて（`random.Random(名前).shuffle`）、(t_k, t_k ＋ 2, t_k ＋ 30) に置く（0025・0027・0028・0029 と同じ作り方） |

経験は Pulse 1〜12000。最後の刺激は 11971（最後の試行の C の枠）。12001 以後はどの本体にも外からの入力はない（可塑性あり）。各本体を 25500 まで進める。

### 2.2 可塑性を止める時刻 T_0（個体ごとに 1 つ）

```text
T_0 ＝ max{ t ∈ [11972, 12000] ： Pulse t に、自然な 21 本体のどれでも、どの Unit も発火していない }
       （11972 ＝ 最後の刺激 11971 の次、12000 ＝ 経験の終わり。0026 の T と同じ規則・同じ窓）
```

- **理由**：T_0 の処理の終わりには、どの自然な本体にも次の Pulse に届く駆動が置かれておらず（発火がないため）、Delta もない。したがって全状態は「3 Unit の状態」と「接続の状態（重みと痕跡）」だけで、F 本体を、置かれた駆動の扱いなしに組み立てられる（担い手の整理 命題 2 の I4、0026 §2.2 と同じ理由）。T_0 は最後の刺激より後なので、T_0 より後にどの本体にも入力はない
- 窓は 0026 の T の窓と同じ式（最後の刺激の次〜経験の終わり、29 Pulse）で、**新しく選んだ値ではない**。「経験の後」は、最後の刺激より後の静かな時点から、と読む（担い手の設計 §4.3）
- T_0 は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる
- **T_0 がない個体**の扱いは §2.6

### 2.3 F 本体（T_0 がある個体で、自然な本体ごとに 1 つ。21）

自然な本体 b（O・M・W1〜W19）ごとに、F(b) を次のように作る。

| 項目 | F(b) |
|---|---|
| 設計図 | C0 の設計図から、s のあいだの 6 本の `plastic: true` だけを除き、6 本の `weight` を **b の T_0 の処理の終わりの重み**（接続の状態の weight の値のまま）にした変種（§2.4）。ほかの YAML の設定値と配線は C0 と同じ |
| 出生時の状態 | 自然な本体と同じ（同じ seed・同じ個体の名前の `parse_birth_state`） |
| 始まりの状態 | b の T_0 の処理の終わりの 3 Unit の状態（activity・順応・不応期の残り・発火の回数）を、公開の `import_state` で写す。接続の状態はない（可塑的な接続がない）。置かれた駆動・Delta はない |
| 進め方 | T_0 ＋ 1 から 25500 まで、外からの入力なし。**重みはずっと T_0 の値**（可塑性がない） |
| Pulse の番号 | 組み立てた個体は Pulse 0 から始まるので、組み立てた後の経過 e に対して、記録では **t ＝ T_0 ＋ e** の絶対の番号にそろえる（発火の時刻・全状態の pulse・駆動の成立の Pulse）。前提 P-τ（担い手の設計 命題 1：12001 以後の更新が状態だけで決まる）による。T_0 から 12000 までも入力はないので同じ |

- 比較は F 本体どうし（O・M・W のすべてに同じ操作）で、自己一致の効果（C2 の整理 命題 D）は入らない
- F(b) は、T_0 より後、b の最初の発火（どれかの Unit）の Pulse までは b と同じ軌道になる（重みが変わるのは発火のときだけなので）。その後は、b の重みが書き換わり、F(b) の重みは変わらないので、分かれうる

### 2.4 実装の制約（道具の段階で守る）

- **Core・正式な設計図・可塑性の規則は変えない**。可塑性の振幅（`amplitude_ratio`）を 0 にする設計図は読み込みで拒まれる（正の値が必要）ので使わない。変種は、C0 の設計図の YAML を読んだ値から、道具の側で 6 本の `plastic: true` を除き `weight` を替えた値を作り、`parse_neuroarchitecture` に渡す（ファイルは作らない）。可塑的でない接続の `weight` は有限の値なら受け付けられる（`yaml_config_source.py`）。0028 の V1 も、C0 から `plastic: true` を除いた設計図だった（重みは 0.005 の一定）
- Unit の状態の写しは、Core の公開の `GenericCognitiveUnit.import_state` だけで行う
- 可塑的でない接続の駆動の重みは、設計図の重みのまま一生変わらない（0028 の V1 の確認 `V1_s_to_s_drive_weights_all_0_005` と同じ性質）。F では、それが b の T_0 の重みであることを確かめる（§7）
- **組み立ての確認の本体 R(O)**（操作の確認だけ）：同じ組み立て方で、**可塑性を残したまま**（C0 の設計図のまま）O の T_0 の状態（Unit の状態と、接続の状態〔重みと痕跡〕のすべて）を写して T_0 ＋ 1 から 25500 まで進めた本体。自然な O の T_0 より後の発火と、13500・25500 の全状態に一致するはず。これで、組み立て直し・Pulse の番号のそろえ方・状態の写しが、可塑性を止めること以外に軌道を変えないことを、実物の runtime で確かめる（0029 の null_swap と同じ役割）

### 2.5 二つの家族の関係

- N^cnt は自然な本体だけを使う。F は F 本体だけを使う。二つの家族は同じ 20 個体・同じ自然な本体から作るので従属しうるが、組み合わせた主張をしないので扱わない（§5.3）
- 0029 の Wt は「W20 の背景に O（M）の重みの塊を入れたとき」の問いで、F は「O（M）自身の重みを固定したとき」、N^cnt は「自然な O（M）そのもの」の問い。三つは別の問いで、結果を組み合わせない（担い手の設計 §4.6 の組み合わせの注意）

### 2.6 T_0 がない個体の記録・確認・判定（事前に固定する）

T_0 があるかどうかは、自然な 21 本体の発火の列だけで決まる（§2.2）。**T_0 がないことは有効な結果**で、その個体（seed）は completed である。記録の欠け・操作の失敗ではない。

**raw の形**（個体ごとの raw。どちらの場合も同じ鍵を持つ。**raw には判定の量〔主の事象〕を書かない**：§7・§9）

| 欄 | T_0 がある | T_0 がない |
|---|---|---|
| `freeze.t0_exists` | `true` | `false` |
| `freeze.t0` | 整数（11972〜12000） | `null` |
| `freeze.window_witness` | `null` | 窓の 29 の Pulse の昇順の配列。要素は `{pulse, body, unit}`：その Pulse に発火した自然な本体と Unit のうち、本体を O・M・W1〜W19 の順、Unit を s1・s2・s3 の順に見て最初のもの |
| 自然な本体の `state_t0` | T_0 の終わりの全状態 | `null` |
| `f_bodies` | 21 本体（O・M・W1〜W19 の順） | 空の配列 `[]` |
| `control_bodies`（R(O)） | 1 本体 | 空の配列 `[]` |

- 自然な 21 本体のほかの記録は、T_0 があるときと同じに保存する
- 上の対応から外れた raw は、その個体の操作の確認の失敗（invalid）とする

**操作の確認**（§7）：確認ごとの結果を `pass`・`fail`・`not_applicable` で記録する。`not_applicable` は「この個体では定義されず、行わなかった」で、**失敗ではなく、invalid の理由にならない**。T_0 がない個体では、F に固有の確認（§7 の F の組み立て・F の重みの一定・F の最初の発火までの一致・組み立ての確認 R(O)）は `not_applicable`、ほかの確認は自然な本体だけで行い、T_0 の規則の確認は **T_0 がないことの証明**（窓のすべての Pulse で自然な本体のどれかに発火があり、`window_witness` の各要素が記録した発火の列と一致し、決めた順で最初のもの）になる。

**判定への数え方**：
- **F の家族**：T_0 がない個体は 20 個体の分母に残り、F の 4 つの事象をすべて「外にない」に数える（凍結とは別に記録する）
- **N^cnt の家族**：T_0 に依らない（自然な本体だけを使う）。**T_0 がない個体でも、N^cnt の 4 つの事象は、ほかの個体と同じに計算する**
- その個体は §9 の「20 個すべて completed の後に一度だけ集計」の completed に含む

**補助**（§6）：T_0 がない個体でも、自然な本体から決まる補助は記録する。F 本体から決まる補助は `null` とし、理由 `no_t0` を付ける。

**smoke**：T_0 の有無も現象の値として表に出さない（確認の結果は `fail`・`ok` だけ。0029 と同じ）

## 3. 量と、向きの根拠

### 3.1 定義（0028 §3.1 と同じ）

本体 X（自然な本体・F 本体のどれも）の発火の列から、主の区間 [S, E] ＝ [13501, 25500] について

```text
N_{X→Y} ＝ #{ t : S ≤ t ≤ E − 1, s_X(t) ＝ 1, s_Y(t ＋ 1) ＝ 1 }       （X ≠ Y。二つの発火がどちらも区間の中にある組だけ）
Δ_AB ＝ N_{A→B} − N_{B→A}、   Δ_AC ＝ N_{A→C} − N_{C→A}
D ＝ Δ_AB − Δ_AC
N_X ＝ #{ t : S ≤ t ≤ E, s_X(t) ＝ 1 }                                  （役 X の区間の中の発火の数）
```

- A・B・C は役（その個体で Receptor A・B・C を受ける Unit）
- 量の形の理由（時間差 1・向きの差・比を使わない・Δ_AB と D を別の判定にする）は 0028 §3.2 と同じ

### 3.2 F の向きの根拠

- 0028 §3.3 と同じ理論（絞り込み 命題 A・予想 C）から、O の T_0 の重みは w(A→B) の偏りを持ち、M の T_0 の重みは w(A→C) の偏りを持つと見込む。F はその重みを固定するので、**F(O) では Δ_AB と D が F(W) より大きく、F(M) では D が F(W) より小さい**と予測する
- **理論の保証ではない**：F(b) の軌道は、固定した重みと、T_0 の Unit の状態（位相・順応）で決まる。自然な本体の経験の後の書き換え（正のフィードバックなど）がないので、外れの大きさ・有無は自然な本体と違いうる。予測と逆の向きの外れは「外にない」と同じに扱い、補助に記録する

### 3.3 N^cnt の事象と、その上界の根拠（担い手の設計 命題 3）

**命題 3 (i)（編集の上界）**：同じ区間の二つの発火の列 X・Y について、𝒮 を区間の中の発火の時刻の集合、△ を対称差として

```text
|Δ_AB(X) − Δ_AB(Y)| ≤ |𝒮_A^X △ 𝒮_A^Y| ＋ |𝒮_B^X △ 𝒮_B^Y|
|D(X) − D(Y)|       ≤ 2|𝒮_A^X △ 𝒮_A^Y| ＋ |𝒮_B^X △ 𝒮_B^Y| ＋ |𝒮_C^X △ 𝒮_C^Y|
```

**命題 3 (ii)（「数だけの違い」の二つの形）**：(a) X の列が Y の列に発火を足す（除く）だけで得られる（共通の発火の時刻は動かない）、または (b) 条件付きの組の割合 q_{B|A}・q_{A|B}（D では q_{C|A}・q_{A|C} も）が同じまま数だけが違う、のどちらでも

```text
|Δ_AB(X) − Δ_AB(Y)| ≤ |N_A^X − N_A^Y| ＋ |N_B^X − N_B^Y|
|D(X) − D(Y)|       ≤ 2|N_A^X − N_A^Y| ＋ |N_B^X − N_B^Y| ＋ |N_C^X − N_C^Y|
```

（証明は担い手の設計 §3.3。(a) は (i) から、(b) は差を書き下して三角不等式と q ≤ 1 から。）

**N^cnt の事象**（担い手の設計 §3.3 (iii) を転記。参照は自然な W1〜W19、不等号はすべて厳密、ΔN_X は比べる二つの本体の N_X の差）：

```text
E_Ca^cnt ⇔ すべての i（1〜19）で  Δ_AB(O) − Δ_AB(W_i) ＞ |N_A(O) − N_A(W_i)| ＋ |N_B(O) − N_B(W_i)|
```

- **向きの根拠**：0028 §3.3 と同じ理論（O は Δ_AB・D が大きく、M は D が小さい）

## 4. 主の判定

### 4.1 個体ごとの事象

自然な本体の参照の集合を 𝒲 ＝ {W1, …, W19}、F 本体の参照の集合を F(𝒲) ＝ {F(W1), …, F(W19)} とする。

```text
F（一方向。T_0 がある個体）
  F の O の Δ_AB が上    ⇔  Δ_AB(F(O)) ＞ max_{d∈𝒲} Δ_AB(F(d))
  F の O が上            ⇔  D(F(O))    ＞ max_{d∈𝒲} D(F(d))
  F の M が下            ⇔  D(F(M))    ＜ min_{d∈𝒲} D(F(d))
  F の O と M が分かれる ⇔  F の O が上 かつ F の M が下

N^cnt（一方向。すべての個体。自然な本体）
  E_Ca^cnt・E_O^cnt・E_M^cnt・E_OM^cnt（§3.3）
```

- 不等号はすべて厳密。等号は「外にない」
- 判定に使う値がすべて等しい個体（凍結。F の J_Ca では F(O) と F(𝒲) の Δ_AB の 20 本、J_O では F(O) と F(𝒲) の D、J_M では F(M) と F(𝒲) の D、J_OM では F(O)・F(M)・F(𝒲) の D の 21 本）は「外にない」に数え、除外しない（A7）。N^cnt の凍結は、自然な本体の同じ値（0028 と同じ形）で定める（記録だけ。N^cnt の事象は、凍結した個体では右辺が 0 以上なので必ず「外にない」になる）
- T_0 がない個体は、F の 4 つの事象すべてで「外にない」（§2.6）。N^cnt はそのまま計算する
- 予測と逆の側の外れ（F の O の Δ_AB が下、F の O が下、F の M が上）は「外にない」と同じに扱い、記録する（§6）

### 4.2 判定（家族ごとに 4 つ）

| 家族 | 判定 | 統計 | 成立の条件 | 担い手の設計との対応 |
|---|---|---|---|---|
| **F** | **J_Ca^F** | h_Ca^F ＝ F の O の Δ_AB が上の個体の数 | **h ≥ 4** | Q3（C-a の形） |
| F | **J_O^F** | h_O^F ＝ F の O が上の個体の数 | **h ≥ 4** | Q3（C-b の O の側） |
| F | **J_M^F** | h_M^F ＝ F の M が下の個体の数 | **h ≥ 4** | Q3（C-b の M の側） |
| F | **J_OM^F** | h_OM^F ＝ F の O と M が分かれる個体の数 | **h ≥ 2** | Q3（内容に応じた逆向き） |
| **N^cnt** | **J_Ca^cnt** | h_Ca^cnt ＝ E_Ca^cnt の個体の数 | **h ≥ 4** | Q4 |

### 4.3 帰無仮説と、交換可能性が成り立つ条件

| 判定 | 帰無仮説（個体ごと） | 個体ごとの上側の確率 |
|---|---|---|
| J_Ca^F・J_O^F・J_M^F | F(O)（F(M)）は F(W1)〜F(W19) と交換可能（その量について） | **1／20 以下** |
| J_OM^F | F(O)・F(M)・F(W1)〜F(W19) の 21 が交換可能（D について） | **1／420 以下** |
| J_Ca^cnt・J_O^cnt・J_M^cnt | 0028 と同じ：自然な O（M）の量は W1〜W19 の量と交換可能 | **1／20 以下**（E^cnt は 0028 の事象の部分集合：§4.4） |
| J_OM^cnt | 0028 と同じ：自然な O・M・W1〜W19 の D の 21 が交換可能 | **1／420 以下** |

**交換可能性が成り立つ条件と、成り立たない場合**（0028 §4.2 の 1〜7 を引き継ぐ）
1. W1〜W19 は同じ手順・別々の名前の乱数の流れから作った列で、互いに交換可能とみなす（乱数の流れの独立性は統計モデル上の前提）。**21 の交換可能性は、実際の生成の手順が保証する性質ではない**
2. O・M は W の作り方から生じた列ではない。帰無仮説は「O（M）は典型的な W と区別できない」という仮説で、確かめた性質ではない
3. 同じ値（引き分け）があると、厳密な不等号の事象の確率は上の値**以下**になる
4. **帰無仮説が内容と無関係に破れうる場合**：O・M の規則性（毎試行同じ並べ方）が、内容と無関係に O・M を W と違わせることはありうる。J_OM は同じ個体で O と M が逆の向きに外れることを求めるので、同じ向きに動かす違いでは起こりにくいが、内容以外の説明を論理的に排除しない
5. J_OM の帰無仮説は、J_O・J_M の帰無仮説のそれぞれより強い
6. **個体をまたぐ独立性**：出生時の状態と並べ替えの乱数の流れを、個体間で独立とみなす（統計モデル上の前提。異なる seed であることから従う性質ではない）
7. **判定のあいだの従属**：家族の中の 4 つの判定は同じ本体を共有し、従属する。家族の誤りの水準は、独立性を使わない Bonferroni の上界で抑える（§5）。F と N^cnt の二つの家族も同じ自然な本体から作り、従属するが、組み合わせた主張をしないので扱わない

### 4.4 N^cnt の事象が 0028 の事象の部分集合であること【命題】

§3.3 の右辺はどれも 0 以上なので

```text
E_Ca^cnt ⇒ すべての i で Δ_AB(O) ＞ Δ_AB(W_i) ⇔ Δ_AB(O) ＞ max_i Δ_AB(W_i)     （0028 の O_Delta_AB_above）
E_O^cnt  ⇒ D(O) ＞ max_i D(W_i)、 E_M^cnt ⇒ D(M) ＜ min_i D(W_i)、 E_OM^cnt ⇒ 0028 の O_and_M_split
```

したがって、0028 と同じ交換可能性の帰無仮説のもとで、E^cnt の個体ごとの確率は 0028 の事象の確率以下（1／20 以下、E_OM^cnt は 1／420 以下）で、閾値（4・4・4・2）も変わらない。事象を厳しくした分、検出力は下がりうる（担い手の設計 §3.3 (iii)）。

## 5. 閾値と、家族の誤りの水準

### 5.1 各家族

- **各家族の水準 0.05**。重みつきの Bonferroni で、**J_Ca・J_O・J_M に 0.016 ずつ、J_OM に 0.002**（0028・0029 の Wt と同じ割り当て）

- J_OM：P(h ≥ 2) ≤ P(Bin(20, 1／420) ≥ 2) ≈ **0.001047** ≤ 0.002（h ≥ 1 では ≈ 0.046557）。閾値 2
- 閾値は、割り当てた水準と個体ごとの帰無の確率（K ＝ 19・一方向）から決まる最小の整数。結果を見る前に決めたもので、データからは選んでいない。**0029 の結果（Wt の成立・U の不成立・凍結の多さ）に合わせて変えていない**

### 5.2 全体の扱い

- **二つの家族は別の問いに答える**。家族ごとに水準を抑え、**二つの家族の結果を組み合わせた検定的な主張はしない**
- **実験全体（8 判定）で誤りの水準 0.05 とは主張しない**。単純な和の上界は 0.10
- 成立は、上の前提のもとで帰無仮説を各判定の水準で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- 家族の中・家族のあいだで、判定の成立を足し合わせたり、h を比べたりしない
