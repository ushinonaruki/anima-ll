## 0. 問いと主張の範囲

### 0.1 問い

> **同じ出生時の状態から、刺激の時刻と数は同じで並べ方だけが違う経験を経た自然な個体（状態を入れ替えない）のうち、順序のある経験（O）の個体は、同じ試し（A の入力）に対して、ランダムな並べ方の経験（S_1〜S_19）の個体の分布の中で典型的でない応答を示すか**

- MF3（順序）の現象 ① の **L2**（違いがあること）を、**自然な状態への試し（O-P）**で問う（研究④ §1.4）
- これまでの O-P の検証は 0012 の H1（fails 8／20）だけで、0014 の as_is は判定のない記録だった。介入（O-I）では、重みの差が試しへの応答を変えうることが示されている（0014 の p、0016〜0019）

### 0.2 主張の形（成立したとき）

「この世界・この設計図・この規則・この試しの区間のもとで、順序のある経験の後の自然な状態は、試しの入力 A が B・C の次の発火の時刻を動かす効果を、並べ方をランダムにした経験の参照分布では典型的でない形で示した（向きを問わない）。その頻度は、O が並べ替えと交換可能であるという帰無仮説のもとで期待される頻度より多かった」

### 0.3 主張しないこと

- 違いを重み（あるいは順応・痕跡・位相のどれか）が運んだ（機構 ③。§12 の後の段で別に調べる）
- 経験した順序に対応した（L3）。向きのある主張は補助の記録で、主の不成立を救わない
- 自発に現れた（O-N）、内容を思い出した、記憶した
- 規則性によらない順序の効果（鏡の条件 M でも、Unit の役に依存しない単純な規則性しか除けない。設計の整理 §2.3）
- 不成立のとき：働きの不在、C0 の構造の限界、重みが効かない（研究④の命題 2・3）

## 3. 試し（対にした試し。設計の整理 §3.1）

### 3.1 手順

各本体 X と、各試しの時刻 t0 ∈ {12001, …, 12300}（毎 Pulse、300 回。0014 と同じ区間）について：

```text
本体 X の t0 − 1 の処理の終わり
   ↓ 複製
A の複製：t0 に Receptor A の出来事を 1 つ入れ、t0 ＋ 1 ＋ T_w まで進める（可塑性あり）
空の側：本体 X そのもの（12001 以後は入力がないので、t0 − 1 から入力なしで進めた複製と同じ）
```

- **空の側に本体を使う理由**：決定論的な個体で、本体は t0 − 1 の状態から入力なしで進むので、入力なしの複製と全く同じ軌道をとる（状態の十分性）。計算を半分にする。これが成り立つことは、各本体の最初と最後の試しで入力なしの複製を実際に作り、本体と一致することで確かめる（§7）
- **複製が本体を変えないこと**：O の本体と、試しの複製を一度も作らない O の双子を 12601 まで進め、全発火・終わりの状態が一致することで確かめる（§7）
- 本体は 12300 ＋ 1 ＋ T_w ＝ 12601 まで進める
- 窓の長さ **T_w ＝ 300 Pulse**（＝ adaptation_tau ÷ pulse_interval_seconds。0014 の試しの区間と同じ導き方。C1・C2）

### 3.2 窓と最初の発火

- 試し t0 の窓：**[t0 ＋ 2, t0 ＋ 1 ＋ T_w]**（T_w 個の Pulse）。t0 ＋ 1 までは、A の複製と本体で B・C の状態と発火が同じ（命題 3 の前提。§7 で確かめる）ので、t0 ＋ 2 から数える
- n_X^A(t0)：A の複製で、Unit X（B または C）が窓の中で最初に発火した Pulse。窓の中で発火しなければ **t0 ＋ 2 ＋ T_w**（窓の 1 つ先。打ち切りの値）
- n_X^∅(t0)：本体で同じ量（打ち切りも同じ）
- 打ち切りの数（A の複製・本体それぞれ、B・C それぞれ）を全件記録する

## 4. 読み出しの量

### 4.1 主の量（R2：対にした前倒しの、B と C の差）

```text
ℓ_X(t0) ＝ n_X^∅(t0) − n_X^A(t0)                （X ＝ B, C。試しが X の最初の発火を何 Pulse 前に寄せたか。−T_w〜＋T_w）
L(本体)  ＝ mean_{t0 ＝ 12001..12300} [ ℓ_B(t0) − ℓ_C(t0) ]
```

- 両方の側で打ち切りなら ℓ ＝ 0（ふつうの算術。A3）
- 向きは構造上決まっていない（設計の整理 §3.2：t0 ＋ 3 以後は、試しの A の発火が A 自身の後の発火を変えるので単調性の議論が使えない）。主の評価は向きを問わない（§5）

### 4.2 補助の量（記録。判定に使わない）

## 5. 主の評価

### 5.1 個体ごと：O が並べ替えの参照分布の外にあるか

各個体（seed）で、20 個の値 L(O)、L(S_1)、…、L(S_19) を比べる。

```text
O が外にある  ⇔  L(O) ＞ max_i L(S_i)   または   L(O) ＜ min_i L(S_i)    （どちらも厳密な不等号）
```

- **向きを問わない**（L2）。等号（並べ替えのどれかと同じ値）は「外にない」に数える
- なぜこの形か（A6）：問い（O がランダムな並べ方の分布の中で典型的でないか）を、追加の尺度（中央値・距離・正規化）を持ち込まずに書ける最も単純な形。並べ替えどうしは同じ出生時の状態から独立な乱数の流れで作るので互いに交換可能であり、O もそれらと交換可能という帰無仮説のもとで、O が両端のどちらかにある確率は、値に同じものがなければ 2／20 ＝ 0.1、同じ値があれば 0.1 以下になる
- 同じくらいもっともらしい別の形（中央値からの距離の順位、片側の順位など）は主にしない。上の形の構成量（L(O) の順位、20 個の値の全件）はすべて記録する

### 5.2 個体をまたぐ判定

- h ＝ O が外にある個体の数（20 個体のうち）
- **判定**：**h ≥ 5 なら成立（holds）、h ≤ 4 なら不成立（fails）**
- 根拠：帰無仮説「どの個体でも、L(O) は L(S_1)〜L(S_19) と交換可能」のもとで、各個体で O が外にある確率は 0.1 以下である。さらに、**個体のあいだの独立性を、統計モデル上の前提として置く**（出生時の状態と並べ替えの乱数の流れが個体ごとに独立に生成されたとみなす。異なる seed を使うことから数学的に従うものではない）。この前提のもとで、h は二項分布 Bin(20, 0.1) 以下に従い、P(h ≥ 5) ＝ 0.0432（Bin(20, 0.1)）で、水準 0.05 以下になる最小の h が 5
- **h ≥ 5 で成立とすることは、「全個体での交換可能性」という帰無仮説を、上の前提のもとで水準 0.05 で棄却すること**であって、交換可能性の破れを数学的に証明したことではない
- **交換可能性は帰無仮説の置き方であって、O について保証された性質ではない**（設計の整理 §2.2）。O は特定の構造を持つ 1 つの並べ方で、ランダムに引いたものではない
- 成立が言うのは「少なくとも一部の個体で、O が並べ替えと交換可能でない」までで、**すべての個体で、または大多数の個体で外にある**とは言わない
- 補助記録（判定に使わない。常設チェック D6）：h／20 の Clopper–Pearson の 95% 区間。この区間は、各個体の「外にある」が独立で同じ確率の試行であるという通常の二項モデルの前提に依る参考値で、母集団の割合の主張には使わない

## 7. 操作の確認（知見ではない。常設チェック D1）

保存した生の記録から再検証する（D2）。

**invalid の扱い**：指定した 20 個体のどれか 1 つでも、下の必須の確認が 1 つでも成り立たなければ、**実験全体を invalid とし、h による holds／fails の判定をしない**。invalid の個体を「外にない」に数えない（道具の不備による無効な測定と、正しく測って O が外れなかったことは違う）。このとき判定の量（L・外にあるか・h・補助の量）は計算も表示もしない（D2）。失敗した個体を含むすべての生の記録と、どの確認が成り立たなかったかを保持・報告し、開示したうえで、新しい事前登録・新しい seed の範囲で行う

**厳密に一致すべきもの**：

| 確認 | 内容 |
|---|---|
| 刺激の札 | 各条件で A・B・C が 200 ずつ、時刻の集合が O と同じ。M は O の B と C を入れ替えたもの。並べ替え 19 本の乱数の流れの名前が protocol どおり |
| 入力なし | 12001 以後、どの本体にも Receptor の出来事がない |
| 札が分かれる前の一致 | 同じ seed の 21 本体は、札が最初に違う Pulse の前まで全状態が一致 |
| 複製の確認 | 各試しの A の複製の t0 − 1 の終わりの全状態が、本体の同じ時点と一致 |
| t0 ＋ 1 までの一致 | A の複製と本体で、t0 ＋ 1 の終わりまで B・C の activity・順応と発火が一致。t0 の終わりの重み・痕跡が一致 |
| **命題 3** | すべての試しで B^A(t0 ＋ 2) ≥ B^∅(t0 ＋ 2)、C も同じ（設計の整理 §3.2 の命題 3。実装が正しければ必ず成り立つ。知見ではない） |
| 空の側の同一性 | 各本体の最初と最後の試し（12001・12300）で入力なしの複製を作り、窓の終わりまで本体と全発火・全状態が一致 |
| 双子 | O の本体と、試しの複製を作らない O の双子が、12601 まで全発火・終わりの状態で一致 |
| 打ち切りの算術 | ℓ・N・打ち切りの数を、保存した発火の記録から再計算して一致 |
| 切り詰めなし | どの本体・複製の重みも [0, w_max] の外に出ない |

**数値の許容誤差**（絶対値。0020〜0022 の 1e-12 を継承）：12000 の重みの再生（発火の記録から Pulse 1 から再生）、組の和 w(i→j) ＋ w(j→i) ＝ w_max（本体、12000・12601）

- 判定の量（L、O が外にあるか、h）・打ち切りの多さ・発火したかどうかは、操作の確認に入れない（D1）

## 8. 記録（保存した生の記録から独立に再計算・再検証できる形で）

ここでの**全状態**は、3 Unit の activity・順応、6 本の重み、接続ごとの 2 つの痕跡、次の Pulse に届く駆動を、実装の内部表現のまま（丸めずに）書き出したものをいう。要約やハッシュだけでは §7 の一致を生の記録から再検証できないので、**比較に使う状態は値そのものを保存する**。

- 各個体・各本体（21）：出生時の状態、経験の札の列、**1〜12601 の全発火**（3 Unit）、12000 の全状態、**11999（最初の試しの複製の元）から 12601 までの各 Pulse の終わりの全状態**
- 各試し（各本体 300 回）：A の複製の**t0 − 1 の終わり（複製の直後）・t0 の終わり・t0 ＋ 1 の終わりの全状態**、窓 [t0, t0 ＋ 1 ＋ T_w] の全発火（3 Unit）、窓の終わりの全状態
- 空の側の確認の複製（各本体 2 回）：窓の終わりまでの全発火と各 Pulse の終わりの全状態
- O の双子：1〜12601 の全発火と、12000・12601 の全状態

  1. 各 seed の実行の前に、その seed の**開始の記録**（seed・測定の commit・protocol のハッシュ・時刻）を排他的に作る。開始の記録がある seed は、終了の記録の有無にかかわらず**再実行を拒否**する
  2. 各 seed の実行の後に、**終了の記録**（seed・状態・終了の時刻・その seed の生の記録のファイルの SHA-256 とバイト数）を作る

  4. この決まりは道具の段階で契約テストに入れる

### 15.5 読むときの注意（記述。判定を変えない）

1. **判定の余裕は小さい**：h ＝ 6 で、閾値 5 を 1 だけ上回った
2. **16014 は参照分布が退化していた**：並べ替え 19 本と M の 20 本体では、すべての試しで B・C とも窓の中で一度も発火せず（両方の側で打ち切り）、L はすべて 0 だった。O の本体だけは B が一部の試しで窓の中で発火し（打ち切り：A の側 226／300、空の側 235／300）、L(O) ＝ 97/75 となった。§5.1 の規則（厳密な不等号。凍結は O と並べ替えの 20 個がすべて等しいときだけ）どおり「外にある」に数えた。この個体では、並べ替えの本体には試しが最初の発火を動かす余地がそもそもなく、O の外れには、窓の中で B が発火するかどうか（本体の自発の活動の違い）が含まれる。§10 の A4 のとおり、これも主の L2 の現象の一部で、担い手は主張しない。**登録した判定ではないが、余裕を示すために書くと、仮にこの個体を外にないと数えれば h ＝ 5 で閾値ちょうどになる**（この数え方は判定に使わない）
