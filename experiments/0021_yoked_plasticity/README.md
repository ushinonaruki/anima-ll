## 0. 問いと主張の範囲

**問い**：0017／0020 と同じ移植で接続に差を植えたあと、**可塑性の更新に使う発火の列を、自分の発火から control の発火に置き換えると**、その後の離散的な発火の列に差が生じるか。

- この実験は **可塑性を止める実験ではない**。I は自分の発火の列で可塑性を更新し、Y は control（C）の発火の列で可塑性を更新する。Y の重みも変わり続ける。問うのは「**自分の発火に依存する可塑性**」を「**control の発火の列による外から与えた可塑性**」に置き換えた効果
- したがって、結果を「すべての可塑性を除いた効果」や「自然な個体の中の媒介の効果」と混同しない
- **主な因果の観測は、I と Y の発火の列の違い**（t2 の有無・時刻・Unit と、その後の違い。§5）
- P・F・D の代数の恒等式と、設計から決まる性質（t2 ≥ t1 ＋ 2 など）は **操作の確認** で、成功の判定にしない（メモ §5.4）
- 集団の holds／fails、0.8 の合格基準、方向の事前予想、Clopper–Pearson の区間は置かない。結果の割合を母集団の性質とは呼ばない

**言わないこと**（§8 にもまとめる）：記憶、再活性化、「活動が経験を保持した」、自然な媒介の経路、24000 より先、t2 がないことを「効果が永久にない」と読むこと。

## 2. 手順

```text
ordered・shuffled を 0020 と同じく経験させる（1〜12000。刺激の列は "0021-shuffle:<seed>"）
shuffled は 12000 まで（donor の値を取るためだけ。24000 まで進めない）
Pulse 12000（＝ t0）の可塑性の更新の終わり ＝ 12001 の重みの固定の前に分ける：
   ├─ C    ：ordered の本体そのもの
   ├─ I    ：C の複製。w(A→B)・w(A→C)・w(B→A)・w(C→A) を shuffled の 12000 の値に置き換える（0017／0020 と同じ移植）
   ├─ Y    ：I の複製（Unit の状態・重み・痕跡・12001 に届く駆動まで同じ）
   ├─ twin ：C の複製（何も変えない。確認用）
   └─ Y0   ：C の複製（何も変えない。確認用）
12001〜24000（＝ W）：5 つの腕を、入力なしで 1 Pulse ずつ並べて進める
```

**各腕の規則**：

| 腕 | 活動・伝達に使う重み | 可塑性の更新（発火の出来事と痕跡） | 役割 |
|---|---|---|---|
| C | 自分 | 自分の発火 | 基準 |
| I | 自分 | 自分の発火 | 自分の発火が可塑性に返る |
| **Y** | 自分 | **全 6 接続で、同じ Pulse の C の発火** | 可塑性の入力を C の列に置き換える |
| twin | 自分 | 自分の発火 | 複製の確認 |
| **Y0** | 自分 | 同じ Pulse の C の発火 | yoke の仕組みの確認（重みの差 0 なので C と完全に一致するはず） |

- Y・Y0 の Unit の状態（activity・順応）は自分の発火で進む（可塑性ではない）
- Y・Y0 の痕跡は C の発火で更新されるので、どの Pulse でも C の痕跡と一致する（メモ §5.3。発火の出来事だけ C にして痕跡を自分の発火で更新すると、恒等式が成り立たない混ざった腕になる）
- 全 6 接続を yoke する（メモ §5.7）。対象の 4 接続だけにすると、B–C の組を通る自分の発火 → 可塑性の経路が Y に残り、断ったものを一言で言えなくなる

**各 Pulse t（W の中）の処理の順序**：

```text
1. C   ：run_pulse(t)。冒頭で w_C(t−1) を固定 → Unit → 駆動（次の Pulse へ）→ 終わりに F_C(t) で可塑性
2. I   ：run_pulse(t)。自分の w_I(t−1)。終わりに F_I(t) で可塑性
3. Y   ：run_pulse(t)。自分の w_Y(t−1) で Unit・駆動。終わりの可塑性だけ、渡された F_Y(t) を使わず 1 の F_C(t) で更新
4. twin：run_pulse(t)（自分）
5. Y0  ：run_pulse(t)。終わりの可塑性を F_C(t) で更新
```

（F_X(t) は腕 X で Pulse t に発火した Unit の集合。Y・Y0 に渡す F_C(t) は Pulse 番号が t で一致することを確かめる。）

- C は他の腕から何も受け取らない。Y・Y0 が受け取るのは、同じ Pulse の C の発火の集合だけ
- Y の Unit の判定は w_Y(t−1) だけで決まり、同じ Pulse の C の発火に依らない（C の発火が効くのは、Y の t の終わりの可塑性だけ）
- 置き換えは実験の道具の中だけで行う（Y・Y0 の接続の状態に渡す発火の集合を C のものに差し替える薄い包み）。Runtime の本体は変えない

## 3. 規則の性質（観測の量の土台）

### 3.1 メモから使うもの

- 1 Pulse の順序・介入の境界（t0 ＋ 1 に届く駆動は置き換えの前の重み。差が入り始めるのは t0 ＋ 2）、不応期 0：メモ §1
- 切り詰めなしと [0, w_max] の不変性（P0）、組の和（F1）、差の届き方（F2）、同じ列の区画（F3）、共通の列のあいだの縮小（F4）：メモ §2
- t1 の差の分解（C と I）：メモ F3c。C と I は t1 − 1 まで列が共通で、どちらも **自分の列 ＝ 共通の列** で可塑性を更新するので、共通の Φ_C で初めの差を運ぶ形が成り立つ
- 3 つの腕の恒等式 P ＝ Y − C ＝ Φ_C·δω、F ＝ I − Y、D ＝ I − C ＝ P ＋ F と、t2 ≥ t1 ＋ 2：メモ §5.4（操作の確認に使う）

### 3.2 t2 の差の接続ごとの寄与（この実験のための導出）

**メモ F3c はそのまま使えない**：I と Y は t1 のあと、発火の列が同じでも、可塑性の更新に使う列が違う（I は自分 ＝ 共通の列、Y は C の列）。したがって I と Y の重みの差は「共通の Φ × 初めの差」の形にならない（初めの差は 0 で、差は t1 の終わりから可塑性の入力の違いで生まれる）。そこで、**各 Pulse で実際に違う接続の重み** を使う差分方程式から導く。

**前提**：
1. I と Y は t0 で全状態が同じ（Y は I の複製。t0 ＋ 1 に届く駆動まで同じ）
2. 不応期 0（メモ §1）
3. W の間、感覚の入力はない（両腕で同じ）
4. Delta・Kernel は活動を駆動しない（c2。この世界の Unit は relay だけ）
5. t2 の定義により、I と Y の発火の列は t0 ＋ 1〜t2 − 1 で共通（以下 s(k) と書く）

**I と Y の重みが分かれる時刻**：t ≤ t1 − 1 では F_I(t) ＝ F_C(t)（t1 の定義）なので、I と Y の可塑性の入力は同じで、重み・痕跡は同じ（Δw(m) ＝ 0、m ≤ t1 − 1。Δ は I − Y）。t1 の終わりに、I は F_I(t1) で、Y は F_C(t1)（≠ F_I(t1)）で更新するので、Δw(t1) は 0 でなくなりうる。

**伝達の遅れ**：Pulse m の終わりの重みは、m ＋ 1 に作る駆動に使われ、その駆動は m ＋ 2 に届く。したがって Δw(k − 2) が受け手に入るのは Pulse k で、**k ≥ t1 ＋ 2**。よって t ≤ t1 ＋ 1 では I と Y の activity は同じで、**t2 ≥ t1 ＋ 2**（メモ §5.4 と一致）。

**差分方程式**：Unit j について、t ≤ t2 で

```text
Δu_j(t)  = Σ_i Δw_ij(t−2) · s_i(t−1)                 （s_i(t−1) は共通の列。t ≤ t2 なので t−1 ≤ t2−1）
Δã_j(t)  = λ · Δa_j(t−1) + Δu_j(t)                   （c_j は共通で消える）
Δa_j(t)  = Δã_j(t)   （j が t に発火しない）
         = 0         （j が t に発火する：両腕でリセット。t ≤ t2 − 1 では発火は共通）
```

実効の閾値 θ_j ＋ h̃_j(t) は自分の発火の列だけで決まるので、t2 まで I と Y で同じ。

**t2 での寄与**：r_j を、t2 より前に j が（共通の列で）最後に発火した Pulse とする（なければ t0）。上を解くと

```text
Δã_j(t2) = Σ_i K_ij(t2)
K_ij(t2) = Σ_{k = max(r_j + 1, t1 + 2)}^{t2} λ^(t2 − k) · Δw_ij(k − 2) · s_i(k − 1)
Δw_ij(m) = w^I_ij(m) − w^Y_ij(m)                      （実際の重み。m ≤ t1 − 1 では 0）
```

- 和の下限 max(r_j ＋ 1, t1 ＋ 2)：r_j のリセットでそれ以前の差は消える（メモ F2 の b）。k ≤ t1 ＋ 1 の項は Δw(k − 2) ＝ 0
- この式は **affine の仮定を使わない**（実際の重みの差をそのまま使う）。P0 のもとでは Δw_ij(m) ＝ F_ij(m) ＝ (Φ_I,ij(m) − Φ_C,ij(m))·ω_I,ij ＋ (ψ_I,ij(m) − ψ_C,ij(m)) と書けるが、K の計算には要らない
- Δw_ij(m) は時間とともに符号・大きさが変わりうる（メモ F4 の「縮むだけ」は成り立たない。可塑性の入力が違うため）
- j ∈ U2 で I が発火し Y が発火しなかったなら Δã_j(t2) ＞ 0、逆なら ＜ 0（閾値が同じなので）
- 寄与があるのは、窓 [max(r_j, t1 ＋ 1), t2 − 1] で発火した送り手 i だけ

**K の読み方（記述だけ）**：K_ij(t2) は、t2 の activity の差を、共通の列の上で接続ごとに正確に分けたもの。ある接続の K を 0 にした腕は実際には走らせていないので、**その接続の差が「必要だったか」は K からは言えない**（メモ F3c の限界と同じ）。K は副の記録で、因果の主張には使わない。

**確認**：Σ_i K_ij(t2) が、t2 − 1 の状態から再構成した ã_j^I(t2) − ã_j^Y(t2) と許容の範囲で一致すること（§6）。

## 5. 観測（個体ごとに記述。判定なし）

### 5.1 主（因果の観測）

| 量 | 定義 |
|---|---|
| t1・U1 | t1 ＝ min{t ∈ W : F_C(t) ≠ F_I(t)}（なければ none）。U1 は F_C(t1) と F_I(t1) の対称差の Unit と、どちらの腕で発火したか |
| **t2・U2** | t2 ＝ min{t ∈ W : F_I(t) ≠ F_Y(t)}（なければ none ＝ 窓の中で未検出）。U2 も同様 |
| t2 − t1 | 記述（下限 2 は設計から決まる） |
| T − t1 | **t1 から終端までの残り Pulse 数**（記述。除外には使わない）。t2 を検出できる Pulse（t1 ＋ 2〜T、§3.2 の下限）の個数は **max(0, T − t1 − 1)** で、T − t1 とは 1 違う |
| 全発火の列 | C・I・Y |
| Unit ごとの発火数 | C・I・Y の W 全体。I・Y の t2〜T（t2 を含む） |
| 発火の集合が違う Pulse の数 | I と Y（N_IY）、C と I（N_CI）、C と Y（N_CY）。W 全体で数える（I と Y は t2 より前は違わないので、N_IY は t2〜T の数） |

- 同じ Pulse に複数の Unit が違う場合は、すべてを U に入れる（順位を付けない）
- **読み方**：I と Y は t0 で同じ状態から始まり、違うのは可塑性の更新に使う発火の列（自分か C か）だけ。系は決定論なので、**I と Y の列の違いは、この置き換えが後の発火に生んだ個体ごとの因果的な違い**（標本の揺らぎはない）
- **t2 なし** は「この観測の窓では発火の違いが現れなかった」とだけ記録する。効果が永久にないとは解釈しない。t1 が遅く、t2 を検出できる Pulse の個数（max(0, T − t1 − 1)）が少ない個体も除外しない

### 5.2 副（記述。新しい知見の主張には使わない）

- **t2 の寄与 K_ij(t2)**（§3.2）：j ∈ U2、送り手 i ごと
- **t1 の寄与**（メモ F3c）：j ∈ U1、送り手 i ごと
- **P・F・D**（T、全 6 接続）：P ＝ w_Y − w_C、F ＝ w_I − w_Y、D ＝ w_I − w_C の値と大きさ。向きの関係は、P と F（同じ向き／逆向き／片方が 0／両方 0）、D と P（同じ向き／反転／片方が 0／両方 0）に分け、**0 を向きの一致に数えない**。A→B と A→C は別々に。W ＝ w(A→B) − w(A→C) は 2 本の差として記録し、単一の S を仮定しない。比（旧案の G）は使わない
- F の値そのものは I と C の列から計算できる量で、Y を走らせて初めて分かるものではない（メモ §5.4）
- C と Y の t1 のあとの列（植えた差が受け身に持ち越されるだけのときの活動）

**データの完全性・実行の記録**：experiment ＝ 0021・kind ＝ preregistered_descriptive_intervention・mode の一致、40 桁の commit、protocol・設計図の一致、個体が 1 つ以上、seed の重複なし、meta の seed の列と実データの一致、本番では 14001〜14100 の全件・確認では 14101〜14200 だけ。開始・終了の記録の一致（§7.1）。

## 8. 言わないこと

- 可塑性を止めた効果、すべての可塑性を除いた効果とは言わない（Y の重みも変わり続ける）
- 自然な個体の中の媒介の経路を分離したとは言わない（Y は人工的な操作）
- t2 がないことを「効果が永久にない」と言わない。窓の外（24000 より先）について言わない
- K・t1 の寄与から、特定の接続の差が「必要だった」とは言わない
- P・F・D の恒等式や t2 ≥ t1 ＋ 2 を、結果や成功の証拠として書かない
- 結果の割合を母集団の性質と呼ばない
- 「記憶」「再活性化」「活動が経験を保持した」とは言わない
