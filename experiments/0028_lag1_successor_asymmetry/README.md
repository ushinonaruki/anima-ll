## 3. 量と、向きの根拠

### 3.1 定義

本体の発火の列 s_X(t)（Unit X が Pulse t に発火したら 1）から、区間 [S, E] について

```text
N_{X→Y} ＝ #{ t : S ≤ t ≤ E − 1, s_X(t) ＝ 1, s_Y(t ＋ 1) ＝ 1 }       （X ≠ Y。二つの発火がどちらも区間の中にある組だけ）
Δ_AB ＝ N_{A→B} − N_{B→A}、   Δ_AC ＝ N_{A→C} − N_{C→A}
D ＝ Δ_AB − Δ_AC
```

- A・B・C は役（その個体で Receptor A・B・C を受ける Unit）。主の量は主の区間 [13501, 25500] の Δ_AB と D
- 同じ Pulse の発火の組（時間差 0）と、時間差 2 以上の組は数えない

### 3.2 なぜこの形か（常設チェック A6）

| 選択 | 理由 |
|---|---|
| **時間差 1** | 直接一段の伝達の遅れは 1 Pulse で（理論のメモ §4.6）、送り手の駆動が受け手をその Pulse に発火させるのは、届いた Pulse である（命題 4.4・系 4.4a）。重みに書かれた向きが直接一段の伝達として現れるなら、時間差 1 の組の向きに現れる（絞り込み 予想 C）。ほかの時間差は、遅れた発火・複数の経路・位相から生じ、規則を事前に導けていない（絞り込み D-4） |
| **向きの差 N_{A→B} − N_{B→A}** | 組の和の保存（w_AB ＋ w_BA ＝ w_max）により、組ごとの重みの自由度は向きの 1 つ（w_AB − w_BA ＝ 2w_AB − w_max）。それに対応する観測は、二つの向きの組の数の差である。比（割り算）は、分母が 0 になりうることと正規化の選び方が新しい自由度になるので使わない |
| **Δ_AB（C-a）と D ＝ Δ_AB − Δ_AC（C-b）を別々の判定にする** | Δ_AB は、理論が直接予測する量（w(A→B) の偏り → A → B の組の向き）で、絞り込みの C-a そのもの。D は、B と C を入れ替えると符号が反転する**対比**で、O と M で予測の向きが入れ替わる（C-b）。二つは同じ事象ではない（例：O で Δ_AB が W より大きくても、Δ_AC も同じように大きければ D は外れない。逆に Δ_AC が小さくなるだけでも D は大きくなりうる）ので、別の判定として置く。**D の差で相殺されるのは、二つの Δ に加法的に全く同じ量が加わる場合だけ**である。A の発火の数が増えて N_{A→B}・N_{A→C} がそれぞれの割合で増える場合（例：E[N_{A→B}] ≈ N_A·p_B なら、D の順向きの部分は N_A(p_B − p_C) で、A の発火の数とともに大きくなる）や、逆向きの組の違い、一般の発火の数・位相の違いは相殺されない。D の利点は、B・C の入れ替えで符号が反転することと、結果の前に向きを固定できることで、**発火の数への耐性ではない** |
| **数の合計（区間の長さで割らない）** | どの本体も同じ区間の長さなので、割っても順位は変わらない（判定は順位だけで決まる） |

同じくらいもっともらしい別の形（時間差 1〜k の重みつきの和、率、正規化した非対称）は、主の判定にしない。構成量（6 つの N と各 Unit の発火の数）を補助として記録する（§5）。

### 3.3 向きの予測の根拠（絞り込み §2.1・§2.3。理論の保証ではない）

- **理想化した発火列の解析**（絞り込み 命題 A、前提 E1〜E3）：O の経験は w(A→B) を出生時の 0.005 から 0.00909 へ大きく動かし、w(A→C) はほとんど動かさない（＋4.4 × 10⁻⁷）。M では役割が入れ替わる（w(A→C) が 0.00909）。W では、どの組も期待値の上で偏らない
- **予想 C（条件付き：Q1〜Q3）**：Δ_AB は w(A→B) が大きいほど大きくなると見込める。組の和により、逆向きの組の数は w(A→B) とともに減る方向に効く
- したがって、**O では Δ_AB が W より大きく（C-a）、D も W より大きい（Δ_AC は W と同じ程度）。M では D が W より小さい（Δ_AC が大きい）**と予測する
- この予測は、実際の個体での自発の発火・誘発の欠け（命題 A の外）、位相の引き込み、発火の数、沈黙、C を経る経路で外れうる（絞り込み §2.3）。**向きは理論から固定したもので、成り立つかは試すまで分からない**

## 4. 主の判定

### 4.1 C0 の家族：四つの判定

個体ごとに、C0 の 21 本体の主の区間の Δ_AB と D を計算する。

```text
O の Δ_AB が上にある  ⇔  Δ_AB(O) ＞ max_i Δ_AB(W_i)                          （厳密な不等号）
O が上にある          ⇔  D(O) ＞ max_i D(W_i)
M が下にある          ⇔  D(M) ＜ min_i D(W_i)
O と M が分かれる     ⇔  O が上にある かつ M が下にある
```

| 判定 | 統計 | 成立の条件 | 絞り込み（#122）との対応 |

### 4.2 帰無仮説と、交換可能性が成り立つ条件

| 判定 | 帰無仮説（個体ごと） | 個体ごとの上側の確率 |
|---|---|---|
| J_Ca | H0_Ca：Δ_AB(O) は Δ_AB(W_1)〜Δ_AB(W_19) と交換可能 | **1／20 以下** |
| J_O | H0_O：D(O) は D(W_1)〜D(W_19) と交換可能（20 個の値の並びのどれも同じ確率） | O が 19 本の W のすべてより厳密に大きい確率は **1／20 以下** |
| J_M | H0_M：D(M) は D(W_1)〜D(W_19) と交換可能 | **1／20 以下** |
| J_OM | H0_all：D(O)・D(M)・D(W_1)〜D(W_19) の 21 個が交換可能 | O が 21 個の最大、M が最小になる確率で、**1／(21 × 20) ＝ 1／420 以下** |

**交換可能性が成り立つ条件と、成り立たない場合**
1. W_1〜W_19 は、同じ手順・別々の名前の乱数の流れから作った列なので、出生時の状態を与えたもとで、互いに交換可能とみなす（乱数の流れの独立性は統計モデル上の前提）。**21 本の交換可能性は、実際の生成の手順が保証する性質ではない**
2. O・M は W の作り方から生じた列ではない（毎試行同じ並べ方）。帰無仮説は「その量について、O（M）は典型的な W と区別できない」という仮説で、O・M について確かめた性質ではない
3. 同じ値（引き分け）があると、厳密な不等号の事象の確率は上の値**以下**になる（並びをランダムに崩したときの事象に含まれるため）
4. **帰無仮説が内容と無関係に破れうる場合**：O・M の規則性（毎試行同じ並べ方）や、B と C の Unit の違いと規則性の組み合わせによって、O（M）が W と交換可能でなくなることはありうる。この場合、J_Ca・J_O・J_M の成立は内容に特有とは言えない（J_Ca は、A から出る組に共通の違いでも成り立ちうる）。**J_OM は、同じ個体で O と M が逆の向きに外れることを求めるので、O と M を同じ向きに動かす違い（規則性だけ、Unit の違いだけ）では起こりにくい**。ただし、H0_all の棄却は論理的には「21 個のどこかの非交換性」であり、内容以外の説明を論理的に排除するものではない
5. **J_OM の帰無仮説は、H0_O と H0_M のそれぞれより強い**。H0_O と H0_M がそれぞれ成り立つだけでは、1／420 の上界は導けない（O と M の従属の形によっては、同時に外れる確率がもっと大きくなりうる）。J_OM の棄却は H0_all の棄却であり、内容の因果的な担い手の証明ではない
6. **個体をまたぐ独立性**：出生時の状態と並べ替えの乱数の流れを、個体間で独立とみなす（統計モデル上の前提。異なる seed から数学的に従うものではない）。h は二項分布に確率的に支配される
7. **判定のあいだの従属**：四つの判定は同じ W の本体を共有し、従属する。家族の誤りの水準は、独立性を使わない Bonferroni の上界で抑える（§4.3）

### 4.3 閾値と、家族の誤りの水準

- **C0 の家族全体の水準 0.05**。重みつきの Bonferroni で、**J_Ca・J_O・J_M に 0.016 ずつ、J_OM に 0.002** を割り当てる（合計 0.05。判定のあいだの従属に依らない）
- J_Ca・J_O・J_M：P(h ≥ 4) ≤ P(Bin(20, 1／20) ≥ 4) ≈ **0.015902** ≤ 0.016。h ≥ 3 では ≈ 0.0755 で超える。したがって閾値は 4
- J_OM：P(h ≥ 2) ≤ P(Bin(20, 1／420) ≥ 2) ≈ **0.00105** ≤ 0.002。h ≥ 1 では ≈ 0.0466 で超える。したがって閾値は 2
- **割り当ての理由**：J_OM は個体ごとの帰無のもとの確率が 1／420 と小さいので、閾値 2 に必要な水準は約 0.00105 で足りる。残りを三つの判定に等しく分け、三つの閾値を 4 に保つ。この割り当ては結果を見る前に、判定の数と K から決めたもので、データからは選んでいない
- 成立は、上の前提のもとで帰無仮説を各判定の水準で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- 四つの判定の成立を足し合わせたり、h を比べたりしない

## 6. 発火の数・位相・沈黙・凍結の扱い（測定の前に固定する）

1. **発火の数**：正規化しない（§3.2）。Δ_AB も D も、発火の数の違いを一般には打ち消さない（D の差で相殺されるのは、二つの Δ に加法的に全く同じ量が加わる場合だけ。§3.2）。各 Unit の発火の数を補助として記録する。発火の数の違いで判定を救う・変えることはしない。成立しても、量だけの違い（X7）を除いたとは言わない
2. **位相**：主の比較では分けない。区間を 5τ_a 後から始めることと、V1 の家族（§4.4）が、位相・Unit の状態の持ち越しへの対照である。成立しても、位相ではなく重みが担ったとは言わない
3. **沈黙**：個体を除かない。主の区間で発火しない Unit は、その Unit を含む組の数が 0 になる（ふつうの算術）。沈黙した Unit を補助として記録する
4. **凍結**：判定に使う値がすべて等しい個体は「外にない」に数える（§4.1）。凍結の数を補助として記録する
5. 沈黙・凍結・発火の数の多さを、判定を救う・変える・個体を除く理由に使わない。操作の確認に入れない
6. **事前に書く限界**：A か B（または C）が主の区間で発火しない個体では、D が 0 に退化し、凍結しうる。凍結が多ければ検出力が下がる。0027 では遅い時点で、20 個体のうち 6 個体で B か C が 20 本体すべての試しの窓で沈黙していた（0027 §15.4。試しの窓の中の最初の発火についての記録で、この実験の発火の数とは定義が違う）。不成立のときは、この限界を報告し、規則・区間・量を変えずに、絞り込み §5.4 のとおり感度の確認と沈黙の構造の切り分けへ進む

### 15.5 読むときの注意（記述。判定を変えない）

1. **判定の余裕**：C0 の J_Ca・J_O・J_M は閾値 4 に対して 10・9・6、J_OM は閾値 2 に対して 3。帰無仮説のもとでの h の期待値は、J_Ca・J_O・J_M で 1 以下、J_OM で 20／420 ≈ 0.048 以下である（記述。判定には使わない）
