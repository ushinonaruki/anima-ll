## この実験が決めないこと

**不応期を外すかどうかは、この実験では決めない。** 外すことは恣意性監査 §3.2 で、独立した根拠がないことによる設計判断としてすでに決まっている。結果がどうであっても、`refractory_pulses = 0` にする。

この実験が調べるのは、**根拠のなくなった 3 を外したとき、これまでに得た知見のどれが成り立ち続け、どれを再検証する必要があるか** だけである。結果を見て「3 の方が自然だから残す」「外したら活発すぎるので別の抑制を足す」とはしない。

## 変えるもの

- `refractory_pulses`：3 → 0。ほかの値（減衰 0.85・閾値 0.5・内在的駆動 0.08・ばらつき ±10%・順応のパラメータ）は変えない
- コードは変えない（`refractory_pulses = 0` は今の力学でそのまま動く。発火すると activity は 0 に戻り、次の Pulse から減衰・駆動・刺激でやり直す）
- 不応期の仕組みをコードから取り除く（`refractory_remaining` の項目を消すなど）のは、この実験のあとの別の作業とする

## 記録するもの（判定には使わない）

K1 の手順の run で、不応期 3（= 0008 の NEW）と不応期 0 を並べて記録する。

- 全 Unit の発火（序盤・終盤、10 分あたり）と Unit ごとの内訳
- 1 Pulse おきより短い間隔で発火した回数（不応期 3 では起きえなかった間隔 1〜3 の発火）
- 意図の数・完了の数、列の長さ（最大・平均・終了時）と、伸び続けているか、待ち時間
- 発話の回数
- K2 の手順の run で、w\* の分布（不応期に当たって「0.6 より上」になっていた個体がどう変わったか）

これらは、動作テスト用の配線（恣意性監査 §3.8）と文章をやり取りする内部表現（§3.6）の上の観察であり、AnIma-ll の認知特性とは解釈しない。

## 予測（参考）

- 不応期 0 では、強い入力が続く Unit や、自分の出力が相互に戻る u1 ↔ u2 の発火の間隔が短くなりうる。順応があるので、発火が続けば実効閾値が上がって間隔は伸びる
- 入力なしの状態では、内在的駆動だけで activity が 0 から閾値に届くまでに数 Pulse かかるので、不応期 3 の影響は小さいかもしれない
- 0005 の w\* は、conditioning の直後に不応期に当たっていた個体で変わりうる
- 意図が増えると、Kernel（遅延 3 秒・Worker 1）に対して列が伸び続ける条件が増えうる。性能不足の計測として記録する

## 再確認しない知見

- 0002（L1 の周期性）・0003（初回の L1 の観察）は LLM を使う観察で、この実験では回さない。周期は Unit の力学から来ていた（0002）ので、不応期 0 の上では **前提つき** で読む
- 0007（計算資源境界）は Runtime の契約で、不応期に依存しない。契約テストは毎回のテストで確かめる

## このあとで

- 結果にかかわらず、`minimal-v2` ＝ `minimal-v1` ＋ `refractory_pulses = 0` を作り、既定にする（`minimal-v1` は比較の基準として凍結する）。不応期の除去は、監査による設計判断としてすでに決まっているため
- ただし、**`minimal-v2` を既定にすることと、順応の参照値（α = 0.01・τ_a = 300）が根拠を保つことは別である**。参照値が要再検証になった場合、`minimal-v2` の設定ファイルには次のように明記する

  ```text
  refractory_pulses: 0          # 採用済み（恣意性監査 §3.2、設計判断）
  adaptation: 0.01 / 300        # 要再検証の暫定の引き継ぎ（実験 0009 で根拠を失った。別途決める）
  ```
- 要再検証になった知見があれば、恣意性監査に記録し、扱いを別に決める
- 結果を見たあとの分析は「事後の探索的観察」として分けて書き、上の判定は変えない

## 結果（2026-10-07）

- 測定：commit `9c331ed`（run.py・analyze.py を含む版）。データ `k1.json.gz`・`k2.json.gz`、判定と記録 `report.json`（このフォルダ）
- 完全性：K1 200 本・K2 4000 本がそろった。設計図の不応期が全 Unit で 0 になっていることを run.py の中で確認した（K2 は、同じ個体の発火の記録が 0005 とすべて違うことでも確認）

| 項目 | 結果 |

- 入力なしでは、不応期 0 にしても発火・発話・列はほとんど変わらなかった。予測のとおり、内在的駆動だけで activity が 0 から閾値に届くまでに十数 Pulse かかる（§3.3 の ρ ≒ 1.07 で約 17 Pulse）ので、不応期 3 がほとんど効いていなかった
- 間隔 1〜3 Pulse の発火（不応期 3 では起きえない）は、順応のない・弱い条件で数百回、`minimal-v1` の参照値では 20 個体で 12 回だけ現れた。u1 ↔ u2 の相互の刺激で、発火の直後にすぐ閾値を超える場合である

これらは動作テスト用の配線の上の観察であり、AnIma-ll の認知特性とは解釈しない。

### 事後の探索的観察（判定は変えない）

- 入力なしの run でほとんど差が出なかったのは、不応期の効き方が内在的駆動の値（ρ）に左右されていたからである。0.08 は ρ ≒ 1.07 で閾値に届くまでが遅いので、不応期 3 は「ほぼ空回りの足場」だった。ρ が大きい領域や、強い入力が続く場面では、不応期の有無の差はもっと大きく出るはずである。§3.3 の ρ の領域ごとの実験で、不応期 0（`minimal-v2`）の上で確かめる
