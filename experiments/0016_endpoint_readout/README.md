## 1. 問い

```text
0013  内部の活動だけで、接続の状態が自己形成する
0014  経験の時間配置で weight contrast が変わり、その差は活動へ因果的に効く
0015  経験が作った差は、無入力の自発活動の終端でも同じ向きで存在する
0016  その後の軌道で、その時々の weight contrast は、まだ活動へ読み出せるか
```

> **0015 と同じ経験（順序あり）と同じ無入力の自発活動を経た個体で、終端（24000）から 1 つの順応の時定数（τ_a ＝ 300 Pulse）の無入力の自発軌道のどこかで、その時点の A→B／A→C の weight contrast が、標準の A の試しに対する直後の B・C の発火へ、因果的に読み出せるか**

### 言えること・言わないこと

- 言うのは「0015 の終端から続く自発軌道の上で、その時々の current weight contrast が、1 つの内生的な時定数の範囲で、少なくとも 1 回 functional readout できた」まで
- **「24000 の weight そのものが読めた」とは言わない**。24001〜24300 のあいだにも W は自発力学で動く
- **「0015 の D（W_ordered − W_shuffled）そのものが活動の差を媒介した」とは言わない**。それには順序あり・順序を崩した のあいだの weight 差だけを消す別の対称な介入が要り、A5・A6 が難しくなるので、0016 ではやらない（順序を崩した条件は置かない）
- 成り立っても「記憶した」とは書かない

## 2. 脳の設計図と経験

0015 v0.2 の順序ありの条件とまったく同じ（`experiments/0012_passive_world/neuroarchitecture.yaml`、A・B・C 各 200、試行 k の A を 1 ＋ 60k、B を ＋2、C を ＋30、経験の終わり 12000、そこから 24000 まで外からの入力なし）。本体はそのまま 24300 まで無入力で進める。

## 3. 試しと介入（0014 v0.3 と同じ）

各試しの時刻 t0（24001〜24300）で、**本体の t0 − 1 の終わりの状態から独立に** 次を行う。300 回の試しはどれも本体に入れないので、試しが個体の未来を変えることはない。

```text
無入力で進む本体
   ↓ t0 − 1 の終わりで複製
試しの元（probe_base）
   ↓ t0 に Receptor A へ刺激、t0 を処理
t0 の処理の終わりで 2 腕に複製
   ├─ そのまま（as_is）
   └─ 重みの差を消した（equalized）：w(A→B) ＝ w(A→C) ＝ m、w(B→A) ＝ w(C→A) ＝ w_max − m
          ↓ 可塑性ありのまま
      t0 ＋ 2 の s_B・s_C の発火を読む
```

- runtime の順序から、2 腕は t0 の終わりまで同一で、t0 ＋ 1 の発火も同一。t0 ＋ 2 の B・C で 2 腕が違いうるのは、A→B・A→C を通る s_A の t0 ＋ 1 の伝達だけ（0014 §3.3、契約テスト済み）
- 介入の定義・名前（weight 成分の B/C 方向の非対称だけを消す。痕跡・Unit の状態・B–C には触らない）は 0014 と同じ

### 値の由来

| 値 | 由来 |
|---|---|
| 終端 24000 | 0015 の終端（2 × 経験の終わり） |
| 本体の総 Pulse 24300、最後の試しの複製は 24302 まで | 本体は最後の試しの元を作る時刻（t0 − 1 ＝ 24299）まで進めば足りるが、最後の試しの時刻 24300 まで進める（total_pulses）。各試しの複製（試しの元・2 腕）は t0 ＋ 2 まで進むので、最後の試しの複製は 24302 まで進む |
| 試しの区間 24001〜24300（毎 Pulse、300 回） | 終端の次の Pulse から、順応の時定数 τ_a の 1 区間（adaptation_tau ÷ pulse_interval_seconds ＝ 300）。0014 と同じ形 |
| 読み出し t0 ＋ 2、分ける時点 t0 の終わり | 0014 v0.3 と同じ |
| seed 8001〜8020・8101〜8106 | これまでに一度も走らせていない seed（新しく選んだ値） |

**単一の試しにしない理由（常設チェック C3）**：単調な力学では E は 0014 の |ΔR| と同じ量になる（W ＞ 0 なら ΔB ≥ 0、ΔC ≤ 0 なので |ΔR| ＝ |ΔB| ＋ |ΔC|）。0014 の記録（独立した既存の測定）では、1 回の試しで E ＞ 0 になる割合は個体ごとに 1〜22%（中央値 7.5%）だった。単一の試しでは、weight の因果効果があっても多くの個体で E ＝ 0 になり、結果が「読める構造があるか」ではなく「その 1 Pulse で B・C がたまたま閾値の際にいたか」で決まる。

## 4. 指標と判定

```text
各試し：E(t0) ＝ |B_as_is(t0) − B_equalized(t0)| ＋ |C_as_is(t0) − C_equalized(t0)|   ∈ {0, 1, 2}
        B・C は、その腕で s_B・s_C が t0 ＋ 2 に発火したら 1、しなければ 0
個体ごと：S ＝ Σ_t0 E(t0)                                                  主の判定 s：S ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 s** | すべての個体 | S ＞ 0（300 回のどこかで 1 回以上 readout された） | 成り立った個体数 ÷ 20 ≥ 0.8 |

- **nonzero causal-readout test であり、向きの検定ではない**。E ≥ 0 は定義からそうなり、0014 で分かったとおり単調な力学では効果の向きも構造的に決まる。それを隠さず、効果が 0 でないかだけを問う（常設チェック A1 を受け入れた形）
- **式の形（A6）**：S ＞ 0 は「300 回のうち 1 回以上 E ＞ 0」と同じ。平均・比・閾値を主に入れない。S の大きさは記録
- **適用対象（A3・A7）**：すべての個体。ρ などで適格を切らない。**仮に 300 回すべてで W_probe(t0) ＝ 0 の個体が出ても、N/A ではなく S ＝ 0 の不成立とする**。0016 は「nonzero の W があると仮定したときの条件つきの読み出しやすさ」ではなく、「終端から続く軌道が、標準の試しに対して、対象の重みに由来する因果的な readout を 1 回でも与えるか」という whole-pipeline の問いだから。0015 で A が無入力の区間に自発発火しなかった種類の個体でも、0016 では外から A の試しを入れるので読み出しの機会がある。300 回すべてで E ＝ 0 なら、それは 0016 での正当な「readout なし」
- 0.8 は 0012〜0015 と同じ比で、**同じ Neuroarchitecture に対する Birth State 間の頑健性の基準**（20 個体のうちどれだけで成り立つか）。効果の大きさの閾値ではない

### S ＞ 0 が構造上ほぼ保証されていないことの確認（A1・A7）

300 回の試しを置いたことで S ＞ 0 が構造上ほぼ保証されていないかを、事前の契約で確かめる（自然な seed・smoke の結果では確かめない）。

- **合成の runtime の全状態からの契約テスト**（道具の段で書く）：妥当な全状態（Unit の状態・痕跡・重み。組の和 ＝ w_max）で、
  - (i) **300 回すべての試しで W_probe(t0) ≠ 0（毎回 equalize が実際に 4 本の重みを変えている）のに、300 回すべてで E ＝ 0（S ＝ 0）** になる状態。始めに W ≠ 0 でも途中で W ＝ 0 になり equalize が何も変えない、という状態では条件を満たさない（それは「nonzero の current weight contrast があっても discrete な readout が起きないことがある」の存在証明にならない）
  - (ii) **S ＞ 0** になる状態
  
  の両方が、実物の runtime で 0016 と同じ手順（無入力の本体からの独立な試し）を通してありうることを、具体的な状態で示す

### 10.2 記録（判定に使わない）

### 10.3 読み方

- 0013 → 0016 で、「出生時の状態から接続の状態が自己形成する」「経験の時間配置で weight contrast が変わり、その差は活動へ因果的に効く」「経験が作った差は無入力の自発活動の終端でも同じ向きで存在する」「終端から続く軌道の上で、その時々の weight contrast は、外からの標準の試しに対して活動へ読み出せる（18／20）」まで来た
- 読み出せなかった 2 個体は、どちらも区間中に B が自発発火しない個体で、合成の契約で示した「W ≠ 0 でも S ＝ 0」の形が自然な seed でも起きた。読み出しは、weight contrast の大きさだけでなく、受け手（B・C）がその時々に閾値の近くにいるかで決まる
- 「記憶」と呼ぶには、まだ次が足りない：経験の何が（順序か、W のどの成分か）読み出しに必要かの切り分け、読み出しが経験に特異的か（0015 の D 媒介の問い）、長い時間での変化
