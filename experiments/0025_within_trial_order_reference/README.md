## 0. 問いと主張の範囲

### 0.1 問い

> **0023 と同じ設計図（C0）・同じ経験の時刻・同じ試し・同じ判定で、参照分布を「試行の中の並べ替え」（各試行の 3 つの枠の中だけで A・B・C の札を並べ替える。どの試行でも A・B・C が 1 回ずつ）に替える。順序のある経験（O）の個体は、同じ試し（A の入力）に対して、この参照（W_1〜W_19）の分布の中で典型的でない応答を示すか**

- 設計の整理の **Q5**（O の外れは、O に特有の順序によるのか、O と M に共通する規則的な配置――試行ごとの刺激の数の釣り合い・時刻の格子――によるのか）のうち、**試行ごとの刺激の数の釣り合い**の部分に答える
- 0023 の並べ替え（S_i。600 個の札を試行をまたいで並べ替える）では、多くの試行で A・B・C が 1 回ずつにならない（設計の整理 命題 9）。O と M はどの試行でも 1 回ずつで、0023 では M も O と同じ頻度で並べ替えの外にあった〔0023〕。W_i はどれも O・M と同じ釣り合いを持つ
- 時刻の格子（刺激の時刻の集合）は、O・M・S_i・W_i のすべてで同じで、ここでは変えない

### 0.2 主張の形（成立したとき）

「C0 という設計で、この世界・この手順のもとで、順序のある経験の後の自然な状態は、試しの入力 A が B・C の次の発火の時刻を動かす効果を、**どの試行でも A・B・C が 1 回ずつ来る並べ方の参照分布**では典型的でない形で示した（向きを問わない）。その頻度は、O がこの参照と交換可能であるという帰無仮説のもとで期待される頻度より多かった（個体間の独立性の前提のもとで、水準 0.05）。つまり、**この Γ では、O の非典型性は、試行ごとの刺激の数の釣り合いだけでは説明されなかった**」

### 0.3 主張しないこと

- 成立したとき：**O に特有の順序（A の直後に B）を学習した**。W_i と O の違いは「A・B・C の並べ方」だけでなく、①「すべての試行で同じ並べ方を繰り返すか（規則性）」、② 各 Unit が試行のどの枠で刺激されるか（直近の刺激からの時間。経験の終わりの順応・位相）も含む（設計の整理 §4.4）。この実験はそれらを分けない（§12）
- 成立したとき：0023 の O の外れが釣り合いでは説明されなかった（seed も参照も違う。0023 の個体は再解析しない）。違いを重み・順応・痕跡・位相のどれかが運んだ（機構 ③）
- 不成立のとき：**0023 の O の外れは釣り合いで説明される**、O は釣り合いを保った並べ方と同じ応答を生む、C0 で現象がない（判定の検出力、ほかの R・窓・時刻は未検討。研究④の命題 2・3）
- どちらでも：経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した・記憶した。**0023・0024 の h と 0025 の h の違いから何かを結論すること**（比べる検定は置かない。seed・参照・設計が違う）

## 2. 経験の条件（同じ seed、同じ出生時の状態から 21 個の本体）

| 条件 | 内容 | 役割 |
|---|---|---|
| **O（順序あり）** | 試行 k（0〜199）の 3 つの枠（`t_k ＝ 1 ＋ 60k`、`t_k ＋ 2`、`t_k ＋ 30`）に A・B・C（0023 と同じ） | 主 |
| **W_1〜W_19（試行の中の並べ替え）** | 同じ枠に、試行ごとに A・B・C を並べ替えて置く。i 番目は乱数の流れ `"0025-within-trial-<i>:<seed>"` を 1 本だけ使い、k ＝ 0, 1, …, 199 の順に、リスト [A, B, C] をその流れで 1 回ずつ並べ替えて（Python の `random.Random(名前).shuffle`）、(t_k, t_k ＋ 2, t_k ＋ 30) に置く | 主の参照分布 |
| **M（鏡）** | 同じ枠に A・C・B（0023 と同じ） | 補助 |

- どの条件でも、**どの試行でも A・B・C が 1 回ずつ**来る。したがって、連続する m 個の試行の区間では、どの Unit も m 回ずつ刺激される（設計の整理 命題 9 の釣り合いが、参照の中でも同じになる）
- 刺激の数は A・B・C とも 200、時刻の集合はすべての条件で同じ。経験は Pulse 1〜12000。12001 以後はどの本体にも外からの入力はない（可塑性あり）
- O と M は、W の分布がとりうる 6^200 通りの並べ方のうちの 2 つ（すべての試行で同じ並べ方を繰り返すもの）である。W_i が O と一致する確率は (1／6)^200 で、無視できるが 0 ではない（一致しても規則どおりに扱う。§5.1）
- **W_i と O のあいだに残る違い**（主の比較では分けない。§0.3・§12）：(1) 並べ方そのもの、(2) すべての試行で同じ並べ方を繰り返すかどうか（規則性）、(3) 各 Unit が試行のどの枠で刺激されるか。(3) は、とくに経験の最後の数試行の並べ方を通して、12000 の順応・位相を変えうる（設計の整理 §4.4 の【模型の予測】、契約 X6）

## 3. 試し（0023 §3 と同じ）

各本体 X と、各試しの時刻 t0 ∈ {12001, …, 12300} について：本体の t0 − 1 の処理の終わりを複製し（A の複製）、t0 に Receptor A の出来事を 1 つ入れて t0 ＋ 1 ＋ T_w まで進める（複製の中も可塑性あり）。空の側は本体そのもの（最初と最後の試しで、入力なしの複製と一致することを確かめる：§7）。窓は [t0 ＋ 2, t0 ＋ 1 ＋ T_w]、窓の中で発火しなければ最初の発火を t0 ＋ 2 ＋ T_w（打ち切り）とする。T_w ＝ 300。

## 5. 主の評価（0023 §5 と同じ。参照だけが W）

### 5.1 個体ごと

```text
O が外にある  ⇔  L(O) ＞ max_i L(W_i)   または   L(O) ＜ min_i L(W_i)    （どちらも厳密な不等号）
```

向きを問わない。等号は「外にない」。20 個の L がすべて等しい個体（凍結）も「外にない」に数え、除外しない。

### 5.2 個体をまたぐ判定

- h ＝ O が外にある個体の数（20 個体のうち）
- **判定：h ≥ 5 なら成立（holds）、h ≤ 4 なら不成立（fails）**
- 根拠（0023 §5.2・0024 §5.2 と同じ）：帰無仮説「どの個体でも、L(O) は L(W_1)〜L(W_19) と交換可能」のもとで、各個体で O が外にある確率は 2／20 ＝ 0.1 以下。**個体のあいだの独立性を、統計モデル上の前提として置く**（異なる seed から数学的に従うものではない）。この前提のもとで h は Bin(20, 0.1) に確率的に支配され（同じ値がある個体では外にある確率が 0.1 より小さくなりうるため）、**P(h ≥ 5) ≤ P(Bin(20, 0.1) ≥ 5) ≈ 0.04317** である。Bin(20, 0.1) の上側確率が水準 0.05 以下になる最小の閾値が 5（P(Bin(20, 0.1) ≥ 4) ≈ 0.133 は 0.05 を超える）。右辺は二項分布の上側確率そのもので、実験の h の帰無仮説のもとでの確率はそれ以下である
- h ≥ 5 で成立とすることは、上の前提のもとで帰無仮説を水準 0.05 で棄却することで、交換可能性の破れの数学的証明ではない。交換可能性は帰無仮説の置き方で、O について保証された性質ではない
- 不成立は、帰無仮説を棄却できなかったということで、交換可能性が成り立つことを示すものではない
- **判定の範囲は「試行の中の並べ替え」の参照に相対的**（protocol の judgment.scope）。0023 の参照（S_i）に対する判定と組み合わせた判定・比較の検定は置かない

### 6.1 沈黙の扱い（0024 §6.1 と同じ。測定の前に固定する）

0023 で、窓の中で B か C がまったく発火しない本体が多かった〔0023〕。0024（V1）でも、silence_counts が 0 でない個体があった〔0024〕。0025 では次のとおり扱い、測定の後に変えない。

1. **個体を除かない**。出生時の状態による適格の条件（設計の整理 §5.3 の (b)）は置かない（同 (a)）
2. 窓の中で発火しない Unit は、両方の側で打ち切りになり ℓ ＝ 0（ふつうの算術。0023 §4.1）。その本体の L はもう一方の Unit だけで決まる
3. 20 個の L がすべて等しい個体（凍結）は「外にない」に数える（§5.1、A7）
4. silence_counts を個体ごとに記録し、打ち切りの数とともに報告する（§6）
5. 沈黙の多さを、主の判定を救う・変える・個体を除く理由に使わない。沈黙を操作の確認に入れない（§7）
6. 沈黙がなぜ起きたか（出生時の余裕 m_i、順応、設計の整理 命題 11 の条件）は、この実験では調べない

### 15.5 読むときの注意（記述。判定を変えない）

### 15.6 言えること・言えないこと（§12・§13 に従う）

**言えること**：§12 の「主が成立」の行。**C0 では、この世界・この規則・この試しの区間（12001〜12300）・T_w ＝ 300・K ＝ 19・20 個体のもとで、順序のある経験の後の自然な状態は、試しの入力 A が B・C の次の発火の時刻を動かす効果（R2）を、どの試行でも A・B・C が 1 回ずつ来る並べ方（W）の参照分布では典型的でない形で示した（向きを問わない）。その頻度（20 個体のうち 7）は、O が W と交換可能であるという帰無仮説のもとで期待される頻度より多かった**（個体間の独立性の前提のもとで、水準 0.05）。つまり、**この Γ では、O の非典型性は、試行ごとの刺激の数の釣り合いだけでは説明されなかった**

**言えないこと**：
- **O に特有の順序（A の直後に B）を学習した**。W と O のあいだには、並べ方そのもののほかに、すべての試行で同じ並べ方を繰り返すか（規則性）と、各 Unit が試行のどの枠で刺激されるか（とくに最後の数試行。12000 の順応・位相）の違いが残る（§2）。この実験はそれらを分けない
- **0023 の O の外れが釣り合いでは説明されなかった**（seed・参照が違う。0023 の個体は再解析していない）
- 違いを重み・順応・痕跡・位相のどれかが運んだ（機構 ③）
- すべての個体・大多数の個体で O が外にある。h／20 を母集団の割合と呼ぶ
- 交換可能性の破れの数学的証明、個体間の独立性が異なる seed から従うこと
- 試しへの応答の大きさだけの違い（§15.5 の 3・4：窓の中で発火するかどうかの違いを含む）
- **0023・0024 の h と 0025 の h の違いから、釣り合い・学習の寄与を結論すること**
- O と M の結果を並べて、規則性と並べ方の寄与に分けること（§15.5 の 6）
- 補助（向き・鏡・R1′・R1・R3・silence_counts）のどれかから、主に何かを足すこと
- §0.3 のすべて：経験した順序に対応した（L3）、自発に現れた（O-N）、内容を思い出した・記憶した
