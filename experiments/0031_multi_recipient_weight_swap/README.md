## 0. 問いと主張の範囲

### 0.1 問い

> **C0 で、0028・0029 と同じ世界・経験（O・M・試行の中の並べ替え W）の後、主の区間（13501〜25500）の始まりの直前の静かな Pulse τ に、5 つの受け手 W20〜W24 のそれぞれで、6 本の重みだけをドナー（O・M・W1〜W19）の τ の値に替える。受け手ごとにドナーを順位づけし、5 つの受け手をまたいで合わせたとき、ドナーが O（M）の入れ替えた本体の Δ_AB と D ＝ Δ_AB − Δ_AC は、ドナーが W のときの分布の中で、予測した向きに典型的でないか（合計の家族 Agg）。また、5 つの受け手のすべてで、そうなっているか（全受け手の家族 All）**

- **0029 の限界**（0029 §0.3・§5.4・§15.6）：0029 の Wt の効果は、各個体で**一つの受け手 W20** の位相・順応・痕跡を背景に固定した条件付きの効果（C-I）だった。受け手は個体ごとに別の本体だが、一つの個体の中では一つの背景しか試していない
- **この実験が足すもの**：同じ個体の中で、**同じドナーの重みの塊を 5 つの背景に入れる**。問いは二つで、どちらも C-I の一般化である（C2 の整理 §8・§9 の 2）
  - **Agg**：5 つの背景をまたいで合わせると、O（M）の重みの塊は典型的でないか（一つの背景の引き方に頼らない形）
  - **All**：5 つの背景の**どれでも**、O（M）の重みの塊は外にあるか（同じ個体の中での一貫性）
- **この実験が問わないもの**：効果が背景によって**違うか**（異質性）。異質性の検定は置かない（§0.3・§12）
- 答えの水準は **C-I**（τ と受け手の残りの塊を背景に固定した、ドナーのあいだの重みの塊の条件付きの効果と、その介入の参照との比較）まで。背景が 1 つから 5 つに増えるだけで、C-II・C-III には進まない

### 0.2 主張の形（成立したとき）

どれも「C0 で、この世界・この手順のもとで、5 つの受け手 W20〜W24 の残りの塊と時刻 τ を背景に固定したとき、個体間の独立性の前提のもとで、判定の水準（§5 の割り当て）で」という限定が付く。

| 家族 | 判定 | 成立したときの主張の形 |
|---|---|---|
| **Agg** | J_Ca^Agg | 5 つの背景で受け手ごとの順位の点を合計すると、O の重みの塊は、W の重みの塊と比べて、Δ_AB を予測した向き（大きい側）に典型的でなかった。その頻度は、ドナーとしての O が W と交換可能であるという帰無仮説の想定より多かった |
| Agg | J_O^Agg・J_M^Agg | 同じ合計で、O の重みの塊は D を大きい側、M の重みの塊は D を小さい側に典型的でなくした |
| Agg | J_OM^Agg | **同じ個体で、合計の点で O の重みの塊が D を W のすべてより大きく、M の重みの塊が D を W のすべてより小さくした、ということが、21 のドナーの交換可能性の想定より多くの個体で起きた**（5 つの背景にまたがる、重みの塊だけによる、経験の内容に応じた逆向きの効果。C-I） |
| **All** | J_Ca^All | **同じ個体の 5 つの背景のすべてで**、O の重みの塊が Δ_AB を W の重みの塊のすべてより大きくした個体が、帰無仮説の想定より多かった |
| All | J_O^All・J_M^All | 同じく、5 つの背景のすべてで、O（M）の重みの塊が D を W のすべてより大きく（小さく）した |
| All | J_OM^All | 同じ個体の 5 つの背景のすべてで、O の重みの塊と M の重みの塊が D を逆の向きに W の外に出した |

### 0.3 主張しないこと

- **背景に依存しない（任意の背景で成り立つ）**：5 つの受け手は、W と同じ手順で作った本体の 5 つにすぎない。All が成り立っても「どの背景でも」とは言わない。O・M を受け手にした背景、ほかの時刻の背景は試さない
- **背景によって効果が違う・違わない（異質性）**：Agg と All の結果の違い、受け手ごとの補助の数から、効果の背景への依存の有無を結論しない。**All の不成立は、背景に依存した証拠ではない**（検出力が低い：§5.3）
- **自然な差の原因（C-III）**：成立しても、「0028 で O が典型的でなかったのは重みの違いのせいだった」「重みが担い手だった」とは言わない（担い手の整理 命題 5）
- **自然な差の再現と消去（C-II）**、**排他性・寄与の割合**（C2 の整理 命題 B・C）
- **塊の中のどの成分か**：6 本のうちどの組の重みか（組ごとの入れ替えは別の事前登録）
- **入れ替えた状態が自然に起こる**（担い手の整理 命題 2）、**学習の必要性**
- **量だけの違い（X7）を除いた**：Wt の外れは、重みが生んだ発火の数の違いを含む（0029 §3.3 と同じ）。経験の後の可塑性も分けない（0030 の F とは別の問い）
- **記憶ができた・内容を理解した・意味を持った**、3 要素の順序・時間差を表した
- 0029・0030 の h と、0031 の h の違いから何かを結論すること（「0029 は W20 に特有だった」「再現した」とは言わない）
- 不成立のとき：重みの塊は効かない、0029 の効果は偶然だった

## 2. 本体と入れ替え

### 2.1 自然な本体（同じ seed、同じ出生時の状態から 26）

| 本体 | 経験の札の列 |
|---|---|
| **O** | 試行 k（0〜199）の 3 つの枠（t_k、t_k ＋ 2、t_k ＋ 30）に A・B・C |
| **M** | 同じ枠に A・C・B |
| **W1〜W24** | i 番目は乱数の流れ `"0031-within-trial-<i>:<seed>"` を 1 本だけ使い、k ＝ 0, 1, …, 199 の順にリスト [A, B, C] をその流れで 1 回ずつ並べ替えて（`random.Random(名前).shuffle`）、(t_k, t_k ＋ 2, t_k ＋ 30) に置く（0025・0027〜0030 と同じ作り方） |

経験は Pulse 1〜12000。12001 以後はどの本体にも外からの入力はない（可塑性あり）。各本体を 25500 まで進める。

### 2.2 入れ替える時刻 τ（個体ごとに 1 つ、すべての受け手に共通）

```text
τ ＝ max{ t ∈ [13441, 13500] ： Pulse t に、自然な 26 本体のどれでも、どの Unit も発火していない }
     （13441 ＝ 主の区間の始まり 13501 − trials.every、13500 ＝ 主の区間の始まり − 1。0029 §2.2 と同じ式）
```

- **理由**（0029 §2.2 と同じ）：τ の処理の終わりには、どの自然な本体にも次の Pulse に届く駆動が置かれておらず、Receptor の出来事もない。重みを入れ替えても、駆動の重みと接続の重みの不整合が起きない
- **すべての受け手に一つの τ**：ドナーの重みの塊を、どの受け手にも同じ時刻の値で入れるため。受け手ごとに τ を変えると、受け手ごとにドナーの塊が違う時刻の値になり、§4.3 の同じドナーを 5 つの背景に入れる形が崩れる
- 本体が 22 から 26 に増えるので、窓の中の静かな Pulse は 0029 より少なくなりうる。τ がない個体の扱いは §2.6
- τ は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる

### 2.3 受け手・ドナー・入れ替えた本体

- **受け手**：**W20・W21・W22・W23・W24 の 5 つ**（並べ替えの番号で事前に決める）
  - **W と同じ手順で作った本体を受け手にする**：問いは「典型的な W の背景」の一般化で、0029 の W20 と同じ種類の背景を増やす
  - **ドナーに含めない**：受け手が自分の塊を受け取る自己一致（C2 の整理 命題 D）を避け、どの受け手にも**同じ 21 のドナー**を入れる（§4.3 の命題 2 の前提）。W1〜W19 のどれかを受け手に兼ねさせる形（一つずつ外す形）は、受け手ごとにドナーの集合が変わるので採らない
  - **O・M を受け手にしない**：O の背景に M の重みを入れる形は、塊と背景の内容の組み合わせという別の問いになる
  - **数 5**：C2 の整理 §8 の C2-a の例（m ＝ 5。0029 の前に書いた）から取った。データからは選んでいない。計算の量は §9
- **ドナー**：O・M・W1〜W19 の 21。**参照のドナー**：W1〜W19（K ＝ 19。0028・0029 と同じ）
- **入れ替えた本体** Y_r(d)：受け手 r の τ の終わりの状態を複製し、6 本の重みをドナー d の τ の終わりの値に替え、τ ＋ 1 から 25500 まで**可塑性ありで**進める。受け手 5 × ドナー 21 ＝ **105 本体**
- **確認の本体**（操作の確認だけ。受け手ごとに 2 つ、計 10）
  - 全部の入れ替え Full_r：受け手 r の状態の重みと Unit の状態・痕跡のすべてを O のものにした本体（O の自然な軌道と一致するはず）
  - 入れ替えなし Null_r：受け手 r の状態の重みと Unit の状態・痕跡を r 自身のものにした本体（r の自然な軌道と一致するはず）

### 2.4 背景として固定するもの

| 欄（τ の処理の終わり） | 入れ替えた本体 Y_r(d) の値 |
|---|---|
| 6 本の重み（接続の状態の weight） | **ドナー d** のもの |
| 3 Unit の activity・順応・不応期の残り（不応期 0 なので常に 0）、発火の回数 | 受け手 r のもの |
| 接続ごとの痕跡（pre_trace・post_trace。値は Unit ごと：担い手の整理 命題 2 の I2） | 受け手 r のもの |
| 置かれた駆動・Delta | ない（§2.2） |
| 出生時に決まる Unit の力学の値・設計図・可塑性の規則 | 個体で共通 |
| τ より後の入力 | ない |

- 0029 §2.4 の命題（担い手の設計 命題 1）を受け手ごとに当てる：**同じ受け手 r の 21 本体は、u（Unit の状態と痕跡）がすべて u_r で同じ**なので、受け手 r の中のドナーのあいだの Δ_AB・D の違いは、重みの塊の違いからしか生じない。τ の位相・順応・痕跡の違い（X5 の経路）は、受け手の中の比較の説明にならない
- **受け手のあいだ**では u が違う。この実験の「背景」とは、この u_r（と τ）のことである
- 入れ替えた後も可塑性は働き、重みは受け手の背景のもとで書き換わる（0029 §3.3 と同じ。分けない）

### 2.6 τ がない個体の記録・確認・判定（事前に固定する。0029 §2.6 と同じ形）

τ があるかどうかは、自然な 26 本体の発火の列だけで決まる。**τ がないことは有効な結果**で、その個体（seed）は completed である。記録の欠け・操作の失敗ではない。

**raw の形**（どちらの場合も同じ鍵を持つ。**raw に判定の量〔主の事象〕は書かない**：§7 の最後の注）

| 欄 | τ がある | τ がない |
|---|---|---|
| `swap.tau_exists` | `true` | `false` |
| `swap.tau` | 整数（13441〜13500） | `null` |
| `swap.window_witness` | `null` | 窓の 60 の Pulse の昇順の配列。要素は `{pulse, body, unit}`：その Pulse に発火した自然な本体と Unit のうち、本体を O・M・W1〜W24 の順、Unit を s1・s2・s3 の順に見て最初のもの |
| 自然な本体の `full_state_end_of_tau` | τ の終わりの全状態 | `null` |
| `swapped_bodies` | 105 本体（受け手 W20〜W24 の順、その中でドナー O・M・W1〜W19 の順） | 空の配列 `[]` |
| `control_bodies` | 10 本体（受け手ごとに全部の入れ替え・入れ替えなし） | 空の配列 `[]` |

- 自然な 26 本体のほかの記録（出生時の状態・力学の値・札の列・1〜25500 の全発火・12000・13500・25500 の全状態・確認のための全状態）は、τ があるときと同じに保存する
- 上の対応から外れた raw（τ がないのに入れ替えた本体がある、τ があるのに配列が空、`window_witness` と `tau_exists` が食い違う、など）は、その個体の操作の確認の失敗（invalid）とする

**操作の確認**（§7）：確認ごとの結果を `pass`・`fail`・`not_applicable` で記録する。`not_applicable` は「この個体では定義されず、行わなかった」で、**失敗ではなく、invalid の理由にならない**。

| 確認 | τ がある | τ がない |
|---|---|---|
| 刺激の札・出生時の状態・札が分かれる前の一致 | 行う | 行う（自然な 26 本体） |
| 入力なし | 自然な本体と、入れ替えた本体・確認の本体 | 自然な本体だけ |
| τ の規則 | §7 の τ の側 | **τ がないことの証明**：窓のすべての Pulse で自然な本体のどれかに発火があり、`window_witness` の各要素が記録した発火の列と一致し、その Pulse で上の順に見て最初のものである |
| 入れ替えの組み立て・入れ替えた状態の不変の関係・全部の入れ替え・入れ替えなし | 行う | `not_applicable` |
| 切り詰めなし・重みの再生・組の和 | 自然な本体（12000・τ・13500・25500）と、入れ替えた本体・確認の本体 | 自然な本体だけ（12000・13500・25500） |
| 数え方の算術 | すべての本体 | 自然な本体だけ |
| 生の記録からの再検証 | 本体の並び：自然な 26、入れ替えた 105、確認の 10 | 本体の並び：自然な 26、入れ替えた本体・確認の本体は空の配列 |

**判定への数え方**：τ がない個体は 20 個体の分母に残り、8 つの主の事象をすべて「外にない」（`false`、理由 `no_tau`）に数える。凍結とは別に記録する。この個体は §9 の「20 個すべて completed の後に一度だけ集計」の completed に含む。

**補助**（§6）：τ がない個体でも、自然な本体から決まる補助（自然な 26 本体の構成量と沈黙、出生時の値による層、自然な本体の比較）は記録する。入れ替えた本体から決まる補助は `null` とし、理由 `no_tau` を付ける。層ごとの事象の数では「外にない」に入れ、層ごとの τ がない個体の数も記録する。

**契約テスト**（道具の段階）：τ がない合成の個体を必ず作り、次の (1)〜(5) を、実行の道具と raw からの再検証の両方で確かめる。
1. raw が上の形になる
2. 入れ替えに固有の確認が `not_applicable` で invalid にならない

5. その個体が completed として集計に入り、8 つの事象が `false`、h の分母が 20 のまま

## 3. 量と、向きの根拠

### 3.1 本体ごとの量（0028 §3.1・0029 §3.1 と同じ）

本体（自然な本体・入れ替えた本体・確認の本体のどれも）の発火の列 s_X(t) から、主の区間 [S, E] ＝ [13501, 25500] について

```text
N_{X→Y} ＝ #{ t : S ≤ t ≤ E − 1, s_X(t) ＝ 1, s_Y(t ＋ 1) ＝ 1 }       （X ≠ Y。二つの発火がどちらも区間の中にある組だけ）
Δ_AB ＝ N_{A→B} − N_{B→A}、   Δ_AC ＝ N_{A→C} − N_{C→A}
D ＝ Δ_AB − Δ_AC
```

- A・B・C は役（その個体で Receptor A・B・C を受ける Unit）。入れ替えた本体の主の区間の発火は、τ ＋ 1 以後に入れ替えた本体が出したものだけ

### 3.2 受け手ごとの順位の点と、受け手をまたぐ合計

受け手の集合を ℛ ＝ {W20, …, W24}、ドナーの集合を 𝒟 ＝ {O, M, W1, …, W19}、参照のドナーの集合を 𝒲 ＝ {W1, …, W19} とする。量 x（Δ_AB または D）について、x_r(d) ＝ x(Y_r(d)) と書く。

```text
順位の点（受け手 r の中、21 のドナーの中で）
  s^x_r(d) ＝ Σ_{e ∈ 𝒟, e ≠ d} sgn( x_r(d) − x_r(e) )        （−20〜20 の整数。下の数 − 上の数。同じ値は 0）

合計の点（5 つの受け手をまたいで）
  S^x(d) ＝ Σ_{r ∈ ℛ} s^x_r(d)                              （−100〜100 の整数）
```

- **この形にする理由**
  - 受け手ごとの順位に直してから足すので、**どの背景も同じ重みで合計に入る**。ある背景だけで値の幅が大きくても、その背景だけが合計を決めない（値そのものを足す形は採らない）
  - C2 の整理 §8 の C2-a が挙げた形（「背景ごとの順位の平均を、同じ量を各 W ドナーについて求めたものと比べる」。0029 の前に書いた）を、同じ値を 0 に数える整数の形にしたもの
  - 受け手が 1 つなら、0029 の事象とちょうど同じになる（§4.3 の命題 1 の帰結 1）
  - ある受け手で 21 の値がすべて等しい（その背景で凍結した）とき、その受け手の点はすべて 0 で、合計の比較に影響しない
- 順位の点は 21 のドナー（M を含む）の中で付ける。J_Ca・J_O でも M を含めて付けるのは、どの事象にも同じ一つの点を使い、ドナーの入れ替えに対して対称な形にするため（§4.3 の命題 2）

### 3.3 向きの根拠

- 0029 §3.2 と同じ（一方向）。0028 §3.3 の理論（絞り込み 命題 A・予想 C）から、O の重みの塊は Δ_AB と D を大きくし、M の重みの塊は D を小さくする向きに働くと予測する
- **理論の保証ではない**：入れ替えた後も可塑性は働き、受け手の位相・順応の背景で重みは書き換わりうる。予測と逆の向きの外れは「外にない」と同じに扱い、補助に記録する

## 4. 主の判定

### 4.1 個体ごとの事象

τ がある個体ごとに、入れ替えた 105 本体の主の区間の Δ_AB と D を計算し、§3.2 の点を求める。

```text
Agg（合計の家族。一方向）
  O の Δ_AB が上（Agg）      ⇔  S^{Δ_AB}(O) ＞ max_{d∈𝒲} S^{Δ_AB}(d)
  O が上（Agg）              ⇔  S^D(O)      ＞ max_{d∈𝒲} S^D(d)
  M が下（Agg）              ⇔  S^D(M)      ＜ min_{d∈𝒲} S^D(d)
  O と M が分かれる（Agg）   ⇔  O が上（Agg） かつ M が下（Agg）

All（全受け手の家族。一方向。0029 の Wt の事象を、5 つの受け手のすべてで求める）
  O の Δ_AB が上（All）      ⇔  すべての r ∈ ℛ で  Δ_AB_r(O) ＞ max_{d∈𝒲} Δ_AB_r(d)
  O が上（All）              ⇔  すべての r ∈ ℛ で  D_r(O)    ＞ max_{d∈𝒲} D_r(d)
  M が下（All）              ⇔  すべての r ∈ ℛ で  D_r(M)    ＜ min_{d∈𝒲} D_r(d)
  O と M が分かれる（All）   ⇔  O が上（All） かつ M が下（All）
```

- 不等号はすべて厳密。等号は「外にない」
- **凍結**：判定に使う値がすべて等しい個体は「外にない」に数え、除外しない（A7）
  - Agg：その判定に使う合計の点（J_Ca は O と 𝒲 の S^{Δ_AB} の 20 個、J_O は O と 𝒲 の S^D、J_M は M と 𝒲 の S^D、J_OM は O・M・𝒲 の S^D の 21 個）がすべて等しい
  - All：5 つの受け手の**どれか**で、その判定に使う値（0029 §4.1 の 20 個・21 個）がすべて等しければ、All の事象は成り立たない。凍結した受け手の数（0〜5）を記録する
- τ がない個体は、8 つの事象すべてで「外にない」（§2.6）
- 予測と逆の側の外れ（Agg：S^{Δ_AB}(O) ＜ min、S^D(O) ＜ min、S^D(M) ＞ max）は「外にない」と同じに扱い、記録する（§6）

### 4.2 判定（家族ごとに 4 つ）

|---|---|---|---|

| Agg | **J_O^Agg** | h_O^Agg ＝ O が上（Agg）の個体の数 | **h ≥ 4** |

### 4.3 命題（事前に示す。結果を決めない）

**命題 1（順位の点は受け手の中の順序を保つ）**：受け手 r と量 x を固定する。どのドナー d・e についても

```text
x_r(d) ＞ x_r(e)  ⇒  s^x_r(d) ≥ s^x_r(e) ＋ 2
x_r(d) ＝ x_r(e)  ⇒  s^x_r(d) ＝ s^x_r(e)
```

- 証明：d・e 以外のドナー f は、s(d) に sgn(x(d) − x(f))、s(e) に sgn(x(e) − x(f)) を加える。x(d) ＞ x(e) なら前者は後者以上。d と e のあいだの項は、s(d) に ＋1、s(e) に −1 を加える。等しいときは、すべての項が同じになる
- **帰結 1（受け手が 1 つなら 0029 と同じ）**：ℛ が 1 つの受け手だけなら、Agg の 4 つの事象は 0029 の Wt の 4 つの事象（その受け手を W20 とした形）とちょうど同じになる
- **帰結 2（All は Agg の部分集合）**：All の各事象が成り立てば、同じ判定の Agg の事象も成り立つ。各受け手で x_r(O) ＞ x_r(W_i) なら s_r(O) ＞ s_r(W_i) で、5 つを足しても S(O) ＞ S(W_i) が保たれる（M の側、J_OM も同じ）。したがって**どの個体でも、どの判定でも h^All ≤ h^Agg**

**命題 2（帰無仮説のもとの上界）**：判定 J_Ca・J_O について、個体ごとに次の帰無仮説 H を置く。

> H：受け手 5 つの τ の状態と、21 のドナーの τ の重みの塊の同時の分布が、O・W1〜W19 のラベルの入れ替えに対して不変（M のラベルは動かさない）

- このとき、合計の点の組 (S(O), S(W1), …, S(W19)) は交換可能である。どの受け手にも同じ 21 のドナーを入れ、点はドナーの入れ替えに対して同じように入れ替わる（対称な）関数だから
- したがって P(S(O) ＞ max_𝒲 S) ≤ 1／20（同じ値は「外にない」なので、以下）
- J_M は M と W1〜W19 で同じ。J_OM は 21 のドナーすべての入れ替えに対する不変を置き、O が 21 個の合計の点の最大、M が最小になる確率で **1／420 以下**
- All の事象は命題 1 の帰結 2 で Agg の部分集合なので、**同じ H のもとで同じ上界**（1／20・1／420）を持つ

### 4.4 帰無仮説と、交換可能性が成り立つ条件

| 判定 | 帰無仮説（個体ごと） | 個体ごとの上側の確率 |
|---|---|---|
| J_Ca・J_O（Agg・All） | §4.3 の H（O と W1〜W19） | **1／20 以下** |
| J_M（Agg・All） | 同じく M と W1〜W19 | **1／20 以下** |
| J_OM（Agg・All） | 21 のドナーすべての入れ替えに対する不変 | **1／420 以下** |

**交換可能性が成り立つ条件と、成り立たない場合**（0029 §4.3 の 1〜7 を引き継ぎ、受け手が増えたことによる点を足す）
1. W1〜W24 は同じ手順・別々の名前の乱数の流れから作った列で、そのドナーとしての塊は互いに交換可能とみなす（乱数の流れの独立性は統計モデル上の前提）。**21 のドナーの交換可能性は、実際の生成の手順が保証する性質ではない**
2. O・M は W の作り方から生じた列ではない。帰無仮説は「その塊のドナーとして、O（M）は典型的な W と区別できない」という仮説で、O・M について確かめた性質ではない
3. **受け手とドナーの関係**
   - 受け手 W20〜W24 の列は、ドナーの W とは別の名前の乱数の流れから作り、O・M は決まった列である。出生時の状態を固定すれば、受け手の状態はドナーの塊と独立とみなせる（統計モデル上の前提）
   - このとき H は、出生時の状態を固定したもとでの、21 のドナーの重みの塊の交換可能性と同じになる
   - 0029 の帰無仮説は一つの受け手での量について述べた。H は塊が 5 つの背景で同時にどう振る舞うかまで含むので、その分だけ強い仮説である
4. **1 つの個体の中の受け手のあいだの従属**：同じドナーの塊が 5 つの受け手に入るので、受け手ごとの事象は強く従属する。この実験は**受け手ごとの判定を並べず**、個体ごとに一つの事象（Agg・All）にする（C2 の整理 §8）。受け手ごとの事象は補助の記録だけ（§6）
5. 同じ値（引き分け）があると、厳密な不等号の事象の確率は上の値**以下**になる
6. **帰無仮説が内容と無関係に破れうる場合**：O・M の規則性（毎試行同じ並べ方）が、重みの塊を通して内容と無関係に O・M を W と違わせることはありうる。J_OM は同じ個体で O と M が逆の向きに外れることを求めるので、同じ向きに動かす違いでは起こりにくい。ただし、内容以外の説明を論理的に排除しない（0029 §4.3 の 4）
7. **個体をまたぐ独立性**：出生時の状態と並べ替えの乱数の流れを、個体間で独立とみなす（統計モデル上の前提）。h は二項分布に確率的に支配される
8. **判定のあいだの従属**：家族の中の 4 つの判定と、二つの家族は、同じ入れ替えた本体を共有して従属する。誤りの水準は、独立性を使わない Bonferroni の上界と、命題 1 の入れ子で抑える（§5）

## 5. 閾値と、誤りの水準

### 5.1 各家族

- 各家族の 4 つの判定に、**J_Ca・J_O・J_M に 0.016 ずつ、J_OM に 0.002**（重みつきの Bonferroni、合計 0.05。0028〜0030 と同じ割り当て）
- J_Ca・J_O・J_M：P(h ≥ 4) ≤ P(Bin(20, 1／20) ≥ 4) ≈ **0.015902** ≤ 0.016（h ≥ 3 では ≈ 0.075484）。閾値 4
- J_OM：P(h ≥ 2) ≤ P(Bin(20, 1／420) ≥ 2) ≈ **0.001047** ≤ 0.002（h ≥ 1 では ≈ 0.046557）。閾値 2
- Agg・All で同じ閾値（個体ごとの上界が同じ：§4.3 の命題 2）

### 5.2 実験全体（8 判定）の誤りの水準

- **この実験では、8 判定をまとめて誤りの水準 0.05 と主張する**。理由：
  - All の各判定は、同じ判定の Agg と**同じ帰無仮説**を持つ
  - All の事象は Agg の事象の部分集合（§4.3 の命題 1 の帰結 2）なので、閾値が同じなら、All の判定が成り立つときは、同じ判定の Agg も必ず成り立つ
  - したがって、8 判定のどれかで帰無仮説を誤って棄却する出来事は、Agg の 4 判定のどれかで誤って棄却する出来事に含まれ、その確率は Agg の水準の和 0.05 以下である（どの帰無仮説が正しい組み合わせでも）
- 0029・0030 は二つの家族が別の帰無仮説・別の本体の比較だったので、実験全体を主張しなかった（単純な和の上界 0.10）。0031 の二つの家族は入れ子なので、この扱いが変わる
- 閾値は、割り当てた水準と、個体ごとの帰無の確率（K ＝ 19）から決まる最小の整数。結果を見る前に決めたもので、データからは選んでいない
- 成立は、上の前提のもとで帰無仮説を各判定の水準で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- 家族の中・家族のあいだで、判定の成立を足し合わせたり、h を比べたりしない。h^All ≤ h^Agg は数学的に決まっているので、二つの h の比や差を、背景への依存の量として読まない

### 6.1 沈黙・凍結の扱い（測定の前に固定する）

- 個体を除かない。主の区間で発火しない役は、その役を含む組の数が 0 になる（ふつうの算術）
- 凍結は「外にない」に数える（§4.1）
- 沈黙・凍結・発火の数の多さ・層・的の本体だけの沈黙を、判定を救う・変える・個体を除く理由に使わない。操作の確認に入れない
- **的の本体だけの沈黙で外にある事象**（例：ある受け手で Y_r(O) でだけ A が沈黙して Δ_AB ＝ 0、ほかがすべて負）は、0028〜0030 と同じく、事象の定義どおり外に数える。補助に記録するが、数え直しはしない
- **事前に書く限界**

### 15.6 言えること・言えないこと（§12・§13 に従う）

**言えること**

どれも、C0・この世界・この手順のもとで、5 つの受け手 W20〜W24 の残りの塊と τ を背景に固定し、個体間の独立性・受け手とドナーの独立という統計モデル上の前提のもとで、8 判定をまとめた水準 0.05 で言える。

- **J_Ca^Agg・J_O^Agg・J_M^Agg**：5 つの背景で受け手ごとの順位の点を合計すると、O（M）の重みの塊は、W の重みの塊と比べて Δ_AB（D）を予測した向きに典型的でなかった。その頻度は、ドナーとしての O（M）が W と交換可能であるという帰無仮説の想定より多かった。0029 の一つの受け手での C-I を、同じ個体の 5 つの背景にまたがる形に広げたもの
- **J_OM^Agg**：**同じ個体で、5 つの背景をまたいで、O の重みと M の重みが D を逆の向きに外した、という内容に応じた逆向きの効果が、21 のドナーの交換可能性の想定より多くの個体で起きた**。受け手の中の比較は、位相・順応の違いでは説明できない（§2.4）
- **J_Ca^All・J_O^All・J_M^All**：**同じ個体の 5 つの背景のすべてで**、O（M）の重みの塊が Δ_AB（D）を W の重みの塊のすべてより予測した向きに外した個体が、想定より多かった
- **J_OM^All**：同じ個体の 5 つの背景のすべてで、O の重みと M の重みが D を逆の向きに外した個体が、想定より多かった（24008・24014・24019）

**組み合わせの注意**（§12）
- Agg・All の両方が成り立った：合計の形でも、5 つの背景のすべての形でも、帰無仮説を棄却した
- それでも、5 つの受け手の外の背景（ほかの W、O・M を受け手にした背景、ほかの時刻、W 型でない背景）への一般化は言わない

**言えないこと**

- 背景に依存しない（任意の背景で成り立つ）。背景によって効果が違う・違わない（異質性は検定していない）
- 重みが担い手だった・内容を運んだ、学習が原因・必要だった
- B に特有（J_Ca）。内容以外の説明を論理的に排除したこと（§4.4 の 6）
- 入れ替えた本体の振る舞いを、自然な個体で起きうる振る舞いと呼ぶこと
- 自然な差の再現・消去（C-II）、原因（C-III）、排他性・寄与の割合、6 本のどの組の重みか
- §15.5 の 4・5 の一致を、自然な差の再現・原因の証拠と読むこと
- 量だけの違い（X7）を除いたこと（重みの塊の外れは、重みが生んだ発火の数の違いを含む。§15.5 の 2 の型も含む）
- §15.5 の 2 の型の事象を数え直して、判定を弱めたり強めたりすること（§6.1）
- k の分布、h^All と h^Agg の違いを、背景への依存の量と読むこと
- 「0029 の効果が再現した」「0029 は W20 に特有ではなかった」と、0029 と 0031 の h を比べて言うこと
- 記憶ができた・内容を理解した・意味を持った・3 要素の順序や時間差を表した
