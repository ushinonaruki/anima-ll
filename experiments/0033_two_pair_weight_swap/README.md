### 2.2 入れ替える時刻 τ（個体ごとに 1 つ、すべての受け手・すべての入れ替えの種類に共通）

```text
τ ＝ max{ t ∈ [13441, 13500] ： Pulse t に、自然な 26 本体のどれでも、どの Unit も発火していない }
     （0029 §2.2・0031 §2.2・0032 §2.2 と同じ式）
```

- τ は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる。τ がない個体の扱いは §2.6

  - **2 組：AB＋AC、AB＋BC、AC＋BC（主）**。替える接続は 2 つの組の 4 本（組の順に並べる）

## 4. 主の判定

### 4.1 個体ごとの事象（2 組の種類 Q ∈ {AB＋AC, AB＋BC, AC＋BC} ごとに）

τ がある個体ごとに、種類 Q の入れ替えた 105 本体の主の区間の Δ_AB と D を計算し、§3.2 の点 S^{x,Q} を求める。

```text
2 組 Q の家族（一方向。0031 の Agg・0032 と同じ形）
  O の Δ_AB が上（Q）      ⇔  S^{Δ_AB,Q}(O) ＞ max_{d∈𝒲} S^{Δ_AB,Q}(d)
  O が上（Q）              ⇔  S^{D,Q}(O)    ＞ max_{d∈𝒲} S^{D,Q}(d)
  M が下（Q）              ⇔  S^{D,Q}(M)    ＜ min_{d∈𝒲} S^{D,Q}(d)
  O と M が分かれる（Q）   ⇔  O が上（Q） かつ M が下（Q）
```

- 不等号はすべて厳密。等号は「外にない」
- **凍結**：その判定に使う合計の点（J_Ca は O と 𝒲 の S^{Δ_AB,Q} の 20 個、J_O は O と 𝒲 の S^{D,Q}、J_M は M と 𝒲 の S^{D,Q}、J_OM は O・M・𝒲 の S^{D,Q} の 21 個）がすべて等しい個体は「外にない」に数え、除外しない（A7）
- τ がない個体は、12 の事象すべてで「外にない」（§2.6）
- 予測と逆の側の外れ（S^{Δ_AB,Q}(O) ＜ min、S^{D,Q}(O) ＜ min、S^{D,Q}(M) ＞ max）は「外にない」と同じに扱い、記録する（§6）
- 1 組・6 本の種類でも同じ 4 つの事象を計算するが、**補助の記録**で、判定しない（§6）

### 4.3 命題（事前に示す。結果を決めない）

**命題 5′（完全な要因の表）**【命題】：§3.4 の 8 通りの値から、主の項 α_P・2 組の項 β_PQ・3 組の項 γ は一意に決まり、f(z) ＝ μ ＋ Σ_P α_P z_P ＋ Σ_{P<Q} β_PQ z_P z_Q ＋ γ z_AB z_AC z_BC がすべての z で成り立つ。0032 の I は Σβ ＋ γ に等しい。

- 項は値の上の分解で、事象（点の外れ）の上の分解ではない。点は種類ごとに順位に直すので、値の項が 0 でも、事象の型は 1 組と 2 組で違いうる（逆も同じ）

### 4.4 帰無仮説と、交換可能性が成り立つ条件

| 判定 | 帰無仮説（個体ごと） | 個体ごとの上側の確率 |
|---|---|---|
| J_Ca^Q・J_O^Q | §4.3 の H_Q（O と W1〜W19） | **1／20 以下** |
| J_M^Q | 同じく M と W1〜W19 | **1／20 以下** |
| J_OM^Q | 21 のドナーすべての入れ替えに対する、2 組 Q の重みの不変 | **1／420 以下** |

**交換可能性が成り立つ条件と、成り立たない場合**（0032 §4.4 の 1〜8 を引き継ぐ）
1. W1〜W24 は同じ手順・別々の名前の乱数の流れから作った列で、そのドナーとしての重みは互いに交換可能とみなす（統計モデル上の前提）。**21 のドナーの交換可能性は、実際の生成の手順が保証する性質ではない**
2. O・M は W の作り方から生じた列ではない。帰無仮説は「その重みのドナーとして、O（M）は典型的な W と区別できない」という仮説で、O・M について確かめた性質ではない
3. **受け手とドナーの関係**：受け手の状態（残りの 1 組の重みを含む）は、ドナーの重みと独立とみなす（統計モデル上の前提）
4. **1 つの個体の中の受け手のあいだの従属**：受け手ごとの判定を並べず、個体ごとに一つの事象（合計の点）にする
5. 同じ値（引き分け）があると、厳密な不等号の事象の確率は上の値**以下**になる
6. **帰無仮説が内容と無関係に破れうる場合**：O・M の規則性が、重みを通して内容と無関係に O・M を W と違わせることはありうる。J_OM^Q は同じ個体・同じ種類で O と M が逆の向きに外れることを求めるので、同じ向きに動かす違いでは起こりにくい。ただし、内容以外の説明を論理的に排除しない
7. **個体をまたぐ独立性**：出生時の状態と並べ替えの乱数の流れを、個体間で独立とみなす（統計モデル上の前提）
8. **判定のあいだの従属**：家族の中・家族のあいだの判定は、同じ個体・同じ受け手・同じ組の重みを共有して従属する（AB＋AC と AB＋BC は A–B の組を共有する）。誤りの水準は、独立性を使わない Bonferroni の上界で抑える（§5）

## 5. 閾値と、誤りの水準

### 5.1 各家族（0032 §5.1 と同じ割り当て）

- 各家族の 4 つの判定に、**J_Ca・J_O・J_M に 0.005 ずつ、J_OM に 0.0015**（重みつきの Bonferroni、家族の合計 0.0165）
- J_Ca・J_O・J_M：P(h ≥ 5) ≤ P(Bin(20, 1／20) ≥ 5) ≈ **0.002574** ≤ 0.005（h ≥ 4 では ≈ 0.015902 ＞ 0.005）。閾値 5
- J_OM：P(h ≥ 2) ≤ P(Bin(20, 1／420) ≥ 2) ≈ **0.001047** ≤ 0.0015（h ≥ 1 では ≈ 0.046557）。閾値 2

### 5.2 実験全体（12 判定）の誤りの水準

- **この実験では、12 判定をまとめて誤りの水準 0.05 と主張する**：12 判定の割り当ての和は 3 × 0.0165 ＝ **0.0495** ≤ 0.05（Bonferroni。判定のあいだの従属に依らない）
- 1 組・6 本の種類の事象は補助で判定しないので、水準を使わない
- 閾値は、割り当てた水準と、個体ごとの帰無の確率（K ＝ 19）から決まる最小の整数。0032 と同じ値で、0032 の結果からは選んでいない
- 成立は、上の前提のもとで帰無仮説を各判定の水準で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- 家族の中・家族のあいだで、判定の成立を足し合わせたり、h を比べたりしない

### 15.6 言えること・言えないこと（§12・§13 に従う）

**言えること**

どれも、C0・この世界・この手順のもとで、5 つの受け手 W20〜W24 の残りの塊（Unit の状態・痕跡と、入れ替えない 1 組の重み）と τ を背景に固定し、個体間の独立性・受け手とドナーの独立という統計モデル上の前提のもとで、12 判定をまとめた水準 0.05 で言える。

- **J_Ca^{AB+AC}・J_O^{AB+AC}**：B–C の組を受け手の値に固定して、A–B・A–C の 2 組の 4 本の重みを入れ替えると、5 つの背景で受け手ごとの順位の点を合計して、O の 2 組の重みは、W の 2 組の重みと比べて Δ_AB と D を予測した向き（大きい側）に典型的でなかった。その頻度は、その 2 組の重みのドナーとして O が W と交換可能であるという帰無仮説の想定より多かった
- **J_OM^{AB+AC}**：同じ個体で、A–B・A–C の 2 組の重みだけで、O が D を W のすべてより大きくし、M が D を W のすべてより小さくする、ということが、21 のドナーの交換可能性の想定より多くの個体で起きた（閾値ちょうど。2 組の重みだけによる、経験の内容に応じた逆向きの効果。C-I）
- **J_Ca^{AB+BC}・J_O^{AB+BC}**：A–C の組を受け手の値に固定して、A–B・B–C の 2 組の重みだけで、O の重みは Δ_AB と D を大きい側に典型的でなくした
- **J_M^{AC+BC}**：A–B の組を受け手の値に固定して、A–C・B–C の 2 組の重みだけで、M の重みは D を小さい側に典型的でなくした
- 受け手と種類を固定した比較は、位相・順応の違いと、入れ替えない 1 組の重みの違いでは説明できない（§2.4・§4.3 の命題 3）

**組み合わせの注意**（§12）
- **J_OM^{AB+AC} が成立し、ほかの 2 組の J_OM が不成立**：§3.3 の見込みと矛盾しない結果だった、ということまで。「O の側は A–B、M の側は A–C から来た」「B–C は要らない」とは言わない。0032 で一つの組の J_OM が成り立たなかったことと合わせて、「J_OM は 2 組の組み合わせで初めて現れた」とも言わない（0032 と 0033 は個体が違い、h を比べない。この実験の中の 1 組の参照との型は §15.4 の記述）
- J_O・J_Ca が A–B を含む 2 組の種類（AB＋AC・AB＋BC）で成り立ち、AC＋BC で成り立たない、J_M が AC＋BC で成り立ち、AB＋AC・AB＋BC で成り立たない：成り立った種類では帰無仮説を棄却し、成り立たなかった種類では棄却できなかった、ということまで。「O の効果は A–B から、M の効果は A–C から来た」「ほかの組は関係ない」とは言わない
- J_M^{AB+AC} が成り立たなかった：見込みが外れた、または検出力が足りなかった（凍結：§15.5 の 4）。「A–B と A–C を合わせると M の効果が消える」とは言わない
- 要因の表の項・事象の型から、「相互作用があった・なかった」「加法的だった」と結論しない

**言えないこと**

- 2 組 Q が 0031 の 6 本の効果を担った・再現した・説明した。除いた組は要らない
- ほかの 2 組の種類・1 組は効かない（不成立は効かない証拠ではない）
- 種類のあいだの比較（「AB＋AC が主な組み合わせ」「AC＋BC の効果は弱い」）、寄与の割合
- 加法的だった・相互作用があった（§15.4 の要因の表・事象の型は記述）
- 組の中のどちらの向きの重みか
- 背景に依存しない（任意の背景で）・背景の異質性、O・M を受け手にした背景、ほかの時刻
- 自然な差の再現・消去（C-II）、原因（C-III）、排他性
- 量だけの違い（X7）を除いたこと（重みの外れは、重みが生んだ発火の数の違いを含む。§15.5 の 3 の型も含む）
- §15.5 の 3 の型の事象を数え直して、判定を弱めたり強めたりすること（§6.1）
- 入れ替えた本体の振る舞いを、自然な個体で起きうる振る舞いと呼ぶこと
- 記憶ができた・内容を理解した・意味を持った・3 要素の順序や時間差を表した
- h を母集団の割合と呼ぶこと。12 判定の水準 0.05 を、ほかの実験の判定の組み合わせに持ち出すこと
