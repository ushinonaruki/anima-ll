## 1. 問い

> **同じ seed の ordered・shuffled を 0015 と同じ経験・無入力の自発活動で終端（24000）まで進め、その後の τ_a の区間（24001〜24300）の各時点で、ordered の試しの元の A–B／A–C の 4 本の重みだけを、同じ時点・同じ試しの手順の shuffled の値に置き換える。置き換えた腕とそのままの腕で、標準の A の試しに対する直後の B・C の発火が、少なくとも 1 回は違うか**

### 言えること・言わないこと

成り立ったときに言うのは次まで：

> ordered の終端から続く Unit・痕跡の土台の上で、自然に実現した A–B／A–C の target weight substate を、同じ時点に shuffled の履歴が実現した substate に置き換えると、事前登録した割合の Birth State で、直後の離散的な活動が変わった

- **「D だけが読み出しを担った」とは言わない**。移植は W の差（D）と平均の成分の差（Δm）を一緒に動かす（§3.2）。D と Δm は記録として分けて出すだけ
- **「平均の成分は関係なかった」とも言わない**
- **「時間配置 → D → 残った D → 活動」の鎖がつながった、とは言わない**。0017 が示しうるのは、後の時点の 2 履歴間の target weight substate の差が、その時点で十分に読み出しを変えうること。12000 の D がそのまま運ばれたかは問わない（その間に W は自発力学で動く。0015 §10）
- **shuffled の土台に ordered の 4 本を移植する対称の腕は置かない**。土台の違いの上で同じ差が効くかは別の問い
- 成り立っても「記憶した」とは書かない

## 3. 試しと介入

### 3.1 手順

各試しの時刻 t0（24001〜24300）で、**両条件の本体の t0 − 1 の終わりの状態から独立に** 次を行う。試しはどれも本体に入れない。

```text
ordered の本体                         shuffled の本体
   ↓ t0 − 1 の終わりで複製                ↓ t0 − 1 の終わりで複製
受け手の試しの元                        提供側の試しの元
   ↓ t0 に Receptor A、t0 を処理          ↓ t0 に Receptor A、t0 を処理（同じ手順）
t0 の終わりで 2 腕に複製                 t0 の終わりの 4 本の weight を読む ───┐
   ├─ そのまま（as_is）                                                     │
   └─ 移植（transplanted）：4 本の weight だけを提供側の値に置き換える ←─────┘
          ↓ 可塑性ありのまま
      t0 ＋ 2 の s_B・s_C の発火を読む
```

- 4 本 ＝ w(A→B)・w(A→C)・w(B→A)・w(C→A)。介入は「D を移植」とは呼ばず、**A–B／A–C の target four-weight substate を移植** と呼ぶ（A5）。痕跡（pre_trace・post_trace）・Unit の状態・B–C の 2 本・それ以外は、すべて ordered の受け手のまま
- **提供側も同じ手順（t0 に A を入れて t0 を処理）にする理由**：移植する値を「shuffled の履歴が、受け手とまったく同じ手順の同じ時点に実際にとった値」と定義でき、受け手と提供側で手順が非対称にならない。runtime の順序では t0 の A の入力は t0 の発火・可塑性に入らない（A が発火するのは t0 ＋ 1。0014 §3.3）ので、提供側の値は shuffled の本体の t0 の終わりの値と一致するはずである。これは前提にせず、手順で揃えたうえで操作の確認（§6）で確かめる
- runtime の順序から、2 腕は t0 の終わりまで同一で、t0 ＋ 1 の発火も同一。t0 ＋ 2 の B・C で 2 腕が違いうるのは、A→B・A→C を通る s_A の t0 ＋ 1 の伝達だけ（0014 §3.3、0016 と同じ。B→A・C→A の違いは t0 ＋ 2 の B・C には届かない）。道具の段で契約テストにする（常設チェック B1・B3）

### 3.2 なぜ 4 本まるごとの移植か（常設チェック A5・A6）

- **新しい数値を作らない**：移植する値は shuffled が自然に実現した値そのもの。式・切り詰め・拡大縮小・適用条件を置かない
- **状態空間の外に出ない**：提供側の 4 本は実際に起きた状態なので、重みの範囲 [0, w_max] と組の和の不変量 w(i→j) ＋ w(j→i) ＝ w_max（`docs/plasticity-v1.1-scale.md` §8）を必ず満たす。受け手の B–C・痕跡と組み合わせても、組の和は 4 本の中で閉じている（A–B・A–C の組だけ）
- **D だけの移植を主にしない理由**：x ＝ w(A→B)、y ＝ w(A→C)、m ＝ (x ＋ y)／2、W ＝ x − y とする。ordered の m のまま W だけを shuffled の値にする置き換え（x* ＝ m_o ＋ W_s／2、y* ＝ m_o − W_s／2）は、自然な状態空間の中に常にあるとは限らない。ChatGPT が 0015 の本番の記録（6001〜6020、独立した既存の測定）で確かめたところ、24000 で成り立つのは 17/20 で、6006・6009・6015 では組の非対称が w_max を超える値が要る（例：6006 で ≈ ＋0.0107、w_max ＝ 0.01）。これを主にすると、切り詰め・拡大縮小・適用条件のどれかを新しく足すことになる
- したがって 0017 の名前は「残った D は読み出しを担うか」ではなく **「A–B／A–C の 4 本の重み（target weight substate）だけを、相手の履歴が同じ時点にとった値に置き換える」**（A5）。痕跡は置き換えない
- D に固有の効果を切り分けるなら、別の実験 **Q8b** として、両腕を同じ中立の平均 m ＝ w_max／2 に置き、W だけを W_ordered と W_shuffled にする別の実験（標準化した背景の上の機構の切り分け。自然な媒介の検定ではない）が数学的に作れる（|W| ≤ w_max なので常に範囲内）。これは「自然な ordered の軌道の上での媒介」ではなく「標準化した背景の上での history-derived contrast の因果効果」という別の問いなので、0017 ではやらない

### 3.3 受け手と提供側が指す runtime の境界（常設チェック B1〜B3）

「同じ t0」という名前だけでなく、受け手と提供側が 1 Pulse の処理のどこまで終わった状態を指すかを固定する。runtime の 1 Pulse（`src/anima_ll/runtime/pulse_runtime.py` の `run_pulse`）は、(1) 冒頭でその Pulse の伝達に使う重みを固定、(2) 感覚の出来事・発火を駆動にして次の Pulse に届ける、(3) 終わりにその Pulse の発火を接続の状態に渡す（可塑性）、の順である（0014 §3.3）。

| | 受け手（ordered） | 提供側（shuffled） |
|---|---|---|
| 複製の元 | 本体の Pulse t0 − 1 の (3) まで終わった状態 | 本体の Pulse t0 − 1 の (3) まで終わった状態 |
| t0 の処理 | Receptor A の出来事を 1 つ入れ、Pulse t0 の (1)〜(3) をすべて終える | 同じ |
| 指す状態 | **Pulse t0 の (3)（可塑性の更新）まで終わり、t0 ＋ 1 の (1) の前** の状態。ここで 2 腕に複製し、移植の腕の 4 本だけを置き換える | **同じ境界** の状態の 4 本の weight を読む |

- 置き換えた 4 本は、移植の腕の t0 ＋ 1 の (1) で伝達に使う重みとして固定される。t0 の伝達と可塑性には入らない（t0 の終わりまで 2 腕は同一）
- t0 ＋ 1 の Unit が受ける駆動は t0 の (2) で t0 の冒頭の重みで凍結されているので、t0 ＋ 1 の発火は 2 腕で同じ。t0 ＋ 2 の B・C で違いうるのは、s_A の t0 ＋ 1 の発火が A→B・A→C を通る伝達だけ
- t0 の A の出来事は t0 の (2) で t0 ＋ 1 への駆動になるだけで、t0 の発火と t0 の (3) には入らない。したがって、2 腕の分けた直後の重みは ordered の本体の t0 の終わりの重みと、提供側の重みは shuffled の本体の t0 の終わりの重みと、それぞれ一致するはずである。両方を操作の確認（§6）で、保存した生の記録から確かめる
- 道具の段の契約テスト（実物の runtime）：2 腕の t0 ＋ 1 の一致、ゼロの移植で E ＝ 0、s_A が t0 ＋ 1 に発火しない試しでは E ＝ 0、上の 2 つの重みの一致

## 4. 指標と判定

```text
各試し：E(t0) ＝ |B_as_is(t0) − B_transplanted(t0)| ＋ |C_as_is(t0) − C_transplanted(t0)|   ∈ {0, 1, 2}
        B・C は、その腕で s_B・s_C が t0 ＋ 2 に発火したら 1、しなければ 0
個体ごと：S ＝ Σ_t0 E(t0)                                                             主の判定 s：S ＞ 0
```

| 判定 | 適用対象 | 成り立つ | 個体群として成り立つ |
|---|---|---|---|
| **主 s** | すべての個体 | S ＞ 0（300 回のどこかで 1 回以上、移植で読み出しが変わった） | 成り立った個体数 ÷ 20 ≥ 0.8 |

- **nonzero causal-readout test であり、向きの検定ではない**（§4.1）
- **式の形（A6）**：E・S は 0016 と同じ形で、介入だけを替えた。S ＞ 0 は「300 回のうち 1 回以上 E ＞ 0」と同じ。平均・比・閾値を主に入れない。S の大きさは記録
- **適用対象（A3・A7）**：すべての個体。適格を切らない。**仮に 300 回すべてで 4 本が提供側と一致する（移植が何も変えない）個体が出ても、N/A ではなく S ＝ 0 の不成立とする**。0017 の問いは「履歴の違いが、後の時点に target weight substate の差として残り、それが読み出しを変えるか」という whole-pipeline の問いで、差が残らなかったこともその答えの一部だから（0016 で W_probe が全試しで 0 の個体を S ＝ 0 とした扱いと同じ）。2 条件は札の並びが違う別々の発火の列を持つので、4 本が浮動小数点で完全に一致し続けることは実際にはまず起きないが、起きた場合の扱いを先に決めておく
- **4 本が一致する試しを専用の分岐で除外しない**。そうした試しでは 2 腕は同一で E ＝ 0 になり、S にふつうの算術で 0 として入る（A3）
- 0.8 は効果の大きさの閾値ではない

### 4.1 符号・非空虚性の確認（A1・A7）

- **A1**：E ≥ 0 は定義からそうなる。さらに、単調な Unit の力学では、t0 ＋ 2 の B の変化の向きは w(A→B) の差の符号から、C の変化の向きは w(A→C) の差の符号から、構造上決まる（0014 §9.3 と同じ理由）。移植は x と y を独立に動かす（平均の成分も動く）ので、B と C が同じ向きに変わることもある。向きは問わず、効果が 0 でないかだけを問う。向き（各 E ＞ 0 の試しで、B・C の変化の符号が x・y の差の符号と一致したか）は記録
- **A7**：0015・0016 で、無入力の区間に A が一度も自発発火せず W が実効的に凍結した個体があった。0017 では外から A を入れるので、凍結した個体にも読み出しの機会があり、移植の差（ordered の凍結した値と shuffled の値の差）も残る。凍結を問いの対象外にせず含める。一方、受け手（B・C）が閾値に近づかない状態では、4 本が違っても S ＝ 0 になりうる（0016 の 8009・8018）
- **合成の runtime の全状態からの契約テスト**（道具の段で書く。合成専用の seed 9400〜9499 だけを使う。自然な seed・smoke の結果では確かめない）：妥当な全状態（Unit の状態・痕跡・重み。組の和 ＝ w_max）の **受け手と提供側の組** を作り、実物の runtime で 0017 と同じ手順（両方の本体を無入力で進め、各 t0 で独立に試しの元を作る）を通して、
  - (i) **300 回すべての試しで、移植が少なくとも 1 本の target weight を実際に変えている（4 本のどれかが受け手と提供側で違う）のに、300 回すべてで E ＝ 0（S ＝ 0）** になる組
  - (ii) **S ＞ 0** になる組

  の両方がありうることを、具体的な状態で示す。(i) で途中から 4 本が一致して移植が何も変えなくなる組は条件を満たさない
- **ゼロの移植の契約**：提供側の 4 本が受け手と同じなら、2 腕は t0 ＋ 2 まで同一（E ＝ 0）になることを、実物の runtime で確かめる（移植の操作そのものが読み出しを変えないこと）

### 4.2 測れる大きさか（C3）

独立した既存の測定（0015 の本番の記録 6001〜6020 の 24000。別の seed）で、移植がどれだけ重みを動かすかの見当をつける。|D|（W_ordered − W_shuffled）の中央値 2.2 × 10⁻³、|Δm|（平均の成分の差）の中央値 1.2 × 10⁻³ で、0016 型の equalize が動かす量（同じ記録の |W_ordered| の中央値 2.6 × 10⁻³。equalize はその半分ずつを x・y に動かす）と同じ桁だった。0016 の equalize は 18/20 で S ＞ 0 だったので、移植の差は「力学に対して測れない大きさ」ではない、という見当になる（値の調整には使わない。smoke では見ない）。
