## 1. 経緯

- 0012 の事前登録 v0.2（README・protocol.yaml）は、**本番の測定の前に改訂する**。結果はまだない
- seed 1001 の動作確認で、s_A の発火が運ぶ 0.25 だけで s_B と s_C が両方閾値を越え、経験の前の試しの指標が上限に張り付くこと、経験の中でも B・C の刺激がそれに埋もれること、3 つの Unit のあいだで反響が数十秒続くことが見つかった（PR #48 の本文）

## 2. 原因の切り分け（式）

### 2.1 静止しているときの、閾値までの距離

力学：`activity ← activity × decay ＋ 刺激 ＋ intrinsic_drive`。発火しない Unit の活動は `a* ＝ intrinsic_drive／(1 − decay) ＝ ρθ` に落ち着く。

**静止時の閾値までの距離** `d ＝ θ ＋ adaptation − a*` を定義する。1 本の入力の重み w で、静止している Unit が発火するのは `w ≥ d` のとき。

minimal-v3 の値（decay 0.85、θ 0.5、内在的駆動 0.08、jitter ±10%）で、出生時のばらつきの式を格子で計算した結果は次のとおり。

| | 割合 | 振る舞い |
|---|---|---|
| ρ < 1（静止する） | 約 23% | d ＝ θ − a* は最大 0.070（θ の 12.7%）、中央値 0.021、上位 10% の点で 0.048 |
| ρ ≥ 1（自発的に発火する） | 約 77% | 孤立した Unit の式で、順応（α 0.01・τ_a 300）があると、自発発火の間隔の中央値は約 57 秒。間の大半は a* の近くで、順応が下がるのを待っている。そのあいだの実効の d は、順応の 1 段（α ＝ 0.01）の程度 |

どちらの Unit でも、**静止時の閾値までの距離は小さい**。内在的駆動を、臨界の直上（ρ ≒ 1.07）に置いたことの帰結である（台帳 §3.3）。

### 2.2 読み出しの感度の範囲と、重みの範囲の食い違い

静止している Unit が、1 本の入力 w で発火する割合（ρ < 1 の Unit について）：

| w | 0.25（今の w0） | 0.125 | 0.05 | 0.02 | 0.01 |
|---|---|---|---|---|---|
| 発火する割合 | 1.00 | 1.00 | 0.92 | 0.49 | 0.27 |

- 試しの読み出し（1 回の s_A の発火で s_B・s_C が発火するか）が重みの違いを区別できるのは、おおむね **w が 0〜0.07 の範囲** だけ。それより大きい重みは、ほぼすべて「必ず発火」になる
- 一方、可塑性 v1 の重みは `0 ≤ w ≤ w_max ＝ θ ＝ 0.5` を動き、初期値は `w0 ＝ w_max／2 ＝ 0.25`
- つまり、**重みの範囲の大半が、読み出しが上限に張り付く側にある**。w0 はその真ん中にある

### 2.3 「可塑性にとって中立」と「力学にとって中立」は別物

- `w0 ＝ w_max／2` は、釣り合った窓と柔らかい上限・下限の組み合わせで、偏りのない組の数なら期待値が釣り合う点（可塑性 v1 の設計案 §3.3）。**可塑性の規則にとっては中立**
- しかし、Unit の力学と組み合わせると、`w0 ≫ d` なので 1 本で受け手を必ず発火させる。**ネットワークの力学にとっては強い興奮性の結合**になる
- 食い違いの元は、重みの尺度（w_max ＝ θ：工学的な正規化）と、静止時の閾値までの距離の尺度（おおむね |1 − ρ|θ ≒ θ／15）が、10 倍以上離れていることにある

### 2.4 反響

- 1 本で受け手を発火させる重み（w ≥ d）の接続が閉じた輪になると、1 回の発火が回り続ける。今は 6 本すべてが w0 ＝ 0.25 ≫ d なので、どの 2 本の組も輪になる
- 反響を止めているのは、順応の積み上がりだけ（seed 1001 では約 30 秒）
- 釣り合った窓は、A → B を強めると B → A を弱める。そのため学習そのものは輪を壊す向きに働く。ただし、出発点の全辺が d を超えていると、その前に反響が起きる

## 3. 設計条件（案。数値より先に固定したいもの）

ChatGPT の 5 つ（C1〜C5）に、Claude が 2 つ（C6・C7）を足した。C6 は ChatGPT のレビューで弱めた（v0.2）。

| | 条件 | 式での意味（§2） |
|---|---|---|
| **C1** | 経験の前の試しで、s_A の 1 回の発火だけで s_B・s_C が自動的に発火しない（指標が上限に張り付かない） | 経験の前の重み w(A→B)・w(A→C) が、受け手の d を多くの個体で下回る |
| **C2** | A の刺激 1 回から、長い自己持続の反響が起きない | w ≥ d の接続が閉じた輪を作らない（出発点で） |
| **C3** | 順序ありの経験で、B・C の刺激による発火が、A 自身が引き起こす B・C の発火に先に埋もれない | 経験の始まりで w(A→B)・w(A→C) < d（C1 と同じ不等式） |
| **C4** | 初期の接続の状態を、H1 に有利な向きへずらさない | 6 本・3 条件で同じ値。規則または力学から決まる値で、結果を見て選ばない |
| **C5** | 報酬・意味のラベル・行動の選択などを足さない | — |
| **C6** | 読み出しが、許される接続の状態の全域を、構造的に同じ値へ潰さない | 設計の上で、重みの範囲（w_min〜w_max）のほぼ全体が「1 本で必ず発火」の側にある、ということがない。**経験の後に B・C を区別できることは要求しない**（経験の後の重みの分布を想定して値を選ぶと、H1 の結果に近づきすぎるため）。失敗の結果として両方が飽和することは許す |
| **C7** | 条件は、式と範囲外の seed の動作確認だけで確かめる | 動作確認で見る「飽和していない」の項目を、本番の前に事前に決める（例：経験の前の試しで、s_B と s_C の窓の発火の割合が、両方とも 1 に張り付いていない） |

C1〜C3 は同じ不等式（Unit → Unit の重みと、静止時の閾値までの距離 d の大小）に帰着する。C6 は、その不等式を重みの許される範囲の全体について見たもので、設計図の構造の条件である（経験の結果の条件ではない）。

## 4. 設計の候補の系統（数値は決めない。条件に対する評価だけ）

| 系統 | 中身 | 条件に対して |
|---|---|---|
| **K1** | w0 だけを d より小さくする（w_max ＝ θ のまま） | C1〜C3 は満たす。しかし C4 の「規則から決まる w0」から外れる。また、自発発火による組が存在する限り、w0 だけを下げてもその値は規則の平衡点ではない。w_max／2 の向きへの期待のドリフトが生じうる（どれだけ生じるかは、自発発火の相関の構造による。刺激なしだから自動的にそこへ向かう、とまでは言えない）。重みの範囲の大半が飽和の側にあるので、C6 も満たさない。尺度の不整合そのものは残る |
| **K2** | w_max を、Unit の力学の応答の余地の尺度から導く。w0 ＝ w_max／2 は保つ | C1〜C4・C6 を同時に満たせる見込みのある系統。可塑性 v1 の設計案 §3.3 の「w_max ＝ θ（工学的な正規化）」を改める（可塑性 v1.1 の設計問題。文書と台帳の改訂が要る）。論点：d は **状態量**（activity・adaptation は Life History で変わる）なので、今の d から w_max を逐次決めると、接続の状態の許される範囲そのものが経験で動く。導くのは、Neuroarchitecture・Birth State から定義できる特性尺度でなければならない。また、出生の分布の何パーセント点、という決め方は新しい恣意性になる |
| **K3** | 内在的駆動を下げて、Unit を閾値から離す | 力学を変える。minimal-v3 の参照値と、0004〜0011 の基準が及ばなくなる。0012 の README §1「力学の値を変えない」に反する |
| **K4** | 読み出しだけを変える（窓をずらす・段階のある指標にする） | C2・C3 を直さない（経験の中の埋没と反響は残る）。ChatGPT も推さない |
| **K5** | 抑制などの新しい仕組みを足す | C5 と「仕組みを足さない」に反する |

**K2 を選ぶ**（Claude・ChatGPT とも、2026-10-11）。食い違いの元（§2.3 の尺度の違い）を、元の場所で直す系統だからである。ただし、これを「0012 用の w_max」にはしない。可塑性 v1.1 の設計問題として 0012 から切り離し、先に議論する。
