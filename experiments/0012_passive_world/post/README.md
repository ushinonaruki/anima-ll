## 0. まとめ

| 候補 | わかったこと（範囲外の 20 個体） |
|---|---|
| **A. 読み出しの感度** | 読み出しは重みに素直に反応する（重み 0.001 あたり、窓での発火の割合が約 0.04 上がる）。順序ありの重みの差は、それだけを取り出すと活動に **+0.023 ± 0.007** の寄与をしていた。しかし同じ個体で、**s_B の興奮しやすさが下がっていて**（主に順応）、それが打ち消した。試しを約 200 回に増やしても、D はほぼ 0 のままだった。**「20 回では少なすぎた」は主な原因ではない** |
| **A の内訳：順応** | 経験の後の始まりで、s_B の順応は s_C より **0.012 ± 0.005** 高かった（順序あり・順序を崩した刺激とも。刺激なしは 0.003）。B の刺激 160 回と C の刺激 40 回という刺激の数の偏りから来る。この差は、重みの範囲全体（w_max ＝ 0.01）を超える |
| **B. 刺激なしのドリフト** | 個体ごとの重みのずれの 79% は d ＝ 1 の組から来ている（相関 0.90）。S の駆動で T が次の Pulse に発火すると、S → T が強まり、T → S が弱まる。**接続そのものが d ＝ 1 の相関を作るので、「独立な発火なら平均は動かない」という釣り合いの前提が、個体ごとには成り立たない**。刺激なしの W の個体間の標準偏差（0.0037）は、順序ありの W の平均（0.0014）より大きい |
| **C. A → C の強まり** | A → C を強めた最大の源は、C の刺激（d ＝ 2、0.0012）ではなく、**s_A 自身の駆動で s_C が t＋2 に発火した組**（d ＝ 1、0.0017）。s_A の駆動は、B の試行でも C の試行でも、s_B・s_C を約 2 割ずつ発火させる。そのため、A → B と A → C を同じように強める **共通の成分** がある。順序に固有の信号は d ＝ 2 の組で、A → B が 0.0035、A → C が 0.0012 |

一行で言えば：**重みの差は活動に届いていた。しかし、同じ経験が作った順応の偏り（刺激の数の偏りから来る）が、それを打ち消した。H1 の対照のうち「刺激なし」には、この偏りがない**。

## 2. 再生の計算（`replay.py`）

保存した発火の記録から、可塑性 v1.1 の規則を同じ順番で計算し直した。60 本 × 6 接続のすべてで、記録された最後の重みと一致した（誤差 2 × 10⁻¹⁸）。

痕跡は過去の発火の和なので、強める量・弱める量を、どの過去の発火との組（時刻の差 d）から来たかに、比例して正確に分けられる。B・C はこの分け方を使った。

## 3. A：読み出しの感度（`readout.py`・`excitability.py`）

### 3.1 応答曲線

刺激なしの個体の、経験の前の試しの時刻（20 個体 × 20 回 ＝ 400 回）で複製を作った。**複製の上でだけ** w(s_A→s_B)・w(s_A→s_C) を値 v に置き換えて、試しを行った（実験の道具による解析の操作。本体の個体には触らない）。

| v | 0 | 0.0025 | 0.005（w0） | 0.0075 | 0.01（w_max） |
|---|---|---|---|---|---|
| s_B が窓で発火した割合 | 0.025 | 0.133 | 0.238 | 0.335 | 0.415 |
| s_C が窓で発火した割合 | 0.033 | 0.128 | 0.248 | 0.348 | 0.440 |

ほぼ直線で、重み 0.001 あたり約 0.04。可塑性 v1.1 の解析（1 本の入力で発火する確率 0.32 → 0.46）とも合う。読み出しは、重みの範囲全体で感度を持っている（C6）。

### 3.2 試しを密にしても D は 0 のまま

本番と同じ手順の個体で、経験の前・後の区間に、試しを 6 Pulse ごとに置いた（前後それぞれ 199 回。本番は 20 回）。

- D の平均：順序あり 0.003、順序を崩した刺激 −0.020、刺激なし −0.008
- D(順序あり) > 0 の個体は 10／20。H1 と同じ形を満たす個体は 5／20
- D の個体間の標準偏差は 0.06〜0.085（20 回の本番では 0.10〜0.14）

3.1 の傾きから、W ≒ 0.0014 なら D は約 0.06 になるはずだった。試しを増やすとゆらぎは減ったが、D の平均は 0 に近いままだった。**重みの効果を打ち消す何かがある**。

### 3.3 打ち消していたもの：s_B の興奮しやすさ（順応）

経験の後の試しの時刻（6 Pulse ごと、199 回）で、次の 2 つを比べた。

- **ふつうの試し**
- **複製の上で w(s_A→s_B)・w(s_A→s_C) をその時点の 2 本の平均に揃えた試し**（重みの差を消した、仮の状態）

R ＝「s_B が窓で発火した割合 − s_C が発火した割合」（20 個体の平均 ± 標準誤差）：

| 条件 | 経験の後の始まりの順応の差（s_B − s_C） | R（ふつう） | R（重みを揃えた） | 重みの差の寄与（差） |
|---|---|---|---|---|
| 順序あり | **0.012 ± 0.005** | 0.007 ± 0.025 | **−0.016 ± 0.025** | **+0.023 ± 0.007** |
| 順序を崩した刺激 | 0.012 ± 0.006 | −0.016 ± 0.019 | 0.016 ± 0.020 | −0.032 ± 0.014 |
| 刺激なし | 0.003 ± 0.007 | −0.004 ± 0.012 | 0.027 ± 0.022 | −0.031 ± 0.016 |

- 順序ありでは、**重みの差の寄与ははっきり正**（+0.023 ± 0.007）
- 重みを揃えた R（重み以外の寄与）を、同じ個体の対照と比べると、順序あり − 刺激なし ＝ **−0.043 ± 0.023**、順序あり − 順序を崩した刺激 ＝ −0.032 ± 0.016。順序ありでは、s_B のほうが発火しにくくなっていた
- その打ち消しは時間とともに弱まる。順序ありで重みを揃えた R は、経験の後の前半 −0.030 → 後半 −0.002。順応の時定数（τ_a ＝ 300 秒）で戻ることと合う。経験の後の試しは、最後の試行の約 60 秒後から始まる
- 順応の差（0.012）は、B の刺激が C の 4 倍（160 対 40）あることから来る。これは順序ありと順序を崩した刺激に共通で、刺激なしにはない。**H1 の 3 つの条件のうち「D(順序あり) > 0」と「D(順序あり) > D(刺激なし)」は、この偏りの分だけ不利になる**

注意：重みの寄与は「重みを平均に揃えた」という仮の状態との差で測っている。重み以外の差を全部「順応」と呼べるかは確かめていない（ほかに、接続の重みの全体の変化、ほかの Unit からの入力なども効きうる）。また、20 個体の標準誤差は小さくない。

## 4. B：刺激なしの重みのドリフト（`why.py` の B_silent_drift）

刺激なしの 20 個体 × 6 接続 ＝ 120 本で、経験の後の重みの w0 からの変化 Δw を調べた。

- Δw の標準偏差 0.0035
- |Δw| のうち、d ＝ 1 の組（S が p − 1、T が p に発火）から来た分の割合：**79%**
- Δw と、d ＝ 1 の組から来た分との相関：**0.90**
- Δw と、「S の 1 Pulse 後に T が発火した回数 − T の 1 Pulse 後に S が発火した回数」との相関：0.87
- Δw と、発火の頻度の差（S − T）との相関：0.51

読み：

- 接続の重みは小さいが（0.005）、受け手が待ちの状態にいると、1 本の入力で約 3 割の確率で発火を前に寄せる（可塑性 v1.1 §4）
- そのため S の発火の 1 Pulse 後に T が発火する組（d ＝ 1）が、偶然より多く起きる。それが S → T を強め、強まった S → T はさらに d ＝ 1 の組を増やす（**結合を通した、自己強化するヘッブ的なドリフト**）
- 発火の多い Unit が「先導」になりやすい
- 釣り合った窓の「偏りのない組なら平均は動かない」は、発火が互いに独立という前提の上の話である。**結合した網では、接続が自分で組の偏りを作る**。全体の符号つきの平均は 0 のまま（本番でも 0）だが、個体ごと・接続ごとには大きく動く

## 5. C：A → B・A → C の変化の内訳（`why.py` の C_a_to_bc_parts）

順序ありの 20 個体で、経験の始まりから経験の後の始まり（Pulse 13799）までの変化を、組の種類に分けた（20 個体の平均）。

| 組の種類 | A → B | A → C |
|---|---|---|
| 強める：試行内 d ＝ 1（s_A の駆動で、受け手が t＋2 に発火） | +0.0011 | **+0.0017** |
| 強める：試行内 d ＝ 2（B の刺激の試行で t＋3 に発火） | **+0.0035** | +0.0003 |
| 強める：試行内 d ＝ 2（C の刺激の試行で t＋3 に発火） | +0.0001 | +0.0012 |
| 強める：試行の s_A とのそのほかの組 | +0.0001 | +0.0007 |
| 強める：経験中のそのほか（自発どうし） | +0.0006 | +0.0005 |
| 弱める：試行の s_A の発火（受け手が先に発火していた） | −0.0010 | −0.0009 |
| 弱める：経験中のそのほか | −0.0003 | −0.0009 |
| 経験の外（Pulse 1800 より前など） | −0.0002 | −0.0001 |

試行の中での発火（順序ありの 20 個体、4000 試行）：

| | t＋2（s_A の駆動だけが届く） | t＋3（感覚が届く） |
|---|---|---|
| B の試行で s_B | 0.23 | 1.00 |
| B の試行で s_C | 0.23 | 0.06 |
| C の試行で s_B | 0.19 | 0.09 |
| C の試行で s_C | 0.24 | 1.00 |

- s_A の駆動（t＋2）は、試行の種類によらず、s_B・s_C を約 2 割ずつ発火させる。この d ＝ 1 の組は、A → B と A → C の **両方** を強める共通の成分になる
- 柔らかい上限のため、すでに強い A → B のほうが、1 回あたりの強まりが小さくなる。そのため、d ＝ 1 の成分は A → C のほうが大きくなった
- 順序に固有の信号は d ＝ 2 の組（A → B 0.0035、A → C 0.0012。理想の比 160：40 ＝ 4 に対して約 2.9）
- 結果として、W（A → B − A → C）は、A → B の上がり幅（約 0.004）の 3 分の 1 程度にとどまった

## 6. 次の設計の問い（0012 の値は変えない。次の事前登録のための材料）

1. **刺激の数の偏りと順応**：p ＝ 0.8 は、順序の偏りと同時に、B・C の刺激の数の偏りを作る。その偏りが、順応を通して読み出しに逆向きに効いた。次の実験では、順序の構造と刺激の頻度を切り離すか（例：B・C の刺激の数を揃え、順序だけを変える）、読み出しの時刻を順応の戻り（τ_a）に対して置くかを、事前に決める必要がある
2. **対照の選び方**：「刺激なし」は、刺激の数の偏りの効果を持たない。H1 の比較の主を何にするか（順序を崩した刺激は同じ偏りを持つ）を、次の問いの形から決める
3. **結合した網での釣り合い**：釣り合った窓は、結合した網では個体ごとにドリフトする（§4）。これを「規則の欠陥」と見るか、「結合を通した学習の性質」と見るか。可塑性の規則の設計の問いとして扱う（S3・S4 などの安定化を足す前に、§2.2 の 4 つの問いに当てる）
4. **s_A 自身の駆動による共通の成分**：d ＝ 1 の組は、P2（順序の構造）の中で「自分の発火が起こした受け手の発火」を学ぶもの。外の順序（刺激）とは別の、内の因果の組である。次の実験で、どちらを測るかを分ける
5. **読み出しの単位**：1 回の試しの、3 Pulse の窓の発火の有無は、重みには素直に反応する（§3.1）。ただし、興奮しやすさの変化と区別できない。重みの差と興奮しやすさを分けて測れる読み出し（たとえば、§3.3 のような複製の上での比較）を、正式な測定にどう組み込むか
