## 0. 実行の形式と、問いと主張の範囲

### 0.1 実行の形式：0039 型の事前登録の実験にする

**0039 型の事前登録の実験**（事前登録 → 道具 → 盲検の smoke → 本番の一度限りの実行 → 結果）にする。0038 型の前方の関門にはしない。

| 観点 | 0038 型の前方の関門 | 0039 型の事前登録の実験（この実験） |
|---|---|---|
| 推定対象 | 操作の可能性 | **同じ個体で、規則のもとで形づくられた重みだけを入れ替えたときの、試しの区間の選択の差 T の、個体ごとの分布**（現象の量）。判定 J_T と推定 E_T（§4） |
| seed | 関門の専用の seed を一度だけ | 契約テストの合成の seed（35301〜35399）・盲検の smoke（35201〜35206）・判定の一度限りの seed（35001〜35200）を分ける（§9.2） |
| 判定の量の表示 | 関門の量だけ | 契約テストと smoke では表示しない（権限の文書 §3）。本番で一度だけ計算する（§9.3） |

- **この形にする理由**：推定対象は選択の差の向きそのもので、現象の量である。0038 型の関門はこの量を出さない
- **別の関門を置かない理由**：本体 B^{A1}・B^{A2} は関門の本体と同じ組み立てで、窓の選択が出ることは関門（0038）で確かめてある。移植・FREEZE・複製・世界の応答の切り替えが AS2b で動くことは、AS2b の契約テスト（CT-Σ・CT-ΣE4）と 0039・0040 の道具で確かめてある。関門を足すと、その結果を見て値を選び直す道が開く

### 0.2 問い

> **問い Q-T**：同じ個体（seed）の二つの本体 B^{A1}・B^{A2}（規則 c ＝ A1 と c ＝ A2。ほかはすべて同じ。可塑性あり、世界は規則 c が指す行動にだけ結果を返す）を、関門と同じ組で、経験の区間 E（窓 1〜25）の終わりの境界 P_E ＝ 1,065 まで走らせる。P_E で各本体を複製し、6 本の重みを、自分の重み W^c のまま、またはもう一方の本体の重み W^d に替えて（PC-4 の型の移植）、試しの区間 U（窓 26〜50）で 6 本を FREEZE して走らせる。世界は背景の本体の規則 c のまま（閉ループ）。試しの区間の A1 の割合 s から、
>
> T_i ＝ [s(G^{A1}[W^{A1}]) − s(G^{A1}[W^{A2}])] ＋ [s(G^{A2}[W^{A1}]) − s(G^{A2}[W^{A2}])] ＝ T^{(A1)}_i ＋ T^{(A2)}_i
>
> を求める。
> - **判定 J_T**：T が定まり 0 でない個体の中で、T の向きがそろう個体は、事前に決めた基準を超えて多いか
> - **推定 E_T**：T が定まる個体のうち、合算の T が 0 でない個体はどれだけあり、少なくとも一方の背景で重みの入れ替えが選択の割合を変えた個体（T^{(A1)} ≠ 0 または T^{(A2)} ≠ 0）はどれだけあり、T はどれだけか

- 向きは事前に決めない。両側で問う（§4.5）。提案の文書 §2.4 の見込み（0040 の＋と 0041 の−を形式の上で続けた向き）は、片側の向きにも、閾値・判定の形の選び方にも使わない
- **主の問い**：この実験の主の問いは、**合算の T が 0 でない個体に限った、条件付きの向き**（その個体の中で、T の符号が＋と−で偏るか）である。「T が定まる個体の過半数で一方向に動くか」（広がりと向きを合わせた多数の問い）は、判定では問わず、広がりを推定 E_T（p_nz・p_any）で示す。この選び方は研究の目的の選択で、多数・広がりの判定を捨てる費用と、0039 の既知の結果による影響の可能性がある。理由・費用・境界は §4.5 に書く
- **T ＝ 0 の意味**：T ＝ 0 は「どちらの背景でも選択が変わらなかった」と同じではない。二つの背景で逆向きに同じだけ変わった個体（打ち消し）も T ＝ 0 になる（§3.2）
- **(iv-a) の問い**：提案の文書 §2.1 の段 (iv) のうち、「同じ個体で、規則の違いのもとで形づくられた重みの違い**だけ**を入れ替えたとき、後の選択は変わるか」を問う。総効果（規則の入れ替えで後の選択が変わるか）とその内訳 (iv-b) は問わない。総効果は記述の対照にとどめる（§6.1）
- **0039 との関係**：本体 B^{A1}・B^{A2}・境界 P_E・移植の系 G^c[·] の組み立ては、0039 と同じである。0039 の J_W は、c ＝ A1 の背景だけの D^W を、J_7 の成立のときだけ判定する固定の順序の二番目に置き、J_7 の不成立で判定しなかった。この実験は、二つの背景の和 T を、総効果の判定を前に置かない唯一の主の判定にし、新しい個体群で問う。0039 の判定を確かめ直したり救ったりするものではなく、0039 の J_7 の不成立の理由の説明にも使わない（§11・§13）
- **0040・0041 との関係**：問いを立てる理由は、0041 の J_B（規則で重みの差の向きがそろう：段 (ii)）と 0040 の J_A（前もって固定した端の重みで選択が変わる：段 (iii)）の成立である（提案の文書 §4.1）。二つの結果を、規則 → 重み → 選択の媒介としてつながない（§0.4）

### 0.3 主張の形（J_T が成立したとき）

「AS2b（関門の組：C0 の力学と可塑性、関門の予定・窓・出口・役、結果を返す世界）で、同じ個体の二つの本体を規則 c ＝ A1・A2 で経験の区間（窓 1〜25）まで育て、P_E で各本体の複製の 6 本の重みだけを、自分の重みともう一方の本体の重みとで入れ替え、試しの区間（窓 26〜50）で重みを固定して閉ループの世界で走らせると、二つの背景を足した試しの区間の A1 の割合の差 T が［＋／−］の向きの個体が、T が定まり 0 でない個体の中で、事前に決めた基準を超えて多かった」

- **＋の向き**（T ＞ 0）：ある行動の割合が、その行動に結果を返す規則のもとで形づくられた重みのときに高い（二つの背景について足し合わせた量で）。−の向きはその逆
- 符号は、行動 ID の札の付け方（どの源を A1 と呼ぶか）に依らない（§3.2）
- **主張の水準**
  - P_E の時点の 6 本の重みという媒介についての、**制御した効果**である。背景（P_E の活動の状態・I2 の決定の部品・世界の状態と規則）は複製の元の本体のまま固定し、試しの区間の可塑性による後の変化を含まない（FREEZE）
  - 世界が結果を返す閉ループの条件の結果である。重みの入れ替えが選択を変え、その選択に結果が返り、手がかりの Unit を通して源に届く経路（即時の帰還）も、T に含まれる
  - 主張は、T が定まり 0 でない個体の中での**向きのそろい**である。合算の T が 0 でない個体や、少なくとも一方の背景で選択が変わった個体がどれだけあるか（広がり）は、判定ではなく推定 E_T（p_nz・p_any）で示す。E_T は判定の成否に依らず、J_T の結果と同じ目立ち方で必ず添える
  - この個体群（T が定まる個体。選別の後の母集団：§4.1・§4.6）・この時点（P_E）・この試しの区間の条件についての、条件付きの結果である

### 0.4 主張しないこと

- 規則 c の入れ替えの総効果（試しの区間の選択が規則で変わること）と、その内訳。総効果が重みを通ったこと（同じ個体での媒介の割合）
- S3 の層 1・層 2 の主張の成立（層 2 は総効果の R-7 の確立が要る。基準 §2）
- 学習・報酬・価値・罰・意味・目的を学んだこと。＋・−の向きを、接近・回避・好み・結果を求めた・避けたと呼ぶこと（基準 §2・§8、命題 G-11）
- 行動に固有の結果の連合の獲得・信用の割り当て
- どの接続の効果か（C → 源・源 → C・源どうし）。6 本を一度に入れ替え、分けていない。どの可塑性の経路（P1〜P6）が W の違いを作ったか
- **広がり**：「多くの個体で選択が変わる」こと。J_T は向きのそろいの判定で、合算の T が 0 でない個体の割合（p_nz）の判定でも、少なくとも一方の背景で選択が変わった個体の割合（p_any）の判定でもない
- 0040 の J_A・E_A、0041 の J_B・E_B、0039 の J_W・D^W・D^{W′} と、この実験の結果をつないで、規則 → 重み → 選択の媒介を言うこと
- 0039 の J_7 の不成立の理由の説明・救済。候補の文書 v0.2 §2 の仮説 H1 が確かめられた・否定されたと言うこと
- **不成立・判定不能から**、「重みは選択に効かない」「規則に依る重みの変化は選択に届かない」と言うこと。個体ごとに向きの違う効果がないと言うこと。不成立を、構成の見直し（提案の文書の候補 3）を始める条件にすること
- E_T の値から、効果が大きい・小さいと判定すること
- ほかの時点（P_E 以外）・ほかの長さの経験・可塑性 ON の試しの区間・結果を返さない世界で、同じ向きになること

### 3.2 量の一覧

どれも、保存した記録から分数で正確に計算し、符号はその正確な値の符号とする。差は「a − b」の順。量は、その差に使う系の s がすべて定まるときだけ定める（一つでも定まらなければ、その量は定まらない）。

| 名前 | 定義 | 役目 |
|---|---|---|
| T^{(c)} | s(G^c[W^{A1}]) − s(G^c[W^{A2}]) | 背景 c での重みの入れ替えの差（必ず報告） |
| **T** | T^{(A1)} ＋ T^{(A2)} | **J_T・E_T** |
| BE(W) | s(G^{A1}[W]) − s(G^{A2}[W])（W ＝ W^{A1}・W^{A2}） | 同じ重みで、背景（状態と規則）だけ違う差（必ず報告） |
| BE | BE(W^{A1}) ＋ BE(W^{A2}) | 同上 |
| TE_F | s(G^{A1}[W^{A1}]) − s(G^{A2}[W^{A2}]) | U で重みを固定した、自然な組み合わせどうしの差（必ず報告） |
| D | s(B^{A1}) − s(B^{A2}) | 自然な対（U も可塑性あり）の差。総効果の記述（0039 の J_7 の量の形。判定しない） |
| S^{(c)}・S | s(G^c[X1]) − s(G^c[X2])、S ＝ S^{(A1)} ＋ S^{(A2)} | 人工の端の感度の対照（必ず報告） |
| T_N^{(c)}・T_N | s(N^c[W^{A1}]) − s(N^c[W^{A2}])、T_N ＝ T_N^{(A1)} ＋ T_N^{(A2)} | 結果を返さない世界での入れ替え（必ず報告） |
| K^c | s_c(G^c[W^c]) − s_c(N^c[W^c]) | 同じ状態・同じ重みでの、試しの区間の結果の帰還の有無の差（必ず報告） |
| Z^c | s_c(B^c) − s_c(G^c[W^c]) | 試しの区間の可塑性 ON・OFF の差（必ず報告。0039 の Z^c と同じ） |
| δ | (a_1^{A1} − a_1^{A2}) − (a_2^{A1} − a_2^{A2})、a_j^c ＝ W^c(C → 源 j) | この個体群での、規則に依る重みの差（0041 §3.2 と同じ定義。必ず報告。J_B のやり直しにしない） |

- **＋の意味**
  - T・T^{(c)}・T_N：ある行動の割合が、その行動に結果を返す規則のもとで形づくられた重みのときに高い
  - BE：同じ重みで、ある行動の割合が、その行動に結果を返す規則の背景のときに高い
  - TE_F・D：ある行動の割合が、その行動に結果を返す規則の本体（重みと背景の両方がその規則のもの）で高い
  - S：C → 源の重みを w_max にした側の源の行動の割合が高い（0040 の D^X と同じ向き）
  - K^c：規則 c が指す行動の割合が、結果が返るときに高い。Z^c：規則 c が指す行動の割合が、U の可塑性があるときに高い
- **札の入れ替えに対する性質**（SE-T11）：源 1 と源 2（A1 と A2）の札を入れ替えると、規則 c ＝ A1 の本体は規則 c ＝ A2 の本体に、W^{A1} は W^{A2} に、X1 は X2 になり、s は 1 − s になる。T・BE・TE_F・D・S・T_N・δ は正確に同じ値のまま、T^{(A1)} と T^{(A2)}、BE(W^{A1}) と BE(W^{A2})、S^{(A1)} と S^{(A2)}、T_N^{(A1)} と T_N^{(A2)}、K^{A1} と K^{A2}、Z^{A1} と Z^{A2} は入れ替わる。そのため、T などの符号は札の付け方に依らない。**この性質は、T の符号が＋・−で対称であることの根拠ではない**（札の入れ替えは T を −T に移さない。§4.6）
  - **確かめた範囲**：`analysis.py` の `label_swap_and_identity_check` は、手で置いた s の値（分数）で、T・BE・TE_F・D・S・T_N と、少なくとも一方の背景で T^{(c)} ≠ 0 であることの真偽が同じ値のまま、背景ごとの量の組が入れ替わること、打ち消しの場合に T ＝ 0 になることを確かめる。δ は s から計算しないので、別の `delta_label_swap_check` が、手で置いた 6 本の重みの組（分数と浮動小数の両方）で、札の入れ替え（本体の入れ替えと、各本体の中の源 1 と源 2 の接続の入れ替え）で δ が正確に同じ値になることを確かめる（浮動小数でも、差の反対称 fl(p − q) ＝ −fl(q − p) により正確に同じ値）
  - 実際の系の記録の上での確かめ（道具が計算する量が、札を入れ替えた記録で同じ値・入れ替わった値になること）は、`analysis.py` では行わない。道具の契約テスト（§14 の CT-42-9）で、手で作った記録と合成の記録で確かめる
- **算術の恒等と、分解をしない**：四つの s が定まる個体では、TE_F ＝ (T ＋ BE)／2 が算術として成り立つ（`analysis.py`）。これを、重みの効果と背景の効果への本当の内訳とは呼ばない（0039 §3.2 の U5、0040 §15.5 と同じ扱い）。「媒介の割合」（T を TE_F や D で割った比）は計算しない（0 の多さと、差の非加法性のため。常設チェック A6）
- **二つの背景の和にした理由**：§4.5
- **T ＝ 0 の意味と、打ち消し**：T は二つの背景の差の和なので、T ＝ 0 は次の二つを含む。(i) 両方 0：T^{(A1)} ＝ T^{(A2)} ＝ 0（どちらの背景でも、重みの入れ替えで選択の割合が変わらなかった）。(ii) 打ち消し：T^{(A1)} ＝ −T^{(A2)} ≠ 0（たとえば T^{(A1)} ＝ ＋1/4・T^{(A2)} ＝ −1/4。両方の背景で選択の割合が変わったのに、和が 0）。そのため、「合算の T が 0 でない」ことと「その個体で重みの入れ替えの効果があった（少なくとも一方の背景で T^{(c)} ≠ 0）」ことを区別する。前者の割合が p_nz、後者の割合が p_any（§4.4）。p_any ≥ p_nz で、差は打ち消しの個体の割合である

### 4.5 この形にした理由（結果を見る前の理由）

**主の量を T（二つの背景の和）にした理由**
- 提案の文書 §3.1 の素案。同じ個体の二つの本体の重み W^{A1}・W^{A2} は、規則の違いのもとで自然に形づくられた重みで、もう一方の規則のもとでなら形づくられた重みが、実際の値として手に入る。重みだけを入れ替える移植で、個体ごとの反実仮想の差が、母集団をまたぐ仮定なしに定まる
- 二つの背景の和は札の入れ替えで値が変わらない（§3.2）。0039 の J_W のように片方の背景を主に選ぶ理由づけが要らず、二つの背景の情報を両方使う。背景ごとの T^{(c)} は必ず報告する（§6.1）
- 和は、二つの背景で逆の向きの差が打ち消し合うと 0 になる。この場合も「0」に数え、別の量に替えない。背景ごとの (sign T^{(A1)}, sign T^{(A2)}) の表で記述する（§6.1）

**試しの区間の世界を閉ループにした理由**
- 問い (iv-a) は、規則のもとで形づくられた重みが、**経験した世界の中で**後の選択を変えるかである。背景の本体の規則のまま走らせると、比べる二つの系の違いが重みだけになり、世界を本体から一つ多く離さずに済む（0039 §4.4 の「世界の規則は背景の本体のまま（閉ループ）にする」と同じ理由）
- 結果を返さない世界での入れ替え T_N は、0040 の条件（結果を返さない世界）に近く、即時の帰還を含まない別の推定対象である。主に混ぜず、必ず報告する記述に置く（§6.1）。どちらを主にするかは、ここで一つに決めた。結果を見てから入れ替えない

**試しの区間で FREEZE にした理由**
- U で重みを止めると、比べる系の違いは P_E の重みだけになり、その後の重みの変化の違いが入らない（0037 の TP-1、0039 §4.4 と同じ理由）。そのため T は「U で重みを固定した系」の結果で、自然な AS2b の全体の効果とは呼ばない（§0.4）。U で可塑性のある自然な対の差 D と、Z^c を記述として並べる

**個体の事象を符号にした理由**
- 符号は閾値・比・正規化を持ち込まない（A6）。|T| の分布は E_T として必ず並べる

**向きを事前に決めない理由**
- 0041 の J_B の−と 0040 の J_A の＋は、個体群・介入・世界・大きさの違う二つの結果で、続けて向きを予想する根拠にならない（提案の文書 §2.2・§2.4）。0041 の−は二つの源を足した δ の符号で、q_1 と q_2 の符号が逆の個体もある（0041 §15.5）
- 閉ループでは、重みの入れ替えで変わった選択に結果が返り、手がかりの Unit を通して源を駆動する経路（命題 G-3、N-3・N-4 §2.4.6）も T に入る。その寄与の向きも前もって決まらない（命題 G-11 の範囲）
- したがって両側で問う

**判定の形を「合算の T が 0 でない個体の中での向き」にした理由**（0039〜0041 の「0 を分母に残す個体の多数」の形にしない理由）

提案の文書 §4.4 は、0 を分母に残す形を第一候補とし、別の形にするなら推定対象から理由を書くとしていた。v0.1 は、その理由の一つに「系は決定論なので、個体の水準の存在は問いにならない」を挙げた。**これは不正確なので撤回する**（ChatGPT のレビュー 6006770113）。特定の seed で移植の効果が正確に定まっても、新しい個体群で、効果のある個体がどれだけあるか（p_any や p_nz）は、決定論のモデルでも統計の問いである。決定論は、どちらの判定の形も強制しない。条件付きの向きが、過半数の判定より論理的に優先されるわけでもない。以下に書くのは、この実験がどちらの問いを主にするかの**研究の目的の選択**、その**費用**、**0039 を知っていることの影響の可能性**である。

**(a) 研究の目的：合算の T が 0 でない個体での、符号の偏りを主に問う**
- 段 (ii) は、0041 で「規則の違いが、C → 源の重みの差に、向きのそろった違いを作る」こととして確立した（J_B）。その次に問うのは、その向きのそろった重みの違いが、選択の側に向きを持って届くか（重みの違いが、選択を一方の向きに押すか）である。この実験は、これを (iv-a) の向きの成分として主に問う
- 広がり（効果のある個体がどれだけあるか）は、重みの差の大きさと、窓の選択の読み出しの粗さ（s は高々 25 窓の割合で、窓の勝ちが入れ替わるときだけ変わる）に強く左右される量と考える。向きの成分は、届いたときに押す向きを問う量で、この実験はそれを先に確かめる段にする【この区別は研究の目的の選択で、読み出しの粗さが広がりにだけ効き、向きに効かないことは確かめていない】
- 二つの形の違い
  - 0 を分母に残す形は、成立に「T が定まる個体の過半数が一方向に動く」（p_＋ ＞ 1/2）ことを要し、広がりと向きを一つの主張に合わせる。T ＝ 0 の個体の割合 z が 1 − k₂(m)／m を超えると、T ≠ 0 の個体がすべて同じ向きでも成立しえない（m ＝ 180〜200 で z ＞ 約 0.42。`analysis.py` の `house_form_ceiling`。分布を仮定しない算術）
  - その形の帰無は、向きごとの p_＋ ≤ 1/2（−の向きは p_− ≤ 1/2）で、それぞれ二項の上側で水準を保つ。これは p_＋ ＝ p_− とは論理的に同じでない
  - J_T の帰無（§4.6）は P(T ＞ 0) ＝ P(T ＜ 0) で、成立は、合算の T が 0 でない個体の中での向きの非対称だけの主張である。二つは別の問いで、この実験は後者を主にする

**(b) 費用：多数・広がりの判定を、意図して捨てる**
- J_T が成立しても、「多くの個体で効いた」「T が定まる個体の過半数が一方向に動いた」とは言えない。0 を分母に残す形の成立は、J_T の型の向きの偏りも含むが、逆は成り立たない。J_T の主張は、0 を分母に残す形の主張より狭い
- m≠ が小さいと、J_T が成立しても、それは少数の個体での向きの偏りである。そのため、結果を書くときは、J_T の結果と同じ表・同じ段落に、m≠／m_def と、p_nz・p_any とその区間を、同じ目立ち方で並べる（§4.7・§12）
- 広がりは推定（p_nz・p_any と区間）だけで示し、判定しない。「効果のある個体は多いか・まれか」という問いに、この実験は判定で答えない
- 判定の母集団は、T が定まり 0 でないという、結果で決まる条件で選んだ個体である。水準は m≠ に条件付けても保たれる（§4.6）が、主張は、その選別の後の個体についてのものにとどまる
- m≠ は結果で決まる数で、m≠ ＜ 10 なら判定不能になる。個体数を後から足さない
- 打ち消しの個体（T^{(A1)} ＝ −T^{(A2)} ≠ 0）は、両方の背景で重みの入れ替えの効果があっても、合算の T が 0 なので向きの数に入らない（§3.2・§4.1）。J_T は、そうした個体の効果を扱わない。件数と p_any で記述する

**(c) 0039 を知っていることの影響の可能性と、前向きの確かめの境界**
- 0039 の系 G^{A1}[W^{A1}]・G^{A1}[W^{A2}]・G^{A2}[W^{A2}]・G^{A2}[W^{A1}] は、この実験の主の四つの系と同じ組み立てである。0039 の D^W ＋ D^{W′} は、0039 の個体群での T に当たる。0039 §15.4 の (sign D^W, sign D^{W′}) の 9 つの組の表は、その符号の一部（両方が同じ符号の組と、片方が 0 の組）を決める情報を含む
- 作成者（Claude）は、0039 の結果を書いたときに、この表と、D^W・D^{W′} の向きごとの数・0 の数を見ている。この案の作成中にも、BLACKBOARD `da57f87` の記録で D^W・D^{W′} の公表値を見た。提案の文書（#194）で第一候補とした 0 を分母に残す形を、条件付きの向きに切り替えたのは、**これらの結果を知った後**である
- したがって、この切り替えが 0039 の既知の結果に動機づけられた可能性、あるいは成立しやすい形を選んだ選択の偏りの可能性は、**残る**。作成者の側から「既知の値を使っていない」と示すことはできない。v0.1 の「上の理由は、それらの値を使わずに書いた」という書き方は、それを示したかのように読めるので改めた

  - H₀^T のもとでの水準は、新しい個体群のデータについてのもので、問いの選び方が既知の結果に動機づけられていても、その新しいデータでの誤りの率は保たれる。残るのは、どの問いを主にしたかの選択の偏りで、読み手が重みづけるものとして開示する

- この説明で選び方が合理的に守れないとレビューで判断されたときは、0 を分母に残す形（m ＝ m_def、k₂(m_def)。帰無は向きごとの p_＋ ≤ 1/2・p_− ≤ 1/2）に戻し、この節を、その形の限界の記述に替える

**補足：T ＝ 0 の個体が多いと見込む材料**【見込み。判定の形の根拠の中心ではない】
- 0041 の自然な |δ| の中央は 4.2 × 10⁻⁴ で、0040 の中間の対（δ の単位で 0.01）の約 24 分の 1、端の対（0.02）の約 47 分の 1 である（0041 §15.4、0040 §2.3、提案の文書 §2.3。公表値の算術）
- 0040 では、その中間の対でも、差が 0 の個体が 187 個体のうち 56、参照との差 Δ^1・Δ^2 でも 185 のうち 54・186 のうち 67 あった（0040 §15.5。条件は出生の状態・結果を返さない世界で、この実験と違う）。自然な差はそれより 1〜2 桁小さい
- s は高々 25 窓の割合で、窓の勝ちが入れ替わるときだけ変わる。重みの差 Δw が源に届ける駆動の違いは、C の 1 回の発火あたり高々 |Δw|、過去の発火を合わせた包絡でも Φ_C |Δw|（Φ_C ≒ 3.03。命題 S-1 の導出の形）で、|Δw| が 10⁻⁴ の桁なら 10⁻³ の桁である。源の余裕 g は −0.07〜0.14 ほどに散らばる（候補の文書 v0.2 §2 の見積もり）。窓の勝ちが入れ替わるのは、二つの源の到達がほぼ並ぶ窓に限られる見込みである
- したがって、0 を分母に残す形は、向きがそろっていても不成立になる見込みがある
- **この見込みの限り**：上の材料は、T の 0 の数を予測・保証しない。0040 の対比は別の個体群・出生の状態・結果を返さない世界の値で、0041 の自然な δ と 0040 の端の大小の比べは、T の検出力を保証しない（BLACKBOARD `da57f87`）。0039 の D^W・D^{W′} の周辺の 0 の数からも、T ＝ T^{(A1)} ＋ T^{(A2)} の 0 の数は導けない（片方だけ 0 でない個体・打ち消し合う個体がある）。この補足は、0 を分母に残す形の不成立が向きのそろいに答えないことが起こりうる、という材料にとどめる

**判定を一つにした理由**
- 問い (iv-a) は T の向き一つである。T^{(c)}・BE・TE_F・D・S・T_N・K^c・Z^c・δ は、背景ごとの見方・背景の効果・総効果・感度・帰還の有無・可塑性の有無・重みの層を記述するもので、それぞれを判定にすると族が増え、水準の扱いが要る。そのため記述に回した

### 4.6 帰無仮説と、その条件

- **推論の対象**：T が定まる個体の母集団（出生時の状態を独立・同一分布の標本と見なすモデルで、四つの s が定まるという条件で選んだ後の母集団）
- **H₀^T**（明示の統計上の帰無）：その母集団で、P(T_i ＞ 0) ＝ P(T_i ＜ 0)
- 帰無と独立・同一分布のモデルのもとでは、T ≠ 0 の個体の集合と m≠ に条件付けると、各個体が「＋」である確率は 1/2 で、個体どうしは独立である。そのため「＋」の個体の数は、m≠ に条件付けて正確に Bin(m≠, 1/2) に従う。「−」も同じ。したがって P(J_T がどちらかの向きで成立 | H₀^T, m≠) ≤ 0.025 ＋ 0.025 ＝ 0.05 で、条件を外しても 0.05 以下である
- **この向きの対称性は、仮定する帰無であって、導いた性質ではない**
  - 札の入れ替えからは導けない。札を入れ替えても T の値は変わらない（§3.2）。T を −T に移す操作ではない
  - 定まる条件（四つの系の n_U ≥ 1）が二つの背景と二つの重みについて対称であることからも導けない（それには、選別の前の系の結合分布に、符号を反転させる交換可能性が別に要る。0039 §4.1 と同じ）
  - 系の構造からも導けない。結果は規則が指す側にだけ返り、AS2b は非対称な構成である（G-11）。その非対称が、自然に形づくられた重みを通して選択の向きのそろいとして現れるかが、この実験の問いである
- 成立は、「T が定まる個体の母集団で、T ≠ 0 の個体の向きが偏っていた」ことで、選別の前の全個体についての主張ではない
- **0 を分母に残す形の帰無との違い**：その形の帰無は向きごとの p_＋ ≤ 1/2・p_− ≤ 1/2（§4.5 の (a)）で、成立は過半数の主張になる。H₀^T は P(T ＞ 0) ＝ P(T ＜ 0) で、成立は過半数を主張しない
- 水準の保証は、出生時の状態の独立・同一分布のモデルの中のもの。seed の連番は、それ自体が無作為な抽出や独立を示さない
- 同じ個体の系どうし（二つの背景・四つの系）は独立ではない。T を一つの個体の事象にして、この依存を判定に入れない

### 9.3 表示しない量

- **契約テスト（合成の seed）と smoke では、次を計算しても表示・保存しない**：s と n_U（すべての系）、§3.2 のすべての量とその符号、向きごとの数、m≠・m_def、E_T のすべての量（p_nz・p_any・打ち消しの数を含む）、Clopper–Pearson の区間、k*、§4.1 の札、W^{A1}・W^{A2} と δ、選択と結果の刺激の数、最初に分かれた Pulse（R6）
- 契約テストは、これらの量の算術を、手で作った記録（合成の割合・窓の結末の列・重み）で確かめる。実際の系の軌道から求めた値は、整合の真偽だけを確かめ、値そのものを出さない。**契約テストの失敗の表示でも値を出さない**（0041 の CT-41-7 の教訓：テストの module に `PYTEST_DONT_REWRITE` を置き、assert の式に評価済みの値が入らない形にし、その仕組み自体を確かめるテストを置く。それでも例外の経路で値が見えたときは、止めて開示し、再レビューを受ける）
- smoke は、操作の確認（O2〜O15）の ok・fail だけを報告する。現象の数値を計算・表示・保存しない（0034〜0041 と同じ）

### 9.4 一度限りの実行

- 判定の seed は一度だけ走らせる。最初の seed の前に、protocol のハッシュに結び付いた試行の札を排他に作る（guard。0039〜0041 と同じ）
- 無効のとき：判定と推定の量を計算・表示しない。何が成り立たなかったかを報告する。同じ seed で走らせ直さない。穴埋めをしない。走らせ直す必要があるなら、理由と見たものを開示し、新しい版・新しい seed で、新しい実行の許可を得て行う
- 判定不能・不成立のとき：同じ seed で走らせ直さない。個体を足さない
- 走らせた後に、この README・protocol・道具を変えない

### 何を決めたか

前の提案で選んだ次の課題（候補 1）について、本番の実験の「調べ方」を、結果を見る前に決めて固定する文書です。

AI の中には、手がかりを受け取る部品と、二つの行動（A1・A2）のどちらかを起こす部品があり、そのあいだの「つながりの強さ」は経験で変わります。世界の決まりで、片方の行動にだけ「結果」（刺激）が返ります。

1. 同じ AI を二つ用意し、片方は「A1 を選ぶと結果が返る世界」、もう片方は「A2 を選ぶと結果が返る世界」で、前半（25 回の選ぶ機会）だけ育てます
2. 前半の終わりで、それぞれの AI をそっくり写し取ります。写した AI のつながりの強さだけを、もう片方の世界で育った AI のものと入れ替えます。ほかのもの（その時の状態や世界）はそのままです
3. 後半（25 回）は、つながりの強さを固定したまま走らせ、A1 と A2 をどれくらいの割合で選ぶかを比べます

### 何を確かめるか

- 入れ替えの比べは、前半を「A1 に結果が返る世界」で育った AI の側と、「A2 に結果が返る世界」で育った AI の側の、二か所で行います。二か所の差を足し合わせた値（T）を、一体ごとの答えにします
- 足し合わせた値が 0 でなかった AI の中で、その向き（「結果が返る側の行動を選びやすくなる」か「選びにくくなる」か）が、偶然とは言いにくいほどそろっているかを確かめます。向きは前もって決めていません
- 足し合わせた値が 0 の AI は、向きの数に入れません。ここには、どちらの比べでも選び方が変わらなかった AI のほかに、二か所で逆向きに同じだけ変わって打ち消し合った AI も入ります。そのため、「足し合わせた値が 0 でなかった AI の割合」と「少なくとも一か所で選び方が変わった AI の割合」を分けて、どちらも数字の幅で報告します
- これまでの実験は「全体の中で、同じ向きに変わる AI が多数か」を確かめる形でした。今回はそれを主にせず、「変わったときの向きがそろうか」を主に確かめます。その代わり、成り立っても「多くの AI で効いた」とは言えません。どれくらいの AI で変わったかは、判定と同じ目立ち方で数字の幅を並べます
- この判定の形は、前の実験（0039）の結果を知った後に選んだものです。知っていたことが選び方に影響した可能性は消せないので、そのことを文書に書いたうえで、新しい 200 体だけを使って、前もって決めたとおりに確かめます

### 言わないこと

- 成り立っても、「ご褒美を覚えた」「多くの AI で選び方が変わる」とは言いません
- 足し合わせた値が 0 の AI を、「選び方がまったく変わらなかった AI」とは呼びません
