## 0. 問いと主張の範囲

### 0.1 問い

> **C0 で、0028 と同じ世界・経験（O・M・試行の中の並べ替え W）の後、主の区間（13501〜25500）の始まりの直前の静かな Pulse τ に、受け手 W20 の状態のうち一方の塊――6 本の重み（Wt）、または 3 Unit の状態と痕跡（U）――だけを、ドナー（O・M・W1〜W19）の τ の値に替える。その後の主の区間の時間差 1 の発火の組の非対称 Δ_AB と、B と C の対比 D ＝ Δ_AB − Δ_AC は、ドナーが O（M）のとき、ドナーが W のときの分布（介入の参照）の中で典型的でないか**

- **Wt**：21 の入れ替えた本体は、τ の Unit の状態（activity・順応）と痕跡が W20 のもので**すべて同じ**で、重みだけがドナーごとに違う。したがって、この家族の中の違いは、τ の位相・順応の違いからは生じない（担い手の設計 命題 1）。問い：**位相・順応をそろえた背景で、O（M）の重みの塊は、W の重みの塊と比べて、予測した向きの典型的でない Δ_AB・D を生むか**。M をドナーに含めるので、**重みの塊だけで、経験の内容（A の直後の要素が B か C か）に応じた逆向きの外れ（J_OM^Wt）が起きるか**も問う
- **U**：21 の入れ替えた本体は、重みが W20 のもので**すべて同じ**で、Unit の状態と痕跡だけがドナーごとに違う。問い：**重みをそろえた背景で、O（M）の Unit の状態の塊（位相・順応・痕跡）は、典型的でない Δ_AB・D を生むか**（X5 の経路。向きは問わない）
- 答えの水準は、**C-I（固定した背景のもとでの、ドナーのあいだの塊の入れ替えの条件付きの効果と、その介入の参照との比較）まで**（担い手の整理 §3.1、0026 §0.1 と同じ）
- 0026 との違い：0026 は経験の終わり（11972〜12000 の静かな Pulse）で入れ替え、試しへの応答 R2 を読んだ。0029 は主の区間の始まりの直前で入れ替え、試しを使わない自発の発火の Δ_AB・D を読む（0028 と同じ量）。M をドナーに含め、J_OM の形の判定を置く

### 0.2 主張の形（成立したとき）

どれも「C0 で、この世界・この手順のもとで、受け手 W20 の残りの塊と時刻 τ を背景に固定したとき、個体間の独立性の前提のもとで、家族の水準 0.05（§5.1・§5.2 の割り当て）で」という限定が付く。

| 判定 | 成立したときの主張の形 |
|---|---|
| J_Ca^Wt | 位相・順応・痕跡を W20 のものにそろえたとき、O の重みの塊は、W の重みの塊と比べて、Δ_AB を予測した向き（大きい側）に典型的でなくした。その頻度は、ドナーとしての O が W と交換可能であるという帰無仮説の想定より多かった |
| J_O^Wt | 同じ背景で、O の重みの塊は D を大きい側に典型的でなくした |
| J_M^Wt | 同じ背景で、M の重みの塊は D を小さい側に典型的でなくした |
| J_OM^Wt | **同じ個体・同じ背景で、O の重みの塊は D を W のすべてより大きく、M の重みの塊は D を W のすべてより小さくした、ということが、21 のドナーが交換可能であるという帰無仮説の想定より多くの個体で起きた**（位相をそろえた背景での、重みの塊だけによる、経験の内容に応じた逆向きの効果。C-I） |
| J_Ca^U・J_O^U・J_M^U | 重みを W20 のものにそろえたとき、O（M）の Unit の状態の塊は、W の Unit の状態の塊と比べて、Δ_AB（D）を典型的でなくした（向きを問わない） |
| J_OM^U | 同じ個体・同じ背景で、O と M の Unit の状態の塊が、D を W の分布の**反対の端**の外に出した（どちらの向きの組でもよい） |

### 0.3 主張しないこと

- **自然な差の原因（C-III）**：成立しても、「0028 で O が典型的でなかったのは、重み（Unit の状態）の違いのせいだった」「重み（位相）が担い手だった」とは言わない（担い手の整理 命題 5、レビュー A5）
- **自然な差の再現と消去（C-II）**：「O の重みを移すと自然な O の外れが再現された」「O の Unit の状態を戻すと外れが消えた」とは言わない（0026 §3 の命題 A、C2 の整理 命題 B）
- **排他性・寄与の割合**：一方の家族だけが成り立っても、その塊だけが外れを運ぶとは言わない（C2 の整理 命題 C）。二つの家族の h を比べない・足さない
- **ほかの背景**：W20 以外の受け手、ほかの時刻での効果
- **塊の中のどの成分か**：6 本のうちどの組の重み（A–B か B–C か A–C か）、activity・順応・痕跡のどれが効いたか
- **入れ替えた状態が自然に起こる**：(u_W20, w_O) のような組み合わせが、何かの経験から到達できるかは分からない（担い手の整理 命題 2）
- **学習の必要性・学習の寄与**：Wt は「その重みを持つと何が起きるか」を問うだけ
- **量だけの違い（X7）を除いた**：Wt では、発火の数の違いもドナーの重みから生じ、外れの一部として含む。X7 の限定した形の対照（N^cnt）と、経験の後の可塑性を止める変種（F）は、別の事前登録で行う
- **記憶ができた・内容を理解した・意味を持った**、3 要素の順序・時間差を表した
- 0026・0028 の h と、0029 の h の違いから何かを結論すること
- 不成立のとき：その塊は効かない、位相（重み）は無関係、外れは組み合わせの性質でありうる（担い手の整理 命題 3 (c)）、検出力・受け手・τ に依る

## 2. 本体と入れ替え

### 2.1 自然な本体（同じ seed、同じ出生時の状態から 22）

| 本体 | 経験の札の列 |
|---|---|
| **O** | 試行 k（0〜199）の 3 つの枠（t_k、t_k ＋ 2、t_k ＋ 30）に A・B・C |
| **M** | 同じ枠に A・C・B |
| **W1〜W20** | i 番目は乱数の流れ `"0029-within-trial-<i>:<seed>"` を 1 本だけ使い、k ＝ 0, 1, …, 199 の順にリスト [A, B, C] をその流れで 1 回ずつ並べ替えて（`random.Random(名前).shuffle`）、(t_k, t_k ＋ 2, t_k ＋ 30) に置く（0025・0027・0028 と同じ作り方） |

### 2.2 入れ替える時刻 τ（個体ごとに 1 つ）

```text
τ ＝ max{ t ∈ [13441, 13500] ： Pulse t に、自然な 22 本体のどれでも、どの Unit も発火していない }
     （13441 ＝ 主の区間の始まり 13501 − trials.every、13500 ＝ 主の区間の始まり − 1）
```

- **理由**：τ の処理の終わりには、どの自然な本体にも次の Pulse に届く駆動が置かれておらず（発火がないため：担い手の整理 命題 2 の I4）、Receptor の出来事もない。したがって全状態は「3 Unit の状態」と「接続の状態（重みと痕跡）」だけで、どちらの塊を入れ替えても、駆動の重みと接続の重みの不整合や、発火の印と駆動の不整合が起きない（0026 §2.2 と同じ理由）
- **窓の幅 60**（＝ trials.every）は、**この実験で新しく選んだ方法上の値**で、既にある時間の尺度（試行の間隔）から取った。データからは選んでいない。窓は主の区間の始まりの直前に置き、入れ替えた状態が主の区間の始まりの状態にできるだけ近くなるようにする
- 窓の中に τ がない個体は、入れ替えをせず、**Wt・U の 8 つの判定すべてで「外にない」に数える**（除外しない。記録して報告する）
- τ は自然な本体の発火の列だけで決まり、判定の量を見ずに決まる

### 2.3 塊と入れ替えた本体

| 塊 | 入れ替える値（τ の処理の終わり） | 受け手 W20 のまま |
|---|---|---|
| **重み（Wt）** | 6 本の重み（接続の状態の weight） | Unit の状態、痕跡、発火の回数 |
| **Unit の状態（U）** | 3 Unit の activity・順応・不応期の残り（不応期 0 なので常に 0）と、Unit ごとの痕跡 X_i（接続の欄の pre_trace・post_trace のすべて。値は Unit ごと：担い手の整理 命題 2 の I2） | 重み、Unit の発火の回数（観察用で力学に使わない） |

- **受け手**：W20（並べ替えの番号で事前に決める。W は作り方から互いに交換可能とみなすので、W20 を選ぶことは 1 本を選ぶことと同じ）
- **ドナー**：O・M・W1〜W19 の 21（受け手 W20 自身はドナーに含めない：C2 の整理 命題 D の自己一致の効果を避ける）

- **確認の本体**（操作の確認だけ）：両方の塊を O のものに替えた本体（O の自然な軌道と一致するはず）、両方の塊を W20 自身のものに替えた本体（W20 の自然な軌道と一致するはず）

### 2.4 同じ混成状態の二つの書き方（0026 §3 の命題 A を τ に当てる）【命題】

τ の処理の終わりの力学に効く状態を (w, u)（w：重みの塊、u：Unit の状態と痕跡の塊）と書く（§2.2 により置かれた駆動はない）。τ より後は入力がなく決定論的なので、τ より後の軌道と主の区間の Δ_AB・D は (w, u) と出生時に決まる Unit の力学の値だけで決まる（担い手の設計 命題 1）。このとき

```text
Y^Wt(d) の状態 ＝ (w_d,  u_W20)  ＝ 「d の Unit の状態と痕跡を W20 のものに戻した本体」
Y^U(d)  の状態 ＝ (w_W20, u_d)   ＝ 「d の重みを W20 のものに戻した本体」
```

- **帰結 1（Wt の家族の比較）**：Wt の 21 本体は u がすべて u_W20 で同じなので、家族の中の Δ_AB・D の違いは w の違いからしか生じない。**τ の位相・順応・痕跡の違い（X5 の経路）は、Wt の家族の中の外れの説明にならない**。発火の数の違いも w の違いから生じる（外れの一部として含む）
- **帰結 2（U の家族の比較）**：U の 21 本体は w がすべて w_W20 で同じなので、家族の中の違いは u の違いからしか生じない
- **言わないこと**：この同値は状態の代数的な等しさで、自然な差の再現・消去（C-II）を独立に確かめたことではない（0026 §3、C2 の整理 命題 B）。自然な O の値が外にあるかは補助の記録だけで、判定の成立条件に入らない

## 3. 量と、向きの根拠

### 3.1 定義（0028 §3.1 と同じ）

本体（自然な本体・入れ替えた本体・確認の本体のどれも）の発火の列 s_X(t) から、主の区間 [S, E] ＝ [13501, 25500] について

```text
N_{X→Y} ＝ #{ t : S ≤ t ≤ E − 1, s_X(t) ＝ 1, s_Y(t ＋ 1) ＝ 1 }       （X ≠ Y。二つの発火がどちらも区間の中にある組だけ）
Δ_AB ＝ N_{A→B} − N_{B→A}、   Δ_AC ＝ N_{A→C} − N_{C→A}
D ＝ Δ_AB − Δ_AC
```

- A・B・C は役（その個体で Receptor A・B・C を受ける Unit）。入れ替えた本体の主の区間の発火の列は、τ ＋ 1 以後に入れ替えた本体が出したものだけ（τ ≤ 13500 なので、区間の中はすべて入れ替えた後）
- 量の形の理由（時間差 1・向きの差・比を使わない・Δ_AB と D を別の判定にする）は 0028 §3.2 と同じ。D が発火の数の違いを一般には打ち消さないことも 0028 §3.2 と同じ

### 3.2 向きの根拠

- **Wt（一方向）**：0028 §3.3 と同じ理論（絞り込み 命題 A・予想 C）から、O の重みの塊は w(A→B) の偏りを持ち、M の重みの塊は w(A→C) の偏りを持つと見込む。O の重みは Δ_AB と D を大きくし、M の重みは D を小さくする向きに働くと予測する。**理論の保証ではない**：入れ替えた後も可塑性は働き、W20 の位相・順応の背景で重みは書き換わりうる。予測と逆の向きの外れは「外にない」と同じに扱い、補助に記録する
- **U（向きを問わない）**：Unit の状態の塊の効果の向きは、理論から導けていない（担い手の設計 §4.2）。「位相が O の関係を運ぶなら O と同じ向き」という見込みはあるが、2 つの Unit の構成では固定した重みのもとで初めの位相の影響がほとんど残らなかった（担い手の設計 命題 5）ように、向きも有無も決まっていない。したがって**向きを問わない判定**にする

### 3.3 この量が分けないもの（事前に書く）

| 混ざりうるもの | 説明 | この実験での扱い |
|---|---|---|
| 発火の数（契約 X7） | Wt では、ドナーの重みが発火の数も変えうる（担い手の設計 命題 5 の構成） | 正規化しない。各 Unit の発火の数を補助として記録する。Wt の外れは「重みが生んだ、数の違いを含む違い」として読む。X7 の限定した形の対照は別の事前登録（N^cnt） |
| 入れ替えた後の可塑性 | 入れ替えた本体でも可塑性は働き、重みは W20 の背景のもとで書き換わる | 分けない（C0-1′ の定義どおり、自然な力学のまま進める）。経験の後の可塑性を止める変種は別の事前登録（F） |
| 塊の中の成分 | 重みの 6 本のどれか、activity・順応・痕跡のどれか | 分けない |
| 受け手の背景 | 効果は W20 という一つの背景での条件付きの効果 | 背景によって効果の向き・有無が変わる場合は、検出力が下がる（§5.4） |
| 沈黙 | 構造的・条件付きの沈黙（担い手の設計 命題 6） | §6 |

## 4. 主の判定

### 4.1 個体ごとの事象

個体ごとに、入れ替えた 42 本体の主の区間の Δ_AB と D を計算する。W のドナーの集合を 𝒲 ＝ {W1, …, W19} とする。

```text
Wt（一方向）
  O の Δ_AB が上（Wt）      ⇔  Δ_AB(Y^Wt(O)) ＞ max_{d∈𝒲} Δ_AB(Y^Wt(d))
  O が上（Wt）              ⇔  D(Y^Wt(O))    ＞ max_{d∈𝒲} D(Y^Wt(d))
  M が下（Wt）              ⇔  D(Y^Wt(M))    ＜ min_{d∈𝒲} D(Y^Wt(d))
  O と M が分かれる（Wt）   ⇔  O が上（Wt） かつ M が下（Wt）

U（向きを問わない）
  O の Δ_AB が外（U）       ⇔  Δ_AB(Y^U(O)) ＞ max_{d∈𝒲} Δ_AB(Y^U(d))  または  ＜ min_{d∈𝒲} Δ_AB(Y^U(d))
  O が外（U）               ⇔  D(Y^U(O)) ＞ max_{d∈𝒲} D(Y^U(d))  または  ＜ min_{d∈𝒲} D(Y^U(d))
  M が外（U）               ⇔  D(Y^U(M)) ＞ max_{d∈𝒲} D(Y^U(d))  または  ＜ min_{d∈𝒲} D(Y^U(d))
```

- 不等号はすべて厳密。等号は「外にない」
- 判定に使う値がすべて等しい個体（凍結。J_Ca では O と 𝒲 の Δ_AB の 20 本、J_O では O と 𝒲 の D の 20 本、J_M では M と 𝒲 の D の 20 本、J_OM では O・M・𝒲 の D の 21 本）は「外にない」に数え、除外しない（A7）
- τ がない個体は、8 つの事象すべてで「外にない」（§2.2）
- Wt で予測と逆の側の外れ（O の Δ_AB が下、O が下、M が上）は「外にない」と同じに扱い、記録する（§6）

### 4.3 帰無仮説と、交換可能性が成り立つ条件

| 判定 | 帰無仮説（個体ごと） | 個体ごとの上側の確率 |
|---|---|---|
| J_Ca^Wt・J_O^Wt | W20 への重みの塊のドナーとして、O は W1〜W19 と交換可能（その量について） | **1／20 以下**（一方向） |
| J_M^Wt | 同じく M は W1〜W19 と交換可能 | **1／20 以下** |
| J_OM^Wt | 重みの塊のドナーとして、O・M・W1〜W19 の 21 が交換可能（D について） | O が 21 個の最大、M が最小になる確率で **1／420 以下** |
| J_Ca^U・J_O^U・J_M^U | W20 への Unit の状態の塊のドナーとして、O（M）は W1〜W19 と交換可能 | **2／20 以下**（向きを問わない） |
| J_OM^U | Unit の状態の塊のドナーとして、21 が交換可能（D について） | O と M が最大と最小の組（どちらの順でも）になる確率で **2／420 ＝ 1／210 以下** |

**交換可能性が成り立つ条件と、成り立たない場合**（0028 §4.2 の 1〜7 を、ドナーの交換可能性に当てはめて引き継ぐ）
1. W1〜W19 は同じ手順・別々の名前の乱数の流れから作った列で、そのドナーとしての塊は互いに交換可能とみなす（乱数の流れの独立性は統計モデル上の前提）。**21 のドナーの交換可能性は、実際の生成の手順が保証する性質ではない**
2. O・M は W の作り方から生じた列ではない。帰無仮説は「その塊のドナーとして、O（M）は典型的な W と区別できない」という仮説で、O・M について確かめた性質ではない
3. 同じ値（引き分け）があると、厳密な不等号の事象の確率は上の値**以下**になる
4. **帰無仮説が内容と無関係に破れうる場合**：O・M の規則性（毎試行同じ並べ方）が、重み（Unit の状態）の塊を通して、内容と無関係に O・M を W と違わせることはありうる。この場合、J_Ca・J_O・J_M の成立は内容に特有とは言えない。**J_OM は同じ個体・同じ背景で O と M が逆の向き（反対の端）に外れることを求めるので、O と M を同じ向きに動かす違いでは起こりにくい**。ただし、21 個の同時の交換可能性の棄却は「21 個のどこかの非交換性」で、内容以外の説明を論理的に排除しない
5. J_OM の帰無仮説は、J_O・J_M の帰無仮説のそれぞれより強い
6. **個体をまたぐ独立性**：出生時の状態と並べ替えの乱数の流れを、個体間で独立とみなす（統計モデル上の前提）。h は二項分布に確率的に支配される
7. **判定のあいだの従属**：家族の中の 4 つの判定は同じドナーの本体を共有し、従属する。家族の誤りの水準は、独立性を使わない Bonferroni の上界で抑える（§5.3）。Wt と U の二つの家族も、同じ自然な本体と受け手を共有して従属するが、組み合わせた主張をしないので扱わない（§5.3）

## 5. 閾値と、家族の誤りの水準

### 5.1 Wt の家族（一方向）

- **Wt の家族全体の水準 0.05**。重みつきの Bonferroni で、**J_Ca^Wt・J_O^Wt・J_M^Wt に 0.016 ずつ、J_OM^Wt に 0.002**（0028 §4.3 と同じ割り当て）
- J_Ca^Wt・J_O^Wt・J_M^Wt：P(h ≥ 4) ≤ P(Bin(20, 1／20) ≥ 4) ≈ **0.015902** ≤ 0.016（h ≥ 3 では ≈ 0.0755）。閾値 4
- J_OM^Wt：P(h ≥ 2) ≤ P(Bin(20, 1／420) ≥ 2) ≈ **0.001047** ≤ 0.002（h ≥ 1 では ≈ 0.0466）。閾値 2

### 5.2 U の家族（向きを問わない）

- **U の家族全体の水準 0.05**。同じ割り当て（0.016・0.016・0.016・0.002）
- J_Ca^U・J_O^U・J_M^U：P(h ≥ 6) ≤ P(Bin(20, 2／20) ≥ 6) ≈ **0.011253** ≤ 0.016（h ≥ 5 では ≈ 0.043174）。閾値 6
- J_OM^U：P(h ≥ 3) ≤ P(Bin(20, 1／210) ≥ 3) ≈ **0.000116** ≤ 0.002（h ≥ 2 では ≈ 0.004070）。閾値 3

### 5.3 全体の扱い

- 閾値は、割り当てた水準と、個体ごとの帰無の確率（K ＝ 19 と向きの扱い）から決まる最小の整数。結果を見る前に決めたもので、データからは選んでいない
- **二つの家族は別の問いに答える**（Wt：位相をそろえた背景での重みの塊の効果、U：重みをそろえた背景での Unit の状態の塊の効果）。家族ごとに水準を抑え、**二つの家族の結果を組み合わせた検定的な主張はしない**
- **実験全体（8 判定）で誤りの水準 0.05 とは主張しない**。二つの家族の誤りの水準の単純な和の上界は 0.10 である
- 成立は、上の前提のもとで帰無仮説を各判定の水準で棄却することで、交換可能性の破れの数学的証明ではない。不成立は、棄却できなかったということで、交換可能性を示すものではない
- 家族の中・家族のあいだで、判定の成立を足し合わせたり、h を比べたりしない

### 5.4 方法上の選択（この実験で新しく確定する。どれも効果と検出力を限る）

| 選択 | 何を限るか |
|---|---|
| **τ の窓 [13441, 13500]（幅 60 ＝ trials.every）と、22 本体に共通の τ** | 入れ替えの時刻は個体ごとに 1 つで、主の区間の始まりより最大 59 Pulse 前になりうる。τ がない個体は 8 つの判定で「外にない」に数えるので、そういう個体が多いと検出力が下がる |
| **受け手を W20 に固定**（各個体に 1 つ） | 効果は一つの背景のもとでの条件付きの効果。背景によって効果の向き・有無が変わる場合は、個体ごとの結果がばらつき、検出力が下がりうる（0026 §5.3 と同じ） |
| **W を 20 にする**（受け手 1 ＋ 参照のドナー 19） | K ＝ 19 を 0028 と同じに保つ |
| **塊を 2 つに分ける**（0026 と同じ置き場所） | 塊の中の成分は分けない。2 つの塊の組み合わせだけが効く場合は、どちらの家族でも外れないことがある（担い手の整理 命題 3 (c)） |

| **入れ替えた後も可塑性ありで進める** | C0-1′ の定義どおり。重みの効果を、区間の中の書き換えと分けない（§3.3） |

### 6.1 沈黙・凍結の扱い（測定の前に固定する）

- 個体を除かない。主の区間で発火しない Unit は、その Unit を含む組の数が 0 になる（ふつうの算術）
- 凍結は「外にない」に数える（§4.1）
- 沈黙・凍結・発火の数の多さ・層を、判定を救う・変える・個体を除く理由に使わない。操作の確認に入れない
- **事前に書く限界**：A が構造的に沈黙する個体では、自然な本体の Δ_AB・D はすべて 0 になる（担い手の設計 命題 6）。入れ替えた本体でも、A が発火しなければ同じく 0 になり、凍結しうる。凍結が多ければ検出力が下がる（0028 では C0 の全判定の凍結が 5 個体：0028 §15.5 の 9）

## 12. 結果ごとに言えること

どの行でも、「言えること」は **C-I（W20 の残りの塊と時刻 τ を背景に固定した、ドナーのあいだの条件付きの効果）とその介入の参照との比較**までで、「言えないこと」には、表に書いたものに加えて、**自然な差の再現・消去（C-II）**、**自然な差の原因（C-III）**、**排他性・寄与の割合**が常に入る。

- 自然な比較（補助）の結果で、主の結果を救ったり強めたりしない。自然な比較で外にあった個体だけを取り出して、入れ替えの効果を語らない
