### 3.2 命題 2（一部だけを入れ替えた状態は、自然な経験から到達しないことがある）【命題】（C0 の式による）

C0（0012 の設計図。内在の駆動 c_i ＞ 0、重みと Receptor の重みは非負、不応期 0、出生時の activity は非負、可塑性 v1.1）で、出生時の状態からどんな Receptor の予定で進めても、Pulse t ≥ 1 の終わりの状態は次をすべて満たす。

| # | 不変の関係 | 理由 |
|---|---|---|
| I1 | 組の和：w(i→j) ＋ w(j→i) ＝ w_max | 出生時に両方 w_max／2。1 Pulse の更新で、j が発火すれば Δw(i→j) ＋ Δw(j→i) ＝ A·X_i·(w_max − w(i→j) − w(j→i))／w_max ＝ 0、i が発火しても同じ形で 0（I2 を使う。0020〜0023 で 1e−12 で確かめている） |
| I2 | 痕跡は Unit ごと：接続 i→j の送り手の痕跡と、接続 k→i の受け手の痕跡は、どれも同じ値 X_i | どれも 0 から始まり、i の発火だけで同じ式（κ 倍して、発火なら 1 を足す）で更新される |
| I3 | a_i(t) ＝ 0 ⇔ i が t に発火した | 発火しなければ a_i(t) ＝ λ a_i(t − 1) ＋（届いた駆動）＋ c_i ≥ c_i ＞ 0。発火すれば 0 に戻る |
| I4 | i が t に発火した ⇔ i から各受け手への駆動が、次の Pulse に届くものとして置かれている | Runtime は、その Pulse に発火した Unit からだけ駆動を作る |
| I5 | i が t に発火した ⇒ X_i(t) ≥ 1 かつ h_i(t) ≥ α | 痕跡も順応も、発火の Pulse に 1・α を足す（減らしてから足す） |
| I6 | 置かれた駆動の重みは、その Pulse の冒頭の重みで、終わりの重みとは 1 Pulse の更新の逆で結ばれる（切り詰めがないとき） | 更新は重みについて affine で、係数 1 − (A／w_max)(X_i·1［j が発火］＋ X_j·1［i が発火］) は、痕跡が 1／(1 − κ) 以下なので正（研究③ 部類 𝒜）。その逆に要る t − 1 の痕跡と t の発火は、I3・I5 により t の終わりの状態から決まる |

状態だけで確かめられる形にすると、I3〜I5 から「a_i ＝ 0 ⇔ i から置かれた駆動がある」「a_i ＝ 0 ⇒ X_i ≥ 1 かつ h_i ≥ α」が出る。

**帰結**：これらのどれかを破る状態は、t ≥ 1 のどんな自然な経験からも到達しない。例えば
- 組の片方の重みだけを入れ替える（I1 を破る）
- ある Unit の activity だけを、そのとき発火していた個体の値（0）に入れ替え、駆動・痕跡・順応を残す（受け手がその Pulse に発火していなければ、上の状態の関係を破る）
- ある接続の痕跡だけを入れ替える（I2 を破る）
- 一方の個体がその Pulse に発火しているときに、重みだけを入れ替える（I6 を破る）

**言えないこと**：I1〜I6 を満たすことは、到達できることの十分条件ではない。入れ替えた組み合わせ（例：O の 6 本の重みと S の Unit の状態）が、何らかの経験の履歴から到達できるかは、一般には分からない【未決】。到達できない状態での応答の違いは、自然な個体の比較からの外挿である。

**【候補】**：入れ替えは、少なくとも I1〜I6 を保つ単位で定義する。
- **重みの塊**：組（i→j, j→i）ごとに、または 6 本まとめて
- **Unit の塊**：Unit i の (a_i, h_i)、すべての接続の欄にある X_i、i から置かれた駆動
- 駆動の重みの不整合（I6）を避けるため、**入れ替える Pulse は、どちらの個体でもその Pulse にどの Unit も発火せず、Receptor の出来事もない Pulse** に置く（置かれた駆動がない。I3 によりすべての a_i ＞ 0）。この規則で時刻が個体の対ごとに変わりうることを、結果の前に決める
- 補助の状態の置き場所（痕跡は接続ごとの欄に重複して置かれているが、値は Unit ごと）で入れ替えの意味が変わる（研究③ 命題 1、研究④ §1.3）ので、置き場所まで書いて決める

### 3.3 命題 3（成分ごとの答えは、組み合わせの性質を取り違えうる）【命題（構成）】

研究④の命題 1 に、次を加える。

- **(a) 打ち消し**（研究④ 命題 1 (a)）：移すと差が出るのに、自然には差がない
- **(b) 冗長**（研究④ 命題 1 (b)）：どちらの成分を単独で戻しても、自然な差が消えない
- **(c) 組み合わせだけが外れる**：状態 (c, z)、L(c, z) ＝ 1［(c, z) ＝ (1, 1)］、O が (1, 1)、並べ替えがすべて (0, 0) とする。O だけが外れる。O の c だけを戻すと (0, 1) で外れが消え、z だけを戻しても (1, 0) で消える。O の c だけを並べ替えへ移すと (1, 0) で外れず、z だけを移しても外れない。**どちらの成分も「戻すと消える」が「移しても生じない」**。外れは組み合わせの性質で、どちらかの成分の性質ではない

（証明：値を代入するだけ。）

C0 には、この種の交互作用がある：t0 ＋ 1 に受け手が発火するのは、届いた駆動 δ（重みと発火で決まる）が余裕 G（Unit の状態で決まる）以上のときで、ある成分の効果はほかの成分の値に依る（識別のメモ 命題 3.4）【既存の命題】。したがって、**成分ごとの寄与の割合は一般に一意に定まらない**（識別のメモ U5）。この文書でも割合に分けない。

### 3.4 命題 4（「戻すと消えた」は、成分の特異性を示さない）【命題（構成）】と介入の参照

状態 (c, z) ∈ ℝ²、L(c, z) ＝ sin(ω(c ＋ z))（ω ＞ 0）とする。O は c_O ＋ z_O ＝ π／(2ω)（L(O) ＝ 1、とりうる最大）、並べ替え S_j の L(S_j) は 1 未満で、正の値と負の値の両方を含むとする（例えば ±0.5）。O は並べ替えの最大より大きく、外にある。
- **c と無関係のずれ**（c_O を c_O ＋ π／(2ω) に替える）でも、L ＝ sin(π) ＝ 0 で、並べ替えの最小と最大のあいだに入り、O の外れは消える
- O の c を S_j の c_j に替えると L(c_j, z_O) ＝ cos(ω(c_j − c_O)) で、ω(c_j − c_O) が 2π の整数倍に近くなければ 1 未満になり、多くの場合に参照の中に入る
- したがって「O の c を並べ替えの値に戻すと外れが消えた」は、c の自然な値が O に特有の情報を持っていたことを示さない。L が状態に敏感なら、c と関係のない置き換えでも外れは消えうる

（証明：代入するだけ。）

C0 の L は、発火の時刻（整数）で決まり、1／300 刻みの値しかとらない。状態の小さな違いが閾値の越え方を変えれば L は跳ぶ（区分的に一定で、不連続）【命題】（定義から）。0023 の並べ替えどうしの L の幅は個体によって大きかった（例：16007 は −25.1〜＋52.5）【既存の結果】〔0023〕。

**介入の参照【候補】**：ℐ-1 の効果を、**並べ替えどうしで同じ成分を入れ替えたときの効果**と比べる。
- 移す向き：受け手 S_j に、ドナー O の c を移した L(S_j ← c_O) を、ほかの並べ替え S_k（k ≠ j）の c を移した L(S_j ← c_{S_k}) の分布と比べる。帰無仮説の候補は「ドナーとしての O は、ドナーとしての S_k と交換可能」（0023 の帰無仮説と同じ形。仮説の置き方で、O について確かめた性質ではない）
- 戻す向き：O に S_k の c を入れた L(O ← c_{S_k}) を、並べ替えどうしで入れ替えた値と比べる
- これで分かるのも C-II（条件付きの効果）までで、C-III ではない

### 3.5 命題 5（自然な差の原因の特定（C-III）は、加法性の前提なしには定まらない）【命題】

自然な差 L(c_O, z_O) − L(c_S, z_S) を、c による部分と z による部分に分けるとき：

（証明：(c) の値を代入する。加法的なら定義から。）

## 10. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

0023 では、「順番どおりの経験をした個体は、同じ問いかけに対して、順番をばらばらにした経験とは違う反応をした」ことを、事前に決めたやり方で確かめました。次は、**その違いを中の何が生んだのか**を調べたいのですが、確かめ方によって言えることが違うので、実験の前に整理しました。

### 大事な区別

1. **「中の部品を入れ替えたら反応が変わった」と「その部品が違いの原因だった」は別です。** 部品どうしは影響し合うので、一つだけ入れ替えると、ふつうの経験ではありえない組み合わせになることがあります。また、反応が状態の小さな違いに敏感なら、どんな入れ替えでも反応は変わりえます。そこで、ばらばらの経験どうしで同じ入れ替えをしたときの変わり方と比べることにします
2. **「学習を止めても同じことが起きた」は、元の脳で学習が無関係だった証拠ではありません。** 逆に、止めたら起きなかったからといって、学習で変わったつながりが違いを運んでいた、とも言えません。学習を止めた脳は、元の脳から学習だけを取り除いたものではなく、別の脳として扱います
3. **0023 で気づいた問題も材料にします。** 順番どおりの経験と、B と C の役を入れ替えた経験は、どちらも「どの部品も毎回 1 回ずつ刺激される」という釣り合いを持っています。ばらばらの経験にはこの釣り合いがありません。違いは、順番そのものではなく、この釣り合いから来ているのかもしれません。また、問いかけの時期に、ほとんど反応しない部品が多いことも分かりました（もともと動きにくい部品だった可能性がありますが、まだ確かめていません）

### この後

候補は、①学習を止めた脳で同じ実験をする、②釣り合いをそろえた並べ替えと比べる、③部品を入れ替える、④問いかけの時期を遅らせる、の 4 つです。計算が軽く、結果の読み方が単純な①と②を先に行い、③はその結果を見てから設計する、という順番を提案しています。どれも、0023 の結論を変えたり、0023 の個体を使い回したりはしません。
