## 0. 読み方

### 0.2 結論の先取り

1. **S3 の主張を二つの層に分け、層ごとに要る比べを決めた**（§2）
   - 層 1「経験による可塑的な変化を通して、選択の分布が変わった」：R-1（可塑性を止めた対照と、PC-3・PC-4 の型の比べ）が要る
   - 層 2「その変化が、行動と結果の対応に依った（結果に応じて変わった）」：層 1 に加えて R-7（対応の入れ替え・結果のランダムな介入 LC3、またはそれに当たる対照）が要る
   - どちらも、価値・意味・目的を学んだとは言わない（三段の比較 §2.4・§4.3）
2. **比べの基準を 10 項目にした**（§4）。R5 §6.3 の完了の条件の 1 に挙げた項目をすべて含み、R-1 と R-7 を最も重い基準にした
3. **推奨：AS2b を第一候補にする**【候補】（§6）
   - R-7 の対照（個体の中で、どちらの行動が結果を返すかを入れ替える）を、行動の源への直接の刺激なしに作れる。AS2 では、入れ替えが行動の源への直接の駆動の型も一緒に変える
   - 足す変更が一つの層（選択の窓と競合 I2）で、Unit を足さない（AS3 は Unit も足す）
   - 限界：結果が片側だけの非対称（命題 G-11）と、刺激の数が行動に依ること。これは層 2 の主張の一部として扱い、価値・罰とは呼ばない
4. **AS2 は第二候補、AS3 は後の候補**にする【候補】
   - AS2：感覚と運動の重なりで、R-7 の入れ替えと即時の帰還が分けにくい。K1 を守るための追加の規則が要る
   - AS3：R-1・R-7 は作りやすいが、Unit・接続・初期の重み・入次数を一度に足す（一度に一つの変更に反する）。AS2b で構成の限界がはっきりしたときの次の候補にする
5. **どの構成でも、S3 の事前登録の前に確かめるもの**を §7 に書いた。とくに、窓の中で行動が出る見込み（測れる大きさ。常設チェック C3）は、三つの構成に共通の未確認の点で、解析と合成の seed の契約テストで確かめる（smoke の結果で調整しない）
6. **0034〜0037 の結果をすべて見た後に書いた**（§1）。結果が基準に入った所を、一つずつ開示した

## 2. S3 の主の問いと、主張の二つの層

三段の比較 §4.3 の問い：**固定した対応のもとで、試しの区間（または後の窓）の行動 X の割合（あるいは X の先行の度合い）が、経験に依って変わったか**。

| 層 | 主張の形 | 要る比べ | 除く対立の説明（N-3・N-4 §3.3.1 の H^alt） |
|---|---|---|---|
| **層 1** | 経験による可塑的な変化を通して、選択の分布が変わった | **R-1**：可塑性を止めた対照（LC1）と、PC-3（再生）・PC-4（移植）の型の比べ。経験の列の分岐を除く比べを少なくとも一つ | (a) 生まれつきの状態・リズムと自己の列の対応、(b) 可塑性を通さない即時の帰還 |
| **層 2** | その変化が、行動と結果の対応に依った（結果に応じて変わった） | 層 1 に加えて **R-7**：個体の中の対応の入れ替え、結果のランダムな介入（LC3）、またはそれに当たる対照 | 結果に関係のない手がかりと発火の時刻の組による可塑性（R5 §5.2 の R-7 の根拠） |

- 層 2 は層 1 を含む。R-7 の対照を作れない構成では、主張の上限を層 1 にする（R5 の R-7）
- どちらの層も、価値・報酬・罰・意味・目的・因果の理解とは呼ばない（三段の比較 §2.4・§4.3、命題 G-11）
- 固定した対応（どの Unit の発火が X か、X がどの刺激を返すか）は実験者が決める。S3 で言う学習は、その対応のもとで選択の分布が変わることである（三段の比較 §2.4）

## 3. 候補の構成【既存の命題・整理】

三段の比較 §4.1 と N-3・N-4 §4.1 の定義をそのまま使う。三つとも、C0 の Unit の力学と可塑性は変えない。

| 構成 | 行動の源（意図の形） | 結果 | 感覚と運動の重なり |
|---|---|---|---|
| **AS2** | 手がかりの後の窓で、手がかりを受けない 2 つの Unit のうち先に発火したもの（I2） | X なら刺激 P、Y なら刺激 Q。P・Q は手がかりでない 2 つの Receptor（対応は乱数で割り当て） | **重なる**：C0 の 3 Unit では、手がかりでない 2 つの Receptor は、行動の源の 2 つの Unit の入口である。結果の刺激が、行動の源に直接来る |
| **AS2b** | AS2 と同じ | X なら手がかりの Receptor にもう一度刺激、Y なら何も来ない（どちらを X にするかは乱数） | 重ならない：結果は手がかりの Unit に来る。行動の源の入口には何も来ない |
| **AS3** | 入口のない Unit を 2 つ足し、その発火（I1）または競合（I2） | AS2 と同じ | 重ならない（行動の Unit は入口を持たない） |

- **検討して、候補に足さなかった変種**【整理】
  - AS2b の対称化（X も Y も手がかりの Receptor に結果を返し、遅れや個数で区別する）：遅れ・個数の違いという新しい値の自由度を足し、その違いそのものが対応の中身になる。3 Unit では、行動の源でない Receptor は手がかりの Receptor 一つしかないので、対称化には新しい値が要る（常設チェック C1）
  - I3・I4（閾値下の状態・時間の積分を読む意図）：新しい関数の形の自由度が多い（N-3・N-4 §2.4.2、常設チェック A6）。今は置かない

## 5. 三つの構成の比べ【整理】

○：満たせる見込み。△：条件付き・交絡あり。×：満たせない。どれも、構成の定義と既存の命題からの評価で、実装・実験はしていない。

| 基準 | AS2 | AS2b | AS3 |
|---|---|---|---|
| **SC-1 問いの形** | ○ | ○ | ○ |
| **SC-2 R-1** | ○（LC1・PC-3・PC-4 を作れる。世界は決定論なので、再生の一致は AS1 と同じ形で成り立つ見込み） | ○（同じ） | ○（同じ。足した Unit の状態・重みも複製・移植の対象に入れる） |
| **SC-3 R-7** | **△**：対応の入れ替え（X → P・Y → Q と X → Q・Y → P）は作れる。しかし、P・Q は行動の源の入口なので、入れ替えは「どちらの行動の後に、どちらの行動の源が直接駆動されるか」も一緒に変える。選択の変化が対応への依存か、直接の駆動の即時の効果かは、LC1 を併せても、可塑性を通さない部分しか分けられない | **○**：個体の中で、どちらの行動が結果を返すか（X ＝ 源 1 か 源 2 か）を入れ替えられる。結果は手がかりの Unit に来るので、入れ替えで行動の源への直接の駆動の型は変わらない。LC3（結果を確率 ρ で返す）も作れる | ○：入れ替え・LC3 とも作れ、結果は行動の Unit に直接来ない |
| SC-4 交絡 | **重なり**：結果の刺激が行動の源を直接動かす（命題 G-3 により次の Pulse に発火しうる）。推定対象 A に入口からの直接の駆動が加わる（三段の比較 §4.2）。窓の中の反射の発火を K1 で除くための規則が要る | **非対称**：結果があるのは X だけで、刺激の数が行動に依る（H^alt の (c)）。X の側にだけ、逆順の時刻の組の弱める項が生じうる（命題 G-11）。結果が手がかりの Receptor に来るので、結果の刺激が次の窓を開かない規則が要る（K6） | **自由度**：足した Unit の配線しだいで、交絡の形が変わる。足した Unit がもとの Unit とつながると、もとの Unit の力学が変わる |
| SC-5 新しい自由度 | 窓、遅れ、同時の扱い、対応、K1 のための規則（結果の刺激の直後の発火の扱い） | 窓、遅れ、同時の扱い、どちらを X にするか、K6 の規則 | AS2 の自由度に加えて、Unit の数・接続・初期の重み・入次数 |

| SC-6 実装の契約 | I2 の集約の部品、意図の隔離、世界の規則、乱数 | 同じ | 同じに加えて、Unit の追加の契約（G-d と重なる変更） |
| SC-7 沈黙 | 行動の源は結果の刺激を入口に受けるので、AS1 とは沈黙の条件が変わる。十分条件を立て直す | 行動の源の入口には何も来ないので、AS1 の沈黙の考え方（N-3・N-4 §3.6）に近い形で立て直せる見込み | 足した Unit の内在の駆動の値しだい（新しい値） |

## 6. 推奨【候補】

### 6.1 順位

1. **AS2b を第一候補にする**
2. AS2 を第二候補にする
3. AS3 を後の候補にする

### 6.2 理由

- **SC-3（R-7）で、AS2b が AS2 より明らかによい**
  - AS2 の入れ替えは、対応と一緒に、行動の源への直接の駆動の型を変える。そのため、層 2 の主張（結果に応じて変わった）に、可塑性を通さない即時の効果だけでなく、「どの行動の源を直接動かしたか」の違いを通した可塑性も混ざる
  - AS2b の入れ替えは、どちらの行動が結果を持つかだけを変え、結果の行き先（手がかりの Unit）は同じである。入れ替えた二つの本体の違いは、行動と結果の対応に限られる
  - 入れ替えは同じ個体（同じ出生時の状態）の中で行うので、どちらの行動の源が生まれつき発火しやすいか（H^alt の (a)）は、二つの本体で同じになる。選択の違いを、生まれつきの偏りと対応への依存に分けやすい（AS2・AS3 の入れ替えでも同じ性質を持つ）
- **SC-5（一度に一つの変更）で、AS2b が AS3 よりよい**
  - AS2b は、AS1 に選択（窓と I2）の層だけを足す。AS3 は Unit も足す
  - S3 で期待した変化が出なかったとき、AS2b なら、原因の候補を選択の層の契約に狭めやすい（三段の比較 §5.2 の P の利点と同じ理由）
- **SC-9 で、AS2b は AS1 の道具・命題に最も近い**：行動の源の入口に刺激が来ない点が AS1 と同じで、再生・移植・反実仮想の道具の形をそのまま使える見込みがある
- **SC-2（R-1）は、三つの構成で差がない**。そのため、推奨は主に SC-3・SC-5・SC-9 で決まった

### 6.3 AS2b の限界と、その扱い

| 限界 | 扱い |
|---|---|
| 結果があるのは X だけで、刺激の数が行動に依る（H^alt の (c)） | 層 2 の主張に含める（行動と結果の対応に依る経験の違いは、対応への依存の一部である）。ただし、層 1 の主張（可塑性を通した）には LC1 が要る。「刺激が多いから変わった」と「可塑性が変わったから変わった」は、LC1 と PC-3・PC-4 の型の比べで分ける |
| X の側にだけ、逆順の時刻の組の弱める項が生じうる（命題 G-11） | 正味の向きは事前に決めない（命題 G-10・G-11 の帰結）。選択が X から離れても、Y に移っても、報酬・罰・回避とは呼ばない |
| 結果の刺激が手がかりの Receptor に来る | 結果の刺激が次の窓を開かないことを、世界の規則として事前に書く（K6）。手がかりの Unit が結果で発火すること（命題 G-3）は、行動の源の発火ではないので K1 に反しない。ただし、その発火が行動の源に間接の駆動を届けることは残る（N-3・N-4 §2.4.6） |
| 対称な構成ではない | 構成の定義として受け入れる。対称化は新しい値を足すので採らない（§3） |

### 6.4 AS2 と AS3 を、いつ使うか【候補】

- **AS2**：AS2b の層 2 の結果が、片側の非対称に強く依ると読める場合に、対称な結果の構成として問い直す候補。そのときは、重なりの交絡を事前に書き、K1 の規則を足す
- **AS3**：AS2b で、選択の層の契約が作れない・行動の源の沈黙が扱えないなどの、構成の限界がはっきりした場合の次の候補。Unit を足す変更として、別の文書で自由度を数える
- どちらも、AS2b の S3 の結果（成立・不成立）を見て選び直すのではなく、上の構成の限界の理由を書いた文書を経る（§1.3）

**三つの構成に共通の、事前登録の前の確認**【候補】
- **窓の中で行動が出る見込み**（測れる大きさ。常設チェック C3）

  - 窓の長さ・手がかりの間隔をどう決めるかで、選択が表に出る試しの数が変わる

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を決めようとしているか

次の段階（S3）では、AI に「二つの行動のどちらを選ぶか」をさせ、経験によってその選び方が変わるかを調べます。そのための仕組みの候補が三つ（AS2・AS2b・AS3）あり、どれを使うかを選ぶ基準を書きました。結果を見てから都合のよい仕組みを選ばないように、先に基準を決めておくためのものです。

### 大事にした点

- **学習のせいかどうかを確かめられるか**：選び方が変わったとき、それが「経験で接続が変わったから」なのか、「受けた刺激の順番が違っただけ」なのかを、比べて分けられる仕組みか
- **行動の結果のせいかどうかを確かめられるか**：「どちらの行動に結果が返るか」を同じ個体の中で入れ替えて、選び方の変化がその組み合わせに依るかを確かめられる仕組みか
- **一度に変えるところが少ないか**：うまくいかなかったときに、原因を探しやすいか

### 推奨

- AS2b を第一候補にしました。片方の行動にだけ結果が返る仕組みで、どちらに返すかを入れ替えても、行動を出す部分に直接刺激が入らないので、「結果のせいか」をきれいに確かめられます
- 片方にしか結果がないという偏りはありますが、それは限界として前もって書いておき、「ご褒美を覚えた」のような言い方はしません

### この後

この基準と推奨をレビューで固めてから、今の段階（S2）を終えて次の段階に進むかを、この推奨と一緒に t-k さんにご相談します。今回、t-k さんに判断していただくことはありません。
