### 0.2 結論の先取り

1. **S3 の主張を二つの層に分け、層ごとに要る比べを決めた**（§2）
   - 層 1「経験による可塑的な変化を通して、選択の分布が変わった」：R-1（可塑性を止めた対照と、PC-3・PC-4 の型の比べ）が要る
   - 層 2「その変化が、結果の付与の規則（どの行動 ID が結果を生むか）に依った」（規則への依存の総効果）：層 1 に加えて R-7（§2.1 の入れ替え・結果のランダムな介入 LC3、またはそれに当たる対照）が要る
   - どちらも、価値・意味・目的を学んだとは言わない（三段の比較 §2.4・§4.3）
2. **R-7 の対応の入れ替えを厳密に定義した**（§2.1）：出生時の状態・行動の源と行動 ID・手がかりの予定・窓の規則・測り方を固定し、世界の側の「どの固定した行動 ID が結果を生むか」の規則だけを入れ替える。入れ替えで分かれる結果の刺激の数・時刻は規則の変更の媒介で、層 2 で言えるのは**結果の付与の規則への依存（総効果）**までである。行動固有の結果の連合の獲得や信用の割り当てとは同一視しない
3. **比べの基準を 10 項目にした**（§4）。R5 §6.3 の完了の条件の 1 に挙げた項目をすべて含み、R-1 と R-7 を最も重い基準にした。R-7 の基準は、対照を作れるか（SC-3a）と、経路の読み方の複雑さ（SC-3b）に分けた
4. **推奨：AS2b を第一候補にする**【候補】（§6）
   - R-7 の対照を作れること（SC-3a）は、三つの構成で差がない
   - AS2b を AS2 より先にする理由：結果が行動の源に直接入らないので、K1 の直接の反射を追加の規則なしに避けられ、対応への依存の効果の経路の整理が相対的に容易（SC-3b）。行動の源の入口に刺激が来ない点が AS1 と同じ（SC-9）
   - AS2b を AS3 より先にする理由：AS3 より足すものが少ない（Unit・接続・初期の重み・入次数を足さない。SC-5）。ただし AS2b も、AS1 に選択の窓と競合（I2）、手がかりの外の予定、結果を手がかりの Receptor に返す世界の規則を足す
   - 限界：結果が片側だけの非対称（命題 G-11）と、刺激の数が行動に依ること。結果の付与の規則の総効果として層 2 に含め、価値・罰とは呼ばない
5. **AS2 は第二候補、AS3 は後の候補**にする【候補】
   - AS2：R-7 の対照は作れる。ただし結果が行動の源を直接動かすので、可塑性を通した直接の刺激の経路と間接の帰還の経路の寄与は分けられない。K1 を守るための追加の規則が要る
   - AS3：R-1・R-7 は作りやすいが、Unit・接続・初期の重み・入次数を一度に足す。AS2b で構成の限界がはっきりしたときの次の候補にする
6. **どの構成でも、S3 の事前登録の前に確かめるもの**を §7 に書いた。とくに、窓の中で行動が測れる形で出る見込み（常設チェック C3）は、三つの構成に共通の未確認の点で、解析と合成の seed の契約テストで確かめる（smoke の結果で調整しない）。**成り立たなければ、その構成では S3 の事前登録に進まない**（前方の関門）
7. **0034〜0037 の結果をすべて見た後に書いた**（§1）。結果が基準に入った所を、一つずつ開示した

## 2. S3 の主の問いと、主張の二つの層

三段の比較 §4.3 の問い：**固定した対応のもとで、試しの区間（または後の窓）の行動 X の割合（あるいは X の先行の度合い）が、経験に依って変わったか**。R-7 の比べでは、X を物理の行動 ID（A1・A2）に読み替えて報告する（§2.1）。

| 層 | 主張の形 | 要る比べ | 除く対立の説明（N-3・N-4 §3.3.1 の H^alt） |
|---|---|---|---|
| **層 1** | 経験による可塑的な変化を通して、選択の分布が変わった | **R-1**：可塑性を止めた対照（LC1）と、PC-3（再生）・PC-4（移植）の型の比べ。経験の列の分岐を除く比べを少なくとも一つ | (a) 生まれつきの状態・リズムと自己の列の対応、(b) 可塑性を通さない即時の帰還 |
| **層 2** | その変化が、結果の付与の規則（どの固定した行動 ID が結果を生むか）に依った（規則への依存の総効果。行動固有の結果の連合の獲得ではない） | 層 1 に加えて **R-7**：§2.1 の入れ替え、結果のランダムな介入（LC3）、またはそれに当たる対照 | 結果に関係のない手がかりと発火の時刻の組による可塑性（R5 §5.2 の R-7 の根拠） |

- 層 2 は層 1 を含む。R-7 の対照を作れない構成では、主張の上限を層 1 にする（R5 の R-7）
- どちらの層も、価値・報酬・罰・意味・目的・因果の理解とは呼ばない（三段の比較 §2.4・§4.3、命題 G-11）
- 固定した対応（どの Unit の発火が X か、X がどの刺激を返すか）は実験者が決める。S3 で言う学習は、その対応のもとで選択の分布が変わることである（三段の比較 §2.4）
- 層 2 で言えるのは、**結果の付与の規則への依存（規則を替えたときの総効果）**までである。行動固有の結果の連合を獲得したこと・信用の割り当てをしたことは言わない（§2.1）

### 2.1 R-7 の「対応の入れ替え」の定義【整理】

記号：二つの行動の源の Unit を「源 1」「源 2」、その発火が生む行動 ID を「A1」「A2」と書く（K2 の割り当て。個体ごとに乱数で決め、記録する）。§3 の表の X・Y は「規則のもとで結果を返す行動」「返さない行動」の略記で、入れ替えの比べでは使わない。

| | 固定するもの（二つの本体で同じ） | 入れ替えるもの |
|---|---|---|
| 脳の側 | 出生時の状態（同じ seed）、源 1・源 2 の物理の ID、手がかりの Unit、Unit から行動 ID への割り当て（源 1 → A1、源 2 → A2） | なし |
| 世界の側 | 手がかりの予定、窓の開閉の規則、同時の扱い、遅れ L、結果の刺激の中身と行き先、試しの区間の条件と測り方 | **どの固定した行動 ID が結果の刺激を生むか**の規則 c だけ（AS2b：c ＝ A1 か A2。AS2：{A1 → P, A2 → Q} か {A1 → Q, A2 → P}。AS3：AS2 と同じ） |

- **報告の量は、物理の行動 ID にそろえる**（例：試しの区間で A1 が選ばれた割合を、c ＝ A1 の本体と c ＝ A2 の本体で比べる）。結果を返す側を X と呼び直して、「X の割合」で比べ直すことはしない（呼び直しで差を作らない。K2、役の整列の原則：三段の比較 §2.1）
- 単なる名前の交換（X・Y の札の付け替え）は、この入れ替えではない。介入は、世界の規則 c の替え方として定義する
- **入れ替えが分岐させるもの**：規則 c を替えると、結果の刺激が実際に来る数・時刻、それに続く経験の軌道も、二つの本体で分かれる（N-3・N-4 §3.3.1 の H^alt の (c)）。これは規則の変更が選択に届く**媒介**で、「二つの本体の介入の違いは規則 c だけ」と両立する
- **言えることの上限**
  - R-1（LC1・PC-3・PC-4 の型）で、可塑性を通した条件付きの違いを示す
  - R-7 で、選択の違いが結果の付与の規則 c に依ったかを問う
  - 合わせて言えるのは「結果の付与の規則を替えると、可塑的な変化を通して、選択の分布が変わった」まで
  - 結果の刺激の総量・時刻による可塑性の効果と、行動に固有の結果の連合・信用の割り当てを分けたことにはならない。後者の機構まで言うなら、ヨーク（同じ数・時刻の結果を行動と無関係に与える）や、外の履歴の量をそろえる対照などが別に要る。それは、この文書の構成の採用に必須の比べとしては求めない（#173 のレビュー）

## 3. 候補の構成【既存の命題・整理】

三段の比較 §4.1 と N-3・N-4 §4.1 の定義をそのまま使う。三つとも、C0 の Unit の力学と可塑性は変えない。

| 構成 | 行動の源（意図の形） | 結果 | 感覚と運動の重なり |
|---|---|---|---|
| **AS2** | 手がかりの後の窓で、手がかりを受けない 2 つの Unit のうち先に発火したもの（I2） | X なら刺激 P、Y なら刺激 Q。P・Q は手がかりでない 2 つの Receptor（対応は乱数で割り当て） | **重なる**：C0 の 3 Unit では、手がかりでない 2 つの Receptor は、行動の源の 2 つの Unit の入口である。結果の刺激が、行動の源に直接来る |
| **AS2b** | AS2 と同じ | X なら手がかりの Receptor にもう一度刺激、Y なら何も来ない（どちらを X にするかは乱数） | 重ならない：結果は手がかりの Unit に来る。行動の源の入口には何も来ない |
| **AS3** | 入口のない Unit を 2 つ足し、その発火（I1）または競合（I2） | AS2 と同じ | 重ならない（行動の Unit は入口を持たない） |

- **検討して、候補に足さなかった変種**【整理】
  - AS2b の対称化（X も Y も手がかりの Receptor に結果を返し、遅れや個数で区別する）：遅れ・個数の違いという新しい値の自由度を足し、その違いそのものが対応の中身になる。3 Unit では、行動の源でない Receptor は手がかりの Receptor 一つしかないので、対称化には新しい値が要る（常設チェック C1）
  - I3・I4（閾値下の状態・時間の積分を読む意図）：新しい関数の形の自由度が多い（N-3・N-4 §2.4.2、常設チェック A6）。今は置かない

## 5. 三つの構成の比べ【整理】

○：満たせる見込み。△：条件付き・交絡あり。×：満たせない。どれも、構成の定義と既存の命題からの評価で、実装・実験はしていない。

| 基準 | AS2 | AS2b | AS3 |

## 6. 推奨【候補】

### 6.1 順位

1. **AS2b を第一候補にする**
2. AS2 を第二候補にする
3. AS3 を後の候補にする

### 6.2 理由

- **重い基準（SC-1・SC-2・SC-3a）では、三つの構成に差がない**。三つとも、R-1 の比べと R-7 の対照を作れる見込みである。そのため、順位は SC-3b・SC-5・SC-8・SC-9 で決まった
  - どの構成でも、入れ替えは同じ個体（同じ出生時の状態）の中で行うので、どちらの行動の源が生まれつき発火しやすいか（H^alt の (a)）は二つの本体で同じになる
- **AS2b を AS2 より先にする理由**（R-7 の識別そのものの優劣ではない）
  - SC-3b：AS2b では、結果が行動の源に直接入らないので、K1 の直接の反射を、追加の規則なしに構成で避けられる。結果の効果は手がかりの Unit を経る間接の経路でだけ行動の源に届くので、対応への依存の効果の経路の整理が相対的に容易である。AS2 では、可塑性を通した直接の刺激の経路と間接の帰還の経路の寄与を分けられず、反射を除く規則も要る
  - SC-9：行動の源の入口に刺激が来ない点が AS1 と同じで、AS1 の命題（G-6〜G-10）の前提と、再生・移植・反実仮想の道具の形を、そのまま使える見込みがある
  - SC-5 では、AS2 と AS2b の差はほとんどない（どちらも共通のものに世界の規則を 2 つ足す）
- **AS2b を AS3 より先にする理由**
  - SC-5：AS3 は、共通のものと世界の規則に加えて、Unit・接続・初期の重み・入次数・内在の駆動の値を足す。AS2b は Unit を足さないので、足すものが少ない
  - SC-8：AS2b は出口を外せば C0 に戻る。AS3 は配線しだいである
  - S3 で期待した変化が出なかったとき、AS2b のほうが原因の候補を狭めやすい（三段の比較 §5.2 の P の利点と同じ理由）
- AS2b も、AS1 に選択の窓と競合（I2）だけを足すのではない。手がかりの外の予定、窓の開閉、結果を手がかりの Receptor に返す世界の規則も足す。「選択の層だけを足す」とは言わない

### 6.3 AS2b の限界と、その扱い

| 限界 | 扱い |
|---|---|
| 結果があるのは、規則 c が指す行動だけで、刺激の数が行動に依る（H^alt の (c)） | 結果の付与の規則の**総効果**として層 2 の主張に含める（§2.1：規則の変更の媒介）。ただし、層 1 の主張（可塑性を通した）には LC1 が要る。「刺激が多いから変わった」と「可塑性が変わったから変わった」は、LC1 と PC-3・PC-4 の型の比べで分ける。総効果を、行動固有の結果の連合の獲得と同一視しない |
| 規則 c の入れ替えで、結果の刺激の数・時刻・経験の軌道が分かれる | 規則の変更が選択に届く媒介として扱う（§2.1）。刺激の総量・時刻による可塑性の効果と、行動に固有の連合・信用の割り当ては分けない。分けるにはヨークなどの別の対照が要る（今の採用の必須の比べにはしない） |
| 結果を返す側にだけ、逆順の時刻の組の弱める項が生じうる（命題 G-11） | 正味の向きは事前に決めない（命題 G-10・G-11 の帰結）。選択が結果を返す側から離れても、もう一方に移っても、報酬・罰・回避とは呼ばない |
| 結果の刺激が手がかりの Receptor に来る | 結果の刺激が次の窓を開かないことを、世界の規則として事前に書く（K6）。手がかりの Unit が結果で発火すること（命題 G-3）は、行動の源の発火ではないので K1 に反しない。ただし、その発火が行動の源に間接の駆動を届けることは残る（N-3・N-4 §2.4.6） |
| 対称な構成ではない | 構成の定義として受け入れる。対称化は新しい値を足すので採らない（§3） |

### 6.4 AS2 と AS3 を、いつ使うか【候補】

- **AS2**：AS2b の層 2 の結果が、片側の非対称に強く依ると読める場合に、対称な結果の構成として問い直す候補。AS2 でも R-7 の総効果は問える。そのときは、直接の刺激の経路と間接の帰還の経路を分けないことを事前に書き、K1 の規則を足す
- **AS3**：AS2b で、選択の層の契約が作れない・行動の源の沈黙が扱えないなどの、構成の限界がはっきりした場合の次の候補。Unit を足す変更として、別の文書で自由度を数える
- どちらも、AS2b の S3 の結果（成立・不成立）を見て選び直すのではなく、上の構成の限界の理由を書いた文書を経る（§1.3）

## 7. 推奨の構成で、S3 の事前登録の前にそろえるもの【整理】

R5 の R-1〜R-7 を、AS2b に当てはめた。どれも S3 の事前登録とそのレビューで確かめる。

| 要件 | AS2b での形 | そろったと言える条件 |
|---|---|---|
| R-1 | LC1（E で可塑性を止めた系）と、PC-3（同じ外の履歴の再生）か PC-4（重みの移植）の型を、少なくとも一つ、主または必ず報告する対照にする | 再生・移植・可塑性の停止を、AS2b の世界（手がかりの予定と、規則 c が指す行動の結果）で作る契約テストが通る。再生の一致（命題 G-2）を合成の seed で確かめる |
| R-2 | 状態への条件付きの対比（例：PC-4 は M の状態のもと）を主に決め、逆の順を必ず報告する | 事前登録に書く |
| R-3 | 試しの区間で可塑性を止めるか動かすかを決め、言わないことを書く | 事前登録に書く |
| R-4 | 行動の源の沈黙と、窓の中で行動が出ない試しの扱い（K5：何もしないことは意図がないこと）を前もって決める | 沈黙の十分条件を AS2b の入力の条件で立て直し、出生時の状態から該当の割合を結果の前に計算する（N-3・N-4 §3.6）。窓の中で行動が測れる形で出る見込みを、解析と合成の seed で確かめる（下の共通の確認。前方の関門） |
| R-5 | 割合と区間を、判定と別に必ず報告する | 事前登録に書く |
| R-6 | 系どうしの構造上の同値（入れ替えた二つの本体が、どこまで同じか。LC1 の系と本体の一致の範囲）を、事前登録の前に書く | 事前登録に書き、契約テストで確かめる |
| R-7 | §2.1 の入れ替え：同じ個体で、規則 c ＝ A1 の本体と c ＝ A2 の本体を走らせる。出生時の状態、源 1・源 2 と行動 ID の割り当て、手がかりの予定、窓の規則、試しの区間の測り方は同じにする。報告の量は物理の行動 ID（A1 の選択の割合など）にそろえる。LC3 を加えるかは、新しい自由度（ρ・乱数）と比べて事前登録で決める | 主の量・成立の条件・帰無・識別の限界を事前登録で固定する。言えることの上限（結果の付与の規則への依存の総効果まで。行動固有の連合ではない）を書く。入れ替えた本体どうしで、規則 c のほかが同じであること（出生時の状態・割り当て・予定）と、どちらの本体でも行動の源への直接の刺激がないことを、契約テストで確かめる |

**三つの構成に共通の、事前登録の前の確認**【候補】
- **窓の中で行動が測れる形で出る見込み**（測れる大きさ。常設チェック C3）。**前方の関門**とする
  - 成り立たなければ、SC-1（選択の問い）を満たさないので、その構成では S3 の事前登録に進まない
  - その場合は、成り立たなかった理由を開示し、§1.3 のとおり、理由を書いた文書を経て次の候補を検討する。どの候補でも成り立たないなら、解けない問題として、t-k さんにご相談する（三つの相談の条件の一つ）
  - 行動の源の入口に刺激を来させない構成（AS2b・AS3）では、手がかりで行動の源が直接に発火することはなく、手がかりの Unit からの駆動（1 回あたり高々 w_max）と内在の駆動に依る
  - 窓の長さ・手がかりの間隔をどう決めるかで、選択が表に出る試しの数が変わる
  - **確かめは、解析と合成の seed の契約テストだけで行う。smoke の結果を見て窓を調整しない**（常設チェック C3・D1・D4）
- **I2 の集約の部品の契約**：Runtime・Effector に選ばせない（AI2〜AI4）。同じ Pulse の X・Y の扱いを対称な規則で前もって書く（N-3・N-4 §2.4.5）
- **意図の出力の隔離**（三段の比較 §2.2）と、出口を外すと C0 に戻ること（命題 G-1）を、契約テストにする
- **乱数の流れ**：行動 ID の割り当て、規則 c の割り付け、手がかりの予定、LC3 の割り付けを、名前で分ける（常設チェック C4）
- **計算の資源**（三段の比較 §5.3 の 4）：層 2 の比べに要る系の数を、事前登録の前に見積もる

## 8. 言わないこと

- この文書を、S3 の構成の決定・S3 への移行の承認と呼ぶこと（判断は t-k さんによる）
- 「AS2b で選択が結果を返す側から離れた（もう一方に移った）」を、報酬・価値の獲得、罰の回避、結果の意味の理解と呼ぶこと（命題 G-11、三段の比較 §2.4）
- R-7 の対照なしに、「結果に応じて選択が変わった」と言うこと（R5 §8）
- 層 1 の比べ（LC1・PC-3・PC-4）だけから、層 2 を言うこと
- 規則 c の入れ替えの効果を、行動固有の結果の連合の獲得・信用の割り当てと呼ぶこと（結果の付与の規則の総効果である。§2.1）
- 結果を返す側を X と呼び直して、入れ替えの差を作ること（報告は物理の行動 ID にそろえる。§2.1）

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を決めようとしているか

次の段階（S3）では、AI に「二つの行動のどちらを選ぶか」をさせ、経験によってその選び方が変わるかを調べます。そのための仕組みの候補が三つ（AS2・AS2b・AS3）あり、どれを使うかを選ぶ基準を書きました。結果を見てから都合のよい仕組みを選ばないように、先に基準を決めておくためのものです。

### 大事にした点

- **学習のせいかどうかを確かめられるか**：選び方が変わったとき、それが「経験で接続が変わったから」なのか、「受けた刺激の順番が違っただけ」なのかを、比べて分けられる仕組みか
- **行動の結果のせいかどうかを確かめられるか**：「どちらの行動に結果が返るか」という世界の決まりだけを、同じ個体の中で入れ替えて、選び方の変化がその決まりに依るかを確かめられる仕組みか
  - 入れ替えるのは世界の決まりだけで、個体や行動の名前は変えません
  - これで言えるのは「結果の返し方の決まりを変えると、選び方が変わった」までで、「どの行動にどの結果がつくかを、AI が一つずつ覚えた」とまでは言いません
- **一度に変えるところが少ないか**：うまくいかなかったときに、原因を探しやすいか

### 推奨

- AS2b を第一候補にしました。片方の行動にだけ結果が返る仕組みです
  - 「結果のせいか」を確かめる比べ自体は、三つの仕組みのどれでもできます
  - AS2b では、結果の刺激が行動を出す部分に直接入らないので、反射のような動きを別の決まりで除かなくてよく、結果がどこを通って効いたかの整理がしやすくなります
  - AS3 より、新しく足すもの（Unit など）が少なくて済みます。ただし AS2b でも、手がかりの予定や、結果の返し方の決まりは新しく足します
- 片方にしか結果がないという偏りはありますが、それは限界として前もって書いておき、「ご褒美を覚えた」のような言い方はしません
- 選ぶための窓の中で、行動が十分に出るかは、まだ分かりません。出ないと分かったら、その仕組みでは次の段階の計画に進みません

### この後

この基準と推奨をレビューで固めてから、今の段階（S2）を終えて次の段階に進むかを、この推奨と一緒に t-k さんにご相談します。今回、t-k さんに判断していただくことはありません。
