### 0.2 結論の先取り

1. **発火の数（X7）は、Δ_AB の側から二つの命題で絞れる**（§3.2・§3.3）。(i) 二つの Unit の発火の列の相対の時刻を一様にずらすと、Δ_AB の平均は**発火の数に依らず 0** になる【命題】。発火の数だけ（相対の時刻の構造なし）では、Δ_AB に系統的な向きは生じない。(ii) Δ_AB は、発火を 1 つ足す・除くごとに高々 1 しか変わらない【命題】。したがって「W の発火の列に発火を足し引きしただけ」の違い、または「W の条件付きの組の割合のまま数だけが違う」違いでは、**Δ_AB の差は |ΔN_A| ＋ |ΔN_B| を超えない**。この上界を超える外れ（「数の差を超える外れ」）は、数だけの違いでは作れない。この事象は 0028 の外れの事象の部分集合なので、**帰無のもとの確率の上界も閾値も 0028 と同じ**で事前登録できる
2. **C0 の主の区間では、ある Unit の発火の数の本体のあいだの違いは、受け取る駆動（結合 × 相手の発火の時刻）を通してしか大きくならない**【条件付き】（§3.4）。入力のない孤立した Unit では、1500 Pulse の後の 12000 Pulse の発火の数は、初めの状態に依らず ±1 に収まった（玩具の格子 25 点 × 初めの状態 60 通り）。そして、**結合だけで「B の発火の数が増え、同時に Δ_AB が増える」ことが起こる**【命題（構成）】（§3.5：2 つの Unit の玩具で、w(A→B) を 0.005 から 0.009 にすると、B の発火の数・N_{A→B}・Δ_AB が一緒に増え、初めの位相にほとんど依らない）。したがって、0028 §15.5 の 4（外れと B の発火の数の違いが同時に起きた）は、結合という説明と矛盾せず、**それ自体は「数だけの違い」の証拠でも反証でもない**。問いは「その違いを、区間の始まりの重みが生んだのか、位相（Unit の状態）が生んだのか」に移る
3. **重みの塊の家族（Wt）**：区間の始まりの直前の静かな Pulse τ で、受け手の本体（W20）の Unit の状態を全員に共通にし、重みの塊だけをドナー（O・M・W1〜W19）のものにする（§4.1）。ドナーのあいだで**位相・順応がそろっている**ので、この家族での O の外れは、τ の Unit の状態の違いでは生じえない。M をドナーに含めるので、**位相をそろえた背景で、重みの塊だけで、経験の内容に応じた逆向きの外れ（J_OM^Wt）が起きるか**を問える。言えるのは C-I まで
4. **Unit の状態の塊の家族（U）**：重みを受け手のものに共通にし、Unit の状態（activity・順応・痕跡）だけをドナーのものにする（§4.2）。**位相・順応の塊が、重みをそろえた背景で外れを生むか**（X5 の経路）を問う。言えるのは C-I まで
5. **経験の後の可塑性を止める変種（F、C0-4）**：経験の終わりの静かな Pulse から重みの更新を止め、O・M・W の 21 本体で 0028 と同じ判定をする（§4.3）。成り立てば「経験の後の重みの書き換えがなくても、この L3 は主の区間に現れた」（変種についての答え）。**実装は、可塑性の振幅を 0 にする設計図が読み込みで拒まれる**ので、本体ごとに「その時点の重みで可塑性のない接続」を持つ設計図の変種を道具の側で作る必要がある（Core は変えない）
6. **沈黙は、出生時の値から事前に二つに分けられる**【命題】（§3.6）。余裕 g_i ＝ c_i／(1 − λ) − θ_i が −0.0294 より小さい Unit は、**どの本体でも、どんな重みでも、主の区間で発火しない**（構造的な沈黙。判定は凍結に決まる）。出生時のばらつきのもとで Unit の約 7.8%。−0.0294 ≤ g_i ＜ 0 の Unit（約 15%）は、相手からの駆動しだいで発火しうり、**本体ごとに沈黙が違いうる**（条件付きの沈黙。0028 の 21013 のような同じ向きの外れを作りうる）。g_i は結果を見ずに出生時の状態から計算できるので、事前登録した層別（補助）にできる。条件付きの沈黙が作る外れは、J_OM（同じ個体で逆の向き）と「数の差を超える外れ」の事象（A の沈黙は |ΔN_A| を上界に足す）で抑えられる
7. **位相**：孤立した Unit の位相には戻す力がなく（理論のメモ 条件付き 4.5b）、5τ_a の遅れは位相に由来する差を必ず消すとは保証できない（レビュー §3.2 (b)）。一方、2 つの Unit の玩具では、固定した重みのもとで、長い区間の数に初めの位相の影響がほとんど残らなかった（§3.5）。3 つの Unit と可塑性のある C0 で位相が残るかは理論で決まらないので、**U の家族で実際に問う**
8. **それでも分からないこと**（§4.6）：背景に依存しない一意の寄与（レビューの A5）、塊の排他性（C2 の整理 命題 C）、自然な差の原因（C-III）、受け手以外の背景での効果、入れ替えた状態が自然に到達できるか、どの組の重み（A–B か B–C か）が効いたか、学習の必要性、3 要素の順序・時間差、「意味」
9. **進め方の案**（§7。承認ではない）：一つの事前登録（0029）に 4 つの家族（自然な本体で「数の差を超える外れ」の 4 判定 N^cnt、Wt、U、F）を置き、各家族の水準を 0.05 にして、実験全体の水準は主張しない。計算は 1 seed 約 70 秒、20 個体で約 12 分の見込み【予想】で、資源の大きな変更には当たらない

## 3. 式と玩具の計算から言えること

記号：区間 [S, E]（長さ L ＝ E − S ＋ 1）、Unit X の区間の中の発火の時刻の集合 𝒮_X、その数 N_X ＝ |𝒮_X|。N_{X→Y} ＝ #{t ∈ 𝒮_X : t ≤ E − 1, t ＋ 1 ∈ 𝒮_Y}、Δ_AB ＝ N_{A→B} − N_{B→A}、D ＝ Δ_AB − Δ_AC（0028 §3.1 と同じ）。

### 3.1 命題 1（主の区間の量は、静かな Pulse τ の状態の関数である）【命題（前提つき）】

前提 P-τ（レビュー §3.2 (b) の 2：12001 以後、次の Pulse への更新が正規化した状態 z だけで決まる）のもとで、τ ≥ 12000 の処理の終わりに、どの Unit も発火していない（したがって次の Pulse に届く駆動がない。担い手の整理 命題 2 の I4）とする。このとき、τ より後の本体の発火の列、したがって [S, E]（S ＞ τ）の N・Δ_AB・D は、τ の状態 (u, w, x)（u：3 Unit の activity・順応、w：6 本の重み、x：Unit ごとの痕跡）と、出生時に決まる Unit の力学の値だけの関数である。

（証明：担い手の整理 命題 1、0026 §3 の命題 A と同じ。決定論的で入力がないので、軌道は τ の状態で決まる。）

- **帰結**：自然な O と W の Δ_AB の違いは、τ の (u, w, x) の違いを通してしか生じない。どの塊が効いたかは、この命題からは言えない
- 可塑性を止めた変種では、x は力学に効かない（重みの更新にしか使わない）

### 3.2 命題 2（相対の時刻を一様にずらすと、Δ_AB の平均は発火の数に依らず 0）【命題】

区間の時刻を 0〜L − 1 の輪とみなし、B の発火の列を s だけ回した列を B_s（B_s(k) ＝ B(k − s mod L)）とする。輪の上の数 N°_{A→B}(s) ＝ #{j : A(j) ＝ 1, B_s(j ＋ 1 mod L) ＝ 1} について

```text
Σ_{s=0}^{L−1} N°_{A→B}(s) ＝ N_A · N_B ＝ Σ_{s=0}^{L−1} N°_{B→A}(s)
したがって  (1/L) Σ_s Δ°_AB(s) ＝ 0
```

（証明：A の発火 j と B の発火 k の組は、ちょうど一つの s で「k が j の 1 後」になり、ちょうど一つの s で「k が j の 1 前」になる。輪でない数え方は、輪の継ぎ目の組（L − 1 と 0）を数えないことだけが違うので、各 s で N と N° の差は 0 か 1。したがって輪でない Δ_AB の s についての平均は −1 以上 1 以下。）

- **意味**：発火の数がどう違っても、二つの発火の列の**相対の時刻に構造がなければ**（一様にずれていれば）、Δ_AB に系統的な向きは生じない。Δ_AB の外れには、相対の時刻の構造（A の 1 Pulse 後に B が来やすい、など）が要る
- **言えないこと**：C0 の Unit は決定論的な振動子で、相対の時刻は一様にずれているわけではない（周期・位相・引き込み）。この命題は、数の違いが「時刻の構造を通して」Δ_AB を変えることを否定しない。それを扱うのが命題 3・4・5

### 3.3 命題 3（Δ_AB は発火の足し引きについて 1 しか動かない。数だけの違いの上界）【命題】

**(i) 編集の上界**：同じ区間の二つの発火の列 X・Y（本体 X と Y）について

```text
|Δ_AB(X) − Δ_AB(Y)| ≤ |𝒮_A^X △ 𝒮_A^Y| ＋ |𝒮_B^X △ 𝒮_B^Y|
|D(X) − D(Y)|       ≤ 2|𝒮_A^X △ 𝒮_A^Y| ＋ |𝒮_B^X △ 𝒮_B^Y| ＋ |𝒮_C^X △ 𝒮_C^Y|
```

（△ は対称差。証明：B に発火 u を 1 つ足すと、N_{A→B} は（u − 1 に A があれば）高々 1 増え、N_{B→A} は（u ＋ 1 に A があれば）高々 1 増えるので、Δ_AB の変化は −1・0・1 のどれか。A に足す場合も同じ。除く場合も同じ。Y の列から X の列へ、対称差の要素を 1 つずつ足し引きすれば着く。D では、A の 1 回の足し引きが Δ_AB と Δ_AC を高々 1 ずつ動かし、B・C の足し引きはどちらか一方を高々 1 動かす。）

**(ii) 「数だけの違い」の二つの形と、その上界**：

- **(a) 足し引きだけ**：X の列が、Y の列に発火を足す（または除く）だけで得られる（共通の発火の時刻は動かない）。このとき対称差は数の差に等しいので

  ```text
  |Δ_AB(X) − Δ_AB(Y)| ≤ |N_A^X − N_A^Y| ＋ |N_B^X − N_B^Y|
  ```

- **(b) 条件付きの組の割合が同じ**：A の発火のうち 1 Pulse 後に B が来る割合 q_{B|A} と、その逆 q_{A|B} が Y と同じまま、数だけが違う（N_{A→B}^X ＝ N_A^X q_{B|A}、N_{B→A}^X ＝ N_B^X q_{A|B}）。q ≤ 1 なので

  ```text
  |Δ_AB(X) − Δ_AB(Y)| ≤ |N_A^X − N_A^Y| q_{B|A} ＋ |N_B^X − N_B^Y| q_{A|B} ≤ |ΔN_A| ＋ |ΔN_B|
  ```

（証明：(a) は (i) から。(b) は差を書き下して三角不等式。）

D についても同じ形で、(a) では (i) から、(b) では |D(X) − D(Y)| ≤ |ΔN_A|(q_{B|A} ＋ q_{C|A}) ＋ |ΔN_B| q_{A|B} ＋ |ΔN_C| q_{A|C} ≤ 2|ΔN_A| ＋ |ΔN_B| ＋ |ΔN_C| になる。

**(iii) 数の差を超える外れ**【候補の事象】：個体ごとに

```text
E_Ca^cnt ⇔ すべての i で  Δ_AB(O) − Δ_AB(W_i) ＞ |N_A(O) − N_A(W_i)| ＋ |N_B(O) − N_B(W_i)|
E_O^cnt  ⇔ すべての i で  D(O) − D(W_i) ＞ 2|ΔN_A| ＋ |ΔN_B| ＋ |ΔN_C|          （ΔN は O と W_i の差）
E_M^cnt  ⇔ すべての i で  D(W_i) − D(M) ＞ 2|ΔN_A| ＋ |ΔN_B| ＋ |ΔN_C|          （ΔN は M と W_i の差）
E_OM^cnt ⇔ E_O^cnt かつ E_M^cnt
```

- **個体ごとに言えること（算術の事実で、統計ではない）**：E_Ca^cnt が成り立った個体では、O の Δ_AB とどの W の Δ_AB の差も、(a)・(b) のどちらの形の「数だけの違い」でも作れない。O と W の列は、共通の発火の相対の時刻が違う
- **帰無のもとの確率**：右辺は 0 以上なので、E_Ca^cnt ⇒ 「Δ_AB(O) ＞ max Δ_AB(W)」（0028 の O_Delta_AB_above）。E_O^cnt・E_M^cnt・E_OM^cnt も同じく 0028 の事象の部分集合。したがって、**0028 と同じ交換可能性の帰無仮説のもとで、個体ごとの確率は 1／20 以下（E_OM^cnt は 1／420 以下）のまま**で、閾値（4・4・4・2）も変わらない。事象を厳しくした分、検出力は下がりうる
- **沈黙への効き方**：A が O だけで沈黙して Δ_AB(O) ＝ 0 になった個体では、右辺に |ΔN_A| ＝ N_A(W_i) が入るので、沈黙だけによる外れは E^cnt を満たしにくい（例：O と W_i の違いが「A の発火をすべて除いたこと」だけなら、命題 3 (i) から Δ の差は N_A(W_i) 以下で、E^cnt は成り立たない）
- **言えないこと**：E^cnt は「数だけの違い」を (a)・(b) の意味で除く。相対の時刻の違いがどこから来たか（重み・位相）は言わない。0028 の記録では E^cnt を**計算していない**（§8）

### 3.4 命題 4（孤立した Unit の発火の数は、初めの状態にほとんど依らない）【条件付き】

**計算**：入力のない 1 つの Unit を、実装と同じ順序（activity ← λ·activity ＋ c、順応を減らしてから、activity ≥ θ ＋ 順応なら発火して activity を 0 に戻し順応に α を足す）で進めた。c ∈ {0.072, 0.076, 0.080, 0.084, 0.088}・θ ∈ {0.45, 0.475, 0.5, 0.525, 0.55}（出生時のばらつきの範囲。25 点）の各点で、初めの activity を 0〜a* ＋ 0.14、初めの順応を 0〜0.3 から 60 通り選び、1500 Pulse（0028 の遅れ）進めた後の 12000 Pulse の発火の数を数えた。

| 結果 | 値 |
|---|---|
| g ＞ 0 の 19 点 | 初めの状態による発火の数の幅は、どの点でも **1** |
| g ＜ 0 の 6 点 | どの初めの状態でも 0（沈黙。理論のメモ 系 4.1a） |

**意味**（この玩具の格子の範囲で）：主の区間のある Unit の発火の数が、同じ個体の本体のあいだで 2 以上違うなら、その違いは**その Unit が受け取った駆動の違い**（相手の重み × 相手の発火の時刻）を通して生じた。0028 で O の B の発火の数が W より多かったこと（§1.2）は、B 自身の区間の始まりの状態だけでは説明できず、A・C からの駆動の違いを通して生じた【条件付き】。

- 理由の素描：孤立した Unit の発火の直後の順応は、自分の周期の固定点へ引き寄せられ（理論のメモ 条件付き 4.2）、5τ_a の後には初めの順応の違いはほぼ残らない。位相は戻らないが、位相は長い区間の数を ±1 しか変えない
- **言えないこと**：一般の証明ではない（格子と初めの状態の範囲の計算）。受け取る駆動の違いが、重みの違いから来たのか、相手の発火の時刻（位相）の違いから来たのかは、この命題からは分からない（それを分けるのが Wt と U の家族）

### 3.5 命題 5（結合だけで、B の発火の数の増加と Δ_AB の増加が一緒に起きる）【命題（構成）】

**構成**：2 つの Unit（A・B）を固定した重み w(A→B)、w(B→A) ＝ w_max − w(A→B)（組の和）で結び、可塑性なし、入力なしで、実装と同じ順序（Pulse t の発火の駆動は t ＋ 1 に届く）で進めた。初めの activity・順応を 30 通りに変え、1500 Pulse の後の 12000 Pulse を数えた。

| A と B（g） | w(A→B) | N_A | N_B | N_{A→B} | N_{B→A} | Δ_AB |
|---|---|---|---|---|---|---|
| A が速い（g_A ＝ ＋0.060、g_B ＝ ＋0.033） | 0.005 | 257〜258 | 160〜161 | 124〜126 | 25〜28 | ＋97〜＋101 |
| 同上 | **0.009** | 257〜258 | **171〜172** | **171〜172** | 0 | **＋171〜＋172** |
| A が速く、B の周期が長い（＋0.033、＋0.008） | 0.005 | 152〜153 | 65〜66 | 65〜66 | 0 | ＋65〜＋66 |
| 同上 | **0.009** | 152〜153 | **76〜77** | **76〜77** | 0 | **＋76〜＋77** |
| B が速い（＋0.033、＋0.060） | 0.005 | 160〜161 | 257〜258 | 25〜28 | 125〜126 | −101〜−97 |
| 同上 | **0.009** | 152〜153 | 259〜261 | 60〜62 | 30〜31 | **＋29〜＋32** |
| B が沈黙する（＋0.085、−0.018） | 0.005・0.009 | 350〜351 | 0 | 0 | 0 | 0 |

（範囲は 30 通りの初めの状態の最小〜最大。手順は §0 の注のとおり、実験の記録を使わない。）

**読み取れること**（この構成の範囲で）：
1. **結合だけで、受け手の発火の数の増加と Δ_AB の増加が一緒に起きる**。A が B を引き込み、B が A の 1 Pulse 後に発火する回数が増えるので、B の発火の数も増える。したがって「外れと B の発火の数の違いが同時に起きた」ことは、結合の説明と両立し、それ自体は X7（数だけ）の証拠ではない
2. B が速い組では、w(A→B) を大きくすると Δ_AB の符号が負から正へ変わり、**A の発火の数が減った**（w(B→A) が小さくなり、B が A を前倒ししにくくなる）。発火の数の変化の向きは、組の周期の関係で変わる
3. **固定した重みのもとでは、長い区間の数は初めの状態（位相）にほとんど依らなかった**（幅 0〜4）。2 つの Unit では、引き込みのもとで、初めの位相の影響はほとんど残らなかった
4. 沈黙した受け手は、w(A→B) ＝ 0.009 でも発火しなかった（§3.6）

**言えないこと**：C0 は 3 つの Unit で、主の区間でも可塑性が働く。3 つの Unit・可塑性のもとで、引き込みが位相を消すか、複数の落ち着き先（どの初めの状態からどこへ行くかが分かれる）があるかは、この構成からは分からない。0028 の V1 では、多くの個体で 21 本体の値が完全に同じだった（凍結 10〜12）が、W の Δ_AB が 74〜150 にわたる個体（V1 の 21014）もあった（0028 §15.3 の表）。3 つの Unit では初めの状態の影響が残る場合がある、という記述にとどめる。

### 3.6 命題 6（構造的な沈黙と、条件付きの沈黙）【命題】

**(i) 発火の間隔の下限**：入力（Receptor の出来事）のない区間で、どの Unit も、発火の後 7 Pulse 以上たたないと次に発火しない。

（証明：発火の直後は activity ＝ 0。1 Pulse に届く駆動は高々 2w_max ＝ 0.02（2 本の接続）、内在の駆動は c ≤ 0.088 なので、n Pulse 後の activity は 0.108 (1 − λ^n)／(1 − λ) ＝ 0.72 (1 − λ^n) 以下。発火には θ ≥ 0.45 以上が要るので λ^n ≤ 0.375、n ≥ ln 0.375／ln 0.85 ≈ 6.04。）

**(ii) 構造的な沈黙**：Unit i の余裕を g_i ＝ c_i／(1 − λ) − θ_i とする。

```text
g_i ＜ − 2 w_max ／ (1 − λ^7) ＝ −0.0294
```

なら、**どの本体でも、どんな重みでも**、主の区間（経験の終わりから 1500 Pulse 以上後）で i は発火しない（下の初めの超過の項が λ^1500 ≈ 10^−106 倍以下になるので、等号の近くを除けば、事実上この条件で決まる）。

（証明：経験の終わり t_e ＝ 12000 の後は入力がない。activity の a*_i からの超過 e(t) ＝ a_i(t) − a*_i は、発火しない Pulse で e(t) ＝ λ e(t − 1) ＋（届いた駆動）、発火した Pulse で e(t) ＝ −a*_i ＜ 0 なので、e(t) ≤ λ^(t − t_e) max(e(t_e), 0) ＋（t_e 以後に届いた駆動の、λ で減衰させた和）。相手 j からの駆動は、(i) により 7 Pulse 以上の間隔でしか来ず、大きさは w_max 以下なので、その減衰させた和は w_max (1 ＋ λ^7 ＋ λ^14 ＋ …) ＝ w_max／(1 − λ^7) 以下。2 つの相手で 0.0294 以下。発火には activity ≥ θ_i ＋ 順応 ≥ θ_i、つまり e(t) ≥ −g_i ＞ 0.0294 が要る。主の区間では λ^(t − t_e) ≤ λ^1500 で、e(t_e) は有界なので、初めの超過の項は事実上 0 で、発火しない。）
- **帰結**：A が構造的に沈黙する個体では、21 本体すべてで Δ_AB ＝ Δ_AC ＝ D ＝ 0 になり、4 つの判定がすべて凍結する。B が構造的に沈黙する個体では、21 本体すべてで Δ_AB ＝ 0 になり J_Ca が凍結する（D ＝ −Δ_AC になる）。C が構造的に沈黙する個体では Δ_AC ＝ 0 で、D ＝ Δ_AB になる（J_O・J_M・J_OM が Δ_AB の判定と同じ値の比較になる）。**この分は、結果を見る前に出生時の状態から決まる**
- **出生時のばらつきのもとでの割合**：実装は θ と c に独立に一様な ±10% を掛ける（`bootstrap.py` の `vary`）。この分布のもとで、g_i ＜ −0.0294 は Unit の約 **7.8%**、−0.0294 ≤ g_i ＜ 0 は約 **15.2%**、g_i ＜ 0 は約 23%（模型の分布からの計算。実験の記録ではない）

**(iii) 条件付きの沈黙**：−0.0294 ≤ g_i ＜ 0 の Unit は、相手からの駆動が十分に重なれば発火しうり、足りなければ発火しない（理論のメモ 系 4.1a、担い手の整理 命題 11）。駆動は重みと相手の発火の時刻で決まるので、**同じ個体でも本体ごとに沈黙が違いうる**。0028 の 21013（A が O と M だけで沈黙）は、この形でありうる【予想】（21013 の g は計算していない）。

- **帰結**：条件付きの沈黙は、O・M の規則性や重みの違いを通して、O と M で**同じ向き**に起きうる。21013 では、それが M の「下」（J_M）を作り、O は予測と逆の「下」になった（0028 §15.5 の 5）。J_OM は同じ個体で逆の向きを求めるので、この形では成り立たない。E^cnt も（§3.3 (iii)）成り立ちにくい

### 3.7 位相について言えること・言えないこと

| | 内容 | 出どころ |
|---|---|---|
| 言えること | 孤立した Unit の位相には戻す力がなく、ずれは減らずに残る | 理論のメモ 条件付き 4.5b |
| 言えること | 5τ_a の遅れは、値のそのままの持ち越しを 1% 未満にするが、位相に由来する差を必ず消すとは保証できない | レビュー §3.2 (b) |
| 言えること | 2 つの Unit を固定した重みで結んだ構成では、長い区間の数は初めの位相にほとんど依らなかった | 命題 5 の 3 |
| 分からないこと | 3 つの Unit と可塑性のある C0 で、主の区間の Δ_AB が区間の始まりの位相に依るか（複数の落ち着き先があるか） | — |

したがって、位相の寄与は理論からは決まらず、**実験で問う必要がある**（U の家族）。ただし U の家族も C-I までで、位相が「担い手だった」とは言えない。

## 4. 介入・変種・判定ごとに、分かること・分からないこと

すべての家族で、主の区間は 0028 と同じ 13501〜25500、量は Δ_AB と D、判定の形は 0028 の 4 つ（一方向、厳密な不等号、凍結は「外にない」、invalid が 1 つでもあれば判定しない）を基本にする【候補】。

### 4.1 重みの塊の家族 Wt（C0-1′：区間の始まりの入れ替え、重み）

**作り方【候補】**
- 自然な本体：O・M・W1〜W20（22。W20 は受け手、W1〜W19 は参照のドナー）を 0028 と同じ手順で走らせる
- **入れ替える時刻 τ**：0026 §2.2 と同じ規則を区間の始まりの直前に当てる。τ ＝ max{t ∈ [13441, 13500]：Pulse t に、自然な 22 本体のどれでも、どの Unit も発火していない}。τ がない個体は、Wt と U のすべての判定で「外にない」に数える（除外しない）
- **入れ替えた本体** Y^Wt(d)：W20 の τ の終わりの状態を複製し、6 本の重みだけをドナー d（O・M・W1〜W19 の 21）の τ の値に替え、τ ＋ 1 から 25500 まで**可塑性ありで**進める。入れ替えは Core の公開の `import_state` だけで行う（0026 §2.4）
- 判定：0028 の J_Ca・J_O・J_M・J_OM と同じ形を、Y^Wt(O)・Y^Wt(M) と Y^Wt(W1〜W19) のあいだで置く（J_Ca^Wt 他）

**分かること**
- 成り立てば：**W20 の Unit の状態（位相・順応）と痕跡を背景に固定したとき、O の重みの塊は、W の重みの塊と比べて、予測した向きの典型的でない Δ_AB（D）を生んだ**（C-I とその介入の参照との比較）
- **位相の説明（X5）を、この家族の比較からは除ける**：21 の入れ替えた本体は τ の Unit の状態がすべて同じなので、その違いは重みの違いからしか生じない（命題 1）。X5 で言う「τ の位相の違いが O の外れを生んだ」は、この家族の外れの説明にならない
- **J_OM^Wt が成り立てば**：位相をそろえた同じ背景で、**重みの塊だけを替えたとき、O の重みと M の重みが逆の向きの外れを生んだ**。経験の内容（A の直後の要素）に応じた逆向きの効果が、重みの塊を通して起こりうることの、C-I の水準での証拠になる
- 数の違いは、この家族ではドナーの重みから生じる（命題 4・5）ので、X7 は「重みが生んだ数の違い」としてこの家族の結果の一部になる。外れと発火の数の違いを分けて主張はしない

**分からないこと**
- **自然な O の外れの原因が重みだった（C-III）**、重みが単独の担い手だった（排他性：C2 の整理 命題 C）。U の家族も成り立ちうる（0026 では両方の塊が成り立った）
- **ほかの背景**（W20 以外の受け手）での効果（0026 §5.3、C2 の整理 C2-a）
- **どの組の重み**（A–B、B–C、A–C）が効いたか。理想化した解析では A–B が主要な項（絞り込み 命題 A）だが、塊の中を分けていない
- 入れ替えた状態 (u_W20, w_O) が自然な経験から到達できるか（担い手の整理 命題 2）
- 学習が必要だったか（重みは学習で作られたが、Wt は「その重みを持つと何が起きるか」を問うだけ）

### 4.2 Unit の状態の塊の家族 U（C0-1′：区間の始まりの入れ替え、Unit の状態）

**作り方【候補】**：Wt と同じ τ・受け手・ドナーで、3 Unit の activity・順応・不応期の残りと、Unit ごとの痕跡（0026 §2.3 と同じ置き場所）だけをドナーのものに替え、重みは W20 のまま。判定も同じ形（J_Ca^U 他）。

- **向きの根拠**：Unit の状態の効果の向きは、理論から導けていない。「位相が O の関係（A の 1 Pulse 後に B）を運ぶなら、O と同じ向きに外れる」を予測として置く案と、向きを問わない判定にする案がある【未決】。向きを問わない場合は、個体ごとの帰無の確率が 2／20 になり、閾値が変わる

**分かること**
- 成り立てば：**W20 の重みを背景に固定したとき、O の Unit の状態の塊（位相・順応・痕跡）は、W の Unit の状態と比べて典型的でない Δ_AB（D）を生んだ**（C-I）。X5 の経路（位相の持ち越し）が、この背景では外れを運びうる
- J_OM^U が成り立てば：位相・順応だけで、内容に応じた逆向きの外れが起こりうる

**分からないこと**
- Wt と同じ（C-III、排他性、ほかの背景、到達できるか）
- **U の不成立は、位相が効かないことの証拠ではない**（棄却できなかったこと：C2 の整理 命題 C (i)）
- **Wt と U の結果を組み合わせて、どちらの塊が「主な」担い手かを言うこと**（寄与の割合は定まらない：担い手の整理 命題 3・5、レビュー A5）

### 4.3 経験の後の可塑性を止める変種 F（C0-4）

**作り方【候補】**
- 停止の時刻 T_0 ＝ max{t ∈ [11972, 12000]：Pulse t に、自然な本体のどれでも、どの Unit も発火していない}（0026 の T と同じ規則）
- 各本体（O・M・W1〜W19 の 21）について、T_0 の状態から、**その本体の T_0 の重みで固定した、可塑性のない接続**で 25500 まで進める（F 本体）
- **実装の制約**：可塑性の振幅（`amplitude_ratio`）を 0 にする設計図は、読み込みで拒まれる（`yaml_config_source.py`：正の値が必要）。Core を変えずに行うには、**本体ごとに、C0 の設計図から s のあいだの 6 本の `plastic: true` を除き、重みをその本体の T_0 の値にした設計図の変種**を道具の側で作り、同じ出生時の状態から組み立てて、Unit の状態を公開の `import_state` で写し、時刻を T_0 からの経過で数える（前提 P-τ）【候補】。操作の確認の候補：F 本体の記録したすべての駆動の重みが T_0 の重みに一致すること、T_0 の後の最初の発火まで F 本体と自然な本体の状態が一致すること
- 判定：0028 と同じ 4 つ（J_Ca^F 他）を、F 本体の O・M と W のあいだで置く

**分かること**
- 成り立てば：**経験の終わりから重みの更新を止めた変種でも、この L3 は主の区間に現れた**。経験の後の自発の発火による重みの書き換え（理論のメモ 命題 4.5c の正のフィードバックなど）が、この L3 の現れに必要ではなかった（変種についての答え）
- 比較は F 本体どうし（O・M・W すべてに同じ操作）なので、自己一致の効果（C2 の整理 命題 D）は入らない

**分からないこと**
- 自然な C0 で、経験の後の書き換えが役に立っていなかった（変種は別の力学：担い手の整理 命題 10 と同じ形）
- 重みが担い手だった（F は Unit の状態も自然なまま残す）
- **F の不成立は、書き換えが必要だった証拠ではない**（棄却できなかったこと）
- 主の区間の中だけ止める変種（τ から止める）との違い（行わない場合）

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

実験 0028 で、「A の直後に B が来る」経験をした脳は、入力のない時間にも「A の直後に B が動く」並びが多くなることが分かりました。次に知りたいのは、**その違いを、脳の中の何が生んでいるのか**です。この文書では、それを確かめる実験で、どの操作をすれば何が分かり、何がまだ分からないかを、実験の前に整理しました。

### 気をつけるべき三つの紛らわしさ

- **発火の回数の違い**：0028 では、外れた個体で B の動く回数も多くなっていました。「回数が多いから並びも多く見えただけでは？」という疑いです。計算で確かめると、(1) 回数だけが違って、動くタイミングの関係が無関係なら、この量は平均すると 0 になる、(2) 回数の違いだけで作れる差には上限がある、ことが分かりました。そこで、「回数の違いでは作れない大きさの差」で判定する方法を提案しました。また、玩具の計算では、A から B へのつながりが強くなるだけで、B の回数と並びの両方が一緒に増えました。回数の増加は、つながりの結果としても自然に起きるということです
- **部品の沈黙**：部品によっては、生まれつきの性質で入力がないと一切動かないものがあります。生まれたときの値だけから「どんな場合でも動かない部品」を事前に見分けられることを示しました（全体の約 8%）。また、「相手しだいで動いたり動かなかったりする部品」（約 15%）が、紛らわしい外れを作りうることも整理しました
- **リズムのずれ（位相）**：部品はそれぞれ自分のリズムで動いていて、経験の最後のリズムのずれが残っている可能性があります。これは式だけでは決まらないので、実験で確かめる必要があります

### 提案する実験

- **つながりの強さだけを入れ替える**：全員のリズムの状態を同じにそろえたうえで、つながりの強さだけを「A の次に B を経験した脳」のものにしたときに、違いが現れるか。リズムのずれでは説明できない形で確かめられます
- **リズムの状態だけを入れ替える**：反対に、つながりをそろえて、リズムの状態だけを入れ替えたときに違いが現れるか
- **経験の後の学習を止める**：経験が終わった後は、つながりの強さが変わらないようにしても、違いが現れるか
- **回数の違いでは作れない差で判定する**：新しい個体で、0028 の結果を、回数の違いを超える差として確かめる

どれも、これまでと同じく結果を見る前に判定の決まりを固定し、新しい個体で一度だけ行います。計算は 20 個体で十数分の見込みです。

### それでも分からないこと

この実験がうまくいっても、「違いのうち何割がつながりで、何割がリズムか」や、「つながりだけが原因だった」とは言えません。言えるのは、「この条件でこれを替えると、違いが現れた」という形までです。また、これは「中身が脳の中にあること」の仕組みを調べる段階で、「記憶」や「意味」が生まれたことの証明ではありません。
