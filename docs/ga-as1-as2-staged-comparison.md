### 0.2 結論の先取り

1. **三つの段階**（§1）
   - **S1 閉ループの成立**：自分の内部の活動から意図が生まれ、外界に作用し、未来の感覚が変わる
   - **S2 帰還による行動の変化**：結果の感覚が脳に戻り、その後の行動の時刻・発生に因果の影響を与える
   - **S3 行動の帰結の学習**：経験による可塑的な変化が、その後の**行動の選択**に使われる
   - 監査 010 の 4 つの目標を対応させた：①入力から重みへの順方向の時刻の対応（S1 に付く書き込み。帰還を要しない）、②帰還が後の行動に効くこと（S2）、③その帰還が可塑性を介したこと（S2 の内訳）、④結果に応じて複数の行動の選択が変わること（S3）
2. **S2 の②は、決定論の C0 では個々の出来事ごとに厳密な反実仮想で問える**（命題 G-6）。全 Unit の状態・重み・痕跡・届く途中の駆動に加えて、世界の状態・まだ届いていない出来事・予約の列まで同じにした 2 つの複製で、結果の刺激 e を届けるか届けないかだけを変える。次の意図までの時刻の差 d_e は、その背景での条件付きの因果の効果として確定する。打ち切りは値ではなく打ち切りの情報として記録する。頻度の主張には事前に決めた統計が要る。d_e ＝ 0 は e の効果がないことを意味しない
3. **S2 の効果を、三つの推定対象に分ける**（§3.3。A は②、B・C は③「可塑性を介したか」）
   - **A 今の帰還の効果**：e が、その時点の重み（過去の経験で形づくられたものを含む）を通って、次の意図に与える効果。G-6 の d_e。経路がどう形づくられたかは問わない
   - **B e 以後の更新の局所の増分**：CF-2（e 以後の可塑性の更新を両方の複製で止める）との差。**e より前に形成された重みは残るので、B が 0 でも過去の学習が効いていないとは言えない**
   - **C 経験で形づくられた帰還の経路の効果**：経験の区間の可塑性が帰還の経路を変え、それが後の行動を変えた効果。経験の区間から可塑性を ON・OFF にする、帰還の側の可塑性だけを経験の区間で止める、同じ外生の刺激の履歴を課す、状態・重みを条件付きで移植する、などの候補（PC-1〜PC-4）。どれも経験の列の分岐・非加法性（U5）・重みの再増加（G-7）の交絡を持つ
   - 介入は、**FB-1 ＝ 帰還の伝達の遮断、FB-2 ＝ 帰還の側の更新の停止（伝達は残るので遮断ではない）、CF-2 ＝ e 以後の更新の停止**として分ける。重みを 0 にしても、今の規則では痕跡と発火があれば重みは増える（命題 G-7）ので、「重み 0」は遮断の定義にならない（監査 010）
   - 直接の組では、組の和の保存（F1）により、帰還の側の重み w(結果を受ける Unit → 行動の源) は w_max − w(行動の源 → 結果を受ける Unit) に等しい。①の順方向の書き込みと帰還の側の学習は、直接の組では一つの数に重なり、帰還の側だけを止める介入は F1 を破る（命題 G-8）
4. **AS1 で問えるのは S1 と S2（①〜③）まで**で、S3（④）は行動が 1 つなので原則として問えない。**AS2 は S3 を問いの形にできる**が、3 Unit では行動の源の Unit が結果の刺激も受ける（感覚と運動の重なり：監査 008）。それを避ける変種（AS2b：結果を手がかりの Receptor に返す片側の形、AS3：専用の行動の Unit）も並べた（§4）
5. **共通の設計の制約**（§2）
   - SD-2 の標準の比較では、ドナーの列を**物理の Receptor の ID のまま再生しない**。役で整列して変換するか、的とドナーで役 → 物理の ID の割り当てを共有する（監査 011）。整列しても H^rank の交換可能性は戻らない
   - 意図の出力は**専用の出力路**にして、`main` を共用しない（脳の中へ INTENT の中身が漏れるため：監査 012）。G-1 の一致の範囲（認知の軌道・脳への非干渉・比べる記録の欄）を分けて契約にする
   - 既存の汎用の Unit と出力の部品だけで作れるのは I1（1 つの Unit の発火）まで。I2（競合）・I3（閾値下の状態）・I4（積分）には、拡張の部品と新しい契約が要る（監査 012）
   - **実験者が固定した Unit と行動の対応を、AI 自身が意味を学んで獲得した行動とは解釈しない**。S3 の「学習」は、固定した対応のもとで選択の分布が経験で変わることを指す
6. **t-k さんに示す二つの進め方**（§5）
   - **P（段階を踏む）**：AS1 で S1・S2 を確かめてから、S3 の構成（AS2・AS2b・AS3）に進む。選ぶ基準は AS1 の結果の前に書き、S2 の読み出しの結果で S3 に進むかどうかを決めない
   - **Q（最初から選択を扱う）**：最初から選択のある構成で S1〜S3 を設計する
   - 私の推奨は P：新しい自由度が最も少ない AS1 で、意図の出口・世界・隔離の契約・反実仮想と介入の道具をまず確かめておけば、S3 の構成で失敗したときに原因を狭めやすいため。**G-6 の局所の時刻差を S3 の論理的な関門にはしない**（後の試しの区間の選択にだけ学習の効果が現れうる）。また Anima-ll の目標には S3 が要るので、P は S3 の設計を後に回すだけで、終点ではない
   - **今回も構成の判断は求めない**

## 1. 三つの段階の定義

### 1.1 段階と、監査 010 の目標

| 段階 | 何を問うか | 監査 010 の目標 | 帰還を要するか | 選択を要するか |
|---|---|---|---|---|
| **S1 閉ループの成立** | 自分の内部の活動から意図が生まれ（AI1）、Runtime と Effector が選ばずに渡し（AI2〜AI4）、世界が変わり、結果が Receptor から戻る（AI6） | ①（S1 に付く書き込み：自分の発火の後に結果が来るので、行動の源 → 結果を受ける Unit の向きの重みに時刻の対応が書かれうる。帰還は要らない） | いいえ | いいえ |
| **S2 帰還による行動の変化** | 結果の感覚が脳に戻ったことが、その後の行動の時刻・発生を変える | ②（帰還が後の行動に効く ＝ 推定対象 A）、③（その効果が可塑性を介した ＝ 推定対象 B・C。§3.3） | はい | いいえ |
| **S3 行動の帰結の学習** | 経験による可塑的な変化が、その後の行動の選択（どの行動か）に使われる | ④（結果に応じて複数の行動の選択が変わる） | はい | **はい** |

- 順序：S2・S3 は S1 を前提にする（閉ループがなければ、結果は自分の行動に依らない）。S3 は、**広い意味の S2**（結果が、いずれかの時点の行動に影響すること）を含意する。しかし、**S2 の特定の読み出し（G-6 の、1 件の結果 → 直後の最初の意図の時刻差）を、S3 の必要条件にはしない**。d_e ＝ 0 の出来事ばかりでも、可塑的な変化が積み重なり、後の試しの区間の選択にだけ効果が現れることはありうる（直後の時刻には現れず、手がかりの後の競合にだけ現れる、など）。これは「起こる」という予想ではなく、論理の上で排除できないという意味である
- ①は S2 ではない。**①が観測されても、帰還が行動を変えたとは言えない**（監査 010：自分の列のもとで、行動の源 → 結果を受ける Unit の重みが変わるのは、逆向きの帰還を要しない）

### 1.2 各段階の「確かめ方」の種類

| 段階 | 確かめ方 | 統計が要るか |
|---|---|---|
| S1 | 契約テストと記録（意図が契約どおりに生まれ、結果が規則どおりに来たか）。**規則が決める量なので、知見ではなく操作の確認**（N-3・N-4 の命題 G-4） | 要らない |
| S1 の① | 自己の列と他者の列の非対称（SD-2、探索の候補）、可塑性を止めた対照（LC1） | 要る（H^rank は学習の不在と同じではない：N-3・N-4 §3.3） |
| S2 の②（推定対象 A） | 出来事ごとの反実仮想（命題 G-6、§3.2 の CF-1）。経路の帰属には FB-1 を複製の両方に置く | 存在の主張には要らない。頻度・大きさの主張には、事前に決めた統計が要る |
| S2 の③ B | CF-2（e 以後の更新を両方の複製で止める）との差 | 同上 |
| S2 の③ C | 経験の区間からの介入（§3.3 の PC-1〜PC-4）。後の行動（試しの区間の意図の時刻・間隔）を T にする | 要る（経験の列が本体ごとに分岐するので、出来事ごとの厳密な反実仮想にはならない） |

## 2. どの構成にも共通の設計の制約

### 2.1 役の整列（監査 011）

- AS1 で、行動の源・結果を受ける Unit・残りの役を個体ごとに独立に一様に割り当てると、ドナーの「結果の Receptor」が的の行動の源に重なる確率は 1／3、残りの Unit に重なる確率も 1／3【既存の命題（台帳 011 の算術）】。**物理の Receptor の ID のまま再生すると**、的の行動の源へ刺激が直接入る（K1 の違反）か、目的と無関係な宛先の違いが混じる
- したがって、**SD-2 の標準の比較では、物理の ID のままの再生を除く**。次のどちらかにする【候補】
  - (A) **役で整列した変換**：ドナーの「結果の役」の出来事を、的の「結果の役」の Receptor に移して再生する
  - (B) **割り当ての共有**：的とそのドナーの集まりで、役 → 物理の ID の割り当てを事前に共有する（的の集まりごとに 1 つ。集まりどうしは重ならない）
- どちらでも、物理の ID と役の辞書、受け取った刺激の数、K1 の違反（行動の源への直接の刺激）の数を、契約テストで監査する
- **役を整列しても、H^rank の交換可能性は回復しない**（自己の列は的の状態と内生的に相関したまま：N-3・N-4 §3.3）。整列は標準の参照の妥当性の条件で、学習がないもとでの帰無の正当化ではない
- 物理の ID のままの再生は、受容野の配置への感度を調べる**別の介入**としてなら定義できる（標準の参照にはしない）

### 2.2 意図の出力の隔離と、G-1 の一致の範囲（監査 012）

- 今のコードでは、出力路（port）ごとに中身の届け先が引かれ（`ProjectionRouter.route`）、Delta の出力路の既定は `main` である（`DEFAULT_PORT`）。既存の Unit どうしの投射と、足した Effector への投射が同じ `main` を共用すると、INTENT の種類の中身が脳の中の Unit にも届き、relay がそれを CONTENT として転送しうる【既存の命題（台帳 012 の ChatGPT の回答）】
- **契約の候補**
  - 意図は**専用の出力路**から、Effector だけへ届ける。`main` を共用しない
  - `DeltaKind.INTENT` はただの種類の文字列で、それだけでは隔離にならない。隔離は配線と契約で保証する
- **G-1 の一致の範囲を三つに分ける**（契約テストで、それぞれ何を比べるかを明示する）
  - (a) 認知の軌道：全 Unit の状態・可塑的な重み・痕跡・発火（N-3・N-4 の命題 G-1 が主張するのはこれ）
  - (b) 脳への非干渉：脳の中の中身・駆動の流入がないこと。ID の採番・ログの違いは別に記録する
  - (c) 記録の比較の欄：旧 C0 の記録と比べる欄を事前に決める（例：Effector への配線が接続の一覧や Snapshot に増えるか、可塑的な重みの書き出しに入るかを実装の後に確かめ、比べる欄から除くかを契約に書く）【未決】
- 専用の出力路の配線を足しただけで (a) が破れるとは言えない（台帳 012）。逆に、(b)(c) の一致は (a) とは別に確かめる

### 2.3 意図の作り方ごとの、実装の要件（監査 012）

| 形 | 既存の汎用の Unit と出力の部品で | 要るもの |
|---|---|---|
| I1 1 つの Unit の発火 | 作れる（出力の部品は発火のときに呼ばれる） | 専用の出力路（§2.2） |
| I2 窓の中の競合 | 作れない（出力の部品は自分の Unit の発火しか見ない） | 複数の Unit を見る集約の部品、または拡張の Unit と、その契約。Runtime・Effector に選ばせない（AI2〜AI4） |
| I3 閾値下の状態 | 作れない（出力の部品は自分の activity を直接読めない） | 状態を読む拡張の Unit と、その契約 |
| I4 時間の積分 | 出力の部品に新しい状態（発火の数）を持たせれば作れうる | その状態の保存・復元の契約（Replay を含む） |

- **AS1 は I1 だけで作れる**。AS2 は I2 が要るので、拡張の部品と新しい契約が要る（実装の自由度が増える）

### 2.4 固定した対応を、獲得した行動と解釈しない

- どの構成でも、「どの Unit の発火が行動 X か」「行動 X がどの刺激を返すか」は実験者が固定する（乱数で割り当てても固定の配線：N-3・N-4 の K2）
- したがって、**S3 で言う「学習」は、固定した対応のもとで、行動の選択の分布が経験に依って変わること**であり、「AI が行動 X の意味を学んだ」「行動の種類を自分で獲得した」ではない
- 行動の ID は X・Y で、意味の名前を付けない（AI7）

## 3. AS1（自発の 1 つの行動）を三段で見る

### 3.1 S1：閉ループの成立

- **作り**：個体ごとに乱数で選んだ行動の源の Unit の発火（I1、専用の出力路）→ 意図 X → 世界が t ＋ L − 1 に結果の Receptor へ刺激（L ＝ 2 の候補）。行動の源の入口には刺激を来させない（K1）
- **確かめ方**：契約テストと記録。意図の数・結果の数・その時刻の関係は規則が決めるので、S1 の成立は**操作の確認**である（命題 G-4）
- **①（順方向の書き込み）**：自分の発火の 2 Pulse 後に結果を受ける Unit が発火するので、行動の源 → 結果を受ける Unit の重みに、時刻の対応が書かれうる。これは帰還を要しない（監査 010）。SD-2（役で整列：§2.1）・LC1 で、自己の列と他者の列の非対称を探索できるが、**①の観測は S2 の証拠ではない**

### 3.2 S2 の②：帰還が次の行動を変えるか（出来事ごとの反実仮想）

#### 命題 G-6（決定論の C0 では、1 回の結果の刺激の効果が、出来事ごとに厳密に定まる）【命題】

**前提**：AS1 の閉ループの系が、Pulse t の処理の終わりに状態 Σ にある。Σ は**脳の側**（全 Unit の状態・可塑的な重み・痕跡・届く途中の駆動と Delta）と、**世界の側**（世界の状態、まだ届いていない結果の刺激とその予約の列、行動に依らない刺激の予定、世界の規則が持つ内部の状態）を、すべて含む。世界の規則では t ＋ 1 に結果の刺激 e が来る。Σ を**脳の側も世界の側も**複製した 2 つの系のうち、系 F は e を受け、系 N は e だけを受けない（予約の列から e だけを除く。世界のそれ以外の状態と規則は同じ）。

**主張**：F と N の t ＋ 1 以後の軌道は、それぞれ一意に定まる。t ＋ 1 以後の最初の意図の時刻を τ_F・τ_N とする。両方が事前に決めた長さ H の中にあるとき、その差 d_e ＝ τ_N − τ_F は、背景 Σ のもとでの、結果の刺激 e の因果の効果として確定する（標本の揺らぎを含まない）。

**証明**：Unit の更新は決定論で、乱数は出生時だけ（再評価 §1.2）。世界の規則も、状態と意図の列が同じなら同じ刺激を返す（N-3・N-4 の命題 G-2 の前提）。F と N は t の終わりで、脳の側も世界の側も同じ状態にある。t ＋ 1 から、どちらかに最初の意図が出るまでのあいだ、二つの系の違いは予約の列の e の有無だけである（それより前の意図の結果で、まだ届いていない刺激と、行動に依らない刺激は、同じ予約の列と予定から両方に同じに来る）。各 Pulse の次の状態は、その Pulse の状態と入力で一意に決まる。∎

**帰結と限界**
- d_e ≠ 0 の出来事があれば、**その背景で、結果の刺激の帰還が次の行動の時刻を変えた**（②）ことが、算術の事実として言える。統計は要らない
- d_e は背景 Σ に依存した条件付きの効果（C-I の形）で、背景をまたぐ一意の寄与ではない（識別のメモ U5）。d_e は、Σ の時点の重み（過去の経験で形づくられたものを含む）を通った効果で、その重みがどう形づくられたかは問わない（§3.3 の推定対象 A）
- 比べる量は「t ＋ 1 以後の最初の意図まで」に限る。それより後は、二つの系の意図の列が分かれ、世界が返す結果の刺激も分かれる（経験そのものが分岐する）
- **d_e ＝ 0 は、e の効果がないことを意味しない**。e は、最初の意図の時刻を変えずに、重み・痕跡・順応・位相を変えうる。その違いは、さらに後の行動に現れうる。最初の意図の時刻 τ_F（＝ τ_N）での二つの系の状態の差を、補助の記録として残せる【候補】
- **打ち切り**：H の中で片方だけに意図が出たときは、d_e の値は定まらず、片側の不等式（例：τ_F ≤ H で N に意図がなければ d_e ＞ H − τ_F）だけが分かる。両方に出なければ、d_e について何も分からない。どちらも**時刻差の値として扱わず、打ち切りの情報として記録する**（値を埋めない）。頻度・大きさの統計では、打ち切りの扱いを事前に決める【未決】。行動の源が沈黙する個体（N-3・N-4 §3.6）では、多くが打ち切りになりうる
- **頻度・大きさの主張**（多くの出来事・多くの個体で d_e が予測の向きに偏る、など）には、事前に決めた統計と帰無が要る【未決】。向きの予測（結果の刺激が w(結果を受ける Unit → 行動の源) の駆動で次の発火を早めるので d_e ＞ 0 になりやすい）は【予想】で、順応・位相で逆にもなりうる。その重みは①の書き込みで弱まりうる（命題 G-8）
- 計算の量：出来事ごとに 1 本の複製（次の意図まで）。結果の刺激の数に比例する【予想】

**CF-1（候補）**：ループの区間の結果の刺激のそれぞれ（または事前に決めた標本）について、G-6 の複製を作り、d_e を記録する。

### 3.3 S2 の③：その帰還は可塑性を介したか（三つの推定対象）

この節の記号：行動の源の Unit を「源」、結果を受ける Unit を「受」、残りの Unit を「他」と書く（推定対象の A・B・C と区別するため、Unit には文字を使わない）。

#### 3.3.1 推定対象を分ける

d_e には、(i) 受の発火による源への直接の駆動（1 回あたり高々 w_max）、(ii) 順応・位相の変化、(iii) 可塑性による重みの変化、が混ざる。分け方は一意でない（U5）。そのうえで、S2 の効果には、少なくとも次の三つの違う推定対象がある（A は②。B・C は、③の「可塑性を介した」の二つの違う意味）。

| 推定対象 | 中身 | 比べ方の候補 | 識別しないもの |
|---|---|---|---|
| **A 今の帰還の効果** | e が、Σ の時点の重み・状態を通って、次の意図に与える条件付きの効果（②） | G-6 の d_e（CF-1）。直接の接続 受 → 源 を通った分の目安には、FB-1 を F と N の両方に置く | 帰還の経路が、経験の可塑性で形づくられたものか、生まれつきのものか |
| **B e 以後の更新の局所の増分** | e の Pulse から次の意図までの可塑性の更新が、d_e に足した分 | d_e と d_e^{CF-2} の差（両方が打ち切りでないとき） | e より前に形成された重みの効果。**B ＝ 0 でも、過去の学習が行動に効いていないとは言えない** |
| **C 経験で形づくられた帰還の経路の効果** | 経験の区間の可塑性が帰還の経路の重みを変え、それが後の行動を変えた効果 | §3.3.4 の PC-1〜PC-4。T は後の行動（試しの区間の意図の時刻・間隔） | 出来事ごとの厳密な効果（経験の列が系ごとに分岐する）。背景をまたぐ一意の寄与（U5） |

- 例（ChatGPT のレビューの例）：経験の区間で 受 → 源 の重みが強まり、その接続を通って e が源の次の発火を早めたとする。このとき e 以後の可塑性を止めても（CF-2）、すでに強まった重みは働く。そのため d_e と d_e^{CF-2} は一致しうる（推定対象 B ＝ 0）。それでも推定対象 A の効果は、過去の学習で強まった接続を通っている（推定対象 C ≠ 0 でありうる）
- したがって、**S2 の③の主張は、どの推定対象についてかを書いてから行う**。A と B だけでは、「経験で変わった接続を使って行動が変わった」（C）を主張しない

#### 3.3.2 介入の定義

| 介入 | 止めるもの | 残るもの | 帰還の遮断か |
|---|---|---|---|
| **FB-1** | 受 → 源 の**駆動の伝達**（その接続の駆動を源に届けない） | その接続の重みの値と、その更新（規則どおりに動く）。他を経る間接の経路の伝達 | **直接の接続の伝達の遮断**。間接の経路は残る |
| **FB-2** | 受 → 源 の接続の**重みの更新** | **既存の重みを通る伝達**。ほかの接続の更新 | **遮断ではない** |
| **CF-2** | e の Pulse から次の意図までの、**すべての接続の可塑性の更新**（F と N の両方で） | e より前に形成された重み・痕跡。すべての伝達 | 遮断ではない |

- 置く区間で、推定対象が変わる。FB-2 を G-6 の複製の中（e 以後）に置けば推定対象 B のうち 受 → 源 の接続の分になる。経験の区間から置けば推定対象 C の候補（PC-2）になる。FB-1 を経験の区間から置くと、帰還の駆動がない経験になるので、経験の列そのものが変わる（推定対象 A を経験の全体で取り除いた比較で、C ではない）
- 伝達を遮断した系（FB-1）・更新を止めた系（FB-2・CF-2）は、出口を外した系と同じく、命題 G-1 の意味で C0 には戻らない（接続の働きか規則を変えている）。比較の対照であって、基準ではない

#### 3.3.3 命題 G-7・G-8

**命題 G-7（重みを 0 にしても、今の規則では 0 に固定されない）**【命題】：可塑性の更新 w′ ＝ (1 − a(P ＋ Q)) w ＋ a P w_max（N-1 の命題 R1-3 の証明の記号）で、w ＝ 0 から始めても、送り手の痕跡 P ＞ 0 のときに受け手が発火すれば w′ ＝ a P w_max ＞ 0。∎

したがって、**帰還の伝達の遮断は「重み 0」ではなく、伝達を届けないこと（FB-1）として定義する**。**更新を止めること（FB-2）は遮断ではない**（既存の重みを通る伝達が残る）。経験で形づくられた重みを取り除くために重みを書き換える介入（PC-4）でも、書き換えた後に更新を止めるのか、規則どおりに動かすのかを別に指定する（監査 010 の ChatGPT の回答、#145 のレビュー）。

**命題 G-8（直接の組では、順方向の重みと帰還の側の重みは一つの数に重なる）**【命題（既存の命題からの帰結）】

**前提**：C0 の可塑性の規則（`balanced_pair_window`）、組の 2 本の初期値 w0 ＝ w_max／2、更新が範囲の中にとどまる（N-1 の命題 R1-3 の証明の「切り詰めに掛からないこと」）。G-a で可塑性の規則を変えない。

**主張**：すべての時刻で、w(受→源) ＝ w_max − w(源→受)（実数の算術。浮動小数点の丸めを除く）。

**証明**：循環のメモ F1（組の和の保存）をそのまま当てはめる。R1-3 の記号で、w(源→受) の更新は (1 − a(P ＋ Q)) w(源→受) ＋ a P w_max である。w(受→源) の更新は、同じ係数 (1 − a(P ＋ Q)) と、P と Q を入れ替えた項 a Q w_max を持つ（受 → 源 では送り手と受け手が入れ替わるため）。和の更新は (1 − a(P ＋ Q))・(和) ＋ a(P ＋ Q) w_max なので、和 ＝ w_max なら次も w_max。初期の和は 2w0 ＝ w_max。∎

**帰結**
- ①の順方向の書き込み（源の発火の後に受が発火して w(源→受) が増える）は、同じ量だけ w(受→源) を弱める。受の発火の後に源が発火すれば、逆に w(受→源) が強まる。経験の列でどちらが勝つかは決めない（【予想】も置かない）
- **直接の組では、①と帰還の側の学習は独立に動けない**（N-1 の命題 R1-7：組の重みは一つの数しか持たない）
  - 受 → 源 の更新だけを止める介入（FB-2、PC-2 の片側の形）は、源 → 受 の更新を残すので、組の和の保存を破る。C0 の規則の族の外への介入で、差には「F1 を破ったこと」の効果が混ざる
  - 組の両方の更新を止める形（N-3・N-4 の LC4）は F1 を保つが、①の書き込みも同時に止める
- したがって、直接の組の重みの変化（一つの数）が後の行動に効いたとき、それを「順方向の書き込みの効果」と「帰還の側の学習の効果」のどちらと呼ぶかは、**重みへの介入だけでは決まらない**。伝達への介入（FB-1：受 → 源 の伝達だけを止める。または 源 → 受 の伝達だけを止める）を併せれば、その一つの数がどちらの向きの伝達を通って効いたかを、条件付きで比べうる（U5）。他を経る間接の経路（受 → 他・他 → 源 の組）も、それぞれ同じ性質を持つ

#### 3.3.4 推定対象 C の候補 PC-1〜PC-4【候補】

どれも、同じ条件の試しの区間（N-3・N-4 の LC5）で、後の行動（意図の時刻・間隔）を T にして比べる。帰無と上界は、どれも別に示す。新しい実験・計算は今は作らない。

| 候補 | 作り | 何を比べるか | 交絡・限界 |
|---|---|---|---|
| **PC-1 経験の区間からの可塑性の ON・OFF** | 同じ Birth State から、経験の区間を可塑性 ON の系と OFF の系で走らせ、試しの区間で T を比べる | 経験の区間の可塑性の全体が、後の行動に与えた効果 | 帰還の経路に限らない（①の書き込み、ほかの組も含む）。閉ループなので、可塑性を止めると行動が変わり、経験の列そのものが変わる（N-3・N-4 §3.3 の H^alt の (c)）。差には「重みの違い」と「経験の違い」が混ざる |
| **PC-2 帰還の側の可塑性だけを、経験の区間で止める** | 受 → 源（と他を経る帰還の経路）の更新だけを、経験の区間で止める。直接の組では、片側だけ（F1 を破る）か、組の両方（LC4。①も止まる）かを選ぶ | 帰還の側の重みの学習が、後の行動に与えた効果（条件付き） | G-8 のとおり、片側の形は F1 を破り、組の両方の形は①と分けられない。経験の列の分岐は PC-1 と同じ |
| **PC-3 同じ外生の刺激の履歴を課す** | 可塑性 ON の系が経験の区間で受けた感覚の列を記録し、可塑性 OFF の系（同じ Birth State）に、開いたループで再生する。試しの区間は同じ条件 | 受けた感覚の列を同じにしたもとでの、可塑性の効果（N-3・N-4 の LC1 と同じ型） | 再生する側の系では、経験の区間のループは開いている（その行動は結果を持たない）。ON の系は命題 G-2 により元の系そのもの。可塑性と、生まれつきの状態と列の対応との相互作用は残る（N-3・N-4 §3.4）。帰還の経路に限らない |
| **PC-4 状態・重みの条件付きの移植** | 経験の区間の終わりの可塑性 ON の系から、Unit の状態・痕跡はそのままに、重み（全部、または帰還の経路の組）だけを、経験の前の値（または PC-1 の OFF の系の値）に置き換えた系を作り、試しの区間で比べる | 経験で形づくられた重みが、その時点の状態のもとで後の行動に与える効果 | 背景の状態に依存した条件付きの効果（U5）。置き換えた組み合わせは、自然には到達しない状態でありうる。組の片側だけを置き換えると F1 を破る（G-8）。置き換えた後も規則が動けば重みは変わる（G-7）ので、試しの区間で更新を止めるかを別に指定する |

- PC-1・PC-2 は経験の列の分岐を含む。推定対象 C を主張するなら、その分岐を除く形（PC-3 か PC-4）を少なくとも一つ併せることを候補にする【候補】
- どの候補も、「経験で変わった接続を使って行動が変わった」の**条件付きの**比較で、背景をまたぐ一意の寄与の割合（C-III）ではない

### 3.4 S3：AS1 では問えない

- 行動が 1 つなので、「結果に応じてどの行動を選ぶか」は存在しない。④は原則として問えない
- AS1 で「行動の頻度が経験で変わった」ことが示されても、それは S2 の延長（帰還による発生の変化）で、選択の学習ではない

## 4. AS2（手がかりの後の 2 つの行動）と変種を三段で見る

### 4.1 構成と変種【候補】

| 構成 | 行動の源 | 結果 | 感覚と運動の重なり | 実装 |
|---|---|---|---|---|
| **AS2** | 手がかりの後の窓で、手がかりを受けない 2 つの Unit のうち先に発火したもの（I2） | X なら刺激 P、Y なら刺激 Q。P・Q は手がかりでない 2 つの Receptor（対応は乱数で割り当て） | **重なる**：結果の刺激が、行動の源の Unit の入口に直接来る | I2（拡張の部品・契約） |
| **AS2b** 片側の結果 | AS2 と同じ | X なら手がかりの Receptor にもう一度刺激、Y なら何も来ない（どちらを X にするかは乱数） | 結果は行動の源に直接来ない（手がかりの Unit に来る） | I2 |
| **AS3** 専用の行動の Unit | 入口のない Unit を足し（2 つ）、その発火（I1）または競合（I2） | AS2 と同じ | 重ならない（行動の Unit は入口を持たない） | Unit・接続・初期の重み・入次数が増える。足した Unit がもとの Unit とつながれば、C0 の軌道には戻らない |

- AS2 の重なり：行動 X の源の Unit が刺激 P も受ける対応では、結果が行動の源を直接発火させる（窓の外での誘発）。対応の入れ替え（X → Q）でも、もう一方の行動の源が誘発される。どちらの対応でも、結果が次の窓の前の行動の源の状態を直接変える
- AS2b は重なりを避けるが、結果が片側にしかないので、二つの行動は「結果がある・ない」で対称でない。行動の価値づけではないが、刺激の数が行動に依って違う（経験の統計の違い：N-3・N-4 §3.3 の H^alt の (c)）。また、結果が手がかりと同じ Receptor に来るので、窓を開くのは予定した手がかりだけと世界の規則に書く必要がある（結果の刺激が次の窓を開かないように。K6）

### 4.2 S1・S2

- S1：AS1 と同じく、契約テストと記録。ただし I2（競合）の実装の契約が要る（§2.3）
- S2：G-6 は AS2 でもそのまま成り立つ（決定論。世界の側の状態・予約の列も複製する）。次の窓の**どちらの行動が出たか**と、その時刻への、1 回の結果の刺激の効果が、出来事ごとに定まる。③には、AS1 と同じく推定対象 A・B・C の区別と介入（§3.3）が要る。AS2 の重なりでは、結果の刺激が行動の源の入口に直接来るので、推定対象 A に入口からの直接の駆動が加わる

### 4.3 S3（④）：選択の変化が、経験による可塑性を通したか

- **問いの形**：固定した対応のもとで、試しの区間（または後の窓）の行動 X の割合（あるいは X の先行の度合い）が、経験に依って変わったか
- **必要な比較の候補**（どれも、帰無と上界は別に示す）
  - **対応の入れ替え（個体の中）**：同じ個体で「X → P・Y → Q」と「X → Q・Y → P」の本体を走らせ、選択の変化が対応で違うかを見る（N-3・N-4 §3.8 の「X と Y の対応の入れ替えの対照」。向きの予測は【予想】で、まだ導いていない）
  - **可塑性を止めた対照（LC1）**：同じ対応のもとで、可塑性を止めた本体と比べる。選択の変化のうち、可塑性に依らない部分（生まれつきのリズム・即時の帰還）を除く
  - **結果のランダムな介入（LC3）**：結果を確率 ρ で返す。結びつきの強さを実験者が割り付ける
  - **推定対象 C の型の比較**（§3.3.4 の PC-1〜PC-4 の T を、試しの区間の選択に置き換えたもの）：選択の変化が、経験で形づくられた経路を通したかを見る。e 以後の更新を止める比較（CF-2 の型）だけでは、過去に形成された重みの効果を除けない
- **S2 の結果を、S3 の関門にしない**：G-6 の d_e が 0 の出来事ばかりでも、試しの区間の選択にだけ学習の効果が現れることは、論理の上で排除できない（§1.1）。S3 の比較は、S2 の読み出しの結果に依らずに設計する
- **S3 で言えることの上限**：「固定した対応のもとで、行動の選択の分布が、経験による可塑的な変化を通して、結果に応じて変わった」まで。**行動の意味を学んだ・目的をもって選んだ・価値を学んだ、ではない**（§2.4）。原則 §6 の 6 の「自分の行動が未来の感覚を変えるという因果を学べるか」を価値なしで問う形で、「なぜ片方を選ぶのか」に価値が要るかは原則 §6 の 7 の別の問いとして残る
- **AS2 の重なりの影響**：結果の刺激が行動の源を直接動かすので、選択の変化が「経験による可塑性」か「結果による直接の状態の変化（即時の帰還）」かの切り分けが、AS2b・AS3 より難しい

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次の脳の候補（外へ働きかける出口と、行動で刺激が変わる世界を足す形）について、二つの始め方を、三つの段階で比べました。

1. **閉ループができる**：自分の動きが外に働き、次に来る刺激が変わる
2. **戻ってきた刺激で、次の動きが変わる**
3. **経験から、どの行動を選ぶかが変わる**（Anima-ll の目標にとって大事なのはここです）

### 分かったこと

- **一つの行動だけの形（AS1）では、1 と 2 までしか問えません**。行動が一つなので、「選ぶ」ことがないからです
- **2 は、今の脳ではとてもはっきり確かめられます**。今の脳は同じ状態から同じように動くので、「戻ってきた刺激を 1 回だけ届けた場合」と「届けなかった場合」を作り、次の動きの時刻がずれたかを直接比べられます（脳だけでなく、世界の側の状態も同じに写し取ります）
- **ただし 2 には、意味の違う三つの問いが入っています**（v0.2 で分けました）
  - 戻ってきた刺激が、**今ある接続を通って**次の動きを変えたか
  - 刺激が戻った**後の**接続の変化が、それに足されたか
  - **それまでの経験で変わった接続**を使って、動きが変わったか
  - 3 番目が、Anima-ll の目的に近い問いです。刺激が戻った後の変化を止めても、それより前に変わった接続は残るので、2 番目を調べただけでは 3 番目は分かりません。3 番目には、経験している間の接続の変化を止めた場合と比べる、などの別の比較が要ります
- 今の脳では、二つの部品のあいだの「行きの接続」と「帰りの接続」の強さは足すと一定になるので、片方だけを変えることができません。「行きの向きに書き込まれた」のか「帰りの向きで学んだ」のかは、接続の強さをいじるだけでは区別できない、ということも分かりました
- **二つの行動の形（AS2）なら 3 を問えます**。ただし今の 3 つの部品では、行動を出す部品が結果の刺激も直接受けてしまいます。そのため、「経験から学んだ」のか「刺激で直接動かされた」のかが分けにくくなります。それを避ける形（結果を片側にだけ返す形や、行動専用の部品を足す形）も並べました
- どの形でも、「この部品が動いたら行動 X」という対応は実験者が決めたもので、AI が意味を学んで手に入れた行動とは考えません

### 二つの進め方

- **P（段階を踏む）**：まず一つの行動の形で 1 と 2 を確かめ、それから 3 の形を決める
- **Q（最初から選択を扱う）**：最初から二つの行動の形で、1〜3 をまとめて扱う

私は P を勧めます。足す仕組みが一番少ない形で、出口・世界・決まりごと・比べ方の道具を先に確かめておけば、3 でうまくいかなかったときに原因を絞りやすいからです。ただし、「1 回の刺激で次の動きの時刻がずれなかった」ことは、3 が起こらない理由にはしません。経験の効果が、後で行動を選ぶ場面にだけ現れることもありうるからです。P は 3 を後に回すだけで、そこで終わりではありません。
