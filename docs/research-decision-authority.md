### 6.2 契約の文書で決めること

- **構成**：C0 の 3 Unit のまま。手がかりの Unit（手がかりの Receptor が入口）と、二つの行動の源（手がかりを受けない二つの Unit）。役と行動 ID の割り当ては個体ごとの乱数（K2）
- **I2 の実現の形**（§6.3）
- **世界の規則**
  - 手がかりの外の予定、窓の開閉
  - 規則 c（どの行動 ID が結果を生むか）、結果の行き先（手がかりの Receptor）、遅れ L
  - 窓の中で、どの意図が結果を持つか（「最初の意図だけ」など）と、同じ Pulse の二つの意図の扱い（K6）
  - 結果の刺激は窓を開かない（K6）。何もしないときは何も来ない（K5）
- **隔離と還元**：意図は世界にだけ届き、脳に戻るのは感覚だけ（AI6）。出口を外すと C0 に戻る（命題 G-1・K4）
- **道具の要件**：状態 Σ の複製、外の履歴の再生、重みの移植、可塑性の停止（LC1）、規則 c の入れ替え（基準 §2.1）、試しの区間の FREEZE。AS1 の契約 3・4 を引き継ぎ、足りない所を書く
- **乱数の流れの名前**：役、行動 ID、規則 c、手がかりの予定（基準 §7）
- **前方の関門の判定の形**：どの量を、どの合成の条件で、どこまで出れば「測れる」とするか。結果の前に書く
- 言わないこと・未決・開示

### 6.3 I2 の実現の形：二つの候補を比べる

契約の文書で最初に決める点である。既存の文書は、二つの読み方を含んでいる。

| | 形 A：選ぶ部品を脳の側に置く | 形 B：二つの I1 の出口と、世界の規則 |
|---|---|---|
| 中身 | 二つの行動の源の発火を読み、窓の中で先に発火した方の ID の意図を一つだけ出す部品を、Neuroarchitecture の側に置く（N-3・N-4 §2.4.2 の I2） | AS1 で確かめた出口（I1）を、二つの源にそれぞれ付ける。源 1 が発火すれば A1、源 2 が発火すれば A2 の意図を、毎回出す。「窓の中で、どの意図が結果を持つか」「同じ Pulse の A1 と A2 をどう扱うか」は、世界の規則として書く（K6、N-3・N-4 §2.4.5）。選択は、窓の中で先に出た意図の ID として**測る量**にする |
| Core | 既存の出力の部品は自分の Unit の発火しか見ないので、複数の Unit を見る新しい種類の部品が要る（三段の比較 §2.3）。Core を変えずに作れるかは、未確認 | AS1 の出口（`IntentSourceUnit`）を、源ごとに行動 ID を変えて使う見込み。Core を変えない |
| 選択の規則 | 「先に発火した方を採り、他方は出さない」「同時なら〜」という固定の規則が、Neuroarchitecture の中に入る | Neuroarchitecture の中に、選ぶ規則を置かない。Runtime・Effector も選ばない（AI2〜AI4）。どの意図に結果が来るかは、世界の物理として決まる |
| 気をつける点 | §2 の 2（行動の選択を、外から恣意的な規則として与える）に当たりうる | 窓の中の二つ目以降の意図も、記録される（Runtime は消さない）。同じ Pulse に、同じ世界へ二つの意図が届く扱い（ActionIntent の境界 §5 の 2 の未決）を、世界の性質として決めることになる。#173 の SC-5・SC-6 の「I2 の競合・集約の部品」の数え方が変わる（三つの構成に共通なので、順位は変わらない見込み） |

- **案：形 B を先に検討する**
  - Core を変えない
  - 脳の中に選択の規則を置かないので、積み上げの方針と AI8（行動の選択の規則を、この層で定義しない）に沿う
  - AS1 で確かめた出口と道具を、そのまま使える見込みがある
- 形 B で、S3 の主の問い（窓の中で先に出る行動の割合が、経験で変わるか）と、R-1・R-7 の比べが立つなら、形 B を契約にする
- 形 B で問いが立たず、形 A が要り、それが脳の中の固定の選択の規則か Core の変更を要するなら、そこで止めて、t-k さんにご相談する（§2 の 2・3）
- どちらの形でも、K1（AS2b では構成の上で満たす）と K5（何もしないことは、意図がないこと）を守る

## 9. 専門知識がなくても読める説明（t-k さんへ）

### 何を決めたか

- 「今の段階を終えるか」「次の段階に進むか」「どの仕組みを使うか」を、毎回 t-k さんに決めていただく必要はありませんでした。最初にいただいた「下から積み上げていく」という方針の中で、AI 側が決めてよいことでした
- これからは、その方針の中では AI 側で決めて進め、節目ごとにご報告します。ご報告は「判断していただくことはありません」と書いてお送りし、お返事を待たずに進めます
- ご判断をお願いするのは、次のような、研究の考え方や土台に関わる分かれ道に来たときだけです
  - 「下から積み上げる」方針そのものを変える必要が出たとき
  - AI が自分で生み出すべき「どちらを選ぶか」「何がよいか」を、こちらが外から決めて与えないと進めないとき
  - AI の土台の作りや、大事な約束事を変える必要が出たとき
  - 研究の目的や優先順位を、今の方針だけでは決められないとき
