## 0. 結論

**推奨**
- 次の課題として、**候補 A「前もって固定した重みの対称な二つの端への介入で、AS2b の窓の中の選択が変わる個体はどれだけあり、どれだけ変わるか」**（新しい個体群での特性の評価）を勧めます
- その次に、**候補 B「結果の付与の規則に依って、重みの変化に向きのそろった違いが生じるか」**（可塑性の層の問い）を勧めます

**理由**
- bottom-up の階段は、次の四段です
  - (i) 経験で重みが変わり、その変化が後の発火に届きうる
  - (ii) その変化が、結果の付与の規則に依る
  - (iii) 重みが、窓の中の選択を動かしうる
  - (iv) 規則に依る重みの変化が、選択を動かす
- 各段の今の位置
  - (i)：AS1 の 0037 で、存在の水準で観測した範囲です（経験の後の 6 本の重みを出生時の値に戻すと、適格な 77 個体のうち 37 個体で意図の列が変わった。個体の多数の主の判定 J_C は不成立。R5 §0.2）
  - (ii)：まだ独立には問うていません
  - (iii)：0039 の必ず報告する記述 D^W で、**存在の水準では観測済み**です。同じ背景の状態と U の世界のもとで、二つの本体に自然にできた重みの差を移植し、U で FREEZE すると、判定対象 188 個体のうち 62 個体（＋ 27・− 35）で U の A1 の割合が変わりました。ただし記述で、J_W は未判定です。自然な学習・規則に依る選択の変化・個体の多数の主張ではありません。関門 0038 が確かめたのは、これとは別の「選択が測れる」ことです
  - (iv)：0039 で問い、事前に定めた基準では確立しませんでした
- (iv) をもう一度問う前に、(ii) を独立に確かめ、(iii) を存在の水準から一歩進めて特性を測るのが、bottom-up の順です
- **A を B の先にする理由**は、(iii) が未確認だからではありません
  - 技術の費用：A は既存の道具（`clone`・`transplant`・`declare`）で組める見込みで、走らせる規模も関門と同じ程度の見込みです。ただし、A を 0039 と同じ形（事前登録 → 盲検の smoke → 本番）で行うなら、B との費用の差は小さくなります（§4.1）
  - 条件付きの構成の診断：自然な重みの差の移植（D^W）とは別に、前もって固定した対称な介入への応答の分布を、新しい個体群で知っておくと、B・(iv) の設計（必要な個体数、選択の量の扱い）の材料になる
- **B は A の結果に依らず意味を持ちます**。A を B の関門にしません。A の結果が陰性でも、B は進められます

**t-k さんのご判断が要るもの**
- 候補 A・B は、どちらも既存の方針・構成・Core の範囲の中の課題で、権限の文書 §2 の分岐に当たりません
- 構成の見直し（候補 D）は、候補 A の結果だけでは始めません。独立の理由を別に示したうえで、基準 §1.3・§6.4 の文書とレビューを経ます。そのとき、C0 の値・Core・基本設計の変更が要るなら分岐 3、研究の優先順位の選び直しなら分岐 4 なので、採用の前にご相談します（§3 の候補 D・§4）

## 3. 候補

### 候補 A（推奨・最初）：前もって固定した対称な二つの端への介入で、窓の中の選択はどれだけ変わるか

**問い**：AS2b の関門の組と C0 の値のもとで、手がかりの Unit と二つの源の間の 2 組（4 本）の重みを、許される範囲（各 [0, w_max]。組の 2 本の和 ＝ w_max の保存 F1：`docs/activity-plasticity-loop-math.md`）の中で前もって固定した相反する二つの端に置く。その二つの系で、試しの区間の選択が変わる個体はどれだけあり、どれだけ変わるか。新しい個体群で測る。

- **段の位置**：(iii) の特性の評価です。学習の問いではありません
- **0039 の観測（事実 4）との関係**
  - 存在：0039 の D^W で、自然にできた重みの差の移植により選択の割合が変わる個体があることは、記述として観測済みです（§0）。候補 A は、この存在を初めて確かめるものではありません
  - 新しい推定対象：自然な移植の差ではなく、**前もって固定した対称な二つの端**への介入に対する応答の分布（変わる個体の割合、変わる大きさ、勝ちの多い行動が入れ替わる割合）を、0039 と重ならない新しい個体群で測ります
  - 0039 の D^W・J_W を確かめ直したり、言い換えたりしません
- **介入の対象**（素案。契約で凍結する）
  - 二つの端は、6 本すべてをそれぞれ端に置くのではなく、次の 2 組（4 本）の相反する端です
    - 源 1 に寄せた端：C → 源 1 ＝ w_max（源 1 → C ＝ 0）、C → 源 2 ＝ 0（源 2 → C ＝ w_max）
    - 源 2 に寄せた鏡の端：C → 源 1 ＝ 0（源 1 → C ＝ w_max）、C → 源 2 ＝ w_max（源 2 → C ＝ 0）
  - 源 1 ↔ 源 2 の組は、どちらの系でも出生時の値 w0（＝ w_max／2）に固定します
  - どちらの端も F1 を保ちます。重みは FREEZE します
- **形の素案**（どれを主の条件にするかは、次の契約で一つに決める。§4.1）
  - 端に置く時点
    - (a) 出生のときから端に置く（経験を含まない）
    - (b) 本体を経験の区間の終わりまで走らせ、その境界で複製して端に移植する（0039 の移植と同じ操作）
  - 試しの区間の世界
    - 結果を返さない世界（`switch_world` で応じない）。即時の帰還（H2）を混ぜずに、重み → 選択だけを見る
    - 規則 c ＝ A1・A2 のそれぞれで結果を返す世界
  - (a)・(b) と、帰還のない・ある世界は、それぞれ**別の推定対象**です。主の条件を一つと、必ず置く対照を、走らせる前に凍結します
  - 量の候補
    - 二つの端で A1 の割合が違う個体の割合
    - 差の大きさの分布
    - 勝ちの多い行動が入れ替わる個体の割合
- **前もって決めること**：走らせる前に凍結し、一度だけ走らせます。項目は §4.1 に並べます
- **言えること**
  - 陽性（変わる個体が、前もって決めた基準を超える）：前もって固定したこの二つの端の対比・この個体群・この窓の条件で、選択がその割合・大きさで変わったこと
  - 陰性：**前もって固定した二つの端の対比・対象の個体群・窓の条件で、所定の差が認められなかった**こと。ここまでです
- **言えないこと**
  - 陰性から、「AS2b は重みで選択を動かしにくい」「構成の余地が小さい」「構成の限界」と結論すること。力学は時間をまたぐと入力について単調でない（`docs/activity-plasticity-loop-math.md` §5.2 の反例）ので、二点だけの対比で差が小さくても、途中の重みや別の向きの介入で選択が変わる可能性は除けません
  - 陰性を、候補 D（構成の見直し・AS3 への切り替え）を始める条件にすること（§3 の候補 D）
  - 端の結果を、範囲の中のほかの重みでの結果の上限・下限と読むこと
  - 端の重みで変わることを、自然な経験で届く重みの変化で変わることと読むこと。端は、自然な経験では到達しない状態でありうる
  - 学習・規則に依る選択の変化の成立。0039 の結果の言い換え・不成立の理由の説明
- **費用**
  - 解析の部分（重みが窓の勝ちを入れ替えうるための必要条件など）は、seed なしで命題の形に書ける見込みです
  - 走らせる部分は、関門と同じ規模の見込みです（0038 は 80 本体で約 17 秒）
  - 道具は、AS2b の道具の `clone`・`transplant`・`declare` で組める見込みです
- **分岐**：当たりません。重みの値を変えるのは測るための介入（移植・FREEZE と同じ種類）で、行動の選択を外から決める規則ではありません（権限の文書 §2 の分岐 2 に当たらない）

### 候補 B（推奨・二番目）：規則 c に依って、重みの変化に向きのそろった違いが生じるか

**問い**：同じ個体の二つの本体（規則 c ＝ A1 と A2）で、経験の区間の終わりの重みを比べる。規則 c が指す源への手がかりの重み（C → 源）が、指さない源への重みに比べてどちらに動くか。その向きは、個体の多数でそろうか。

- **段の位置**：(ii)。選択の下の層で、経験 → 規則に依る可塑的な変化を問います。(i) の次の段です
- **量の素案**（事前登録で決める）
  - δ_i ＝ [W^{A1}(C → 源 1) − W^{A2}(C → 源 1)] − [W^{A1}(C → 源 2) − W^{A2}(C → 源 2)]
  - A1・A2 の札を入れ替えても、値が変わりません
  - F1 により、C → 源 と 源 → C は補い合うので、独立な対は 3 つです
- **判定の素案**（事前登録で決める）
  - 向きは事前に決めません。命題 G-11 は、結果を返す側に逆順の時刻の組による弱める項が生じうることを示しますが、強める項もあり、正味の向きは前もって決まりません（G-11 の原文の範囲。正味が負の向きだとは断定しない）。そのため両側で問います
  - δ_i の札の入れ替えへの不変性は式の性質ですが、選んだ後の母集団での符号の対称性は論理の定理ではありません。0039 v0.2 と同じく、両側の帰無は**事前登録の上の仮定**として明記します
  - 0 の扱い・母集団（適格の条件）・多重性・否定的な結果の書き方は、別の契約・事前登録で決めます。個体の多数の判定の形は、0034〜0039 と同じ形を第一候補にします
- **前もって決めること**：新しい事前登録・道具・smoke・本番の工程を通します。seed は新しい範囲です
- **言えること**：成立すれば、「結果の付与の規則に依って、可塑的な重みの変化に向きのそろった違いが生じる」こと。重みの層の、規則に依る変化です
- **言えないこと**
  - 選択の変化・学習・報酬
  - 0039 の不成立の説明・救済（別の量・別の seed の、独立の問い）
  - 0039 の J_W・D^W や候補 A の結果と、候補 B の結果をつないで、媒介（規則 → 重み → 選択）の証明とすること
  - 重みの変化の向きを、接近・回避と呼ぶこと

### 何を提案するか

0039 では、「結果が返る行動を入れ替えると、後半の選び方が一方の向きにずれるか」を確かめ、前もって決めた基準には届きませんでした。そこで、いきなり同じ問いを問い直すのではなく、その手前の段を一つずつ確かめることを提案します。

1. **（最初）つながりの強さを端まで寄せると、どれくらいの AI で、どれくらい選び方が変わるか**
   - 0039 で、つながりの強さだけを入れ替えると選び方の割合が変わる AI がいることは、もう見えています（188 体のうち 62 体）
   - そこで、前もって決めた二つの「端」に寄せたとき、どれくらいの AI で、どれくらい変わるかを、新しい AI たちで測ります
   - 変わらなかったとしても、それだけで「今の仕組みでは無理」とは決めません。決めた二つの端では差が見えなかった、というところまでです。仕組みの見直しは、別の理由がそろったときに、別に検討します
2. **（次）結果の返し方の違いで、つながりの強さの変わり方がそろって違ってくるか**
   - 選び方ではなく、その下のつながりの強さの層で、規則による違いを確かめます

### なぜその順番か

- 0039 では、判定対象の 187 体のうち 99 体で、二つの世界での選び方の割合がまったく同じでした。ここからは、「選び方は生まれつきの差でほぼ決まっていて、つながりの強さが入り込む余地が小さいのかもしれない」という見込みが立ちます
- 一方で、つながりの強さだけを入れ替えると選び方の割合が変わった AI も、188 体のうち 62 体いました。つながりの強さで選び方が変わること自体は、すでに一部の AI で見えています
- 1 を先にするのは、2 より小さな手間で済み、2 やその先の設計の材料になるからです。2 は 1 の結果に関係なく進められます
