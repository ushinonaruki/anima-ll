## 0. 結論

**推奨**
- 次の課題として、**候補 A「AS2b の窓の中の選択は、可塑的な重みの許される範囲の中で、そもそも動きうるか」**（可変性の確かめ）を勧めます
- その次に、**候補 B「結果の付与の規則に依って、重みの変化に向きのそろった違いが生じるか」**（可塑性の層の問い）を勧めます

**理由**
- bottom-up の階段は、次の四段です
  - (i) 経験で重みが変わり、その変化が後の発火に届きうる
  - (ii) その変化が、結果の付与の規則に依る
  - (iii) 重みが、窓の中の選択を動かしうる
  - (iv) 規則に依る重みの変化が、選択を動かす
- (i) は、AS1 の 0037 で、存在の水準で観測した範囲です（経験の後の 6 本の重みを出生時の値に戻すと、適格な 77 個体のうち 37 個体で意図の列が変わった。個体の多数の主の判定 J_C は不成立。R5 §0.2）
- (iv) は 0039 で問い、事前に定めた基準では確立しませんでした
- (ii) と (iii) は、まだ独立には問うていません。(iv) をもう一度問う前に、この二段を一つずつ確かめるのが bottom-up の順です
- (iii) は、関門 0038 が確かめていない前提でした。0038 が確かめたのは「選択が測れる」ことで、「重みで選択が動きうる」ことではありません

**t-k さんのご判断が要るもの**
- 候補 A・B は、どちらも既存の方針・構成・Core の範囲の中の課題で、権限の文書 §2 の分岐に当たりません
- 候補 A の結果によっては、構成の限界の文書（基準 §1.3・§6.4）を経て、構成や C0 の値を見直す必要が出るかもしれません。そのとき、C0 の値・Core・基本設計の変更が要るなら分岐 3、研究の優先順位の選び直しなら分岐 4 なので、採用の前にご相談します（§4）

## 3. 候補

### 候補 A（推奨・最初）：可塑的な重みの許される範囲で、窓の中の選択は動きうるか

**問い**：AS2b の関門の組と C0 の値のもとで、可塑的な 6 本の重みを、許される範囲（各 [0, w_max]。組の 2 本の和 ＝ w_max の保存 F1：`docs/activity-plasticity-loop-math.md`）の両端に置いたとき、試しの区間の勝ちの行動はどれだけ変わるか。

- **段の位置**：(iii)。学習の問いではなく、構成が「重みで選択が動く」余地を持つかの確かめです。関門 0038（選択が測れるか）の続きに当たる前方の関門です
- **事実 4 との関係**：自然な重みの差でも、一部の個体では選択の割合が変わりました（記述）。候補 A は、それを確かめ直すのではなく、許される範囲の端まで重みを動かしたとき、選択が動く個体がどれだけあり、どれだけ動くか（構成の余地の目安）を、新しい seed で前もって決めた形で測ります
- **形の素案**（契約で決める）
  1. 関門の本体と同じ組み立てで、同じ seed から二つの系を作る
  2. 二つの系の 6 本の重みを、F1（組の 2 本の和 ＝ w_max）を保つ二つの端に置く
     - 一方の源に寄せた端：C → 源 1 ＝ w_max（源 1 → C ＝ 0）、C → 源 2 ＝ 0（源 2 → C ＝ w_max）。源どうしは出生時の値 w0
     - もう一方の源に寄せた鏡の端
  3. 重みを止めて（FREEZE）走らせ、二つの系の窓の結末を比べる。端に置く時点は、次のどちらかを契約で決める
     - (a) 出生のときから端に置く（経験を含まない。いちばん単純）
     - (b) 本体を経験の区間の終わりまで走らせ、その境界で複製して端に移植する（0039 の移植と同じ操作。内の状態は経験の後のもの）
  4. 試しの区間の世界は、次のどちらを主にするかを契約で決める
     - 結果を返さない世界（`switch_world` で応じない）。即時の帰還（H2）を混ぜずに、重み → 選択だけを見る
     - 規則 c ＝ A1・A2 のそれぞれで結果を返す世界（対照の候補）
  5. 量の候補
     - 二つの端で A1 の割合が違う個体の割合
     - 差の大きさの分布
     - 勝ちの多い行動が入れ替わる個体の割合
- **前もって決めること**（0038 と同じく、走らせる前に宣言して固定し、一度だけ走らせる）
  - 合否の基準
  - 合成の seed の新しい範囲（0039 の範囲を含め、これまでのどの範囲とも重ねない）
- **言えること**
  - 端の重みでも勝ちがほとんど動かないなら、この構成で可塑的な重みが選択を動かす余地は小さい、という強い手がかり（構成の限界の候補。範囲の中のすべての重みについての証明ではない）
  - 動く個体が多いなら、この構成には、重みが選択を動かす余地があること。(ii)・(iv) を、この構成で問い続ける前提の一つが立ちます
  - どちらの場合も、0039 の不成立の理由の説明にはしません
- **言えないこと**
  - 端の重みで動くことを、自然な経験で届く重みの変化で動くことと読むこと。端は、自然な経験では到達しない状態でありうる
  - 端の結果を、範囲の中のほかの重みでの結果の上限と読むこと。力学は時間をまたぐと入力について単調でない（`docs/activity-plasticity-loop-math.md` §5.2 の反例）。示すのは、「許される範囲の中に、選択を動かす重みがあるか、どれだけの個体であるか」です
  - 学習・選択の変化の成立。0039 の結果の言い換え
- **費用**
  - 解析の部分（重みが窓の勝ちを入れ替えうるための必要条件など）は、seed なしで命題の形に書ける見込みです
  - 走らせる部分は、合成の seed だけで、関門と同じ規模です（0038 は 80 本体で約 17 秒）
  - 道具は、AS2b の道具の `clone`・`transplant`・`declare` で組める見込みです
- **分岐**：当たりません。重みの値を変えるのは測るための介入（移植・FREEZE と同じ種類）で、行動の選択を外から決める規則ではありません（権限の文書 §2 の分岐 2 に当たらない）

### 候補 B（推奨・二番目）：規則 c に依って、重みの変化に向きのそろった違いが生じるか

**問い**：同じ個体の二つの本体（規則 c ＝ A1 と A2）で、経験の区間の終わりの重みを比べる。規則 c が指す源への手がかりの重み（C → 源）が、指さない源への重みに比べてどちらに動くか。その向きは、個体の多数でそろうか。

- **段の位置**：(ii)。選択の下の層で、経験 → 規則に依る可塑的な変化を問います。(i) の次の段です
- **量の素案**（事前登録で決める）
  - δ_i ＝ [W^{A1}(C → 源 1) − W^{A2}(C → 源 1)] − [W^{A1}(C → 源 2) − W^{A2}(C → 源 2)]
  - A1・A2 の札を入れ替えても、値が変わりません
  - F1 により、C → 源 と 源 → C は補い合うので、独立な対は 3 つです
- **判定の素案**：向きは事前に決めません。命題 G-11 により、結果を返す側には弱める項も生じうるので、両側で問います。個体の多数の判定の形は、0034〜0039 と同じにします
- **前もって決めること**：新しい事前登録・道具・smoke・本番の工程を通します。seed は新しい範囲です
- **言えること**：成立すれば、「結果の付与の規則に依って、可塑的な重みの変化に向きのそろった違いが生じる」こと。重みの層の、規則に依る変化です
- **言えないこと**
  - 選択の変化・学習・報酬
  - 0039 の不成立の説明・救済（別の量・別の seed の、独立の問い）
  - 重みの変化の向きを、接近・回避と呼ぶこと
- **費用**：0039 と同じ程度（1 個体あたり 2 本体で足りる見込み）
- **分岐**：当たりません

### 候補 C（保留）：可塑性を通さない規則の依存（即時の帰還）の記述

- **問い**：可塑性を止めた系で、結果の刺激が手がかりの Unit を通して、源の発火の時刻をどう動かすか（H2）
- **保留の理由**：学習の階段（i〜iv）の外にある、力学の性質の記述です。候補 A・B の後で、選択の変化の経路を分ける必要が出たときに取り上げます

### 候補 D（条件付き）：構成の見直し

- **取り上げる条件**：候補 A で、構成の限界（重みが選択を動かす余地が小さい）がはっきりした場合だけです
- **手続き**：基準 §1.3・§6.4 のとおり、0039 の結果ではなく、限界の理由を書いた別の文書とレビューを経ます
- **候補**：基準 §6.4 の AS3（入口のない行動の Unit を足す構成）など。基準 §6.4 も、AS3 を「AS2b で構成の限界がはっきりした場合の次の候補」とし、AS2b の S3 の結果を見て選び直さないと定めています。AS2 は、§6.4 では「片側の非対称に強く依る」ときの候補で、重みの余地の限界とは理由が違います
- **t-k さんへのご相談**：次のどれかが要るなら、採用の前にご相談します
  - C0 の確定した値（w_max、Receptor の重み、力学の値）・Core・基本設計の変更（分岐 3）
  - 研究の優先順位の選び直し（分岐 4）

### 候補 E（勧めない）：同じ AS2b の組での S3 の問い直し

- **例**：別の推定対象（大きさ・個体ごとに向きの違う効果）や、別の区間の分け方で、S3 をもう一度事前登録し直すこと

- **候補 B を候補 A の後にする理由**
  - 候補 A のほうが小さく、構成の妥当性（S3 をこの構成で問い続けてよいか）を先に決められます
  - 候補 B は、候補 A の結果に依らず意味を持つ問いです。候補 A の受理の後なら、並べて進めることもできます。その判断は、候補 A の受理のときにお願いします
- **分岐 2 との関係**：どの候補でも、行動の選択や価値の判断を外から与える規則は足しません（I2 の中立な手続きのまま）
- **分岐 3 との関係**：Core・C0 の確定した値・Pulse の順序・AI1〜AI10 は、候補 A・B では変えません

## 7. 専門知識がなくても読める説明（t-k さんへ）

### 何を提案するか

0039 では、「結果が返る行動を入れ替えると、後半の選び方が一方の向きにずれるか」を確かめ、前もって決めた基準には届きませんでした。そこで、いきなり同じ問いを問い直すのではなく、その手前の段を一つずつ確かめることを提案します。

1. **（最初）つながりの強さで、選び方はそもそも動くのか**
   - つながりの強さを、許される範囲のいちばん端まで寄せてみて、選び方が変わるかを確かめます
   - 端まで寄せても選び方がほとんど変わらないなら、今の仕組みでは、経験で選び方が変わる余地がもともと小さい、という強い手がかりになります
2. **（次）結果の返し方の違いで、つながりの強さの変わり方がそろって違ってくるか**
   - 選び方ではなく、その下のつながりの強さの層で、規則による違いを確かめます

### なぜその順番か

- 0039 では、判定対象の 187 体のうち 99 体で、二つの世界での選び方の割合がまったく同じでした。ここからは、「選び方は生まれつきの差でほぼ決まっていて、つながりの強さが入り込む余地が小さいのかもしれない」という見込みが立ちます
- 一方で、つながりの強さだけを入れ替えると選び方の割合が変わった AI も、188 体のうち 62 体いました。余地がまったくないわけではなさそうです
- どちらも見込みで、まだ確かめていません。余地がどれくらいあるかを、前もって決めた形で確かめるのが、1 の提案です
