## 2. 規則：釣り合った時刻の差の窓

### 2.1 形

送り手 S・受け手 T の発火の Pulse の差 d ＝ t_T − t_S について、

```text
d ≥ 1   ：Δw = + A · exp(−(d − 1)·Δt / τ_x)     … S が先（P2）
d ≤ −1  ：Δw = − A · exp(−(|d| − 1)·Δt / τ_x)   … T が先
d = 0   ：Δw = 0
```

- 強める側と弱める側は、**同じ大きさ A・同じ時定数 τ_x**（釣り合った窓）
- 実装は発火の痕跡で行う（監査 §2.2）。接続ごとの rule_state に、S の痕跡 x と T の痕跡 y を持つ。Pulse の境界で、この Pulse の ActivityEvent を使って
  - T が発火した → Δw ＋＝ A · x（前の Pulse までの S の痕跡）
  - S が発火した → Δw −＝ A · y（前の Pulse までの T の痕跡）
  - そのあと、痕跡を減らし（exp(−Δt/τ_x)）、この Pulse に発火していれば痕跡に 1 を足す（加算。§2.4）
- 同じ Pulse で S と T が両方発火したときは、前の Pulse までの痕跡だけを使うので、d = 0 の組は数えられない（順番に依存しない）

### 2.2 弱める側を入れ、釣り合わせる理由

- 0011 のとおり、今の Unit は入力がなくても内在的駆動で発火し続ける。強めるだけの窓では、**世界の構造と関係のない偶然の前後関係でも重みが増え続け**、どの接続もいずれ上限へ向かう。これは測る前に、規則の形と力学から分かる（監査 §3.1）
- 窓を釣り合わせると、**互いに関係なく発火する 2 つの Unit のあいだでは、強める組と弱める組がほぼ同じだけ起きる**。重みが偏って動くのは、**一方が他方より先に来る、という順序の偏りがあるときだけ**になる。これは「世界の順序の構造だけを学ぶ」という 0012 の問いと直接対応する（柔らかい上限・下限と組み合わせたときの落ち着き先は §3.2）
- 結果として、別の安定化（ゆっくり戻る S3）で偶然の漂流を打ち消す必要がなくなり、そのための値（戻る時定数）も要らない

### 2.3 d = 0 を v1 では学ばない理由

- 境界の仕様 §6.3 のとおり、d = 0 はこの接続を通った因果ではない
- 今の力学では、同じ Pulse の発火は主に **共通の入力**（同じ送り手から同時に駆動される）から起きる。d = 0 で強めると、釣り合いが崩れ、共通の入力を持つ Unit どうしが一方的に強まる
- P1（順序のない共起）は捨てるのではなく、**別の問いとして残す**（v1 は「順序の構造」だけを確かめる）。入れるなら、釣り合いへの影響と合わせて別に事前登録する

### 2.4 痕跡：加算型にする理由と、時定数

- Unit の activity は decay 0.85／秒で減る。時定数は τ_m ＝ −1／ln 0.85 ≒ 6.15 秒（Unit の activity の工学的な時定数。生物の膜の時定数とは呼ばない）
- **痕跡は加算型**：発火のたびに 1 を足し、exp(−Δt/τ_x) で減る。これは監査 §2.1 の `Δw ＝ Σ（発火の組）K(d)` を、すべての発火の組について指数の窓で数えることと同じである（新しい状態ではなく、組を数える計算の仕方）
- **「発火で 1 にする」（v0.1 の案）は採らない**：痕跡が 1 で頭打ちになるので、発火の多い送り手 S の痕跡 x はいつも高く、発火の少ない受け手 T の痕跡 y は低くなりやすい。すると互いに独立でも、強める項 A·x が弱める項 A·y より大きくなり、**S → T が強まりうる**。今は Birth State のばらつきで Unit ごとに発火の頻度が違うので、無視できない。これでは §2.2 の釣り合いと、§3.2 の w0 ＝ θ／2 の導出が崩れる
- 加算型なら、発火の頻度が違っても、独立に発火する 2 つの Unit のあいだの「S が先」の組と「T が先」の組は期待値で同じ数になり、釣り合いが保たれる
- **時定数 τ_x ＝ τ_m**：生物学的に同じ時間だから、ではない。**v1 で新しい自由な時間の尺度を増やさないための、値を減らす足場** として置く（台帳に記録する）。τ_m 以外にする独立した理由が出たら、そのとき別に決める

## 3. 安定化：柔らかい上限・下限

### 3.1 形

```text
強める：Δw = + A · x · (w_max − w) / w_max
弱める：Δw = − A · y · w / w_max
0 ≤ w ≤ w_max
```

- 変化の量に、残りの余地（上限まで、下限まで）を掛ける（S2）。上限・下限に張り付きにくい
- **下限 0**：興奮性の接続が抑制性に変わらない（監査 §3.3）
- **上限 w_max ＝ θ**：設計図の閾値（出生時のばらつき前・順応なし）を、重みの尺度と上限に使う **工学的な正規化**。「1 本で必ず受け手を発火させられる生物的な上限」とは呼ばない（実際の受け手には、順応と出生時のばらつきが乗るため）。ほかの値を選ぶより恣意が少ない、という以上の意味は持たせない
- 振幅 A は w_max に対する比で書く（台帳 §3.9）

### 3.2 順序の偏りがないときの落ち着き先と、初期の重み

柔らかい上限・下限では、変化の量に (w_max − w) と w が掛かる。釣り合った窓のもとで、強める組と弱める組が同じだけ起きると、平均の変化は (w_max − w) − w ＝ w_max − 2w に比例し、**重みは w_max／2 に落ち着く**（w_max／2 より上なら下がり、下なら上がる）。

したがって、

- 初期の重みを w0 ＝ w_max／2 ＝ θ／2 にすると、**最初の状態が、順序の偏りがないときの落ち着き先そのもの** になる。順序の偏りのない活動（自発発火・順序を崩した刺激）では重みは平均して動かず、順序のある経験だけが重みを w_max／2 から動かす
- これで w0 は自由に選ぶ値ではなくなる（規則の形から決まる）。w0 ＝ θ／2 < θ なので、1 本では休んでいる受け手を発火させない、という §4.1 の条件も満たす
- ただし、これは「強める組と弱める組が同じだけ起きる」ときの話である。s1〜s3 は互いに w0 でつながっており、出生時のばらつきで発火しやすさも違うので、刺激がなくても前後関係が偏りうる。その分の漂流は、刺激なし・順序を崩した刺激の対照（同じ seed）で測り、順序ありの条件と比べる

### 3.3 使わないもの

- **S3 ゆっくり戻る**：§2.2 の釣り合いで、偶然の漂流は平均して打ち消される。忘却そのものは別の問い（記憶・Replay の段）で扱う
- **S4 受け手ごとの合計を保つ**：受け手に入る全接続を読む必要があり、規則の局所性が下がる（境界の仕様 §8 の 4）。v1 では使わない
- **S1 硬い上限**：S2 の範囲の制限としてだけ持つ（0 ≤ w ≤ w_max）

### 3.4 4 つの問い

| 問い | 釣り合った窓 ＋ 柔らかい上限・下限 |
|---|---|
| 症状を直すためだけか | いいえ。暴走・漂流は、測る前に規則の形と 0011 の力学（自発発火が続く）から分かる。安定化は規則と同時に、測る前に決める |
| 独立した原理として説明できるか | 釣り合い：関係のない活動では動かない。上限：1 本の接続が持てる意味のある強さの上限。下限：接続の種類（興奮性）を変えない |
| 計算資源の数を変えても同じ意味か | はい。読むのは発火の Pulse と、その接続の重み・痕跡だけ |
| 副作用を次の状態で補償していないか | 弱める側は、強める側の副作用の補償ではなく、窓そのものの形（順序の向き）として入れる。ただし、v1 の結果で新しい漂流が見えても、ここに仕組みを足さない（事前登録の扱いに書く） |

## 4. 受け身の人工世界

### 4.1 脳の設計図（0012 用。動作テスト用の足場）

```text
receptor.x1 ─(w_in)→ s1
receptor.x2 ─(w_in)→ s2          s1・s2・s3 のあいだは、すべての組（6 本）を w0 でつなぐ
receptor.x3 ─(w_in)→ s3          この 6 本だけが可塑性の対象
```

- Unit は 3 つ（s1〜s3）。出力の部品は relay（中身は流さない。SensoryEvent に中身を付けないので、relay は何も出さない）。kernel_request の Unit は置かない（LLM なし）
- **Receptor → Unit は 1 対 1、重み w_in は `minimal-v3` の receptor → u0 と同じ（1.0）**。可塑性の対象外。1 対 1 は「この Unit は x1 担当」という配線による役割の付与に近い（台帳 §3.8）。ただし 0012 の問いは「Unit どうしの結びつきが経験で変わるか」であり、入口のつなぎ方（seed で疎につなぐ案）まで同時に未知数にすると、何が効いたか読めなくなる。足場として台帳に記録する
- **s1〜s3 のあいだは同じ初期の重み w0 ＝ θ／2**（§3.2。1 本では休んでいる受け手を発火させない）。設計者が A → B だけを強く描く、という偏りがない（Birth State の非対称は残る。同じ seed どうしで比べる）
- 力学の値は `minimal-v3` のまま（内在的駆動・閾値・減衰・jitter・順応の参照値）。0012 の結果に合わせて変えない

### 4.2 環境（どれが A・B・C かは環境だけが知る）

- 刺激は「A の Δ 秒後に、確率 p で B、確率 1 − p で C」の試行を、試行の間隔 I をあけて繰り返す（Δ < τ_x、I ≫ τ_x）
- A・B・C を x1〜x3 のどれに割り当てるかは、環境の設定。**個体ごとに入れ替える**（Birth State の非対称が特定の役に偏らないように）。入れ替えは乱数ではなく **seed から決まる決まった割り当て**（3 つの役の並べ方 6 通りを seed で順に回す、など）にし、同じ seed なら順序あり・順序を崩した刺激・刺激なしで必ず同じ割り当てにする
- 刺激の中身は付けない（material なし）

### 4.3 条件と比べ方

| 条件 | 刺激 |
|---|---|
| 順序あり | 上の試行 |
| 順序を崩した刺激 | A・B・C の出る回数と時刻の並びは同じで、どの刺激がどの時刻に出るかをランダムに入れ替える（「A の後に B」という構造だけを取り除く） |
| 刺激なし | 同じ時間、刺激を出さない |

- **同じ seed（同じ Birth State）どうしで比べる**
- 経験の前と後に、**A だけを与える試し（probe）** を行う。試しは、**実験の道具が個体をその時点で丸ごと複製し、複製のほうにだけ** A を与えて測り、複製は捨てる。本体は試しを受けずに続く

  ```text
  本体の流れ ──┬─────────────── 本体はそのまま続く（試しを受けない）
               └─ 複製 → A だけを与える → 測る → 捨てる
  ```

  - **複製でも可塑性は止めない**（認知の側に「試しのときだけ可塑性を止める」モードを作らない）
  - 複製は実験の道具の操作であり、AnIma-ll の認知の仕組みではない。測ることが本体の Life History を汚さないようにするためだけに使う
  - 0012 の人工世界には LLM・Kernel の仕事がないので、個体の状態（Unit の状態・接続の状態・BrainState・Receptor の台本の位置）をまとめて複製できる。複製のしかたは実装のときに決める

### 4.4 指標

- **主（活動）**：A だけを与えたあとの窓の中で、B 側の Unit が発火した割合 − C 側の Unit が発火した割合。経験の後 − 経験の前 を、3 条件で比べる
- **確認（仕組み）**：w(A 側 → B 側) − w(A 側 → C 側)、w(B 側 → A 側) の変化（釣り合った窓なら、逆向きは弱まる側に動くはず）
- 判定の値（何個体以上で、どれだけの差なら「成り立つ」か）は 0012 の protocol.yaml に置く

## 6. 0012 の前に実装すること

1. **ConnectionState**（境界の仕様 v0.2）：個体の Neuroarchitecture に属する。初期の重みと可塑性の規則・パラメータは設計図から作る。スナップショットに `connections` を足す

4. 契約テスト：
   - **可塑性を無効にすると、0011 と同じ結果**（発火の記録の一致）
   - **本来の T7**：境界で重みが変わっても、前の Pulse に成立した Drive は元の重みのまま
   - 同じ Pulse の Unit の処理の順番を入れ替えても、重みの更新が変わらない（T4）
   - 規則に Delta の中身・Runtime の状態が渡らない（T5）
   - 保存して再開すると、重みと痕跡が続く（T6）
   - 釣り合いの確認：関係なく発火する 2 つの Unit（台本で与える）で、重みの平均の変化が小さいこと（規則の単体テスト）
