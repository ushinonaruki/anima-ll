## 0. 合意の射程

### 0.1 合意したこと（研究の進め方と判断原則）

1. **最終目標**：人間と同等以上の記憶機能を含む、生命的な内部力学を持つ AnIma-ll を目指す。記憶機能を会話の正答率や履歴の検索だけに還元しない。主観的な記憶体験・感情の存在は機能的な再現と分け、実現済みと主張しない。
2. **生物学の取り入れ方**：現実の脳の構造と因果的な作用をできるだけ忠実に手本とする。一方で、実際のニューロン数や細胞の微細構造まで一対一でコピーすることは求めず、計算資源と検証可能性の制約下で、必要な因果関係を保った抽象化を検討する。
3. **意味の非埋め込み**：「この Unit は嬉しさ担当」「この Unit は記憶担当」のように、認知・意味・感情の完成したラベルを Unit の動作規則へ焼き込まない。生物に見られる細胞種、回路構造、接続の方向や発達上の偏りをモデル化することは、意味の割り当てと同一ではない（R1〜R6 と恣意性台帳に照らして監査する）。
4. **優先順**：まず **S2（人間の記憶機能を支える因果構造・必要な能力）** を整理し、それと往復しながら **S1（その構造を失わずに表せる Unit の抽象粒度と活動・学習規則）** を検討する。次に生物学的忠実性、計算資源、失われる情報、科学的識別可能性を比較し、初めて次の Core の判断へ進む。
5. **性能だけで正当化しない**：必要な能力の実現と、内部状態・接続・可塑性がその結果に因果的に関わったことの識別を分けて評価する。既存 LLM＋LoRA＋DB と出力が同じだけでは、目的の内部機構が成立した根拠にはならない。
6. **採否の規律**：モデルを詳しくする／粗くする判断は、結果を見てから都合よく決めない。保存したい能力、比較対象、識別条件、失敗の意味を先に決め、恣意性台帳で理由と値を監査する。

これらは**研究方針への合意**であり、各機構の実装合意ではない。

### 0.2 有力な候補にとどめること（採用していない）

- S1 の第一候補は、**神経集団（ニューロン群）を抽象 Unit とし、局所回路から脳領域に相当する回路群へ組み上がる、階層的・マルチスケールの構造**。生物の一ニューロン＝一 Unit とする案、他の計算的抽象単位も比較から排除しない。
- 興奮・抑制の相互作用、局所性と疎な長距離結合、順応、可塑性・恒常性、広域の修飾信号、速い学習系と遅い統合系、身体との閉ループは**生物由来の設計仮説**。Claudeが提案した①〜⑥は、現在この位置づけにある。
- 興奮性群・抑制性群を別にするのは妥当なモデル化の候補だが、「どのニューロンも全出力先に同一の興奮／抑制効果を及ぼす」という生物学的な絶対則とはしない。伝達物質の共放出や受容体依存の作用がある。
- Wilson–Cowan 型などの発火率（連続活動）モデルは比較対象であり、**そのまま採用しない**。イベント型（発火時刻を扱う）・発火率型・混合型を並べる。現在のタイミング依存可塑性を別形式の Unit にそのまま流用できるとは考えない。
- 海馬系・視床系・大脳皮質等の**回路の結合関係と動作特性**は参考になるが、その名称を付けるだけで「記憶」「注意」「認知」が成立したとはしない。生物の神経回路が実際に持つ構造と、機能達成に必要な因果構造は別に整理して照合する。
- ニューロモーフィック計算機は将来の移植先の候補であって、現段階でのハードウェア要件でも、脳機能再現の保証でもない。

## 1. S2：記憶について先に整理する対象

**最終目標：人間同等以上の記憶機能の再現。** 今の3 Unitで「重みが変わった」ことを記憶の達成と呼ばず、以下を機能面と因果機構面の両方から調べる。

| 研究対象 | 機能面で問うこと | 内部の因果機構で問うこと |
|---|---|---|
| 経験の符号化と区別 | 異なる経験、順序、時間関係を区別できるか | 何が経験に応じて変形し、異なる経歴を区別するか |
| 保持と安定性 | 短時間から長時間にわたって何が保たれるか | 持続する変化、再活性化、固定化、忘却をどう区別するか |
| 想起と再構成 | 部分的・不完全な手掛かり、または自発活動から経験を呼び戻せるか | 現在の活動がどの保存状態を使い、過去の活動に由来する関係をどう再構成するか |
| 連想と一般化 | 個々の出来事を越えて共通の知識や関係を獲得できるか | 過去の経歴から現在の内部表現へどんな変換があるか |
| 記憶の利用 | 後の知覚・学習・判断・行動が経験に依存して変わるか | 変化の媒介が内部のどこにあるか。外部の回答テンプレートで代替されていないか |
| 干渉・忘却・再学習 | 新しい経験と既存の記憶がどう相互作用するか | 可塑性と安定化、活動と不活動、資源制約の関係は何か |

- これらは**検討する能力の一覧**であり、現時点で個別の合否閾値・最終仕様を採用したものではない。
- 記憶の現象と、その現象を起こす機構を別にし、実験で識別できることを後から記憶の定義にしない（#89、#94 E1〜E8）。
- 外への行動がまだない段階でも、内部活動や後続の知覚が経験に因果的に依存するかは別の問いとして扱える。ただし行動が感覚に影響を返す閉ループ（R6）は将来の必要課題で、現行3 Unitでは未実装。
- 脳で観測される想起・再生・相補的学習などを知ることと、すべてを最小要件にすることは同義ではない。必要性と、生物学上の実在を切り分ける。
- 主張の射程に応じて、単独 Unit の時間パターンと複数 Unit 間の活動関係の再出現を区別する（#94 E5、Q5 L3 の対応規則 R は未決）。

## 2. S1：Unit の抽象化で保存する情報を比較する

比較対象の候補：

| 模型の粒度 | 残せそうな情報 | 欠落しうる情報・要検討点 |
|---|---|---|
| 単一ニューロンに近いイベント型 | 発火時刻、局所的な時間順序、イベントによる可塑性 | 人間規模への拡張の計算負荷。生物の細部の取捨選択 |
| 神経集団の連続活動率型 | 集団の平均的な活動・興奮抑制の相互作用 | 個々の時刻関係、同期や分布、現行の発火対による可塑性の情報 |
| 神経集団のイベント／活動率の混合型 | 集団の量的状態と集団的イベントの双方を扱える可能性 | どのイベントが意味のある粗視化か、追加状態の根拠、計算負荷 |
| 複数の粒度の混合（マルチスケール） | 必要な場所の時間関係を細かく保ち、他は粗くできる可能性 | 粒度間の伝達・学習の整合性、境界の恣意性、検証難度 |

**原則**：Unit の活動を変えるなら、可塑性の更新則、痕跡、伝達遅延、観測方法もセットで検討する。現行 v1.1 は発火の時間差に依存するため、連続活動率型ではそのまま使えない。#84・#94の数学命題も自動継承されない。

**比較の基準を結果の前に明示する**：
1. S2で必要とした経験の区別・時間関係・想起への因果経路を保持しうるか。
2. 生物の構造・現象との対応をどこまで説明できるか。対応がない場合、どんな抽象化上の理由があるか。
3. 実行コスト（Unit・接続の数、計算の局所性、状態の保存と転送）と科学的な識別可能性。
4. 任意の数値や配線を増やしていないか、成功しやすいように後付けで選んでいないか。

**注意**：脳のニューロン数に対する一定の圧縮率から必要 Unit 数を決めない。何個の生物ニューロンが1 Unitに相当するかも、この段階では未決。

## 3. DB の役割は未決

少なくとも三つの異なる用途を区別して比較する。

1. **工学的な永続化**：Unit・結合・痕跡などの内部状態を再起動後に復元する。保存場所が DB であることは、その情報が認知的な意味を持つ根拠にはならない。
2. **外界の記録**：映像・音声・出来事などの大量の原資料を保持する。外部に保存されているだけでは本人の想起とは言わない。
3. **経験への索引を支える基盤**：内部状態の変化から過去の経験を選び、再構成する過程を支える可能性。ただし、検索ルールや意味ラベルを人間が代わりに与え、認知の働きを実装の外へ押し出していないか監査する。

DB を生記録専用とも、記憶の本体とも、排除すべきものとも決定しない。保存と想起・利用を分け、永続化の工学的必要性と、本人の活動を構成する因果的必要性を別々に評価する。
