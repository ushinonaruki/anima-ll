## 1. 現行 Core の構造（コードと設計図が正本）

### 1.1 位置づけ：3 Unit は最小模型であって、AnIma-ll の完成形ではない

- 0012〜0022 で使ったのは、**現象を分離して研究するための最小模型**（研究用の設計図 `experiments/0012_passive_world/neuroarchitecture.yaml`）である。設計図の注にも「AnIma-ll の脳の新しい版ではない」とある

### 1.3 1 Pulse の順序（`pulse_runtime.run_pulse`）

```text
0. この Pulse の伝達に使う重みを固定する（ConnectionStore の写し）：w(t−1)
1. 感覚の出来事（Receptor が成立させたもの）を、固定した重みで駆動にする（届くのは t+1）
2. この Pulse のスナップショットを作る（前の Pulse に作られた駆動が、この Pulse に受け手へ届く）
3. 前の Pulse までに終わった Kernel の計算を返す（研究用の設計図では Kernel がない）
4. 全 Unit を進める：届いた駆動の重みの合計を刺激にして力学を 1 秒進め、発火したら ActivityEvent を作り、
   固定した重みで駆動を作る（届くのは t+1）。Unit を進める順番は結果に影響しない
5. 計算の意図の受理と実行（研究用の設計図ではない）
6. Pulse の境界：中身と駆動を BrainState に反映し、この Pulse に発火した Unit の集合を ConnectionStore に渡して
   可塑性を更新する。更新は次の Pulse の冒頭の固定から見える
7. Effector への作用（研究用の設計図ではない）
8. 観察用の標本（Runtime は中身を解釈しない）
```

### 1.4 式（不応期 0、Δt ＝ 1、研究用の設計図、循環のメモ §1 と同じ記号）

```text
ã_j(t) = λ a_j(t−1) + u_j(t) + c_j                         （判定の直前の activity）
h̃_j(t) = γ h_j(t−1)
s_j(t) = 1  ⇔  ã_j(t) ≥ θ_j + h̃_j(t)
a_j(t) = (1 − s_j(t)) ã_j(t),   h_j(t) = h̃_j(t) + α s_j(t)
u_j(t+1) = Σ_i w_ij(t−1) s_i(t)  ＋（感覚の駆動 1.0 × Receptor の出来事）
w_ij(t) = σ_ij(t) w_ij(t−1) + β_ij(t)
σ_ij(t) = 1 − a [ X_i(t−1) s_j(t) + X_j(t−1) s_i(t) ],   β_ij(t) = a X_i(t−1) s_j(t) w_max   （a ＝ A／w_max ＝ 0.01。activity の a_j とは別の記号）
X_i(t) = κ X_i(t−1) + s_i(t),   κ = λ
```

派生する量（理論のメモ §4）：a*_j ＝ c_j／(1 − λ)、g_j ＝ a*_j − θ_j、ρ_j ＝ a*_j／θ_j。出生時のばらつきの範囲では a* ∈ [0.48, 0.587]、θ ∈ [0.45, 0.55]、g ∈ [−0.070, 0.137]。g ＞ 0 の Unit の入力のないときの周期は T ≈ τ_a ln(1 ＋ α／g)（条件付き 4.2）で、g ＝ 0.137 で約 21、g ＝ 0.01 で約 208、g → 0 で発散する。

### 1.5 人が追える説明：1 回の試行と、そのあとの入力のない時間

0014〜0022 の世界（試行 k の始まり s_k ＝ 1 ＋ 60k、200 回）の ordered の 1 回の試行は、次のように進む。

1. Pulse s_k に Receptor A の感覚の出来事が成立する。駆動（重み 1.0）は s_k ＋ 1 に s_A に届く
2. 1.0 は閾値（約 0.5）の約 2 倍なので、s_A は s_k ＋ 1 にほぼ必ず発火する（0014・0016 で 1.00）。activity は 0 に戻り、順応が α 上がる
3. s_A の発火は、s_k ＋ 1 の冒頭に固定した重み w(A→B)・w(A→C)（それぞれ 0〜0.01）で駆動になり、s_k ＋ 2 に s_B・s_C に届く。これは閾値の約 2% 以下の小さな押しで、受け手が発火の直前にいるときだけ、その Pulse の発火を起こす。そうでなければ λ 倍ずつ減りながら、次の発火を少し早める
4. s_k ＋ 2 に Receptor B の出来事が成立し、s_B は s_k ＋ 3 に発火する。s_k ＋ 30 に C の出来事が成立し、s_C は s_k ＋ 31 に発火する
5. 各 Pulse の終わりに、可塑性が「この Pulse に発火した Unit」と、前の Pulse までの痕跡だけを見て重みを更新する。s_A が先に発火していたので（痕跡 X_A は 1 Pulse ごとに 0.85 倍）、s_B が発火すると w(A→B) は強まり、w(B→A) は同じだけ弱まる（組の和が w_max のまま。循環のメモ F1）。時間差 30 の A→C の組は κ^29 ≈ 0.009 の重みでしか書き込まれない
6. 試行と試行のあいだ（約 60 Pulse）、Unit は自分の内在的駆動と順応で動く。g ＞ 0 の Unit は自力で発火し、g ＜ 0 の Unit は、ほかの Unit からの小さな押しが積み重ならない限り発火しない

経験が終わった後の入力のない時間（W ＝ 12001〜24000）には、外からの駆動はない。

- 各 Unit は自分の周期（順応で決まる）で発火する。互いの発火は 1 Pulse 遅れの小さな押しとして届き、相手の次の発火の時刻を前に寄せる（順応で決まる範囲では数十〜数百 Pulse。理論のメモ 系 4.4d）
- 発火の組が生じれば、重みはさらに書き換わる（循環）
- 片側の Unit が発火しない組の重みは、痕跡が減ると実効的に動かなくなる（§3.1 の可塑性規則の行、命題 2.4b）

### 2.3 まとめ：4 種類に分けた現在地

**〔観測〕自然な個体で観測されたこと**
- 入力がなくても活動が続き、Unit ごとの周期と沈黙が Birth State で分かれる（台帳 §3.3 の 0007〜0010 の記録、0015 §10.3、0020 §10.1。式は理論のメモ §4）
- 価値を使わない可塑性で、接続の状態は経験の前から出生時の状態の向きへ自己形成し（0013 C）、経験の時間配置で変わる（0012 M、0014 w）
- 経験の終わりの重みの対比の差は、入力のない 12000 Pulse の終端でも多くの個体で同じ向きだった。ただし実効的な凍結による個体を含む（0015）
- 同じ Birth State の 2 つの自然な個体の自発の発火は、W の初めの早い時期から分かれた（0022 の t_OS）
- **自然な読み出し（介入のない腕）では、重みの違いは活動の違いとして揃っては現れなかった**（0012 H1、0014 の as_is）

**〔数学〕式から導かれたこと**：§2.2 の表。特に、学習した接続の通り道が組ごとの 3 値であること、直接一段の遅延が 1 であること、同じ発火の列を生む重みの集合が凸であること（重みが違っても発火が同じ、が一般に起こりうる）

**〔介入〕人工介入でだけ識別されたこと**

### 2.4 0022 の「接続の差があっても発火の差がない」と「発火する Unit が少ない個体」

#### (a) 観測されたこと（README §13.3・§13.6。新しい集計はしていない）

- t_OS があるのに t_YO・t_YS のどちらもない個体が 14（区分 (b)）。14 個体とも T で F_O ≠ 0 の接続があり、F_S ≠ 0 も 15024 を除く 13 個体にあった
- そのうち 8 個体（15009・15024・15026・15063・15070・15082・15095・15099）では、W の間、4 つの主の腕のどれでも発火した Unit が 1 つだけだった。残りの 6 個体では、少なくとも 1 つの腕で 2〜3 の Unit が発火していた
- 区分 (a) の 2 個体（15056・15078）は、W の間、4 つの主の腕のどれでも、どの Unit も発火しなかった

#### (b) 式から導かれること

**【命題 2.4a】発火する Unit が 1 つだけなら、その Unit の発火の列は W の重みに依らない**

W（[t0 ＋ 1, T]）に発火する Unit が i だけなら、i に届く駆動は [t0 ＋ 2, T] で 0 である（駆動は発火した送り手からしか生じない：活動の伝達 仕様 C2、`pulse_runtime._transmit`）。したがって i の W の発火の列は、i の t0 の (a, h)・t0 ＋ 1 に届く駆動（t0 の発火と w(t0 − 1) で作られ、yoke の腕と基準で同じ）・Birth State だけで決まり、t0 以後の重みに依らない。重みの違いが発火の列を変えるには、沈黙している Unit のどれかが、片方の腕でだけ閾値に届く必要がある。

**【命題 2.4b】ある腕の可塑性に使う発火の列で発火する Unit が 1 つだけなら、その腕の W の重みの更新は、沈黙した Unit の t0 の痕跡にだけ比例する（腕ごとの上限）**

腕 X の可塑性の更新に使う発火の列を S_X と書く。自然な腕 O・S では自分の発火、yoke の腕 Y_O←S では S の発火、Y_S←O では O の発火である。X の痕跡は、X 自身の t0 の値から S_X の発火で更新される（0022 の設計：yoke の腕は自分の基準の t0 の痕跡を保ち、相手の発火で更新する）。

**条件（腕ごと）**：S_X で W に発火する Unit が i_X だけで、ほかの Unit は S_X で発火しない。

このとき、i_X と、S_X で沈黙している Unit j を結ぶ 2 本は次のように動く。接続 i_X→j は、j が発火しないので強まらず、i_X が発火したときに A·X_j·w／w_max だけ弱まる。接続 j→i_X は、i_X が発火したときに A·X_j·(w_max − w)／w_max だけ強まり、j が発火しないので弱まらない。沈黙した 2 つの Unit を結ぶ 2 本は変わらない。Pulse t の更新は前の Pulse の痕跡 X_j(t − 1) を使い、X_j は t0 から κ 倍ずつ減るだけなので、W 全体での 1 本の重みの変化の総量は

```text
|Δw_c^X| ≤ A · Σ_{t=t0+1}^{T} X_j^X(t−1) ≤ A · X_j^X(t0) · Σ_{k≥0} κ^k = A · X_j^X(t0)／(1 − κ) ≈ 6.7 × 10⁻⁴ · X_j^X(t0)
```

以下である（A ＝ 10⁻⁴、κ ＝ 0.85。(w_max − w)／w_max と w／w_max は 1 以下。X_j^X(t0) は腕 X の t0 の痕跡）。変化は κ^k で減る寄与の和なので、W の初めの数十 Pulse でほぼ作られる。**この条件を満たさない腕（S_X で 2 つ以上の Unit が発火する腕）には、この上限は使えない。**

**yoke の腕と基準の腕の差 F の上限（2 つの腕の条件がどちらも成り立つ場合だけ）**：Y_O←S と O を比べるとき、O の列（O 自身の発火）で発火するのが i_O だけ、**かつ** S の列（Y_O←S の可塑性に使う）で発火するのが i_S だけなら、接続 c ごとに

```text
|F_c| ≤ |Δw_c^Y| + |Δw_c^O| ≤ A · ( X_{j_Y(c)}(t0) + X_{j_O(c)}(t0) )／(1 − κ) ≤ 2A · max_j X_j(t0)／(1 − κ)
```

である。j_X(c) は、腕 X の列で接続 c の端のうち沈黙している Unit で、両端が沈黙ならその腕の項は 0 にする。Y_O←S は O の複製なので、t0 の重みと痕跡は O と同じ（X^Y(t0) ＝ X^O(t0)）。
- i_O ＝ i_S なら j_Y(c) ＝ j_O(c) で、上限は 2A·X_{j(c)}(t0)／(1 − κ) になる
- i_O ≠ i_S なら、2 つの腕で沈黙している Unit が違い、参照する痕跡も違う。一律の上限は max を使った右端の形に限る
- どちらかの腕の列で 2 つ以上の Unit が発火するなら、この上限は使えない
- Y_S←O と S の組も同じ形（S 自身の列と O の列の両方に条件が要る）
- 0022 の 8 個体は、README §13.6 によれば 4 つの主の腕のどれでも発火した Unit が 1 つだけなので、O の列と S の列の両方で条件を満たし、2 つの組とも上の上限が使える。O と S で発火した Unit が同じかは README に書かれておらず、この文書では調べていない（どちらの場合も右端の上限は成り立つ）

**【命題 2.4c】2〜3 の Unit が発火する個体でも、重みの差が発火の判定を変えない区画は一般にある**

循環のメモ F3：t0 の状態のうち重みだけを動かしたとき、同じ発火の列を生む重みの集合は凸である。重みの差が、その区画の中に収まり続ければ、発火の列は変わらない。0020 の 7 個体（A が発火し続けたのに列が同じ）、0021 の (b) の 4 個体、0022 の (b) の残り 6 個体は、どれもこの形と矛盾しない（この文書では、どの個体が区画のどこにいたかは調べていない）。

#### (c) 直ちに 3 Unit の不足の証明としない理由

1. **問いが違う**：0022 が問うたのは、yoke の操作の条件付きの因果効果であり、模型の能力ではない。指定された W で効果が現れなかったことは、窓の外・別の背景・別の操作について何も言わない（0022 README §13.4）
2. **数学的には予想される形**：命題 2.4a〜2.4c のとおり、重みの差があっても発火が変わらないことは、今の規則と力学の一般的な性質から起こりうる。3 Unit に特有の現象として導いたものではない
3. **パラメータの領域と t0 の状態に依る**：出生時の g の区分の割合と動員の帯の幅は、内在的駆動の置き場所（ρ ≈ 1.07。台帳 §3.3 D で「根拠なし」）と出生時のばらつきの幅、重みの尺度 w_max ＝ α、入次数 2 の組み合わせで決まる。さらに、W で実際に何個の Unit が発火するかは t0 の状態（activity・順応）にも依る（§3.3）。この組み合わせを変えれば区分の割合も変わるので、Unit の数だけの問題とは言えない
4. **疎な活動そのものは原則に反しない**：原則 §2 は「局所的・疎な特徴の表現は排除しない」とし、R2 は「分散して表せる」ことを求めて「完全に分散していること」は求めない。入力のない時間に一部の Unit が沈黙することは、それだけでは原則の違反ではない

#### (d) それでも残る、個体ごとの構造上の限界

- 入力のない時間に発火する Unit が 1 つだけの個体では、**W の自発の活動は 1 つの Unit の、入力のない孤立した発火の列（t0 の状態と Birth State だけで決まる。命題 2.4a）に限られる**。複数の Unit にまたがる自発の活動のパターンは、その個体の W には定義上存在しない
- そのような個体でも、外から刺激を入れれば、学習した重みは応答に効く（0016 の A が沈黙した 5 個体、0017 の 4 個体はどれも S ＞ 0）。限界は「入力のない時間に、学習した接続の構造が自発の活動として表れること」の側にある
- これは B5 の問いのうち、**複数の Unit にまたがる活動の関係の再出現** にとって意味のある性質である。1 つの Unit の時間のパターン（発火の間隔など）の再出現は、L3 の対応の規則 R が未決なので、ここでは否定しない。ただし、そのような個体を減らすために値を変えることは、症状に合わせた調整になる（台帳 §2.2 の問い 1）。§3.3・§5 で、原理の側からだけ扱う

#### (e) 分からないこと

- 0022 の 8 個体が、§3.3 の出生時の g の区分のどれに入るか、t0 の状態の条件（命題 3.3b の θ − max(a(t0), a*) ＞ B など）を満たすかは、保存済みの Birth State と t0 の状態の値を読めば分類できる。しかしそれは保存済みの記録への新しい量の後付けの当てはめになるので、この文書では行わない。行うなら、読み取り専用の事後の記述として別の承認を得る
- (b) の残り 6 個体で、重みの差がどれだけ区画の境界から離れていたか【未解決】

### 3.2 表から読めること

1. **〔原理〕から直接来る制約は少ない**。Unit 数・結合の形・遅延の長さ・組の和の保存・興奮性だけ・Receptor の 1 対 1 は、どれも原理からではなく、値・初期値・時間の解像度・足場から来ている
2. 原理から来るのは「Pulse の境界による遅延 ≥ 1」「価値を使わない局所的な規則」「中身を読まない伝達」「P1 による 1 本あたりの上限」である。これらは、最小模型を拡張しても残る種類の制約である
3. 監査の上で特に重い〔数値〕〔足場〕は、(i) 内在的駆動の置き場所とばらつき（台帳 §3.3 で既に「根拠なし」「要監査」）、(ii) 組の和の保存（初期値の帰結）、(iii) Receptor の 1 対 1（刺激の同一性を配線が与える）、(iv) 順応の参照値が別の配線で選ばれたこと、の 4 つである

### 3.3 自然な個体の発火が 1 Unit に偏ること：構造から必然か、パラメータの領域か、識別不能か

この節では、次の 3 つを分けて書く（v0.2）。

| | 何についての主張か | 何で決まるか |
|---|---|---|
| (i) 十分に長い時間についての命題 | 入力のない時間が続けば、いつかは発火するか | Birth State（と、比べ始めの状態） |
| (ii) 固定した W（12001〜24000、\|W\| ＝ 12000）の中についての命題 | W の中で発火するか、何回まで発火しうるか | Birth State と、t0 の状態（activity・順応）と、W の長さ |
| (iii) 出生時の g の区分の算術 | Birth State の分布の上で、各区分がどれだけの割合を占めるか | 分布の式だけ |

(iii) の割合は Birth State の分布の性質で、**W の中で発火する Unit の数の保証でも頻度でもない**。

**実数の命題についての注**：この節の命題は実数の計算である。実装は倍精度の浮動小数点なので、|g_j| や |g_j ＋ B| が丸めの大きさ（θ の近くで 10⁻¹⁵ 程度）以下の Unit については、この節の命題で実装の振る舞いを言わない。

#### (i) 十分に長い時間について

**【命題 3.3a】g_j ＞ 0 の Unit は、入力のない時間が十分に長く続けば、発火を繰り返す**

重みは 0 以上なので、駆動 u ≥ 0。最後の発火（または比べ始め）からの経過 n で、その時点の activity a_0 ≥ 0 と順応 h_0 を使うと

```text
ã(n) ≥ a* + (a_0 − a*) λ^n        （非負の駆動を落とした）
G(n) = θ + h̃(n) − ã(n) ≤ (a* − a_0) λ^n + h_0 γ^n − g ≤ a* λ^n + h_0 γ^n − g
```

n → ∞ で右辺 → −g ＜ 0 なので、有限の時間の中でいつかは発火する。発火のあとも同じ式が成り立つので、発火を繰り返す。他の Unit がどう動いても、この Unit を沈黙させることはできない（抑制がない）。

ここで言えるのは「有限の時間の中で、いつかは」までである。その時間は a_0・h_0・g で決まり、g → 0 で上限なく長くなる。**固定した W の中で発火することは、この命題からは出ない。**

#### (ii) 固定した W の中について

**【命題 3.3a′】W の中で少なくとも 1 回発火する十分条件（t0 の状態を使う）**

ある 1 ≤ n ≤ |W| で

```text
(a*_j − a_j(t0)) λ^n + h_j(t0) γ^n ≤ g_j
```

なら、j は [t0 ＋ 1, t0 ＋ n] のどこかで発火する。証明：それまで発火していなければ、命題 3.3a の不等式から G(n) ≤ 0 となり、t0 ＋ n に発火する。

この条件は t0 の (a_j, h_j) に依り、Birth State だけでは決まらない。

**【系 3.3a″】順応の上限を使って、Birth State だけから言える十分条件**

順応は出生時に 0 から始まり（`bootstrap.py`）、1 Pulse に高々 1 回の発火で α を足して γ 倍ずつ減るので、どの履歴でも

```text
h_j(t) < α／(1 − γ) ≈ 3.005
```

である。a_j(t0) ≥ 0 とあわせて、命題 3.3a′ を n ＝ |W| に使うと、

```text
g_j > g_W := a*_j λ^{|W|} + α γ^{|W|}／(1 − γ)
```

なら、t0 の状態がどうであっても、j は W の中で少なくとも 1 回発火する。|W| ＝ 12000 では γ^12000 ＝ e^(−40) なので g_W ≈ 1.3 × 10⁻¹⁷（a* λ^12000 の項は 10⁻⁸⁴⁶ 程度）。

- **0 ＜ g_j ≤ g_W の Unit については、W の中の発火を数学的に保証できない**。この区間が出生時に占める割合は、g の分布の密度（0 の近くで約 6.6）× g_W で 10⁻¹⁶ 程度だが、0 ではない。また、この区間は浮動小数点の丸めの大きさより狭いので、実装の振る舞いもこの命題では言わない（上の注）
- この十分条件が言うのは、W の中で「少なくとも 1 回」までである。何回発火するか、2 回目以後の時刻は、t0 の状態と結合で決まる

**【命題 3.3b】入力のない時間に、他の Unit が閾値から遠い Unit を発火させることはできない（動員の帯）**

(i) **発火の最短の間隔**：入力のない時間には、どの Unit も 7 Pulse 未満の間隔で発火できない。発火の直後 a ＝ 0 から n Pulse 後の判定の直前の activity は

```text
ã(n) ≤ (c + 2 w_max) · (1 − λ^n)／(1 − λ)
```

で（入次数 2、1 本 ≤ w_max は P0）、c ≤ 0.088、θ ≥ 0.45 では n ≤ 6 で ã(n) ≤ 0.4485 ＜ θ になるからである（n ＝ 7 で初めて 0.489）。

(ii) **積み重なる駆動の上限**：t0 以後の送り手の発火（間隔が 7 以上）から j に届く駆動を、減衰をつけて足したものは

```text
Σ_m λ^(t−m) u_j(m) ≤ w_max Σ_{i→j} Σ_q λ^(7(q−1)) = 2 w_max／(1 − λ^7) =: B ≈ 0.0294
```

以下である（B は閾値の約 6%）。和を「j のある発火の後に届いた駆動」だけに限っても、同じ上限が成り立つ。

(iii) **帰結**：j が t0 以後に発火していなければ ã_j(t) ＝ a*_j ＋ (a_j(t0) − a*_j) λ^(t−t0) ＋ Σ_m λ^(t−m) u_j(m) なので、

```text
θ_j − max(a_j(t0), a*_j) > B   ⇒   j は W の間一度も発火しない
```

- これを **g_j ＜ −B** に言い換えるには、**a_j(t0) ≤ a*_j** が要る。a_j(t0) は経験の終わりの状態で、Birth State の θ・c だけでは決まらない
- 等号 θ_j − max(a_j(t0), a*_j) ＝ B（a_j(t0) ≤ a*_j なら g_j ＝ −B）は条件を満たさないので含めない
- この上限 B は最悪の場合の値である。送り手の発火の間隔が T_s 以上なら上限は 2w_max／(1 − λ^(T_s)) に下がる（例えば T_s ≥ 21 なら約 0.0207）。実際の送り手の間隔は順応で決まり、ふつうは 7 よりずっと長い【条件付き】

**【命題 3.3b′】g_j ＜ −B の Unit は、W の中で高々 1 回、しかも初めの過渡にしか発火しない**

- **一度発火すれば、二度と発火しない**：発火で a_j ＝ 0 ≤ a*_j になる。以後は (ii) の和を発火の後の駆動に限っても B 以下なので、ã_j ≤ a*_j ＋ B ＜ θ_j ≤ θ_j ＋ h̃_j となる
- **最初の発火は初めの過渡だけ**：最初の発火までは ã_j(t) ≤ a*_j ＋ (a_j(t0) − a*_j) λ^(t−t0) ＋ B なので、発火できるのは

  ```text
  (a_j(t0) − a*_j) λ^(t−t0) ≥ −g_j − B  （＞ 0）
  ⇔  t − t0 ≤ ln((a_j(t0) − a*_j)／(−g_j − B))／ln(1／λ)
  ```

  の Pulse だけである（a_j(t0) ≤ θ_j − B なら一度も発火しない）
- 過渡の長さは a_j(t0) に依り、Birth State だけでは決まらない。a_j(t0) ＜ θ_j ＋ h̃_j(t0)（t0 に発火していなければ）なので有限である

**【系 3.3c】W で発火する Unit の数：Birth State だけから言えることと、t0 の状態が要ること**

```text
#{ j : g_j > g_W }  ≤  W で少なくとも 1 回発火する Unit の数  ≤  #{ j : θ_j − max(a_j(t0), a*_j) ≤ B }
W で 2 回以上発火する Unit の数  ≤  #{ j : g_j ≥ −B }
```

- 左端（系 3.3a″）と 2 行目（命題 3.3b′）は **Birth State だけで決まる**。1 行目の右端（命題 3.3b）は **t0 の activity に依る**
- −B ≤ g_j ≤ g_W の Unit（**帯**。0 ＜ g ≤ g_W の極めて狭い区間を含む）が W で発火するか・何回発火するかは、送り手の位相・重み・t0 の状態で決まり、Birth State だけからは決まらない【未解決】

#### (iii) 出生時の g の区分の算術【命題、今の値に条件付き】

閾値 θ ～ 一様 [0.45, 0.55]、a* ＝ c／(1 − λ) ～ 一様 [0.48, 0.5867] が独立とすると（`bootstrap.py` の jitter 0.1）、g ＝ a* − θ について、長方形の上の三角形の面積として閉じた形で

```text
P(g > 0)        = 1 − (0.55 − 0.48)²／(2 × 0.10667 × 0.1)            = 0.7703
P(g < −B)       = (0.55 − B − 0.48)²／(2 × 0.10667 × 0.1)            ≈ 0.0771
P(−B ≤ g ≤ 0)   ≈ 0.1526
```

（P(g ＞ 0) ≈ 0.77 は、可塑性 v1.1 の文書 §3 の「自発発火する Unit 約 77%」と同じ量。分布は連続なので、境界の等号の扱いは割合を変えない。g ＞ 0 と g ＞ g_W の違いは出生時の割合で 10⁻¹⁶ 程度で、下の表の数字には現れない）

3 つの Unit は独立なので、**出生時の g の区分**の割合は次のようになる。右の 2 列は、その区分について W の中で言えることで、**割合を W の中の個数の頻度と読まない**。

| 出生時の g の区分（3 つの Unit） | 出生時の割合 | Birth State だけから W について言えること | さらに t0 の状態などが要ること |
|---|---|---|---|
| 3 つとも g ＞ 0 | 0.457 | g ＞ g_W のものは、どれも W で少なくとも 1 回発火する | 回数・時刻 |
| 2 つが g ＞ 0、1 つが g ＜ −B | 0.137 | g ＞ g_W の 2 つは少なくとも 1 回。g ＜ −B の 1 つは高々 1 回、初めの過渡だけ | g ＜ −B の 1 つが発火するか（θ − max(a(t0), a*) ＞ B なら発火しない） |
| 2 つが g ＞ 0、1 つが帯（−B ≤ g ≤ 0） | 0.272 | g ＞ g_W の 2 つは少なくとも 1 回。帯の 1 つは決まらない | 帯の Unit の動員【未解決】 |
| 1 つだけ g ＞ 0、2 つが g ＜ −B | 0.014 | g ＞ g_W の 1 つは少なくとも 1 回。**W で 2 回以上発火しうるのはこの 1 つだけ**。残りの 2 つは高々 1 回ずつ、初めの過渡だけ | 残りの 2 つが θ − max(a(t0), a*) ＞ B を満たせば、W で発火するのは 1 つだけになる。満たすかは t0 の activity しだい |
| 1 つだけ g ＞ 0、帯が 1 つ以上 | 0.108 | g ＞ g_W の 1 つは少なくとも 1 回。帯は決まらない | 帯の Unit の動員【未解決】 |
| g ＞ 0 がない | 0.012 | W の中で発火する保証はない。g ＜ −B の Unit は高々 1 回 | t0 の状態と、帯の Unit どうしの駆動 |

g ＞ 0 の Unit が 1 つ以下の区分の出生時の割合は 0.134 で、0013 の「出生時のばらつきの式からの見込み約 13%」と同じ量である。これも出生時の区分の算術で、W の中で発火する Unit が 1 つ以下になる頻度ではない。

計算の手順：θ と a* の一様分布の長方形 [0.45, 0.55] × [0.48, 0.5867] の上で、a* − θ ＞ x となる部分の面積を全体の面積で割った。x ＝ 0 と x ＝ −B の 2 点だけを使い、3 つの Unit の区分の組み合わせの確率を掛け合わせた。模型は動かしていない。

## 5. 次の構造的な選択肢の比較

各案について、ChatGPT の指定した 5 つの観点で書く：①独立した原理的な必要性、②既存構造でできないこと、③その変更で新たに可能になること、④恣意性の持ち込み、⑤複雑化によって失う識別可能性。**どの案も推さない。**

### 5.1 案 1：現行構造を維持する

1. **必要性**：「維持すべき」という原理はない。理由は手順の側にある：原則 §6 の順序（B4 の問いを最小の場で分離する）、台帳 §2.1・§2.2（原因の層を先に判定し、症状から機構を足さない）。今の模型には、世界を変えずに理論で詰められる未解決が残っている（予想 4.5d、U8、§3.3 の帯の Unit の動員、位相の持ち越しの持続、L3 の規則 R）
2. **できないこと**：①刺激の同一性を経験から形成すること（Receptor の 1 対 1）②組ごとに両向きの結合の強さを別々に持つこと（組の和）③時間差ごとの関係を別々の重みに持つこと（命題 4.6・3.3）④直接一段で 1 以外の遅延 ⑤抑制による相互作用 ⑥行動の出口と閉ループ ⑦閾値から帯より遠い Unit を、入力のない時間に参加させること（命題 3.3b）⑧Unit の内部の状態（スカラー・hard reset・決定論）の範囲を超える力学
3. **新たに可能になること**：なし。0012〜0022 との比較と、#84・#88〜#90 の命題がそのまま使える
4. **恣意性**：新しくは持ち込まない。ただし既存の「根拠なし」「要監査」の値と足場（0.08・ばらつき・Receptor の 1 対 1・一定の駆動）を持ち越す
5. **失う識別可能性**：なし

### 5.2 案 2：Unit 数・結合構造を拡張する

下位の案：(2a) Unit 数を増やす、(2b) 結合の生成規則を入れる（疎・規則・乱数）、(2c) Receptor → Unit の写像を 1 対多にする。

1. **必要性**：原則 §8 の 2 は「今の配線に分散した表現を担えると判断する根拠はない」「必要な Unit の数は未決定」とする。また原則 §4 の「内部の表現は経験によって形成される」と、Receptor の 1 対 1（同一性を配線が与える）には緊張がある。しかし、**どの数・どの結線が必要かを導く原理はまだない**。言えるのは「今の数が十分だという根拠もない」という否定形までである。前提として「1 つの Unit が何を粗視化した単位か」（原則 §8 の 2）が決まっていない
2. **できないこと**（案 1 のうち）：①（1 対 1）、学習の通り道が 3 に限られること（全結合なら組の数 N(N−1)／2）、入次数 2 による動員の帯の上限（命題 3.3b の B ＝ 入次数 × w_max／(1 − λ^(n_min)) は入次数とともに増える。n_min も入次数で変わる）、3 つを超える要素の列、経路の長さと数の多様さ（3 Unit では、ある組を結ぶ 2 段の経路は 1 本だけ）
3. **可能になること**：関係の種類と学習の自由度の増加、収束・発散の経路、複数の経路による 1 より長い実効的な時間差（伝達の規則は変えずに）、刺激が複数の Unit にまたがる入口（2c）
4. **恣意性**：N・結線の規則・入口の写像・初期の重み。手で描く配線の恣意性（台帳 §3.8）が大きくなる。**P1 は 1 本あたりの上限なので、出次数が増えると 1 回の発火が起こす発火の目安が増える**（v1.1 §4 の反響の目安 2 × P(w0) が (N − 1) × P(w0) になる。この目安は受け手の独立を仮定した解析上の値で、反響の基準 C2 の成立の証明ではない【条件付き】）。重みの尺度の導出（v1.1）を見直す必要が出うる
5. **失う識別可能性**：状態の次元（Unit ごとの a・h・痕跡、接続ごとの重み）が増え、寄与の非加法性（U5）の組み合わせが増える。単体の Unit の命題（周期・単発の入力の効果）は残るが、網の全体の閉じた形は作りにくくなる。0012〜0022 と比べられなくなる。偶然の見積もり（U9）が関係の増加で楽になるかは【予想】

## 9. 専門知識がなくても読める短い解説（t-k さんへ）

**今の Core はどんなものか**

- 小さな「点」（Unit）が 3 つだけの、脳の模型です。点は、何もしなくても少しずつ「たまって」いき、いっぱいになると「パチッ」と発火して空に戻ります。発火するたびに少し「疲れ」がたまり、疲れは 5 分くらいを目安にゆっくり抜けていきます。この「たまる・発火する・疲れる」のくり返しで、外から何もしなくても、それぞれの点が自分のリズムで動き続けます
- 点どうしは線（接続）でつながっていて、ある点が発火すると、1 秒後に相手の点を少しだけ押します。押す強さは「相手の疲れ 1 回分」より強くならないように決めてあります。だから線は、相手を無理やり発火させるのではなく、相手の次の発火を少し早めるだけです
- 線の太さは経験で変わります。「自分が発火した少しあとに相手が発火した」ことが多い線は太くなり、逆向きの線は同じだけ細くなります。ご褒美や正解は使いません
- 外からの刺激（A・B・C）は、それぞれ決まった 1 つの点を発火させます
- 3 つにしているのは、起きていることを 1 つずつ切り分けて調べるためです。AnIma-ll の完成した脳ではありません

**ここまでで分かったこと**

- 経験の順番が違うと線の太さが変わり、何もしない時間が 3 時間あまりたった後でも、多くの個体で同じ向きの違いが見られました（そのあいだずっと続いていたかまでは確かめていません）
- 線の太さの違いは、刺激への反応を確かに変えます。ただし、それがはっきり確かめられたのは、ほかの条件をそろえる人工的な操作をしたときです。自然なままでは、違いはそろっては見えませんでした
- 何もしない時間の自発のリズムも、線の太さの変わり方によって後から変わりえます
- まだ分かっていないこと：経験したパターンが、何もしない時間に「思い出す」ように再び現れるか。これは記憶の入り口で、まだ調べ方も決まっていません

**0022 で気になった点**

- 線の太さが違っても、リズムが変わらない個体がありました。その半分以上は、何もしない時間に、3 つのうち 1 つの点しか発火していませんでした
- 点の「たまりやすさ」は生まれつき少しずつ違い、そのせいで、いくら待っても自分だけでは発火までたどり着かない点が出ます。ほかの点から押されても、押す力は合わせても閾値の約 6% までしか積み上がりません。だから閾値から遠い点は、経験の終わりに残った「勢い」で何もしない時間の初めに 1 回だけ発火することはあっても、そのあとは眠ったままです
- 生まれつきの値の組み合わせで数えると、「十分に長く待てば自分で発火を繰り返せる点が 1 つ以下」の個体は約 13%、そのうち「自分で発火を繰り返せる点がちょうど 1 つで、残りの 2 つの点がどちらも閾値から遠い」個体は約 1.4% です。ただしこれは生まれつきの値の割合で、何もしない時間に本当に 1 つしか発火しないかは、経験の終わりに残った状態でも変わるので、この数だけでは決まりません
- これは「3 つでは足りない」証拠ではありません。今の「たまりやすさ」の値（根拠なしと記録済み）、生まれつきの違いの幅、押す力の上限、入ってくる線が 2 本しかないこと、の組み合わせで起きています。値を変えて眠る点を減らすのは、結果に合わせた調整になるので、それを理由にはしません

**次の選択肢**

1. **今の形のまま**、式で詰められることを詰める
2. **点の数やつなぎ方を増やす**：できることは増えますが、「点 1 つが何を表すのか」がまだ決まっていないので、いくつにするかを決める根拠がありません
3. **伝わり方や線の変わり方のルールを見直す**：たとえば今の線は「両向きとも太い」状態になれず、伝わる時間はどこも 1 秒で、時間差の情報が 1 本の線の中で混ざります。ただ、ルールを変えると、今まで証明できた性質が使えなくなります

今の判断は「どれかを選ぶ根拠は、まだ足りない」です。先に決めたいのは、「点 1 つが何を表すか」と、「記憶（B5）が最低限何を必要とするか」を、見つけやすさではなく原理から書くことです。

- 何もしない時間に眠ったままの点がいることを、生まれつきの個体差として自然だと見ますか、模型の都合だと見ますか
