### 0.2 結論の先取り

1. **G-a の中身**：C0 の Unit の力学・可塑性・入口はそのままにして、(i) 内部の出来事から行動の意図（ActionIntent）が生まれる出口と、(ii) その意図に応じて次の感覚の出来事を決める世界の規則を足す。内部の状態 → 意図 → 世界 → 感覚 → 内部の状態、の因果の環ができる（§1）。**今のコードには、発火を Effector へ届ける経路も ActionIntent の型もない**ので、Core の変更を伴う
2. **N-3（何が可能になり、何を失うか）**（§2）
   - 可能になること：自分の内部の状態が自分の後の経験を決める、という因果（原則 §6 の 6、R6）を、価値なしで問えるようになる。経験に依って変わった内部の状態が行動に入るか（契約の MF9 後半）も、問いの対象になる。出口の切断・結果の付け替えという、脳の状態に触れない新しい介入の手段も得る
   - **恣意性の中心は、どの内部の出来事を行動の意図とするか**。C0 の知見から、次の基準を置く
     - K1：直前の刺激に入口で直接駆動される Unit の発火は、行動の意図にしない。その発火は順応が十分小さければ必ず起き（命題 G-3）、決められた反応になるから
     - K2：Unit と行動の ID の対応は、Receptor の役と同じく個体ごとに乱数で割り当て、意味の名前を付けない
     - K3：新しい自由度を数える
     - K4：出口を外せば C0 に正確に戻る（命題 G-1）
   - 失う識別可能性：感覚の列が脳の状態に依るので、固定した予定の上のラベルの交換可能性の設計（0023〜0033 の O・M・W）が、そのままは使えない。経験は個体の結果になる。重みの入れ替え（C-I）の効果には、世界を通した経路が入る
3. **N-4（どう比べるか）**（§3）
   - **同じ出生時の状態の本体に、元の本体が受けた感覚の列をそのまま再生すると、元と同じ軌道になる**（命題 G-2。決定論）。したがって、同じ個体の「感覚の yoke」は対照にならない。決定論の脳では、閉じたループの効果は、実現した感覚の列の効果に尽きる
   - ループの効果は反実仮想で定義する。**推奨の形は、別に用意したドナーの個体（行動の主）が自分の行動で作った列を、的の個体の本体に再生する参照**（他者の行動から生まれた列の yoke。C-II の整理の「ドナーの集まりを的から分ける」と同じ考え方）。的の個体の、自分の行動から生まれた列を受けた本体が、他者の列を受けた 19 本体と比べて典型的でないかを、結果を止めた試しの区間の統計で問う
   - 行動と結果の相関のように規則が決める統計は、証拠にならない（命題 G-4）
   - C0 との比較：出口を外し C0 の予定を与えた本体が C0 と一致することを、契約テストで確かめる（命題 G-1）。試しの区間の統計には C0 の形（Δ_AB・D）を使える。0028〜0033 の値とは比べない（総括 E13）
4. **最小の G-a の候補**（§4）：AS1「自発の 1 つの行動」（ある Unit の自発の発火が、少し後に別の刺激を呼ぶ）を最初の候補とする。AS2「手がかりの後の 2 つの行動」（手がかりの後の窓で、手がかりを受けない 2 つの Unit のどちらが先に発火したかで、次の刺激が変わる）はその次、AS3（専用の行動の Unit を足す）は C0 に正確に戻せないので後にする。どれも決定ではない
5. **t-k さんに判断を仰ぐ点**（§6）：G-a の方向（Core に行動の意図の経路を足すこと・世界を変えること）、最初の候補（AS1 か AS2 か）、計算の資源。ChatGPT のレビューの後に、相関と必要性 §5.2 の形でお願いする

## 1. G-a とは何か

### 1.1 最小の定義

- **脳**：C0（研究用の設計図。3 Unit、可塑的な接続 6 本、入口は Receptor → Unit の 1 対 1）。Unit の力学・可塑性の規則・値・Birth State の作り方は変えない
- **出口**：ある内部の出来事（§2.4 で選ぶ）が成立したとき、行動の意図 X（または X・Y）が生まれ、Runtime が記録して Effector に渡す（AI1〜AI4）。意図の発生は Unit の状態を変えない。結果は Receptor からだけ戻る（AI6）
- **世界**：行動の意図に応じて、後の感覚の出来事（どの Receptor に、いつ来るか）を決める規則。規則は事前に登録し、「正しい行動」を埋め込まない（原則 §8 の 4）

```text
内部の状態（活動・接続・痕跡）
   ↓（§2.4 で選ぶ内部の出来事）
行動の意図 X（Neuroarchitecture の中で成立。AI1）
   ↓ Runtime：記録して渡す（選ばない。AI4）
Effector：外界に作用する（選ばない。AI3）
   ↓
世界の規則：次の感覚の出来事を決める（原則 §8 の 4 の監査の対象）
   ↓ Receptor
内部の状態が変わる（可塑性を含む。規則は C0 のまま）
```

### 1.2 今のコードとの関係

- 研究用の設計図は `effectors: []` で、出力の部品は relay（中身を出さない）
- minimal-v3 の注のとおり、**発火は送り手からの接続に伝わるが、Effector には届かない**。Effector に届くのは Delta（中身）だけである（`pulse_runtime.py` が Delta を脳宛てと Effector 宛てに分ける）
- ActionIntent は、行動の意図の境界（契約）にだけあり、型・経路はコードにない
- したがって G-a は、**Core に新しい経路（発火から行動の意図を作る出力の部品、または新しい出来事の型）を足す変更**を伴う。実装はしない。構成の変更として t-k さんの承認が要る

## 2. N-3：何が新たに可能になり、何を失うか（再評価 §5 の 5 つの観点）

### 2.1 ① 独立した原理的な必要性

- 原則 R6（行動の意図は内部の状態から出る。外へ作用する出口があり、その結果が次の内部の状態を変える閉じたループ）は、採用済みの内部表現の契約である【既存の命題】
- 原則 §6 の 6（行動の意図を実際に閉じたループへつなぐ。自分の行動が未来の感覚を変えるという因果を学べるか。どちらが「よい」かは決めない）は、合意した順番の一段である
- 行動の意図の境界（AI1〜AI10）は、この段のために先に決めてある（原則 §6 の 2）
- 症状を直すための変更ではない（恣意性の台帳 §2.2 の問い 1・2）：C0 の否定的な結果を直すためではなく、C0 では対象がない段を問うために足す

### 2.2 ② 既存の構造でできないこと

- N-1 の命題 R1-2：C0 の感覚の列は（protocol、seed、札の列）だけで決まり、脳のどの状態にも依らない。内部の状態がその後の感覚を変えることは、C0 では構成上ない【既存の命題】
- これは「出口がないので行動として実現しない」という主張で、「内部に情報がない」ではない（N-1 の命題 §3.2）

### 2.3 ③ 新たに可能になること

| # | 新たに可能になること | 何がそれを可能にするか | 可能にならないこと |
|---|---|---|---|
| P1 | **自分の内部の状態が、自分の後の経験（感覚の列）を決める**因果を、価値なしで問える（原則 §6 の 6） | 出口と行動に応じる世界 | 「よい」行動の選択、価値・好み（原則 §6 の 7。価値は置かない） |
| P2 | 経験に依って変わった内部の状態が、行動（したがって次の経験）に入るか（契約の MF9 後半の「思い出した内容が行動の選択に入る」の、最初の形） | 同上。C0 で経験に依ることを示した時間差 1 の関係（総括 §2）が、行動の源になりうる | 「思い出した」こと・内容を理解したこと（L3・MF9 は意味ではない：相関と必要性 §1.1） |
| P3 | **脳の状態に触れない介入の手段**：出口の切断、結果の付け替え（他者の行動から生まれた列の再生）、規則の入れ替え | 世界の側の操作 | 脳の内部の担い手の特定（C-III は変わらず定まらない） |
| P4 | 個体ごとに違う経験の列が、個体自身の状態から生まれる（経験の内生化） | 閉じたループ | 「個性」「主体性」などの心理の言葉での主張 |

### 2.4 ④ 持ち込む恣意性（中心の問い：行動の意図を内部の活動からどう生むか）

#### 2.4.1 基準

行動の意図を生む内部の出来事（以下「行動の源」）の選び方に、次の基準を置く。どれも、C0 の命題と原則から導いたもので、結果を見て選ぶものではない。

| # | 基準 | 出どころ |
|---|---|---|
| **K1** | **内部の状態に依る**：行動の源は、直前の刺激に入口で直接駆動される Unit の誘発された発火であってはならない（命題 G-3） | 命題 G-3、再評価 §3.1 の感覚入力の行、ChatGPT の指示（決められた反応にしない） |
| **K2** | **意味の役割を持ち込まない**：どの Unit がどの行動の ID を出すかは、Receptor の役（A・B・C）と同じく個体ごとに乱数で割り当て、記録する。行動の ID に意味の名前を付けない（X・Y）。「ある内部の状態なら X」という規則を書かない | 原則 §3・R5、AI7・AI8、0028〜0033 の役の割り当て（(seed − 1) mod 6） |
| **K3** | **新しい自由度が少ない**：窓・遅れ・同時の扱い・対応の数を数え、どれも新しく選ぶ値として理由を書く（チェック C1） | チェック C1・A6 |
| **K4** | **C0 に正確に戻せる**：出口を外し（または世界が意図を無視し）、C0 の予定を与えれば、C0 と同じ軌道になる（命題 G-1） | 総括 E13・N-4 |
| **K5** | **何もしないは意図がないこと**：意図を出さないことを選ぶ仕組みを作らない | AI9 |
| **K6** | **Runtime・Effector は選ばない**：「窓の中の最初の意図だけが結果を持つ」のような決まりは、世界の規則として事前に書く。Runtime が意図を消したり選んだりしない | AI2〜AI4 |

#### 2.4.2 命題 G-3（直前の刺激に直接駆動される Unit の発火は、決められた反応になる）【命題（条件付き）】

**主張**：刺激 k の感覚の出来事が Pulse t に成立し、s_k の順応が h_k(t) ＜ 1.0 ＋ c_k − θ_k を満たすなら、s_k は t ＋ 1 に必ず発火する。

**証明**：t ＋ 1 の判定の直前の activity は ã_k(t ＋ 1) ＝ λ a_k(t) ＋ u_k(t ＋ 1) ＋ c_k ≥ 1.0 ＋ c_k（a ≥ 0、入口の駆動 1.0）。閾値の側は θ_k ＋ γ h_k(t) ≤ θ_k ＋ h_k(t) ＜ 1.0 ＋ c_k。したがって ã ≥ θ ＋ h̃ で発火する（再評価 §1.4 の式）。∎

**帰結**：右辺は 1.0 ＋ c − θ ≥ 0.52（出生時のばらつきの範囲。再評価 §3.1）で、0014・0016 では誘発の割合が 1.00 だった【既存の結果】。この条件のもとで、その発火は刺激の予定だけで決まり、経験に依る内部の状態を運ばない。**それを行動の源にすると、行動は刺激への決まった反射になる**（K1 で除く）。

#### 2.4.3 世界の規則の恣意性

| 項目 | 恣意性の中身 | 置き方の案（採用ではない） |
|---|---|---|
| 結果の中身 | どの行動がどの刺激を呼ぶか | 刺激は意味のない A・B・C のまま。行動と結果の対応は個体ごとに乱数で割り当てる（K2）。どの対応も「正しい」としない |
| 何もしないとき | 意図がなければ何が起きるか | 何も来ない（世界は意図があるときだけ変わる）を既定にする。別の刺激を既定で出すと、それ自体が新しい予定になる |
| 遅れ | 意図から結果の刺激までの Pulse 数 | 新しく選ぶ値（チェック C1）。命題 G-5 のとおり、遅れが痕跡の時定数（約 6）より長いと、行動の源と結果を受ける Unit の組の書き込みは κ^(L−1) で急に小さくなる。**検出しやすい値を選ぶのではなく**、C0 の世界の時間差（2）に合わせて比較可能性を保つ、などの独立の理由で、結果の前に決める |
| 窓・同時 | いつの意図が結果を持つか、同じ Pulse の複数の意図 | 世界の規則として書く（K6）。同じ Pulse の X と Y は、どちらの結果も起こさない、のような対称な決まりにする |
| 試行の構造 | 手がかりを置くか、自発だけか | §4 の候補ごとに決める |

#### 2.4.4 命題 G-5（行動から結果までの遅れと、書き込みの大きさ）【算術】

行動の源の Unit i が Pulse t に発火し、結果の刺激が t ＋ L − 1 に成立して、それを受ける Unit j が t ＋ L に発火する（ほかの発火がない）とき、その 1 組による w_ij の増加の上限は a κ^(L−1) w_max（N-1 の命題 §3.4 の表と同じ式）。

| L | 2 | 6 | 10 | 30 |
|---|---|---|---|---|
| κ^(L−1) | 0.85 | 0.44 | 0.23 | 0.009 |

- 遅れの選び方は、ループが重みを通して閉じるかに直接効く。だからこそ、結果を見て選ばない

#### 2.4.5 Core の側の恣意性

- 行動の意図を作る部品の形（出力の部品か、新しい出来事の型か）。どちらも Unit の状態を変えないこと（K4）と、乱数の流れを C0 と分けること（チェック C4。足した部品が Birth State の乱数を消費すると、C0 と同じ seed で同じ個体にならない）を契約にする
- 行動の意図の境界 §5 の未決（遠心性コピー、同じ Effector への重なり、強さ・持続）は、最初の G-a では置かない形を勧める（遠心性コピーなし、意図は出す・出さないだけ）。足すたびに新しい自由度になる

### 2.5 ⑤ 失う識別可能性

| # | 失うもの | なぜか | 補う手段（§3） |
|---|---|---|---|
| L1 | **固定した予定の上のラベルの交換可能性**（0023〜0033 の O・M・W の参照） | 感覚の列が個体の状態に依るので、同じ予定を本体ごとに与えるという作りが崩れる | 他者の行動から生まれた列の再生（§3.3 の SD-2） |
| L2 | **経験の外生性**：本体ごとの経験の違いは、実験者が割り当てたものではなく、個体の結果になる | 閉じたループ | ドナーの列で経験の統計をそろえる。経験の数（行動の回数）を補助に記録する |
| L3 | **N-1 の命題 R1-3 の前提**（後の感覚の列が同じ） | 行動で感覚の列が分かれる | 入れ替えを問うなら、感覚の列を固定した本体（開いたループ）で行う。閉じたループの入れ替えの効果は、世界を通した経路を含む「全体の効果」で、別の推定対象になる |
| L4 | **小さな違いの扱いやすさ** | 帰還で小さな違いが増幅されうる。決定論の軌道が周期に固まる、まったく行動しない、などの退化した型もありうる | 退化した型（ループが閉じない個体）を事前に定義して数える（§3.5、総括 E14） |
| L5 | **0028〜0033 の結果との直接の比較** | 経験の分布が変わる | 外挿しない。出口を外した本体で C0 の条件を再現できた場合だけ比較の基準にする（総括 E13） |

**残るもの**：Unit・可塑性の局所の更新規則の式だけを前提とする命題（総括 §6.1 の理由 3）、Birth State の個体間の独立、出口を外した本体が C0 に一致すること（命題 G-1）。

## 3. N-4：閉じたループと開いたループ、C0 との比較、行動で経験が変わる場合の統計

### 3.1 命題 G-1（開いたループへの還元）【命題（前提つき）】

**前提**：(a) G-a で足すのは行動の意図を作って Effector へ渡す経路だけで、Unit の状態の更新・可塑性・接続・Birth State の作り方（乱数の流れを含む）は変えない。(b) 意図の発生は、Environment と Receptor を通る以外に Unit へ何も返さない（AI3・AI6）。(c) 世界が意図を無視する（または出口を外す）。(d) 感覚の予定は C0 の実験と同じ。

**主張**：同じ seed の個体について、G-a の本体の軌道（全 Unit の状態・重み・痕跡・発火）は C0 の本体の軌道と一致する。

**証明**：再評価 §1.3・§1.4 の更新は、Unit の状態、届いた駆動（発火と Receptor の出来事 × 重み）、値だけで決まる。(a)〜(d) のもとで、どの Pulse でもこれらが C0 と同じなので、帰納法で軌道は一致する。∎

**帰結**：この一致は**契約テスト**（合成の seed で、C0 の道具の軌道とビット単位で同じか）で確かめるもので、知見ではない。総括 E13 の「旧 C0 の条件の再現」は、まずこの意味で満たす。

### 3.2 命題 G-2（同じ出生時の状態の本体に、元の感覚の列を再生すると、元と同じ軌道になる）【命題】

**前提**：閉じたループの本体 M（ある個体、ある規則）が、ある区間で感覚の列 S_M を受けた。同じ個体（同じ Birth State）の本体 Y は、出口を外し、S_M を固定の予定として受ける。

**主張**：Y の軌道は、その区間で M と一致する。M で行動の意図になった内部の出来事も、Y で同じ Pulse に起きる（Y では結果を持たないだけ）。

**証明**：Pulse 1 で Y と M の状態は同じ（同じ Birth State）。各 Pulse で、両者に届く感覚の出来事は S_M で同じで、状態も同じなら、次の状態も同じ（決定論の更新、命題 G-1 の (a)(b)）。帰納法。∎

**帰結**
- **同じ個体の「感覚の yoke」（同じ列の再生）は、閉じたループの対照にならない**。差は構成上 0 である
- 遠心性コピーなどの別の経路がない決定論の脳では、**閉じたループの効果は、実現した感覚の列の効果に尽きる**。「自分が起こした」ことを、同じ列を受けた場合と区別する手段は脳の中にない
- したがって、ループの効果は**反実仮想**で定義する：「自分の状態から生まれた列」と「別の列」を、同じ個体で比べる（§3.3）
- この「yoke」は、0021・0022 の yoke（自分の発火による可塑性を相手の発火による駆動に置き換える）とは別の操作である（`docs/natural-history-plasticity-feedback-theory.md`）。この文書では「感覚の列の再生」と呼ぶ

### 3.3 統計の設計の候補【候補】

#### SD-1：同じ個体で、規則を反実仮想として替える

- 的の個体の本体 M（行動に応じる規則）と、同じ個体の 19 本体（結果が行動に依らない規則：結果の刺激が、事前の乱数の予定で来る）を比べる
- 弱点：M の列は M 自身の状態から生まれ、参照の列は独立の乱数の予定なので、「ループの効果がない」場合でも、列の統計（間隔の分布・数）が系統的に違いうる。交換可能性の帰無仮説が、ループの効果の有無と別の理由で破れやすい

#### SD-2：別に用意したドナーが自分の行動で作った列を、的の個体に再生する（推奨の形）

- **的の個体 i** ごとに
  - M_i：個体 i の、閉じたループの本体（規則 R）
  - **ドナー D_i1〜D_i19**：別の seed の個体を、同じ規則 R の閉じたループで走らせ、それぞれの実現した列 S_ij を得る。ドナーは的にも参照にも使わず、的の個体ごとに重ならない（個体間の独立を保つため）
  - **参照 Y_ij**：個体 i の本体（同じ Birth State）で、出口を外し、S_ij を固定の予定として受ける
- **試しの区間**：ループの区間の後、全本体を同じ条件（結果を止めた区間：外からの入力がない区間、または手がかりだけの区間）に置き、統計 T を測る。行動と結果の対応そのもの（規則が決める量）は T にしない（命題 G-4）
- **事象**：T(M_i) が {T(Y_ij)} の外（向きは事前に決めるか、向きを問わない形）
- **帰無仮説 H^loop**：個体ごとに、(T(M_i), T(Y_i1), …, T(Y_i19)) が交換可能。言い換えると、**「受けた列が自分の状態から生まれたこと（自分の状態と列の結びつき）」が T に効かず、M_i の列 S_i は、同じ規則のもとで別の個体が作った列 S_ij と同じに振る舞う**。個体は独立・同一分布（Birth State）なので、S_i と S_ij は周辺の分布として同じであり、この仮定は「結びつきが効かない」ことの統計モデル上の表現になる。強い仮定で、0023〜0033 と同じく統計モデルの仮定として置く
- **上界**：H^loop のもとで、個体ごとの事象の確率は、向きを決めた事象（20 個のうちの厳密な最大）なら 1／20 以下、向きを問わない事象（どちらかの端）なら 1／10 以下。個体間の独立から、判定の閾値は 0028〜0031（向きつき）・0029 の U（向きなし）と同じ形で決まる
- **棄却の意味**：同じ個体・同じ規則・同じ試しのもとで、**自分の行動から生まれた列を受けた本体が、他者の行動から生まれた同じ種類の列を受けた本体と比べて、T で典型的でなかった**。これは、命題 G-2 で「ループの効果」と定めた、自分の状態と経験の列の結びつきの効果である
- **棄却しても言えないこと**：因果を「理解した」こと、価値・好み・意味、どの内部の担い手か（C-III）
- **C-II の整理との対応**：参照の列を、的とは別のドナーから取るのは、C-I^own で交換に使うドナーの集まり 𝒬 を的の集まり 𝒯 から分けたのと同じ考え方で、帰無の上界と個体間の独立を保つための形である
- 計算の量【予想】：的の個体ごとに、M_i が 1 本、ドナーが 19 個体（各 1 本）、参照が 19 本で計 39 本体。C0 の本体の長さ（25500 Pulse 程度）なら、0033 の 1 個体（自然 26 本 ＋ 混成 745 本、混成は約 12000 Pulse）より小さい見込み

#### SD-3：AS2 の対応を個体の中で入れ替える（後の候補）

- §4 の AS2 で、行動と結果の対応を同じ個体で「そのまま」「入れ替え」の 2 通りにし、向きの予測（前者は自己強化、後者は交互になる）を可塑性の式から事前に導けるなら、向きつきの判定にする
- 予測は【予想】で、まだ導いていない。導けない限り、SD-3 は置かない

### 3.4 命題 G-4（規則が決める統計は、証拠にならない）【命題】

閉じたループの本体で、自分の意図とその後の結果の刺激の対応から計算する統計（例：X の後に B が来た割合）は、意図の列が決まれば、世界の規則で決まる。∎（定義から）

- チェック A1 の形（判定の量の符号が、介入の定義で決まっている）である。T には使わない
- 意図の列そのものの統計（行動の頻度・偏りの時間の変化）は規則で決まらないが、列の効果と混ざる。SD-2 の参照と比べて読む

### 3.5 ループが閉じない個体と、凍結（総括 E14）

- 行動の源の Unit が、その世界の入力のもとで発火しなければ、意図は出ず、結果も来ず、ループは閉じない。AS1 では、行動の源の Unit の入口に刺激が来ない。孤立した Unit として見れば、出生時の余裕 g ＜ 0 なら自発には発火しない（出生時のばらつきで約 23%）。ほかの Unit からの駆動を含めると、構造的な層（g ＜ −0.03。7.5%）は C0 の主の区間の条件で発火しない（N-1 の命題 R1-9）が、条件付きの層は相手しだいである【既存の命題（C0 の条件）】
- G-a の世界では、結果の刺激は意図の後にしか来ないので、無入力の場合の命題がそのまま当てはまる区間と、当てはまらない区間がある。**その世界の入力の条件で、沈黙の十分条件を先に立て直し**（総括 E14）、出生時の状態から該当する個体の割合を結果の前に計算する
- ループが閉じない個体は、分母に残す（後から除かない）。そのような個体で事象が成り立つことの意味（自分の状態が「行動しない」経験を作った）を、事前登録で書く
- 命題 5（C-II の整理 §7）の形の、ラベルについて対称な適格の条件を置くかは【未決】

### 4.1 AS1 を最初の候補にする理由

1. **一度に一つの変更**（総括 E20）：AS1 で足すのは「自分の発火が、自分の経験の時刻を決める」ことだけである。AS2 は、それに選択・競争・対応・窓を足す
2. **C0 と形が近い**：C0 の O では、A の誘発された発火の 2 Pulse 後に B の誘発された発火が来た（刺激は s_k と s_k ＋ 2、発火は s_k ＋ 1 と s_k ＋ 3）。AS1 で L ＝ 2（意図の次の Pulse に結果の刺激）にすると、「自分の発火の 2 Pulse 後に B の発火」になる。1 Pulse の順序（再評価 §1.3：Effector への作用はその Pulse の終わり、感覚の出来事は次の Pulse の初め）のもとで、これは実現できる最も短い遅れである。違いは、時刻が予定で決まるか、自分の状態で決まるかだけである。比較可能性のために L ＝ 2 を選ぶのは、検出のしやすさとは別の理由である（§2.4.3）
3. **決められた反応にならない**：行動の源の Unit の入口には刺激を来させないので、その発火は自分の位相・順応と重みで決まる（K1）
4. **戻せる**：出口を外せば C0（入力の予定を与えれば C0 の実験）に戻る（K4）

### 4.2 AS1 の弱点（事前に書くこと）

- 行動の源の Unit の余裕が負なら、ループが閉じない個体が出うる（§3.5。G-a の世界での十分条件は立て直しが要る）
- 選択がないので、原則 §6 の 6 の「X なら B、Y なら C」の分岐は問えない（AS2 の段で問う）
- ループの効果が小さい見込みがある【予想】：AS1 では、ループは結果の刺激を受けた Unit から行動の源へ戻る重み（1 回あたり高々 w_max）を通して、行動の源の次の発火の時刻に効く。その大きさは C0 の命題からは導いていない

## 10. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次の脳の第一候補は、「今の脳（C0）の中身はそのままにして、外へ働きかける出口と、その行動で次に来る刺激が変わる世界を足す」形です。今回は、それで何ができるようになり、何が分かりにくくなるか、これまでの C0 とどう比べるかを、実験の前に整理しました。

### 大事な点

1. **「決まった反応」にしない**：刺激を受けた部品は、すぐに必ず反応します。その反応を「行動」にすると、刺激にただ反射するだけになります。そこで、行動は、刺激を直接受けていない部品の、自分のリズムと経験で決まる動きから出すことにしました
2. **どの部品がどの行動を出すかに、意味を持たせない**：個体ごとにくじで割り当て、行動には「X」「Y」のような名前しか付けません
3. **比べ方の落とし穴**：今の脳は、同じ生まれの個体に同じ刺激の列を与えれば、まったく同じに動きます。そのため、「自分の行動で生まれた刺激の列」を同じ個体にもう一度見せても、何も違いが出ません。そこで、**別の個体が自分の行動で作った刺激の列を見せた場合**と比べることにしました。違いが出れば、「自分の状態から自分の経験が生まれたこと」の効果と言えます
4. **最初の形の候補**：ある部品が自分のリズムで動くと、少し後に別の刺激が来る、という一番小さな形（AS1）から始めるのがよいと考えます。「X なら B、Y なら C」のような選択のある形（AS2）は、その次です
