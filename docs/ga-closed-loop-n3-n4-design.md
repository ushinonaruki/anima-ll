### 0.2 結論の先取り

1. **G-a の中身**：C0 の Unit の力学・可塑性・入口はそのままにして、(i) 内部の出来事から行動の意図（ActionIntent）が生まれる出口と、(ii) その意図に応じて次の感覚の出来事を決める世界の規則を足す（§1）。**今の素の C0 と設計図だけでは、行動の意図は生まれない**（発火は Effector に届かず、relay は中身のない感覚から何も出さない：監査 007）。何らかの新しい意図の生成の機構が要る。それを Core の境界の変更で作るか、既存の拡張の口（`unit_overrides` など）に足す部品で作るかは比べる対象で、どちらも未実装・未承認である
2. **N-3（何が可能になり、何を失うか）**（§2）
   - 可能になること：自分の内部の状態が自分の後の経験を決める、という因果（原則 §6 の 6、R6）を、価値なしで問えるようになる。脳の状態に触れない介入（出口の切断・列の付け替え・規則の入れ替え）を得る
   - **恣意性の中心は、どの内部の出来事を行動の意図とするか**。意図の作り方の形を I1〜I4 に分けた（§2.4.2）。どの形も実験者が決める配線・規則で、「自然に生じた行動」とは呼ばない。基準 K1〜K6 は設計上の制約で、満たしても内発の行動・学習の証明にはならない
     - K1：直前の刺激に入口で直接駆動された Unit の、次の Pulse の発火を行動の源にしない。C0 の条件（不応期 0）では、順応が十分小さければその発火は必ず起きるから（命題 G-3）。ただし、これは直接の反射を除く制約で、ほかの経路の感覚の駆動は残る
     - K2：Unit と行動の ID の対応は個体ごとに乱数で割り当て、意味の名前を付けない。ただし、乱数の割り当ても**実験者が与えた固定の配線**で、恣意性を個体に分散させるだけである
   - 失う識別可能性：固定した予定の上のラベルの交換可能性、経験の外生性、R1-3 の前提、小さな違いの扱いやすさ、0028〜0033 との直接の比較、感覚と運動の区別（3 Unit では役が重なる：監査 008）
3. **N-4（どう比べるか）**（§3）
   - 命題 G-1：出口を外して C0 の予定を与えれば、C0 と同じ軌道になる（契約テストで確かめる）
   - 命題 G-2：同じ出生時の状態の本体に、元の本体が受けた感覚の列を再生すると、元と同じ軌道になる。**同じ個体の再生は対照にならない**。これは再生した入力のもとで軌道が同じということで、閉じたループの反実仮想の効果（別の列を受けたら違う）が 0 という意味ではない
   - **SD-2**（ドナーの行動から生まれた列を的の個体に再生する参照）の順位の判定が棄却するのは、**交換可能性の形式の仮説 H^rank** である。生まれつきのリズムと自己の列の対応だけでも、学習なしに H^rank は破れうる（§3.3 の反例）。したがって SD-2 は「内生的な自己の列と他者の列での反応の非対称」を調べる**探索の候補**にとどめ、**行動の帰結の学習を主張するには、可塑性を止めた対照などの別の比較**（§3.4 の LC1〜LC4）を、帰無の条件とともに別に設計する
   - 規則が決める統計（自分の意図の後に結果が来た割合など）は証拠にならない（命題 G-4）
4. **最小の候補**（§4）：AS1「自発の 1 つの行動」を、**閉ループの構造（意図 → 世界 → 感覚の経路の成立、経験の列の内生化、状態依存の帰還）を検証する最初の候補**として残す。AS1 で示せるのはそこまでで、行動の選択や行動の帰結の学習（R6 の研究の目的、MF9 後半）は別の問いと設計が要る。AS2・AS3 で何を示せるかも §4.2 の表に並べた
5. **今回は t-k さんに構成の判断を求めない**（§6）。判断をお願いするのは、AS1 と AS2 で何を示せるか、学習を主張するには何が要るかを、レビューで確かめた後にする

## 1. G-a とは何か

### 1.1 最小の定義

- **脳**：C0（研究用の設計図。3 Unit、可塑的な接続 6 本、入口は Receptor → Unit の 1 対 1）。Unit の力学・可塑性の規則・値・Birth State の作り方は変えない
- **出口**：ある内部の出来事（§2.4 で選ぶ）が成立したとき、行動の意図 X（または X・Y）が生まれ、Runtime が記録して Effector に渡す（AI1〜AI4）。意図の発生は Unit の状態を変えない。結果は Receptor からだけ戻る（AI6）
- **世界**：行動の意図に応じて、後の感覚の出来事（どの Receptor に、いつ来るか）を決める規則。規則は事前に登録し、「正しい行動」を埋め込まない（原則 §8 の 4）

```text
内部の状態（活動・接続・痕跡）
   ↓（§2.4 で選ぶ内部の出来事：実験者が決める配線・規則）
行動の意図 X（Neuroarchitecture の中で成立。AI1）
   ↓ Runtime：記録して渡す（選ばない。AI4）
Effector：外界に作用する（選ばない。AI3）
   ↓
世界の規則：次の感覚の出来事を決める（原則 §8 の 4 の監査の対象）
   ↓ Receptor
内部の状態が変わる（可塑性を含む。規則は C0 のまま）
```

### 1.2 今のコードとの関係（段ごと。監査 007）

| 段 | 今あるもの | ないもの |
|---|---|---|
| 内部の出来事 | Unit の力学と発火（`SimpleActivityDynamics`、ActivityEvent）。発火は、送り手からのすべての接続に伝わる | — |
| 意図の生成 | 出力の部品の差し込み口（`UnitOutput`）。`DeltaKind.INTENT` という列挙値。`bootstrap.build_application(..., unit_overrides=..., effector_overrides=...)` の拡張の口 | **Neuroarchitecture 由来の行動の意図を作る機構**。研究用の設計図の 3 Unit は relay で、relay は新しく届いた中身を転送するだけ。C0 の感覚の出来事は中身がないので、何も出さない。ActionIntent の独立のモデル・発生の規則もない |
| 配送 | `PulseRuntime` は、Effector 宛ての `ProposedDelta → StateDelta` を `EffectorDispatcher` に渡す | 発火を Effector へ届ける経路。これは**活動の伝達の仕様 §7 で作らないと固定されている**（`ProjectionRouter.route_activity` も Effector を除く）。発火 → Effector の経路は、AI1 の「内部の状態 → ActionIntent → Effector」を迂回する別の行動の経路になるから |
| 外界への作用 | Effector の差し込み口（console・recording の実装） | 研究用の世界の中で、意図に応じて状態を変える Effector・世界の規則 |
| 感覚としての戻り | 予定された Receptor（`ScheduledReceptor`。実行の前に protocol から作る） | 行動に応じて出来事を作る Receptor |

- したがって、YAML に Effector を足すだけでは行動の意図は生まれない。**何らかの新しい意図の生成の機構の実装が要る**
- その機構を、(i) Core の境界の変更（ActionIntent の型と経路）で作るか、(ii) 既存の拡張の口（`unit_overrides` で差し込む Unit・出力の部品、`effector_overrides`、研究用の世界の Receptor）で作るかは、比べる対象である。どちらも、AI1〜AI10 と活動の伝達の仕様 §7 を破らないこと、命題 G-1 の前提（Unit の状態・乱数・駆動に干渉しない）を満たすことを契約テストで確かめる必要がある【未決】
- どちらも実装しない。構成の変更として t-k さんの承認が要る

## 2. N-3：何が新たに可能になり、何を失うか（再評価 §5 の 5 つの観点）

### 2.1 ① 独立した原理的な必要性

- 原則 R6（行動の意図は内部の状態から出る。外へ作用する出口があり、その結果が次の内部の状態を変える閉じたループ）は、採用済みの内部表現の契約である【既存の命題】
- 原則 §6 の 6（行動の意図を実際に閉じたループへつなぐ。自分の行動が未来の感覚を変えるという因果を学べるか。どちらが「よい」かは決めない）は、合意した順番の一段である
- 行動の意図の境界（AI1〜AI10）は、この段のために先に決めてある（原則 §6 の 2）
- 症状を直すための変更ではない（恣意性の台帳 §2.2 の問い 1・2）：C0 の否定的な結果を直すためではなく、C0 では対象がない段を問うために足す

### 2.2 ② 既存の構造でできないこと

- N-1 の命題 R1-2：C0 の感覚の列は（protocol、seed、札の列）だけで決まり、脳のどの状態にも依らない【既存の命題】
- これは「出口がないので行動として実現しない」という主張で、「内部に情報がない」ではない（N-1 の命題 §3.2）

### 2.3 ③ 新たに可能になること

| # | 新たに可能になること | 何がそれを可能にするか | 可能にならないこと |
|---|---|---|---|
| P1 | **自分の内部の状態が、自分の後の経験（感覚の列）を決める**閉じたループの構造を、価値なしで作り、調べられる | 出口と行動に応じる世界 | 「よい」行動の選択、価値・好み（原則 §6 の 7） |
| P2 | 経験に依って変わった内部の状態が、行動（したがって次の経験）に入るかを、**問いとして立てられる**（契約の MF9 後半の最初の形）。答えるには §3.4 の比較が要る | 同上 | 「思い出した」こと・内容を理解したこと（相関と必要性 §1.1） |
| P3 | **脳の状態に触れない介入の手段**：出口の切断、結果の付け替え（ほかの列の再生）、規則の入れ替え | 世界の側の操作 | 脳の内部の担い手の特定（C-III は変わらず定まらない） |
| P4 | 個体ごとに違う経験の列が、個体自身の状態から生まれる（経験の内生化） | 閉じたループ | 「個性」「主体性」などの心理の言葉での主張 |

### 2.4 ④ 持ち込む恣意性（中心の問い：行動の意図を内部の活動からどう生むか）

#### 2.4.1 前提：どの形も、実験者が決める配線と規則である

行動の意図を「どの内部の出来事から作るか」は、AI1 が未決とした点で、どの形を選んでも実験者が決める配線・規則になる。**この文書のどの形も「自然に生じた行動」「本人が選んだ行動」とは呼ばない**（監査 007 の ChatGPT の回答）。比べるのは、持ち込む自由度の量、C0 に戻せるか、何を調べられるか、である。

#### 2.4.2 意図の作り方の形（AI1 の選択肢）

| 形 | 内容 | 持ち込む自由度 | 注意 |
|---|---|---|---|
| **I1** 1 つの Unit の発火 → 意図 | 指定した Unit が発火したら、その Pulse に意図 X が生まれる（出力の部品） | どの Unit・どの ID | AI1 は「1 つの Unit の出力部品かもしれない」として許す。ただし実質は**固定の「発火 → 行動」の配線**である。活動の伝達の仕様 §7 は「発火を駆動として Effector に流す」経路を禁じるので、I1 は駆動の経路ではなく、意図の出来事として作る |
| **I2** 窓の中の競合 | 窓の中で、指定した複数の Unit のうち先に発火したものの ID の意図 | 窓・同時の扱い・どの Unit | 同じ Pulse の発火は区別できない（下の監査 009） |
| **I3** 閾値下の状態の読み出し | activity・順応などの状態が、新しく決める値を超えたら意図 | 新しい閾値・関数の形（チェック A6） | 発火だけを読む形が拾わない閾値下の差を読む。その代わり新しい自由度が多い |
| **I4** 時間の積分 | 窓の中の発火の数が k 以上なら意図 | k・窓 | 発火の数（X7）と相対の時刻を分けない |

- **監査 009**：発火のたびに activity は 0 に戻る（hard reset）。同じ Unit が二つの本体で同じ Pulse に発火すれば、それまでの閾値下の activity の差は、そこで消える。したがって、**I1・I2 のように発火だけを読む形では、同時の発火で消える閾値下の差は行動に入らない**。重みの差や、その後の入力の差は残りうる（N-1 の命題 R1-3）。読み出しの定義・観測の時間・精度を、事前に決める
- 最小の候補（§4）は I1（AS1）と I2（AS2）を使う。I3・I4 は自由度が多いので、最初には置かない

#### 2.4.3 基準 K1〜K6（設計上の制約）

どれも、C0 の命題と原則から導いた**設計上の制約**で、結果を見て選ぶものではない。**満たしても、行動が内部から生じたことや、学習が起きたことの証明にはならない。**

| # | 基準 | 何を除き、何を除かないか | 出どころ |
|---|---|---|---|
| **K1** | 直前の刺激に入口で直接駆動された Unit の、次の Pulse の発火を、行動の源にしない | **除く**：入口の直接の反射（命題 G-3）。**除かない**：ほかの Unit の感覚に誘発された発火が、接続を通して行動の源に届く間接の駆動（§2.4.6）、結果の刺激からの帰還。直接に刺激された Unit の発火が経験と無関係だということも示さない（順応 h が条件を満たすかは過去の活動に依る） | 命題 G-3、ChatGPT の指示（決められた反応にしない） |

## 3. N-4：閉じたループと開いたループ、C0 との比較、行動で経験が変わる場合の統計

### 3.1 命題 G-1（開いたループへの還元）【命題（前提つき）】

**前提**：(a) G-a で足すのは、行動の意図を作って Effector へ渡す機構だけで、Unit の状態の更新・可塑性・接続・Birth State の作り方（乱数の流れを含む）は変えない。(b) 意図の発生は、Environment と Receptor を通る以外に Unit へ何も返さない（AI3・AI6）。(c) 世界が意図を無視する（または出口を外す）。(d) 感覚の予定は C0 の実験と同じ。

**主張**：同じ seed の個体について、G-a の本体の軌道（全 Unit の状態・重み・痕跡・発火）は C0 の本体の軌道と一致する。

**証明**：再評価 §1.3・§1.4 の更新は、Unit の状態、届いた駆動（発火と Receptor の出来事 × 重み）、値だけで決まる。(a)〜(d) のもとで、どの Pulse でもこれらが C0 と同じなので、帰納法で軌道は一致する。∎

**帰結**：前提 (a)(b) は実装が満たすべき条件で、**契約テスト**（合成の seed で、C0 の道具の軌道とビット単位で同じか。意図の発生が乱数・Unit の状態・可塑性・届く駆動に影響しないか）で確かめる。知見ではない。

### 3.2 命題 G-2（同じ出生時の状態の本体に、元の感覚の列を再生すると、元と同じ軌道になる）【命題】

**前提**：閉じたループの本体 M（ある個体、ある規則）が、ある区間で感覚の列 S_M を受けた。同じ個体（同じ Birth State、同じ初期条件）の本体 Y は、出口を外し、S_M を固定の予定として受ける。外からの入力の出来事は S_M だけ。

**主張**：Y の軌道は、その区間で M と一致する。M で行動の意図になった内部の出来事も、Y で同じ Pulse に起きる（Y では結果を持たないだけ）。

**証明**：Pulse 1 で Y と M の状態は同じ。各 Pulse で、両者に届く感覚の出来事は S_M で同じで、状態も同じなら、次の状態も同じ（決定論の更新、命題 G-1 の (a)(b)）。帰納法。∎

**帰結**
- **同じ個体の「感覚の列の再生」は、閉じたループの対照にならない**。差は構成上 0 である
- これは、**再生した入力のもとで軌道が同じ**ということで、**閉じたループの反実仮想の効果が 0 という意味ではない**。M が別の行動をしていれば別の列を受け、軌道は違った
- 遠心性コピーなどの別の経路がない決定論の脳では、「自分が起こした」ことを、同じ列を受けた場合と区別する手段は脳の中にない。ループの効果は、**別の列**を受けた場合との反実仮想で定義する（§3.3・§3.4）
- この「再生」は、0021・0022 の yoke（自分の発火による可塑性を相手の発火による駆動に置き換える）とは別の操作である

### 4.3 AS1 を最初の閉ループの検証の候補にする理由と、その射程

1. **一度に一つの変更**（総括 E20）：AS1 で足すのは「自分の発火が、自分の経験の時刻を決める」ことだけである。AS2 は、それに選択・競争・対応・窓を足す
2. **C0 と形が近い**：C0 の O では、A の誘発された発火の 2 Pulse 後に B の誘発された発火が来た。AS1 で L ＝ 2（意図の次の Pulse に結果の刺激）にすると、「自分の発火の 2 Pulse 後に B の発火」になる。1 Pulse の順序（再評価 §1.3）のもとで、これは実現できる最も短い遅れである。比較可能性のために L ＝ 2 を選ぶのは、検出のしやすさとは別の理由である
3. **直接の反射にならない**：行動の源の Unit の入口には刺激を来させない（K1）。ただし、間接の駆動と帰還は残る（§2.4.6）
4. **戻せる**：出口を外せば C0 に戻る（K4）
5. **射程**：AS1 で検証できるのは、**単一の内生的なタイミングを持つ閉ループの実装と、状態依存の帰還**までである。最初の G-a の「認知の成功」の判定や、「自分の行動の因果を学んだ」ことと等しくしない。行動の選択・行動の帰結の学習は、AS2 以後と §3.4 の比較で、別の問いとして設計する

### 4.4 AS1 の弱点（事前に書くこと）

- 行動の源の Unit の余裕が負なら、ループが閉じない個体が出うる（§3.6）
- 選択がないので、原則 §6 の 6 の「X なら B、Y なら C」の分岐は問えない
- ループの効果が小さい見込みがある【予想】：帰還は、結果の刺激を受けた Unit から行動の源へ戻る重み（1 回あたり高々 w_max）を通して、行動の源の次の発火の時刻に効く。その大きさは C0 の命題からは導いていない
- 行動の源の発火の、自発・間接の誘発・帰還への分け方は一意でない（§2.4.6）
