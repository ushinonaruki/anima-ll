## 1. 問いの形

### 1.1 比べるもの

- 同じ出生時の状態 b から、経験の条件だけが違う個体を作る（K1）。経験の後は、どの個体も**状態を入れ替えずに**自然に進める
- 試しは 0014 と同じく、**本体の複製の上でだけ**行う（試しの元：本体の t0 − 1 の終わりの状態の複製。試しは本体の未来を変えない）
- 試しの入力：t0 に Receptor A の出来事を 1 つ（0014 と同じ）。読み出しの対象：B・C の活動

### 1.2 L2 として何を主張するか

- 主張の形：**「この世界・この設計図・この規則のもとで、順序のある経験の後の自然な状態は、同じ試しに対して、順序に特有の違う活動を生んだ」**
- 言わないこと：その違いを重みが運んだ、経験した順序の内容を思い出した（L3）、自発に現れた（O-N）、記憶した

## 2. L2 を自明にしないための比較の基準

### 2.1 命題 1（O と単独の S の差だけでは、O という並べ方が特別とは言えない）【命題】

順序ありの経験 O と、同じ刺激の時刻・数で札だけを並べ替えた経験 S（0014 の shuffled）を比べるとする。読み出し R について R(O) ≠ R(S) が観測されたとする。

- このことは、**「札の並べ方の違いが R に効いた」**ことを示すが、**「順序ありという並べ方が特別だった」**ことは示さない。S を別の並べ替え S′ に替えても R(S′) ≠ R(S) となりうるからである
（証明：定義から。「O が特別」という主張は、O と S の比較だけでなく、S と同じ種類の別の経験との比較を含む。O と S の違いだけでは、その比較の片方しか観測していない。）

**この命題が言うのはここまでである**。「特別さ」をどう操作的に定めるかは命題からは決まらず、次の §2.2 の参照分布は、そのための**設計の候補の一つ**である（唯一の方法でも、論理的に必要な方法でもない）。

**意味**：
- 決定論的な個体では、違う履歴の後の状態は一般に違い（P0 は満たされやすい）、どの読み出しにも違いが出うる。0022 で、違う経験をした自然な 2 個体の自発の発火が 98／100 個体で W の初めから分かれたことは、履歴の違いが活動の違いに出やすいことの一例である（O-N の観測で、O-P についての証拠ではない）
- そこで、**L2 の主の比較を「O と S の差 ≠ 0」ではなく、「O が並べ替えの参照分布の典型を外れるか」**にすることを提案する【候補。設計の選択】
- これは、1 つの決定論的な個体の中で偶然の大きさを見積もれない問題（識別のメモ U9、契約 X9）への一つの対処でもある。個体ごとに、同じ出生時の状態から並べ替えを K 通り作れば、その個体の中で「並べ方の違いがどれだけの差を生むか」の参照ができる

### 2.2 参照分布の作り方と使い方（候補）

- 各個体（出生時の状態 b）について、O と、並べ替え S_1, …, S_K を、別の名前の乱数の流れ（例：`"<実験番号>-shuffle-<i>:<seed>"`。常設チェック C4 の形）で作る。K は事前登録で決める【未決】
- 量の例：O の値 R(O) と、並べ替えの値の集まり {R(S_i)} から、O の外れ方を順位で表す（R(O) が {R(S_i)} の中で何番目か）。**向きを問わない**（L2）なら、中央からの離れ方の順位を使う
- 個体の割合の判定の基準（例：何個体のうちいくつ）は事前登録で決める。参照を使うことで、「並べ方の違いはいつも何かの差を生む」ことと「順序ありが特別」とを分けることを狙う
- **参照の使い方を事前登録で決める**【未決】：
  - **記述として使う**：O の順位をそのまま報告し、判定は「順位が上位（または下位）のある範囲に入る個体の割合」のような事前の基準で行う。確率の解釈は付けない
  - **統計の判定として使う**（順位から確率の値を出すなど）：「O の値は並べ替えの値と同じように分布する」という帰無仮説のもとで、R(O) と R(S_1)〜R(S_K) が**交換可能**であることを前提にする。並べ替えどうしは同じ出生時の状態から独立な乱数の流れで作るので互いに交換可能だが、O は特定の構造を持つ 1 つの並べ方で、ランダムに引いたものではない。交換可能性は O について保証される性質ではなく、帰無仮説の置き方そのものである。個体をまたいでまとめる方法（個体ごとの結果を数えるのか、確率の値を合わせるのか）も前提とあわせて決める

### 2.3 規則性と順序を分ける：鏡の条件（候補）

O と並べ替えは、**順序だけでなく規則性**（試行ごとに A・B・C が同じ時間配置で来ること）も違う。並べ替えより O が外れたとき、それが「A の直後に B が来る」順序によるのか、規則的な時間配置による位相の引き込み（契約 X5）によるのかは分からない。

- **鏡の条件 M**：O と同じ規則性で、B と C の役を入れ替える（試行 k で A を 1 ＋ 60k、**C を 2 Pulse 後、B を 30 Pulse 後**）【候補】
- O と M は、規則性・刺激の数・時刻の集合が同じで、**A の直後に来るのが B か C か**だけが違う。O と M の違いは、**Unit の役に依存しない単純な規則性だけでは**説明できない
- **ただし、学習された順序の証明にはならない**。O と M では、同じ時刻に刺激される Unit が違う（O では試行の +2 に B、M では C）。B と C は出生時の状態・内在の周期が違うので、**学習がなくても**、Unit の個性・内在の周期・位相の引き込みと入力の時刻の相互作用で、O と M に違いが出うる（契約 X5）
- ただし B と C は出生時の状態が違う Unit なので、O と M の違いには、順序と Unit の個性の相互作用も入る。役と Receptor の対応を 0014 と同じく回す（`(seed − 1) mod 6`）ことで、特定の Unit の個性への偏りを個体のあいだで散らす
- M は新しい経験の条件である（今の Receptor のまま、時間配置だけを変える）。世界・設計図・規則は変えない
- **M は補助の対照にとどめる**【候補】。学習による違いと学習なしの違いを分けるには、学習なしの対照（契約 K7：結合のない基準、または可塑性を止めた条件）で O と M を比べることが考えられるが、どちらも設計図の変種か継続する操作（ℐ-2）になり、扱いは【未決】（§10）

### 2.4 向きを問わない L2 と、向きのある主張を分ける

- 向きを問わない L2：O が参照を外れる（どちらの向きでもよい）
- **向きのある主張**（例：O では A の後に B 側が C 側より強く応じる）は、読み出しが**経験した順序に対応する**という主張で、対応の規則を結果の前に置く必要がある（識別のメモ §5.3 の L3 の形）。0012 の H1 はこの形だった
- 主の評価は向きを問わない L2 にし、向きのある主張は補助、または別の主張として扱う【候補】。補助の向きが合っても、主の L2 の不成立を救わない

## 3. 読み出し R の候補（項目 (1)(2)）

### 3.1 対にした試し

試しの元（本体の t0 − 1 の終わりの状態）から、**2 つの複製**を作る【候補】。

- **A の複製**：t0 に A の出来事を入れる（0014 の試しと同じ）
- **空の複製**：t0 に何も入れない（自然な状態のまま進める）

どちらも同じ状態から始まるので、2 つの違いは**試しの入力の有無だけ**から来る（研究④ §1.3 の「試しの操作」で、状態への介入 ℐ ではない）。

**命題 2（対にした読み出しは、試しの入力の因果効果を、その時点の自然な状態の上で測る）【命題】**：決定論的な個体で、A の複製と空の複製は t0 の入力だけが違う。したがって、2 つの複製の B の活動の違いは、すべて t0 の A の入力の効果（その時点の自然な状態を背景とした効果）である。試しの入力によって変わらなかった B の発火（試しに関係ない自発の発火を含む）は、2 つの複製で同じなので差に入らない。

（証明：状態の十分性（識別のメモ 命題 3.1）。t0 − 1 の状態が同じで、入力の列は t0 だけが違う。）

**意味**：
- 0014 の as_is の R（A の複製だけの B(t0 ＋ 2) − C(t0 ＋ 2)）は、**B・C の試しに関係ない自発の発火も含む**。O と S で B・C の自発の位相が違えば、それだけで R が違いうる。対にすれば、その部分を差し引ける
- 対にした読み出しで O と S を比べることは、「経験が、**試しの入力の効果**をどう変えたか」を問うことになる。これは、MF3 の ①「後の試しへの反応が経験で違う」にそのまま当たる

## 4. 主の評価と補助の評価（項目 (4)）

### 4.1 規則【候補】

1. 主の評価は **1 つ**（読み出し・比較・判定の基準の組）を事前登録で決める

3. すべての主・補助の結果を報告する。補助で見えたことは、次の事前登録の仮説の材料にとどめる
4. **既に見た値を開示する**：R1（0014 の as_is）と、0012 の H1 の読み出しの自然な値は、既に見ている。どれを主にするかの判断がそれに影響しうるので、事前登録にその事実を書く

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を準備したか

これまでの実験でつながりの違いが反応を変えると確かめたのは、ほとんどが「中のつながりを人の手で入れ替えたとき」でした。次は、**何もいじらないふつうの状態**で、経験の違いが反応に出るかを確かめたいと考えています。そのための確かめ方を、実験の前に決めておくための整理です。

### 大事な工夫

1. **「違いがある」だけでは足りません。** 違う経験をした個体どうしは、どこかが違ってくることがよくあります。そこで、順番どおりの経験（A → B → C）を、順番をばらばらにした経験いくつかと比べ、「ばらばらの経験どうしの違い」よりも目立って違うかを見ます
2. **「規則正しさ」と「順番」を、できる範囲で分けます。** 順番どおりの経験は規則正しくもあるので、B と C の役を入れ替えた、同じくらい規則正しい経験とも比べます。ただし B と C はもともと性質の違う部品なので、それで違いが出ても、「学習で順番を覚えた」証拠にまではなりません
3. **問いかけの効果だけを取り出します。** 同じ瞬間の状態を 2 つに写し、片方にだけ A を入れて、もう片方はそのままにします。2 つの違いは A を入れた効果だけなので、もともとの自発の動きの違いに惑わされにくくなります
4. **見る場所は先に 1 つ決めます。** 似た測り方をいくつも並べて、うまくいったものを後から選ぶことはしません

### この後

この整理をもとに、実験の事前登録を作ります。ふつうの状態で違いが見えたら、そのあとで、中のどの部分がその違いを運んでいるかを、部分ごとに入れ替えて調べます。
