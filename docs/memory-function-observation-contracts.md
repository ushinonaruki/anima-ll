## 0. 読み方

### 0.1 三つの段階（ChatGPT の指定）

各 MF について、次の三つを分けて書く。**①を示しても②③は自動では成り立たない。②を確かめても、生物と同じ機構が成り立ったとは限らない。**

| 段階 | 検証すること |
|---|---|
| **① 現象** | 過去の経験によって、後の活動・判断・行動が変わるか |
| **② 因果** | その違いが、**経験によって変わった内部の状態**に依存しているか |
| **③ 機構** | 具体的に、どの活動・可塑性・回路の構造によって成り立ったか |

識別のメモとの対応：
- ① は、識別のメモの**現象の問い**（どの内部の状態が生んだかを問わない。§5.1）に当たる。① の中にも、L1（同じ個体の中で似る）・L2（経験の違いで違う）・L3（経験した構造に対応する）の水準があり、L1 ⇏ L2 ⇏ L3（命題 5.1・5.2）なので、**どの水準の主張か**を書く
- ③ は、識別のメモの**機構の問い**（どの成分が「運ぶ」か、「関与する」か。§5.1）に当たる
- ② はその間にある。決定論的な個体では、後の観測はすべて t0 の全状態の関数である（識別のメモ 命題 3.1）。したがって ② の問いは「内部の状態に依存するか」ではなく、**「経験による内部の状態の違いが、後の違いを生んだか」** と書く必要がある。ここで「出生時の状態・外部の記録 D・固定された規則 F ではなく」とは、**F だけ、D だけ、出生時の状態の違いだけでは、履歴の違いによる後の違いを説明できない**という意味である（F は応答の法則として常に関与するので、「F が関与しない」という意味ではない）。これは ChatGPT の指定を、識別のメモに合わせて具体化したものである。② の具体的な形は §1.1 に書く

### 0.2 札

| 札 | 意味 |
|---|---|
| **【要件の候補】** | 検証のために採用することを提案する方法の要件。模型から導いた定理ではない（識別のメモの【要件】と同じ扱い）。**この文書では正式に採用しない** |
| **【命題】** | 書いた前提のもとで証明できること（既存の文書の命題を引く場合は出どころを書く） |
| **【既存の結果】** | 0012〜0022 の実験で、事前登録した基準のもとで得られた結果（再評価 §2.1 の値だけを引く） |
| **【未決】** | この文書では決めない |
| **〔構成要素：観測〕** | MF の働き全体ではなく、その**構成要素**（重みの差ができる・残る、など）についての観測の証拠 |
| **〔構成要素：介入〕** | 構成要素についての、選んだ背景のもとでの介入の証拠（重みの差が標準化した試しへの応答を変える、など） |

**二層の区別**（ChatGPT の指定）：**構成要素について〔観測〕〔介入〕の証拠があること ≠ MF という能力の段階 ① ② が確認できたこと**。§2・§4 では、現行 3 Unit の結果を、まず構成要素の証拠として書き、MF の段階は別に書く。先行の結果を否定するものではなく、確かめた因果関係を、記憶の働きの達成と混同しないための区別である。

### 0.3 契約の位置づけ（識別のメモ §0.1 を引き継ぐ）

- この文書の観測量・対照・水準は、**研究者の側の観測・識別の契約**である。AnIma-ll が学習して持つ内部の意味や行動の規則ではない
- 対照の操作（状態の複製・移植、可塑性の停止、yoke、外部の記録の遮断など）は、**因果を識別するための人工の介入**で、自然な個体に組み込む機構ではない
- **結果を見て選ばない**：観測量・時間の区間・対応の規則・成功の判定（置くかどうかを含む）は、結果の前に決める
- **契約を満たさないことは、現象がないことではない**
- **構成した例は、自然な軌道の証拠ではない**

### 0.4 モデルに依存させない（ChatGPT の指定）

- **働きの定義と、① の観測される現象は、Unit の模型に依存させない**。例えば MF6 を「記憶したときと同じ発火の模様が再び現れれば合格」とはしない。それはイベント型（C0）に有利で、別の内部の表現から同じ働きを作る模型を不当に外す（S2 の Rec1：同じ形の再出現は生物での一つの実現）
- ① の観測は、行動・出力、または**結果の前に決めた読み出し**で書く。読み出しの具体的な形は、候補ごとに §3 で別に書く
- ② ③ では、候補ごとに観測・介入できる内部の状態が違う。それも §3 に分ける

### 0.5 区別する三つのもの

| 記号 | 何か | 例 |
|---|---|---|
| **S** | 内部の状態（Core の中） | 速い活動、遅い変数（順応・痕跡など）、接続の重み、接続ごとの可塑性の状態 |
| **D** | 外部の記録 | DB、ログ、Thought Workspace、LLM の文脈・プロンプト、検索で取り出した文章 |
| **F** | 固定された規則・事前の知識 | 設計者の if、テンプレート、外部モデル（LLM・エンコーダ）の事前知識と埋め込み（原則 §3・§4） |

AnIma-ll の記憶の働きとして主張できるのは、② で **S の経験による違い** が後の違いを生んだと示せた場合だけである。D や F だけで説明できる結果は、どれほど正しく答えても、内部の記憶の証拠にしない（S2 §7・§11、原則 §3）。

### 0.6 契約の見直しの規則（ChatGPT の指定）

研究の順番は ①観測の契約 → ②粗視化と力学的な閉包 → ③局所的な可塑性 だが、一方通行ではない。② ③ で新しい識別の問題が見つかれば、この契約を見直す。そのときは、**見直す理由と、既に得た結論への影響を記録**し、結果に合わせた恣意的な基準の変更にしない（変更した版で、変更の前に得た結果を合格に変えない）。

## 1. 共通の枠組み

### 1.1 一般形

- **① 現象**：同じ出生時の状態の 2 個体（または同じ個体の複製）に、違う経験の履歴 H_a・H_b を与え、同じ試しの入力に対する、結果の前に決めた読み出し（または行動）を比べる
- **② 因果**：次の 3 つを分けて書く（ChatGPT の指定）
  - **(a)** 経験の後の内部の状態 S に、経験による違いが生じたことの観測
  - **(b)** 経験の寄与が、後の応答に現れることの観測
  - **(c)** S のうち**対象の部分だけ**を入れ替える・戻す（ほかの部分・D・F・後の入力は揃える）条件付きの反実仮想で、後の違いがその部分に従うこと
  - **全状態の移植は、それだけでは記憶の担い手を同定しない**。出生時の状態・D・F・後の入力を揃えて S 全体を入れ替えれば、後の振る舞いが入れ替わるのは、状態の十分性（識別のメモ 命題 3.1）から自明である。全状態の移植は、背景が揃っていることの確認として使う
- **③ 機構**：S のどの成分が、違いを**運ぶ**（経験によって違う）か、**関与する**（違わないが、ほかの成分の違いが現れるのに必要）か（識別のメモ §5.1）。成分ごとの移植・固定・除去で調べる。結果は、選んだ背景のもとでの条件付きの効果である（識別のメモ 命題 3.4）。(c) と ③ はつながっているが、(c) は「その部分が後の違いを担いうる」ことまで、③ は「どの成分がどう働いたか」まで問う

| X2 | **固定された規則・事前の知識 F**：設計者の if、テンプレート、外部モデルの事前知識や埋め込みが、答えや一般化を与えた | 原則 §3・§4、R5 |

### 1.4 共通の識別の限界

- **U1**：t0 で同じ全状態に至る 2 つの履歴は、後のどんな観測でも区別できない（識別のメモ 命題 3.1）
- **全状態の移植の自明さ**：全状態を入れ替えて振る舞いが入れ替わることは、担い手の同定にも、自然な媒介の同定にもならない（§1.1）
- **条件付きの効果**：介入で示せるのは、選んだ背景のもとでの条件付きの因果効果で、自然な個体の中で媒介した割合ではない（再評価 §2.3、識別のメモ U5）
- **出力が同じでも中身は違いうる**：① だけでは、LLM と DB のような外部の仕組みと区別できない（S2 §11 の 5）。内部の記憶を主張するには、少なくとも ② が要る
- **② は生物と同じ機構を意味しない**（ChatGPT の指定）
- **契約を満たさないことは、現象がないことではない**（§0.3）

## 2. MF ごとの契約

各 MF について、表に 7 項目を書き、その下に候補ごとの観測手段と、現行 3 Unit での状態を書く。現行 3 Unit の状態は、**構成要素の証拠**と**MF の段階**に分けて書く（§0.2 の二層）。MF の札（強い候補・候補）は S2 §8 のまま。② の (a)(b)(c) は §1.1 の区別。

### MF1 似た経験を区別して保持し、使う【強い候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 入力として似ているが違う経験 E・E′ の後に、同じ試しへの後の活動・判断が、どちらの経験をしたかで違う。その違いが、遅延と、ほかの経験を挟んだ後も残る |
| ① 現象 | K1 の 2 個体（E と E′）で、同じ試しへの読み出しが違う（L2）。「似ている」は**入力の側で、結果の前に**決めた尺度で定める（内部の表現の似かたで定めない） |
| ② 因果 | (a) E と E′ の後の S の違い。(b) その違いが試しへの読み出しに現れる。(c) S のうち対象の部分だけを入れ替えると、読み出しがその部分に従う。D・F は両方の腕で同じ |
| ③ 機構 | どの成分が区別を運ぶか。内部の状態の違いが入力の違いより大きくなっているか（狭い意味の「分離」）は、**入力と内部の状態は違う空間なので、距離・正規化・対照の分布・読み出しを定めない限り、大小を比べられない**。この段階では【未決】で、要件にしない |
| 対立する説明 | X4（入力が十分に似ていなかった）、X6（主張した長さの保持ではない）、X3、X1・X2 |
| 必要な対照 | K1、K3（成分ごと）、K5、K8、K9（主張する保持の長さに合わせる） |
| 識別の限界 | 区別できたことは、内部で特定の分離の仕組みが働いたことを意味しない。1 つの試しで区別できたことは、ほかの試しでの区別を意味しない |

- 候補ごとの観測：C0 は発火の列と重み、C1 は Unit をまたぐ活動率の列、C2 は Unit ごとのベクトル、C3 は細かいモジュールの素子と要約。C3 で要約を通す結合なら、違いが現時刻の要約に見えず、後の時刻に現れうるので、**読み出しの時刻を 1 つに限らない**（S1 命題 2.2）。C1 では Unit の内部の模様は表現されないので、それを観測の要件にしない（S1 §2.2）
- 現行 3 Unit：構成要素の証拠 なし。MF の段階：**対象が存在しない**。刺激の同一性は配線が与え（A・B・C が別の Receptor）、似ている度合いを持つ経験が今の世界にない（S2 §8.1）

### MF2 一回の経験から、後で使える情報を保持する【強い候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 1 回だけの経験 E の後、遅延をおいた試しへの反応が、E の内容に特有の形で、経験しなかった場合と違う。**保持の長さは、短期・中期・長期を分けて調べる**。どの長さを主張するかに応じて遅延を定め、候補の特定の状態の寿命では定めない |
| ① 現象 | K1・K2：E を 1 回 vs なし、と、E を 1 回 vs 別の E″ を 1 回。後者で、違いが**内容に特有**か（量の違いだけでないか）を見る。複数の遅延で見る |
| ② 因果 | (a) 1 回の経験で S のどこに違いが生じたか。(b) それが遅延の後の反応に現れるか。(c) その部分だけを経験の直後に戻す（または入れ替える）と、後の違いが消える（または移る） |
| ③ 機構 | どの変化（重みの増分、順応などの遅い変数、ほか）が、どの大きさで起きたか。**順応などの状態が担っていても、それを理由に記憶の働きから除外しない**（ChatGPT の指定） |

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 「覚えている」をどう確かめるか

友だちが、t-k さんの誕生日を言い当てたとします。それだけでは、本当に覚えていたのかは分かりません。スマホのカレンダーを見ただけかもしれないからです。

AnIma-ll でも同じです。過去のことを正しく答えても、DB やメモを読み出しただけかもしれません。そこで、確かめ方を 3 段階に分けました。

1. **現象**：経験したことで、後の反応が変わったか（誕生日を言えた）
2. **因果**：その変化が、本人の中で経験によって変わった部分から来ているか（カレンダーを見ずに言えた。カレンダーを取り上げても言えるか、で確かめる）
3. **機構**：中のどんな仕組みでそうなったか（脳のどこで、どうやって覚えていたか）

AnIma-ll の記憶と呼べるのは、少なくとも 2 まで確かめられたときです。3 は、生き物と同じ仕組みである必要はありません。

### 作り方に有利な試験にしない

「覚えたときと同じ発火の模様が出たら合格」という試験にすると、発火の模様で覚える作り方だけが受かり、別のやり方で同じことができる作り方を落としてしまいます。だから、まず「何ができればよいか」を作り方に依らずに決め、そのうえで、作り方ごとに「どこを見れば確かめられるか」を別に考えます。

### 今の 3 Unit で分かっていること

- **確かめられたこと（記憶の「部品」について）**：経験の順番で中のつながりが変わり、その違いは長い時間残る。条件をそろえれば、そのつながりの違いが反応を変える
- **まだ確かめていないこと（記憶の「働き」として）**：ふだんのままの状態で、経験した順番を思い出して使えるか。少しの手がかりから、欠けた部分を思い出せるか。新しく覚えても古いことを保てるか。1 回だけの経験で覚えられるか
- **今は試す材料がないこと**：似た経験の区別、共通点のまとめ、行動への利用、頭の中での組み替えなど。これは「できなかった」のではなく、今の小さな世界にその課題がない、ということです

部品がそろっていることと、記憶の働きが成り立っていることは別です。エンジンが回ることが確かめられても、車が目的地まで走れるかは、別に確かめる必要がある、というのと同じです。
