## 0. 読み方

### 0.1 三つの段階（ChatGPT の指定）

各 MF について、次の三つを分けて書く。**①を示しても②③は自動では成り立たない。②を確かめても、生物と同じ機構が成り立ったとは限らない。**

| 段階 | 検証すること |
|---|---|
| **① 現象** | 過去の経験によって、後の活動・判断・行動が変わるか |
| **② 因果** | その違いが、**経験によって変わった内部の状態**に依存しているか |
| **③ 機構** | 具体的に、どの活動・可塑性・回路の構造によって成り立ったか |

識別のメモとの対応：
- ① は、識別のメモの**現象の問い**（どの内部の状態が生んだかを問わない。§5.1）に当たる。① の中にも、L1（同じ個体の中で似る）・L2（経験の違いで違う）・L3（経験した構造に対応する）の水準があり、L1 ⇏ L2 ⇏ L3（命題 5.1・5.2）なので、**どの水準の主張か**を書く
- ③ は、識別のメモの**機構の問い**（どの成分が「運ぶ」か、「関与する」か。§5.1）に当たる
- ② はその間にある。決定論的な個体では、後の観測はすべて t0 の全状態の関数である（識別のメモ 命題 3.1）。したがって ② の問いは「内部の状態に依存するか」ではなく、**「経験による内部の状態の違いが、後の違いを生んだか（出生時の状態・外部の記録・固定された規則ではなく）」** と書く必要がある。これは ChatGPT の指定を、識別のメモに合わせて具体化したものである

### 0.2 札

| 札 | 意味 |
|---|---|
| **【要件の候補】** | 検証のために採用することを提案する方法の要件。模型から導いた定理ではない（識別のメモの【要件】と同じ扱い）。**この文書では正式に採用しない** |
| **【命題】** | 書いた前提のもとで証明できること（既存の文書の命題を引く場合は出どころを書く） |
| **【既存の結果】** | 0012〜0022 の実験で、事前登録した基準のもとで得られた結果（再評価 §2.1 の値だけを引く） |
| **【未決】** | この文書では決めない |

### 0.3 契約の位置づけ（識別のメモ §0.1 を引き継ぐ）

- この文書の観測量・対照・水準は、**研究者の側の観測・識別の契約**である。AnIma-ll が学習して持つ内部の意味や行動の規則ではない
- 対照の操作（状態の複製・移植、可塑性の停止、yoke、外部の記録の遮断など）は、**因果を識別するための人工の介入**で、自然な個体に組み込む機構ではない
- **結果を見て選ばない**：観測量・時間の区間・対応の規則・成功の判定（置くかどうかを含む）は、結果の前に決める
- **契約を満たさないことは、現象がないことではない**
- **構成した例は、自然な軌道の証拠ではない**

### 0.4 モデルに依存させない（ChatGPT の指定）

- **働きの定義と、① の観測される現象は、Unit の模型に依存させない**。例えば MF6 を「記憶したときと同じ発火の模様が再び現れれば合格」とはしない。それはイベント型（C0）に有利で、別の内部の表現から同じ働きを作る模型を不当に外す（S2 の Rec1：同じ形の再出現は生物での一つの実現）
- ① の観測は、行動・出力、または**結果の前に決めた読み出し**で書く。読み出しの具体的な形は、候補ごとに §3 で別に書く
- ② ③ では、候補ごとに観測・介入できる内部の状態が違う。それも §3 に分ける

### 0.5 区別する三つのもの

| 記号 | 何か | 例 |
|---|---|---|
| **S** | 内部の状態（Core の中） | 速い活動、遅い変数（順応・痕跡など）、接続の重み、接続ごとの可塑性の状態 |
| **D** | 外部の記録 | DB、ログ、Thought Workspace、LLM の文脈・プロンプト、検索で取り出した文章 |
| **F** | 固定された規則・事前の知識 | 設計者の if、テンプレート、外部モデル（LLM・エンコーダ）の事前知識と埋め込み（原則 §3・§4） |

AnIma-ll の記憶の働きとして主張できるのは、② で **S の経験による違い** が後の違いを生んだと示せた場合だけである。D や F だけで説明できる結果は、どれほど正しく答えても、内部の記憶の証拠にしない（S2 §7・§11、原則 §3）。

### 0.6 契約の見直しの規則（ChatGPT の指定）

研究の順番は ①観測の契約 → ②粗視化と力学的な閉包 → ③局所的な可塑性 だが、一方通行ではない。② ③ で新しい識別の問題が見つかれば、この契約を見直す。そのときは、**見直す理由と、既に得た結論への影響を記録**し、結果に合わせた恣意的な基準の変更にしない（変更した版で、変更の前に得た結果を合格に変えない）。

## 1. 共通の枠組み

### 1.1 一般形

- **① 現象**：同じ出生時の状態の 2 個体（または同じ個体の複製）に、違う経験の履歴 H_a・H_b を与え、同じ試しの入力に対する、結果の前に決めた読み出し（または行動）を比べる
- **② 因果**：H_a の後の内部の状態 S_a（またはその一部）を、H_b の個体に移す（またはその逆）。D と F を両方の腕で同じにする（または取り除く）。後の違いが移した S に従うなら、経験による S の違いが後の違いを生んだ
- **③ 機構**：S のどの成分が、違いを**運ぶ**（経験によって違う）か、**関与する**（違わないが、ほかの成分の違いが現れるのに必要）か（識別のメモ §5.1）。成分ごとの移植・固定・除去で調べる。結果は、選んだ背景のもとでの条件付きの効果である（識別のメモ 命題 3.4）

### 1.2 共通の対立する説明（MF ごとの節では番号で引く）

| # | 対立する説明 | 出どころ |
|---|---|---|
| X1 | **外部の記録 D の読み出し**：DB・ログ・Thought Workspace・LLM の文脈が、正しい答えを持っていた（検索で補う方式 [Lewis2020] はその典型） | S2 §7、原則 §3 |
| X2 | **固定された規則・事前の知識 F**：設計者の if、テンプレート、外部モデルの事前知識や埋め込みが、答えや一般化を与えた | 原則 §3・§4、R5 |
| X3 | **出生時の状態の違い**：経験ではなく、個体の生まれつきの違いが後の違いを生んだ | 再評価 §2.1（0013） |
| X4 | **試しの入力そのものの違い**：比べた 2 つの試しの入力が同じでなかった。または、入力の似ている度合いが大きく違っていた | — |
| X5 | **学習しない経路による時間の関係**：内在の周期と位相の持ち越しが、学習なしに経験に似た時間の関係を作る | 識別のメモ U4・I3、再評価 E2 |

| X7 | **量だけの違い**：発火の数や活動の量が違うだけで、経験した構造とは対応していない（L2 であって L3 ではない） | 識別のメモ 命題 5.2 |
| X8 | **凍結による保持**：活動しない組の重みが動かないために残っただけで、活動の中で保たれたのではない | 再評価 E6 |
| X9 | **個体のあいだのばらつき**：1 つの決定論的な個体では偶然の大きさを見積もれず、個体のあいだでは出生時の状態が違う | 識別のメモ U9 |

### 1.4 共通の識別の限界

- **U1**：t0 で同じ全状態に至る 2 つの履歴は、後のどんな観測でも区別できない（識別のメモ 命題 3.1）
- **条件付きの効果**：介入で示せるのは、選んだ背景のもとでの条件付きの因果効果で、自然な個体の中で媒介した割合ではない（再評価 §2.3、識別のメモ U5）
- **出力が同じでも中身は違いうる**：① だけでは、LLM と DB のような外部の仕組みと区別できない（S2 §11 の 5）。内部の記憶を主張するには、少なくとも ② が要る
- **② は生物と同じ機構を意味しない**（ChatGPT の指定）
- **契約を満たさないことは、現象がないことではない**（§0.3）

## 2. MF ごとの契約

各 MF について、表に 7 項目を書き、その下に候補ごとの観測手段と、現行 3 Unit での状態を書く。MF の札（強い候補・候補）は S2 §8 のまま。

### MF1 似た経験を区別して保持し、使う【強い候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 入力として似ているが違う経験 E・E′ の後に、同じ試しへの後の活動・判断が、どちらの経験をしたかで違う。その違いが、遅延と、ほかの経験を挟んだ後も残る |
| ① 現象 | K1 の 2 個体（E と E′）で、同じ試しへの読み出しが違う（L2）。「似ている」は**入力の側で、結果の前に**決めた尺度で定める（内部の表現の似かたで定めない） |
| ② 因果 | E の後の S を E′ の個体へ移すと、読み出しが移した S に従う。D・F は両方の腕で同じ |
| ③ 機構 | どの成分が区別を運ぶか。内部の状態の違いが、入力の違いより大きくなっているか（狭い意味の「分離」。内部の尺度が要るので、候補ごとの問い） |
| 対立する説明 | X4（入力が十分に似ていなかった）、X6（直前の入力の残り）、X3、X1・X2 |
| 必要な対照 | K1、K3、K5、K8、K9（短い時間の残りより後の試し） |
| 識別の限界 | 区別できたことは、内部で特定の分離の仕組みが働いたことを意味しない。1 つの試しで区別できたことは、ほかの試しでの区別を意味しない |

- 候補ごとの観測：C0 は発火の列と重み、C1 は Unit をまたぐ活動率の列、C2 は Unit ごとのベクトル、C3 は細かいモジュールの素子と要約。C3 で要約を通す結合なら、違いが現時刻の要約に見えず、後の時刻に現れうるので、**読み出しの時刻を 1 つに限らない**（S1 命題 2.2）。C1 では Unit の内部の模様は表現されないので、それを観測の要件にしない（S1 §2.2）
- 現行 3 Unit：**対象が存在しない**。刺激の同一性は配線が与え（A・B・C が別の Receptor）、似ている度合いを持つ経験が今の世界にない（S2 §8.1）

### MF2 一回の経験から、後で使える情報を保持する【強い候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 1 回だけの経験 E の後、遅延をおいた試しへの反応が、E の内容に特有の形で、経験しなかった場合と違う |
| ① 現象 | K1・K2：E を 1 回 vs なし、と、E を 1 回 vs 別の E″ を 1 回。後者で、違いが**内容に特有**か（量の違いだけでないか）を見る |
| ② 因果 | 1 回の経験で変わった S の成分を、経験の直後に戻す（または移す）と、後の違いが消える（または移る） |
| ③ 機構 | どの変化（重みの増分、遅い変数など）が、どの大きさで起きたか |
| 対立する説明 | X6（遅延が activity・痕跡・順応の時間尺度より短い）、X7（発火の量の違いだけ）、X3、X1 |
| 必要な対照 | K1、K2、K3、K9。遅延は、候補の短い時間の状態が消える長さより長くとる（現行なら activity 約 6 秒、順応 300 秒） |
| 識別の限界 | 1 回の経験の効果が検出できても、それが「後で使える情報」かは、内容に特有の違い（MF1 と同じ形）を示すまで言わない |

- 候補ごとの観測：変わった状態の成分（C0 は重みと h、C1・C2 は重みと遅い変数、C3 は細かいモジュールの接続）
- 現行 3 Unit：**未検証**。実験は 200 回の試行で行った。1 回の Pulse の更新で強まる重みは上限の約 6.7% 以下（S1 §3.1）だが、これは式の上限で、検証ではない

### MF3 順序・時間の間隔を区別して保持し、使う【強い候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 同じ要素を違う順序（または違う間隔）で経験した後、後の反応が、経験した順序・間隔に特有の形で違う |
| ① 現象 | K1：同じ要素の ordered と shuffled（または間隔だけ違う経験）。**違いがあること（L2）と、その違いが経験した順序に対応すること（L3）を分ける**。L3 を主張するなら、対応の規則 R を結果の前に固定する（識別のメモ §5.3） |
| ② 因果 | S（または重みだけ）の移植で、後の反応が移した側に従う |
| ③ 機構 | 順序を運ぶのが、学習した接続か、位相の持ち越しか、痕跡か（識別のメモ §5.1・§5.5） |
| 対立する説明 | X5（内在の周期と位相の持ち越し）、X7（量だけの違い。命題 5.2）、X3、X6。N は 3 点以上の順序を決めない（U2） |
| 必要な対照 | K1、K3（成分ごと）、K4、K7（結合のない基準で、学習しない経路を見る）、K8 |
| 識別の限界 | L2 は L3 を含意しない（命題 5.2）。今の規則の 1 本の重みは、時間差を κ^(L−1) で重みづけた 1 つの値しか持たない（U7、再評価 E3）。それを超える間隔の主張には、別の担い手が要る |

- 候補ごとの観測：C0 は Pulse の分解能の発火時刻。C1・C2 は連続の軌道で、速い時刻の構造は τ で弱められ、雑音・精度・帯域で区別できなくなりうるので、**標本化の刻み・精度・読み出しの帯域を結果の前に決める**（S1 §3.1a）。C3 は細かい部分の時刻
- 現行 3 Unit：
  - **検証済み（② の水準、条件付き）**：順序で重みの差ができる（0014 の w 19／20、0012 の M）。重みの差を、Unit の状態を揃えた複製に載せると、刺激の直後の応答が変わる（0014 の p 20／20、0016〜0019）【既存の結果】
  - **未検証**：介入のない自然な読み出しでの ①（0012 の H1 は fails、0014 の as_is は揃わない）【既存の結果】。L3（経験した順序が後に再び現れるか。Q5、R は未決）
  - **対象が存在しない**：間隔の違いを持つ経験は、今の世界にない

### MF4 素早い学習と長期の保持を、新しい学習と両立させる【前半：強い候補】／何を長く保つかが変わる【後半：候補】

| 項目 | 内容 |
|---|---|
| 機能の定義 | 前半：経験 E1 の後に別の経験 E2 を学んでも、長い遅延の後に E1 の効果が残り、E2 も少ない回数で身につく。後半：経験の性質の違い（新しさなど）で、保持の長さが違う |
| ① 現象 | 前半：E1 だけ／E1 の後に E2／E2 だけの 3 つで、E1 と E2 の試しへの反応を、時間をおいて比べる。後半：性質だけが違う 2 つの経験の保持を比べる |
| ② 因果 | 遅い時点の S の移植で、後の反応が移した側に従う（0016・0017 の形）。後半は、経験の後の内部の過程に介入する（その間の可塑性を止める、など）と、保持の違いが変わる |
| ③ 機構 | 速い成分・遅い成分、固定化、選択の信号のどれが担うか（S2 の実現の仮説） |

| 複数の Unit にまたがる関係と、1 つの Unit の時間の模様の、どちらの射程の主張か | 再評価 E5 | MF5・MF6 で主張の射程を書く（§7 の未決） |
| 凍結による保持と、活動の中で保たれる保持を分ける | 再評価 E6 | X8、MF4 の限界 |
| 「一部の長期化」が何かを決める | 再評価 E7 | MF4（【未決】として残す） |
| 寄与は足し算に分けられず、効果は背景ごとの条件付き | 識別のメモ 命題 3.4・U5 | §1.1 の ③、§1.4 |

**矛盾は見つからなかった**。一点だけ具体化した：ChatGPT の ② 「内部の状態に依存しているか」は、決定論的な個体では命題 3.1 により常に成り立つので、「**経験による内部の状態の違い**が、出生時の状態・外部の記録・固定された規則ではなく、後の違いを生んだか」と書いた（§0.1）。

## 7. 未決（次に決めること）

1. **入力の似かたの尺度**（MF1・MF7）：内部の表現に依らず、入力の側で、結果の前にどう定めるか
2. **対応の規則 R**（MF3・MF5・MF6 の L3）：識別のメモ §7 のまま未決
3. **経験の性質の定め方**（MF4 後半）：新しさなどを、価値を使わずに、どう定めるか（原則 §6）
4. **主張の射程**（MF5・MF6）：複数の Unit にまたがる関係か、1 つの Unit の時間の模様か（再評価 E5）。粗視化の候補では「Unit」の単位が変わるので、射程の書き方も見直す
5. **行動の出口**（MF9 後半）と**操作の課題**（MF10）：将来の観測の条件として、行動の境界の契約とあわせて決める
6. **世界の材料**：MF1・MF7・MF8 などを試す経験（似た経験、構造の共通する経験、重なる順の学習）は、今の世界にない。世界を変えることは、この文書の範囲外で、別の承認が要る
7. **契約の見直し**：次の研究（② 粗視化と力学的な閉包、③ 局所的な可塑性）で新しい識別の問題が出たら、§0.6 の規則で見直す

## 8. 言わないこと

- 「正しく答えた」「過去と同じ活動が出た」だけを、内部の記憶の成立と呼ばない
- ② を確かめたことを、生物と同じ機構が成り立ったと呼ばない
- 「対象が存在しない」を、今の模型の不合格と呼ばない
- 特定の候補の内部の状態（発火の模様など）の再出現を、MF の合格の条件にしない
- この文書の契約を、採用済みの基準と呼ばない

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 「覚えている」をどう確かめるか

友だちが、t-k さんの誕生日を言い当てたとします。それだけでは、本当に覚えていたのかは分かりません。スマホのカレンダーを見ただけかもしれないからです。

AnIma-ll でも同じです。過去のことを正しく答えても、DB やメモを読み出しただけかもしれません。そこで、確かめ方を 3 段階に分けました。

1. **現象**：経験したことで、後の反応が変わったか（誕生日を言えた）
2. **因果**：その変化が、本人の中で経験によって変わった部分から来ているか（カレンダーを見ずに言えた。カレンダーを取り上げても言えるか、で確かめる）
3. **機構**：中のどんな仕組みでそうなったか（脳のどこで、どうやって覚えていたか）

AnIma-ll の記憶と呼べるのは、少なくとも 2 まで確かめられたときです。3 は、生き物と同じ仕組みである必要はありません。

### 作り方に有利な試験にしない

「覚えたときと同じ発火の模様が出たら合格」という試験にすると、発火の模様で覚える作り方だけが受かり、別のやり方で同じことができる作り方を落としてしまいます。だから、まず「何ができればよいか」を作り方に依らずに決め、そのうえで、作り方ごとに「どこを見れば確かめられるか」を別に考えます。

### 今の 3 Unit で分かっていること

- **確かめられたこと**：経験の順番で中のつながりが変わり、そのつながりの違いは、条件をそろえれば反応を変えられる大きさを持っている
- **まだのこと**：ふだんのままの状態で、その違いがはっきり反応に出るか。1 回だけの経験で覚えられるか
- **今は試す材料がないこと**：似た経験の区別、行動への利用、頭の中での組み替えなど。これは「できなかった」のではなく、今の小さな世界にその課題がない、ということです
