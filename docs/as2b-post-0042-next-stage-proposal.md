## 2. 0042 から言えることと、言えないこと

### 2.1 前もって書いた動機と、実現した条件

前の提案は、0042 の結果の前に、自然な差と端の対比の違いを、次の三か所に書いていました。
- §2.3：自然な差は端の対比より大きさがずっと小さく（δ の単位で約 47 分の 1）、形も違う（源ごとの成分がそろわず、源どうしの接続の差も 0 でない個体がある）
- §3.1 の否定的結果の限界：候補 1（＝ 0042）の陰性の読みを、二つの場合に分けていた
  - 「感度の対照が変わり、自然な差の入れ替えが変わらなかったとき」：「自然な差の大きさ・形では届きにくかった」という記述まで
  - 「感度の対照も変わらなかったとき」：「この背景・この条件では人工の端にも応じにくかった」という記述まで
- §3.4 の 4a：対称な重みの対比の大きさへの応答を、「候補 1 の結果の後に、陰性の読み分けが必要になったときの候補」としていた

0042 で実現したのは、§3.1 の二つの場合のどちらとも、字義どおりには違います。
- 自然な差の入れ替えは、「変わらなかった」のではありません。T が定まる 189 個体のうち、77 個体で T ≠ 0 でした。確立しなかったのは、その 77 個体の中での向きの偏りです（＋ 33・− 44。どちらも k₂(77) ＝ 48 に届かない）
- 感度の対照 S は、定まる 190 個体のうち 144 個体で 0 でなく、その 144 個体のうち 143 個体が＋でした（記述。判定ではない）

したがって、次のように扱います。
- この文書は、§3.1 の読み「自然な差の大きさ・形では届きにくかった」を、0042 の読みとして使いません。0042 の不成立の原因は、識別されていません
- 候補 A の動機は、§2.3・4a が結果の前に挙げていた大きさと形の違いです
- 候補 A の主の量（中心の差）は、この文書で新しく立てる問いで、0042 の結果から導いたものではありません

### 2.3 選択の量の飽和（設計の材料）

- 0042 の主の四つの系の U の s（A1 の割合）の分布は、どれも第 1 四分位が 0、第 3 四分位が 1 でした（§15.5 の 2 × 2 の表）。U の決まった窓の中央は 13 です（§15.6 の R2）
- 基の系の s が 0 なら、そこからの片側の差は 0 以上に限られます（1 なら 0 以下）。これは割合という量の算術の性質で、0042 の結果の説明ではありません
- 中心の差 s(W^c ＋ k e) − s(W^c − k e) の符号は、基の系の s の値では限られません
  - ただし、両側の系の s が同じだけ動けば、中心の差は 0 になります（どちらも 0 のまま、どちらも同じ値に動く、など）
  - **中心の差は、飽和を解消するものでも、検出力を改善するものでもありません**（どちらも保証されません）
- 中心の差を素案にする理由は、次の三つの性質だけです
  - 二つの系が、同じ中心 W^c から同じ大きさだけ逆の向きに動かした重みであること
  - 符号の意味が、T と同じ規則の意味であること
  - 札の入れ替えに対して不変であること（§3.1）
- 基の系の s（0・1・その間）ごとの内訳は、記述として必ず報告します
- この性質を理由に、0042 の判定の形を選び直すことはしません

### 3.1 候補 A（推奨）：規則のもとで形づくられた重みの差の向きを保ったまま、その大きさを前もって決めた段に延ばすと、試しの区間の選択の差は一方の向きにそろうか

#### δ をそろえた対称な介入の対照：そろえる量と符号

- **u**：C → 源 1 ＝ ＋1、源 1 → C ＝ −1、C → 源 2 ＝ −1、源 2 → C ＝ ＋1、源どうしの 2 本 ＝ 0 の向きです
  - 0040 の X1 − X2 を w_max で割った向きです。δ(u) ＝ 2 で、F1 を保ちます
- **m_k**：\|δ(2 m_k u)\| ＝ \|δ(2k e)\| となるようにそろえます。つまり m_k ＝ k \|δ(e)\|／2 です（絶対量案では m ＝ a／2）
- **量**：D^u_k^{(c)} ＝ s(G^c[W^c ＋ m_k u]) − s(G^c[W^c − m_k u])、D^u_k ＝ D^u_k^{(A1)} ＋ D^u_k^{(A2)}
- **D^u の＋の意味**：C → 源 1 を上げ、C → 源 2 を下げた側（X1 の側）で、A1 の割合が高いこと
  - 0040 の D^X・0042 の S と同じ、重みの向きで決めた符号です。C_k の＋（規則の意味）とは別のものです
  - 札を入れ替えると u は −u に、s は 1 − s に移るので、D^u_k も札の付け方に依りません
- **そろうのは δ の大きさだけです**
  - δ に現れない成分があります。C → 源 1 と C → 源 2 の共通の変化と、源どうしの 2 本です。これらは e では 0 でないことがあり、u では 0 です
  - そのため、6 本の変化の全体の大きさは、一般にはそろいません
  - 中心は、どちらも同じ W^c です（0042 の T と S では、中点も違っていました。§2.2）
- **符号の関係**
  - δ の上での e の向きは、δ(e) の符号で決まります。δ(e) ＜ 0 なら、C_k の＋の端は、δ の上では −u の側にあります
  - 極端な場合として e ＝ −b u（b ＞ 0）なら、m_k ＝ k b で、二つの対比の端点の組は同じになり、C_k ＝ −D^u_k です
  - そのため、C_k と D^u_k の符号をそのまま並べて、「同じ向き・逆の向き」と読みません
  - δ の上の向きをそろえて並べる記述（C_k に sign δ(e) を掛けるなど）を置くかどうかと、その形は、事前登録で決めます。どちらも判定にしません
- **δ(e) ＝ 0 の個体**：e ≠ 0 でも起こりえます（C → 源 1 と C → 源 2 の成分の差が同じとき、または源どうしだけに差があるとき）
  - 倍数案では m_k ＝ 0 になり、対照の二つの系が同じ重みになって、対比になりません。「対照が定まらない（δ(e) ＝ 0）」として、測った 0 と分けて数えます
  - 絶対量案では、主の量の倍率そのものが定まりません
- **言えること**：δ の大きさをそろえた二種類の介入の応答を、同じ個体・同じ中心で並べた記述
- **言えないこと**：「同じ大きさで形だけが違う比べ」、「0042 の不成立の原因を、大きさと形に分けられる」という一般化

#### 個体の区分と、比べに使う個体（素案）

- (個体, c, 段) ごとに、C_k と D^u_k のそれぞれについて、次を分けて数えます
  1. **範囲の外**：V の 6 本のどれかが [0, w_max] の外
  2. **s が定まらない**：範囲の中だが、必要な系の U に決まった窓がない
  3. **構造上の 0**：e ＝ 0 で、二つの系が同じ重みになる。対照では δ(e) ＝ 0 も含む
  4. **測った差が 0**
  5. **0 でない**（＋・−）
  6. 絶対量案では、**倍率が定まらない**（δ(e) ＝ 0）
- 個体の量（二つの背景の和）が定まる条件と、主の判定の分母は、事前登録で理由を書いて決めます。0042 の §4.1 の区分は参考にしますが、引き写しません
- **個体の中の比べ**（C_k と D^u_k を並べる記述）では、同じ背景・同じ段で両方が定まる共通の個体を使い、その数を示します。片方だけの分母での推定も、並べて示してかまいません
- **段をまたぐ記述**では、段ごとに残る個体が違いえます
  - そのため、段ごとの割合の違いを、残った個体の違いごと、倍率だけの効果とは読みません
  - 比べる全段で定まる共通の個体での記述を、その数とともに並べます
- 範囲の外の個体が多い段の推定は、選別の前の全個体についての主張にしません

#### 否定的結果の限界

- 不成立から、「この向きの重みの差は選択の向きをそろえない」「規則に依る重みの変化は選択に届かない」とは言えません。測った段・この背景・この試しの区間の条件のものです
- 対照がそろい、自然な差の向きの対比がそろわなかったとしても、言えるのは「δ の大きさをそろえた二種類の介入で、応答が違った」という記述までです
  - 二つの介入は、δ 以外の成分でも違うので、形だけの違いとは言えません
  - どの接続・どの経路が理由かも言えません
- 陰性を、構成の限界の結論や、候補 E を始める自動の条件にしません

## 7. 専門知識がなくても読める説明（t-k さんへ）

### 今どこまで分かったか

- 「つながりの強さ（重み）を人の手で端まで寄せると、AI の選び方が変わる」ことは、0040 で確かめられました
- 「どの行動に結果が返る世界で経験したかで、つながりの強さの変わり方がそろって違ってくる」ことは、0041 で確かめられました
- 0042 では、同じ AI が二つの世界で自然に作ったつながりの強さを入れ替えて、選び方の変わる向きがそろうかを見ました
  - 比べられた 189 体のうち、77 体で選び方の割合が変わりました。ただ、変わる向きは＋が 33 体、−が 44 体に分かれ、そろうとは言えませんでした
  - 一方、同じ条件で端まで寄せたつながりを入れ替えると、190 体のうち 144 体で割合が変わり、そのうち 143 体が同じ向きでした

### 何が分からないままか

- 自然な違いを入れ替えたとき、なぜ向きがそろわなかったのかは分かっていません
- 自然な違いと端まで寄せた違いでは、大きさも、形も、真ん中の位置も違います。そのどれが関わったのか、あるいは別の理由なのかを、0042 の記録からは見分けられません

### 何を提案するか

- 同じ AI で、自然にできた違いの**向きはそのまま**にして、大きさだけを段階的に（たとえば 2 倍・4 倍・8 倍に）大きくした重みを比べ、向きがそろうかを見ます
- あわせて、ある一つの物差し（δ）で大きさをそろえた**左右対称な**違いも、同じ AI・同じ真ん中の位置で並べて見ます
  - そろうのはその物差しだけで、ほかの部分の違いは残ります。そのため、「大きさのせいか、形のせいか」をきれいに分けることはできません。二種類の違いへの反応を並べて記録する、という位置づけです
- 大きくしすぎると、重みが決まった範囲からはみ出す個体が出ます。はみ出した個体や、比べられなかった個体は別に数え、比べに使った個体の数をはっきり示します
- 大きくした重みは人の手で作ったものなので、向きがそろっても、「自然な違いが選び方を変えた」とは言いません
