## 1. 判断 1：S2 の正式な完了

### 1.1 提案と根拠

**提案**：S2 を正式に完了とする。

- **S2 で置いた問いを、決めた比べ方で測り終えた**（R5 §4）
  - S1（閉ループの契約）：0034〜0037 の 260 個体のすべてで、違反がなかった。帰還の出来事を実際に観測したのは 207 個体。53 個体は行動の源が沈黙した
  - A（今の帰還の効果）：存在を三つの実験で繰り返し観測した
  - B（e 以後の更新の局所の増分）：0034・0036 で、0 でない出来事は少数（2/552、7/1,620）。記述として測った
  - C（経験で形づくられた重みの効果）：測定の手段（PC-3 の再生、PC-4 の移植、状態 × 重みの 2 × 2）が AS1 で成立した。存在を観測した（6 本の重みだけを出生時の値に戻すと 37/77 個体で、同じ外の履歴を学習を止めて再生した系と比べると 46/77 個体で、後の意図の列が変わった）
- **道具と比較の契約が、実験で堅固だった**（R5 §6.1 の 3）
  - 四つの実験とも、操作の確認がすべて成り立ち、invalid の個体はなかった
  - 実行した側の独立の照合は、どれも不一致 0 だった。0037 は ChatGPT も独立に計算し、不一致 0 だった
- **R4 で完了を示せない主な理由とした二つの項目が、どちらも解消した**（R5 §6.1・§6.2）
  - 項目 2：C を経験の列の分岐を除いて測る方法が、0037 で動くことを確かめた。C が成立したのではなく、C を測れるようになった
  - 項目 4：S3 の構成の採用の基準を、#173 で固定した（R5 §5.1 で、S3 に進む前に解くべきものとした唯一の点）

### 1.2 完了としても、言えないこと

- 「完了」は、**研究の工程としての区切り**である。AS1 で、S1 の契約、A の存在、B・C の定義ごとの測定の手段の検証までを終えた、という技術の評価にとどまる（R5 §6.2）
- 四つの主の判定（0034 J_A 10/18、0035 J_S 14/30、0036 J_P 19/56、0037 J_C 37/77）は、どれも、各実験で事前登録した個体の事象について、個体の多数の主張を確立しなかった。四つは数えた事象が違い、一つの「効果の頻度」ではない（R5 §2.2）
- 次のことは、識別していない（R5 §4・§5.3）
  - 帰還の経路に固有の可塑性の効果と、その機構
  - 自然な AS1 の可塑性の総効果、寄与の割合
  - 帰還の効果の向きを決める機構
- 0037 の結果は、介入の条件を付けた形でだけ引く（R5 §3.1）：「経験の終わりの内の状態をそろえ、可塑的な 6 本の重みだけを出生時の値に戻し、その後の区間で重みを止めたところ、適格な 77 個体のうち 37 個体で意図の列が変わった。当該の介入のもとでの条件付きの因果の違いであり、自然な AS1 全体の効果、帰還の経路に固有の効果、寄与の割合を示すものではない」
- 主の判定の不成立は、S3 に進めないことの自動の理由にはしない。逆に、S2 の特定の結果を S3 の必要条件にもしない（三段の比較 §1.1）

### 1.3 完了としない場合

- 足りないとお考えの点を伺い、その点を調べる計画を docs だけで出す
- 候補は、R5 §5.3 の並行の問題（帰還の経路に固有の効果を、重みへの介入と伝達への介入を併せて問う比べ、など）である。それぞれ、どの条件なら S3 の前に要るかは R5 §5.3 に書いてある

## 2. 判断 2：S3 への移行

### 2.1 提案と根拠

**提案**：S3 に移行する（三段の比較 §5.2 の進め方 P の手順 2）。

- R5 §5.1 で「S3 に進む前に解決すべきもの」としたのは、構成の採用の基準だけで、それは #173 で固定した
- 未解決の問題（§1.2）は、S3 の主の主張を因果として識別するのに、直接は要らない。要るようになる条件は R5 §5.3 に書いてあり、無条件には先送りしない
- S2 から S3 に引き継ぐ要件 R-1〜R-7 は、S3 の事前登録で満たし、そのレビューで確かめる（R5 §5.2、基準 §7）
  - R-1：可塑性による変化と、経験の列の違いによる変化を分ける比べ
  - R-7：選択の変化が、結果の付与の規則に依ったかを問う対照
- 進め方 P の手順 2 は、もともと、S2 の特定の読み出しの結果で S3 に進むかを決めない、としていた（三段の比較 §5.2）

### 2.2 移行しても、すぐには始まらないこと

移行を「はい」としていただいた後の手順の案である。どの段も、これまでと同じく、Claude が出し、ChatGPT が独立にレビューしてマージする。Claude はマージしない。

1. S3 の構成の最小の実装の契約（docs だけ。AS1 の #147 に当たる）
2. 道具と契約テスト（AS1 の #148 に当たる）
   - 窓の中で行動が測れる形で出るかの**前方の関門**を、解析と合成の seed の契約テストだけで確かめる（基準 §7）
   - 成り立たなければ、その構成では事前登録に進まない
3. S3 の実験の事前登録（R-1〜R-7 を満たす。主の量・成立の条件・帰無・識別の限界を前もって固定する）
4. 盲検の smoke（別の明示の承認が要る）
5. 本番（別の明示の承認が要る）

- 移行の「はい」は、この 1〜5 のどれの承認でもない
- 途中で、t-k さんにもう一度ご相談するのは、次の三つの場合だけにする
  - 基盤の構成を変える必要が出たとき（例：§3.3 の意図の機構を Core に置く必要が出たとき）
  - 解けない問題に当たったとき（例：どの候補の構成でも、窓の中で行動が測れないとき）
  - S3 の完了を支持する技術の根拠がそろったとき

### 2.3 移行しない場合

- S2 を完了とし（判断 1 が「はい」のとき）、S3 の前に何をするかを伺う
- 候補は §1.3 と同じく、R5 §5.3 の並行の問題である

## 3. 判断 3：S3 の構成に AS2b を採用するか

### 3.1 提案と根拠

**提案**：AS2b を採用する。順位は AS2b・AS2・AS3（基準 §6.1）。

AS2b：手がかりの後の窓で、二つの行動の源（手がかりを受けない二つの Unit）のうち先に発火した方を選択とする。片方の行動にだけ、手がかりの Receptor に結果の刺激が返る。

- **重い基準（基準 §4）では、三つの構成に差がない**
  - SC-1：問いの形にできる
  - SC-2（R-1）：可塑性を止めた対照、再生、移植を作れる
  - SC-3a（R-7）：結果の付与の規則を入れ替える対照を作れる
- **順位は、次の点で付けた**（基準 §6.2）
  - AS2b を AS2 より先にする：結果の刺激が行動の源に直接入らないので、直接の反射を、規則を足さずに避けられる。結果がどこを通って選択に届くかの整理が相対的に容易。AS1 と同じく、行動の源の入口に刺激が来ない（SC-3b・SC-9）
  - AS2b を AS3 より先にする：Unit・接続・初期の重み・入次数を足さないので、新しく足すものが少ない。出口を外せば C0 に戻る（SC-5・SC-8）
  - これは、R-7 の識別の優劣ではない
- 基準は、0034〜0037 の結果をすべて見た後に、今後に向けて固定したものである。主の判定の割合や 0037 の向きの型は、基準にも推奨にも使っていない（基準 §1）

### 3.2 採用しても、言えないこと

- **設計の上の第一候補**という評価である。実装できること、窓の中で行動が十分に出ること、学習の効果が出ることは、どれも確かめていない
- S3 で、R-1 と R-7 の比べが成り立っても、言えるのは「結果の付与の規則を替えると、可塑的な変化を通して、選択の分布が変わった」まで（基準 §2.1）
  - 行動ごとの結果の結び付き（連合）を獲得したこと、どの行動の手柄かの割り当て（信用の割り当て）は言わない
  - 報酬・価値・罰・意味・目的の学習とは呼ばない
- AS2b の限界：結果が片方の行動にだけ返る非対称と、結果の刺激の数が行動に依ること。結果の付与の規則の総効果の一部として扱う（基準 §6.3）

### 3.3 採用の前提に置くこと

- **C0 は比較の基準として残す**。Core の Unit の力学・可塑性の規則・確定したパラメータ・Pulse の順序は変えない
- **意図の機構（窓と、先に発火した方を選ぶ競合）は、AS1 と同じく拡張の部品に置く案**とする（三段の比較 §5.3 の 3）。Core に置く必要が出たら、基盤の構成の変更として、改めてご相談する
- AS2b の値（窓の長さ、手がかりの予定、遅れ、同時の扱いなど）は、S3 の事前登録で、結果の前に理由を書いて決める（基準 §9）

### 3.4 別の構成を選ぶ場合

- AS2（結果の刺激を、二つの行動の源の入口に返す）：R-7 は問える。直接の刺激の経路と間接の帰還の経路を分けないことを事前に書き、直接の反射を除く規則を足す（基準 §6.4）
- AS3（入口のない Unit を二つ足す）：足すものを別の文書で数える
- どちらでも、基準（#173）は変えない。その構成の限界を、事前登録に書く

## 7. 専門知識がなくても読める説明（t-k さんへ）

### お願いしたいこと

三つのことを、それぞれ決めていただきたいです。

1. **今の段階（S2）を、正式に終わりにしてよいか**
   - 今の段階では、「行動の結果を感じることが、その後の行動を変えるか」を、いちばん簡単な仕組みで調べてきました
   - 調べると決めたことは、決めた方法で調べ終えました。その方法がきちんと働くことも確かめました
   - ただし、「多くの個体でこうなる」という形の仮説は、四つとも基準に届きませんでした。どこを通って効くかという仕組みも、まだ分かっていません
   - そのため、ここで言う「終わり」は「調べる作業の区切り」であって、「学習の仕組みが分かった」という意味ではありません
2. **次の段階（S3）に進んでよいか**
   - 次の段階では、AI に二つの行動のどちらかを選ばせ、経験で選び方が変わるかを調べます
   - 進む前に決めておくべきだった「仕組みを選ぶ基準」は、もう決めました
3. **次の段階で、AS2b という仕組みを使ってよいか**
   - 片方の行動にだけ結果が返る仕組みです
   - 結果がどこを通って効いたかの整理がしやすく、ほかの候補より足すものが少ないので、第一候補にしました
   - ただし、うまく動くか、学習が起きるかは、まだ分かりません。また、うまくいっても言えるのは「結果の返し方の決まりを変えると、選び方が変わった」までで、「ご褒美を覚えた」とは言いません

### 決めていただいた後

- 「はい」をいただいても、すぐに実験を始めるわけではありません。まず仕組みの約束事を文書にし、次に道具を作り、計画を決め、試しの実行と本番は、それぞれ別に承認を受けてから行います
- 途中で t-k さんにもう一度ご相談するのは、AI の基盤の作りを変える必要が出たとき、解けない問題に当たったとき、次の段階を終えてよい根拠がそろったとき、の三つだけです
- 「いいえ」や「保留」でも大丈夫です。その場合は、足りないと思われる点を伺って、そこから進めます

### お答えの形

「判断 1：はい／判断 2：はい／判断 3：はい」のように、三つそれぞれに「はい・いいえ・保留」でお答えください。理由やご意見があれば、あわせて書いてください。
