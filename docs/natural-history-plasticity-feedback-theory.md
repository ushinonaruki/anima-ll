## 1. 問いの定義と、Q5 との境界

**Q4 の問い**：同じ Birth State の 2 つの個体 O（ordered の経験）と S（shuffled の経験）が、W で、それぞれ自分の発火で可塑性を更新しながら入力なしで進む。このとき、自分の発火に依存する可塑性（循環）は、2 つの個体の違いにどう作用するか。

境界：

| | Q4（この文書） | Q5（#88・#89） | 0021 |
|---|---|---|---|
| 問うこと | 循環が、自然な 2 個体の違いにどう作用するか | 経験した活動のパターンが W に再び現れるか | 人工の移植で植えた差の上で、循環の置き換えが後の発火を変えるか |
| 違いの出どころ | 自然な履歴（全成分が違う） | 自然な履歴 | 人工の移植（4 本の重みだけが違う） |
| 言わないこと | 再活性化・記憶・経験したパターンの再出現 | 機構を特定しない限り、運び手を言わない | 自然な媒介 |

**Q4 の結果を、再活性化や記憶の成立と解釈しない**。2 つの個体の違いが続いても広がっても、それは「違いの持続・変化」であり、経験したパターンの再出現（Q5 の L3）ではない。

## 2. 自然な 2 個体の、t0 の違いと W への表出

**【命題 2.1】t0 では全成分が違いうる**（識別のメモ 命題 3.1・3.2）

O と S は、t0 で次のすべてが違いうる。
- 各 Unit の (a, h)
- 重み（組の和の条件のもとで自由度 3）
- 痕跡（3）
- t0 ＋ 1 に届く駆動（3）

W はこの全状態を通してしか履歴を見ない。

**【命題 2.2】違いが W に入る順序**（循環のメモ §1 の順序から）

| Pulse | 発火の判定に入る違い |
|---|---|
| t0 ＋ 1 | (a, h) の違いと、t0 ＋ 1 に届く駆動の違い（w(t0 − 1) と t0 の発火で作られる）。**t0 の重み ω の違いは入らない** |
| t0 ＋ 2 以後 | ω の違いが、t0 ＋ 1 の発火から作る駆動を通して入る。以後は、それまでの発火と状態の違いがすべて重なる |
| （どの Pulse でも） | 痕跡の違いは発火の判定に入らない。W の可塑性の更新だけに入る（識別のメモ 命題 3.3b） |

**帰結**：
- 自然な 2 個体では、発火の列が t0 ＋ 1 から違いうる。その違いは重みではなく、Unit の状態と t0 ＋ 1 に届く駆動から来る
- 0021 の t1（接続差の離散的な発火への表出）に当たる「最初の違い」は、自然な 2 個体では重みの表出を意味しない

**【命題 2.3】順応の違いの推移**（理論のメモ 命題 4.5a の (i) と同じ式）

```text
Δh(t) = γ^(t − t0) Δh(t0) + α Σ_{k = t0+1}^{t} γ^(t−k) (s_O(k) − s_S(k))
```

初めの差の項は、自然な 2 個体では一般に 0 でない。

### 3.1 腕

| **S** | 自然 | shuffled の経験の後の全状態 | 自分の状態・重み | 自分 | 自分の t0 の値から、自分の発火で更新 |

- 痕跡を移植しない基本の候補は、実験の設計の決定ではない。痕跡も相手の値に置き換える案は、§4 の痕跡の差の項を 0 にするが、その代わりに自然な履歴から得た痕跡を捨てる人工の組み合わせになる【未解決】
- 両向きを扱うのは、どちらを基準にするかで条件付きの因果効果が違いうるため（§7）
- **yoke は循環を取り除く操作ではない**。自分の発火による可塑性の駆動を、相手の発火による駆動に置き換える操作である。相手の発火には、相手自身の循環の結果が含まれる

### 3.2 操作の台帳（識別のメモ §4.1b と同じ形）

| 腕 | 操作の対象 | 値の出所 | 固定される背景 | t0 に既に残っているもの | この腕だけでは推定できないこと |
|---|---|---|---|---|---|
| O・S | なし（自然） | なし | 同じ Birth State と、同じ刺激の時刻の格子 | 全成分の違い（命題 2.1） | 違いのうち、循環が生んだ部分 |

## 4. 0021 の P の恒等式の一般化（初めの痕跡が違う場合）

1 本の接続 i→j を考える。2 つの腕 A・B が、t0 の後に **同じ可塑性の入力の発火 (s_i(t), s_j(t))** を受け、初めの重み ω^A・ω^B と初めの痕跡 X^A(t0)・X^B(t0) だけが違うとする。次のように書く。

```text
δω = ω^A − ω^B
ΔX_i(t0) = X_i^A(t0) − X_i^B(t0)      ΔX_j(t0) = X_j^A(t0) − X_j^B(t0)
D(t) = w^A(t) − w^B(t)
```

更新は循環のメモ §1 のとおりで、κ ＝ λ である。

```text
w(t) = σ(t) w(t−1) + β(t)
σ(t) = 1 − a [ X_i(t−1) s_j(t) + X_j(t−1) s_i(t) ]
β(t) = a X_i(t−1) s_j(t) w_max
X(t) = κ X(t−1) + s(t)
```

### 4.1 痕跡の差の減り方（ChatGPT の項目 1）

**【命題 4.1】同じ発火で更新すれば、痕跡の差は κ 倍ずつ減る**

```text
ΔX_i(t) = κ^(t − t0) ΔX_i(t0)      ΔX_j(t) = κ^(t − t0) ΔX_j(t0)
```

証明：両方の腕に同じ s(t) が足されるので、差は κ 倍されるだけである。

- 痕跡の差は、発火の有無にかかわらず約 6 Pulse の時定数で減る
- 0 にはならない（実数では）

### 4.2 痕跡の差が σ・β に入る形（項目 2）

**【命題 4.2】**

```text
Δσ(t) = σ^A(t) − σ^B(t) = −a κ^(t−1−t0) [ ΔX_i(t0) s_j(t) + ΔX_j(t0) s_i(t) ]
Δβ(t) = β^A(t) − β^B(t) =  a κ^(t−1−t0) ΔX_i(t0) s_j(t) w_max
```

証明：命題 4.1 を σ・β の式に入れる。

- 差が入るのは、受け手 j か送り手 i が発火した Pulse だけである
- その大きさは κ^(t−1−t0) で減る

### 4.3 重みの差の分解（項目 3）

**【命題 4.3】重みの差は、初めの重みの差の持ち越しと、痕跡の差による更新の和に書ける**

Φ^B(k, t) ＝ Π_{m = k+1}^{t} σ^B(m)（空の積は 1）と置く。このとき

```text
D(t) = Φ^B(t0, t) · δω  +  T^B(t)
T^B(t) = Σ_{k = t0+1}^{t} Φ^B(k, t) · e^A(k)
e^A(k) = Δσ(k) w^A(k−1) + Δβ(k)
       = a κ^(k−1−t0) [ ΔX_i(t0) s_j(k) (w_max − w^A(k−1)) − ΔX_j(t0) s_i(k) w^A(k−1) ]
```

証明：D(t) ＝ σ^A w^A(t−1) − σ^B w^B(t−1) ＋ Δβ ＝ σ^B D(t−1) ＋ Δσ w^A(t−1) ＋ Δβ を、t0 から繰り返し展開する。

- 第 1 項は **初めの重みの差の持ち越し** で、B の発火の組で縮む
- 第 2 項は **痕跡の差による更新の差** である

**同じことの affine の形**：各腕の重みは、自分の σ・β の列について w^X(t) ＝ Φ^X(t) ω^X ＋ ψ^X(t) と書ける（循環のメモ F3 の証明の 2）。したがって

```text
D(t) = Φ^B(t) δω + (Φ^A(t) − Φ^B(t)) ω^A + (ψ^A(t) − ψ^B(t))
```

A と B は同じ発火の列を受けるので、Φ^A ≠ Φ^B・ψ^A ≠ ψ^B は痕跡の差だけから来る。

**【命題 4.4】持ち越しと痕跡の効果の分け方は、一意ではない**

基準を A に取ると、D(t) ＝ Φ^A(t) δω ＋ (Φ^A(t) − Φ^B(t)) ω^B ＋ (ψ^A(t) − ψ^B(t)) とも書ける。2 つの書き方の「持ち越し」の項の差は (Φ^A(t) − Φ^B(t)) δω である。

したがって、2 つの効果を一意に分けられるのは、Φ^A ＝ Φ^B（痕跡の差が発火の Pulse に一度も効かない）か、δω ＝ 0 のときだけである。これは 0020 の M_I・M_C の基準の依存（J）と同じ形である。

### 4.4 P0 の使える範囲（項目 4）

**【命題 4.5・条件付き】4 つの腕のすべてで、切り詰めは起きず、組の和も保たれる**

- 痕跡は、どの発火の列で更新しても 0 ≤ X ≤ 1／(1 − κ) にとどまる。これは自然な履歴の t0 の値から始めても、相手の発火で更新しても同じである
- したがって循環のメモ P0 の評価（a(X_i ＋ X_j) ≤ 2a／(1 − λ) ＜ 1）がそのまま使え、σ ∈ [13／15, 1]、β ≥ 0 である
- 重みは [0, w_max] にとどまり、`plasticity.py` の切り詰めは働かない。各腕の更新は厳密に affine である
- 組の和（循環のメモ F1）：組の 2 本は、同じ 2 つの痕跡（送り手と受け手が入れ替わるだけ）と同じ発火で更新される。そのため、yoke した腕でも σ_ij ＝ σ_ji で、出生時の S ＝ w_max は保たれる
- 条件：今の値 a ＝ 0.01、κ ＝ λ ＝ 0.85（2a／(1 − λ) ＜ 1）に依る

代数の確かめでは、境界での丸めによるはみ出しが高々 1.7 × 10⁻¹⁸ あった（実数では 0。循環のメモ §7）。

**【命題 4.6】痕跡の効果の上限と、前に偏ること**

0 ≤ w ≤ w_max（命題 4.5）と Φ^B ∈ [0, 1] から、次が成り立つ。

```text
|T^B(t)| ≤ a w_max Σ_{k = t0+1}^{t} κ^(k−1−t0) ( |ΔX_i(t0)| s_j(k) + |ΔX_j(t0)| s_i(k) )
         ≤ a w_max ( |ΔX_i(t0)| + |ΔX_j(t0)| ) / (1 − κ)
```

t0 ＋ L 以後の Pulse からの寄与は、高々 a w_max (|ΔX_i(t0)| ＋ |ΔX_j(t0)|) κ^(L−1)／(1 − κ) である。

- 痕跡の差の効果は **W の初めに偏り**、t0 の後に送り手・受け手が発火しなければ 0 である
- ただし最悪の場合（|ΔX| が 1／(1 − κ) に近い）、上限は w_max と同じ大きさになりうる。実際の大きさは、t0 の直前の発火の違いで決まり、観測しなければ分からない【未解決】

### 4.5 0021 の恒等式の回復（項目 5）

**【命題 4.7】痕跡の差が 0 なら、0021 の恒等式に戻る**

ΔX(t0) ＝ 0 なら、すべての k で e^A(k) ＝ 0 なので T^B ≡ 0 で、D(t) ＝ Φ^B(t0, t) δω である。

0021 では、Y は I の複製、I は C の複製で、痕跡は残した（移植したのは重みだけ）。Y と C は同じ発火（C の発火）で可塑性を更新する。したがって A ＝ Y、B ＝ C として P ＝ Y − C ＝ Φ_C·δω である（0021 README §3・循環のメモ §5.4）。

### 4.6 Q4 の腕への当てはめ

上の A・B に、同じ可塑性の入力を受ける腕の組を入れる。

| 組 | 同じ可塑性の入力 | 初めの違い | 恒等式（操作の確認に使える） |
|---|---|---|---|
| Y_O←S と S | S の発火 | δω ＝ ω^O − ω^S、ΔX ＝ X^O(t0) − X^S(t0) | P_O(t) ≡ w^{Y_O←S}(t) − w^S(t) ＝ Φ^S δω ＋ T^S（命題 4.3） |
| Y_S←O と O | O の発火 | −δω、−ΔX | P_S(t) ≡ w^{Y_S←O}(t) − w^O(t) ＝ −Φ^O δω ＋ T^O |

**【命題 4.8】yoke した腕の重みは、走らせなくても自然な 2 個体から計算できる**

Y_O←S の重みの列は、ω^O・X^O(t0) と S の発火の列だけで決まる（Y 自身の発火に依らない）。したがって、O・S の自然な走行の記録（t0 の状態と W の全発火）から計算できる。
- 0021 の F と同じく（循環のメモ §5.4）、yoke の腕を走らせて初めて分かるのは、**その腕の活動（発火の列）** だけである

**【命題 4.9】yoke した腕は、可塑性の入力が初めて違う Pulse の 2 つ後までは、基準の個体と同じ**

t_OS ＝ min{t ＞ t0 : F_O(t) ≠ F_S(t)} と置く。

- Y_O←S は O の複製で、t_OS より前は可塑性の入力（S の発火）が O 自身の発火と同じなので、O と全状態が同じである
- t_OS の終わりに重み・痕跡が初めて違いうる。その重みが駆動に使われるのは t_OS ＋ 1、届くのは t_OS ＋ 2
- したがって Y_O←S と O の発火の列は、t_OS ＋ 1 まで同じで、違いうるのは t_OS ＋ 2 からである（0021 の t2 ≥ t1 ＋ 2 と同じ形）
- Y_S←O と S も同様である
- 自然な 2 個体は t0 ＋ 1 から違いうる（命題 2.2）ので、t_OS ＝ t0 ＋ 1 もありうる

**【命題 4.10】自然な差の分け方は恒等式で、知見ではない**

```text
D_nat(t) ≡ w^O(t) − w^S(t) = [ w^O − w^{Y_O←S} ] + [ w^{Y_O←S} − w^S ] = F_O(t) + P_O(t)
                           = [ w^O − w^{Y_S←O} ] + [ w^{Y_S←O} − w^S ] = −P_S(t) + F_S(t)
```

（F_S ≡ w^{Y_S←O} − w^S）
- どちらも足して引くだけの恒等式である
- **2 つの分け方が一致する、F_O と F_S が等しい・逆符号になる、と仮定しない**（命題 4.4 と同じ理由で、基準によって違う）

## 6. 「広げる・縮める」の観測量の候補と、式の恣意性監査

**方針**（ChatGPT）：「広げる・縮める」はまだ判定として採用しない。まず元の量を独立に扱い、自然に導ける単一の尺度がなければ、尺度を作らず量ごとの違いとして報告する。

### 6.1 元の量（尺度を作らない）

| 量 | 中身 | 時間の基準 |
|---|---|---|
| 接続ごとの符号付きの重みの差 | D_nat,ij(t)（組の和により、独立なのは組ごとの 3 つ） | t0 の値 δω_ij がある |
| 各 Unit の発火の列と、最初に違う発火の時刻 | F_O(t)・F_S(t)、t_OS、役ごと・Unit ごとの最初の違い | t0 には「発火の違い」の初めの値がない |
| 各時刻の Unit の状態の差 | Δa_j(t)・Δh_j(t) | t0 の値がある |
| 痕跡の差と、その重みの更新への効果 | ΔX(t)（自然な 2 個体では発火が違うので、命題 4.1 の形にはならない）、yoke の組での T^S・T^O | t0 の値がある |
| yoke による違い | F_O(t)・F_S(t)・P_O(t)・P_S(t)（接続ごと） | t0 で 0（F）または δω（P） |

### 6.2 「広げる・縮める」を量ごとに言うときの選択

| 候補の式 | 新しい数値 | 含まれる選択 | 問題 |
|---|---|---|---|
| 接続ごとに \|D_ij(t)\| と \|δω_ij\| を比べる | なし | 比べる時刻 t | 符号が反転して大きさが増えた場合を「広がった」と呼べない。時刻の選び方 |
| 接続ごとに sign(δω_ij)·D_ij(t) | なし | 比べる時刻 t | 同じ向きに残ったかは言えるが、大きさの比較と別。0 の扱い（識別のメモと同じく、0 を向きの一致に数えない） |
| 比 \|D_ij(t)\|／\|δω_ij\| | なし | 時刻 | δω_ij が 0 に近いと不安定（0021 で旧案の G を捨てた理由と同じ） |
| 3 つの組の差を 1 つにまとめる（和・二乗和など） | 重みづけ | 組の重みづけ・ノルムの種類 | 組ごとに広がる・縮むが違うと、打ち消し合う。どのまとめ方も選択 |
| 時間の平均 | なし | 区間 | 区間の選び方。W の初めの痕跡の効果（命題 4.6）や位相の持ち越しの区間を含むかで変わる |
| 発火の集合が違う Pulse の数 | なし | 区間 | 発火数の違いが混ざる（識別のメモ 命題 2.2）。t0 での初めの値がないので「広がった」の基準がない |
| Δa・Δh の大きさ | なし | どの Unit・どの時刻 | a と h は単位も役割も違う。まとめると選択になる |

**監査の結論**【要件】：
- 単一の「距離」「増幅率」を、模型の構造から一意に導く方法は見つかっていない
- したがって、この文書では尺度を作らず、§6.1 の量を **量ごと・接続ごと・Unit ごと** に、時刻の関数として報告する方針を候補にする
- 比・絶対値の和・ノルム・時間の平均・正規化・閾値を入れる場合は、その式そのものを恣意性監査の対象にし、結果を見る前に固定する
- 「広がった」は、量と時刻を明示した文（例：「接続 A→B の符号付きの差は、t で t0 より同じ向きに大きい」）でだけ使う

## 7. 条件付きの因果効果と、自然な媒介の境界

**【命題 7.1】自然な差には、W より前の違いと W の中の循環の違いが重なっている**

D_nat には、次の 2 つが一緒に入っている。
- t0 で既にある全成分の違い（命題 2.1）
- W の中で、それぞれの個体の発火が可塑性を動かした違い

O と S の比較だけからは、2 つを分けられない（識別のメモ 命題 3.1）。

**【命題 7.2】yoke の比較で分かるのは、背景を固定した条件付きの因果効果である**

O と Y_O←S の比較で分かるのは、「O の t0 の全状態を固定したうえで、W の可塑性の入力を O 自身の発火から S の発火に置き換えたときの効果」である。
- 重みについては F_O、活動については Y_O←S の発火の列と O の発火の列の違い
- これは自然な O と S の違いのうち、循環が占めた割合ではない

**自然な媒介を同定できない理由**：
1. yoke の腕は自然な個体ではない（人工の組み合わせ：O の状態に、S の活動が可塑性を駆動する）
2. 寄与は一般に足し算に分けられない（識別のメモ 命題 3.4）。同じ置き換えの効果は背景（O か S か）で違いうる
3. 2 つの分け方（命題 4.10）は、どちらも足して引くだけの恒等式である。どちらかを「正しい分解」とする根拠はない
4. yoke は循環を取り除くのではなく、相手の活動（相手自身の循環の結果を含む）に置き換える（§3.1）

**【要件】仮定しないこと**：両向きの yoke の効果について、次のどれも仮定しない。
- 等しい
- 符号が逆になる
- 足し合わせれば自然な差に戻る（命題 4.10 は 1 つの向きの中の恒等式で、2 つの向きの効果の和についての主張ではない）
