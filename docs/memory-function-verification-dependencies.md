## 1. 共通の道具

### 1.1 記号

- 個体の出生時の状態を b、経験の履歴を H とし、経験の後（試しの直前の時刻 t_p）の内部の状態を s_H ＝ Φ_H(b) と書く。外部の記録 D と固定された規則 F は、比べる腕で同じにする（契約 §0.5。そうでない結果は内部の記憶の証拠にしない）

### 1.4 観測の様式：自然に現れたことと、誘発できたことを分ける（欄 (c)）

| 様式 | 状態 | 入力 | 何を示すか |
|---|---|---|---|
| **O-N 自発** | 経験の後の自然な状態 | 試しを与えない（または世界のふだんの入力だけ） | 経験の違いが、求められずに後の活動に現れたか（t-k さんの「尋ねられなくても動き出す」に当たる観測の様式） |
| **O-P 試し** | 経験の後の自然な状態 | 研究者が決めた試し | 経験の違いが、試しへの自然な応答に現れたか |
| **O-I 介入** | ℐ で一部を変えた状態 | 試し、または試しなし | 選んだ背景の上で、その部分がその読み出しを変えうるか（条件付きの因果効果。識別のメモ 命題 3.4） |

- **O-I で差が出たことは、O-P・O-N で差が出ることを含意しない**（次の命題 1）。**O-P で差が出たことは、O-N で差が出ることを含意しない**【命題（構成）】：状態を (c, z)、試しの読み出し R-P が c に、自発の読み出し R-N が z に依り、経験の違いが c にだけあれば、R-P は違い R-N は違わない（試しの入力が、自発の活動では効かない成分の違いを引き出す場合）
- 既存の実験を様式で分けると：0014 の p・0016〜0019 は O-I、0014 の as_is と 0012 の H1 は O-P、0015 の終端の重みは R-S（② (a)）、0020〜0022 の介入の腕の発火の列は O-N の上の O-I（0020 は ℐ-1、0021・0022 は ℐ-2）、0022 の t_OS（同じ出生時の状態から ordered・shuffled を経た自然な 2 個体 O・S の自発の発火が、最初に違う時刻）は O-N の自然な比較である【既存の結果の分類】

**命題 1（誘発と自然な発現は、どちらの向きにも含意しない）【命題（構成）】**：状態を 2 つの成分 (c, z) ∈ ℝ² とし、試しへの読み出しを R とする。

- **(a) 誘発できても、自然には現れない（打ち消し）**：R(c, z) ＝ c ＋ z、経験 H_a の後が (δ, −δ)、H_b の後が (0, 0)（δ ≠ 0）とする。自然な状態の比較では R ＝ 0 と 0 で差がない。ところが H_b の状態に、成分 c だけを H_a の値へ移す（ℐ-1）と (δ, 0) で R ＝ δ となり、差が出る
- **(b) 自然には現れても、成分ごとに戻す介入では消えない（冗長）**：R(c, z) ＝ 1[c ＞ 0 または z ＞ 0]、H_a の後が (1, 1)、H_b の後が (0, 0) とする。自然な比較では R ＝ 1 と 0 で差がある。H_a の状態の c だけを H_b の値に戻すと (0, 1) で R ＝ 1、z だけを戻しても (1, 0) で R ＝ 1 で、どちらの単独の「戻す」介入でも差は消えない（両方を戻せば消える）

（証明：値を代入するだけ。）

**意味**：
- 介入で誘発できたこと（O-I）は、「その部分がその背景で効きうる」ことまでで、自然な個体でその違いが振る舞いに現れたことではない。(a) の形は、0012 の事後の解釈（重みの効果が、ほかの状態の違いに打ち消されて、ふだんの活動に出なかった）と同じ形であるが、**その解釈が正しいかはこの命題からは言えない**
- 単独の成分を戻す介入で差が消えないことは、その成分が関与しないことを意味しない。(b) で H_b の状態に c だけを移せば (1, 0) で R ＝ 1 となり差が出るので、**移す向きと戻す向きで結果は違いうる**。どちらの向きの介入か、単独か組み合わせかを、結果の前に決める【要件の候補】

## 2. 観測されなかったとき、何を否定でき、何を否定できないか（欄 (b)）

### 2.1 命題 2（否定的な結果が反証するもの）【命題】

事前に決めた検証を、条件の組 Γ ＝（世界、設計図と値、出生時の状態の分布、seed、経験の組の種類、読み出し R とその窓、介入 ℐ、判定の基準）と、予測「Γ のもとで、R が判定の基準を満たす」の組とする。否定的な結果は、**この予測が Γ のもとで成り立たなかった**ことを示す。

一方、MF の働きがある（例えば ① が成り立つ）という主張は、許される R・世界・経験の組の**どれかで**成り立つ、という存在の主張である。したがって、

- 1 つの Γ での否定的な結果は、その Γ の予測を反証するが、**ほかの R・世界・値・経験の組での成立を反証しない**
- 個体の割合の判定（例：20 個体のうち 16 以上）が満たされなかったことは、その割合の予測の反証であって、**どの個体でも働きがないことを示さない**

（証明：論理だけ。存在の主張は、1 つの例の否定では反証されない。）

### 2.2 三つの説明を分ける

否定的な結果の説明として、方針案 §3 (b) の三つを、読み出しの部類 ℛ（結果の前に決めた、許す読み出しの集合）に相対的に定義する。個体 b と経験の組 (H_a, H_b) について、s_a ＝ Φ_{H_a}(b)、s_b ＝ Φ_{H_b}(b) とし、

  s_a ≈_ℛ s_b  ⇔  ℛ のすべての R で R(s_a) ＝ R(s_b)

と書く（研究②の命題 2 の同値で、許す操作を ℛ の試しの列に限ったもの）。

| 説明 | 定義 |
|---|---|
| **R が合っていない** | 使った R では R(s_a) ＝ R(s_b) だが、ℛ の別の R′ では R′(s_a) ≠ R′(s_b)（s_a ≉_ℛ s_b） |
| **（ℛ に対する）働きの不在** | s_a ≈_ℛ s_b（ℛ のどの読み出しでも区別できない） |
| **C0 の構造の限界（ℛ・𝓗・𝓑 に対する）** | 読み出しの部類 ℛ と経験の組の種類 𝓗 が**どちらも空でなく**、許す出生時の状態の集合 𝓑 のすべての b と、𝓗 のすべての組で s_a ≈_ℛ s_b |

**命題 3（三つの説明の関係）【命題】**：
1. 構造の限界 ⇒ 𝓑・𝓗 の各個体・各組で働きの不在 ⇒ その個体・その組では、ℛ の各 R で R(s_a) ＝ R(s_b)（個体ごとの否定的な結果）
2. 逆はどれも一般には成り立たない
3. 𝓗 が空（世界にその経験の種類がない）なら「すべての組で」という主張は空虚に真になり、ℛ が空（読み出しの出口がない）なら ≈_ℛ はどの状態のあいだでも成り立つ。どちらも構造の限界とは呼ばない（定義で ℛ・𝓗 が空でないことを要求した理由）。これは**検証の材料がない**ことで、構造の限界とも未検証とも別である

（証明：1 は全称の主張を個々の場合に当てはめるだけ。2 は、ある R で否定的でも別の R′ で区別できる例（例えば R が c だけ、R′ が z だけを読み、s_a ＝ (0, 1)、s_b ＝ (0, 0)）と、ある個体で不在でも別の個体で区別できる例で示せる。3 は全称の空虚な真の定義から。）

**意味**：
- **観測の失敗だけから、構造の限界は言えない**。構造の限界を言うには、𝓑 と 𝓗 のすべてについて区別できないことを、構造と力学の前提から示す必要がある（ChatGPT の条件）
- 働きの不在も ℛ に相対的である。ℛ が狭すぎれば、ℛ に対して不在でも、働きそのものの不在ではない。**ℛ は結果の前に決める**（契約 §0.3）
- 実際の検証は、ℛ のすべてを試せないことが多い。そのとき言えるのは、試した R についての否定までである

### 2.3 構造上観測できないことを示す方法（十分条件）

命題 3 の構造上観測できないことを示すために使える十分条件。どれも、**特定の ℛ・担い手・個体に相対的**である。

| 種類 | 内容 | 例（§3 で使う） |
|---|---|---|
| **(S1) 読み出しの通り道がない** | 設計図に、その R が読む出口がない（ℛ が空）。このとき、その R の部類ではどの状態も区別できない。**命題 3 の定義では構造の限界に入れず、「検証の材料がない（出口がない）」とする**。出口を足せば変わる、設計図の条件である | MF9 後半（行動の出口がない）。MF10 の操作は、活動を読む出口はあるので S1 ではなく、世界に課題がない（命題 3 の 3） |
| **(S2) 状態が一致する** | 2 つの経験の後の状態が同じ（s_a ＝ s_b）なら、どの R でも区別できない（識別のメモ 命題 3.1、U1） | 一般 |
| **(S3) 担い手を限った読み出し** | R が状態の一部の成分 c だけの関数で、経験の違いがその成分では区別されないなら、その R では区別できない | 学習した接続は組ごとの 3 つの値しか運ばず、経験した時間差を別々に持たない（識別のメモ 命題 3.3、U7）。重みだけを読む（R-S を重みに限る）・重みだけを移す（ℐ-1）比較では、**最終の重みの値が一致する履歴どうし**は区別できない。これは圧縮であって、時間差の違いを一切区別できないことではない（1 組の発火の寄与は時間差 L で κ^(L−1) なので、0 ＜ κ ＜ 1 なら時間差 2 と 30 で違う値になる） |
| **(S4) 個体ごとの沈黙** | R がある Unit の発火を要し、その Unit がその区間で発火できないことが示せるなら、その個体ではその R は値を変えない | 再評価 命題 3.3b（閾値から遠い Unit は、入力のない時間に他の Unit に発火させられない） |

- (S3) が示すのは「その担い手だけでは区別できない」ことで、**ほかの担い手（位相の持ち越し・痕跡・遅い変数など）での区別は否定しない**。MF の段階での構造の限界ではない
- (S4) は個体ごとの条件で、**ほかの個体や、入力のある区間での区別は否定しない**

## 3. MF ごとの整理

各 MF について、(a) 証拠の三段階と R・ℐ の候補、(b) 否定的な結果の射程、(c) 様式、(d) 今の 3 Unit、(e) 依存を書く。契約の各 MF の表（定義・対立する説明・対照）は引き継ぎ、ここでは繰り返さない。(d) は次の 4 つに分ける。

| (d) の区分 | 意味 |
|---|---|
| **構成要素の証拠** | 契約 §4 の左の列（〔構成要素：観測〕〔構成要素：介入〕）。MF の段階の確認ではない |
| **未検証** | MF の段階 ① ② を確かめていない。検証の材料がない、または構造上観測できない、とは示していない |
| **検証の材料がない** | 世界にその経験・課題の種類がない（命題 3 の 3）、または設計図に読み出しの出口がない（§2.3 の S1）。Unit の力学の限界ではない |
| **構造上観測できないと示した** | §2.3 の十分条件で示したもの。どの ℛ・担い手・個体についてかを書く |

### MF1 似た経験を区別して保持し、使う

- (a) ①：K1 の 2 個体（E・E′。入力の側の似かたの尺度は結果の前に決める）で、R-P または R-N の値が違う（L2）。② (a) R-S の違い、(b) その違いが ① の R に現れる、(c) ℐ-1 で対象の部分だけを移す・戻す。③ どの成分が区別を運ぶか
- (b) 区別できなかったことは、その R・その似かたでの予測の反証。似かたが近すぎた（X4）、保持の長さが足りない（X6）を分けるために、似かたと遅延を複数の水準で決めておく【要件の候補】
- (c) O-P が基本。O-N（区別された経験が自発の活動に違う形で現れるか）は MF5・MF6 と共通の問い
- (d) **検証の材料がない**：刺激の同一性は配線が与え、似ている度合いを持つ経験が今の世界にない（契約 MF1）。構造の限界ではない
- (e) 〔論〕P0（§4.2）。〔模〕C1 では Unit の内部の素子ごとの模様は表現されないので、それを区別の担い手や観測の要件にはできない（S1 §2.2）。区別そのものは、1 つの Unit の活動率の値の違い（例えば 0.2 と 0.8）でも、Unit をまたぐ模様でも表しうる。その違いが持続するかは、力学で別に確かめる。〔模〕入力の似かたの尺度（契約 §7 の 1）が要る。〔仮〕まばらな符号・直交化（S2 の実現の仮説）

### MF2 一回の経験から、後で使える情報を保持する

- (a) ①：1 回の E と、なし（K2）、および別の 1 回の E″（K1）。内容に特有の違いか（量だけの違いでないか：X7）を見る。遅延は短期・中期・長期で分ける（契約 MF2）。② (c) は ℐ-1 で経験の直後の対象の部分を戻す
- (b) 遅延の後に違いがないことは、その遅延・その R での予測の反証。より短い遅延での保持や、別の担い手での保持は否定しない。**短い時間の保持を記憶でないとは言わない**（X6 は長い保持を主張するときだけの対立説明）
- (c) O-P（1 回の経験の後の試し）が基本
- (d) **未検証**（実験は 200 回の試行で行った。1 回の経験の条件は、今の Receptor のまま刺激の時間配置を決めれば作れる形だが、それが世界の変更に当たるかは【未決】）。1 回の Pulse の更新で強まる重みは上限の約 6.7% 以下（S1 §3.1）というのは**式の上限で、構造の限界ではない**。重み以外の担い手（順応・痕跡）を含めた 1 回の経験の効果の上限は示していない
- (e) 〔論〕P0。〔模〕𝒜 の 1 変数の規則では、1 回の書き込みの大きさは r w_max 以下で、大きく書くと後の出来事で早く上書きされる（研究③ 命題 3・5）。〔仮〕一回で書き込む可塑性、連想記憶（S2）

### MF3 順序・時間の間隔を区別して保持し、使う

- (a) ①：同じ要素の ordered と shuffled（K1）で、R-P・R-N の値が違う（L2）。経験した順序に対応すること（L3）は、対応の規則 R を結果の前に決めて別に主張する（識別のメモ §5.3）。② (c) は ℐ-1 で重みなどを移す
- (b) L2 の否定的な結果は、その R・窓での予測の反証で、L3（対応の規則 R による別の主張）は検証していない。逆に L2 が成り立っても L3 は含意されない（識別のメモ 命題 5.2）
- (c) **O-I では構成要素の証拠があるが、O-P の自然な発現は未検証**（0014 の as_is は記録、0012 の H1 は fails）。O-N は未検証
- (d) **構成要素の証拠**：順序で重みに差ができる（0014 の w 19／20、0012 の M）、その差を状態をそろえた複製に載せると直後の応答が変わる（0014 の p、0016〜0019）。**MF の段階**：① ② 未検証。**構造上観測できないと示した（担い手と履歴の組に限って）**：学習した接続は組ごとの 3 つの値しか運ばないので、重みだけを読む・重みだけを移す比較では、**最終の重みの値が一致する履歴どうし**は区別できない（S3。識別のメモ 命題 3.3、U7）。時間差が違えば重みの値は一般に違いうるので、時間差の違いを重みで一切区別できないとは言わない。位相の持ち越し・痕跡を含む全体の状態での区別は否定しない。**間隔**は、間隔だけが違う経験が今の世界にないので**検証の材料がない**
- (e) 〔論〕P0。〔論〕順序を重みに書くには L ≥ 1 の窓（痕跡か遅延）が要る（研究③ 命題 2 (b)。重みに依らない規則の場合）。〔模〕U7（圧縮。最終の重みが一致する履歴は重みだけでは区別できない）。〔模〕学習しない経路（内在の周期と位相の持ち越し）が経験に似た時間の関係を作りうる（X5、U4）ので、K7 の対照が要る。〔未決：R・ℐ に依る〕L3 の規則

### MF4 素早い学習と長期の保持を、新しい学習と両立させる（前半）／何を長く保つかが変わる（後半）

- (a) ①：E1 だけ／E1 の後に E2／E2 だけ、を時間をおいて比べる。② (c) は遅い時点での ℐ-1。後半の ② は、経験の後の過程を止める（**ℐ-2**）ので、研究②の命題 2 の対象外である
- (b) E1 の効果が残らないことは、その E2・その遅延での予測の反証。新しい学習を挟まない保持の成功は、両立の証拠にならない（契約 MF4）
- (c) O-P が基本
- (d) **構成要素の証拠**：重みの差が入力のない 12000 Pulse の後も多くの個体で同じ向き（0015 の 19／20。凍結の 4 個体を含む）、長い自発の活動の後の重みが標準化した試しへの応答を変える（0016 の 18／20、0017）。**MF の段階**：未検証（新しい学習を挟む設計をしていない）。後半は**検証の材料がない**（性質の違う経験と、保持を選ぶ信号がない）
- (e) 〔論〕P0（長い遅延）。〔模〕**𝒜 の 1 変数の規則では、古い内容を残すことと後で学ぶことが、後の出来事の量で結ばれる**（研究③ 命題 5）。これは**書き込みの大きさと、後の出来事による忘却の速さのトレードオフ**で、両立が不可能という証明ではない。1 変数の 𝒜 でも、後の出来事が有限で r ＜ 1 なら前の出来事の取り分は 0 にならず（研究③ 命題 4）、E1 と E2 の違いは小さくなりながら最終の重みに残りうる（それが MF4 の十分な実現かは別）。2 つ以上の変数（研究③ 命題 7）は、このトレードオフを調整する構成の一つで、必要条件ではない。非負・単調・線形の応答なら、出来事の数 n について 1／(n ＋ 1) の上限が残る（研究③ 命題 6。上限であって不可能の証明ではない）。〔模〕凍結による保持と活動の中の保持を分ける（X8）。〔仮〕速い変数から遅い変数への移し替え・固定化（S2、研究③ §4.5）。〔未決〕後半の「性質」を価値を使わずにどう定めるか

### MF5 新しい入力のない間の、保持内容の安定化・統合

- (a) ①：入力のない期間の前後の、経験に依存した保持と利用の変化の**記述**（契約 MF5）。② は、その期間の可塑性や自発の活動を止める・置き換える介入（**ℐ-2**、K4）で、研究②の命題 2 の対象外。③ は、その期間の活動が経験した構造に対応するか（L3）
- (b) 入力のない期間に保持が「良く」ならなかったことは、MF5 の否定ではない（MF5 は候補で、良くする必要があるかは【未決】）
- (c) **O-N（自発）が中心**。t-k さんの「尋ねられなくても過去をきっかけに動き出す」の観測の様式は、この MF と MF6 の O-N 版に当たる
- (d) **構成要素の証拠**：入力のない期間に差の多くが縮んだ（0015）、自分の発火による可塑性を別の発火の列に置き換えると後の自発の発火が変わる個体が多い（0021、0022）。**O-N の自然な比較**：同じ出生時の状態から ordered・shuffled を経た自然な 2 個体 O・S の自発の発火は、98 個体で W の初めから分かれた（0022 の t_OS。t_OS − t0 の中央値 22.5）【既存の結果】。これは P0 と、O-N で何らかの違いが自発の活動に現れたこと（L2 の差の存在）の観測だが、内容に特有か（X7）、短い時間尺度の状態や位相の持ち越しだけで説明できるか（X5・X6）、どの担い手かは分けていない。契約 §4 もこれを MF5 の構成要素の証拠に挙げていない。**MF の段階**：未検証。L3 も未検証
- (e) 〔論〕P0（期間の前に、経験に依存した違いがあること）。〔模〕C0 では自発の活動による出来事も古い内容を上書きする（研究③ §4.4）。〔模〕ℐ-2 を含む因果の抽象化は未決（研究② §9 の 3c）。〔仮〕再活性化を通した安定化（S2 の Con3）。〔未決：R・ℐ に依る〕L3 の規則（識別のメモ §7）

### MF6 部分的な手がかりから、過去の経験に由来する状態を再構成し、後の処理に使う

- (a) ①：(p1, p2) と (p1, p3) を経験した 2 個体（K1）に同じ p1 だけを与え、後の R-P が欠けた部分に応じて違う。**保持（R-S の違い）と取り出し（手がかりの後の R-P の違い）を分けて測る**（契約 MF6）。③ の問い（手がかりの後の状態が経験したときに似るか）を合格の条件にしない
- (b) 手がかりの後に違いがないことは、その手がかり・その窓での予測の反証。保持がないことは示さない（取り出せないことは保持がないことではない：S2 の Rec2）。命題 1 (a) の打ち消しで、保持された違いが自然な応答に出ないこともある
- (c) O-I（介入）では構成要素の証拠がある。**O-P は未検証**。O-N（手がかりなしに、経験に由来する処理が起きる）は自発的な想起の問いで、未検証（0022 の t_OS は自発の活動の違いの観測だが、手がかりにない部分に依存した処理かは分けていない）
- (d) **構成要素の証拠**：重みの差を状態をそろえた複製に載せると、手がかり A の後の B・C の応答が変わる（0014 の p、0016〜0019）。重みと発火を別々に観測できる（0022 の (b) 14 個体）。**MF の段階**：① ② 未検証。今の Receptor（A・B・C）のまま、経験の時間配置を「A の後に B」と「A の後に C」にすれば、p1 ＝ A、欠けた部分 ＝ B か C、の形を作れる（0014 は ordered の経験の後に A を手がかりとして B・C の応答を読む、これに近い形である。p は O-I、as_is は O-P の判定のない記録）。その配置が世界の変更に当たるかは【未決】
- (e) 〔論〕P0（手がかりの時刻に、欠けた部分に応じた状態の違い）。〔模〕速い活動の多重の安定状態（自己連想の補完）で実現するなら、活動率の模型で L·k·w_max ≥ 1 が要る（S1 命題 2.4。特定の実現の必要条件で、働きの必要条件ではない）。C0 で発火による再構成を行うなら、接続の本数の弱い必要条件がある（S1 命題 2.5 の系）。〔仮〕アトラクター・前向きの連想・索引（S2 の Rec1）

### MF7 個々の経験の区別と、共通の構造の抽出・利用を両立させる

- (a) ①：新しい具体への反応（汎化）と、学んだ具体の区別（MF1 の形）。② (c) は共通の成分・具体の成分を ℐ-1 で移す。外部のエンコーダの事前知識（X2）を K6 で除く
- (b) 汎化が見えないことは、その新しい具体・その構造での予測の反証
- (c) O-P が基本
- (d) **検証の材料がない**（具体が違い構造が共通する経験の集まりが今の世界にない）
- (e) 〔論〕定義により MF1 の ① の形を含む（(ii)）。〔論〕P0。〔模〕入力の似かたの尺度（MF1 と共通）。〔仮〕一つの系か二つの系か（S2 の Gen1）

### MF8 新しい学習による破局的な干渉を避ける

- (a) ①：E1 → E2（E1 と要素が重なる）と E1 →（中立の期間）で、E1 の試しへの反応を比べる。② (c) は ℐ-1
- (b) 重ならない E2 での「干渉がない」は自明で、証拠にしない（X11）。重なる E2 で E1 の効果が消えたことは、その重なり・その規則での予測の反証
- (c) O-P が基本
- (d) **未検証**（経験を順に 2 つ学ぶ設計をしていない）

### MF9 思い出さなくても処理を変える（前半）／思い出した内容が判断に入る（後半）

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

「AnIma-ll が覚えている」「思い出した」「自分から昔のことをきっかけに動いた」を、**どうやって確かめるか**と、**確かめられなかったときに何が言えるか**を整理しました。記憶をどう作るかは決めていません。

### 分かったこと

1. **確かめ方には 3 つの様子があります。** (1) こちらが中をいじって起こした反応、(2) ふつうの状態で、こちらが問いかけたときの反応、(3) 何も問いかけないのに自分から出てくる反応、です。(1) ができても (2) ができるとは限らず、(2) ができても (3) ができるとは限りません。これまでの AnIma-ll の実験で確かめたのは、ほとんどが (1) でした。(3) については、違う経験をした個体どうしで自発の活動が分かれることまでは見えていますが、それが経験の中身を思い出したものかは、まだ分かりません
2. **「確かめられなかった」は「できない」ではありません。** 確かめ方（何を見るか）が合っていなかったのかもしれませんし、その個体だけの事情かもしれません。「今の作りでは原理的にできない」と言うには、試してだめだったことではなく、作りそのものから証明する必要があります
3. **どの記憶の働きにも共通して、論理的に必ず要るものが 1 つあります。** 確かめる時点まで、経験による何らかの違いが中に残っていることです。ただし、どこに・どんな形で残るかは決めていません
4. **今の 3 Unit で「作りとして確かめられない」と示せたのは、ごく一部です。** 例えば「経験の結果、つながりの強さがたまたま同じ値になった 2 つの経験は、つながりの強さだけを見ても区別できない」といった、見る場所と比べる経験を限った場合だけです。「思い出した内容で行動を選ぶ」は、行動の出口がまだないので試す材料がない、という扱いです。ほかの多くは「まだ確かめていない」です
5. **次に確かめるとよさそうなのは**、「ふつうの状態で問いかけたとき（(2)）に、経験の違いが反応に出るか」です。今の世界でも材料があり、これまでの実験はここを判定として確かめていませんでした。ただし実験は、別に事前登録と承認が要ります
