### 0.2 結論の先取り

1. **介入の参照に照らした「戻す」は、残りの塊を O から「移す」ことと同じ**（命題 B）。したがって、二つの塊に分けたときの C-II（設計の整理 §3.1 の形）は、「塊 c を移すと外れ、残りの塊 z を移しても外れない」、つまり **c の排他性** の主張になる
2. 排他性の半分（z を移しても外れない）は**帰無仮説を棄却できなかったこと**で、これまでの統計の枠（個体の中の交換可能性を帰無仮説に、個体間の独立性を前提に置いた二項の上界）では積極的に示せない。また、**N・R・E の連言の数を数えても、帰無のもとの上界は一つの検定のものより小さくならない**（命題 C）
3. O の自分の背景での比較（自然な O と、O の背景に W の塊を入れた混成）は、**自己一致の効果**（自然な状態と混成の違い）を O の特異性と取り違える（命題 D）。0026 は受け手 W1 をドナーに含めないことで、これを避けていた
4. 積極的に検証できるのは、**混成どうしを比べる「移す」型の比較（C-I）**である。0026 の単一の背景の限界に答える C-I の一般化（背景を増やす）は候補になる（§8 の C2-a）。消去の向きを残すなら、O と同じ操作を W にも施した対称な対照と比べる、新しい統計の枠が要る（§8 の C2-b・C2-c）
5. どれを行うか（行わないか）は、方針どおり、E4 の後の C0 の研究レビューで決める

## 1. 記号と四つの出来事

- 1 個体の自然な本体を 𝒩 ＝ {O, W_1, …, W_K}（O は順序あり、W_i は試行の中の並べ替え）とする
- 共通の時刻 T（0026 §2.2 の規則：T の処理の終わりに、どの本体にも置かれた駆動がない）で、本体 a の状態を **(c_a, z_a)** と書く。c は調べる塊、z は残りの塊（0026 では c ＝ 重みなら z ＝ Unit の状態、その逆も）
- **混成** Y(a, b)：本体 b の T の状態の c の欄を本体 a の値にした本体（状態 (c_a, z_b)）。T より後は同じ試しをする。Y(a, a) は a の自然な軌道と一致する（0026 の全部の入れ替え・入れ替えなしの確認と同じ形）【既存の結果】
- L(a, b) ≔ L(Y(a, b))。自然な L(a) ＝ L(a, a)
- 外にある：x が集合 S の外 ⇔ x ＞ max S または x ＜ min S（厳密な不等号。0023〜0026 と同じ）。内 ⇔ 外でない

個体ごとの出来事：

| 記号 | 出来事 | 向き・参照 |
|---|---|---|
| **N** | L(O, O) が {L(W_i, W_i)}_{i＝1..K} の外 | 自然な比較（0025 の主と同じ形） |
| **R_b**（b は W のどれか） | L(O, b) が {L(W_k, b)}_{k ∈ 𝒟_b} の外（𝒟_b ⊆ {W_1..W_K} ∖ {b}） | 移す向き、介入の参照（0026 の C-I は b ＝ W1） |
| **E^int_k**（k は W のどれか） | L(W_k, O) が {L(W_k, W_j)}_{j ∈ ℬ_k} の内（ℬ_k ⊆ {W_1..W_K} ∖ {k}） | 戻す向き、介入の参照（設計の整理 §3.4 の「並べ替えどうしで入れ替えた値と比べる」） |
| **E^nat_k** | L(W_k, O) が {L(W_i, W_i)}_{i＝1..K} の内 | 戻す向き、自然な参照 |

設計の整理 §3.1 の C-II は、塊 c について **N ∧ R ∧ E**（両方の向き）である。どの背景 b・どの戻すドナー k を使うか、E を介入の参照で見るか自然な参照で見るかは、設計の整理では決めていない【既存の命題】。

## 2. 命題 B（介入の参照に照らした「戻す」は、残りの塊の「移す」である）【命題】

塊 c を戻すドナー k について、

```text
混成 Y(W_k, O) の状態 ＝ (c_{W_k}, z_O) ＝ 「W_k の背景に、O の z を移した本体」
その介入の参照 {Y(W_k, W_j)}_{j∈ℬ_k} の状態 ＝ {(c_{W_k}, z_{W_j})} ＝ 「W_k の背景に、W_j の z を移した本体」の集合
```

したがって、

```text
E^int_k(c)  ⇔  ¬ R^{(z)}_{W_k}        （塊 z の「移す」で、背景 W_k、ドナーの参照 ℬ_k のとき）
```

（証明：定義どおりに書き下す。混成の状態が同じなら、T より後の軌道と L は同じ（0026 §3 の命題 A と同じ理由）。）

**帰結 1（C-II は排他性になる）**：介入の参照に照らした C-II は

```text
C-II^int(c)  ＝  N  ∧  R^{(c)}_b  ∧  ¬ R^{(z)}_{W_k}
```

で、「c を O から移すと外れる（十分性）」と「z を O から移しても外れない」の組、つまり**二つの塊のうちで c だけが外れを運ぶ（排他性）**という主張になる。

**帰結 2（二つの塊の両方で C-II^int が同じ個体で成り立つことはない）**：塊 c の C-II^int を背景 b で、塊 z の C-II^int を戻すドナー b で見ると、前者は R^{(c)}_b を、後者は（命題 B を z と c を入れ替えて使うと）¬R^{(c)}_b を必要とする（参照の集合を同じにしたとき）。両立しない。

**帰結 3（塊を三つ以上に分けても同じ）**：塊 c を O に戻すことは、c 以外のすべての塊（の和）を O から移すことと同じである。分け方を細かくしても、介入の参照に照らした「戻す」は、つねに補の「移す」になる。

- 0026 §3 の命題 A は、この命題の二つの塊の場合を「同じ混成状態の二つの書き方」として述べたものである【既存の命題】。0026 はそれを C-II の実証と同一視しないとした。この文書でも、命題 B は**自然な O の外れが消えたこと**（E^nat）を言わない

## 3. 命題 C（排他性は、これまでの帰無仮説の枠では積極的に示せない）【命題】と【命題（構成）】

**帰無仮説の置き方（これまでと同じ形）**：個体の中で、O は W と、自然な本体としても、塊のドナー・背景としても交換可能（同時の交換可能性）。個体間の独立性は統計モデルの前提に置く。

**(i) ¬R は棄却できなかったことにすぎない**：帰無仮説のもとで、P(R_b) ≤ 2／(|𝒟_b| ＋ 1)。したがって P(¬R_b) ≥ 1 − 2／(|𝒟_b| ＋ 1)（|𝒟_b| ＝ 19 なら 0.9 以上）。「z を移しても外れなかった」は帰無仮説のもとでもふつうに起こり、z が外れを運ばない証拠にはならない。

**(ii) 連言の上界は、一つの検定の上界より小さくならない**：

```text
P(N ∧ R_b ∧ E_k) ≤ min{ P(N), P(R_b) } ≤ min{ 2／(K ＋ 1), 2／(|𝒟_b| ＋ 1) }
```

右の不等号は帰無仮説から、左の不等号は連言の確率がどの成分の確率も超えないことから。**N の上界 2／(K ＋ 1) は、連言のままで、同時の交換可能性のもとで達成されうる**：

- 構成：L(a, b) ＝ f(c_a)（L が c だけで決まる。c が唯一の担い手）とし、(c_a, z_a) を本体のあいだで独立に同じ分布から選ぶ（同時の交換可能性が成り立つ）。f(c) は連続な値で、同じ値は確率 0 とする
- N は「f(c_O) が {f(c_{W_i})} の最大より大きいか最小より小さい」。𝒟_b は W の一部なので、N ⇒ R_b
- E^int_k：L(W_k, O) ＝ f(c_{W_k}) で、参照 {L(W_k, W_j)} ＝ {f(c_{W_k})} はすべて同じ値なので、内（等号は内）。つまり E^int_k はつねに成り立つ
- よって C-II^int ⇔ N で、P(C-II^int) ＝ P(N) ＝ 2／(K ＋ 1)

（証明：構成に値を当てはめる。P(N) は K ＋ 1 個の独立で同じ分布の連続な値のうち O が最大か最小である確率。）

**意味**：
- 「N と R と E がすべて成り立った個体」を数えても、帰無のもとの上界は N だけを数えたときと同じ 2／(K ＋ 1) で、20 個体の判定の閾値は一つの検定と同じ（K ＝ 19 なら h ≥ 5）になる。**成分の確率を掛け合わせた上界（例：0.1 × 0.1）は使えない**（N と R は同じ c_O を通して従属する。上の構成では N ⇒ R）
- 連言を要ることで、帰無のもとの確率は小さくならず、対立のもとで成り立つ個体だけが減る（検出力が下がる）
- 連言に E（棄却できなかったこと）を入れても、排他性の証拠は増えない。C-II^int の「成立」は、排他性の読みを、棄却できなかったことを通してしか足さない

**帰結**：介入の参照に照らした C-II（二つの塊）を、0023〜0026 と同じ枠の事前登録した判定にしても、その成立が言えるのは「N か R の検定が棄却された」ことまでで、排他性ではない。**この形のまま実験にすることは勧めない**（§9）。

## 4. 命題 D（O の自分の背景での比較は、自己一致の効果を O の特異性と取り違える）【命題（構成）】

戻す向きを、介入の参照ではなく **O の背景の中で**見る比較が考えられる：自然な O の L(O, O) を、O の背景に W の c を入れた混成 {L(W_k, O)} と比べる（「O の背景では、O 自身の c が W の c と比べて典型的でないか」）。

- 構成：L(a, b) ＝ 1［a ＝ b］（自然な状態なら 1、混成なら 0。**自己一致の効果**）
- すべての個体で、L(O, O) ＝ 1 は {L(W_k, O)} ＝ {0} の外にある。**W_j の自分の背景でも同じ**（L(W_j, W_j) ＝ 1 は {L(W_k, W_j)} の外）。O に特有のものは何もない
- このとき、「O の背景への c のドナーとして、O は W と交換可能」という帰無仮説はどの個体でも偽で、O が外にある確率は 1 になる。二項の上界（各個体 0.1 以下）は成り立たない

（証明：値を代入するだけ。）

**意味**：自然な状態（自己一致の状態）と混成（一部だけを入れ替えた状態。設計の整理 命題 2 のとおり、自然な経験から到達しないことがある）は、系統的に違いうる。O の自分の背景での比較は、その違いを含む。**0026 は、受け手 W1 をドナーに含めないことで、どの比較も混成どうしになるようにしていた**（受け手の背景で、ドナー O もドナー W も混成）。

- 同じ理由で、E^nat（混成 L(W_k, O) を自然な本体の L と比べる）も、自己一致の効果を含む。上の構成では L(W_k, O) ＝ 0 はつねに自然な {1} の外（下）で、E^nat はつねに成り立たない。別の構成では、ほぼつねに成り立つようにもできる（例：自然な値 L(a, a) を 0 を中心に連続に散らばる値とし、混成をすべて L(a, b) ＝ 0（a ≠ b）とすると、0 はほとんどつねに自然な値の最小と最大のあいだにあり、E^nat は O と関係なくほぼつねに成り立つ）
- したがって、戻す向きを O の背景で見るなら、**同じ操作を W_j の自分の背景にも施した対照**（W_j の自然な状態と、W_j の背景の混成の比較）と比べる必要がある【候補】（§8 の C2-c）

## 5. 個体の選び方と平均への回帰（設計の整理 命題 6 の再掲と、消去の向きへの当てはめ）

- 設計の整理 命題 6：外にあることで個体を選ぶと、L(O) が分布の端にある個体を選ぶことになり、どんな入れ替えでも L は端から内側へ動きうる。**選んだ個体で「戻すと外れが消えた」が多く出ることは、塊の役割がなくても起こりうる**【既存の命題】
- E^nat は、N が成り立つ個体（O が端にある個体）で意味を持つ出来事なので、この問題をそのまま持つ。設計の整理 命題 4 (a) のとおり、塊の自然な値と関係のない置き換えでも外れは消えうる【既存の命題】
- 対称な対照の考え方【候補】：個体の中で、O と同じ「戻す」操作を W の本体にも施し、その消え方と O の消え方を比べる。同時の交換可能性のもとで O の消え方が対照の消え方と交換可能になるのは、**操作を受ける本体を選ぶ規則が O と W で同じとき**に限る（例：20 本体すべてに施す。O はつねに含め、W は端にあるものだけを選ぶ規則は対称でなく、交換可能性が崩れる）。どの本体を対照にするかと、消え方の量（端からの距離の変化など）を、結果の前に決める必要がある【未決】
- いずれの場合も、**新しい seed の全個体**で、個体の選び方・分け方を事前に決める（設計の整理 §3.6 の候補を引き継ぐ）

## 6. 部分的な消去と、複合的な寄与

- 0026 では、どちらの塊も、もう一方を W1 の値に固定した背景のもとで外れを生んだ（h_weights 13／20・h_units 6／20、C-I まで）【既存の結果】。設計の整理 命題 3 の (a)〜(c)（打ち消し・冗長・組み合わせだけが外れる）のどれもが、C0 で起こりうる【既存の命題】
- このような系で「戻す」と、外れが**一部だけ消える**（端から内側へ動くが外に残る、戻すドナー k によって消えたり消えなかったりする）ことが起こりうる。外にあるかの 2 値の出来事は、これを捉えない
- 段階のある量の候補【候補】：戻すドナーのうち、混成が参照の内に入った割合。端からの順位の動き。ただし、
  - **二つの塊の効果の大きさを比べる帰無仮説は、この枠にない**。二つの塊は交換可能な対象ではないので、「c の割合のほうが z の割合より大きい」を検定する自然な帰無の分布がない。0026 §13 と同じく、塊のあいだの比較・寄与の割合はしない
  - 段階のある量も、自己一致の効果（命題 D）と平均への回帰（§5）を含むので、対称な対照と比べる必要がある

## 7. 0026 の結果をこの枠で読むと、何が言えて何が言えないか

- 命題 B により、0026 の Unit の状態の家族（背景 W1 の重み、ドナー O 対 W2〜W20 の Unit の状態）は、**「O の重みを W1 の重みに戻した混成 (c_{W1}, u_O) と、その介入の参照」の比較**と同じである。同じく、重みの家族は「O の Unit の状態を W1 のものに戻した混成と、その介入の参照」の比較と同じである【命題】（0026 §3 の命題 A）
- したがって、0026 で Unit の状態の家族で O が外にあった個体では、**戻すドナー W1・介入の参照の形の E^int_{W1}(重み) は、定義どおり成り立っていない**（重みの家族で外にあった個体での E^int_{W1}(Unit の状態) も同じ）。これは個体ごとの出来事の真偽を定義から言い直したもので、統計的な主張ではない（外にある個体の一つひとつが交換可能性の破れた個体とは言えない：設計の整理 命題 6）
- **言えないこと**：自然な O の外れが、塊を戻すと消えた・消えなかった（E^nat）。0026 は N（自然な O が外にあるか）を補助の記録にとどめ、E^nat に当たる比較をしていない。0026 の個体ごとの組（重みで外・Unit で中など）を数えて C-II の成否を言うこと（事前登録していない事後の集計で、§3 のとおり、数えても排他性の証拠にならない）。**この文書では数えない**

3. **消去の向きを残すなら、C2-b か C2-c の形に作り直す**。どちらも新しい統計の枠（個体の中での O と対照の W の交換可能性）を要るので、事前登録の前に、量・対照・判定の形をこの文書の次の版か別の docs で詰める
4. **C2 のどれを行うか、行わないかは、E4 の後の C0 の研究レビューで決める**（方針 2026-10-18 の 3）。そのとき、C2 を C0 で行う価値（C0 の可能性と限界をより正確に知ることに、どれだけ足すか）と、計算の量を合わせて判断する

## 12. 専門知識がなくても読める解説（t-k さんへ）

### 何を確かめたかったか

0026 では、「経験の終わりに、部品の一部（つながりの強さ、または部品の内部の状態）だけを、順番どおりの経験をした個体のものに入れ替えると、その後の反応が変わる」ことを確かめました。次の段階として考えていた C-II は、さらに一歩進んで、「その部品を移すと違いが**生まれ**、その部品を元に戻すと違いが**消える**」ことを示そうとするものでした。

### 整理して分かったこと

1. **「戻す」は、裏返すと「残りを移す」と同じでした。** 部品を二つに分けているので、順番どおりの個体の片方の部品を戻すことは、もう片方の部品だけを別の個体へ移すことと、同じ状態を作ります。そのため、C-II は「この部品だけが違いを運ぶ（もう片方は運ばない）」という主張になります
2. **「もう片方は運ばない」は、今の確かめ方では示せません。** 「違いが見つからなかった」は「違いがない」ことの証拠にならないからです。いくつもの条件をそろえて数えても、偶然では起こりにくいという強さは増えません
3. **自分の中で比べると、別のものが混ざります。** 順番どおりの個体の中で「本来の部品」と「入れ替えた部品」を比べると、「入れ替えたこと自体」の影響が混ざります。0026 は、比べる相手をすべて入れ替えたものにそろえて、これを避けていました

### この後

- 今の形の C-II は、実験にしないことを勧めます
- 確かめられる形にするなら、(a) 0026 を、入れ替える相手の個体を増やして確かめ直す、(b) 順番どおりの個体と同じ操作を、ほかの個体にも施して比べる、という作り直しが考えられます
- どれを行うかは、E4（問いかけの時期を遅らせる実験）の結果を見た後の、C0 の研究のまとめで決めます
