## 1. 前提と記号

- 役 i, j ∈ {A, B, C}。区間 I ＝ [t_a, t_b]、|I| ＝ t_b − t_a ＋ 1
- 観測量（理論のメモ §2.3）：

  ```text
  N_ij(k; I) = #{ t : t ∈ I かつ t + k ∈ I、s_i(t) = 1 かつ s_j(t + k) = 1 }      （k = 0, 1, …, |I| − 1）
  ```

- 経験の区間 E ＝ [1, t0]、W ＝ [t0 ＋ 1, T]。同じ Birth State b の 2 つの経験 ord・shuf について：

  ```text
  Δ_E N = N^ord(·; E) − N^shuf(·; E)      Δ_W N = N^ord(·; I_W) − N^shuf(·; I_W)      （I_W ⊂ W）
  ```

- **区別する 3 つの水準**（ChatGPT の整理）。以後この記号で書く

| 水準 | 内容 |
|---|---|
| **L1 類似** | 同じ個体で、経験の間と W に、似た二点の関係が観測された |
| **L2 経験への依存** | 経験の条件を変えると、W の二点の関係が変わった（Δ_W N ≠ 0） |
| **L3 経験した構造の再出現** | 経験の間に形成された活動の時間の構造が、その後の W に再び現れた |

- **4 つの寄与**：
  - 発火数（R）
  - 内在の周期（P）：Birth State の θ・c と、α・τ_a・λ で決まる
  - 位相の持ち越し（C）：t0 の Unit の状態と、t0 ＋ 1 に届く駆動
  - 学習した接続（L）：t0 の重みと、W の可塑性

  ただし、これらは N の足し算の成分ではない（§3.1）

## 2. 観測量 N から確定すること・確定しないこと

### 2.1 確定すること

**【命題 2.1】発火数は N から決まる**：N_ii(0; I) ＝ n_i（i の I の中の発火数）。

**【命題 2.2】組の総数は発火数だけで決まる**（理論のメモ 命題 3.3）：

```text
i ≠ j：Σ_k N_ij(k; I) + Σ_k N_ji(k; I) − N_ij(0; I) = n_i · n_j
i = j：Σ_k N_ii(k; I) = n_i (n_i + 1) / 2
```

向きのある二つの関数を一つにまとめると、扱いやすくなる。

```text
M_ij(k) = N_ij(k)（k ≥ 0）、 N_ji(−k)（k < 0）      （−(|I| − 1) ≤ k ≤ |I| − 1）
⇒ Σ_k M_ij(k) = n_i · n_j      （i ≠ j）
```

**【命題 2.3】上限**：0 ≤ N_ij(k; I) ≤ min(n_i, n_j, |I| − k)。1 つの Unit は 1 Pulse に高々 1 回しか発火しないので、i のある発火と時間差 k で組になる j の発火は高々 1 つだから。

**【命題 2.4】時刻をそろってずらしても変わらない**：すべての役の発火を同じだけずらし、どれも I の中に残るなら、N は変わらない。N は「いつ」を持たず、「どれだけ離れているか」だけを持つ。

**【命題 2.5】時間を逆にすると、向きが入れ替わる**：区間の中で時間を逆にすると、N_ij(k) と N_ji(k) が入れ替わる。したがって、向きの情報は反対称の部分 N_ij(k) − N_ji(k) にだけある。対称の部分 N_ij(k) ＋ N_ji(k) は向きを持たない。

### 2.2 確定しないこと

**【命題 2.6】N は三点以上の順序を決めない**

時刻の集合 u と、役ごとの時刻の集合 v_i を取る。x_i ＝ {a ＋ b : a ∈ u, b ∈ v_i} とし、同じ役の中で和が重ならないとする。−u（u の時間を逆にしたもの）で同じように作った x′_i は、N のすべての成分が x_i と同じになる。

証明：x_i と x_j の時間差 k の組の数は Σ_d D_u(d)·D_{v_i, v_j}(k − d)。D_u(d) は u の中の時間差 d の組の数で、−u でも同じ。すべての発火が I の中にあれば、両端を I に限っても数え方は変わらない。

例：u ＝ {0, 1, 3}、v ＝ (A: 0, B: 1, C: 2) とする。
- X：A {0, 1, 3}、B {1, 2, 4}、C {2, 3, 5}
- Y：A {0, 2, 3}、B {1, 3, 4}、C {2, 4, 5}

Y は X をずらしたものではないが、9 つの N_ij(k) はすべて同じである。一方、A ≤ B ≤ C の 3 つ組の時間差 (B − A, C − B) の多重集合は違う。例えば (2, 3) は X にだけ、(3, 2) は Y にだけある。

- これは観測量の性質の例で、模型がこの配置を生むかは問わない
- 帰結：三点以上の順序（A→B→C の列）の再出現は、N だけからは確かめられない

**【命題 2.7】区間全体の N は、区間の中のどこで起きたかを分けられない**

区間を I ＝ I_1 ∪ I_2 と分けると、次のようになる。

```text
N(k; I) = N(k; I_1) + N(k; I_2) + #{ I_1 から I_2 にまたがる時間差 k の組 }
```

同じ回数の組が W の初めに集まっていても、W 全体に散らばっていても、W 全体の N は同じになりうる。
- 位相の持ち越し（初めに効く）と、続く関係を分けるには、区間の分け方が要る
- その分け方は分析上の選択である（§2.3）

**【条件付き 2.8】経験の間の N は、誘発の発火と内在の発火を区別しない**

刺激の時刻は既知なので、刺激の 1 Pulse 後の発火を誘発の発火とみなすことはできる（理論のメモ 条件付き 2.2）。ただし、内在の発火や接続による発火が同じ Pulse に重なると区別できない。

**【命題 2.9】N は機構を含まない**：同じ発火の列は、どの機構から生じても同じ N を与える。

### 2.3 発火数と時間の関係：恒等式と分析上の選択

| 内容 | 種類 |
|---|---|
| 組の総数 n_i·n_j、n_i(n_i ＋ 1)／2 は発火数で決まる（命題 2.2） | **恒等式** |
| 総数が、どの時間差にどう配られるかは、発火数からは決まらない | **恒等式からは決まらない**。発火数の成分と時間の関係の成分に、一意に分けることはできない |
| 2 つの腕ですべての Unit の発火数が同じなら、Δ_W N を組ごとに時間差について足すと 0 になる（配り方の違いだけが残る） | **恒等式**（命題 2.2 から） |
| M_ij を n_i·n_j で割った、時間差についての分布 p_ij(k) | **分析上の選択**。新しい数値は要らない。ただし n_i·n_j ＝ 0 では定義されない（0 ではなく「定義されない」と記録する） |
| 時間差 k で数えられる位置の数（区間の長さ − k）で割る | **分析上の選択**（区間の端の補正） |
| 「独立に発火したら期待される数」と比べる | **分析上の選択**。独立の模型（帰無の模型）の選び方を含む |
| 発火が 0 の Unit | N のその行と列はすべて 0 になる。「関係がない」ではなく「関係を観測できない」と記録する（**恒等式からの帰結と記録の約束**） |

**【条件付き 2.10】周期的な Unit では、発火数と時間の関係は同じ一つの量で決まる**

孤立して厳密に周期 T で発火する Unit では、次の 2 つがどちらも T で決まる。
- N_ii(k) が正になるのは、k が T の倍数のところだけ
- n_i ≈ |I|／T

したがって、このような Unit については、「発火数の違い」と「時間の関係の違い」は原理的に分けられない。周期的でない Unit・結合した Unit では一般に別だが、どこまで分けられるかは【未解決】。

## 3. W は t0 の状態を通してしか経験を見ない

### 3.1 状態の十分性と、寄与の非加法性

**【命題 3.1】状態の十分性**

W の間は入力がなく、系は決定論的である。したがって、W のどんな観測量（N に限らない）も、t0 の全状態 S(t0) と Birth State の値の関数である。

- t0 の全状態とは、各 Unit の (a, h)、重み、痕跡、t0 ＋ 1 に届く駆動のこと
- 経験の履歴は、S(t0) を通してしか W に効かない
- **t0 で同じ全状態に至る 2 つの履歴は、W のどんな観測でも区別できない**

**【命題 3.2】状態の次元**

0012 の世界では、W に効く t0 の状態は次のとおりである。

| 成分 | 数 |
|---|---|
| 各 Unit の (a, h) | 6 |
| 可塑的な重み | 6（組の和が保たれる条件のもとでは自由度 3。理論のメモの前提の F1） |
| 痕跡 | 接続ごとに 2 つ。出生時に 0 から始まり同じ発火で更新されるので、Unit の痕跡 3 つに等しい（循環のメモ §1） |
| t0 ＋ 1 に届く駆動 | 3（t0 の発火と w(t0 − 1) で決まる） |

W の可塑性を止めれば、痕跡は W の活動に効かない。

**【命題 3.3】学習した接続の通り道は、自由度 3 である**（組の和の条件のもとで）

経験の間に学習した接続が W に運べるのは、3 つの値（組ごとの w_ij − w_ji）だけである。
- 理論のメモ 命題 4.6 により、1 本の重みは、時間差 L の組を κ^(L−1) で重みづけて足した 1 つの値として変わる
- したがって、経験した時間差（2 か 30 か）は、重みの中に別々には蓄えられない
- これは「重みを通して時間差 2・30 の関係が W に現れることはない」という意味ではない。現れるとすれば、3 つの値と Birth State の値と t0 の Unit の状態から、W の力学がそれを作る場合である（§5.4、【未解決】）

**【命題 3.4】寄与は足し算に分けられない**

理論のメモ 命題 4.4 から、t0 ＋ 1 に受け手が発火する ⇔ 届いた駆動 δ ≥ 余裕 G である。
- δ は重みと t0 の発火で決まる（L と C の両方）
- G は Unit の状態で決まる（C）

G が大きい状態では、δ を変えても発火は変わらない。G が小さい状態では変わる。したがって、ある成分を変えたときの効果は、ほかの成分の値に依存する（交互作用）。

- 「寄与率」（N の違いのうち何割が学習した接続によるか）は、一意には定まらない
- 成分を入れ替える順序や、背景の取り方によって答えが変わる

### 3.2 帰結

- L2（Δ_W N ≠ 0）は、「S(t0) の違いが W の発火を変えた」ことしか言わない（理論のメモ 命題 3.1 と同じ）
- 運んだ成分を言うには、成分を入れ替える腕が要る（§4）
- それで分かるのは、選んだ背景のもとでの **条件付きの因果効果** で、自然な個体の中の媒介の割合ではない（命題 3.4）

## 4. 4 つの寄与と対照：消えるものと、初めの状態に残っているもの

### 4.1 対照ごとの表

番号は理論のメモ §6.1 と同じ。「t0 に残っているもの」は、その対照でも消えない経験・学習の影響を指す。

| 対照 | 取り除くもの | t0 の状態に既に残っているもの | 見分けられる範囲（条件付き） | 見分けられないもの |
|---|---|---|---|---|
| ① 同じ Birth State の ord と shuf | Birth State の値の違い（同じ b なので、θ・c の主効果は消える） | 全状態の違い（(a, h)・重み・痕跡・t0 ＋ 1 に届く駆動） | L2：経験の順序への依存 | 運んだ成分。W の中の書き換え。発火数の違い（§2.3） |
| ② Unit の状態を写す（(a, h)。t0 ＋ 1 に届く駆動・痕跡を写すかは取り決め） | 写した成分の違い | 写さなかった成分の違い（重み。駆動・痕跡を写さなければそれも）。**写した状態そのものも、経験の間の学習した接続の影響を受けて生じたもの** | 写した背景のもとでの、残りの成分の条件付きの効果 | 自然な媒介の割合（命題 3.4）。写す向き（ord→shuf か shuf→ord か）で答えが違いうる |
| ③ 重みだけを写す（0017／0020 の移植） | 写した接続の重みの違い | 受け手の (a, h)・痕跡・t0 ＋ 1 に届く駆動（写す前の重みで作られている） | 受け手の背景のもとでの、重みの条件付きの効果 | ② と同じ。人工的な組み合わせ |
| ④ W の可塑性を止める | W の中の書き換え | t0 のすべて（学習した重みを含む） | ①・⑤と比べた、W の中の書き換えの寄与（条件付き） | 運んだ成分 |
| ⑤ W の可塑性を yoke する（0021 型） | 自分の発火による書き換え（C の発火による書き換えに置き換わる） | t0 のすべて | 循環（Q1〜Q4 の線）の効果 | 経験した構造の再出現そのもの |
| ⑥ 学習を伴わない対照（経験の間も可塑性なし） | 経験の間の学習 | 経験の間の活動の結果としての (a, h)・t0 ＋ 1 に届く駆動。**ただし経験の間の活動そのものが学習ありの個体と違いうる**（重みは発火を変える） | 学習を通らない経験依存（位相・順応）の大きさ | ⑥ と学習ありの個体の差を「学習した接続だけの効果」とは読めない。学習は、重みと、経験の間の活動（したがって (a, h)）の両方を変えるから。比べる「経験した構造」（Δ_E N）も同じでない |
| ⑦a 結合のない基準（計算） | W の結合の伝達（t0 ＋ 1 に届く駆動も除く） | t0 の (a, h)。**これには、経験の間の学習した接続の影響が既に含まれうる** | 「t0 の Unit の状態と内在の周期だけ」で生じる N | ⑦a は「経験や学習の影響がない基準」ではない |
| ⑦b t0 由来の駆動を一回だけ含む（計算） | t0 ＋ 2 以後の結合 | ⑦a と同じ ＋ t0 ＋ 1 に届く駆動（学習した w(t0 − 1) と t0 の発火で作られる） | ⑦a との差：t0 由来の駆動一回の条件付きの効果 | 学習による効果を単独で分けたことにはならない（駆動は学習した重みと位相の両方で決まる） |

### 4.2 寄与ごとのまとめ

| 寄与 | 見分けられる範囲 | 残ること |
|---|---|---|
| **R 発火数** | 発火数そのものは N から決まる（命題 2.1）。全 Unit の発火数が同じ腕どうしでは、差は配り方だけ（§2.3） | 発火数が違うとき、発火数の成分と時間の関係の成分の一意の分解はない。周期的な Unit では原理的に分けられない（条件付き 2.10）。正規化は選択 |
| **P 内在の周期** | 同じ Birth State の比較（①）では、θ・c の主効果は消える | 周期は順応 h（状態）でも変わる。そのため、状態との交互作用は残る。L1（同じ個体の中の類似）では、周期の一致（例：周期が試行の 60 に近い）が大きな交絡になる |
| **C 位相の持ち越し** | ②・⑦a・⑦b で、状態と t0 ＋ 1 に届く駆動の条件付きの効果 | 持ち越される状態そのものが、経験の間の学習の影響を受けている（⑦a の行）。どれだけ続くかは【未解決】（理論のメモ §9 の 2） |
| **L 学習した接続** | ③（重みの条件付きの効果）、④（W の書き換えを除く）、②（状態をそろえた背景） | 自然な媒介の割合は見分けられない（命題 3.4）。⑥ との差は学習した接続だけの効果ではない。通り道は自由度 3（命題 3.3） |

## 5. Δ_E N と Δ_W N の対応（中心の課題）

### 5.1 3 つの水準は互いに含意しない

**【命題 5.1】L1 は L2 を含意しない**：同じ個体の中で経験の間と W の N が似ていても、もう一方の経験で同じように似ているなら、Δ_W N ＝ 0 でありうる。例えば、時間の格子が共通（理論のメモ 命題 2.3）なら、役によらない時間差の一致は両方の経験で起こる。

**【命題 5.2】L2 は L3 を含意しない**：Δ_W N ≠ 0 は、S(t0) のどこかの違いが W の発火を変えたことしか言わない（命題 3.1）。その違いが経験の間の時間の構造と対応している必要はない。
- 例：発火数の違いだけでも Δ_W N ≠ 0 になる（命題 2.2）
- 順応の水準の違いだけで周期が変わっても Δ_W N ≠ 0 になる

**【命題 5.3】L3 は（ある条件のもとで）L2 を含意する**

経験した構造が Δ_E N ≠ 0 で、対応の規則 R が 2 つの経験を区別する（§5.2 の R3）とする。両方の経験で、それぞれの構造が再出現するなら、Δ_W N ≠ 0 である。R が 2 つの経験を区別しないなら、W は経験の違いを運んでおらず、「その経験した構造の再出現」とは言えない。

### 5.2 対応の規則が満たすべき条件

L3 を主張するには、Δ_E N から Δ_W N のどんな形を「対応する」とみなすかの規則 R が要る。理論のメモ（§4.6）のとおり、直接一段の伝達・遅れた発火・複数の Unit を経る経路・位相の変化で、時間の関係は変換されうる。だから「同じ時間差」を初めから必須にはしない。一方、どんな変換でも認めれば反証できない定義になる。

そこで、R が意味を持つための **必要条件** を論理として置く。

| 条件 | 内容 | 欠けるとどうなるか | 札 |
|---|---|---|---|
| **R1 事前に固定** | R は W のデータを見る前に決め、模型の力学と世界の構造から導く。データに合わせて選ばない | 事後の選択で、何でも対応に見える | 【命題】（欠けたときの帰結） |
| **R2 反証できる** | Δ_E N が与えられたとき、R が認めない Δ_W N が存在する | R はどんな結果も認め、何も主張しない | 【命題】（同上） |
| **R3 経験の内容で予測が変わる** | 違う経験（Δ_E N が違う）に対して、R が認める Δ_W N の集合が違う | W が経験の違いを運んだとは言えない（命題 5.3） | 【命題】（同上） |
| **R4 ほかの機構と予測が違う** | R が認める Δ_W N が、学習した接続を通らない機構（位相の持ち越し・内在の周期・発火数）だけで生じうる Δ_W N と区別できる。区別できない場合は、それらの機構を取り除く対照（§4）と組にする | L2 と L3 を区別できない。学習した接続による再出現を、持ち越しなどと取り違える | 【命題】（同上） |

R1〜R4 は必要条件で、R の中身（どの変換を認めるか）は決めない【未解決】。

### 5.3 同じ時間関係を求める規則（恒等の規則）

R が「Δ_W N_ij(k) が、Δ_E N_ij(k) と同じ時間差 k・同じ向きで現れる」とする場合を考える。

- R1〜R3 は満たしうる
- **R4 は、対照なしでは満たさない見込みが高い**【条件付き】
  - 位相の持ち越しは、学習した接続を通らずに、経験の最後の時間差（ordered なら A→B は 2、A→C は 30）を、そのままの形で W の初めに持ち込みうる（理論のメモ §5.3）
  - 一方、学習した接続の直接一段の伝達がまず作りやすいのは、時間差 1 の関係である（理論のメモ 系 4.4a）
  - したがって、この世界では、**同じ時間差での一致は、学習しない機構のほうが作りやすい形**になりうる。恒等の規則を状態の対照（② か ⑦a・⑦b）なしで使うと、持ち越しを学習による再出現と取り違えやすい
- 恒等の規則は、再出現の **十分条件にならない**（R4 が欠けうる）。また、変換された再出現を見落とすので **必要条件でもない**（力学による変換がありうる）

### 5.4 力学で変換された関係を認める規則

**直接一段の伝達による変換**：「重みの向き（w_ij ＞ w_ji）が、時間差 1 の向きのある関係として W に現れる」とする場合。

- R1：理論のメモの 系 4.4a・命題 4.5c・命題 4.6 から導ける【条件付き】
- R3：限られる。重みは時間差を別々に持たないので（命題 3.3）、この規則が運べるのは **組ごとの向き（自由度 3）だけ**である。経験した時間差 2 と 1 を区別できない
- R4：満たすとは限らない。周期の等しい 2 つの Unit が時間差 1 の位相で持ち越されると、結合なしでも同じ列になりうる（§6 の U4）。状態の対照が要る

**ネットワーク全体による変換**：遅れた発火、複数の Unit を経る経路、積み重なる位相（理論のメモ 予想 4.5d）による変換。
- R1 を満たす導出は、まだない【未解決】
- この導出がないまま変換を認めると、R1・R2 が欠ける

**U4 の構成（条件付き）**

W のある区間で、次の列 Z を考える（τ_0 は初めの時刻、m は回数）。

```text
A：τ_m = τ_0 + m·T     B：τ_m + d      （m = 0, 1, …）
```

次の 2 つの機構は、どちらも Z を作る。

- **(i) 持ち越しと内在の周期**
  - A と B の自分の周期がどちらも T に等しい
  - W の結合が A・B の発火の時刻を変えない（届く駆動が、受け手の余裕より常に小さい）
  - t0 の状態で、B が A の d Pulse 後に発火するように位相が持ち越されている
- **(ii) 結合による引き込み（d ＝ 1 の場合）**
  - A は自分の周期 T で発火し、B からの駆動で時刻を変えない
  - A の各発火の次の Pulse に、B の余裕が w_AB 以下になる（理論のメモ 命題 4.4）
  - B は毎回そこで発火してリセットされ、次の A の発火の次の Pulse まで、自分では発火しない

d ＝ 1 なら、2 つの機構の列は同じなので、W のどんな観測でも区別できない（命題 2.9）。区別には介入が要る。
- 結合を除いた ⑦a では、(i) は列が変わらず、(ii) は B が自分の周期に戻る
- (i) の位相の持ち越しの d には、最後の試行の時間差がそのまま入りうる。ordered なら A→B は 2 で、これは恒等の規則が探す時間差そのもの（§5.3）

どちらの機構の条件も、実際の Birth State の分布のもとでどれだけ満たされるかは【未解決】。ここでは値を置かずに、条件だけを書いた。

**内在の周期と位相の持ち越し**（ChatGPT の例）について：孤立した Unit の列は、周期（Birth State と h）と位相（t0 の状態）の両方で決まり、2 つは別々の「代わりの説明」ではない。
- 時間差の関係が長く安定するには周期の一致が要る。どの時間差になるかは位相で決まる
- したがって、W の N に現れた時間差の値を経験の最後の時間差に結びつけられるのは、位相の出どころを変える対照（同じ b の ① で最後の試行が違うこと、② で状態を写すこと）を通してだけである
- 同じ条件の一つの腕の中では、位相の出どころを区別できない（U1）
