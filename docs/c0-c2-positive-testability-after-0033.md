## 3. 命題 1（C-II の「再現」は、介入の参照に照らすと C-I である）【命題】

担い手の整理 §3.1 の C-II の「再現」の向きは「O の c を並べ替えの背景へ移すと、並べ替えが外れる」である。これを

- **(i) 介入の参照**（同じ背景 r に、W のドナーの c を入れた混成 {Y(W_k → r)}）に照らすと、事象は「L(O → r) が {L(W_k → r)} の外」で、0031〜0033 の事象（受け手を一つにしたもの、または受け手をまたぐ合計）そのものである
- **(ii) 自然な参照**（{L(W_i → W_i)}）に照らすと、混成と自然な本体を比べることになり、C2 の整理 命題 D の自己一致の効果（自然な状態と混成の系統的な違い）を含む

（証明：定義を書き下すだけ。(ii) は C2 の整理 命題 D の構成 L(k → a) ＝ 1［k ＝ a］で、O と関係なく混成がつねに自然な参照の外になる。）

**帰結**：再現の向きで積極的に検証できる形は、0031〜0033 で既に行った C-I である。足せるのは、受け手の種類（§6）と時刻（§8 の K5）の広げ方だけ。

## 4. 命題 2（「戻す」は、3 組と Unit の塊に分けても、補を「移す」ことである）【命題】

C2 の整理 命題 B は塊を二つに分けた場合だった。0032・0033 のように重みを組に分けても同じである：塊 c（組の集まり）を W_k から O に戻した混成 Y(W_k → O) の状態は (c_{W_k}, z_O) で、これは「W_k の状態に、O の補 z（入れ替えない組の重み、Unit の状態、痕跡）を移した本体」と同じ状態である。その介入の参照 {(c_{W_k}, z_{W_j})} も、「W_k に W_j の z を移した本体」の集まりと同じ。したがって

```text
E^int_k(c を戻すと内に入る)  ⇔  ¬ R^{(z)}_{W_k}(補 z を O から W_k へ移しても外に出ない)
```

（証明：C2 の整理 命題 B と同じ。混成の状態が同じなら、τ より後の軌道と L は同じ。）

- 例：0033 の 2 組の種類 AB＋AC の本体 Y_r^{AB+AC}(O) ＝ (O の A–B・A–C の重み, r の B–C の重み・Unit の状態・痕跡) は、「O の状態の補（B–C の重み・Unit の状態・痕跡）を r のものに戻した本体」とも書ける。**0033 の事象をこの読みで数え直して、消去の成否を言うことはしない**（§11）
- 帰結：介入の参照に照らした消去は、つねに補の「移す」の否定で、排他性の主張になる（C2 の整理 命題 B の帰結 1）

## 5. 命題 3（「消える」は、今の枠では積極的に示せない。同等性の形の条件）【命題】と【予想】

**(i) 棄却できなかった側**：0031〜0033 と同じ交換可能性の帰無仮説のもとで、受け手を一つにした「移す」の事象の確率は 1／20 以下なので、「内に入る（外に出ない）」の確率は 0.95 以上になる。内に入ったことは、帰無仮説のもとでもふつうに起こり、消えた証拠にならない（C2 の整理 命題 C (i)）。0031〜0033 の受け手をまたぐ合計の形でも同じ。

**(ii) 連言は強くならない**：再現・消去の事象の連言を数えても、帰無のもとの上界は再現の事象だけのものと同じで、成分の確率の積では見積もれない（C2 の整理 命題 C (ii)。構成も同じ）。

**(iii) 同等性の形に直すと、新しい幅と多くの個体が要る**：消去を「補 z を O から移したときに外に出ることは、幅 δ より少ない」と書き、H0（外に出る確率は δ 以上）を棄却する形にすれば、積極的な検定にはなる。n 個体のうち外に出た個体の数を h とし、h ≤ k なら H0 を棄却する。**H0 の「確率」が何の確率かで、上界の成り立ち方が違う**：

| H0 の形 | 意味 | P(h ≤ k) ≤ P(Bin(n, δ) ≤ k) は |
|---|---|---|
| **(α) 共通の p** | 個体（Birth State）を独立・同一分布の標本と見て、p をその母集団で事象が起きる確率（周辺の確率）とする。H0：p ≥ δ | **すべての k で成り立つ**。h は Bin(n, p) に従い、P(h ≤ k) は p について単調に減る |
| **(β) 各個体の下限** | 個体ごとの確率 p_i を固定する（個体の間は独立）。H0：**すべての i で** p_i ≥ δ | **すべての k で成り立つ**。独立な一様の乱数 U_i で 1［U_i ≤ p_i］ ≥ 1［U_i ≤ δ］と結合すれば、h は Bin(n, δ) より確率的に大きい |
| **(γ) 平均** | p_i を固定する。H0：(1／n) Σ_i p_i ≥ δ | **k 一般では成り立たない**。反例（ChatGPT のレビュー）：n ＝ 20、δ ＝ 0.15、10 個体で p_i ＝ 0・10 個体で p_i ＝ 0.3（平均 0.15）。P(h ≤ 4) ＝ 0.849732 ＞ P(Bin(20, 0.15) ≤ 4) ＝ 0.829847（k ＝ 3 でも 0.649611 ＞ 0.647725）。**k ＝ 0 だけは成り立つ**：P(h ＝ 0) ＝ Π_i (1 − p_i) ≤ ((1／n) Σ_i (1 − p_i))^n ≤ (1 − δ)^n（相加・相乗平均の不等式） |

- **v0.1 の「個体ごとの確率が違っても、どの個体でも p ＝ δ のときに最大」は、(β) の量化子でだけ正しく、(γ) では誤りだった（撤回）**

## 6. 命題 4（自分の背景での対称な比較：相対的な C-I は積極的に検証できる）

### 6.1 設計 C-I^own【候補】

C2 の整理 §8 の C2-c（自己一致の対照つきの、自分の背景での比較）を、**ドナーの集まりを的の集まりから分ける**ことで、帰無の上界が成り立つ形にする。

- 的の集まり 𝒯 ＝ {O, M, W_1, …, W_19}（21 本体）。各 a ∈ 𝒯 の**自分の背景**（a の τ の状態）を使う。点を比べる参照は 𝒲 ＝ {W_1, …, W_19}

- **自分の背景の符号付き順位点**：

  ```text
  s^x(a) ＝ Σ_{k∈𝒬} sgn(L(a → a) − L(k → a))
         ＝ #{k ∈ 𝒬 : L(k → a) ＜ L(a → a)} − #{k ∈ 𝒬 : L(k → a) ＞ L(a → a)}     （−q〜q の整数）
  ```

  a 自身の塊を Q_k の塊に替えたとき、L が下がったドナーの数から、上がったドナーの数を引いたもの

- **事象 (A)**（主の事象の候補。向きは 0031〜0033 と同じ：O の重みは Δ_AB・D を大きく、M の重みは D を小さくすると予測する）

```text
E_Ca^own  ⇔  s^{Δ_AB}(O) ＞ max_{d∈𝒲} s^{Δ_AB}(d)
E_O^own   ⇔  s^D(O)     ＞ max_{d∈𝒲} s^D(d)
E_M^own   ⇔  s^D(M)     ＜ min_{d∈𝒲} s^D(d)
E_OM^own  ⇔  E_O^own かつ E_M^own
```

- **事象 (B)**（方向の条件つき。(A) の部分事象）と、その強い形 (B′)

```text
E_Ca^own,B  ⇔  E_Ca^own かつ s^{Δ_AB}(O) ＞ 0        （(B′) では s^{Δ_AB}(O) ＝ q）

```

- **(A) の読み**：「O の自分の背景で、O の重みを 𝒬 のドナーの重みに替えたときの符号付き順位点（下がった数 − 上がった数）が、W_1〜W_19 がそれぞれ自分の背景で同じ 𝒬 に対して示す点のどれよりも大きかった」。**O の重みが 𝒬 のすべての重みより Δ_AB（D）を大きくしていたこと（s(O) ＝ q）も、過半より大きくしていたこと（s(O) ＞ 0）も含まない**。言えるのは、W の自分の背景での点に対する、**相対的な**位置だけである（(b5) の反例）
- **(B) の読み**：(A) に加えて、O の自分の背景では、𝒬 の過半のドナーへの交換で O の値が下がった（同じ値のドナーを除いた数で比べる。同じ値がなければ「O の自然な値が、q 個の混成の値の中央値より上」）。(B′) なら、すべてのドナーへの交換で下がった
- (A)・(B) のどちらも、O の自然な値 L(O → O) が自然な W の値 {L(W_i → W_i)} の外にあること（N）を前提にせず、交換した後の値が自然な W の範囲に入ったことも言わない。**自然な差の消去（C-II）とは同じでない**

### 6.2 (a) 帰無の上界【命題】

帰無仮説 H^own：個体ごとに、𝒯 ∪ 𝒬 の本体の τ の状態の同時の分布が、ラベル O・W_1, …, W_19 の入れ替えに対して不変（M は動かさない）。M の事象には同じく M・W_1, …, W_19 の入れ替え（O は動かさない）、O と M が分かれる事象には、𝒯 の 21 のラベルすべての入れ替えに対する不変を置く。**同時の分布についての強い仮定**で、0031〜0033 の帰無仮説と同じく統計モデルの仮定として置く（ドナーとしての交換可能性を、自分の背景を持つ本体としての交換可能性に置き換えたもの）。

**(a)** このとき、P(E_O^own) ≤ 1／20、P(E_M^own) ≤ 1／20、P(E_OM^own) ≤ 1／420（E_Ca^own も 1／20）。

**(a′) 方向の条件つきの事象**：(B)・(B′) の事象は (A) の部分事象なので、同じ帰無仮説のもとで

```text
P(E_O^own,B) ≤ P(E_O^own) ≤ 1／20、 P(E_M^own,B) ≤ 1／20、 P(E_OM^own,B) ≤ P(E_OM^own) ≤ 1／420    （(B′) も同じ）
```

**(B) の方向の条件が、統計の上で足すもの・足さないもの**【命題】

### 6.3 (b) 何を区別し、何を区別しないか【命題（構成）】

連続な値で同じ値が確率 0 の構成で示す（𝒬 と 𝒲 の本体は独立に同じ分布、O は構成ごとに決める）。どれも玩具の構成で、C0 の L がこの形であるとは言わない。

### 6.4 (c) 言えること・言えないこと（成り立ったとき）

- **(A) を主にしたときに言えること**：C0・この世界・この手順で、21 の的のそれぞれの自分の背景（Unit の状態・痕跡・入れ替えない組の重みと τ）を固定し、塊を 𝒬 のドナーの値に替えたとき、O（M）の自分の背景での符号付き順位点は、W_1〜W_19 の自分の背景での点に比べて、予測した向きに典型的でなかった。そうなった個体が、𝒯 のラベルの交換可能性の想定より多かった（**自分の背景での、相対的な C-I**）
- **(B) を主にしたときに足せること**：数えた個体の一つひとつについて、O の自分の背景では、𝒬 の過半（(B′) ならすべて）のドナーへの交換で O の値が下がった（M では D が上がった）。算術の事実で、頻度の主張ではない
- **言えないこと**

  - (A)・(B) のどちらでも：母集団で「O の重みを替えると O の値が下がる」こと（向きの頻度は検定していない。§6.2）、外れが消えた（C-II の消去）、自然な差（N）があったこと、重みの排他性・担い手（C-III）、重みの内容と組み合わせの区別（(b3)）、自然な状態で到達できるか（担い手の整理 命題 2）
- **候補「O・M を受け手にした別の背景」との関係**：C-I^own は、O・M を受け手にした背景で、参照の作り方を「各 W も自分の背景で同じことをする」に決めたものである。0031 §2.3 が「O の背景に M の重みを入れる形は、塊と背景の内容の組み合わせという別の問いになる」としたのは、背景ごとに参照を作れなかったためで、C-I^own は自分の背景どうしを比べることでそれを避ける。その代わり、主張は (A) の相対的な形になる

## 14. 専門知識がなくても読める解説（t-k さんへ）

### 何を確かめたかったか

これまでの 0031〜0033 では、「順番どおりに経験した個体（O）のつながりの強さを、ほかの個体へ**移す**と、その個体の反応が O らしく変わる」ことを、条件を変えながら確かめてきました。もともとの目標（C-II）には、もう半分がありました。「O のつながりの強さを、ふつうの個体のものに**戻す**と、O らしさが**消える**」です。今回は、計算をせずに、この「消える」を今のやり方で確かめられるかを整理しました。

### 整理して分かったこと

1. **「消える」は、今のやり方では示せません。** 「違いが見つからなかった」は「違いがない」ことの証拠にならないからです。「ほとんど違いがない」と言い直すと確かめられる形にはなりますが、「どこまでを『ほとんど』とするか」を新しく決める必要があり、個体も今の 20 から 30〜60 以上に増やさないと、ほとんど何も言えません
2. **「消える」の代わりに確かめられる形はありましたが、言えることは最初に書いたより狭いものでした。** O・M・ふつうの個体のそれぞれで、自分のつながりの強さを、別に用意した個体たちのものに入れ替えます。そのときの反応の変わり方を、O とふつうの個体で比べます
   - 言えるのは、「O の入れ替えの結果が、ふつうの個体の入れ替えの結果と比べて、予想した側に寄っていた」という**相対的なこと**までです。v0.1 では「O のつながりの強さを替えると、O の反応が下がる」と書きましたが、それは言えません（ChatGPT さんの指摘のとおりで、ふつうの個体がみな大きく上がり、O だけが少し上がる、という場合にも成り立ってしまいます）
   - 「下がった」まで言いたいなら、「数えた個体では、入れ替えの過半で実際に下がっていた」という条件を足せます。ただしそれは、数えた個体ごとの事実の確認で、「全体として下がる」ことを確かめたことにはなりません
3. 統計の書き方も一か所直しました。「個体ごとに確率が違っても大丈夫」と書いた部分は、「確率の平均だけが分かっている」場合には成り立たないことがあります（これも ChatGPT さんの指摘）。この文書では、「個体は同じ母集団から独立に取り出したもの」という、これまでと同じ見方を採ると明記しました

### 研究の進め方の比較（今回足したこと）

Gemini さんの監査の論点（0033 で 9 個体が反応しなかったこと、発火の数の違いと発火の順序の違いの区別、C0 をいつ終えて次の構成へ進むか）と合わせて比べました。

- どの追加の実験も、「効果が見えなかった」側の結果では、次の構成へ進むかどうかの判断を変えません。「見えなかった」は「ない」の証拠にならないからです
- 次の構成へ進む条件のうち、いちばん大事なのは「C0 では何がどうしても表せないのか」を示すことです。これは実験より、理屈（命題）で示すほうが現実的です。たとえば「経験から刺激の区別を作る」「覚えたことを行動に使う」は、C0 の作りそのものからできないと言いやすい見込みです
- そこで、**まず計算をせずに、その整理と、C0 で分かったこと・分からないことの台帳を作る**ことを提案しました
- 追加の計算をするなら、「発火の数の違いだけでは説明できない差か」を確かめる形（K9、20 個体で約 25 分の見込み）を、今回の「自分の背景での入れ替え」（K3、約 2 時間 20 分）より先にするのがよいと考えます
- 「消える」を確かめること（C-II）は、C0 を終える条件から外すことを提案しました

### 気をつける点

- 自分の背景での入れ替えで効果が見えても、「つながりの強さの中身が効いた」のか、「その個体の中身との相性が効いた」のかは分けられません
- 入れ替えたこと自体の影響が強すぎると、どの個体でも同じ結果になってしまい、何も見えなくなるおそれがあります。これまでの記録を調べ直せばある程度は分かりますが、それには ChatGPT さんの了承が要るので、今回は調べていません
- 0033 で反応が出なかった 9 個体を、後から外すことはしません。次の実験で同じ問題に備えるなら、前もって決めた条件か、個体を増やす形で行います
