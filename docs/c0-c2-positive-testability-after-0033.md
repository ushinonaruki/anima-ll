### 0.2 結論の先取り

1. **C-II の「再現」の向きは、介入の参照に照らすと C-I そのもので、0031〜0033 が既に行った形である**（命題 1）。新しく足せるのは背景・時刻の広げ方だけ
2. **C-II の「消去」の向きのうち「外れが消える（内に入る）」は、棄却できなかった側の主張で、今の枠では積極的に示せない**（命題 2・命題 3）。同等性（外れが一定の幅より小さい）の形に直すと検定にはなるが、新しく選ぶ幅が要り、20 個体では「補を移したときの外れの頻度」を帰無の水準（1／20）の近くまで抑えることすらできない（0／20 でも片側 95% の上限は 0.139。0.10 を切るには 29 個体、0.05 を切るには 59 個体）
3. **「消える」を「減る」に替えると、積極的に検証できる形がある**（命題 4）：O・M・W1〜W19 の**それぞれの自分の背景**で、自分の重みを、**別に用意したドナーの集まり**（W のほかの本体）の重みに替える。O の自然な値が、自分の背景で、よその重みを入れたどの値よりも予測した向きの端にあるかを、同じことを各 W について求めたものと比べる。これは「O の背景で、O の重みをよその重みに替えると、O の外れが予測した向きに減る」という**消去の向きの C-I**（この文書では C-I^own と呼ぶ）で、O・M を受け手にした背景という「別の背景」の候補でもある。両方の候補（C-II と別の背景）は、この形で一つにまとまる
4. C-I^own の帰無の上界は、0031〜0033 と同じ交換可能性の前提のもとで 1／20（O と M が分かれる事象は 1／420）で、O の外れが残りの塊（Unit の状態など）で運ばれているだけのときには、誤って成り立たない（命題 4 の (b2)）。ただし、成り立っても、重みの「内容」と、重みと背景の「組み合わせ」は分けられない（(b3)）。自然な状態と混成の違い（自己一致の効果）が大きすぎると、同じ値が増えて検出力がなくなる（(b4)。この大きさは既存の raw から数えうるが、再解析になるので、この文書では数えない）
5. **凍結は、新しい事前登録で、ラベルについて対称な条件を前もって決めるなら、帰無の上界を保ったまま扱える**（命題 5）。ただし、0033 を見て決めた条件になるので開示が要る。条件を置かず個体を増やす形もある（30 個体なら閾値は、0031 の割り当てで 5・5・5・3、0032・0033 の割り当てで 6・6・6・3）
6. **推奨**（§8。固定しない）：C-II を元の形（#106 §3.1）のまま実験にしない。次の事前登録の候補の第一は **C-I^own**（重み 6 本、ドナーの集まりは 40 本体、凍結は「外にない」に数え、事前に決めた数の個体）。第二は、ほかの時刻の τ での C-I。W の受け手を増やすだけの形は、足すものが少ない

## 2. 記号

## 3. 命題 1（C-II の「再現」は、介入の参照に照らすと C-I である）【命題】

担い手の整理 §3.1 の C-II の「再現」の向きは「O の c を並べ替えの背景へ移すと、並べ替えが外れる」である。これを

- **(i) 介入の参照**（同じ背景 r に、W のドナーの c を入れた混成 {Y(W_k → r)}）に照らすと、事象は「L(O → r) が {L(W_k → r)} の外」で、0031〜0033 の事象（受け手を一つにしたもの、または受け手をまたぐ合計）そのものである
- **(ii) 自然な参照**（{L(W_i → W_i)}）に照らすと、混成と自然な本体を比べることになり、C2 の整理 命題 D の自己一致の効果（自然な状態と混成の系統的な違い）を含む

（証明：定義を書き下すだけ。(ii) は C2 の整理 命題 D の構成 L(k → a) ＝ 1［k ＝ a］で、O と関係なく混成がつねに自然な参照の外になる。）

**帰結**：再現の向きで積極的に検証できる形は、0031〜0033 で既に行った C-I である。足せるのは、受け手の種類（§6）と時刻（§8 の K5）の広げ方だけ。

## 4. 命題 2（「戻す」は、3 組と Unit の塊に分けても、補を「移す」ことである）【命題】

C2 の整理 命題 B は塊を二つに分けた場合だった。0032・0033 のように重みを組に分けても同じである：塊 c（組の集まり）を W_k から O に戻した混成 Y(W_k → O) の状態は (c_{W_k}, z_O) で、これは「W_k の状態に、O の補 z（入れ替えない組の重み、Unit の状態、痕跡）を移した本体」と同じ状態である。その介入の参照 {(c_{W_k}, z_{W_j})} も、「W_k に W_j の z を移した本体」の集まりと同じ。したがって

```text
E^int_k(c を戻すと内に入る)  ⇔  ¬ R^{(z)}_{W_k}(補 z を O から W_k へ移しても外に出ない)
```

（証明：C2 の整理 命題 B と同じ。混成の状態が同じなら、τ より後の軌道と L は同じ。）

- 例：0033 の 2 組の種類 AB＋AC の本体 Y_r^{AB+AC}(O) ＝ (O の A–B・A–C の重み, r の B–C の重み・Unit の状態・痕跡) は、「O の状態の補（B–C の重み・Unit の状態・痕跡）を r のものに戻した本体」とも書ける。**0033 の事象をこの読みで数え直して、消去の成否を言うことはしない**（§10）
- 帰結：介入の参照に照らした消去は、つねに補の「移す」の否定で、排他性の主張になる（C2 の整理 命題 B の帰結 1）

## 5. 命題 3（「消える」は、今の枠では積極的に示せない。同等性の形の条件）【命題】と【予想】

**(i) 棄却できなかった側**：0031〜0033 と同じ交換可能性の帰無仮説のもとで、受け手を一つにした「移す」の事象の確率は 1／20 以下なので、「内に入る（外に出ない）」の確率は 0.95 以上になる。内に入ったことは、帰無仮説のもとでもふつうに起こり、消えた証拠にならない（C2 の整理 命題 C (i)）。0031〜0033 の受け手をまたぐ合計の形でも同じ。

**(ii) 連言は強くならない**：再現・消去の事象の連言を数えても、帰無のもとの上界は再現の事象だけのものと同じで、成分の確率の積では見積もれない（C2 の整理 命題 C (ii)。構成も同じ）。

**(iii) 同等性の形に直すと、新しい幅と多くの個体が要る**：消去を「補 z を O から移したときの外れの頻度 p_z は、幅 δ より小さい」（H0：p_z ≥ δ を棄却する）と書けば、積極的な検定にはなる。個体ごとの確率が個体によって違っても、H0 のもとで「外れた個体の数 h が k 以下」の確率は、どの個体でも p ＝ δ のときに最大になるので、上界は二項分布で求まる。ただし
- 幅 δ は新しく選ぶ値（チェック C1）で、問いからも力学からも導けない
- 20 個体で H0：p_z ≥ 0.15（δ ＝ 0.15）を水準 0.05 で棄却するには h ＝ 0 が要る（P(Bin(20, 0.15) ＝ 0) ≈ 0.039）。p_z が帰無の水準 0.05 のときでも、h ＝ 0 になる確率は約 0.36 にとどまる【予想】
- 0／20 でも、Clopper–Pearson の片側 95% の上限は 0.139 で、帰無の水準（1／20）の近くまで抑えられない。0.10 を切るには 29 個体、0.05 を切るには 59 個体（どちらも h ＝ 0 のとき）が要る
- しかも、抑えられるのは「補を移したときの外れの頻度」で、「自然な O の外れが消えた」こと（E^nat）ではない。E^nat は混成と自然な本体を比べるので、自己一致の効果を含む（命題 1 の (ii)）

（証明：(i)(ii) は C2 の整理 命題 C。(iii) の上界は、h が独立なベルヌーイの和のとき P(h ≤ k) が各 p_i について単調に減ることから。数値は二項分布を計算した。）

**帰結**：「外れが消える」の形の C-II は、今の 20 個体・交換可能性の枠では積極的に示せない。同等性の形は、新しい幅と 30〜60 個体以上を要し、それでも頻度の上限しか言えない。**今は勧めない**（§8）。

## 6. 命題 4（自分の背景での対称な比較：「減る」は積極的に検証できる）

### 6.1 設計 C-I^own【候補】

C2 の整理 §8 の C2-c（自己一致の対照つきの、自分の背景での比較）を、**ドナーの集まりを的の集まりから分ける**ことで、帰無の上界が成り立つ形にする。

- 的の集まり 𝒯 ＝ {O, M, W_1, …, W_19}（21 本体）。各 a ∈ 𝒯 の**自分の背景**（a の τ の状態）を使う
- **ドナーの集まり** 𝒬 ＝ {W_20, …, W_{19+q}}（q 本体。W と同じ手順・別の名前の乱数の流れで作り、的に含めない）
- 混成：各 a ∈ 𝒯 と各 k ∈ 𝒬 について Y(k → a)（a の背景に、k の塊 c を入れる）。21 × q 本体
- **自分の背景の点**：s^x(a) ＝ Σ_{k∈𝒬} sgn(L(a → a) − L(k → a))（−q〜q の整数。a 自身の c を、よその c に替えたときに、L が下がる数 − 上がる数）
- 個体ごとの事象（向きは 0031〜0033 と同じ。O の重みは Δ_AB・D を大きく、M の重みは D を小さくする）

```text
O の自分の背景で上（Δ_AB）  ⇔  s^{Δ_AB}(O) ＞ max_{d∈𝒲} s^{Δ_AB}(d)
O の自分の背景で上（D）     ⇔  s^D(O)     ＞ max_{d∈𝒲} s^D(d)
M の自分の背景で下（D）     ⇔  s^D(M)     ＜ min_{d∈𝒲} s^D(d)
O と M が分かれる           ⇔  上の 2 番目と 3 番目がともに成り立つ
```

- 読み：O の事象は「O の背景では、O 自身の重みが、よその W の重みのどれと比べても Δ_AB（D）を大きくしていた。その端らしさが、各 W が自分の背景で示す端らしさのどれよりも大きかった」。O の重みをよその重みに替えると O の値が下がる、つまり**消去の向きの C-I**（外れが「減る」）である
- 0031〜0033 との関係：0031〜0033 は「𝒯 の本体をドナーにして、𝒫 の背景へ移す」形だった。C-I^own は**その転置**で、「𝒬 の本体をドナーにして、𝒯 の自分の背景へ入れる」形である。どちらも、𝒯 のラベルの交換可能性という同じ帰無仮説を使う

### 6.2 (a) 帰無の上界【命題】

帰無仮説 H^own：個体ごとに、𝒯 ∪ 𝒬 の本体の τ の状態の同時の分布が、ラベル O・W_1, …, W_19 の入れ替えに対して不変（M は動かさない）。M の事象には同じく M・W_1, …, W_19 の入れ替え（O は動かさない）、O と M が分かれる事象には、𝒯 の 21 のラベルすべての入れ替えに対する不変を置く（0031〜0033 の帰無仮説と同じ形で、ドナーとしての交換可能性を、自分の背景を持つ本体としての交換可能性に置き換えたもの）。

このとき、P(O の事象) ≤ 1／20、P(M の事象) ≤ 1／20、P(O と M が分かれる) ≤ 1／420。

（証明：s(a) は、a の状態と 𝒬 の状態だけの同じ関数 F で決まる：s(a) ＝ F(状態_a；状態_𝒬)。ラベルを入れ替えると、(s(O), s(W_1), …, s(W_19)) の並びも同じく入れ替わる。帰無仮説のもとでこの並びは交換可能で、O が 20 個の厳密な最大になる確率は 1／20 以下（同じ値があれば小さくなる）。O と M の事象は、0031 §4.3 の命題 2 と同じく、21 個のうち O が最大かつ M が最小になる確率で 1／(21 × 20) ＝ 1／420 以下。）

- 𝒬 を 𝒯 から分けるのが要点：𝒬 の状態はどの a の点にも同じように入り、O の重みはほかの的の点に入らない。**ドナーに 𝒯 のほかの本体を使う形**（s(a) を 𝒬 ∪ 𝒯∖{a} のドナーで数える）も帰無の上界は保つが、O の重みが W の背景で強い C-I を持つだけで W の点が下がり、O の事象が成り立ちやすくなる（O の自分の背景での効果と、0031〜0033 の効果が混ざる）。この文書では採らない【候補の比較】

### 6.3 (b) 何を区別し、何を区別しないか【命題（構成）】

連続な値で同じ値が確率 0 の構成で示す（𝒬 と 𝒲 の本体は独立に同じ分布、O は構成ごとに決める）。

- **(b1) 重みの内容が加法的に効く**：L(k → a) ＝ f(c_k) ＋ g(z_a)。s(a) ＝ Σ_k sgn(f(c_a) − f(c_k)) で、z に依らない。f(c_O) がすべてより大きければ s(O) ＝ q（最大）。**事象は「どの W も、自分の重みで 𝒬 のすべてを上回らない」ときに成り立ち、その確率は q／(q ＋ 19)**（W と 𝒬 の 19 ＋ q 個の最大が 𝒬 に入る確率）。q ＝ 20 なら約 0.51、q ＝ 40 なら約 0.68、q ＝ 60 なら約 0.76。**重みが完全に効いても、個体ごとの検出の確率に上限がある**（点が −q〜q に収まり、W が同じ最大の点を取りうるため）。0031〜0033 の形（O が W の点を直接下げる）にはなかった上限である
- **(b2) 外れが残りの塊だけで運ばれる**：L(k → a) ＝ g(z_a) ＋ ε(k, a)（ε は独立で同じ分布）。g(z_O) が飛び抜けていても（自然な比較では O は外にある）、s(a) は ε だけで決まり、(s(a))_{a∈𝒯} は独立で同じ分布になる。**O の事象の確率は 1／20 以下**。つまり C-I^own は、O の外れが重みに運ばれていないときに「重みを替えると減った」と誤って言わない（自然な比較の事象とは違う）
- **(b3) 組み合わせだけが効く**：L(k → a) ＝ 1［k ＝ a］·h(z_a) ＋ ε(k, a)（自分の重みと自分の背景が合っているときだけ、背景に応じた違いが出る）。h(z_O) が大きく h(z_W) が小さければ、O の事象は成り立つ。一方、O の重みを W の背景に移しても何も起きない（0031〜0033 の形は成り立たない）。**C-I^own の成立は、「重みの内容」と「重みと背景の組み合わせ」を区別しない**。区別するには、同じ個体で 0031〜0033 の形（移す）と並べて読むしかなく、その場合も二つを連言にして上界は小さくならない（命題 3 (ii)）
- **(b4) 自己一致の効果が大きすぎる**：L(k → a) ＝ 1［k ＝ a］·H ＋ ε(k, a)、H がどの背景でも ε の幅より十分大きい。すべての a で s(a) ＝ q になり、すべて同じ値で、O の事象はどの個体でも成り立たない。**検出力が 0 になる**（チェック A7 の凍結と同じ形）。C0 で H がどの程度かは、この文書では分からない
  - 0031〜0033 の raw には、受け手 W20〜W24 の自分の背景（自然な受け手の値 L(r → r) と、21 のドナーの混成 L(d → r)）があり、受け手の自分の背景の点は数えうる。ただしそれは既存の raw の再解析で、ChatGPT の方針（別の合意の前に始めない）により、この文書ではしない
  - 行うなら、O・M のラベルの事象に触れない「受け手だけの自己一致の効果の監査」として、量・止め方を先に決め、別に合意を得る（§8.1 の K8）。その結果で K3 の設計（q・点の形）を選ぶことは、既存のデータを見て設計を決めることになるので開示が要る

### 6.4 (c) 言えること・言えないこと（成り立ったとき）

## 13. 専門知識がなくても読める解説（t-k さんへ）

### 何を確かめたかったか

これまでの 0031〜0033 では、「順番どおりに経験した個体（O）のつながりの強さを、ほかの個体へ**移す**と、その個体の反応が O らしく変わる」ことを、条件を変えながら確かめてきました。もともとの目標（C-II）には、もう半分がありました。「O のつながりの強さを、ふつうの個体のものに**戻す**と、O らしさが**消える**」です。今回は、計算をせずに、この「消える」を今のやり方で確かめられるかを整理しました。

### 整理して分かったこと

1. **「消える」は、今のやり方では示せません。** 「違いが見つからなかった」は「違いがない」ことの証拠にならないからです。「ほとんど違いがない」と言い直すと確かめられる形にはなりますが、「どこまでを『ほとんど』とするか」を新しく決める必要があり、個体も今の 20 から 30〜60 以上に増やさないと、ほとんど何も言えません
2. **「消える」を「減る」に言い直すと、確かめられる形がありました。** O・M・ふつうの個体のそれぞれで、自分のつながりの強さを、別に用意した個体たちのものに入れ替えます。O のときだけ、反応が予想した向きに特に大きく変わるかを比べます。「入れ替えたこと自体の影響」は、ふつうの個体でも同じように起きるので、比べることで打ち消せます
3. この形は、「O を受け手にした別の背景」という、もう一つの候補とも同じものになります

### 気をつける点

- この形で効果が見えても、「つながりの強さの中身が効いた」のか、「その個体の中身との相性が効いた」のかは分けられません
- 入れ替えたこと自体の影響が強すぎると、どの個体でも同じ結果になってしまい、何も見えなくなるおそれがあります。これまでの記録を調べ直せばある程度は分かりますが、それには ChatGPT さんの了承が要るので、今回は調べていません
- 0033 で反応が出なかった 9 個体を、後から外すことはしません。次の実験で同じ問題に備えるなら、前もって決めた条件か、個体を増やす形で行います
