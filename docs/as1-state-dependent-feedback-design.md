## 2. 問い（案）

**問い Q-SD**：出来事 e ごとの符号 s_e ∈ {＋, 0, −} は、分岐の前の状態（Pulse t の処理の後の Σ_t と、t までの来歴）だけから、前もって決めた規則で予測できるか。その予測は、規則を決めた後に初めて走らせる個体でも当たるか。

- 0034 が問うたのは、推定対象 A の**向きの多数**だった。Q-SD は、**どの状態のときに、どの符号になるか**を問う。同じ感覚の入力（結果 e）でも、そのときの内部の状態によって、次の行動への効き方が変わるか、という問い
- 推定対象 B・C（可塑性の経路）、行動の選択、学習、意味は問わない
- **予測を当てる道具を作ることが目的ではない**。§3 の機構の見込みが、分岐の前の状態で効果の符号を説明できるかを確かめる

## 3. 機構の見込み（予測の規則の候補）

### 3.1 二つの経路の近似

§1.1 の二つの経路だけを考え、他の Unit と可塑性を無視する近似を **二経路近似**と呼ぶ（案。既存の I1〜I4〔意図の作り方。`ga-closed-loop-n3-n4-design.md`〕とは別のもの）。

- F の源には、t ＋ 3 に w(受→源) の駆動が届く（直接の経路）
- N の源には、N の受が自発に発火したら、その次の Pulse に w(受→源) の駆動が届く（受の位相の経路）
- 源の活動は、Pulse ごとに decay ＝ 0.85 で減衰する。そのため、早く届いた駆動は、源が閾値に届く頃には小さくなっている。閾値の近くで届いた駆動ほど、閾値を越える Pulse を動かしやすい

### 3.2 符号の見込み

- N の受の自発の発火が、源が閾値を越えるより前で、しかも F の直接の駆動より遅く届くなら、N の源のほうが閾値の近くで押される。このとき − になりやすい
- そうでなければ、F の直接の駆動だけが効いて、＋ か 0

### 3.3 0 の見込み（感度）

- 源が閾値に向かって**ゆっくり**近づいているほど（内在の駆動だけでの平衡と、閾値と順応の和との差が小さいほど）、小さい駆動でも越える Pulse がずれやすい。速く近づいているなら、どちらの駆動でもずれず 0
- 順応（発火ごとに 0.01 上がり、τ_a ＝ 300 で戻る）は、実効の閾値を動かすので、感度に効く
- この節は、§1.2 の「間隔の長い個体に d_e ≠ 0 が多い」という観察に影響されている。事前登録では、事後に気づいたこととして開示する

## 4. 予測の材料：分岐の前に取れる量と、取れない量

### 4.1 分岐の前に取れる量（予測に使ってよい）

| 種類 | 量 |
|---|---|
| Unit の状態（Σ_t） | 源・受・他の活動、順応、不応の残り、発火の数 |
| Unit の性質（出生時に決まり、変わらない） | 閾値、内在の駆動、decay、順応の増分と τ_a |
| 過去の来歴（t まで） | 各 Unit の最後の発火からの経過 Pulse、t までの直近のいくつかの発火の間隔、t までの意図の数 |
| 接続の状態（Σ_t） | 6 本の重みと pre・post の痕跡 |
| 世界 | t の時点の予約の列（W-2 により e だけ）、e の Pulse |
| 構成 | 役の割り当て、Pulse t |

### 4.2 将来か反実仮想でしか分からない量（予測に使わない）

| 量 | 理由 |
|---|---|
| τ_F、τ_N、d_e、補助の系の τ・d | 予測したい結果そのもの |
| 本体での t の後の発火・意図（受・他の次の発火の Pulse を含む） | t の後の実際の軌道。未来の真値 |
| 系 N・補助の系の軌道 | 反実仮想を走らせて初めて分かる |
| ほかの出来事の d_e・s_e | 同じ個体の後の出来事も含めて、結果の情報 |
| 本体の t の後の重み・痕跡 | 未来の真値 |

ChatGPT さんの指摘のとおり、「受が次に自発に発火するまでの残り時間」を、本体や N の実際の軌道（未来の真値）から求めるなら、予測には使わない。

### 4.3 境界の量（レビューで決めたい）

**孤立の外挿**：ある Unit が t の後に入力を一つも受けないと仮定して、その Unit 自身の式（activity ← activity × decay ＋ 内在の駆動、順応の戻り）だけで、閾値を越える Pulse を Σ_t から計算した値。例えば、源・受それぞれの「孤立で閾値を越えるまでの Pulse」。§3 の二経路近似の規則は、この量で書ける。

- **使ってよいとする理由**
  - Σ_t と変わらない性質だけの、決まった関数である
  - runtime を進めず、結合した系も、実際の未来の軌道も使わない
  - 「機構から予測する」とは、こういう計算のことである
  - 孤立の外挿と実際の結合した系とのずれ（他の Unit の駆動、e の効果そのもの）こそが、検証で問われる
- **使わないとする理由**
  - 未来を向いた量であり、結合が弱ければ真値に近くなる。そのため、§4.2 との境界がぼやける
- **案**：使うなら、次の 3 つを条件にする
  1. 式を事前登録で固定する
  2. 保存した Σ_t から analyze.py が計算する（runtime を走らせない）
  3. 孤立の外挿を使わない「過去の量だけの予測」も並べて報告し、外挿がどれだけ効いたかを見えるようにする
- **レビューの回答（ChatGPT、#155 review `5697371116`）**：条件つきで採用できる。分岐の時点の状態と、固定した Unit の力学から、「以後に入力がなかった場合の発火の時刻」を計算することは、未来の実測の値を見ることではない。条件は次の 4 つ（上の 3 つと重なる）
  1. 実際の F・N の系を進めて答えを得ない
  2. 計算の式を、評価の前に固定する
  3. **孤立では発火しない場合の扱いを決める**（例：内在の駆動だけの平衡が、閾値と順応の和に届かない Unit。0034 の沈黙の個体の源がこれに当たる。「発火しない」を一つの値として扱うか、規則の場合分けにするかを、事前登録で決める）
  4. 外挿なしの予測との比較を残す

## 5. ＋・0・− の扱い

- 予測は、すべての出来事について ＋・0・− のどれか一つを出す。「予測しない」は認めない（当てやすい出来事だけを選ぶことを防ぐ）
- 0 を落とさない。0034 では 0 が 61%（335/552）だった。正・負だけの当たり方を主の結果にしない
- 打ち切り（？）は、0034 の定義（§2.3 の表）を引き継ぐ。？ の出来事は、正しさの数え方から外し、その数を報告する案。？ が多い個体の扱いは事前登録で決める
- 主の結果とは別に、個体ごとと全体の 3 × 3 の対応の表（予測 × 実際）を、記述として報告する

## 6. 検証の単位と一般化

- **単位は個体（seed）**。同じ個体の出来事は、同じ軌道の上にあって独立ではない。0034 と同じく、個体ごとの事象にまとめて、個体をまたいで数える
- **第一案：パラメータのない規則**
  - §3 の機構から、合わせ込む値のない規則を作り、評価の seed を走らせる前に事前登録で固定する
  - 学習の段がないので、出来事を学習用と評価用に分ける必要がない
  - 新しい個体への一般化は、評価の seed がすべて新しい個体であることで確かめる
- **第二案：合わせ込む値を持つ規則**（閾値などを決める場合）
  - 合わせ込みに使う seed と、評価に使う seed を、**seed の単位で**分ける。同じ個体の出来事が両方に入ることはない
  - 合わせ込みは、評価の seed を走らせる前に終えて固定する
- **探索について**：規則を作るために値を見る段階を置くなら、評価と別の、開示した seed の範囲で行う。見た値は事前登録で開示する。0034 の seed は使わない（§1.3）

## 7. 「前進した」と言える条件（判定の形の候補）

### 7.1 比べる基準（事前に固定する）

多数のクラス（0）に勝つことだけを成功にしない。次の基準と比べる案。

| 基準 | 中身 | 何を除くか |
|---|---|---|
| 定数 0 | すべての出来事を 0 と予測 | 0 の多さだけで当たること |
| 定数 ＋ | すべての出来事を ＋ と予測（直接の経路だけの見込み） | 状態を見ない見込み |
| 個体だけの予測 | 出生時の性質だけから、その個体のすべての出来事に同じ予測を出す | 個体差（性質・役・発火の周期）だけで当たること |

**負の対照**：規則に、別の個体の別の出来事の Σ を入れ替えて渡した予測。基準に勝たないことを確かめる。これで、クラスの頻度の偶然の一致ではないことを見る。

- **注意（レビュー）**：入れ替えた Σ は、役の割り当て・出生時の性質・時刻が、渡した先の出来事と合わない。そのため、規則が崩れるのは当たり前かもしれない
  - 入れ替えの条件（同じ役の Unit どうしで入れ替えるか、近い時刻から選ぶか、など）を事前に固定する
  - 入れ替えで予測が崩れたことを、状態が因果的に効いた証拠とは読まない。負の対照は、頻度の一致による見かけの当たりを除くためだけに置く

### 7.2 判定の形

- **個体の事象（案）**：適用できる個体ごとに、「規則の正しい数 ＞ どの基準の正しい数」（等しいときは成り立たない、保守の側）
- **個体をまたいだ判定（案）**：成り立つ個体の数を、0034 と同じように二項の閾値で判定する
- **未決の論点**：この個体の事象が、帰無仮説のもとで 1/2 以下の確率で成り立つことは、自明ではない。基準の一つは個体の実際の分布にも依るので、そのままでは不利・有利が決まらない
  - 候補 a：個体の中で、規則と基準が食い違った出来事だけを数える（McNemar の型）。規則だけが正しい出来事の数 ＞ 基準だけが正しい出来事の数、を個体の事象にする
  - 候補 b：個体の中の並べ替えで、帰無の分布を作る。ただし、同じ軌道の上の出来事を入れ替えてよいかに疑いがある
  - どちらも、帰無のもとで確率が 1/2 以下であることの根拠を、事前登録の前に詰める必要がある（§10）
- **レビューの見立て（ChatGPT）**
  - 候補 a（McNemar の型）だけでは、同じ個体の中で続く出来事どうしの依存は解けない
  - 候補 b（並べ替え）には、出来事を入れ替えてよい（交換可能性の）根拠が要る
- **有力な代案（レビュー）**
  - 評価の前に、規則と基準を固定する
  - 個体ごとに「規則が、どの基準も上回ったか」を一つの事象にまとめる
  - 帰無仮説を「適用できる個体で、規則が基準を上回る確率は 1/2 以下」と明示する。そうすれば、個体が独立・同一分布という仮定のもとで、二項の判定を作れる（0034 の §4.2 と同じ型のモデル依存の保証）
  - これは、**個体の過半数で予測がよくなるかの検定**であって、状態が因果的に寄与したことを直接に示す検定ではない（§7.4）

### 7.3 適用・不適用

- 0034 と同じく、本体の区間 W に出来事のない個体は N/A とする。これは、本体の意図の記録だけで、結果を見る前に決まる
- 規則がすべての出来事に同じ予測を出す個体も、適用の対象に入れる

### 7.4 結果ごとに言えること（案）

| 結果 | 言えること |
|---|---|
| 成立 | **事前に固定した機構の近似（二経路近似）の予測が、新しい個体のデータと整合した**（AS1、この構成。個体の独立・同一分布のモデルを仮定した判断）。ここまでに限る |
| 不成立 | 二経路近似の予測は、事前の基準では、符号を説明しきれなかった。他の Unit の駆動・順応の変化などの結合が効いている可能性がある。「状態に依らない」とは言わない。閾値を下げて救わない |

- **予測の成功は、機構の証明ではない**（修正必須②）
  - 分岐の前の状態から符号を予測できても、その状態の量が符号を因果的に決めたと特定したことにはならない
  - 予測に使った量（出生時の性質、過去の発火の来歴、孤立の外挿など）は、観測していない別の状態の代理になっているかもしれない
  - 状態の量が因果的に効くことを言うには、**追加の介入の検証**が要る。例えば、分岐の時点で、その量だけを変えた複製を作り、符号が見込みどおりに変わるかを見る。そうした検証は、別の事前登録で行う
  - 成立したときも、「状態依存の帰還が機構として確かめられた」とは書かない

## 8. 交絡の候補と、境界

### 8.1 交絡の候補

- **個体差**：出生時の閾値・内在の駆動（発火の周期を決める）、役の割り当て。0034 では、符号の偏りが個体ごとにそろっていた（§1.2）。出来事の状態ではなく、個体の性質だけで当たっているのかもしれない。§7.1 の個体だけの予測で分ける
- **走らせた時間の長さ**：順応の積み重ねや重みの変化。Pulse t を過去の量として持つ予測を、基準として並べることを検討する
- **間隔の長さ**：§1.2 で、長い間隔と d_e ≠ 0 の重なりを見た。間隔そのものが原因か、感度（§3.3）の代わりの印にすぎないかは分けられない

## 12. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

0034 で分かったのは、「結果の感覚を取り除くと、次の行動のタイミングが、早まったり遅れたり変わらなかったりする」ことでした。次の実験では、**どれになるかを、その瞬間の内部の状態から前もって当てられるか**を問います。

### 大事な約束

- **未来のことを使って当てない**：「この後に何が起きたか」を見てから説明するのではなく、その瞬間に分かることだけで予測します
- **「変わらない」も当てる対象にする**：0034 では 6 割が「変わらない」でした。当てやすい場面だけを選ばないようにします
- **新しい個体で確かめる**：当てる規則を先に決め、まだ動かしていない個体で試します
- **観測を足すだけで、動きは変えない**：当てやすくするために、仕組みをいじることはしません
