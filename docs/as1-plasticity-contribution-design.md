### 0.2 結論の先取り

1. **経験の履歴の違いを、二つの層に分ける**【整理】（§1.3）
   - **外の履歴**：経験の区間に受けた感覚の列。閉ループでは、可塑性を止めると行動が変わり、受ける列も変わる（PC-1 の交絡）
   - **内の履歴**：同じ列を受けても、重みが違えば発火が違い、Unit の状態（活動・順応など）が違ってくる
   - PC-3（再生）は外の履歴をそろえ、PC-4（移植）は内と外の両方の履歴をそろえる。PC-3 だけでは、内の履歴の違いが残る
2. **中心の比較の案：経験の区間の終わり P_E で、「状態」と「重み」を入れ替えた 2 × 2**【候補】（§6.1）
   - 本体 M（可塑性あり、閉ループ）と、再生の系 Y を P_E まで走らせる。Y は同じ個体で、経験の区間の全体で可塑性を止め、M が受けた感覚の列を開いたループで受ける
   - P_E で、M の状態に経験の前の重みを移植した M[W_0]（PC-4）と、Y の状態に M の重みを移植した Y[W_M] を作る
   - Y は E の全体で FREEZE 中なので、P_E の境界で、E の介入の解除 → 複製 → 移植 → 世界の規則の切り替え → U の介入の宣言、の順で作る（§3.2 の S0〜S6）
   - 4 つの系は、経験の区間に受けた感覚の列が同じである
   - M と M[W_0]、Y と Y[W_M] は、重みだけが違う（痕跡も同じ）
   - M[W_0] と Y は、重みが同じ W_0 で、内の状態（Unit の状態と届く途中の駆動）と痕跡が違う。試しの区間で重みを止めれば痕跡は軌道に効かない（命題 Q2-5）ので、実質的に内の状態だけが違う
   - 「重みの違い」の効果を二つの状態のもとで別々に測り、どちらの順でも報告する。分け方は一意でない（U5）
3. **経験の列そのものの違いは、可塑性を止めた閉ループの系 K（PC-1 の OFF）と Y を比べて、別に測る**【候補】（§6.2）
   - K と Y は、どちらも可塑性を止めている
   - 違いは、経験の区間に受けた列（K 自身の行動から生まれた列か、M の列か）と、ループが閉じているかどうか
4. **経験の区間は、出生から P_E までを第一候補にする**【候補】（§3.1）
   - 経験の前の重みは、出生時の値 w0（6 本とも）で、組の和の保存（F1）を満たす
   - 可塑性を止めた系（Y・K）の重みも w0 のまま。そのため、PC-4 の移植の先の二つの候補（経験の前の値、OFF の系の値）は一致する（§9 の SE-2）
5. **試しの区間は、すべての系で同じ条件にする（LC5）**【候補】（§3.3）
   - 第一候補：経験と同じ閉ループの規則で、可塑的な接続 6 本を FREEZE する
   - 重みを止めると、試しの区間の中で経験の列がまた分岐しても、重みには効かない（G-7 の再移動を除ける）
   - その代わり、試しの区間の系は、命題 G-1 の意味で C0 の力学の系ではない。この形の結果を「自然な AS1 全体の効果」とは呼ばない。規則どおりに動かす形は、感度の分析の候補にする
6. **比べる量は、試しの区間の意図の列から取る。符号を事前に決めない（両側。G-10）**【候補】（§7）

## 1. 問い（案）と、分けたい違い

### 1.1 問い（案）

R4 §6.3 の問い：**AS1 で、経験の区間の可塑性で形づくられた重みは、後の行動（試しの区間の意図の時刻・間隔）に寄与するか。**

### 1.2 PC-1 だけでは足りない理由【既存の命題・整理】

- 閉ループでは、可塑性を止めると重みが変わり、発火が変わり、意図の時刻が変わり、結果の刺激の時刻が変わる（三段の比較 §3.3.4、N-3・N-4 §3.3 の H^alt の (c)）
- そのため、可塑性あり・なしの閉ループの系の差には、「重みの違い」と「受けた経験の違い」が混ざる

### 1.3 記号と二つの層【整理】

**記号**
- 源・受・他：三段の比較 §3.3 と同じ（行動の源の Unit、結果を受ける Unit、残りの Unit）
- E ＝ [1, P_E]：経験の区間
- U ＝ [P_E ＋ 1, P_E ＋ |U|]：試しの区間（|U| はその長さ）
- W：可塑的な接続 6 本の重み（0034〜0036 の出来事の窓 W とは別の記号）
  - W_0：E の始まりの重み
  - W_M：P_E の終わりの M の重み
- S^ext：E に成立した感覚の出来事の列（Pulse・Receptor・個数）
- 状態：Σ（AS1 の契約 §4.1）のうち、重み以外のもの。次の三つに分けて呼ぶ
  - **内の状態**：Unit の状態（活動・不応・順応・発火の数）と、届く途中の駆動・Delta
  - **痕跡**：可塑的な接続ごとの、送り手と受け手の痕跡
  - **世界と記録**：世界の予約・受けた意図の記録・計数、識別子の発行、Runtime の内部の記録など

**二つの層**
- **外の履歴**：S^ext。閉ループの M では、M 自身の意図から生まれる
- **内の履歴**：E の全 Unit の発火の列と、そこから決まる P_E の内の状態・痕跡
- **経験中の可塑的な接続変化**：W_M − W_0

**M の中の因果の向き**：可塑性 → W の変化 → 発火の変化 → (a) 内の状態・痕跡の変化、(b) 意図の変化 → 結果の刺激の変化（S^ext の変化）→ 発火の変化 → …

- PC-1（M と K）では、W・内の履歴・外の履歴の三つが、すべて違う
- PC-3（M と Y）では、外の履歴がそろい、W と内の履歴が違う。内の履歴の違いは、それ自体が可塑性の結果である（命題 Q2-1）
- PC-4（M と M[W_0]）では、内と外の履歴の両方がそろい、W だけが違う。その代わり、組み合わせが自然には到達しない状態でありうる

### 1.4 個体ごとの対比の名前【候補】

ある量 T（§7）について、個体 i ごとに次のように書く。T が数でないとき（意図の列そのもの）は、差の代わりに一致・不一致を使う。

| 名前 | 定義 | 何をそろえ、何を変えたか |
|---|---|---|
| **C^tr** | T(M) − T(M[W_0]) | 内と外の履歴をそろえ、P_E の重みだけを W_M から W_0 に替えた（PC-4） |
| **C^tr′** | T(Y[W_M]) − T(Y) | Y の状態のもとで、重みだけを W_0 から W_M に替えた（逆の順の移植） |
| **C^rep** | T(M) − T(Y) | 外の履歴をそろえ、E の可塑性を止めた（PC-3） |
| **H^ext** | T(Y) − T(K) | 可塑性を止めたまま、受けた列（M の列か、K 自身の列か）とループの閉じ方を変えた |
| **C^PC1** | T(M) − T(K) | E の可塑性を止めた閉ループの系との差（PC-1）。C^rep ＋ H^ext に等しい |

- どれも、背景の状態に依存した条件付きの対比で、背景をまたぐ一意の寄与（C-III）ではない（U5）
- 数の T について、C^rep ＝ C^tr ＋ [T(M[W_0]) − T(Y)] ＝ [T(M) − T(Y[W_M])] ＋ C^tr′ と二通りに書ける。どちらの順を「本当の内訳」とも呼ばない（§6.1）

## 2. 前提の命題

### 命題 Q2-1（G-2 の系：再生の系の差は、可塑性を止めたことだけから生じる）【命題】

**前提**
- Y^ON：Y と同じ作りで、FREEZE だけを置かない系
- 同じ出生時の状態・役の割り当てで、M の S^ext（と §3.2 の持ち越し）を、開いたループで受ける

**主張**
- (i) Y^ON の軌道は、P_E まで M と一致する
- (ii) Y と M の P_E での違い（重み・内の状態・痕跡・発火の列）は、すべて、E で可塑性を止めたことから生じる。受けた感覚の列は同じである

**証明**
- (i) は N-3・N-4 の命題 G-2 そのものである（AS1 の道具では `test_open_loop_replay_of_the_own_sensory_sequence_reproduces_the_closed_loop` が確かめている）
- (ii) Y と Y^ON の作りの違いは FREEZE だけで、Y^ON は (i) により M と同じ軌道をたどる

∎

**帰結**
- Y^ON は比べる系にしない（差は構成上 0）。契約テストにだけ使う（CT-PC1）
- C^rep は、「外の履歴をそろえたもとでの、E の可塑性の全体の効果」である。重みの違いと、それが生んだ内の履歴の違いの両方を含む

### 命題 Q2-2（FB-1 を置いた接続の重みは、ほかの量に効かない）【命題】

**前提**
- (a) AS1 の道具の FB-1：対象の接続 c について、伝達に渡す重みを 0 にする。中の重みは規則どおり動く（CT-I2）
- (b) 可塑性の規則は接続ごとに局所的である：各接続は、自分の重み・痕跡と、両端の Unit がその Pulse に発火したかだけで更新される（`ConnectionStore.apply_activity`、`balanced_pair_window`）
- (c) 痕跡は、両端の Unit の発火だけで更新される（同じく `balanced_pair_window`）
- (d) Unit の状態の更新は、Unit の状態、届いた駆動の重みの和、Receptor の入力で決まる（命題 G-1 の証明で使う更新の形。`GenericCognitiveUnit.tick` は駆動の重みの和だけを読む）

**主張**
- 境界 u0 で、c の重みだけが違う二つの系がある
- 両方で [u0 ＋ 1, u1] に FB-1 を c に置く
- このとき、その区間の全 Unit の発火と状態、c 以外のすべての接続の重みと痕跡、c の痕跡は、二つの系で一致する
- 違うのは c の重みだけである（FREEZE を併せれば、それも一定のまま）

**証明**：帰納法。Pulse u の冒頭で、ほかのすべてが一致しているとする。
- 伝達に渡す重みは、c について両方 0（前提 (a)）で、ほかは一致する
- そのため、駆動が一致し、Unit の状態と発火も一致する（前提 (d)）
- c 以外の接続の更新は、自分の状態と発火だけで決まり、一致する（前提 (b)）
- c の痕跡も、発火だけで決まり、一致する（前提 (c)）

∎

**帰結**
- 試しの区間で c に FB-1 を置くなら、c だけの移植は構造上何も変えない。比べる系にしない（§9 の SE-6）
- 直接の組（源 → 受・受 → 源）を移植し、試しの区間で受 → 源 の伝達に FB-1 を置くと、二つの系の差は 源 → 受 の重みの違いを通してだけ生じる
- 逆に 源 → 受 に FB-1 を置けば、差は 受 → 源 の重みの違いを通してだけ生じる
- これは、三段の比較の命題 G-8 の帰結（「その一つの数が、どちらの向きの伝達を通って効いたかを、条件付きで比べうる」）を具体にした形である（§6.3）
- 0036 で見落とした抑制と遮断の構造上の一致（R4 §3.2）と同じ型の性質である

### 命題 Q2-3（組ごとの移植は F1 を保つ）【命題（既存の命題からの帰結）】

**前提**
- 境界 u0 で、移植する組のそれぞれについて、2 本の両方を、和が w_max になる値に置き換える
- 例：出生時の値 w0 ＋ w0 ＝ w_max。または、F1 を満たす系（M など）の同じ組の値
- その後は、自然な規則で、更新が範囲の中にとどまる（三段の比較の命題 G-8 の前提）

**主張**：u0 の後も、その組の和は w_max のまま（浮動小数点の丸めを除く）。

**証明**：G-8 の証明（F1）の帰納法を、u0 から始めればよい。FREEZE のもとでは、和は一定である。∎

**帰結**
- 組の両方を移植する形（全 6 本、直接の組）は、G-8 の前提を保つ
- 片側だけの移植（受 → 源 だけ）は F1 を破る。主の比較にしない（CT-I5 で記録する）

### 命題 Q2-4（源が沈黙していれば、源に接する重みは変わらない）【命題】

**前提**
- 痕跡は 0 から始まる（`PlasticState` の初期値）
- 可塑性の規則は `balanced_pair_window`
  - 受け手が発火したとき、送り手の痕跡 x を使って A·x·(w_max − w)／w_max だけ強める
  - 送り手が発火したとき、受け手の痕跡 y を使って A·y·w／w_max だけ弱める
  - 痕跡は、1 Pulse ごとに減衰し、その Pulse に発火していれば 1 を足す
- 源が Pulse 1〜P に一度も発火しない

**主張**
- P の終わりに、源に接する可塑的な 4 本（源 → 受、受 → 源、源 → 他、他 → 源）の重みは、出生時の値と、浮動小数点のビット単位で同じ
- 源の側の痕跡（源 → u の送り手の痕跡、u → 源 の受け手の痕跡）は 0 のまま

**証明**
- 源の痕跡は 0 から始まり、源が発火したときにだけ 1 が足される。減衰は 0 を 0 のままにする
- 源 → u：強める項は x ＝ 源の痕跡 ＝ 0 なので 0.0。弱める項は源の発火が要るので 0
- u → 源：強める項は源の発火が要るので 0。弱める項は y ＝ 源の痕跡 ＝ 0 なので 0.0
- w ＋ 0.0 − 0.0 ＝ w で、範囲の切り詰めは働かない（w0 は範囲の中）

∎

**帰結**
- 同じ証明で、源の最初の発火の Pulse の一つ前まで、この 4 本の重みは w0 のままである
- E で源が沈黙した個体では、次が成り立つ
  - 直接の組の移植 M[W_0^pair] は、M と同じ系になる（恒等）
  - 全 6 本の移植 M[W_0] と M の違いは、受 − 他 の組の重みだけになる
  - S^ext は空になる（AS1 には行動に依らない刺激がない）
- 0034〜0036 では、源が全期間で沈黙した個体が 1〜2 割あった（2/20・11/60・17/80。R4 §4）。この割合は Q2 の個体でも同じ程度と見込む【予想】

### 命題 Q2-5（重みをすべて止めた区間では、痕跡は軌道に効かない）【命題】

**前提**
- [u0 ＋ 1, u1] で、可塑的な接続 6 本のすべてに FREEZE を置く（痕跡の扱いはどちらでもよい）
- AS1 の道具の FREEZE は、毎 Pulse の更新の後に、重みを宣言の時点の値に戻す（CT-I3）

**主張**：境界 u0 で痕跡だけが違う二つの系の、その区間の全 Unit の発火と状態、全接続の重みは一致する。

**証明**
- 伝達に渡す重みは、FREEZE の値で、痕跡に依らない
- Unit の更新は、駆動と Unit の状態だけで決まる
- 痕跡が入るのは重みの更新だけで、その結果は FREEZE が上書きする
- 帰納法で一致する

∎（三段の比較の命題 G-9 の前提 (d) と同じ型）

**帰結**
- 試しの区間で 6 本を FREEZE するなら、PC-4 で痕跡を残すか、移植の先の値に合わせるかは、軌道に効かない
- M と M[W_0] は、もともと重みだけが違う（移植は痕跡を変えない）
- M[W_0] と Y は、重みが同じ W_0 で、内の状態と痕跡が違う。この命題により、実質的に内の状態だけが違う（世界と記録の欄の違いは CT-PC5 で扱う）
- 試しの区間で規則どおりに更新するなら（§3.3 の TP-2）、この命題は使えない。痕跡も比べる違いに入る

## 3. 経験の区間と試しの区間【候補】

### 3.1 区間の形

- **経験の区間 E ＝ [1, P_E]**：出生から始める（第一候補。X-1）
  - 経験の前の重み W_0 は、出生時の値（6 本とも w0 ＝ w_max／2）で、すべての個体で同じ。F1 を満たす
  - 可塑性を止めた系（Y・K）は、出生から FREEZE するので、重みは W_0 のまま。移植の先の「経験の前の値」と「OFF の系の値」が一致する（SE-2）
  - 共通の前の区間の長さという、別の自由度を持ち込まない
  - 限界：出生の直後の過渡も、経験の区間に入る。「OFF」は「一度も可塑性が働かなかった」ことを意味する
- 代わりの候補（X-2）：共通の前の区間 [1, P_0] を、可塑性あり・閉ループで全系に共通に走らせ、P_0 で分ける
  - W_0 は M の P_0 の重みになる。これは前の区間の可塑性で、すでに形づくられている
  - 「OFF」は「P_0 から後に変わらない」ことを意味する
  - 「ある時期の経験」を問うときに使う形で、Q2 の最初の実験では採らないことを候補にする
- **試しの区間 U ＝ [P_E ＋ 1, P_E ＋ |U|]**
- P_E と |U| は、事前登録で、すべての個体に同じ値を決める。結果に依って変えない
  - 長さは、計算の時間と、0034〜0036 の §15 に書かれた公表済みの値（出来事の数など）から見積もる
  - 合成の seed で判定の量を見て決めることはしない

### 3.2 境界の規則

- **B-1 持ち越し**
  - M の E の意図から生まれ、P_E より後に成立する結果の刺激は、M の履歴から作るすべての系（M・M[·]・Y・Y[·]）で同じに届ける
  - L ＝ 2 では、Pulse P_E の意図の結果が P_E ＋ 1 に成立するものだけが該当する（AS1 の契約の WC-2：意図が Pulse t に来たら、結果を Pulse t ＋ L − 1 に予約する）
  - Y では、再生する列に含める。K は、自分の持ち越しを持つ（K は自分の履歴の系だから）
- **B-2 世界の規則の切り替え**
  - P_E ＋ 1 から後は、すべての系が試しの区間の世界の規則に従う。P_E ＋ 1 以後の意図には、その規則で応じる
  - Y・Y[W_M]（E では開いたループ）では、境界 P_E で世界の規則を切り替える（S4）
  - 持ち越しの刺激（P_E ＋ 1）と、試しの区間の結果（早くて P_E ＋ 2）は、同じ Pulse に重ならない
- **B-3 境界 P_E の操作の順序（S0〜S6）**
  - **S0**：M・Y・K を、Pulse P_E の処理の後（Pulse のあいだ）まで進める
  - **S1 E の介入の解除**：Y と K で、E の FREEZE を解除する（`clear`。境界 P_E を記録する）。M は E に介入を持たない。これで、すべての系の介入の状態が空になる
  - **S2 複製**：M から M[W_0]・M[W_0^pair] の元を、Y から Y[W_M] の元を、丸ごと複製する（M1）。元の系と複製は、介入の状態（空）を含めて Σ が同じ
  - **S3 移植**：複製に、宣言した重みを移植する。M[W_0] は全 6 本を W_0 に、M[W_0^pair] は直接の組を W_0 に、Y[W_M] は全 6 本を M の P_E の重みにする
    - 介入の状態が空なので、今の `transplant` の検査（FREEZE 中の接続へは移植できない）に掛からない
    - Y に E の FREEZE を残したまま移植すると、`transplant` が止める。v0.1 の「移植してから FREEZE を宣言する」だけでは、この手順が決まっていなかった
  - **S4 世界の規則の切り替え**：Y・Y[W_M]（E では開いたループ）の世界を、試しの区間の規則に切り替える。TC-1 では、M・M[·]・K はすでに同じ閉ループなので、そのまま。TC-2 なら、すべての系を切り替える
  - **S5 U の介入の宣言**：すべての系で、U の介入を一度の宣言で置く
    - 宣言は、それまでの介入の全体を置き換える（監査 024）。FB-1 と FREEZE を併せる変種（§6.3）は、同じ宣言の中で置く。別々に宣言すると、後の宣言が前の介入を消す
    - TP-1 では、6 本の FREEZE（痕跡の扱いも宣言する）。FREEZE の値は宣言の時点の重みで、M は W_M、M[W_0] は W_0、Y は W_0、Y[W_M] は W_M、K は W_0
    - S1 から S5 までのあいだに Pulse を進めない。可塑性の更新は Pulse の末尾にだけ起きるので、解除しているあいだに規則どおりの更新は一度も起きない
  - **S6 U を進める**：すべての系を、P_E ＋ |U| まで進める
    - 宣言した介入と移植した重みは、Pulse P_E ＋ 1 の冒頭の伝達と末尾の更新から効く（AS1 の道具の宣言の境界の意味）
    - Pulse P_E に生まれた届く途中の駆動は、移植の前の重みで作られたまま、移植した系と元の系で同じである（AS1 の契約 §4.4：重み以外の Σ は比べる系で同じにする）
  - **比べる時点**：系の間の Σ の比べ（CT-PC5）は、(a) S3 の直後（S4 の前）と、(b) S5 の直後の二つで行う
  - 道具の口は今のまま（`clear`・`clone`・`transplant`・`declare`）で足りる。FREEZE 中の移植を許す変更はしない
- **代わりの案：静かな区間**（AS1 の契約 §4.4 の「一つの案で、必須ではない」）
  - E と U のあいだに、予約の列と駆動が空になるまで待つ区間を置く
  - それ自体が経験と世界の条件を変えるので、第一候補にしない。置くなら、別の条件として記録する
- **B-4 測る区間**
  - T は U だけから取る
  - E の行動は T にしない。母集団の定義（§8.1）と記述にだけ使う

### 3.3 試しの区間の条件

すべての系で同じにする（LC5）。二つの軸がある。

**世界**
- **TC-1 経験と同じ閉ループの規則**（第一候補）
  - U の結果の刺激は、経験で形づくられた帰還の経路の重みを通って、後の行動に効く。推定対象 C の定義（経験で形づくられた帰還の経路の効果）に最も近い
  - U の結果の刺激の列は、系ごとに違う（意図が違うので）。これは同じ規則のもとでの結果の一部で、交絡ではない
- **TC-2 結果を止める**
  - 受に結果の刺激が来ないので、源への接続を通る駆動は、結果の刺激以外の要因（Unit 自身の活動、ほかの Unit からの伝達）で生じた受・他の発火から来る分だけになる
  - 「自発のリズムが変わったか」を見る形で、U では帰還を使わない

**可塑性**
- **TP-1 6 本の FREEZE**（第一候補）
  - U の重みは、P_E の値のまま。T は、P_E の重みの効果を読む
  - U の中で経験の列が分岐しても、重みは分岐しない（PC-1 の交絡が、U の中でまた起きない）
  - 命題 Q2-5 により、痕跡の扱いが軌道に効かない
  - 限界：U の系は、命題 G-1 の意味で C0 の力学の系ではない。「後の行動」は、重みを止めた系の行動である
  - そのため、TP-1 の結果を「自然な AS1 全体の効果」とは呼ばない
- **TP-2 規則どおり**
  - 自然な続きになる
  - その代わり、移植した重みが U の中でまた動く（G-7）。M[W_0] は U の中で学び直し、差には U の中の学習の違いが入る。経験の列の分岐も、U の中でまた起きる
  - 感度の分析の候補にする

## 4. PC-3：同じ外の履歴の再生

### 4.1 作り【候補】

- **L-R4 帰還の経路に限らない**

- **L-R7**：出生から可塑性を止めた系は、命題 G-1 の意味で C0 には戻らない。比較の対照であって、基準ではない

## 5. PC-4：状態をそろえて、重みだけを移す

### 5.1 作り【候補】

- **M[W_0]**：M を P_E で複製し（M1。AS1 の契約 §4。§3.2 の S2）、宣言した接続の重みを W_0 に置き換える（S3）。そのあと、U の介入を宣言する（S5）

  - 直接の組の 2 本（源 → 受、受 → 源。PC-4-pair）
  - 片側（受 → 源 だけ）：F1 を破る（G-8）ので主にしない。置くなら、組の和を記録する（CT-I5）
- **逆の順の移植 Y[W_M]**：Y の E の FREEZE を解除してから（S1）、Y を複製し（S2）、M の P_E の重み（全 6 本）を移植する（S3。§6.1 の 2 × 2）

  - 解除から U の介入の宣言（S5）までのあいだに Pulse を進めないので、規則どおりの更新は起きない
- **移植の先の値**：W_0（経験の前の値）。X-1 では出生時の値 w0 で、Y・K の値と同じ（SE-2）

### 5.2 適用の条件

## 6. 二つを組み合わせる【候補】

### 6.1 状態 × 重みの 2 × 2（中心の比較の案）

P_E の時点の 4 つの系：

|---|---|---|

  - 重みの効果：C^tr（M の状態のもと）と C^tr′（Y の状態のもと）

## 8. 判定の形の候補（事前登録で決める）

### 8.1 単位と母集団

- 単位は個体。出生時の状態を独立・同一分布と見なす（0034〜0036 と同じ）
- 個体を、次の三つに分けて扱う。どれも事前登録で前もって定め、結果を見てから変えない

| 分け方 | 定義 | 主の判定（J-1）での扱い | 報告 |
|---|---|---|---|
| **適格外**（研究目的による事前の除外） | M の E の意図の数 n_E(M) が m_E より少ない | 分母に入れない | 件数を報告する。対比の量は計算できるので、記述として並べてよい（判定には使わない） |
| **適格で、構造上の恒等** | 適格な個体のうち、移植する集まりで W_M ＝ W_0 | **分母に残し、P_i ＝ 0 と数える** | 「重みの差がないので、構成上、検出できない」の札と件数を別に報告する |
| **適格で、恒等でない** | 残りの適格な個体 | 分母に入れ、P_i を観測のとおりに数える | — |

- **適格の条件は、比べる対比より前に決まる量だけで定める**
  - n_E(M) は、ほかの系を作る前に M だけから決まる（Y の受ける列も M の E から作る）。U の結果にも、W_M ＝ W_0 かどうかにも依らない
  - 理由（研究目的）：Q2 は、閉ループの経験で形づくられた重みを問う。源が E でほとんど行動しなかった個体は、その経験をほとんど持たない
- **源の沈黙は、観測できないことではなく、適格外である**
  - m_E ≥ 1 なら、E で源が一度も発火しなかった個体は適格外になる
  - その個体は、PC-4-pair では構造上の恒等になる（命題 Q2-4）が、PC-4-all では受 − 他 の組の重みが変わりうるので、全 6 本の恒等とは限らない。二つを同じ札にしない
  - 0034〜0036 では、源が全期間で沈黙した個体が 1〜2 割あった（R4 §4）。個体の数の見込みに、前もって入れる（R4 §6.3）
- **観測できない場合**
  - 主の第一候補の T0（意図の列の一致・不一致）は、意図が一つもなくても定まる。そのため、適格な個体で観測できないことはない
  - T2・T3 を使う量では、打ち切り・意図の数の不足の扱いを事前に決める（§7.1）
- **W_M ＝ W_0 を確かめてから、主の判定の分母から除くことはしない**
  - 除くと、帰無・閾値・区間が、別の条件付きの母集団のものになる
  - 別の条件付きの母集団（例：Δw が目安を超える個体）を使うなら、その定義・判定の閾値・帰無を、主の判定とは独立に事前登録する

### 8.2 判定の候補

- **J-1 存在（個体の多数）**
  - 母集団：§8.1 の適格な個体（m 個体）。構造上の恒等の個体も含む
  - P_i：I_U(M) ≠ I_U(M[W_0])。構造上の恒等の個体では P_i ＝ 0
  - 判定：0034〜0036 と同じ形（m 個体のうち k(m) 個体以上）
  - **多数を問う理由**（R4 §7.2）
    - 個体ごとの比べは決定論で、一つの個体から一つの 0・1 が得られる。独立の標本と見なせるのは、出生時の状態のモデルのもとでの個体で、出来事ではない
    - 「適格な個体の過半で、重みを経験の前に戻すと、後の意図の列が変わる」は、効果の大きさが個体で大きく違っても、母集団の性質として述べられる
    - 過半という閾値は 0034〜0036 と同じ形で、結果を見てから変えない。過半に届かない割合は、区間とともに記述する
  - 個体の割合とその区間（Clopper–Pearson）を、判定と別の欄で必ず報告する
  - **注意**：存在は大きさではない
    - 決定論の系では、ある Pulse で発火が一つ分かれると、その後の列は（順応などを通して）違ってきうる
    - P_i が言うのは「重みの違いが、U のうちに源の意図に届いた」ことで、「効果が大きい」ことではない
    - そのため、最初に分かれた Pulse と、T1〜T3 の差の分布を並べる
- **J-2 向き（両側）**
  - D_i ＝ T1(M) − T1(M[W_0])（または T2）
  - D_i ≠ 0 の個体について、符号の検定（厳密な二項、両側。D_i ＝ 0 の個体を除く通常の形）
  - D_i ＝ 0 の個体の数（構造上の恒等を含む）を、別に報告する
  - 帰無：独立・同一分布の母集団で、P(D_i ＞ 0) ＝ P(D_i ＜ 0)
  - 不成立は効果がないことではない。符号が個体で違いうる（G-10）
- **J-3 大きさ（記述）**：D_i の分布（四分位など）。閾値を置かない
- C^rep（PC-3）・C^tr′・H^ext・C^PC1 にも、同じ形の量を計算する
- **主の判定は一つにする**
  - 対比 × 量 × 形の組を一つ選ぶ
  - ほかは、判定なしの必ず報告する対照にするか、事前に決めた族の水準の調整のもとで判定する
- **主の判定の第一候補**：C^tr（PC-4-all、M の状態、TC-1・TP-1）× T0 の存在（J-1）
  - 内と外の両方の履歴をそろえ、重みだけを変える。ChatGPT の指示の中心（経験中の可塑的な接続変化の効果を、経験の履歴の違いと区別する）に最も近い
  - C^rep・C^tr′・H^ext は、必ず報告する記述の対照にする。C^rep は、自然には到達しない状態を作らない対照でもある
  - v0.1 のレビューで、この方向は支持された。承認は v0.2 の確認の後で、事前登録で固定する（§12）
  - 代わりの案（C^rep を主にする）は、第一候補にしない

### 8.3 識別に役立つ陰性と、情報の足りない不成立（R4 §9）

- 母集団の多くの個体で Δw がはっきり 0 でないのに J-1 が成り立たない場合
  - 「この経験の長さで形づくられた重みの変化は、U のうちに、後の意図の列をめったに変えなかった」という、識別に役立つ陰性になりうる
- Δw が小さい、または適格外が多くて適格な母集団が小さい場合
  - 情報の足りない不成立
- 「はっきり 0 でない」の目安（w0 との比など）と読み方は、結果の前に事前登録で書く【未決】
- どちらの場合も、「推定対象 C は存在しない」とは言わない。区間の長さと条件に依る
- 成立・不成立・判定不能（操作の確認の不成立、母集団が判定に必要な数に届かない、など）のどれになっても、すべて報告する（R4 §6.4）。判定不能の条件は、事前登録で前もって書く

## 14. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次に調べる「学習の効き目」（経験の中で起きた接続の変化が、後の行動に効いているか）の測り方を、実験の前に設計しました。今回は設計だけで、実験はしていません。

### 難しいところ

AI は、自分の行動の結果を感じながら経験します。学習（接続の変化）を止めると、行動が変わり、感じる結果も変わります。そのため、「学習あり」と「学習なし」を単純に比べると、違いが「学習のせい」なのか、「違う経験をしたせい」なのかが分かりません。

さらに、「経験の違い」には二つの層があります。
- **外の経験**：外から何を感じたか
- **内の経験**：同じものを感じても、接続が違えば中の動き方が違い、その積み重ねで中の状態（疲れ具合のようなもの）が違ってきます

### 考えた方法

- **再生（PC-3）**：学習ありの AI が感じたものを、そっくり記録して、学習なしの同じ AI に聞かせます。外の経験はそろいますが、内の経験の違いは残ります
- **移植（PC-4）**：学習ありの AI の経験が終わった時点で、そのコピーを作ります。コピーの接続の強さだけを、経験の前の値に戻します。内と外の経験はそっくり同じで、接続の強さだけが違います。ただし、「経験した中の状態」と「経験の前の接続」の組み合わせは、自然には起きない状態かもしれません
- **入れ替えの 2 × 2**：この二つを組み合わせ、「中の状態」と「接続の強さ」を入れ替えた 4 通りを作ります。接続の強さの違いの効き目を、二通りの状態のもとで測れます
- 「違う経験をしたせい」の分も、学習なしの二つの AI を比べて、別に測ります

### 前もって気づいたこと

前回の実験 0036 では、違う二つの操作が、仕組み上同じ結果になることを、事前に書いていませんでした。今回は、そうなる組み合わせを先に探して並べました。例えば、行動する Unit が一度も動かなかった個体では、その Unit に関わる接続は変わらないので、移植しても何も変わりません。

### v0.2 で直したこと

- 「学習なしの AI のコピーに、学習ありの AI の接続の強さを移す」手順で、今の道具では、学習を止めたままの AI には接続の強さを書き込めないと分かりました。そこで、止めるのを解いてから書き込み、すぐにまた止める、という順番を決めました。そのあいだに AI を 1 歩も進めないので、学習は起きません
- 接続の強さが変わらなかった個体は、移しても何も変わりません。そういう個体を、結果を見てから数から外すと、判定の基準が変わってしまいます。そこで、最初に決めた対象に残して「変わらなかった」と数え、その理由（重みの差がない）を別に報告することにしました
- 行動する Unit が経験の中でほとんど動かなかった個体は、「経験で形づくられた接続」を調べる対象にならないので、最初から対象の外にすると決めておきます
