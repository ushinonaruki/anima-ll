## 1. 記号と 1 Pulse の順序

- Unit を i, j、Pulse を t（1 Pulse ＝ 1 秒、Δt ＝ 1）と書く。s_i(t) ∈ {0, 1} は、i が Pulse t に発火したか
- 力学の値：減衰 λ ＝ 0.85、内在的駆動 c_i、閾値 θ_i（どちらも出生時のばらつきを含む、個体の中では一定）、順応の増分 α ＝ 0.01、順応の戻り γ ＝ e^(−1/τ_a)
- 状態：a_i(t) は Pulse t の終わりの activity、h_i(t) は順応（adaptation）、w_ij(t) は接続 i→j の重み（Pulse t の終わりの可塑性の更新のあと）
- 窓 W ＝ [t0 ＋ 1, T]。0020 では t0 ＝ 12000、T ＝ 24000。**W の間、感覚の入力は比べる腕どうしで同じ**（0020 では入力なし）とする

**1 Pulse（t）の順序**（`pulse_runtime.run_pulse`）：

```text
1. この Pulse の伝達に使う重みを固定する：w(t−1)
2. 各 Unit を進める：
     ã_j(t) = λ · a_j(t−1) + u_j(t) + c_j          （判定の直前の activity）
     h̃_j(t) = γ · h_j(t−1)
     s_j(t) = 1  ⇔  ã_j(t) ≥ θ_j + h̃_j(t)
     a_j(t) = (1 − s_j(t)) · ã_j(t)                  （発火したら 0 に戻す）
     h_j(t) = h̃_j(t) + α · s_j(t)
3. 発火した Unit から駆動を作る。重みは 1 で固定した w(t−1)。届くのは次の Pulse：
     u_j(t+1) = Σ_i w_ij(t−1) · s_i(t)
4. Pulse の終わりに、この Pulse の発火 s(t) で可塑性を更新する
```

この発火の式は **不応期 0（`refractory_pulses: 0`）** を前提にする（minimal-v3 と 0012 の設計図の値。`simple_activity_dynamics.py` の不応期の分岐は働かない）。不応期を入れた設計図では、この文書の式は確かめ直す。

**可塑性 v1.1**（`balanced_pair_window`）：Unit ごとの痕跡を X_i(t) ＝ κ · X_i(t−1) ＋ s_i(t)、κ ＝ e^(−1/τ_x) ＝ λ（τ_x ＝ −1/ln λ）と書く。接続 i→j の送り手の痕跡は X_i、受け手の痕跡は X_j（接続ごとに写しを持つが、出生時に 0 から始まり、同じ発火で更新されるので Unit の痕跡と等しい）。a ＝ A／w_max ＝ 0.01（amplitude_ratio）、w_max ＝ α ＝ 0.01、w_min ＝ 0 とすると：

```text
w_ij(t) = σ_ij(t) · w_ij(t−1) + β_ij(t)
σ_ij(t) = 1 − a · [ X_i(t−1) · s_j(t) + X_j(t−1) · s_i(t) ]
β_ij(t) = a · X_i(t−1) · s_j(t) · w_max
```

（強める側 A·x·(w_max − w)／w_max と、弱める側 A·y·w／w_max を展開したもの。上限・下限の切り詰めは命題 P0 で起きないことを示す。）

**介入の時点と境界**：0020 の移植と C1 は、Pulse t0 の可塑性の更新が終わったあとに重みを置き換える（置き換えたあとの重みを ω ＝ w(t0) と書く）。1 の順序に当てはめると：

```text
送り手 i が t0 に発火    → 駆動は t0 に w(t0−1)（置き換えの前・腕どうしで同じ）で作られ、t0+1 に届く → 差なし
送り手 i が t0+1 に発火  → 駆動は t0+1 に w(t0) ＝ ω（置き換えのあと）で作られ、t0+2 に届く   → 差が初めて入る
```

したがって、t0 ＋ 1 の判定には（送り手が t0 ＋ 1 に発火しても）重みの差は入らない。以下の和は **すべて k ≥ t0 ＋ 2 から** 始め、k ≥ t0 ＋ 2 では

```text
δw_ij(k−2) = Φ_ij(k−2) · δω_ij,    Φ_ij(t0) = 1（空の積）
```

と書く（**2 つの腕の列が共通のあいだ**。F4。k ＝ t0 ＋ 1 の項は和に含めない。δw(t0 − 1) ＝ 0 と同じこと）。

**大事な形**：1 本の重みの更新は、**その重みの値と、発火の列だけ** で決まる（ほかの接続の重みを読まない）。

## 2. 可塑性と伝達について証明できる性質

### P0 切り詰めは起きない【命題・条件付き】

1 Pulse に発火は高々 1 回なので、X_i(t) ＝ Σ_k κ^k s_i(t − k) ≤ 1／(1 − κ) ＝ 1／(1 − λ) ≈ 6.67。よって

```text
a · (X_i + X_j) ≤ 2a／(1 − λ) ＝ 2／15 < 1    →    1 − 2a／(1 − λ) ≤ σ_ij(t) ≤ 1,   β_ij(t) ≥ 0
（今の値 a ＝ 0.01、λ ＝ 0.85 では、下限は 1 − 2a／(1 − λ) ＝ 13／15 ≈ 0.866667）
```

w ∈ [0, w_max] なら：下側は σ ≥ 0・β ≥ 0 から w' ≥ 0。上側は、s_j ＝ 0 なら w' ＝ σw ≤ w ≤ w_max、s_j ＝ 1 なら w' ≤ (1 − aX_i)·w ＋ aX_i·w_max ≤ w_max（aX_i ≤ 1 なので凸結合）。

**不変性**：上の評価はどの発火の列でも成り立つので、帰納法により、**初めの重みが [0, w_max] にあれば、どの列のもとでも、以後のすべての重みが [0, w_max] にとどまり、`plasticity.py` の切り詰め（min・max）は一度も働かない**。このとき更新は厳密に affine である。初めの重みが [0, w_max] の外にあると切り詰めが働きうるので、affine とは限らない（F3 の定義域をこの範囲に限るのはそのため）。

条件：a ＝ 0.01、κ ＝ λ ＝ 0.85 という今の値に依る（2a／(1 − λ) < 1 であること）。値を変えたら確かめ直す。

### F1 組の和は保たれる【命題・条件付き】

前提：(i) i→j と j→i の両方が同じ規則・同じ値で可塑的、(ii) 両方の痕跡が同じ時刻に 0 から始まっている（したがって i→j の送り手の痕跡 ＝ j→i の受け手の痕跡 ＝ X_i）、(iii) P0。

S ＝ w_ij ＋ w_ji と置く。σ_ij ＝ σ_ji ＝ 1 − a(X_i s_j ＋ X_j s_i) なので、2 本の更新を足すと

```text
S(t) = σ_ij(t) · S(t−1) + a (X_i s_j + X_j s_i) · w_max = σ_ij(t) · S(t−1) + (1 − σ_ij(t)) · w_max
⇒  S(t) − w_max = σ_ij(t) · ( S(t−1) − w_max )
```

したがって、出生時に S ＝ w_max（w0 ＝ w_max／2 ずつ）なら、S ＝ w_max はずっと保たれる。S ≠ w_max から始めても |S − w_max| は増えない。

移植について（条件付き）：組の 2 本を、同じく S ＝ w_max を満たす別の個体の値で **2 本ともまとめて** 置き換え、痕跡は残すなら、介入した腕でも保たれる。0020 の移植はこの形。

- 【記述】0020 の 100 個体・両腕の 24000 で |w(i→j) ＋ w(j→i) − w_max| の最大は 1.6 × 10⁻¹⁷
- 帰結：移植した 4 本の自由度は 2 つ。δw_BA ＝ −δw_AB、δw_CA ＝ −δw_AC（δ は 2 つの腕の差）

### F2 重みの差が受け手に届く経路【命題】

前提：2 つの腕が t0 で Unit の状態と痕跡を共有し（重みだけが違ってよい）、t − 1 までの発火の列が同じ。このとき 1 の順序から

```text
δu_j(t0+1) = 0
δu_j(t)    = Σ_i δw_ij(t−2) · s_i(t−1)                          （t ≥ t0+2）
δã_j(t)    = Σ_{k = max(r+1, t0+2)}^{t} λ^(t−k) · δu_j(k)       （r：t より前で j が最後に発火した Pulse。なければ t0）
```

（t ＝ t0 ＋ 1 では和が空で δã_j(t0 ＋ 1) ＝ 0。）

証明：t0 では δa ＝ 0（状態を共有）。t0 ＋ 1 に届く駆動は t0 に w(t0 − 1) で作られていて腕どうしで同じなので δu_j(t0 ＋ 1) ＝ 0（§1 の境界。送り手が t0 ＋ 1 に発火しても、その駆動が届くのは t0 ＋ 2）。t ≥ t0 ＋ 2 では、t − 1 の発火が共通なので δu_j(t) は上の式。j が両腕で同時に発火した Pulse では a_j ＝ 0 なので δa_j ＝ 0。それ以外の Pulse では δa_j(k) ＝ λ·δa_j(k−1) ＋ δu_j(k)（c_j は共通で消える）。

読み方：
- (a) i→j の重みの差が j に入るのは、**i が発火した次の Pulse だけ**
- (b) 入った差は、**j が両腕で同時に発火すると、リセットで 0 に消える**
- (c) それ以外は 1 Pulse ごとに λ 倍で減る
- 実効閾値 θ_j ＋ h̃_j は列だけで決まるので、列が同じあいだは両腕で同じ

### F3 同じ発火の列を生む重みの集まりは凸【命題】

t0 の状態のうち、可塑的な接続の重み ω ＝ w(t0) だけを動かし、ほかの状態（activity・順応・痕跡・t0 ＋ 1 に届く駆動）と W の間の感覚の入力は固定する。

**定義域**：ω は許容集合

```text
Ω      = [0, w_max]^n                                    （n：可塑的な接続の数。0012〜0020 の世界では 6）
Ω_pair = { ω ∈ Ω : すべての組で ω_ij + ω_ji = w_max }     （組の和の制約も課すとき。F1 の前提の形）
```

の中だけを動かす。どちらも凸（箱、または箱と affine な等式の共通部分）。0020 の control・介入の ω はどちらも Ω_pair にある。

W 上の 0／1 の列 σ について

```text
C_σ = { ω ∈ Ω : ω から動かすと、W 上の発火の列が σ になる }
```

と置くと、C_σ は **Ω と、有限個の {ℓ(ω) ≥ 0}（閉じた半空間）・{ℓ(ω) < 0}（開いた半空間）の共通部分** で、ℓ は ω の affine な関数である。したがって **C_σ は凸**（凸集合の共通部分）。ただし閉じているとも開いているとも限らない（≥ の面は含み、< の面は含まない）。空のこともある。Ω の代わりに Ω_pair を使っても同じ（C_σ ∩ Ω_pair も凸）。

証明：
1. ω ∈ Ω なら、P0 の不変性により、どの列のもとでも重みは [0, w_max] にとどまり、更新は切り詰めなしの affine
2. 列 σ を決めると、痕跡 X(t) と順応 h(t) は σ だけで決まる。したがって σ_ij(t)・β_ij(t) も σ だけで決まり、1 本ずつの更新から
   ```text
   w(t) = Φ_σ(t) · ω + ψ_σ(t),    Φ_σ(t) は対角で、 Φ_σ,ij(t) = Π_{k = t0+1}^{t} σ_ij(k)（Φ_σ(t0) = 1）
   ```
3. σ のリセットの位置で activity を 0 にしながら計算すると、ã_j(t) は ω の affine な関数になる（u(t0 ＋ 1) は ω によらず固定、t ≥ t0 ＋ 2 の u(t) は w(t−2) の affine、λ は定数）
4. 帰納法：動かした結果が t − 1 まで σ と同じなら、t の実際の状態は σ で計算した状態と一致する。したがって t の判定は ℓ_{j,t}(ω) ＝ ã_j^σ(t; ω) − θ_j − h̃_j^σ(t) の符号で決まる（≥ 0 なら発火。不応期 0 の前提）。W 全体で σ になる ⇔ すべての (j, t) で「s_j(t) ＝ 1 なら ℓ ≥ 0、0 なら ℓ < 0」

**系 F3a（線分）**：2 つの腕の列が W で同じなら、2 つの ω を結ぶ線分上のどの点から動かしても、列は同じ。

**系 F3b（最初の分岐）**：列が違えば、最初に違う Pulse を t1 と置く。t1 − 1 までは両方が同じ列の前半の区画に入り、t1 では、ある ℓ_{j,t1} の符号が 2 つの ω で違う（ℓ は affine なので、線分上でその符号が変わる点はちょうど 1 つ）。

**系 F3c（最初の分岐の差の分解）**：t1 までは列が共通なので、F2 と F3 の証明の 2 から

```text
δã_j(t1) = Σ_{(i→j)} Σ_{k = max(r+1, t0+2)}^{t1} λ^(t1−k) · Φ_ij(k−2) · s_i(k−1) · δω_ij      （Φ_ij(t0) = 1）
```

が厳密に成り立つ。和は k ≥ t0 ＋ 2 に限る（k ＝ t0 ＋ 1 の項は、§1 の境界により腕どうしで同じ駆動なので含めない。送り手が t0 ＋ 1 に発火した場合、その寄与は k ＝ t0 ＋ 2 の項 Φ_ij(t0)·s_i(t0 ＋ 1)·δω_ij ＝ s_i(t0 ＋ 1)·δω_ij として入る）。これは反実仮想ではなく、共通の列の上の恒等式である。したがって **最初の分岐の activity の差を、接続ごとの初めの差の寄与に正確に分けられる**（#83 のレビューで「局所的な再構成だけでは分からない」とされた点への部分的な答え）。限界：
- t1 より後には及ばない
- ある接続の寄与を 0 にした点（δω_ij ＝ 0 にした点）は、一般に線分上にない。その点が t1 − 1 まで同じ列を保つかは、凸性からは出ない。その接続が「必要だったか」を言うには、その点について改めて全部の制約を確かめる計算が要る

### F4 列が共通のあいだ、可塑性は差を縮めるだけ【命題】

列が共通のあいだは Φ が両腕で同じなので、F3 の証明の 2 から 1 本ずつ

```text
δw_ij(t) = Φ_ij(t) · δω_ij,    0 < Φ_ij(t) ≤ 1   （P0）
```

**符号は保たれ、大きさは増えない**。Φ_ij ＝ 1 のまま（凍結）なのは、送り手・受け手の発火が相手の痕跡と組にならない間。σ_ij ＝ σ_ji なので、組の 2 本は同じ割合で縮む（F1 と整合）。

**W（2 本の差）に一つの縮み方はない**：W ＝ w_AB − w_AC について δW(t) ＝ Φ_AB(t)·δω_AB − Φ_AC(t)·δω_AC。2 本の Φ が違うので、**列が同じでも |δW| は増えうる**（δω_AB と δω_AC が同符号のとき）。W に単一の S を仮定しない。
- 【記述】0020 の列が同じ 22 個体では、4 本すべてで例外なく符号が保たれ大きさが増えなかった（F4 そのもの）。|ΔW_T| ＞ |ΔW₀| の 10 個体はすべて Δx₀・Δy₀ が同符号（README §10.3）

## 3. A：沈黙していた Unit が介入で発火し始める条件

### S1 沈黙が破れる最初の Pulse【命題】

前提：control では A が W の間ずっと発火しない。介入した腕は t0 で control と同じ状態で、重みだけが違う（B–C の組の差は 0）。control の列の上で

```text
m_A(t)  = θ_A + h̃_A(t) − ã_A^C(t)    （> 0：control の閾値までの余裕）
δã_A(t) = Σ_{k = t0+2}^{t} λ^(t−k) · [ Φ^C_BA(k−2) · δω_BA · s_B^C(k−1) + Φ^C_CA(k−2) · δω_CA · s_C^C(k−1) ]
t*      = min { t ∈ W : δã_A(t) ≥ m_A(t) }
```

（Φ^C は control の列で計算した F3 の Φ、Φ^C(t0) ＝ 1。t ＝ t0 ＋ 1 では和が空で δã_A ＝ 0 なので、t* ≥ t0 ＋ 2。B や C が t0 ＋ 1 に発火した場合、その差は k ＝ t0 ＋ 2 の項として入る。）

と置く。t* があれば、介入した腕は t0 ＋ 1〜t* − 1 で control と同じ列で、**A の最初の発火は t***。t* がなければ、介入した腕も W の間ずっと control と同じ列（A は沈黙のまま）。

証明：A が両腕で沈黙しているあいだ、A→B・A→C は伝達しない（F2 の a）。B と C は互いからの入力も同じ（B–C の差は 0、列が共通）。したがって B・C の列は両腕で同じで、A の差は上の δã_A（A は発火しないのでリセットなし）。t < t* ではどの Pulse でも不等式が成り立たないので A は発火せず、この議論が t* まで続く。t* で初めて発火する。

区別（ChatGPT の指摘）：「ある Pulse で不等式が成り立つ」だけでは、その Pulse が最初の発火とは言えない。**それより前のどの Pulse でも成り立たないこと** が要る（t* を最小として定義するのはそのため）。t* より後の Pulse では、もう列が共通でないので上の式は使えない。

注：
- 0020 の記録は余裕の最小とその Pulse、60 Pulse ごとの標本だけなので、S1 を 0020 の記録から正確に評価することはできない。評価するには control の再計算（探索 seed の再実行）が要るので、しない
- 符号：δω_BA ≥ 0 かつ δω_CA ≥ 0 なら δã_A ≥ 0。符号が混ざると単調な言い方はできない

### E1 「B から 1 回の入力の増分 ＞ 余裕の最小」【予想】

## 4. B：重みが違っても発火の列が同じ条件

F3a のとおり、**列が同じ ⇔ 2 つの ω が同じ区画にある**。そのとき線分上のすべての点でも列は同じ。

### G1〜G3 ある接続の差が最初の分岐の原因にならない十分条件【命題】

列が共通のあいだ、接続 i→j について：
- **G1 送り手の沈黙**：i が W の間発火しなければ、δw_ij は一度も j に入らない（F2 の a）
- **G2 向きと受け手の沈黙**：control で j が沈黙していて、j に入るすべての差 δω_kj が ≤ 0 なら、共通の列のあいだ δã_j ≤ 0 < m_j。したがって **j は最初に分かれる Unit にならない**（ほかの Unit が先に分かれたあとは、この言い方は使えない）
- **G3 リセットによる消去**：j が両腕で同時に発火した Pulse で、それまでに入った差は 0 に消える（F2 の b）

どれも十分条件で、列が W 全体で同じであることは、F3 の全部の制約が成り立つことと同じ。

### 列が同じであるための必要十分な不等式【命題】

列が共通のあいだ、Unit j・Pulse t ごとに、control の値 e_j(t) ＝ ã_j^C(t) − θ_j − h̃_j(t) と F2 の δã_j(t) を使うと：

```text
j が両腕で t に発火する   ⇔  e_j(t) ≥ 0  かつ  e_j(t) + δã_j(t) ≥ 0     （越え幅が差に負けない）
j が両腕で t に発火しない ⇔  e_j(t) < 0  かつ  e_j(t) + δã_j(t) < 0     （余裕 m_j ＝ −e_j が差に負けない）
```

列が W 全体で同じ ⇔ すべての (j, t) でどちらかが成り立つ（F3 の制約を Unit ごとに書いたもの）。注意：ここに入るのは **その Pulse の δã_j（入った差の減衰した和、F4 で縮んだ重みの差）** で、初めの 1 本の重みの差 δω_ij そのものではない。

δã_j の符号だけで片側が自動的に成り立つ：δã_j(t) ≥ 0 なら発火する側の条件は自動、δã_j(t) ≤ 0 なら発火しない側の条件は自動（1 Pulse の単調性）。

## 5. C：活動が可塑性へ戻る循環

### 5.1 式から決まること【命題】

- **t1 より前は、両腕の間に、発火の列の差による可塑性のフィードバックの差はない**：どちらの腕も自分の活動で可塑性を更新し続けているが、列が共通なので更新の係数（σ・β）も同じ。したがって重みの差は縮むだけ（F4）で、介入した腕 I と control C の重みの差は Φ^C · δω
- **t1 より後の分解**：I の重みは Φ_I · ω_I ＋ ψ_I、C の重みは Φ_C · ω_C ＋ ψ_C（それぞれ自分の列で）。したがって 1 本ずつ
  ```text
  D = w^I(T) − w^C(T) = Φ_C(T) · δω  +  [ (Φ_I(T) − Φ_C(T)) · ω_I + (ψ_I(T) − ψ_C(T)) ]
                      =       P       +                     M_I
  ```
  （0020 の M_I と同じ量。基準を ω_C に取ると M_C になり、M_I − M_C ＝ ΔΦ · δω ＝ J）
- **1 Pulse の中の単調性**：ほかを固定すれば、刺激が大きいほど発火しやすい（判定は刺激について単調）。次の Pulse の刺激は、各 w_ij について単調に増える

### 5.2 時間をまたぐと発火は入力について単調でない【命題（反例）】と、自己増強の見込み【予想 E3】

**反例**（ChatGPT のレビューの例。数値は §1 の式で確かめた）：今の値 λ ＝ 0.85、c ＝ 0.08、θ ＝ 0.5、α ＝ 0.01、1 つの Unit が a(0) ＝ 0.49、h(0) ＝ 0 から始まる。Pulse 1 に届く入力だけが違う 2 つの場合を比べる（Pulse 2 の入力はどちらも 0）。

| | Pulse 1 の入力 | Pulse 1 の ã | Pulse 1 | Pulse 2 の ã | Pulse 2 |
|---|---|---|---|---|---|
| 小さい入力 | 0 | 0.85 × 0.49 ＋ 0.08 ＝ 0.4965 | 0.4965 < 0.5 で発火しない | 0.85 × 0.4965 ＋ 0.08 ＝ 0.502025 ≥ 0.5 | **発火する** |
| 大きい入力 | 0.004 | 0.5005 | 0.5005 ≥ 0.5 で **発火**（a → 0、h → 0.01） | 0.85 × 0 ＋ 0.08 ＝ 0.08 < 0.5 ＋ γ·0.01 | 発火しない |

入力が大きい方が Pulse 1 では発火し、Pulse 2 では発火しない。したがって **1 Pulse の中の単調性（§5.1）は、時間をまたいだ発火の列の単調性を保証しない**。原因はリセットと順応で、さらに発火の時刻がずれると、ほかの接続を通る入力の時刻もずれる。

この反例は、長い窓での M_I の符号を決めるものではない。言えるのは、**W 全体での M_I（＝下の F）の符号は、単調性の議論からは決まらない** ということまで。
- **E3（予想、未検証）**：一次の見積もりでは、介入（w(A→B) を下げ w(B→A) を上げる）は「A のすぐ後に B」を減らし「B のすぐ後に A」を増やすので、窓の規則では A→B をさらに弱める向き、つまり植えた差と同じ向きに書き込む（自己増強）と見込まれる
- 【記述】0020 では agree の 72 個体のうち 61 で M（W）が ΔW₀ と同じ向き、11 で逆、disagree 6。**逆の 11 と disagree の 6 の原因は確かめていない**。「二次の効果が勝った」とは断定しない

### 5.3 C1（yoked）の 3 つの腕

| 腕 | 始まり（t0） | 活動・伝達 | 可塑性の更新（発火の出来事と痕跡） |
|---|---|---|---|
| **C**（control） | ordered の本体 | 自分の重み | 自分の発火 |
| **I**（intervention） | C の複製、4 本だけ移植 | 自分の重み | 自分の発火 |
| **Y**（yoked） | **I と同じ状態**（Unit の状態・重み・痕跡） | 自分の重み | **C の発火**。痕跡も C の発火で更新する（Y の痕跡は C の痕跡とずっと同じ） |

- 痕跡も C の列にそろえる理由：発火の出来事だけ C にして痕跡を Y の発火で更新すると、F3 の証明の 2 の affine の形が崩れ、下の恒等式が成り立たない混ざった腕になる

### 5.4 設計から決まる恒等式と性質【命題】── 新しい知見にはしない

Y の重みは ω_I と C の列だけで決まる。ω_C・ω_I ∈ Ω なので P0 の不変性により切り詰めは働かず、F3 の証明の 2 から 1 本ずつ：

```text
P = Y − C = Φ_C · δω              （受け身の持ち越し）
F = I − Y = M_I                    （自分の発火を可塑性に返したことによる差）
D = I − C = P + F
```

さらに：
- **I と Y は t1 − 1 まで重みが同じで、t1 まで列が同じ**（t1 までは I の発火 ＝ C の発火なので、2 つの可塑性は同じ入力を受ける。t1 の判定に使う重み・刺激も同じ）

- 6 接続をすべて yoke するなら、B–C の組は P ＝ 0

### 5.5 C1 で初めて識別できること

**Y の活動**、つまり「植えた差が受け身に持ち越されるだけで、自分の活動が可塑性に返らなかったら、その後の発火の列はどうなったか」。C1 で初めて分かるのはこれ。

- **t2**：I と Y が最初に違う発火をした Pulse（と Unit）。I と Y は t0 で同じ状態から始まり、違うのは可塑性の入力（自分の発火か C の発火か）だけ。系は決定論なので、**I と Y の列の違いは、その操作が後の離散的な発火に生んだ因果的な違い** として個体ごとに読める（標本の揺らぎはない）

  - P と F が同じ向きか逆向きか
  - D が P と同じ向きか、反転したか
  - P・F・D の大きさ
  - A→B と A→C はまず別々に扱う。W は 2 本の差として記録する（§2 F4 の注）

新しい閾値・正規化は要らない。旧案の G ＝ |Δw_T|／|S_C·Δw₀| は使わない（向きが反転して大きさだけ増えた場合を区別できない。分母が 0 に近いと不安定）。

### 5.7 6 接続すべてを yoke するか、対象の 4 接続だけか

| | 6 接続すべて（第一候補） | 対象の 4 接続だけ |

## 7. 浮動小数点について

命題はすべて実数の計算として証明した。実装は float64 なので、恒等式は丸めの範囲でしか成り立たない（0020 の【記述】：affine の再構成は 10⁻¹² 以内、組の和のずれは 1.6 × 10⁻¹⁷、アンダーフロー 0）。**境界の付近（ℓ が 0 に近い Pulse）では、丸めで判定が変わりうる**。その幅は、重み・痕跡・累積した期間・入力の差・丸めの伝わり方に依存するので、一律の値は主張しない。事前登録で恒等式を操作の確認に使うときの許容の幅は、検証の契約で決める。
