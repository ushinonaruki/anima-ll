| **類似の再出現** | 過去に似た活動（時間の関係）が、再び生じること | 経験に依存するとは限らない。内在の周期・位相の持ち越し（§5）でも起こる |

| **経験したパターンの再出現** | 経験の間の時間の関係（Δ_E N）と同じ関係が、経験に依存して W に再び現れること | 経験依存の活動変化とは別。どう比べれば言えるかは **判断保留**（§3.2） |
| **再活性化** | `docs/internal-representation-principles.md` の定義では「以前と似た活動のパターンが再び生じること」 | このメモでは、類似の再出現・経験依存の活動変化・経験したパターンの再出現の 3 つを分けて扱う。「再活性化した」と一語では主張しない |
| **位相の持ち越し** | 経験の終わりの Unit の状態（最後の発火の時刻・activity・順応）が、W の初めの発火の時刻を決めること | 経験に依存する。孤立した Unit・学習なしの対照の範囲では、学習した接続を通らない経路として働きうる。自然な結合した W 全体で学習の影響がないとは言わない（§5.3・K3） |

## 2. 何を「再び」観測するのか

### 2.1 刺激の列（世界の側）

- **ordered**：試行 k（k ＝ 0〜199）の始まりを s_k ＝ 1 ＋ 60k とし、A を s_k、B を s_k ＋ 2、C を s_k ＋ 30 に入れる
- **shuffled**：ordered の 600 個の刺激の時刻はそのままにし、札だけを時刻のあいだで並べ替える（名前で分けた乱数の流れ）
  - 札ごとの数は 200 のまま
  - 1 試行の中で、ある Unit が 0〜3 回刺激されうる
- 経験の終わりは t0 ＝ 12000。最後の試行の始まりは s_199 ＝ 11941

刺激の列は世界の性質で、脳の活動ではない。**再活性化で比べる相手は刺激の列ではなく、経験の間に実際に生じた発火**（2.2）である。

### 2.2 経験の間に実際に生じる発火（脳の側）

**【命題 2.1】感覚の出来事から発火まで 1 Pulse**

Pulse t の感覚の出来事は、Pulse t の終わりに駆動として積まれ、Pulse t ＋ 1 に重み 1.0 で届く。Unit が発火した場合と同じ運び方である（`pulse_runtime.run_pulse` の 1 と 6）。

**【条件付き 2.2】刺激は必ず発火を起こすか**

受け手 j が t ＋ 1 に発火する条件は λa_j(t) ＋ 1 ＋ c_j ≥ θ_j ＋ h̃_j(t ＋ 1)。a ≥ 0 なので、h̃_j(t ＋ 1) ≤ 1 ＋ c_j − θ_j なら必ず発火する。出生時のばらつきの範囲では、右辺は 0.522 以上。

順応 h がこれを越えるのは、極端に高い発火率が続いたときだけと見込まれる。ただし、これは確かめていない。

**この条件のもとでの帰結**：
- 刺激で起きた発火（**誘発の発火**）は、刺激の時刻の 1 Pulse 後に起きる
- したがって ordered の誘発の発火の時間差は、刺激の列と同じ（A→B は 2、A→C は 30、B→C は 28）

実際の発火には、誘発の発火のほかに次が混ざる。

1. **内在の発火**：§4 の周期で、Unit ごとに違う
2. **接続による発火**：送り手の発火の次の Pulse に、受け手の余裕が重みより小さければ起きる（§4.4）
   - 例：ordered で A が s ＋ 1 に誘発で発火すると、B には s ＋ 2 に w_AB が届く
   - そのとき B の余裕が w_AB 以下なら、B は s ＋ 2 に発火する。そのあと s ＋ 3 に誘発でもう一度発火する
3. **shuffled の不規則なリセット**：誘発の発火の時刻が役ごとに不規則になる

**可塑性は、刺激の列ではなく、この実際の発火 s(t) だけから更新される**（循環のメモ §1）。

### 2.3 比べるもの：役ごとの、向きのある二点の時間の関係

区間 I ＝ [t_a, t_b]（両端を含む Pulse の区間）で、役 i の発火から k Pulse 後に役 j が発火した回数を、次のように書く。

```text
N_ij(k; I) = #{ t : t ∈ I かつ t + k ∈ I、s_i(t) = 1 かつ s_j(t + k) = 1 }
（i, j ∈ {A, B, C}、i = j も含む。k ＝ 0, 1, …, t_b − t_a）
```

- **発火の時刻 t と t ＋ k の両方を I の中に限る**
  - 経験の区間 E ＝ [1, t0] の N に、W の発火は混ざらない
  - W ＝ [t0 ＋ 1, T] の N は、T より後を参照しない
  - 時間差 k の取りうる値は、区間の長さで決まる
- 時間差 k で数えられる t の個数は |I| − k（|I| ＝ t_b − t_a ＋ 1）。この個数で割るなどの正規化は選択を含むので、ここでは決めない（§7）
- この量は、**全時間差の二点の関係** の、閾値を置かない記述である。ただし活動のパターンの完全な記述ではない
  - 三点以上の関係（A→B→C の順序の列など）は、二点の関係の集まりからは一般に復元できない
  - 【未解決】三点以上の関係をどこまで扱うか
- **経験した役ごとの構造**：同じ Birth State の ordered と shuffled の、経験の区間での差

  ```text
  Δ_E N_ij(k) = N_ij^ord(k; E) − N_ij^shuf(k; E)
  ```

  これは関数のまま扱い、1 つの数にまとめない

**【命題 2.3】時間の格子は 2 つの条件で共通**

刺激の時刻の集合は 2 つの条件で同じである。違うのは、どの役がどの時刻に刺激されるかだけ。したがって、時間差 2・28・30・32・58・60 などの構造は、どちらの経験の誘発の発火にも現れる。

**系**：W の中で、役によらずこれらの時間差が現れても、それは経験の**順序**への依存を示さない。

## 3. 経験依存の活動変化と、経験したパターンの再出現

個体の Birth State を b、経験の条件を e ∈ {ord, shuf} とする。W の中の区間 I_W について、N_ij^e(k; I_W) を考える。

- **類似の再出現**：同じ個体・同じ条件の中で、N^e(·; I_W) が N^e(·; E) と共通の特徴を持つこと
  - 1 つの個体・1 つの条件だけからは、なぜそうなったかは言えない
  - 内在の周期・位相の持ち越しでも起こる（§5）
- **経験依存の活動変化**：同じ b で、W の中の差 Δ_W N ＝ N^ord(·; I_W) − N^shuf(·; I_W) が 0 でないこと
  - 言えるのは「経験の条件によって、W の二点の統計が違う」ことまで
- **経験したパターンの再出現**：経験の間の関係（Δ_E N）と同じ関係が、経験に依存して W に再び現れること
  - Δ_W N ≠ 0 だけからは言えない
  - Δ_W N と Δ_E N をどう関係づければ言えるかは **判断保留**（§3.2）
  - 恣意的な類似度・成功の閾値は置かない

**【命題 3.1】依存したことは、運んだ状態を言わない**

W の間は入力がなく、系は決定論的である。したがって W の発火の列は、t0 の全状態で決まる。全状態とは、activity・順応・痕跡・重み・t0 ＋ 1 に届く駆動のこと。

- 同じ Birth State の ordered と shuffled は、t0 でこれらの **すべて** が違いうる
- Δ_W N ≠ 0 は「t0 の状態のどこかの違いが発火を変えた」ことしか言わない
- どの成分が運んだか（重み＝学習した接続か、Unit の状態＝位相・順応か、t0 ＋ 1 に届く駆動か）は、成分を入れ替える腕（§6）がなければ分からない

**【未解決 3.2】Δ_W N と Δ_E N の比べ方**

- 直接一段の伝達の時間差は 1 である（命題 2.1 と同じ運び方）。一方、経験の間の誘発の発火の時間差は 2・30 などである
- しかし受け手の発火は遅れうる（系 4.4b）。複数の Unit を経る経路もある。学習は複数 Pulse の履歴を見る（命題 4.6）
- そのため、ネットワーク全体がどの時間差の関係を作るかは確定していない（§4.6）
- 同じ時間差で比べるか、力学が写す時間差で比べるかを、今は決めない

**【命題 3.3】発火数だけで N は変わる**

i ≠ j とし、区間 I の中の i・j の発火数を n_i・n_j とする。I の中の発火の組 (t, t′)（i が t、j が t′）は、t′ ≥ t なら N_ij(t′ − t; I) に、t′ ＜ t なら N_ji(t − t′; I) に数えられる。同じ時刻の組は両方に数えられる。したがって

```text
Σ_k N_ij(k; I) + Σ_k N_ji(k; I) − N_ij(0; I) = n_i · n_j
```

- 同じ形で Σ_k N_ii(k; I) ＝ n_i(n_i ＋ 1)／2（k ＝ 0 は同じ発火を 1 回数える）。したがって、どれかの Unit の発火数が 2 つの腕で違えば、時間の関係が何も変わっていなくても、N のどこかの成分は必ず違う
- したがって Δ_W N ≠ 0 には、発火数（順応の水準などで変わる。§5.4）の違いが含まれる。時間の関係の変化と混同しない
- 発火数を除く方法（率で割るなど）は選択を含むので、ここでは決めない（§7・§9）

## 4. 今の力学から：単発の入力の効果

記号は循環のメモ §1 と同じ。

- 減衰 λ ＝ 0.85
- 内在の駆動 c_j、閾値 θ_j（出生時のばらつきあり）
- 順応の増分 α ＝ 0.01、順応の戻り γ ＝ e^(−1/τ_a)、τ_a ＝ 300
- 不応期は 0

さらに次の記号を置く。

```text
a*_j = c_j / (1 − λ)      （入力がないときに activity が近づく値）
g_j  = a*_j − θ_j         （それが閾値をどれだけ越えるか）
```

### 4.1 入力のない軌道

**【命題 4.1】入力のない軌道の閉じた形**

Pulse 0 の終わりの状態を (a_0, h_0) とし、Pulse 1〜n に入力がなく、Pulse 1〜n − 1 に発火がないとする。このとき

```text
ã(n) = a* + (a_0 − a*) λ^n
h̃(n) = h_0 γ^n
G(n) := θ + h̃(n) − ã(n) = (a* − a_0) λ^n + h_0 γ^n − g      （発火の判定の余裕。G(n) ≤ 0 で発火）
```

証明：a(n) − a* ＝ λ (a(n−1) − a*)（λa* ＋ c ＝ a* から）、h̃(n) ＝ γ h(n−1)。

**系 4.1a（沈黙）**：g ＜ 0 で a_0 ≤ a* なら、入力がない限り発火しない。G(n) ≥ −g ＞ 0 だからである（g ＝ 0 は境界で、a_0・h_0 による）。

**系 4.1b（いつかは発火する）**：g ＞ 0 なら、入力がなくてもいつかは発火する。G(n) → −g ＜ 0 だからである。

**系 4.1c（余裕は単調に減る）**：発火の直後（a_0 ＝ 0）から入力がなければ、G は n について厳密に減る。

- 出生時のばらつきの範囲では a* ∈ [0.48, 0.587]、θ ∈ [0.45, 0.55] なので、g の符号は個体・Unit ごとに違う
- 沈黙する Unit も、周期的に発火する Unit もありうる

### 4.2 内在の周期

**【条件付き 4.2】周期は順応で決まる**

g ＞ 0 の Unit が入力なしで発火を繰り返すとき、発火の直後の順応を h_post、直前を h_pre ≈ g と置く。周期 T のあいだ activity の項 a* λ^T が g より十分小さければ、次が成り立つ。


### 4.3 単発の入力の残り

**【命題 4.3】入力の残りは、受け手が発火するまで λ 倍ずつ減る**

受け手 j に、ほかの入力に加えて δ ≥ 0 を Pulse m に足す。j が m 以後に最初に発火する Pulse を n_1 とする（足した場合と足さない場合のうち早いほう）。このとき m ≤ n ＜ n_1 で

```text
Δã_j(n) = δ λ^(n − m),   Δh_j = 0
```

証明：発火までは力学が線形で、h は発火だけで変わる。

**系 4.3a（時刻が変わらなければ何も残らない）**：入力が j の次の発火の時刻を変えないなら、その発火で両方とも a ＝ 0 にリセットされ、h も同じになる。したがって、それ以後の j の状態は完全に同じである。

ネットワークの中でも、j の発火が変わらなければ、ほかの Unit への駆動も可塑性（発火だけを見る）も変わらない。**残りの activity は、受け手の発火の時刻を変えたときにだけ、後に何かを残す。**

**系 4.3b（非負の入力は次の発火を遅らせない）**：その 1 周期の中では、ã が下がらず閾値は同じなので、最初に閾値を越える時刻は遅くならない。

### 4.4 発火の時刻への効き方

**【命題 4.4】単発の入力は、届いた Pulse の余裕が δ 以下なら、その Pulse に受け手を発火させる**

受け手 j が、直前の発火のあと入力なしで進んでいるとする。Pulse m に δ が届くとき、j がその Pulse に発火する ⇔ δ ≥ G(m)（G は命題 4.1 の、入力がないときの余裕）。

**系 4.4a（届いた Pulse で発火させる位相の範囲）**：発火の直後から測ると G は厳密に減る（系 4.1c）。したがって δ が届いた Pulse に発火させる m の集合は、入力がないときの次の発火 n_0 の直前で終わる連続した区間 [n_δ, n_0 − 1] になる（n_δ ＝ min{n : G(n) ≤ δ}）。このとき

- 前倒しの最大は n_0 − n_δ
- 前倒しは、届いた Pulse と、もとの発火の時刻の差そのものになる

**系 4.4b（遅れて発火させる場合）**：δ が m に届き、j が m ＋ k（k ≥ 1）に初めて発火する場合を考える。区間 [m ＋ k, n_0) での G の 1 Pulse あたりの減り方の最小を r_min とすると

```text
n_0 − (m + k) < δ λ^k / r_min + 1
```

証明：G(m ＋ k) ≤ δλ^k、G(n_0 − 1) ＞ 0、G は 1 Pulse に r_min 以上減る。

- 遅れて発火させるほど、前倒しは小さい
- ただし r_min が小さい Unit では、遅れても前倒しは 0 にならない

**【条件付き 4.4c】前倒しの大きさは、余裕の閉じ方の遅さで決まる**

G(n) ＝ (a* − a_0)λ^n ＋ h_0 γ^n − g の 2 つの項は、閉じる速さが大きく違う。
- activity の項：約 6 Pulse の時定数（−1／ln λ ≈ 6.15）
- 順応の項：τ_a ＝ 300 Pulse

周期が長い Unit では、発火の前の長い時間、activity はほぼ a* に達していて、余裕は順応の項だけでゆっくり閉じる（1 Pulse あたり約 g／τ_a）。そのとき前倒しの最大は次のようになる。

```text
n_0 − n_δ ≈ τ_a · ln(1 + δ / g)          （順応で決まる範囲）
```

- 表 1 では、周期が約 80 以上の点で、この近似と実際の差は 5 Pulse 以内
- 周期が短い点（activity の上昇で決まる範囲）では、近似は大きすぎ、実際の前倒しは 1〜13 Pulse

**系 4.4d（重みの大きさの物差し）**：w_max ＝ α（0012 の設計図で `w_max: adaptation_increment`）なので、重みは順応の 1 回の増分と同じ物差しにある。したがって重みは、閾値（約 0.5）と比べれば小さいが、**順応で決まる範囲では発火の時刻を数十〜数百 Pulse 動かしうる**。
- 表 1：出生時の重み w_max／2 ＝ 0.005 で、前倒しの最大は 1〜208 Pulse
- 届いた Pulse に発火させる位相は、周期の約 9%〜63%

**撤回**：BLACKBOARD の比較の Q5 に書いた「1 回の入力で早める幅は多くて 1〜2 Pulse 程度」は、上限として成り立たない。成り立つのは、周期が短く、activity の上昇で決まる範囲の Unit だけである。同じ節の「重みは発火の時刻を少しずらすだけ」も、順応で決まる範囲では成り立たない。

### 4.5 長い時間の効き方：リセット・順応・位相・可塑性

単発の入力の効き方は、時間の尺度ごとに分かれる。

| 経路 | 何が残るか | 時間の尺度 | 札 |
|---|---|---|---|
| activity | δ λ^k。受け手の発火で 0 に消える | 約 6 Pulse | 【命題 4.3】 |
| 発火の時刻 | 前倒し（受け手の発火を変えたときだけ） | 1 回 | 【命題 4.4】 |
| 順応 | 同じ時刻で比べた差は、両腕とも発火しない Pulse で γ 倍に減り、片方だけが発火する Pulse で ±α 跳ぶ（符号も変わりうる）。各発火から測ると、早く発火した側の h が高い | 発火のない区間で約 300 Pulse | 【命題 4.5a】 |
| 位相 | 孤立した Unit では、前倒しの一部がずっと残る | 減らない | 【条件付き】下 |
| 重み | 発火の組が変われば重みが変わる。発火の組がなければ変わらない | 減らない（変わるのは発火の組だけ） | 【命題】下 |

**【命題 4.5a】順応の違い：2 つの時間軸**

順応は h(t) ＝ γ h(t−1) ＋ α s(t) で、activity にも入力にも依らない。同じ Unit の 2 つの腕 P・U（例：入力を足した腕と足さない腕）について、比べる時間軸を分ける。

**(i) 同じ時刻で比べる**

比べ始める時刻を t_s とすると、t ＞ t_s で

```text
Δh(t) = h_P(t) − h_U(t) = γ Δh(t−1) + α (s_P(t) − s_U(t))
      = γ^(t − t_s) Δh(t_s) + α Σ_{k = t_s+1}^{t} γ^(t−k) (s_P(k) − s_U(k))
```

- 初めの差の項 γ^(t − t_s) Δh(t_s) が要る
  - 出生時から足し上げる場合は、両腕とも h ＝ 0 から始まるので、この項は 0 になる
  - 比べ始めで Δh(t_s) ＝ 0 の場合（下の例のように、入力の差より前は同じ状態の場合）も 0 になる
- 同じ Birth State の ordered と shuffled を t0 から比べる場合は、一般に Δh(t0) ≠ 0 なので、この項を含める
- 差は、両腕とも発火しない（または両方が発火する）Pulse でだけ γ 倍に減る。片方だけが発火する Pulse で ±α 跳ぶ
- 例：孤立した Unit で、2 つの腕が Pulse m の入力の差より前は同じ状態（Δh ＝ 0）だったとする。P が n に、U が n_0（＞ n）に発火し、その間にほかの発火がないとする
  - n ≤ t ＜ n_0 では Δh(t) ＝ αγ^(t−n) ＞ 0
  - n_0 の更新の後は Δh(n_0) ＝ −α(1 − γ^(n_0 − n)) ＜ 0 で、**符号が反転する**
- 「差が γ 倍ずつ減りながら残る」は、両腕とも発火しない区間でだけ成り立つ

**(ii) 各腕の発火から測った時刻で比べる**

前提：2 つの腕は、共通の最後の発火（そのときの h を h_0 とする時刻 0）から入力の差まで同じ状態で、P の n の発火が最初の違う発火、U の n_0 の発火がそれに対応する発火とする。

- P の n の発火の直後の h は h̃(n) ＋ α で、U の n_0 の発火の直後の h̃(n_0) ＋ α より h_0(γ^n − γ^(n_0)) ＞ 0 だけ高い
- 孤立した Unit で入力がなければ、その発火から次の発火までの間隔は、P のほうが短くならない。どちらも a ＝ 0 から始まり、各発火から測った同じ経過時刻で P の閾値が常に高いので、系 4.3b と同じ理由による

位相の議論（4.5b）は (ii) の時間軸で行う。

**【条件付き 4.5b】孤立した Unit では、位相のずれが残る**

時間は各発火から測る（命題 4.5a の (ii)）。順応で決まる範囲（§4.4c）で、余裕 G_m（≤ δ）の位相で発火させられた場合を考える。前倒しは τ_a ln((g ＋ G_m)／g)、次の周期の延びは τ_a ln((g ＋ α ＋ G_m)／(g ＋ α)) で、その次の発火では h の違いがほぼ消える。したがって

```text
残る位相の前倒し ≈ τ_a · [ ln((g + G_m)/g) − ln((g + α + G_m)/(g + α)) ]  > 0
```

- 表 1：十数周期後のずれの最大と、この近似（G_m ＝ δ）は、周期が長い点でよく合う
- 玩具の数値の格子（13,745 通り）では、単発の正の入力で十数周期後の発火が遅れた例はなかった。これは数値の観察で、一般の証明ではない
- 自律的な周期の位相には、元に戻す力がない。そのため孤立した Unit では、ずれが減らずに残る。これは一般的な性質で、ここでは近似と数値で確かめた範囲に留める

**【命題 4.5c】接続による発火は、その接続を強める**

i が t − 1 に発火し、j が t に発火し、i は t に発火しなかったとする。このとき循環のメモ §1 の更新から

```text
w_ij(t) = w_ij(t−1) + a · X_i(t−1) · (w_max − w_ij(t−1)),   X_i(t−1) ≥ 1
```

となり、w_ij は増える。組の和（循環のメモ F1）により w_ji は同じだけ減る。

**系（成立しうる機構。必ず起きる現象ではない）**：

- w_ij が大きいほど、i の発火が j を届いた Pulse に発火させる位相の範囲は広がる（系 4.4a。G(m) ≤ w_ij の範囲）
- その発火の組が成立すれば、w_ij はさらに強まる（命題 4.5c。w_ij ＜ w_max なら厳密に増える）
- このように、接続に因果的に起こされた発火がその接続を強めるなら、正のフィードバック（循環）になりうる

ただし、次の 2 つは別である。
- 命題 4.5c の形の発火の組が成立したこと
- 受け手の発火が、その接続によって因果的に起こされたこと（自発の発火でも同じ組は生じる）

また、そうした組が W の中で起きない場合もある。したがって、W の可塑性が働けば必ず生じる現象とは言えない。これは Q1〜Q4 の線の現象で、経験したパターンの再出現とは別である（§11）。

**【予想 4.5d】ネットワークでは位相の関係が積み重なる**

3 つの Unit が互いに接続による発火を繰り返すと、残る位相のずれ（4.5b）が積み重なる。その結果、位相の関係が特定の形に落ち着く（同期・固定した順序）ことがありうる。

- 候補の形：送り手の次の Pulse に受け手が発火する鎖（時間差 1）、同じ Pulse の同期
- それ以外の時間差（2 や 30）は、周期がたまたま近いか、位相の持ち越し（§5.3）が残っているあいだに現れやすいと見込む
- どれも証明していない

**この節のまとめ（ChatGPT の注意への答え）**：直接の入力の activity は約 6 Pulse で減る。しかし発火の時刻・位相・重みへの効果は残り、積み重なりうる。したがって「直接の入力の減衰が速い」ことだけからは、長い時間のパターン形成が不可能だとは言えない。

**【命題 4.6】可塑性は複数 Pulse の履歴を見て、1 本の重みに 1 つの値として書き込む**

循環のメモ §1 の更新で、受け手 j が t に発火したとき、送り手 i の痕跡は次のとおり。

```text
X_i(t−1) = Σ_{L ≥ 1} κ^(L−1) s_i(t − L)
```

したがって、i が時間差 L だけ前に発火した組は、κ^(L−1) の重みで w_ij を強める（弱める側も同じ形で、役が入れ替わる）。

- 経験した時間差 2 の組（ordered の誘発の A→B）は κ^1 ≈ 0.85、時間差 30 の組は κ^29 ≈ 0.009 の重みで書き込まれる。可塑性は時間差 1 だけを見ているのではない
- ただし 1 本の重みは、時間差ごとの組を κ^(L−1) で重みづけて足した 1 つの値として変わる（上限・下限に向かう形で）。時間差そのものは、1 本の重みの中に別々には残らない
- これは 1 本の重みについての命題である。ネットワーク全体（複数の重み・Unit の周期・位相）が時間差 2・30 の関係を作れないことは意味しない

**帰結（範囲を限定する）**：

- 直接一段の伝達では、受け手が届いた Pulse に発火する位相の範囲がある（系 4.4a）。したがって、重みに書き込まれた向き（w_ij ＞ w_ji）が、時間差 1 の関係の向きとして現れることがありうる。これは直接一段の伝達の範囲での見込みである【予想】
- 学習した重みが、ネットワーク全体として、経験した時間差 2・30 の関係を W に再び生じさせうるかは【未解決】
- **v0.1 の「同じ時間差での一致は重みからは期待されない」「経験した時間差 2 の形ではない」は撤回する**

## 6. 対照で切り分けられること・切り分けられないこと

t0 の全状態（命題 3.1）を、5 つの成分に分ける：Unit の状態 (a, h)、重み、痕跡、t0 ＋ 1 に届く駆動、W の可塑性の扱い。

- **t0 ＋ 1 に届く駆動** は、t0 に発火した Unit から、重み w(t0 − 1) で作られる（循環のメモ §1）
  - 大きさは高々 2·w_max（送り手 2 つ）だが、§4.4 のとおり受け手を t0 ＋ 1 に発火させうる
  - したがって、(a, h) をそろえても、この駆動が違えば W の初めの発火は分かれうる
- **痕跡** は発火の判定には入らない。W の可塑性が働くときだけ、W の初めの重みの更新を変える

## 7. 恣意的な閾値を置かずに、時間の関係を書く

- 時間の関係は、§2.3 の N_ij(k; I) を **関数のまま** 書く。発火の時刻の両端を I に限る。似ているかどうかを 1 つの数（相関・一致率など）にまとめず、成功の基準も置かない
- N は二点の関係の記述で、三点以上の関係は別に扱う必要がある（§2.3）
- 経験依存の活動変化は、同じ Birth State の腕どうしの **差の関数**（Δ_W N）で書く
  - 運んだ成分の切り分けは、§6 の腕どうしの差の関数で書く
  - 発火数の違い（命題 3.3）が差に含まれることを、差の関数と一緒に書く
- 構造から決まる時間差は閾値ではない。次の 2 つで、どちらも新しい数値ではない
  - 力学：時間差 1（直接一段の伝達の遅れ）
  - 世界：2・28・30・32・58・60 など（刺激の列）
- 残る選択（【未解決】）：
  - 区間 I をどう取るか。W 全体か、構造で決まる区切りか（例：τ_a の何倍か）。区切りを結果を見て選ばない
  - 時間差の範囲。区間の長さで決まる全範囲を報告すれば選ばずに済むが、扱いにくい
  - 時間差 k で数えられる t の個数（|I| − k）や発火数で割るか。割るなら何で割るか
  - 3 つ組以上の関係をどこまで書くか

## 8. 理論上の結論の候補（ChatGPT の #88 のレビューの判断を反映。最終の合意ではない）

- 積み重なる位相（予想 4.5d）

**K3（区別を維持、範囲を限定）**
位相の持ち越し（§5.3）は、学習した接続によらない経験依存の経路になりうる。そう言えるのは、孤立した Unit・学習なしの対照の範囲である。

この最小の世界の原理的な限界と判断するには早い。【予想 4.5d】と、§4.6 のネットワーク全体の経路を理論で詰める前には、限界とは言わない。
