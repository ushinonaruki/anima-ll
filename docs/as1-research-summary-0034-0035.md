### 2.1 S1：閉ループの成立【確認済み（操作の確認）】

- 契約（#147）・道具（#148）の契約テストと、0034・0035 の O2 で、次を確かめた

### 2.2 S2 の②：時刻効果の存在【確認済み（G-6 の算術）】

- 0034：552 の出来事のうち、d_e ≠ 0 は 217（39%）。d_e は −102〜＋16
- 0035：1,232 の出来事のうち、d_e が求まるのは 1,217 で、d_e ≠ 0 は 335（28%）。d_e は −70〜＋49
- 命題 G-6 により、d_e ≠ 0 の出来事では、その背景のもとで e の帰還が次の意図の時刻を変えたことが、算術の事実として言える。統計は要らない
- 二つの実験の割合の違い（39% と 28%）は、個体の集まり（seed）が違うので、比べて検定しない
- d_e ＝ 0 は、e の効果がないことを意味しない（G-6 の帰結）

### 2.3 S2 の②：向きについて事前登録した問い【確認済み】

- **0034 の J_A（早める向きの多数）は不成立**
  - 符号は ＋ 109・− 108・0 335 で、全体ではほぼ半々だった

**合わせた読み方**【整理】
- 帰還は、次の行動の時刻を変えることがある（存在）
- しかし、その向きが個体の多数で一方に偏ることは示されず（0034）、源と受だけの近似で個体ごとに予測できることも示されなかった（0035）

- 「向きは状態に依存する」は、否定もされていないが、示されてもいない。0035 の不成立は「符号は状態に依らない」という意味ではない（0035 §12）

## 5. S3 へ進む前に答えておく問い（案）【整理】

### 5.1 S2 で確かめたいことの全体

| S2 で確かめたいこと | いまの状態 | この文書の扱い |
|---|---|---|
| 自分の行動による感覚の帰還が、後の行動に影響するか（推定対象 A の存在） | 0034・0035 で、出来事ごとの算術として観測した | 済み |
| その効果の向きが、個体の多数で一方に偏るか | 0034 で不成立 | 問い直さない（結果は確定。別の向きの仮説を同じ形で重ねない） |
| 状態から、効果の向きを説明・予測できるか | 0035 の二経路近似では不成立 | Q1 の結果を受けて、必要なら改めて問う |
| その効果が、どの経路を通るか | 未解決 | **Q1** |
| 経験の区間の可塑性が、後の行動に寄与するか（推定対象 C） | 未検証 | **Q2** |

### 5.2 二つの問いと、それを要件にする理由

**Q1 経路**：帰還の効果（d_e、s_e）は、他の Unit を経る伝達を止めると変わるか
- 0035 で最もはっきりした手がかり（§3.1）を、介入で条件付きに問う
- S3 の構成（AS2・AS2b・AS3）は、Unit や行動の経路が AS1 より多い。AS1 で、帰還が直接の経路だけで伝わるのか、ほかの Unit を経て伝わるのかを確かめておくと、S3 での読み方と失敗の原因の切り分けが容易になる

**Q2 可塑性**：経験の区間の可塑性は、後の行動（試しの区間の意図の時刻・間隔）に寄与するか（推定対象 C）
- S3 の「学習」は、経験による可塑的な変化が後の行動に使われることを指す（三段の比較 §1.1）
- AS1 で、可塑性の寄与を、経験の列の分岐を除いた形（PC-3 の再生、PC-4 の移植）で測る方法を確かめておかないと、S3 の結果が出ても、それが可塑性によるのか、経験の列の違いによるのかを分けられない

**要件の形**【整理】
- Q1・Q2 のそれぞれで、**事前登録した検証で答え（成立・不成立・判定不能）を確定させる**ことを、S3 へ進む前の要件にする案である
- **成立は要件にしない**
  - Q1 が不成立なら、「AS1 では、他の Unit の伝達を止めても帰還の効果の向きは変わらなかった（その基準では）」という土台になる
  - Q2 が不成立なら、「AS1 では、経験の可塑性が後の行動の時刻に効くことは、その基準では示されなかった」という土台になり、S3 の構成で何を変えるべきかの材料になる
- 判定不能（例：判定の対象の個体が足りない）のときは、その理由を報告し、パラメータを変えて走らせ直さない。別の事前登録で、理由を書いて行う
- 三段の比較 §5.2 の「S2 の特定の読み出しの結果で、S3 に進むかどうかを決めない」と矛盾しない：成立か不成立かではなく、問いに答えが出ているかで決める

**要件にしないもの**【整理】
- 状態から向きを予測できること（0035 型の予測）。Q1 の結果を受けて、必要なときに改めて問う

### 5.3 Q1・Q2 の設計の注意（次の設計メモで詰める）【候補】

**Q1（他の Unit の経路への介入）**
- **新しい介入の契約が要る**：0034 の FB-1 は「受 → 源 の伝達の遮断」として定義した。他の Unit → 源・受 の伝達の遮断は、同じ介入ではない

  - しかし、対象と操作（どの接続を、どの区間で、F・N のどちらに）を新しい契約として定義し、契約テストで確かめる必要がある（ChatGPT の指摘）

- **解釈の限界**
  - 遮断すると、全体の活動の水準も変わりうる。「遮断で予測が当たるようになった」は「他の Unit が唯一の原因」を意味しない（ChatGPT の指摘）

  - 介入した系についての答えなので、介入しない元の系の機構については、条件付きの主張にとどまる
- seed・世界・構成：新しい seed の範囲で行う。0034・0035 の seed・raw は使わない

**Q2（推定対象 C）**
- 候補は三段の比較 §3.3.4 の PC-1〜PC-4。経験の列の分岐を除く形（PC-3 か PC-4）を少なくとも一つ含める（三段の比較の候補）

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

実験 0034 と 0035 で分かったことと、まだ分かっていないことを、一つにまとめました。そのうえで、次の段階（S3：経験から行動の選び方を学ぶ）に進む前に、答えを出しておくべき問いを 2 つに絞りました。

### 分かったこと

- AI が自分で行動し、その結果を感じる仕組み（閉ループ）は、設計どおりに動いています
- 行動の結果を感じたかどうかで、次に行動するタイミングが変わることがあります。これは、実験で確かめられた事実です
- ただ、その変わり方が「早まる」のか「遅れる」のかを決めている仕組みは、まだ分かっていません
  - 0034：「多くの個体で早まる」とは言えませんでした
  - 0035：簡単な計算の式で予測しようとしましたが、うまく当てられませんでした
- 手がかりとして、3 つ目の Unit が静かな場面ではその式がほぼ当たり、外れた場面のほとんどで 3 つ目の Unit が動いていました。ただし、これは「3 つ目の Unit が原因だ」という証明ではありません

### 次に答えを出しておくこと

1. **帰還の通り道**：3 つ目の Unit からの伝わりを止めると、結果の効果は変わるか
2. **学習の効き目**：経験の中で起きた接続の変化（学習）が、後の行動に効いているか

どちらも、結果が「はい」でも「いいえ」でも、それ自体が次の段階の土台になります。答えが出ないまま次へ進むことはしない、という形にしました。
