### 0.1 結論の先取り

1. **総括の Q1 の字面どおりの比較（2 × 2）は、独立の介入の対比として残し、記述・報告する**【整理】
   - 同じ Σ_t から、結果の刺激の有無と、他の Unit の伝達の遮断の有無を組み合わせる（F・N・F^{blk}・N^{blk}）
   - 対比は「他の Unit を抑えたときの、帰還の効果の変化」：(τ_N − τ_F) − (τ_{N^{blk}} − τ_{F^{blk}})
   - 見込み【予想】：遮断した系の源と受は、二経路近似の系に可塑性を足したものになるので、遮断した系の効果は二経路近似の差に近い
     - これは見込みで、示されてはいない。0035 の 23/23 は、可塑性を止め他の Unit が静かな合成の条件での道具の確かめである。0034 の 2/552 は、別の条件での推定対象 B の記述である。自然な可塑性のもとで、この対比が近似の誤差と同じか小さいかは分かっていない
     - そのため、この見込みで 2 × 2 を格下げしない。因果の対照として記述・報告する
   - 「他の Unit の発火を抑える」（F^{o:=∅}）と「他 → 源・他 → 受 の伝達だけを遮断する」（F^{blk}）は、違う操作である（§3.5）。同一視しない
2. **2 × 2 だけでは分けられないことを、別の対比で問う**【整理】
   - 他の Unit が、e の効果に関わる形には、少なくとも二つが考えられる
     - **(i) 発火の変化を通す**：e が受の発火を変え、それが他の Unit の発火の時刻を変え、その違いが源に届く
     - **(ii) 発火の有無を通す**：他の Unit の発火の時刻は F と N で同じだが、その発火があることが、源と受の状態を変え、受 → 源 の効果の条件を変える
   - 2 × 2 の遮断では、(i) と (ii) をまとめて取り除くので、どちらが効いたかを分けられない
3. **中心の対比の案：他の Unit の発火の時刻を、もう一方の世界のものに固定する**【候補】
   - F の中で、他の Unit の発火の時刻だけを N のものにした系 F^{o:=N} を作る
   - **主の順（事前に固定する案）**：N の発火に固定する
     - d_e^{fix} ＝ τ_N − τ_{F^{o:=N}}：他の Unit の発火の時刻を N のものに固定した、条件付きの対比
     - d_e^{chg} ＝ τ_{F^{o:=N}} − τ_F：他の Unit の発火の時刻を F のものから N のものに置き換えた差
   - 逆の順（F の発火に固定した N^{o:=F}）は、感度の分析にする
   - **これは一般の「経路ごとの効果」ではない**（§4.3）
     - 固定した系でも、他の Unit は源と受を駆動する
     - その駆動の重みは、e に依る可塑性で変わりうる
     - d_e^{fix} は「他の Unit を通るすべての経路を除いた効果」ではなく、「他の Unit の発火の時刻の変化を固定した条件付きの効果」である
4. **判定は、存在の記述（P1）と、符号への影響（P2）を中心にする。P3 は探索の記録にとどめる**【候補】（§6）
5. **見込み**【予想】：他の Unit の発火の時刻が e で変わることは少なく、d_e^{chg} ≠ 0 の出来事は少ない
   - 理由：受 → 他 の 1 回の駆動は、重みが高々 w_max ＝ 0.01 である。閾値（約 0.5）までの距離に比べて小さいので、他の Unit の発火の時刻を動かすことは少ないと見込む
   - 0035 の結果を見た後の見込みである。事前登録の仮説に使うなら、その由来を開示する
6. **限界**（§7）
   - 介入した系についての答えである
   - 固定の順で値が変わる（三段の比較の U5）
   - 発火の時刻の固定は、他の Unit の経路をすべて除くことではない
   - 結果は Σ_t と AS1 の構成に条件づけられる

## 3. 比べる系と、対比の定義

### 3.1 記号

- 源・受・他は、0034・0035 と同じ役（seed ごとの乱数の割り当て）
- 分岐の時点は、本体を Pulse t の処理の後まで進めたところ。状態は Σ_t（0035 §2.4）
- t の後に源が最初に発火するまで、源は発火しない。そのため、t の後の他の Unit の入力は、次の三つだけである
  - Σ_t の駆動（Pulse t に作られ t ＋ 1 に届くもの。Pulse t の源の発火による駆動を含む）。F と N で同じ
  - 受からの駆動
  - 他の Unit 自身の力学（他の Receptor には刺激が来ない）
- 系 X は、t の後の最初の意図の時刻 τ_X か、その系の打ち切りの Pulse c_X で止める。τ_X が見つかれば「既知」、見つからなければ「c_X で打ち切り（τ_X ＞ c_X）」

### 3.2 系の一覧（同じ Σ_t から作る）

| 系 | e | 他の Unit | 打ち切りの Pulse c | 役目 |
|---|---|---|---|---|
| **F** | 届く | そのまま | t ＋ H | 本体（0034・0035 と同じ） |
| **N** | 取り消す | そのまま | t ＋ H | 0034・0035 と同じ |
| **F^{o:=N}** | 届く | 発火の時刻を N のものに固定 | min(N の止まった Pulse, t ＋ H) | 主の固定の対比 |
| **N^{o:=F}** | 取り消す | 発火の時刻を F のものに固定 | min(F の止まった Pulse, t ＋ H) | 逆の順（感度の分析） |
| **F^{blk}・N^{blk}** | 届く・取り消す | 他 → 源・他 → 受 の伝達を遮断（他の Unit は発火し、可塑性も規則どおり） | t ＋ H | 2 × 2 の対照（総括の Q1 の字面どおり） |
| **F^{o:=∅}・N^{o:=∅}**（補助） | 届く・取り消す | 発火させない | t ＋ H | 発火の抑制の変種（§3.5） |

- 参照の系（F^{o:=N} にとっての N、N^{o:=F} にとっての F）を先に走らせ、その他の Unit の発火の列を記録する

### 3.3 対比（出来事ごと）

- **全体の効果**：d_e ＝ τ_N − τ_F（0034・0035 と同じ）
- **発火の時刻を N に固定した条件付きの対比**：d_e^{fix} ＝ τ_N − τ_{F^{o:=N}}
  - F^{o:=N} と N では、他の Unit の発火の時刻が同じである。違うのは、e と、e が受を通して源と受に与える影響である
  - 固定した系でも、他の Unit は、その系の時刻ごとの重みで源と受を駆動する。その重みと更新は、e に依りうる（§4.3）。そのため、d_e^{fix} は「他の Unit を通るすべての経路を除いた効果」ではない
- **発火の時刻を置き換えた差**：d_e^{chg} ＝ τ_{F^{o:=N}} − τ_F
  - F と F^{o:=N} の違いは、他の Unit の発火の時刻だけである（e はどちらにも届く）
- **恒等式**：d_e ＝ d_e^{fix} ＋ d_e^{chg}（三つの τ がすべて既知のとき）
- **すぐ分かる場合**：F と N で、区間の中の他の Unit の発火の時刻が同じなら、F^{o:=N} は F と同じ発火の列を強制するので、F^{o:=N} ＝ F（§4.2 の一致の条件）。このとき d_e^{chg} ＝ 0
- 符号：s_e、s_e^{fix}、s_e^{chg}（§3.4 の規則）

### 3.4 打ち切りと、参照の系が先に止まる場合（レビューの必須 1）

**参照の系は延ばさない案**【候補】
- 参照の系（例：N）は、0034・0035 と同じく、最初の意図か t ＋ H で止める。その後の他の Unit の発火は定義しない
- 固定した系（例：F^{o:=N}）は、参照の系が止まった Pulse で打ち切る（c ＝ min(N の止まった Pulse, t ＋ H)）
  - F^{o:=N} がそれまでに最初の意図を出せば、τ は既知
  - 出さなければ、τ_{F^{o:=N}} ＞ c と分かるだけである
- 延ばさない理由：参照の系を最初の意図の後まで延ばすと、その系の新しい意図、新しい結果の予約、それに続く受と他の Unit の発火が、参照の列に入る。それを含めるか抑えるかを決めると、参照の系が自然な系でなくなるか、e と関係のない新しい出来事が入る
- 延ばす案は、比べる候補として残す【未決】

**符号の規則（止まる Pulse が系ごとに違う場合）**：系 X と Y の差 τ_Y − τ_X の符号を、次で決める（0034 §2.3 の表を広げたもの）
- 両方が既知：sign(τ_Y − τ_X)
- X が既知、Y が c_Y で打ち切り：c_Y ≥ τ_X なら ＋（τ_Y ＞ c_Y ≥ τ_X）。そうでなければ ？
- Y が既知、X が c_X で打ち切り：c_X ≥ τ_Y なら −。そうでなければ ？
- 両方が打ち切り：？
- **値**（d そのもの）は、両方が既知のときだけ求まる
- 打ち切りの Pulse がどちらも t ＋ H なら、0034 §2.3 の表と同じになる

**例**：τ_N が既知で、F^{o:=N} が τ_N までに意図を出さないとき
- s_e^{fix}（＝ τ_N − τ_{F^{o:=N}} の符号）は −（τ_{F^{o:=N}} ＞ τ_N）
- s_e^{chg}（＝ τ_{F^{o:=N}} − τ_F の符号）は、τ_F が既知で τ_F ≤ τ_N なら ＋、そうでなければ ？
- 値 d_e^{fix}・d_e^{chg} は求まらない（恒等式も使わない）

**契約テストに入れる例**：参照の系の方が先に止まる場合、固定した系が参照の止まった Pulse で打ち切られ、上の規則どおりの符号になること

### 3.5 2 × 2 の対照と、発火の抑制の変種（レビューの必須 5）

- **2 × 2 の対比**：d_e^{blk} ＝ τ_{N^{blk}} − τ_{F^{blk}}。他の Unit を抑えたときの帰還の効果の変化は、d_e − d_e^{blk}（と符号の変化）
  - 遮断は、他 → 源・他 → 受 の伝達に渡す重みを 0 にする（0034 の FB-1 と同じ仕組みで、対象が違う。新しい契約が要る）。他の Unit は発火し続け、その発火による可塑性の更新も規則どおり
  - 他の Unit を抑えたときの帰還の効果の変化を問う、独立の介入の対比である。結果は、見込み（§0.1 の 1）によらず記述・報告する
- **発火の抑制の変種**：d_e^{∅} ＝ τ_{N^{o:=∅}} − τ_{F^{o:=∅}}
  - 他の Unit を発火させない。遮断と違い、他の Unit にかかわる接続の可塑性の更新も、発火がないものとして行われる
  - 遮断と同一視しない。主の 2 × 2 には遮断を使い、抑制は補助の変種にする案【候補】
- 新しい seed の二経路近似の予測 ŝ と、s_e^{blk}・s_e^{∅} の不一致は、可塑性や近似の差として別に記録する（§6.4）

## 4. 介入の定義（他の Unit の発火の時刻の固定）【候補】

### 4.1 操作

- 対象は他の Unit 一つだけ。区間は、Pulse t の処理の後から、その系が止まるまで
- 固定した系の他の Unit は、指定した時刻の列のとおりに発火し、それ以外の Pulse では発火しない
- **発火の決まり方だけを置き換える**：他の Unit の内部の状態は、自然な力学のまま計算し、発火するかどうかだけを列で決める
  - 列が「発火」なら、自然な発火と同じ更新をする（活動を 0 に戻す、不応、順応の増分、発火の数）
  - 列が「発火しない」なら、閾値を越えていても発火の更新をしない
- 出力の駆動：発火した Pulse に、その系のその時点の重み（他 → 源、他 → 受）で作られ、次の Pulse に届く（いまの Pulse の順序のまま：0034 §10 の B1〜B3）
- 可塑性：今の規則は、各接続の送り手と受け手が発火したかどうかだけを使う（`ConnectionStore.apply_activity` の `fired`）。他の Unit にかかわる接続の更新は、指定した発火の列で、規則どおりに行う

### 4.2 自然な系との一致の条件（契約で定める）

- **恒等の条件**：指定した列が、その系自身の自然な発火の列と同じなら、固定した系は自然な系と一致する（発火の列・すべての Unit の状態・重み・痕跡・止まった Pulse・Σ）
  - §4.1 の決まり方なら、これが成り立つ見込みである。契約テストで確かめる
- **他の Unit の内部の状態**：固定した区間では、他の Unit の活動・順応などは、出力にも可塑性にも効かない（出力と痕跡の更新は、発火だけで決まる：§4.1）。ただし、固定した系の Σ には入るので、記録して、自然な系とは区別する
- §3.3 の「すぐ分かる場合」（F と N で他の Unit の発火が同じなら F^{o:=N} ＝ F）は、この恒等の条件から従う

### 4.3 何を固定し、何を固定しないか（レビューの必須 2）

- **固定するもの**：他の Unit の発火の時刻
- **固定しないもの**：
  - 他 → 源・他 → 受 の重み。その系の可塑性で動く。重みの更新は、他の Unit の発火（固定）と、源・受の痕跡（e に依る）で決まる
  - そのため、他の Unit が源と受に届ける駆動の大きさは、系ごとにわずかに違いうる
- **したがって**
  - d_e^{fix} は、「他の Unit の発火の時刻の変化を固定した、条件付きの効果」である。他の Unit を通るすべての経路を除いた効果ではない
  - d_e^{chg} は、「発火の時刻を置き換えた対比」である。一般の経路ごとの効果（媒介の分析の自然な間接の効果など）の同定とは区別する
- **別の介入（感度の分析）**：(b) 届く駆動の値そのものを、もう一方の世界から Pulse ごとに写す
  - 介入の対象が違う（発火の時刻ではなく、源と受に届く駆動）。そのため、(a) と (b) の結果を同じ因果の主張として混ぜない
  - (b) を置くかどうかは、事前登録で決める【未決】

### 4.4 なぜ遮断だけでなく、発火の固定を置くのか

- 遮断（F^{blk}）や抑制（F^{o:=∅}）は、他の Unit の働きをまとめて取り除く。§0.1 の 2 の (i) と (ii) を分けられない
- 他の Unit の発火を**もう一方の世界のものに置き換える**ことで、発火の時刻の変化が帰還の効果に与えた差を取り出せる
- 重みを 0 にする方法は、遮断の定義にならない（命題 G-7）

### 6.3 判定の候補と、その前提

**P1 存在の記述（主の判定にしない案）**
- d_e^{chg} ≠ 0 の出来事（他の Unit の発火の時刻の変化が、時刻を変えた出来事）の有無と数を、個体ごとに記述する

**P2 符号への影響（主の判定の第一の候補）**
- 出来事の事象：s_e^{fix} ≠ s_e（発火の時刻を N に固定すると、帰還の効果の符号が変わる）

  - **母集団の割合と帰無**：例えば π ＝ その母集団で個体の事象が成り立つ割合とし、H₀：π ≤ 1/2。個体の独立・同一分布のモデルの中で、二項の上側の閾値で判定する

### 6.4 P3：分類は排他的でない（レビューの必須 3）

- 「遮断（または抑制）で符号が変わる」（s_e^{blk} ≠ s_e^{fix}）と「発火の時刻の固定で符号が変わる」（s_e^{fix} ≠ s_e）は、同じ出来事で両方が起こりうる。打ち消し合うこともある

- **分類**：三つの符号（s^{blk}、s^{fix}、s）がすべて観測できる出来事を、次の五つに分ける

## 7. 因果の解釈の限界

  - 学習・選択・意図・意味
  - 「他の Unit が向きを決める機構である」（対比は介入のもとの算術で、機構の特定ではない）

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次に調べる「帰還の通り道」の実験の設計を、案としてまとめました。ChatGPT さんのレビューで 5 点の直しを受けて、v0.2 にしました。

### 考えたこと

- 0035 では、3 つ目の Unit が動いた場面で、予測がよく外れました
- 3 つ目の Unit の関わり方には、少なくとも二通りが考えられます
  1. **動くタイミングが変わることで効く**：結果を感じたことで 3 つ目の Unit の動くタイミングがずれ、そのずれが行動を出す Unit に届く
  2. **動くこと自体で効く**：3 つ目の Unit のタイミングは同じでも、動くことで、行動を出す Unit の「効き方の条件」を変える
- 実験は、2 つの比べ方を組み合わせます
  - 3 つ目の Unit の伝わりを止める比べ方（ChatGPT さんの提案。これはそのまま残します）
  - 3 つ目の Unit の動くタイミングを、「結果を感じなかった方の世界」とそろえる比べ方
- この二つを組み合わせると、1 と 2 を、ある程度分けて見られます。ただし、両方が同時に起きたり、打ち消し合ったりすることもあるので、きれいに「どちらが原因」とは言い切らない形にしています

### 見込み

3 つ目の Unit のタイミングが結果で変わることは少ない、と予想しています。ただし、これは 0035 の結果を見た後の予想です。そのことを明記したうえで、新しい個体で確かめます。
