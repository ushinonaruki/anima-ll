1. **総括の Q1 の字面どおりの比較（他の Unit の出力を止めた F と N）は、ほとんど構成から決まる**【整理】
   - 他の Unit から源・受への伝達を止めると、源と受の系は、二経路近似の系に可塑性を足したものになる
   - 0035 の道具の確かめ（可塑性を止め、他の Unit が発火しなかった出来事で 23/23 一致）と、推定対象 B が 0 でない出来事の少なさ（0034 で 2/552）から、止めた系の τ はほぼ二経路近似の τ̂ になると見込まれる【予想】

   - この比較は、参照と道具の確かめとして残す
2. **新しく分かるのは、他の Unit の働きを二つに分けることである**【整理】
   - **(i) 経路として運ぶ**：e が受の発火を変え、それが他の Unit の発火を変え、それが源に届く（e の効果の一部が、他の Unit を通って運ばれる）
   - **(ii) 背景として変える**：他の Unit の発火は F と N で同じだが、その発火が源と受の状態を変え、受 → 源 の直接の効果の大きさ・向きを変える（他の Unit は e の効果を運ばず、効き方の条件を変える）
   - 0035 の外れ（他の Unit が発火した出来事）が、(i) と (ii) のどちらによるのかは、まだ分かっていない
3. **中心の介入の案：他の Unit の発火の時刻を、もう一方の世界のものに固定する**【候補】
   - F の中で、他の Unit の発火の時刻だけを N のものにした系を作る（記号は F^{o:=N}）
   - そうすると、帰還の効果 d_e ＝ τ_N − τ_F は、他の Unit を通らない部分と、他の Unit を通る部分に、出来事ごとに厳密に分かれる（§3.2）
   - 決定論の系なので、これは出来事ごとの算術として定まる（命題 G-6 の拡張）
4. **見込み**【予想】：他の Unit を通る部分は小さく、外れの多くは (ii) の背景による
   - 理由：受 → 他 の 1 回の駆動は、重みが高々 w_max ＝ 0.01 である。閾値（約 0.5）までの距離に比べて小さいので、他の Unit の発火の時刻を 1 Pulse でも動かすことは少ないと見込む
   - これは 0035 の結果を見た後の見込みで、事前登録の仮説として使うなら、その由来を開示する
5. **限界**
   - 経路ごとの効果の分け方は一意でない（どちらの世界の発火に固定するかで変わる。三段の比較の U5）。両方の順で計算して報告する
   - 固定した系は自然には起きない系である
   - 結果は、その背景（Σ_t）と AS1 の構成に条件づけられた効果である

## 3. 比べる系と、推定対象の定義

### 3.1 記号

- 源・受・他は、0034・0035 と同じ役（seed ごとの乱数の割り当て）
- 分岐の時点は、本体を Pulse t の処理の後まで進めたところ。状態は Σ_t（0035 §2.4）
- t の後に源が最初に発火するまで、源は発火しない。そのため、t の後の他の Unit の入力は、次の三つだけである
  - Σ_t の駆動（Pulse t に作られ t ＋ 1 に届くもの。Pulse t の源の発火による駆動を含む）。F と N で同じ
  - 受からの駆動
  - 他の Unit 自身の力学（他の Receptor には刺激が来ない）
- 系 X の、t の後の最初の意図の時刻を τ_X と書く（H で打ち切り）

### 3.2 系の一覧（同じ Σ_t から作る）

| 系 | e | 他の Unit | 役目 |
|---|---|---|---|
| **F** | 届く | そのまま | 本体（0034・0035 と同じ） |
| **N** | 取り消す | そのまま | 0034・0035 と同じ |
| **F^{o:=N}** | 届く | 発火の時刻を N のものに固定 | 他の Unit を通らない効果を取り出す |
| **N^{o:=F}** | 取り消す | 発火の時刻を F のものに固定 | 逆の順の分け方（§3.4） |
| **F^{o:=∅}・N^{o:=∅}** | 届く・取り消す | 発火させない | 参照（総括の Q1 の字面どおりの比較）・道具の確かめ |

- 「発火の時刻を固定する」は、他の Unit の出力（他 → 源、他 → 受 の伝達と、他の Unit の発火にかかわる可塑性の更新）を、指定した時刻の列の発火として扱うこと（§4）
- 他の Unit の発火の列は、F と N を走らせて得る。F^{o:=N} は N の後に、N^{o:=F} は F の後に走らせる

### 3.3 推定対象（出来事ごと）

- **全体の効果**：d_e ＝ τ_N − τ_F（0034・0035 と同じ）
- **他の Unit を通らない効果**：d_e^{dir} ＝ τ_N − τ_{F^{o:=N}}
  - F^{o:=N} と N では、他の Unit の発火が同じなので、違いは e と、e が受を通して源に与える影響だけである
- **他の Unit を通る効果**：d_e^{ind} ＝ τ_{F^{o:=N}} − τ_F
  - F と F^{o:=N} の違いは、他の Unit の発火の時刻だけである
- **分解**：d_e ＝ d_e^{dir} ＋ d_e^{ind}（打ち切りがないとき。算術の恒等式）
- **すぐ分かる場合**
  - F と N で、区間の中の他の Unit の発火の時刻が同じなら、F^{o:=N} ＝ F なので d_e^{ind} ＝ 0
  - これは F と N の記録だけで決まる。F^{o:=N} を走らせなくてよい
  - ただし、可塑性で 他 → 受 の重みが F と N でわずかに違うと、発火の時刻が同じでも駆動の大きさが違いうる。固定の定義（§4）で、この扱いを決める
- 符号も同じ表で作る：s_e、s_e^{dir}、s_e^{ind}（0034 §2.3 の表。打ち切りは分かる符号だけ）

### 3.4 分け方が一意でないこと（U5）

- 他の Unit を「N の発火に固定して F と比べる」分け方（§3.3）と、「F の発火に固定して N と比べる」分け方がある
  - 後者：d_e^{dir′} ＝ τ_{N^{o:=F}} − τ_F、d_e^{ind′} ＝ τ_N − τ_{N^{o:=F}}
- 他の Unit の経路と直接の経路が相互に作用すると、二つの分け方は違う値を出す
- 両方を計算して報告する。主の判定にどちらを使うかは、事前登録で決める【未決】
- どちらも、背景（Σ_t）に条件づけられた、その介入のもとでの効果で、背景をまたぐ一意の寄与の割合ではない

### 3.5 「背景として変える」の量

- 他の Unit を発火させない系での効果：d_e^{∅} ＝ τ_{N^{o:=∅}} − τ_{F^{o:=∅}}
- 背景の効果：d_e^{dir} − d_e^{∅}
  - 他の Unit の発火（F と N で同じ列）があることで、他の Unit を通らない効果がどれだけ変わったか
- §0.1 の 1 の見込みどおりなら、d_e^{∅} はほぼ二経路近似の差 τ̂_N − τ̂_F になる【予想】。それ自体は知見ではなく、道具と近似の整合の確かめにする

## 4. 介入の定義（他の Unit の発火の時刻の固定）【候補】

### 4.1 操作

- 対象は他の Unit 一つだけ。区間は、Pulse t の処理の後から、その系が止まるまで（最初の意図か t ＋ H）
- 固定した系では、他の Unit は、指定した時刻の列のとおりに発火し、それ以外の Pulse では発火しない
  - 他の Unit の出力の駆動：発火した Pulse に、その系のその時点の重み（他 → 源、他 → 受）で作られ、次の Pulse に届く（いまの Pulse の順序のまま：0034 §10 の B1〜B3）
  - 可塑性：他の Unit にかかわる接続の更新は、指定した発火の列で行う（規則は変えない）
- 他の Unit の活動・順応などの内部の状態は、固定した区間では外から見えない量として扱う。比べる Σ からは除くか、区別して記録する【未決】

### 4.2 なぜ伝達の遮断（FB-1）ではなく、発火の固定にするのか

- 0034 の FB-1 は、受 → 源 の伝達に渡す重みを 0 にする介入として定義した。他の Unit の出力の伝達を 0 にする（F^{o:=∅} に近い）こともできる
  - その場合も、FB-1 とは対象が違うので、新しい契約が要る（総括 §5.5、ChatGPT の指摘）
- しかし「止める」だけでは、§0.1 の 2 の (i) と (ii) を分けられない。他の Unit の発火を**もう一方の世界のものに置き換える**ことで、初めて「他の Unit の発火の違いが運んだ効果」を取り出せる
- 重みを 0 にする方法は、遮断の定義にならない（命題 G-7）

### 4.3 固定の定義の選択肢（レビューで決めたい）

| 案 | 他の Unit の出力の駆動の大きさ | 長所 | 短所 |
|---|---|---|---|
| (a) 発火の時刻だけを固定 | 固定した系のその時点の重み × 指定した発火 | 自然な Pulse の順序と可塑性の規則のまま。実装が素直 | 他 → 源・他 → 受 の重みが、系によってわずかに違いうる。そのぶん d_e^{ind} が残りうる |
| (b) 届いた駆動の値そのものを写す | もう一方の世界で実際に届いた値を、Pulse ごとに写す | 源と受が受け取るものが、もう一方の世界と厳密に同じ | 写した駆動と、その系の重み・可塑性が食い違う。実装が複雑 |

- 私の案は (a)。可塑性による重みの差は小さい見込み（0034 の B）で、(a) の自然さを優先する。差が出たときに、それを報告する【候補】

## 5. 可塑性の扱い

- **主**：すべての系で、可塑性は規則どおりに動かす（0034・0035 の本体・N と同じ）
- **補助**：すべての系で、e 以後の可塑性を止めた変種（CF-2 の形）。推定対象 B の分を分けて記述する
- 止めた変種では、F^{o:=∅}・N^{o:=∅} の τ は、二経路近似の τ̂ と一致するはずである（0035 の道具の確かめと同じ条件）。これを**道具の確かめ**（操作の確認）にする
- 経験の区間（t より前）の可塑性には触れない。Σ_t は自然な経験の結果のまま。経験の区間からの介入は Q2（推定対象 C）の問いで、この問いではない

## 7. 因果の解釈の限界

- **介入した系についての答え**である。固定した系（F^{o:=N} など）は、他の Unit の発火がその内部の状態と食い違う、自然には起きない系である。分解の値は、その介入のもとでの経路ごとの効果で、自然な系の「本当の内訳」ではない
- **分け方は一意でない**（§3.4、U5）。相互の作用があれば、順によって値が変わる。両方を報告し、片方だけの値を経路の寄与の割合として読まない
- **「背景」は残りの差である**。d_e^{dir} − d_e^{∅} には、他の Unit の発火が源と受の位相・順応・可塑性を変えた効果が混ざる。どの量を通ったかは、この比較では分けない
- **止めた系（F^{o:=∅}）は、全体の活動の水準も変える**。止めた系で効果が変わっても、「他の Unit が唯一の原因」とは言わない（ChatGPT の指摘）
- **条件づけ**：結果は Σ_t と AS1 の構成（L ＝ 2、3 Unit、外の刺激なし、確定したパラメータ）に条件づけられる。他の構成へは外挿しない
- **言わないこと**
  - 学習・選択・意図・意味
  - 「他の Unit が向きを決める機構である」（分解は介入のもとの算術で、機構の特定ではない）
  - 不成立を「他の Unit は効かない」と読むこと

## 11. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次に調べる「帰還の通り道」の実験の設計を、案としてまとめました。

### 考えたこと

- 0035 では、3 つ目の Unit が動いた場面で、予測がよく外れました
- 3 つ目の Unit の関わり方には、二通りが考えられます
  1. **運び役**：結果の効果を、3 つ目の Unit が受け取って、行動を出す Unit に運ぶ
  2. **場の変化**：3 つ目の Unit は効果を運ばないが、動くことで、行動を出す Unit の「効き方の条件」を変える
- 3 つ目の Unit の伝わりを単に止めるだけだと、この二つを区別できません。止めた後の系は、0035 の予測の式とほとんど同じになるので、新しく分かることも少なくなります
- そこで、3 つ目の Unit の動き（発火のタイミング）を、「結果を感じなかった方の世界」と同じにそろえる実験を考えました。そうすると、効果のうち 3 つ目の Unit が運んだ分と、それ以外の分を、出来事ごとに分けて計算できます

### 見込み

3 つ目の Unit が運ぶ分は小さく、外れの多くは「場の変化」によるもの、と予想しています。ただし、これは 0035 の結果を見た後の予想なので、そのことを明記したうえで、新しい個体で確かめます。
