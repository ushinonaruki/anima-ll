### 0.2 結論の先取り

1. **この世界で、C0 の可塑性が書き込める「経験した構造」は、ほぼ A → B の一つの関係である**【命題】（§2.1）。刺激に誘発された発火の組だけを数えると、O の 200 試行で w(A→B) は出生時の w_max／2 から上限の w_max へ向かって残りの差の約 82% を詰める。B → C の関係は時間差 28 が痕跡の時定数（約 6）より長いので、200 試行で残りの差の約 3.7% しか動かない。A と C の関係は、周期 60 の繰り返しの中で「A の 30 後に C」と「C の 30 後に A」が同じ重みで書き込まれるので、向きの偏りが生じない
2. **R2（0023〜0027 の読み出し）の向きの規則は〔現時点で導出できない〕**（§2.2）。簡単にした前提のもとでも、w(A→B) を大きくすると、試しが B を前倒しする場合（正）と、試しが A の自然な発火を遅らせて B の前倒しを奪う場合（負）の両方が増える【命題（前提つき）】。どちらが勝つかは A と B の発火の時刻の関係に依り、重みだけからは決まらない。0023〜0027 で向きを問わない判定にしたことは、この点で妥当だった
3. **〔検証可能な候補〕がある**（§3.3）。入力のない時間の自発の発火で、「A の発火の 1 Pulse 後に B が発火する」組の数から逆向きの組の数を引いた量 Δ_AB は、w(A→B) が大きいほど大きくなると見込める【条件付き】。候補 C-a は「O の Δ_AB は W の参照より大きい（向きを事前に固定）」。候補 C-b は、鏡の経験 M（A の 2 後に C、30 後に B）では w(A→C) が書き込まれるので、**予測の向きが入れ替わる**（O は Δ_AB − Δ_AC が W より大きく、M は小さい）。規則性と時刻の格子を O とそろえたまま、内容だけで予測が変わる対照になる。これは原則 §6 の 4（「A の後に B が来やすい」世界で、A の後に B の側の活動が起きやすくなるか）を、事前に固定した規則で問う形である
4. 〔理論的に不可能〕と言えるのは、前提を明示した次の範囲だけである（§3.1）：重みだけを読む比較で、最終の重みが一致する履歴を区別すること（既存）。この世界の刺激に誘発された組の書き込みで、A と C の順序を重みに書くこと。直接一段の伝達で、経験した時間差 2 をそのまま試しへの応答の遅れとして出すこと。**どれも、C0 で L3 一般が不可能であることの証明ではない**。また、A と C・B と C についての限界は、主に世界の時刻（周期 60、時間差 28・30）と痕跡の時定数の関係から来る。脳の構成ではなく世界の変更で変わりうる
5. **必要性の評価**（§4）：必要なのは C-a と C-b（同じ実験の本体として作れる）、操作の確認、規則と判定の事前固定。C-a が成り立った場合に必要になるのは、学習なしの対照（V1）、同じ統計での塊の入れ替え（C0-1 の作り直し）、待つあいだの可塑性を止める変種（C0-4）。C-a が成り立たなかった場合に必要になるのは、読み出しの感度の確認（標準化した背景）と、沈黙の構造の切り分けである。C2-a・C2-b・C2-c・さらに遅い読み出し・5 本の規則的な参照は、今は判断を変えないので「不要（今は）」とする
6. **C0 を続ける条件と、次の構成を検討できる条件**を §5 に事前に定義した。次の構成へ進む根拠は「未解決がなくなった」ではなく、「主張したい内容について、C0 とこの世界で運べない・現れないことが、命題か、信頼性の検証を伴う事前登録の結果で示され、その不足が世界の変更で足りるのか脳の構成の変更が要るのかを区別できた」ことである
7. **L3 は「意味」ではない**（§1.1）。L3 が成り立っても、それは経験した構造と後の活動の対応を示すまでで、その違いが Anima-ll 自身の処理・行動・目的の中で使われたこと（原則 R6・§6 の 6〜7）は示さない

## 2. C0 の式から言えること

式は再評価 §1.4（循環のメモ §1）のとおり。可塑性は、受け手 j が Pulse t に発火し、送り手 i が発火しなかったとき

```text
w_ij ← w_ij + a · X_i(t−1) · (w_max − w_ij)、 w_ji ← w_ji − a · X_i(t−1) · w_ji      （a ＝ 0.01）
X_i(t−1) ＝ Σ_{L≥1} κ^(L−1) s_i(t − L)
```

で、組の和 w_ij ＋ w_ji ＝ w_max を保つ（循環のメモ F1）。同じ Pulse の発火の組は数えない。

### 2.1 命題 A（刺激に誘発された発火の組による書き込み）【命題】（式と §1.2 の時刻から）

刺激に誘発された発火の組だけを数える（自発の発火による寄与は除く）。O の 1 試行あたりの、組ごとの w の変化は次のとおり（u ＝ 先の Unit から後の Unit への重み）。

| 組 | 1 試行の更新 | 固定点 | 1 試行あたりの近づく速さ | 200 試行で詰める割合 |
|---|---|---|---|---|
| (A, B)：u ＝ w(A→B) | u ← u ＋ aκ(w_max − u) − aκ^57 u | w_max·κ／(κ ＋ κ^57) ≈ w_max | a(κ ＋ κ^57) ≈ 0.0085 | 固定点までの差の約 82%（残り約 18%） |
| (B, C)：u ＝ w(B→C) | u ← u ＋ aκ^27(w_max − u) − aκ^31 u | w_max／(1 ＋ κ^4) ≈ 0.657 w_max | a(κ^27 ＋ κ^31) ≈ 0.00019 | 固定点までの差の約 3.7% |
| (A, C)：u ＝ w(A→C) | u ← u ＋ aκ^29(w_max − u) − aκ^29 u ＝ u ＋ aκ^29(w_max − 2u) | w_max／2 | a·2κ^29 ≈ 0.00018 | 出生時の w_max／2 から動かない |

（試行の中で、組の 2 つの更新は別の Pulse に起きるので、1 試行の更新は 2 つの式の合成で、1 次の近似で上の和になる。表の数は、出生時の重み w_max／2 から、刺激に誘発された組だけで 200 試行進めたときの値）

**帰結**

1. 刺激に誘発された組だけで見ると、O の経験は w(A→B) を w_max／2（0.005）から約 0.0091 まで動かす。B → C は残りの差の約 3.7%（重みにして約 6 × 10⁻⁵）しか動かさない。A と C の組には向きの偏りを書き込まない
2. **A と C の順序は、この世界の繰り返しの中では定義としても対称である**。周期 60 の列では「A の 30 後に C」と「C の 30 後に A」が同じ時間差で交互に来る。順序は A → B → C → A の循環で、A と C のあいだの「先・後」は時間差 2 の A → B のようには決まっていない
3. M では、同じ計算で w(A→C) が上限へ向かい、(A, B) の組には向きの偏りを書き込まない。W では、どの組でも「枠 0 → 枠 1」になる確率は両方の向きで 1／6 ずつで、期待値の上では w_max／2 へ戻す向きに働く
4. 自発の発火による組（経験の間の試行のあいだ、経験の後の待つ時間）も重みを書き換える。その寄与は経験に依りうるが、刺激の構造そのものの書き込みではない。個体ごとの大きさは【未決】（記録の再解析はしない）
5. したがって、**この世界で C0 の重みが運べる「経験した構造」の内容は、ほぼ A → B（M では A → C）の一つの向きのある関係である**。3 要素の順序や時間差 28・30 の関係は、刺激に誘発された組の書き込みとしてはほとんど運ばれない。これは主に、世界の時間差（28・30）と痕跡の時定数（約 6）の関係から来る

### 2.2 命題 B（R2 の向きは、重みだけからは決まらない）【命題（前提つき）】

R2 は、試しの時刻 t0 に Receptor A の出来事を入れた複製（A は t0 ＋ 1 に発火し、駆動 w(A→B) が t0 ＋ 2 に B に届く）と、本体そのもの（空の側）とで、B の窓の中の最初の発火を比べる：ℓ_B ＝ n_B^∅ − n_B^A（レビュー §1.1）。

**前提**（簡単にした場合）
- P1：窓の中の B の最初の発火までに、B に届く駆動は A からのものだけ（C からの駆動・B → A の効果は無視できる）。B は t0・t0 ＋ 1 に発火しない
- P2：窓の中の可塑性による重みの変化は無視できる
- P3：B は順応で決まる範囲にあり（理論のメモ 条件付き 4.4c）、Pulse m に届いた 1 回の駆動 w(A→B) は、m が区間 J ＝ [n_B^0 − M, n_B^0 − 1] にあるときだけ B をその Pulse に発火させ、そうでなければ B の発火の時刻を変えない（系 4.4a。遅れて発火させる系 4.4b の効果は無視する）。n_B^0 は A からの駆動がないときの B の次の発火（t0 ＋ 1 までは両方の側で B の状態は同じなので、両方の側で共通）、M ＝ M(w(A→B)) は w(A→B) について減らない（系 4.4a）
- P4：試しの側では、t0 ＋ 1 の A の発火の後の A の次の発火は、n_B^0 より後にある（試しが A の自然な発火を遅らせ、その駆動が J に入らない）
- τ_A：本体の A の、t0 以後の最初の自然な発火（τ_A ≥ t0 ＋ 1 とする）

**場合分け**
1. t0 ＋ 2 ∈ J：試しの側は n_B^A ＝ t0 ＋ 2。空の側の n_B^∅ は、窓の定義と P1 から t0 ＋ 2 以上。**ℓ_B ≥ 0**
2. t0 ＋ 2 ＜ n_B^0 − M かつ τ_A ＋ 1 ∈ J：試しの側は、t0 ＋ 2 の駆動が効かず、A の自然な発火の駆動も P4 により来ないので n_B^A ＝ n_B^0。空の側は n_B^∅ ＝ τ_A ＋ 1 ＜ n_B^0。**ℓ_B ＝ (τ_A ＋ 1) − n_B^0 ＜ 0**（大きさは最大 M）
3. それ以外：ℓ_B ＝ 0

（証明：P1〜P4 のもとで、B の最初の発火は、J に入る A の駆動のうち最も早いものの Pulse、なければ n_B^0 である。各場合でこれを当てはめる。）

**帰結**
- M（すなわち w(A→B)）を大きくすると、場合 1（正）になる t0 の範囲も、場合 2（負）になりうる t0 の範囲も広がる。300 回の t0 の平均 L_B の向きは、A の自然な発火がどれだけ B の J に入るか（A と B の周期の比、位相の関係、A が B を引き込んでいるか）に依る。**重みの大きさだけからは向きが決まらない**
- この前提は C0 の個体の一部の場合を簡単にしたもので、C0 の個体がどの場合にどれだけ当たるかは【未決】。言えるのは、重みから R2 の向きを導く一般の規則は、この簡単な場合でもすでに成り立たない、ということまでである
- 0014 の p（標準化した背景での直後の応答）では向きが構造上決まっていた（再評価 §2.1）。R2 では空の側が本体そのものなので、本体の A の自然な発火が比較に入り、向きが決まらなくなる。0023〜0027 で向きを問わない判定にしたことは、この点で妥当だった
- 0026 で Unit の状態の塊も単独で効いたこと（C-I）は、この命題と矛盾しない（Unit の状態は n_B^0・τ_A を決める）

### 2.3 予想 C（時間差 1 の組の非対称は、w(A→B) とともに大きくなる）【条件付き】

入力のない時間の本体の発火から、次の量を数える。

```text
N_{A→B} ＝ #{ t : s_A(t) ＝ 1, s_B(t ＋ 1) ＝ 1 }、   Δ_AB ＝ N_{A→B} − N_{B→A}
```

**見込みの根拠**
- A が t に発火すると、駆動 w(A→B) は t ＋ 1 に B に届き、B の余裕が w(A→B) 以下ならその Pulse に B を発火させる（理論のメモ 命題 4.4）。その位相の範囲 M_B は w(A→B) とともに広がる（系 4.4a）
- 組の和により w(B→A) ＝ w_max − w(A→B) なので、逆向きの範囲 M_A は w(A→B) とともに狭まる
- 前提 Q1（A の発火の時刻が B の周期の中で偏らない）・Q2（発火の数が w に大きく依らない）・Q3（順応で決まる範囲）のもとでは、E[N_{A→B}] ≈ N_A · M_B／T_B、E[N_{B→A}] ≈ N_B · M_A／T_A で、**E[Δ_AB] は w(A→B) について増える**【条件付き】
- A が B を引き込む場合（Q1 が成り立たない場合）も、引き込みが強いほど N_{A→B} は増えると見込む【予想】

**R2 との違い**：R2 は試しが本体の A の自然な発火を動かすので、正と負の経路が混ざる（命題 B）。Δ_AB は本体の自然な発火だけを数えるので、試しによる「前倒しを奪う」経路がない。そのため、向きを事前に固定しうる。

**成り立たない場合**：A か B が入力のない時間に沈黙する個体では、Δ_AB は O と W のどれでも 0 になりうる（凍結。再評価 §3.3）。順応で決まる範囲の外（周期が短い Unit）では M が小さく、効果は小さい（理論のメモ 条件付き 4.4c）。C を経る経路や、位相の関係の積み重なり（理論のメモ 予想 4.5d）が、Δ_AB を別の向きに動かすこともありうる。**これらがあるので、予想 C は定理ではなく、事前に向きを固定して試す候補の根拠である**

## 8. 専門知識がなくても読める解説（t-k さんへ）

### 何をしたか

C0（3 つの部品の小さな脳）で、「経験の違いが後の反応に残る」ことは確かめられました。次に知りたいのは、**その違いが、経験した出来事の中身（A の次に B が来た）と対応しているか**です。この文書では、それを C0 の式からどこまで予測できるかを調べ、次に何を確かめる必要があるかを絞り込みました。

### 分かったこと

- **この世界で C0 の脳が覚えられる中身は、ほぼ「A の次に B」の一つだけ**です。B と C は 28 Pulse 離れていて、部品の「直前の記憶」（痕跡）が約 6 Pulse で薄れるため、ほとんど書き込まれません。A と C は、繰り返しの中で「A の 30 後に C」と「C の 30 後に A」が同じように来るので、そもそも順番が決まっていません。これは脳の作りより、世界の刺激の間隔から来る限界です
- **これまでの読み出し（A で問いかけて B・C の反応を見る）では、「A の次に B」を覚えているほど反応がどちら向きに変わるかを、式から決められない**ことが分かりました。問いかけが B を早める場合と、問いかけが A の自然な動きを乱して B を遅らせる場合の両方があるからです。これまで向きを問わない判定にしていたのは正しかったと言えます
- 代わりに、**問いかけをせず、入力のない時間に「A が動いた直後に B が動く」ことがどれだけ多いか**を数えれば、「A の次に B」を覚えている脳ほど多くなると、向きまで事前に予測できそうです。さらに、順番を入れ替えた経験（A の次に C）では予測が逆になるはずなので、それを対照にすれば、「中身に対応しているか」を確かめられます

### 次にすること（案）

- この二つの予測を、結果を見る前に決めて、新しい個体で確かめる実験を提案します。計算の量はこれまでと同じ程度です
- 確かめられたら、何がそれを保っているかを調べます。確かめられなかったら、「書き込まれていないのか」「書き込まれたのに現れないのか」「測り方が感じていないのか」を切り分けます
- C0 をいつ区切るかの条件も先に決めました。「すべて分かったら」ではなく、「次の変更が必要な理由が、証拠でそろったら」です。そのときは、「これを確かめたので、この変更が必要だと考えます。認めますか？」とお聞きします
- なお、この確認がうまくいっても、それは「中身が脳の中にある」ことまでで、その経験が Anima-ll 自身にとって意味を持った（行動や判断に使われた）ことまでは示しません。そこは、行動の出口を持つ先の段階の問いです
