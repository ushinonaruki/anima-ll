### 0.2 結論の先取り

1. 【確認済み】C0 で、順序のある経験 O の後の自然な状態は、同じ試しに対して、二つの参照（試行をまたぐ並べ替え S、試行の中の並べ替え W）の分布で典型的でない応答を示した（0023 h ＝ 6、0025 h ＝ 7）。W に対しては、経験の終わりから 5τ_a 後に始まる区間でも示した（0027 h_late ＝ 10）。経験の終わりの共通の時刻に一方の状態の塊だけを O のものにすると、固定した一つの背景のもとで、どちらの塊でも典型的でない応答が生じた（0026、C-I）。学習を止めた設計 V1 では、同じ判定は成立しなかった（0024 h ＝ 3）
2. これらは、**契約の MF3（順序）の現象 ① の L2 を、自然な状態への試し（O-P）で、事前登録した判定として示した最初の結果群**である（0012〜0022 で O-P に判定を置いたのは 0012 の H1 だけで、fails）。0027 は、研究④ 命題 4 の必要条件（試しの時刻まで経験による状態の違いが残る）を、Unit の状態の最も遅い時定数の 5 倍の遅れで、読み出しの水準で満たした例でもある。ただし必要条件であって、十分条件ではない
3. 【未識別】このレビューの中心の二つの問いは、どちらも決まっていない
   - **(A) どの状態が、遅い時点の非典型性を維持したか**：遅らせることだけでは原理的に分けられない部分がある（§3.2 (b)：重みには減る時定数がない、位相の違いは時間の並進で保たれる、L は不連続）。さらに、自然な差の原因（C-III）は加法性なしには定まらない（担い手の整理 命題 5）。C0 で得られるのは、条件付きの効果（C-I）か、変種についての答えである
   - **(B) それが過去の出来事の内容（A の後に B、その後に C）を表現しているか**：判定は向きを問わない L2 で、対応の規則（L3）を事前に決めていない。向きはそろっていない。W との違いには、順序のほかに規則性と枠の位置が残る。内容の問いは、C0 の世界（刺激 3 種、規則的な並べ方は 6 通り、間隔の違いがない）と足場（Receptor の 1 対 1）と学習の通り道（組ごとの 3 値）に、射程を強く制約される。ただし、これは C0 で L3 が不可能であることの証明ではない
4. 【選択肢】C0 のままで答えが増える問いは、(A) の側では遅い時点での入れ替え・背景を増やした C-I（C2-a）・対称な対照つきの消去（C2-b・C2-c）・待つあいだの可塑性を止める変種、(B) の側では対応の規則を理論から先に導く L3 の問い・順序と規則性を分ける参照・自発の活動（O-N）での現れである。さらに遅い読み出しは、持続の時間の範囲を広げるが、(A)(B) のどちらも識別しない（§4）
5. C0 を続けるか、次の構成へ進むか（あるいは併用か）は、**t-k さんの方針判断**に戻す（§7）。この文書はどれも推さない

### 3.2 (A) どの状態が維持したか

#### (a) 今わかっていること

- 0027 命題 1：経験の終わりの値の**そのままの持ち越し**は、遅い区間の始まり（13500）で、順応で e^{−5} ≈ 0.0067、痕跡・activity では事実上 0（e^{−244} 程度）
- 状態の十分性（識別のメモ 命題 3.1、担い手の整理 命題 1 と同じ形）：遅い区間の L は、13500 の全状態（と、出生時の状態で決まる力学の値）の関数である。O と W の L の違いは、13500 の全状態の違いを通してしか生じない
- 0026：経験の終わりの T では、どちらの塊にも、固定した背景で応答を動かす O 由来の違いがあった（C-I）。13500 での塊については何もわからない

#### (b) 遅らせることだけでは、担い手を分けられない理由

1. 【既存の命題】**重みには減る時定数がない**。可塑性の規則では、発火の組がなければ重みは変わらない（再評価 §3.1 の可塑性規則の行）。待つあいだは自分の発火で更新され続け、差は縮みうる（循環のメモ F4、0015）が、その速さは個体の発火で決まり、設計図の値から決まる時間の尺度ではない
2. 【命題】**時間の並進**：12001 以後の本体は、外からの入力のない決定論的な写像 F で 1 Pulse ずつ進む（ノイズはなく、Δt ＝ 1 で一定、力学は時刻を陽に読まない：`simple_activity_dynamics.py`・`plasticity.py`）。F は activity・順応・痕跡・重み・次の Pulse に届く駆動を含む全状態についての写像である。このとき、本体 X の時刻 t の全状態が本体 Y の時刻 t − s の全状態と等しければ、以後のすべての t′ ≥ t で X(t′) ＝ Y(t′ − s) が成り立つ
   - 証明：X(t′) ＝ F^{t′−t}(X(t)) ＝ F^{t′−t}(Y(t − s)) ＝ Y(t′ − s)
   - 帰結：「同じ軌道の上で何 Pulse 進んでいるか」という種類の違い（位相の違い）は、力学そのものによっては減らない。0027 命題 1 の減り方（経験の終わりの値のそのままの持ち越しが e^{−D/τ_a}）は、この種類の違いには当てはまらない
   - 範囲：O と W の状態がちょうど時間をずらした関係にあることは、一般には起きない（重みも違う）。この命題が言うのは、**5τ_a の遅れが位相の違いを消すことを、C0 の力学は保証しない**ということだけである。13500 にどれだけの位相の違いが残っていたかは【未識別】（記録の再解析はしない）
3. 【既存の命題】L は発火の時刻で決まり、1／300 刻みの値しかとらない、区分的に一定で不連続な量である（担い手の整理 §3.4）。命題 1 の小さな残り（順応で 1% 未満）も、閾値の越え方を変えれば L を変えうる
4. **帰結**：遅れ D をどれだけ長くしても、(1) の重み、(2) の位相、(3) を通した小さな残り、そしてそれらから決まる待つあいだの発火の履歴は、D に応じて消える保証がない。**「十分に遅らせれば重みだけが残る」という論法は、C0 では成り立たない**（上の 1〜3 からの帰結）。遅れの実験は、担い手の候補を時間の側から絞ることはできても、分けることはできない

### 3.3 (B) 過去の出来事の内容を表現しているか

#### (a) 今わかっていること

- 0023・0025・0027 は、参照と違うこと（L2）を、**向きを問わずに**判定した。どんな違いなら経験した順序に対応するか（対応の規則 R）は、事前に決めていない（各 README §0.3）

- W と O のあいだには、順序のほかに、規則性（すべての試行で同じ並べ方を繰り返す）と、各刺激が試行のどの枠に来るか（とくに最後の数試行の位置で、経験の終わりの順応・位相に効く）の違いが残る（0025 §2）。S との比較でも、規則性の違いは残る（0023 §2）

#### (b) 内容の表現を言うには、何が足りないか

1. **L3**（契約 MF3 の ①、識別のメモ §5.3）：対応の規則を、結果の前に固定する必要がある。L2 は L3 を含意しない（識別のメモ 命題 5.2）。今の結果は、量だけの違い（X7）と区別できていない
2. **規則を既に見た結果から作れない**：§1.3 の向きの分布を見て規則を作れば、観測の規則を結果に合わせて選ぶこと（X10）になる。対応の規則は、模型の式（可塑性の規則・伝達・順応）から理論で導き、新しい seed で確かめる必要がある。0023〜0027 の seed と結果は、その検証に使えない。また、規則が導けない、または個体ごとの出生時の状態に依る形（0013 の先導の向き）にしかならない可能性もある【未識別】
3. **読み出しの時間の尺度**：R2 は 300 Pulse の窓の中の最初の発火の時刻を読む。経験した時間差（A の 2 後に B、30 後に C）に特有の応答を読む形ではない。対応の規則を決めるときは、どの時間の尺度の応答を内容と見なすかも、先に決める必要がある
4. **沈黙した Unit**：0027 で外にあった 10 個体のうち 3 個体は、B か C の一方が 20 本体すべてで沈黙し、L はもう一方の Unit の前倒しだけで決まった。これらの個体では、L を「B と C の関係」（順序の内容）として読むことがそもそもできない。沈黙は Birth State と t0 の状態から構造的に起きうる（再評価 §3.3、E5）
5. **順序と規則性を分ける参照の大きさ**：刺激は 3 種なので、試行の中の規則的な並べ方は 3! ＝ 6 通りしかなく、時刻の格子を変えずに作れる「O 以外の規則的な並べ方」の参照は、最大 5 本である。K ＝ 5 では、交換可能性のもとで個体ごとに O が外にある確率は 2／6 ＝ 1／3 以下で、20 個体で水準 0.05 にするには h ≥ 11 が要る（P(Bin(20, 1/3) ≥ 11) ≈ 0.038、h ≥ 10 では ≈ 0.092。この文書での算術）。判定は作れるが弱く、枠の位置の違いは残る。**これは脳の構成（C0）ではなく、世界（刺激の種類の数）の制約である**
6. **学習の通り道は組ごとの 3 値**（識別のメモ U7、再評価 E3）：重みに書かれる順序の情報は、時間差を κ^(L−1) で重みづけた 3 つの値に圧縮される。重みだけで運べる「内容」は、この 3 値で表せるものに限られる（位相・痕跡を含む全状態での区別は否定しない：研究④ MF3 の (d)）
7. **刺激の同一性は配線が与える**：Receptor から Unit への 1 対 1 の配線が「A という出来事」を区別している（再評価 §3.1）。内容の表現を、経験によって形成された表現（原則 §4）として問うには、この足場が問いの射程を限る
8. **間隔**：間隔だけが違う経験は、今の世界にない（契約 MF3）

#### (c) どこまでが C0 の限界か

- 研究④ §5.2 のとおり、**MF の段階で C0 の構造の限界と示したものはない**。上の 4〜8 は、内容の問い（B）を C0 で立てるときの**射程の制約**で、C0 で L3 が不可能であることの証明ではない

### 5.1 再評価（#94）の結論と、0023〜0027 が足したこと

## 9. 専門知識がなくても読める解説（t-k さんへ）

### 何をまとめたか

実験 0023〜0027 の 5 つで、3 つの部品（Unit）だけの小さな脳（C0）について、何が分かり、何がまだ分からないかをまとめました。C0 を続けるか、次の脳の形へ進むかを、t-k さんに決めていただくための材料です。

### 分かったこと

- 「A → B → C の順番で刺激を受け続けた脳」は、その後に A だけで軽く問いかけたときの反応が、「同じ刺激を、順番をばらばらにして受けた脳」たちの中で、目立って違うものになりやすいことが分かりました。偶然では説明しにくい頻度でした（0023・0025）
- その違いは、刺激が終わってから、部品の内部の「疲れ」（順応）がほぼ抜けきるだけの時間（1500 Pulse）がたった後にも現れました（0027）
- 刺激が終わった時点では、「部品どうしのつながりの強さ」と「部品の内部の状態」のどちらを入れ替えても、反応が変わりうることが分かりました（0026）
- これは、記憶と呼べるものが成り立つための**必要条件**（経験による違いが後まで残り、問いかけへの反応に現れる）を、C0 で初めて、結果を見る前に決めた基準で確かめたものです。十分条件ではありません

### まだ分からないこと（いちばん大事な点）

- **何がその違いを保っていたのか**：つながりの強さは放っておいても減りませんし、部品のリズムのずれ（位相）も、時間がたてば消えるとは限りません。ですから「時間がたった後にも残った」ことだけでは、どれが保ったのかを決められません。部品を入れ替える実験では「この部品にも反応を変える力がある」までは言えますが、「自然な脳では、この部品のせいだった」は、C0 の性質上、決めきれません
- **その違いが「A の次に B が来た」という出来事の中身を表しているのか**：今の結果は「違う」ことまでで、違いの向きもそろっていません。中身を表すと言うには、「どんな違いなら順番を覚えていると言えるか」を、結果を見る前に理論から決めて、新しい個体で確かめる必要があります。また、C0 の世界には刺激が 3 種類しかなく、規則的な並べ方は 6 通りしかないことなどが、この問いを立てる幅を狭めています

### t-k さんに決めていただきたいこと

- C0 で「何が保ったか」をもう少し詰める（方向 1）か、C0 で「中身」の問いに挑む（方向 2）か、C0 をここで区切って次の脳の形の検討を始める（方向 3）か、それらを並行する（方向 4）か
- この文書は、どれも推していません。どれを選んでも、C0 は比較の基準として残します
