### 0.2 結論の先取り

1. **成果**【確認済み】：C0 で、順序のある経験の後、外からの入力も試しもない区間の自発の発火に、**経験した時間差 1 の後続関係（A の直後に B、M では C）が、内容に応じて入れ替わる形で現れた**（0028：J_Ca 10・J_O 9・J_M 6・J_OM 3）。これは原則 §6 の 4（「A の後に B が来やすい世界で、A の後に B の側の活動が起きやすくなるか」）を、事前に固定した規則で問うた答えで、相関と必要性の見取り図の「C-a・C-b がどちらも成り立つ」の行に当たる。経験の後の可塑性を止めた変種でも現れ（0030 の F）、自然な O の外れの一部は発火の数の差だけでは作れない大きさだった（0030 の N^cnt の J_Ca・J_O、閾値ちょうど）。主の区間の直前の時刻 τ に重みの塊だけを O・M のものに替えると、W 型の受け手の背景で同じ形の外れが起き（0029 の Wt、0031 の 5 受け手）、組ごと・2 組ごとに替えても一部の判定が成り立った（0032・0033）。Unit の状態の塊だけを替えた形では観測されなかった（0029 の U）
2. **限界**：成り立ったのは、どれも W 型の背景と一つの τ を固定した**条件付きの効果（C-I）**と、自然な比較での L3 までである。自然な差の消去（C-II）は今の統計の枠で積極的に示せず（C-II の整理）、自然な差の原因・寄与の割合（C-III）は入れ替えでは定まらない（担い手の整理 命題 5）。入れ替えの家族では、発火の数・沈黙の切り替えと相対の時刻を分けていない（台帳 002）。各実験で 5〜9 個体が全判定で凍結し、ほとんどが A の沈黙だった（台帳 001）。統計は時間差 1 の組の数の関数なので、3 要素の順序はそもそも見ていない（N-1 の命題 R1-6）。世界は一つ、値の組も一つである
3. **追加の C0 検証が要るのは、次の構成の設計が、今は限定つきの C0 の主張に頼る場合だけ**【整理】（§4）。例：「C0 の重みは数を超える相対の時刻を運ぶ」に頼るなら K9、「自分の背景でも重みが効く」に頼るなら K3、「間隔は C0 では運べない」に頼って時間の担い手を足すなら、まず間隔を変える世界での問い。頼らないなら、追加の C0 実験は要らない
4. **ゲートは内容ごと・変更ごとに読む**【整理】（§5）。N-1 の命題により、**閉じたループ（行動の意図の出口と、行動に応じる世界）は、構成から N-1・N-2 が立つ**。残りは N-3（その変更が不足を補う見込みと、失うもの）と N-4（C0 を比較の基準に残す手順）の文書である。入口については、**入口の直接の写像を学習で変える部品**に限って N-1 が立ち、下流での刺激の区別の形成一般には立たない（まず似た刺激のある世界で、C0 のまま問える）。時間差・間隔の担い手を足す変更は、全状態の N-1 が〔未識別〕なので、まだ根拠がそろっていない
5. **次の人工脳の設計への提案**【候補】（§6）：最初に検討する変更は、**C0 の Unit の力学と可塑性を変えずに、閉じたループ（原則 §6 の 6）を足す形**。Unit・可塑性の局所の更新規則が同じなので、その式だけを前提とする命題は引き継がれる。特定の感覚列・同じ入力の条件・無入力の区間・旧い世界・旧い観測の窓に依存する命題（N-1 の命題 R1-3・R1-9 など）は、その前提が新しい世界でも保たれる場合に限って適用する。閉じたループでは経験の分布そのものが変わるので、0028〜0033 の結果も直接外挿はしない。ループを開いた対照（出口を外した本体・yoke）で旧 C0 の条件を再現できた場合にだけ、C0 の結果を比較の基準にする（E13）。入口の形成はその次に、時間の担い手は間隔を変える世界での問いの後に、活動の領域（内在的駆動）は症状合わせではない独立の原理の問いとして扱う。設計の要求の候補 E13〜E20 を §6.2 に足した。**どれも決定ではなく、構成・世界の変更は t-k さんの承認が要る**

### 2.2 並べて言えること（新しい検定ではなく、判定の並置）【整理】

1. **C0 は、受け身の世界で、経験した 2 要素の時間差 1 の関係を、入力のない後の活動に、内容に応じて現した**（0028）。0023〜0027 の L2（試しへの応答の非典型性）から一段進み、対応の規則を事前に固定した L3 が観測された
2. その外れは、経験の後の可塑性による書き換えがない変種でも現れた（0030 の F）。自然な比較の外れの一部は、数だけの違いでは作れない大きさだった（0030 の N^cnt。O の側だけ、閾値ちょうど）
3. 主の区間の直前の時刻では、**重みの塊は、W 型の背景で、O・M の内容に応じた向きの効果を持った**（0029・0031。5 つの受け手でも）。Unit の状態の塊の効果は、重みをそろえた背景では観測されなかった（0029 の U。「無関係」とは言わない）
4. 組・2 組への分解では、成り立った判定の組み合わせが種類によって違った（0032・0033）。**種類の間の h の違いから、組の主要性・排他性・必要性・最小十分性・寄与の割合は結論しない**（台帳 003。0033 の要因の表は記述）
5. 2 と 3 は別の主張の並置で、一つの「重みが内容を運んだ」という主張に合成しない（0030 §15.6）

### 3.2 発火の数・沈黙と、相対の時刻（台帳 002）【未識別】

- より一般に、R(X) ＝ N_B(X) − N_{A→B}(X) ＋ N_{B→A}(X)（≥ 0）とおくと Δ_AB(X) ＝ N_B(X) − R(X) で、参照の W が飽和している（R(W) ＝ 0：B のすべての発火が A の 1 Pulse 後で、逆向きがない）と、その W に対して J_Ca の側の数の差を超える外れは算術上成り立たない。D の側では、A–C の側の数の超過が要る（台帳 004 の ChatGPT の回答）。B の沈黙はその特別な場合である。この不成立は「数の変化だけで説明できる」という意味で目的に合うが、その指標が引き込み・位相の違いを拾えないという射程の限界でもある

## 10. 専門知識がなくても読める解説（t-k さんへ）

### 何をまとめたか

0028〜0033 の 6 つの実験で分かったことと分からないことを整理し、「次の脳の形へ進むには何がそろえばよいか」「次の脳をどう作るのがよいか」を考えました。

### 分かったこと

- 今の脳（C0）は、「A の直後に B が来る」という経験をすると、その後、何も入力がない時間の自発の動きにも「A の直後に B が動きやすい」という偏りが出ました。鏡の経験（A の直後に C）では、偏りの向きが入れ替わりました（0028）
- 経験の後に学習を止めても、この偏りは出ました（0030）
- つながりの強さだけをほかの個体へ移すと、移した先でも同じ向きの偏りが出ました（0029・0031）。つながりの一部だけを移した場合も、一部の判定で出ました（0032・0033）

### 分からないこと・限界

- 「つながりの強さが記憶の担い手だった」とまでは言えません。言えるのは、「ある条件のもとで、移すと効いた」までです
- 偏りが「発火の回数の違い」だけで説明できるかは、まだ一部しか分けていません
- 毎回 5〜9 個体で、生まれつきほとんど動かない部品のために反応が出ませんでした
- これまでの数え方では、3 つ以上の並びや間隔は見ていません

### 次の脳について（提案）

- 対になる文書で、C0 では作りそのものから「覚えたことを行動に使う」ことができないと示しました。そこで、**最初の変更の候補は、脳の中身は C0 のままにして、外へ働きかける出口と、その行動で次の刺激が変わる世界を足す形**です。中身を変えないので、部品の更新の決まりについての理屈は引き継げ、出口を外せば C0 に戻ります。ただし、世界や入力の条件に依る理屈（たとえば「入力のない時間に動かない部品」の話）は、新しい世界でもその条件が保たれるときにだけ使います。ただし、ループを閉じると経験そのものが変わるので、これまでの実験の結果は、出口を外した対照で同じ条件を再現できたときにだけ、比べる土台に使います
- 「刺激の見分け方」については、C0 でもその後ろのつながりで作れるかもしれないので、脳を変える前に、まず世界に似た刺激を入れて今の脳で試すのがよいと考えます（最初の版では言い過ぎていました）。「時間の間隔を扱う部品」は、まず今の脳で間隔を変える経験を試してから、と考えています
- **どれも提案で、決めるのは t-k さんです**。この後、ChatGPT さんのレビューを経て、変更の案ごとに「何が補えて、何を失うか」の文書を書き、t-k さんに確認をお願いする流れになります
