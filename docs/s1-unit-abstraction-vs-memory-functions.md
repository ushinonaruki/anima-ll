### 0.2 判定の語

| **保てる** | その働きを実現する構成の存在が、根拠の札（【証明】【既存研究】）で示されている |

## 2. 候補をまたぐ数学

### 2.1 命題 2.1：「集団」と「ニューロン」というラベルは、数学を変えない【証明】

- C1 の式は、K 個の素子を持つ活動率のネットワークと**同じ形**である。C1 の力学についての命題は、すべて K 素子の活動率のネットワークについての命題である。「1 Unit ＝ 1 集団」という解釈が加えるのは、パラメータへの制約（f は集団の入出力関数、τ は集団の時定数、重みは集団どうしの平均の結合）と、どの生物の知見と照合すべきかだけである
- C2 は、F_i が成分ごとの関数で、W_ij が任意の d × d 行列なら、**Kd 個の素子を持つ一般の活動率のネットワーク（つまり Kd 個の Unit の C1）と同じ**である。C2 が C1 と違うものになるのは、ブロックに制約（低ランク、Unit 間の入次数の制限、Unit ごとに共通の性質など）を課すときか、Unit の内部の力学 F_i を成分ごとでない一般の写像にするときだけである
- C3 は、モジュールのネットワークで、モジュールごとに内部の次元（1、d、M）が違うものである

証明は式の書き換えだけで済む。

**帰結**：候補の違いは「神経集団か、ニューロンか」ではなく、**(i) 状態の形（イベントか連続か）、(ii) Unit の内部の次元、(iii) 結合の構造（ブロック・低ランク・要約を通すか）、(iv) 時間の刻みと時定数、(v) 可塑性の形** にある。以下はこの 5 つで比べる。

### 2.2 命題 2.2：要約の先では、要約に現れない違いは、**現時刻の作用では**区別できない【証明】

モジュール A が、ほかの部分に、要約 s_A ＝ g(x_A)（q 次元）を通してだけ作用するとする。A の状態が x_A と x′_A で、g(x_A) ＝ g(x′_A)、ほかの部分の状態が同じなら、ほかの部分の**次の**状態は同じになる。

**これは現時刻の作用についてだけの命題である**（ChatGPT の指摘）。A の内部の状態が違えば、A の内部の力学によって、後の時刻の要約 g(x_A(t)) が分かれ、ほかの部分の軌道も後から分かれうる。

- 反例：x_A ＝ (u, v)、g(x_A) ＝ u、u(t ＋ 1) ＝ v(t) とする。今の u が同じで v が違えば、次の時刻の要約で区別できる
- 現時刻に見えない情報が**後の時刻にも外へ効かない**には、追加の前提が要る。例：要約についての力学的な閉包（g(x_A(t ＋ 1)) が g(x_A(t)) と入力だけで決まる）、または、粗視化の模型が隠れた状態を**初めから持たない**こと

候補への当てはめ：
- **C1**：Unit の状態そのものが活動率 r で、集団の内部の模様（どのニューロンが活動しているか）を持つ状態が模型にない。→ **表現されない**（命題 2.2 からではなく、模型の前提から）。C1 が妥当なのは、捨てた内部の状態が、後の活動や学習に効かない（要約が閉じる）場合である（§2.2b、§3.2）
- **C2**：d 次元までは表せる。d 次元を超える成分は**表現されない**
- **C3**：要約を通す結合なら、細かいモジュールの内部の模様は、**現時刻には** q 次元を通してだけ外へ効く。内部の状態は残るので、後の時刻の要約の値を通して外へ効きうる（**現時刻に見えない**）。素子どうしを直接結ぶなら、この制約はない

### 2.2b 命題 2.2b：集団の内部に学習で構造ができると、集団の粗い変数だけでは力学が閉じない【証明（反例）】

細かい模型：集団 A・B がそれぞれ 2 個の素子を持つ。A の活動 x ＝ (x_1, x_2)、B の素子 j への入力は Σ_i w_ij x_i、学習はヘッブ則 Δw_ij ＝ η x_i y_j。初めはすべて w_ij ＝ w0。粗い変数は、平均の活動 X̄・Ȳ と平均の重み W̄。

- 学習の前：B への入力の平均は w0·Σ_i x_i ＝ 2w0·X̄ で、X̄ だけで決まる（粗い変数で閉じる）
- 型 x ＝ (1, 0)、y ＝ (1, 0) を 1 回学ぶと、w_11 だけが η 増える
- 学習の後、X̄ ＝ 0.5 が同じ 2 つの入力 x ＝ (1, 0) と x′ ＝ (0, 1) を比べる。B への入力の平均は、x では (2w0 ＋ η)／2、x′ では w0 で、**X̄・W̄ が同じでも違う**。B の入出力が厳密に増加なら、Ȳ の次の値も違う

→ 学習の前に粗い変数で閉じていた力学が、**学習によって集団の内部に構造ができると閉じなくなる**。C1 が捨てるのは、まさに「集団の内部に学習でできた構造」である。粗視化の問題は、情報の量が減ることだけでなく、**捨てた内部の状態が、後の活動と学習にどう効くか**にある（ChatGPT の示唆）。

### 2.3 命題 2.3：線形の読み出しで、任意に対応づけられる対の数【証明】

手がかりの状態 c（n 次元）に線形の写像 R をかけて出力を得るとする。p 個の手がかり c_1, …, c_p に、**任意の**出力 y_1, …, y_p を対応づける R が、出力の選び方によらず存在するのは、c_1, …, c_p が線形独立のときであり、そのとき p ≤ n。

（証明の要点：c_p ＝ Σ γ_μ c_μ と書けるなら R c_p ＝ Σ γ_μ y_μ が強制され、y_p を任意には選べない。）

→ 固定した n 次元の手がかりと任意の**線形**写像の範囲では、**読み出せる状態の次元**（C1 なら K、C2 なら Kd）が、任意に対応づけられる対の数の上限になる。これは一般の記憶容量の上限ではない。非線形の読み出し・アトラクター・時間を使う読み出しでは、この数え方は変わる（§2.6）。

### 2.4 命題 2.4：速い状態が縮小的なら、安定な状態は 1 つで、過去は指数的に消える【証明】

活動率の候補（C1・C2、C3 の活動率の部分）で、重みを固定した時間の尺度で考える。

- 離散時間 r(t ＋ 1) ＝ f(W r(t) ＋ b(t))、または連続時間 τ ṙ ＝ −r ＋ f(W r ＋ b(t))
- f は成分ごとの関数で、リプシッツ定数（傾きの上限）L を持つ。‖W‖∞ ＝ max_i Σ_j |w_ij|

**L·‖W‖∞ ＜ 1 なら**：
1. 入力 b が一定なら、平衡点はちょうど 1 つで、すべての軌道がそこへ指数的に近づく
2. 入力が時間で変わっても、初期の状態が違う 2 つの軌道の差は指数的に縮む（離散時間なら (L‖W‖∞)^t 以下、連続時間なら率 (1 − L‖W‖∞)／τ）。つまり、**速い状態に残る過去の影響は指数的に消える**

（証明：成分ごとに |f(x) − f(y)| ≤ L|x − y| だけを使う。f の単調性・微分可能性は使わない。離散時間では ‖f(Wr ＋ b) − f(Wr′ ＋ b)‖∞ ≤ L‖W‖∞‖r − r′‖∞ なので、写像は縮小写像で、縮小写像の原理から 1、2 が従う。連続時間では、一定の入力のもとで写像 r ↦ f(Wr ＋ b) が縮小写像なので、平衡点 r* ＝ f(Wr* ＋ b) がちょうど 1 つ存在する。2 つの軌道の差 e ＝ r − r′ について、|e_i| ＝ ‖e‖∞ となる成分 i で τ·D⁺|e_i| ≤ −|e_i| ＋ |f((Wr ＋ b)_i) − f((Wr′ ＋ b)_i)| ≤ −‖e‖∞ ＋ L‖W‖∞‖e‖∞（D⁺ は右上の微分）なので、‖e(t)‖∞ ≤ e^(−(1 − L‖W‖∞)t／τ)‖e(0)‖∞。r′ を r* の定数の軌道にとれば 1 が、一般の r′ にとれば 2 が従う。v0.1 は 0 ≤ D ≤ L を使っていたが、f の単調性は要らない。）

**帰結**：
- **重みを固定し、入力が一定のもとで、速い活動の状態として**複数の安定な状態を持つこと（アトラクターによる自己連想の補完、持続する発火による作業記憶）には、**L·max_i Σ_j |w_ij| ≥ 1 が必要**。重みが |w| ≤ w_max、入次数が k なら、**L·k·w_max ≥ 1 が必要**（十分ではない）。重みや遅い変数に記憶を持たせる実現は、この条件の対象外である
- これは**働きそのもの**の必要条件ではなく、**特定の実現**（アトラクター・持続する発火）の必要条件である。S2 の規律のとおり、補完は別の Unit 群への前向きの連想でも作れ（命題 2.3 の写像はその一例）、作業記憶は遅い変数（順応・短期のシナプスの変化）でも作れる [Mongillo2008]。縮小的な領域でも、遅い変数には過去が残りうる
- 縮小的な領域でも、入力の履歴は指数的に薄れながら速い状態に残る（「薄れていく記憶」。安定な状態なしに計算する枠組みとして [Maass2002]【既存研究：理論】）

### 2.5 命題 2.5：現行の式で、ネットワークの入力だけでは発火しない条件【証明】

前提：現行の C0 の式（再評価 §1.4）。区間 (t0, t1] で、Unit j に感覚の入力（Receptor）が届かない。j への可塑的な入力は k_j 本で、重みは 0 ≤ w ≤ w_max。順応 h ≥ 0。

M_j ＝ max(a_j(t0), a*_j ＋ k_j·w_max／(1 − λ))（a*_j ＝ c_j／(1 − λ)）とおく。**θ_j ＞ M_j なら、j は区間の中で一度も発火しない。**

（証明：a_j(t − 1) ≤ M_j とする。届く駆動は u_j(t) ≤ k_j·w_max（発火は 0 か 1、重みは w_max 以下）なので、ã_j(t) ＝ λ a_j(t − 1) ＋ u_j(t) ＋ c_j ≤ λ M_j ＋ k_j w_max ＋ c_j ≤ M_j（M_j ≥ (c_j ＋ k_j w_max)／(1 − λ) による）。閾値は θ_j ＋ h̃_j ≥ θ_j ＞ M_j ≥ ã_j なので発火せず、a_j(t) ＝ ã_j(t) ≤ M_j。帰納法で区間全体に成り立つ。）

**系（P1 のもとで。接続の本数の、非常に弱い構造上の必要条件）**：w_max ＝ α（v1.1、設計原則 P1）。区間の中で、a_j(t0) ＜ θ_j の Unit j が**ネットワークの入力だけで**どこかの Pulse に発火するなら、j への可塑的な入力の本数は

  k_j ≥ (θ_j − a*_j)·(1 − λ)／α

を満たす（命題の対偶）。現行の値では (1 − λ)／α ＝ 15。

- これは**接続の本数**の必要条件で、**同時に発火する入力の数**の下限ではない。上の証明の評価は、異なる時刻に届いた入力が activity に積み重なる場合を含む（ChatGPT の指摘）
- θ_j − a*_j ≤ 0 なら、下限は 0 以下で、何も制約しない
- **現行の設計図**：出生時の θ − a* は [−0.137, 0.070]（再評価 §1.4）。正の余裕の最大 0.070 でも、必要な本数は 1.05 以上、つまり 2 本で、今の設計図（k ＝ 2）はこれを満たす。**この式だけから、大きな入次数が必要とは言えない**。実際に発火するかは、入力の密度・最短の発火間隔・順応など、別の制約で決まる。この命題は、再評価の命題 3.3b（入力のない時間の最短の発火間隔 7 を使う、より強い評価）とは別の、一般の弱い評価である
- 【仮説（条件付き）】もし、まばらな符号（MF1）を「多くの Unit の余裕 θ − a* が大きい」という形で実現し、かつ再構成（MF6）を発火で行うなら、余裕に比例した本数の入力が構造上必要になる。ただし、まばらな符号は競合・抑制などでも生じ、余裕が一様に大きいことを意味しない（ChatGPT の指摘）。どの形でまばらにするかは未決で、v0.1 の「まばらな符号 ⇒ 大きな余裕 ⇒ 大きな入次数」という結論は撤回する
- 生物でも、1 本のシナプスの効果は閾値までの距離に比べて小さく、皮質は弱いが同期した多数の入力で駆動される [Bruno2006]【既存研究：実験（ラット、生体内の記録）】。P1 はこれと矛盾しない
- 補完を閾値の下の activity の変化（発火の時刻をずらす）で行う構成なら、この命題の対象外である（P1 は接続を「発火を強制するもの」でなく「発火の時刻を前後させるもの」と位置づける：台帳 §3.11）

### 2.6 容量についての既存研究（前提ごと。一般の上限ではない）

| 前提 | 結果 | 根拠 |
|---|---|---|
| ヘッブ則（外積）、ランダムで偏りのない密な ±1 の型、全結合の K 素子、K → ∞ の極限 | 想起の誤りが小さいまま型を保てる数の臨界値が 約 0.138K | 【既存研究：理論】[Amit1985] |
| ランダムで偏りのない型を、安定の余裕 0 の固定点にする結合が**存在するか**を問う（学習則を問わない）、K → ∞ の典型的な場合 | その臨界値が 約 2K。安定の余裕（雑音への強さ）を求めると小さくなる。あらゆる型の集合に対する絶対的な最大ではない | 【既存研究：理論】[Gardner1988] |
| まばらな型（活動する素子の割合 a が小さい） | 素子あたりに保てる型の数が大きく増える | 【既存研究：理論】[Tsodyks1988][Gardner1988] |
| 状態の数が有限のシナプスで、ランダムな型を順に学び続ける | 古い記憶は上書きされ、保てる数は log K 程度にしか増えない。学習の確率を K に合わせて下げるか、まばらな符号と抑圧の釣り合いがあれば改善する | 【既存研究：理論】[AmitFusi1994] |
| 速い変数と遅い変数を連ねたシナプス | 保持の期間と容量を大きく伸ばす | 【既存研究：理論】[Fusi2005][Benna2016] |

- どれも、**ランダムで互いに無相関な型**、型の長さ K、符号化、精度・雑音、全結合、特定の学習の方式（または結合の存在だけ）を固定した、**特定の密結合の模型での、典型的・漸近的な値**である。相関のある実際の経験（MF7 ではむしろ相関を使う）には、そのままは当てはまらない
- これらは、その模型での**規模に対する増え方の直観**を与えるだけである。「蓄える型の数は素子の数に比例する」「蓄える情報の量は可塑的な接続の数に比例する」は、**一般の神経回路では自動的には従わない**（接続の制約、低ランク、独立な自由度、精度・雑音、学習の方式で変わる）（ChatGPT の指摘）
- したがって、容量を比べるときは、「集団か、ニューロンか」のラベルではなく、型を作る次元、独立に変えられる自由度、符号のまばらさ、学習則、雑音を、**模型ごとに明示**する必要がある

### 2.7 部類としての表現力：不可能と示していないことは、可能と示したことではない

- 連続時間の再帰型ネットワークは、素子を十分に増やせば、**与えられた**滑らかな力学系の有限時間の軌道を任意の精度で近似できる [Funahashi1993]【既存研究：理論（存在定理）】。これは近似する構成が**存在する**ことを言うだけで、何個要るか、**経験に依存して学習で得られるか**、保持・選択・想起を達成するかは言わない
- イベント型（閾値の素子）についても、抑制を含めれば論理回路を組めることが古典的に知られているが、この文書では文献を照合していない【仮説】
- したがって、この調査で言えるのは次のことまでである（ChatGPT の指摘）
  - C0〜C3 のどれについても、**ある MF を不可能とする一般的な定理は示していない**
  - 同時に、**どの MF も可能であることを示してもいない**。構成の存在、局所的で価値を使わない可塑性（原則 §6）で経験から学べるか、計算の制約の下で足りるかは、**未決の研究の問い**である。これは否定的な結果が出たという意味ではない

比較の中身は、(a) **階層ごとに何が表現されないか、何が現時刻に見えないか**（命題 2.2・2.2b）、(b) **決まった規模で何が構成できるか**、(c) **許される学習則で得られるか**、(d) **計算の要求量**、(e) **生物との対応と識別のしやすさ**、になる。

**C0 は発火の時刻と可塑性をどこまで使えるか**（ChatGPT の問い）：現行の規則で重みに書き込まれるのは、**順序（どちらが先か）** と、**時間差を κ^(L−1) で重みづけた回数の和**である。1 本の重みの中では、間隔と回数が混ざる（識別のメモ 命題 3.3、再評価 §3.1）【証明（既存の命題）】。1 回の Pulse の更新で強まる重みは、Δw ≤ (A／w_max)·X_i·(w_max − w) と X_i ≤ 1／(1 − κ) から、**上限の約 6.7% 以下**である（送り手が直前に 1 回だけ発火した組なら X_i ≤ 1 で 1% 以下）【証明：再評価 §1.4 の式から】。時刻の分解能は 1 Pulse で、遅延の違いは使っていない。遅延の種類を増やす、Δt を細かくする、秒の窓の規則（BTSP に近いもの）を足す、はどれも【仮説】である。

### 3.1a 時定数によるフィルタと、離散化は別のもの【証明（反例）】

線形の τ ṙ ＝ −r ＋ I(t) なら、I(t) ＝ r(t) ＋ τ ṙ(t) なので、理想的に連続で雑音のない観測では、入力の速い変化も r の軌道から復元できる。したがって「τ より短い時刻の構造は消える」は、一次の時定数だけからは数学的に成り立たない（v0.1 の誤り。ChatGPT の指摘）。

速い時刻の構造が**区別できなくなる**のは、次のどれかがあるときである。
1. **明示的な時間平均、または刻み Δt での標本化**：Δt より細かい時刻は模型に**表現されない**。C0 の Pulse はこれ
2. **有限の精度**
3. **雑音**：τ で弱められた速い成分が、雑音に埋もれる
4. **読み出しの帯域**：読み出す側も遅いと、速い成分を取り出せない
5. **飽和・閾値**：入出力が一対一でないと、入力の違いが同じ出力に潰れる
6. **模型に表されない内部の状態**

C0 の Δt による量子化（1 の場合）と、C1 の τ によるフィルタ（2〜5 が加わったときに区別できなくなる）は、別のものとして扱う。

### 3.2 何をひとまとめにするか（訂正 §0.4 の 1 を受けて）

- **集団の活動率への縮約が妥当な条件**：集団の中のニューロンが統計的に同等で、非同期に発火しているとき、集団の活動率の式で良く近似できる【既存研究：理論】[Brunel2000][WilsonCowan1972]。逆に言えば、C1 の Unit は、**集団の内部の模様が、後の活動と学習に効かない**（粗い変数で力学が閉じる）ときに妥当である。学習で集団の内部に構造ができると、この閉包は崩れうる（命題 2.2b）
- **記憶の痕跡は、領域の中のまばらな部分集合として現れる**【既存研究：実験（主にマウス）】[Josselyn2020][Cai2016]。領域全体を 1 つの C1 Unit にすると、痕跡に参加する細胞としない細胞を平均してしまい、痕跡の区別はその Unit の階層では**表現されない**（命題 2.2b）
- **分け方の 3 種類**：
  1. **細胞の種類・層・領域・回路の構造で分ける**：生物学的な根拠のある分け方で、意味の割り当てではない（ChatGPT の補足、方針 §0.1 の 3）
  2. **同じ種類の細胞を、内容によらず多数の小さな Unit に分ける**（ランダムな分割など）：意味は入らない。痕跡は「多数の Unit をまたぐ模様」になり、読める次元は Unit の数で決まる（命題 2.3）【証明（次元）＋仮説（十分か）】
  3. **記憶の内容（どの経験に参加するか）で分ける**：生物ではこれは学習で決まる（割り当て、S2 の Enc4）。設計で固定すると、割り当てを設計者が決めることになる。これは避ける候補

### 3.3 生物の集団活動の次元についての証拠（C2 の d に関わる）

- 運動の制御の課題では、運動野の集団の活動の多くの分散が、少数の成分で説明される（神経多様体）【既存研究：総説（主にサル）】[Gallego2017]
- 一方、マウスの一次視覚野は、自然画像に対して高い次元の応答を示した【既存研究：実験（マウス、大規模記録）】[Stringer2019]
- 記憶の痕跡の模様（海馬など）が、少数の成分にまとめられるかは、この文書の範囲では**不明**。→ C2 の d をいくつにすべきかは、生物の証拠からは決められない

## 4. MF ごとの比較

各 MF について、(a) 働きに最低限要ること（実現の形ではなく）、(b) 候補ごとの判定、(c) 何を失いうるか、を書く。MF の札（強い候補・候補）は S2 §8 のまま。

### MF1 似た経験を区別して保持し、使う【強い候補】

(a) 似た入力を、互いに離れた内部の状態に写し、学習の後も区別できること。理論では、**多くの次元への展開と、まばらにする非線形性**（閾値・競合）が重なりを減らす [Marr1971][Babadi2014]【既存研究：理論】

| 候補 | 判定 | 根拠 |
|---|---|---|
| C0 | 現行の値：**不明**（刺激の同一性は配線が与え、分離を作る場がない：S2 §8.1）。部類：**条件付き**（多くの Unit と、活動の割合を保つ仕組み＝抑制・競合または閾値の調整） | 【既存研究：理論】。現行の可塑的な接続は興奮性だけで、まばらにする競合に通常使われる抑制はない（順応による自己抑制だけ） |

| C2 | **条件付き**：Unit の内部の d 次元でも分離できる。Kd 素子のネットワークと同じ（命題 2.1） | 【証明】。痕跡の模様が少数の成分に入るかは不明（§3.3） |
| C3 | **条件付き**：細かいモジュールで、歯状回のような展開とまばらな符号を置ける | 【既存研究：理論】[Marr1971][Treves1994] |

### MF2 一回の経験から、後で使える情報を保持する【強い候補】

(a) 1 回の出来事で、後で読み出せる大きさの変化が起き、しかも多くの古い記憶を消さないこと。上限のあるシナプスでは、1 回の変化を大きくするほど古い記憶が早く上書きされる【既存研究：理論】[AmitFusi1994]

| 候補 | 判定 | 根拠 |
|---|---|---|
| C0 | 現行の値：1 回の更新で強まる重みは上限の約 6.7% 以下、1 回だけの発火の組なら 1% 以下（§3.1）。後で使える大きさかは**不明**。部類：**条件付き**（規則の振幅、秒の窓の規則など） | 【証明（上限）】 |
| C1 | **条件付き**：外積による 1 回の書き込みは連想記憶の模型で成り立つ | 【既存研究：理論】[Hopfield1982] |

| C3 | **条件付き**：細かいモジュールに 1 回の書き込みの規則を置ける | 【既存研究：理論】[Hopfield1982]。BTSP は生物の一つの実現 [Bittner2017] |

### MF3 順序・時間の間隔を区別して保持し、使う【強い候補】

(a) 非対称な結合（どちらが先か）と、時間の構造を持つ状態（遅延・連鎖・時間とともに動く状態）

| 候補 | 判定 | 根拠 |

| C2 | **条件付き**：C1 と同じ。Unit の内部の状態が時間とともに回る構成で間隔を表す案もある | 【既存研究：理論】＋【仮説】 |

### MF4 素早い学習と長期の保持を、新しい学習と両立させる【前半：強い候補】／何を長く保つかが重要さで変わる【後半：候補】

(a) 前半：上書きを避けながら素早く書き込むこと（§2.6 の上限のあるシナプスの問題）。後半：重要さの信号が、保持を変えること

| 候補 | 判定 | 根拠 |

## 5. 計算の要求量（理論。機材の数字は置かない）

### 5.1 式

| 候補 | 状態の記憶 | 接続の記憶 | 1 回の更新の計算 |
|---|---|---|---|
| C0（イベントで駆動） | O(K) | O(K·k·s_c)（＋疎な結合の添え字） | Unit の更新 O(K) ＋ 届ける O(ρ·K·k) ＋ 可塑性 O(ρ·K·k·s_c)。ρ ＝ 1 回の更新で発火する Unit の割合。現行の規則は、発火した Unit の行と列だけを更新する |
| C1（密な活動率） | O(K) | O(K·k·s_c) | 入力の和 O(K·k) ＋ 可塑性 O(K·k·s_c)（可塑性の更新を間引くことはできる） |
| C2 | O(K·d) | 全行列：O(K·k·d²·s_c)、低ランク：O(K·k·d·r·s_c) | 全行列：O(K·k·d²)、低ランク：O(K·k·d·r) |
| C3 | O(K·d ＋ Σ M) | O(Σ_m M_m·k_f·s_c ＋ モジュール間) | 細かい部分 Σ_m O(ρ·M_m·k_f)（イベント）または O(M_m·k_f)（活動率）＋ 集団の部分 |

1 秒あたりの計算は、上の「1 回の更新」× 1／Δt。

上の数え上げは、**実装の形を固定した条件付きの概算**である（密な行列、発火した Unit の行と列だけの更新、など）。C1・C2 の可塑性の計算は、規則と更新の頻度で大きく変わる。C0 でも、毎回の Unit の状態の更新 O(K) は、活動の割合によらず残る。

### 5.2 読み取れること

1. どの候補でも、計算と記憶は**接続の数 × 接続あたりの状態の数 ×（イベント型なら活動の割合）× 更新の頻度**で決まる【証明（数え上げ）】。ChatGPT の指摘のとおり、Unit の数より接続の数と更新の方式が効く
2. **イベント型では、届ける計算と可塑性の計算が活動の割合 ρ に比例する**。ただし、今の Runtime は毎 Pulse すべての Unit を進めるので、O(K) の部分は減らない。また、これは計算の手数の話で、ニューロモーフィックの機材のような、工学的に実現された省電力とは別である。MF1 もまばらな活動を求めるので、手数の点では同じ向きを向く【証明（数え上げ）＋仮説】
3. **多時間尺度のシナプス**（MF4 の実現の仮説）は s_c を増やし、接続の記憶を s_c 倍にする。同じ記憶量で接続を増やすのと、どちらが MF4・MF8 に効くかは比較の対象になる【証明（数え上げ）＋仮説】
4. **C2 の全行列は d² で増える**。低ランク r にすると安くなるが、その時刻に 1 対の Unit の間で伝わる成分は r 次元に限られる（命題 2.2。時間とともに別の成分がその通り道に現れることはありうる）【証明】
5. **C3 の細かい部分の計算は M·k_f で決まる**。どこを細かくするかの選び方が、そのまま計算の量になる
6. **生物のニューロン 1 個ずつの規模の参考**：2013 年に「京」で、神経細胞 17 億 3,000 万個・シナプス 10 兆 4,000 億個（人間の脳の約 1%）のシミュレーションを行い、生物の 1 秒分に約 40 分かかった [RIKEN2013]【既存研究：実績】。ニューロン 1 個ずつを写す抽象化は、どの候補を選んでも現実的でない。これは「まとめ方が要る」ことの根拠で、どのまとめ方かの根拠ではない

### 5.3 方針の記録

- 計算の予算を理由に、生物学的に必要かもしれない構造（例：細かい層、抑制、遅延の種類）を、この段階で外さない
- 同じ記憶の働きを保てるなら、計算効率のよい構造を優先して検討する
- 規模の数字（何 Unit なら可能か）は、構造の候補を絞ってから見積もる

## 7. まとめ

1. **「集団か、ニューロンか」は、数学の上では違いを生まない**（命題 2.1）。違いを生むのは、状態の形、Unit の内部の次元、結合の構造、時間の刻み、可塑性の形である
2. **C1 の主な代償は、Unit の内部の模様を模型に持たないこと**。学習で集団の内部に構造ができると、集団の粗い変数だけでは力学が閉じなくなる（命題 2.2b）。記憶の痕跡は領域の中のまばらな模様なので、C1 で領域を 1 Unit にすると痕跡は表現されない。C1 で MF1・MF6 を持つには、Unit をまたぐ模様に必要な次元（多くの Unit）が要る。C2・C3 は、d や M の分だけ内部の模様を表せる。C3 で要約を通す結合なら、内部の模様は現時刻には見えないが、後の作用で現れうる（命題 2.2）
3. **多重の安定状態で働きを実現するなら**（アトラクターの補完、持続する発火）、重みを固定した速い活動について結合の強さの条件がある（命題 2.4）。C0 で発火による再構成を行うなら、接続の本数に非常に弱い必要条件がある（命題 2.5）。**現行の値では、この式から大きな入次数が必要とは言えない**。重みや遅い変数で実現する道は、これらの条件の対象外
4. **容量の値は模型の前提に強く依る**（§2.6）。0.14N や 2K は特定の模型の典型・漸近の値で、上限ではない。「情報量は接続の数に比例」も一般には言えない
5. **不可能と示していないことは、可能と示したことではない**（§2.7）。どの候補についても MF を不可能とする一般的な定理は示しておらず、可能であることも示していない。構成の存在、局所的で価値を使わない学習で得られるか、計算の制約の下で足りるかは、未決の研究の問いである。S1 の判断は、決まった規模・許される学習則・計算の要求量・生物との対応・識別のしやすさの比較になる

## 10. 専門知識がなくても読める解説（t-k さんへ）

### 何を比べたか

AnIma-ll の「部品」（Unit）の作り方を 4 つ並べて、S2 で整理した 10 個の記憶の働きを持たせられるかを比べました。

- **C0（今の作り）**：1 つの部品が、1 秒ごとに「発火した／しない」を出す
- **C1**：1 つの部品が、ニューロンの群れの「にぎやかさ」を 1 つの数で表す
- **C2**：1 つの部品が、群れの様子を数個の数で表す
- **C3**：大部分は C1・C2 のようにまとめて、大事なところだけ細かく作る

### 分かったこと

1. **「群れ」と呼ぶか「ニューロン」と呼ぶかは、計算の中身を変えません。** 変わるのは、部品の中にいくつの数を持たせるか、部品どうしをどうつなぐか、です
2. **群れを 1 つの数にまとめる作り方では、群れの中の「誰が活動しているか」を最初から持てません。** 学習で群れの中に偏りができると、群れの「にぎやかさ」だけでは、次に何が起こるかが決まらなくなります（数式の例で示しました）。ところが、記憶の跡は、脳の中では「ある場所の、一部の細胞」として残ることが多いのです。だから C1 で記憶を持たせるには、部品をたくさん並べて、「どの部品が活動しているか」で記憶を表す必要があります
3. **少しの手がかりから思い出す、少しの間覚えておく、といった働きを「つながりで活動を支え続ける」やり方で作るなら、つながりがある程度強い必要があります。** これは数式で示せました。ただし、別のやり方（ゆっくり変わる状態に残す、など）もあるので、これは働きそのものの条件ではありません
4. **どの作り方についても、記憶の働きが「無理」だと示す理屈は見つかりませんでした。でも、「できる」と示せたわけでもありません。** AnIma-ll の決まり（局所的に、価値を使わずに学ぶ）で、経験からそこまで学べるかは、これからの研究の問いです
5. **記憶の働きのうち、半分くらいは部品の作り方ではなく、「つながりがどう変わるか（学習の規則）」や「全体をどう組むか」で決まります**

### 計算機について

ニューロン 1 個ずつを写す作り方は、スーパーコンピュータでも人間の脳の 1% を、とても遅くしか動かせませんでした。だから「まとめ方」は必要です。ただし、どのまとめ方にするかを、今の予算だけで決めることはしません。構造の候補を絞ってから、必要な計算機を見積もります。
