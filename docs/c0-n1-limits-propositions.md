### 0.3 結論の先取り

1. **N-1 を「情報が全状態から完全に消える」の意味では立てない**（§1.3、台帳 006）。区別するもの・保持の塊・許す読み出しと介入・時間と精度を指定して立てる（§3.0）。その根拠の一つとして、**同じ個体の、ある時刻に重みだけが違う 2 本体は、その後、発火の列が違ってくるか、重みの違いが正の倍率で保たれるかのどちらかで、違いが黙って消えることはない**（命題 R1-3。実数の算術）。一方、自然な本体どうし（重み・Unit の状態・痕跡がすべて違う）の全状態での識別は、単射も衝突も【未証明】である。したがって C0 の N-1 は、(a) 内容がそもそも書き込まれない・外へ出ない〔構成上〕、(b) 読み出しの類を指定する〔読み出しの類〕、(c) 値の領域を指定する〔値の領域〕、のどれかの形で立てる。「活動に現れない」は読み出しの感度の問い、「行動に使えない」は出口の問いで、どちらも「内部に情報がない」とは別である
2. **〔構成上の不可能〕が立つのは次の内容**（命題 R1-1・R1-2）
   - **刺激の同一性を経験から形成すること**（どの Unit が刺激を受けるか・刺激どうしの似かたを経験で作ること）。入口の写像は固定で、刺激は中身のない出来事なので、入口での表現は経験で変わらない。刺激が他の Unit に経験に依って与えうる直接の駆動は、1 段で高々 w_max（閾値の約 2%）。〈世界〉と〈構成〉の両方の変更が要る
   - **覚えた内容を行動に使うこと・自分の行動が次の感覚を変えることを学ぶこと**（契約の MF9 後半、原則 §6 の 6）。出口がなく、感覚の列は脳の状態に依らない。〈構成〉（行動の意図の出口）と〈世界〉（行動に応じる規則）の両方が要る
   - 3 つを超える要素を、それぞれ専用の入口で受けること（Receptor と Unit が 3 つずつ）。〈世界〉と〈構成〉
3. **〔読み出しの類に限った不可能〕が立つのは次の内容**
   - 時間差・間隔：重みだけを読む比較では、時間差は 1 本の重みの更新の大きさにだけ入り、別々には運ばれない（I-1、命題 R1-4）。時間差 28 と 30 の 1 回の組の違いは、重みの上で約 3.4 × 10⁻⁷（w_max の約 0.003%）【算術】。直接一段の遅れは 1 に固定（I-2）
   - 3 要素の順序：時間差 1 の組の数 N（0028〜0033 の Δ_AB・D はその関数）では、3 点以上の順序は決まらない（U2、命題 R1-6）。**0028〜0033 の統計は、3 要素の順序をそもそも見られない**
   - 向きによらない結びつきの強さ：組の和の保存で、組の重みは 1 つの数（向き）しか持たない（F1、命題 R1-7）
   - 同時に起きたこと：同じ Pulse の発火は重みに書かれない（命題 R1-8）
4. **〔値の領域での不可能〕**：出生時の余裕 g ＜ −0.03 の Unit は、どの本体でもどんな重みでも主の区間で発火しない（担い手の設計 命題 6）。その Unit の自発の発火に頼る読み出しは、その個体で必ず凍結する。0033 の全種類・全判定の凍結 9 個体は、どれも A が全自然本体で沈黙した個体で、出生時の層は構造的 3・条件付き 6 だった【既存の結果】
5. **N-1 が立たない内容**：時間差 1 の後続関係（A の直後の B）は〔観測された〕（0028 の L3、0029〜0033 の C-I、0030 の F）。3 要素の順序・間隔は、全状態では〔未識別〕で、間隔は〔問いの対象が世界にない〕。多要素の活動のパターンの再出現も〔未識別〕。これらについて「C0 では表せない」とは言わない
6. **ゲートへの帰結**（§5）：N-1 は、**入口の形成と、閉じたループ（行動を介した内容の利用）について、構成から立つ**。どちらも〈世界〉と〈構成〉の両方の変更が要る（N-2）。時間差・間隔について構成の変更を決める根拠は、重みだけの I-1 では足りない（全状態は〔未識別〕）。どの N-1 も、新しい構成で足した部品が働くことの証拠ではない（それは N-3 の見込みで、別に書く）

## 1. N-1 とは何を示すことか

### 1.1 ゲートの N-1

相関と必要性 §5.2 は、次の構成の検討を始められる条件の一つ目を次のように定める【既存の命題】。

> N-1：主張したい内容（例：3 要素の順序、時間差・間隔、刺激の同一性の経験による形成、内容の利用）について、C0 とこの世界で運べない・活動に現れないことが、明示した前提のもとの命題、または信頼性の検証を伴う事前登録の結果で示された

- N-1 は**内容ごと**に立てる。ある内容で N-1 が立っても、ほかの内容については何も言わない
- 同 §5.2 のとおり、「C0 の未解決がすべてなくなる」ことは条件にしない

### 1.2 実験の不成立は N-1 にならない

C-II の整理 §9.1（非棄却の非対称）のとおり、0023〜0033 の形の判定は交換可能性の帰無仮説の棄却で、不成立は「棄却できなかった」にとどまる【既存の命題】。実験で N-1 を示すには、検出力を設計した同等性の形が要り、20 個体では 0／20 でも外れの頻度の上限が 0.139 にとどまる（C-II の整理 §5 (iii)）。**この文書は、命題で N-1 を立てる道だけを扱う。**

### 1.3 「情報がある」「区別できる」「使える」を分ける

台帳 006 の回答に従い、次の三つを分ける。

- **情報がある**：理想の実数の全状態で、二つの履歴の後の状態が違う
- **区別できる（現れる）**：指定した読み出し・有限の精度・有限の観測時間で、違いが判定できる
- **使える**：違いが、その個体の処理・行動に入る（相関と必要性 §1.1 の「意味」の側）

- 「運べない」を「情報がない」と読むと、C0 の N-1 はほとんど立たない。ある時刻に重みだけが違う本体どうしでは、違いは黙って消えない（命題 R1-3）。ただし、これは自然な本体どうしの全状態が履歴について単射だという主張ではない。指数的に減る項が 0 にならないことだけでは単射は従わず（台帳 006）、自然な本体どうしについては、単射も衝突も【未証明】である
- 有限の精度の実装は、無限に続く履歴を区別し続けることはできない。しかし、それだけで、有限の内容（3 要素の順序・間隔など）を保てないとは言えない（台帳 006）
- **この文書は、N-1 を「情報が全状態から完全に消える」の意味では定義しない**。N-1 の命題は、「書き込まれない（入口・出口・規則の形）」「指定した読み出しの類では区別できない」「指定した値の領域では発火しない」のどれかの形で、§3.0 の表のとおり、区別するもの・保持の塊・読み出し・時間と精度を指定する

### 3.1 命題 R1-1（入口での表現は経験で変わらない）【命題】〔構成上の不可能〕

**主張**：§2 の前提のもとで、どんな履歴のあとでも、
- (i) 刺激 k の感覚の出来事が Pulse t に成立すると、t ＋ 1 に s_k に駆動 1.0 が届き、ほかの Unit には直接の駆動は届かない。この写像（どの刺激がどの Unit を直接駆動するか、その強さ）は出生時と同じ
- (ii) 刺激 k が s_j（j ≠ k）に経験に依って与えうる駆動は、s_k が t ＋ 1 に発火したときの t ＋ 2 の w_kj(t) だけで、0 ≤ w_kj ≤ w_max ＝ 0.01（閾値の約 2%）。2 段以上の経路も、1 段ごとに 1 本あたり高々 w_max である
- (iii) 刺激は中身のない出来事で、刺激どうしに共通の特徴がない（どの 2 つの刺激も、別の Receptor の 1 回の出来事）

**証明**：(i) 入口の接続は可塑性の対象外で、重みは 1.0 のまま（設計図）。運び方は活動の伝達の仕様どおり次の Pulse（再評価 §1.3）。(ii) 刺激 k が s_j に届く経路は、s_k の発火による s 同士の接続だけで、その重みは [w_min, w_max] ＝ [0, 0.01] にある（柔らかい上限・下限）。(iii) 感覚の出来事に payload がない（活動の伝達の仕様 C2・C3）。∎

**帰結**

- 刺激どうしの似かたが世界にないので、契約の MF1（似た経験の区別）・MF7（共通の構造の抽出）の対象も C0 の世界にない（契約 §4 の表の「対象が存在しない」）

### 3.2 命題 R1-2（感覚の列は脳の状態に依らない：閉じたループがない）【命題】〔構成上の不可能〕

**主張**：§2 の前提のもとで、各個体の各本体について、感覚の出来事の列は（protocol、seed、本体の札の列）だけで決まり、脳のどの状態にも依らない。したがって、どんな内部の状態（経験で書き込まれた内容を含む）も、その後の感覚の入力を変えない。

**帰結**

### 3.3 命題 R1-3（重みだけが違う 2 本体の違いは、活動に出るか、正の倍率で保たれる）【命題】

**主張**：同じ個体の 2 本体 Y・Y′ が、時刻 t1 の処理の終わりに、可塑的な重みだけが違い（Unit の状態・痕跡・届く途中の駆動・それ以後の感覚の出来事は同じ）、w(t1) ≠ w′(t1) とする。このとき、どの t ≥ t1 についても、次のどちらかが成り立つ。
- (a) 区間 [t1 ＋ 1, t] のどこかの Pulse で、2 本体の発火が違う
- (b) すべての可塑的な接続 ij について、w_ij(t) − w′_ij(t) ＝ Π_{u=t1+1}^{t} σ_ij(u) · (w_ij(t1) − w′_ij(t1))。ここで σ_ij(u) ＞ 0 なので、t1 で違っていた接続は t でも違う

**証明**：区間で発火が同じなら（(a) でないなら）、痕跡 X は t1 で同じで、同じ発火で更新されるので区間で同じ。再評価 §1.4 の式で、σ_ij(u) ＝ 1 − a[X_i(u−1)s_j(u) ＋ X_j(u−1)s_i(u)] と β_ij(u) ＝ a X_i(u−1) s_j(u) w_max は発火と痕跡だけで決まるので、2 本体で同じ。差をとると β が消え、差は σ を掛けるだけで進む。X ≤ 1／(1 − κ) ≈ 6.67 なので a(X_i ＋ X_j) ≤ 0.134 ＜ 1、σ ≥ 0.866 ＞ 0（循環のメモ P0 と同じ条件）。∎

**帰結**
- **重みだけが違う本体どうしでは、重みに書き込まれた違いは、正確な算術では黙って消えない**。消えるとすれば、まず活動の違いとして現れる（(a)）。したがって、この形の比較（0029〜0033 の混成と同じ形）では、全状態の意味の「運べない」は成り立たず、N-1 は「指定した読み出しで現れない」（読み出しの感度）の形で問うことになる
- これは、自然な本体どうしの全状態が履歴について単射だという主張ではない（この節の最後の項、台帳 006）
- 0029〜0033 の混成（τ の状態の重みの塊だけを替えた本体）は、この命題の前提を満たす。そこで観測された外れは (a) の側が起きた例である【既存の結果。命題はその頻度を言わない】
- 浮動小数点では、差が丸めの大きさ以下になれば区別できなくなりうる（命題は実数の算術）
- 自然な本体どうし（O と W）は、痕跡と Unit の状態も違うので、この命題の前提を満たさない。自然な比較で違いが消えうるかは、この命題では言わない

### 3.4 命題 R1-4（時間差は、1 本の重みの更新の大きさにだけ入る）【既存の命題】と【算術】〔読み出しの類に限った不可能〕

**既存の命題**（相関と必要性 §3.1 の I-1、識別のメモ 命題 3.3・U7、理論のメモ 命題 4.6）：重みだけを読む・移す比較では、最終の重みの値が一致する履歴どうしを区別できない。時間差 L の組は、1 本の重みに κ^(L−1) で重みづけた 1 つの値として書き込まれる。学習した接続の通り道は組ごとの 3 値で、時間差を別々に持たない。

**算術**（再評価 §1.4 の式で、送り手 i が受け手 j の L Pulse 前に 1 回だけ発火し、その間に i のほかの発火がない場合）：1 回の組による w_ij の増加は a · κ^(L−1) · (w_max − w_ij) ≤ a κ^(L−1) w_max。

| 時間差 L | κ^(L−1) | 1 回の組の増加の上限（a κ^(L−1) w_max） |
|---|---|---|
| 1 | 1 | 1.0 × 10⁻⁴ |
| 2 | 0.85 | 8.5 × 10⁻⁵ |
| 28 | 0.0124 | 1.24 × 10⁻⁶ |
| 30 | 0.00898 | 8.98 × 10⁻⁷ |

- 時間差 28 と 30 の 1 回の組の違いは、上限の差で約 3.4 × 10⁻⁷（w_max の約 0.0034%）【算術】
- 痕跡 X_i は Unit ごとに 1 つで、i から出るすべての接続に共通である（再評価 §1.2 の痕跡の行）。どの時間差だったかは、別の変数には残らない

**分類**
- 重みだけを読む・移す比較：時間差・間隔の区別は〔読み出しの類に限った不可能〕（最終の重みが一致する履歴について）。一致しない場合も、時間差は他の組と混ざった 1 つの値にしか入らない
- 全状態（位相・痕跡・Unit の状態を含む）：〔未識別〕。区別できるともできないとも【未証明】。I-1 は全状態での区別を否定しない（相関と必要性 §3.1）。重みだけが違う本体どうしなら、重みに入った小さな違いも黙っては消えない（R1-3）が、それが読み出しに現れる大きさか、有限の精度・観測時間で区別できるかは別の問いである。理想の実数で違いが残ることから、単射を結論しない（台帳 006）
- 間隔の違いそのもの：C0 の世界は、どの本体でも枠 0・2・30 で、同じ組の間隔を変える経験がない。**〔問いの対象が世界にない〕**（契約 §4 の MF3 の「間隔は対象が存在しない」）
- 変わるには：まず〈世界〉（同じ組の間隔を変える、時間差を痕跡の時定数〔約 6〕と同じ程度にする。E-1 の小ささも主に世界の時刻から来る：相関と必要性 §3.1）。間隔を重みとは別の担い手に持たせるなら〈構成〉（接続ごとの遅延・痕跡の複数の時定数：再評価 §5.3 の (3a)(3b)）。**構成の変更を決める根拠は、重みだけの I-1 では足りない**（全状態は〔未識別〕）

## 8. 専門知識がなくても読める解説（t-k さんへ）

### 何を整理したか

次の脳の形へ進むかどうかの条件の一つに、「今の脳（C0）では、どうしてもできないことがある」と示すことがあります。今回は、実験をせずに理屈だけで、C0 で「できない」と言えることと、「まだ分からない」ことを分けました。

### 分かったこと

1. **C0 では、作りそのものからできないことが二つあります**
   - 経験から「刺激の見分け方」を作ること。C0 では、どの刺激をどの部品が受けるかが生まれつき固定で、経験で変わりません
   - 覚えたことを行動に使うこと。C0 には外へ働きかける出口がなく、何を覚えても、次に来る刺激は変わりません
   - どちらも、脳の作りと世界の作りの両方を変えないと試せません
2. **時間の間隔や、3 つ以上の並びについては「できない」とは言えません**。つながりの強さだけで比べる読み方では区別できないことは示せますが、脳の状態全体では分かっていません。今の世界では、間隔を変える経験そのものがないので、まず世界を変えて問うことになります。また、これまでの実験の数え方は、3 つ以上の並びをそもそも見られない数え方でした
3. **つながりの強さだけが違う二つの個体を比べる形では、違いは計算の上で黙って消えません**。反応の違いとして表に出るか、そのまま残るかのどちらかです。ただし、ふつうの個体どうしで違いが必ず残るかは、まだ証明できていません。また、「違いが残っている」ことと、「読み取れる」「使える」ことは別のことです
4. 9 個体で反応が出なかったのは、生まれつきほとんど動かない部品があったためで、内容がなかったからではありません
